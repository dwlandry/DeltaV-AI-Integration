# GitHub Integration

**Purpose:**
Maintain version control and a backup of the entire DeltaV AI Integration project, including:
- Obsidian notes and documentation
- Parsing scripts and other code
- Configuration and pipeline files

**Repository:**
[GitHub: DeltaV-AI-Integration](https://github.com/dwlandry/DeltaV-AI-Integration.git)

**Workflow:**
1. Develop changes locally.
2. Stage and commit changes using `git add` and `git commit`.
3. Push changes to GitHub with `git push`.
4. Use `git pull` to retrieve updates if multiple contributors or machines are in use.

**Branches:**
- `master` or `main`: Stable branch with working versions.
- `feature/*`: For new features or experiments (e.g., `feature/embedding-integration`).

**Change Tracking:**
- Code updates: Documented in commit messages.
- Obsidian note changes: Track updates via commit diffs. Use meaningful commit messages referencing the note or section changed.

**Backup and Safety:**
- GitHub acts as a remote backup.  
- If local machine fails, clone the repository elsewhere.
