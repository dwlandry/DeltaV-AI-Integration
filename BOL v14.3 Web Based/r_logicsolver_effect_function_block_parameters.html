Logic Solver Effect function block parameters

The following table lists the system parameters for the function block:

LSEFFECT Function Block System Parameters

Parameter

(Data Type)

Default Value

(Units)

Characteristics

Description

DELAY_TIMERn (Floating point)

0

NVM:

Preserved on Download

Countdown timer for the input trip delay function for IN_Dn.

DELAY_TIMEn (Floating point)

0

Access:

Configurable, Tuning

NVM:

Restored on Restart

Time the input must be in the tripped state before it is considered tripped.

DESC_INn (String)

None

None

User-defined label for IN_Dn.

DESC_OUT (String)

None

None

User defined label for OUT_D.

EFFECT_ALERTS (Option bitstring)

None

NVM:

Preserved on Download

Contains the runtime value of alarm conditions set by the block (inactive=0, active=1). The possible values are:
  • Forced: active when the block is being forced.
  • Trip: active when the block is in the Tripped state.
  • Inhibited: active when there are not enough eligible inputs to cause a trip.

  • Reminder: active when the force to normal timer is about to expire based on REMINDER_TIME.

ENABLEn (Boolean)

True

Access:

Tuning

NVM:

Restored on Restart

Indicates whether or not the input is enabled.

FORCE_EFFECT (Named Set)

Do Not Force

Access:

Operating

NVM:

Preserved on Download

Determines whether the block is forced to trip, forced to the normal state, or not forced at all.

FORCE_OPTS (Option bitstring)

None

Access:

Configurable

Configurable options for forcing effects. The possible values are:
  • Force permit not required to force to tripped
  • No timeout when forced to normal
  • Timeout on force to normal for indication only
  • Force permit control should be visible in Operator Interface

FORCE_PERMIT (Boolean)

False

Access:

Tuning

NVM:

Preserved on Download

Must be true in order for FORCE_OPTS to force the block.

FORCE_TIMEOUT (Floating point)

1

Access:

Configurable

Maximum period the block can be forced to Normal by FORCE_OPTS, in hours.

FORCE_TIMER (Floating point)

0

NVM:

Preserved on Download

Countdown timer indicating how long before the force to normal will be removed if the value of FORCE_OPTS is not Timeout on force to normal for indication only.

IN_D

False

Access:

Tuning

NVM:

Restored on Restart

Monitored value. IN_Dn is extensible from one to four.

INPUT_OPT (Named Set)

Any

Access:

Configurable

Determines whether any or all inputs must be tripped to cause the block to trip.

INPUT_STATEn

(Named Set)

Disabled

NVM:

Preserved on Download

Indicates the current state of the input. The possible values are:
  • Disabled
  • Normal
  • Delayed
  • Tripped

LATENT_TRIP (Boolean)

False

NVM:

Preserved on Download

When True, indicates that removing the force will result in a trip.

LOGIC_TYPE (Named Set)

Negative

Access:

Configurable

Indicates whether the tripped state is TRUE (Positive) or FALSE (Negative).

OUT_D (Boolean with status)

False

NVM:

Preserved on Download

Output value the block.

False if Tripped and True if Normal when the logic type is Negative. True if Tripped and False if Normal when the logic type is Positive.

OVERRIDES (Named Set)

None

NVM:

Preserved on Download

Indicates the highest priority override present on the block.

REMINDER_TIME (Floating point)

0

Access:

Configurable, Tuning

NVM:

Restored on Restart

Number of hours prior to force timeout required to generate an alarm.

REPORT_OPTS (Option bitstring)

None

Access:

Configurable, Tuning

NVM:

Restored on Restart

Configurable options for block reporting features:
  • Alarm conditions do not roll up to module level.
  • Input event records are not generated.
  • Output event records are not generated.

RESET_A(Boolean)

False

Access:

Operating

NVM:

Preserved on Download

Reset parameter used when going from tripped to normal based on RESET_OPTS.

RESET_B (Boolean)

False

Access:

Operating

NVM:

Preserved on Download

Reset parameter used when going from tripped to normal based on RESET_OPTS.

RESET_OPT (Named Set)

A only

Access:

Configurable

Determines how the two resets are used when the trip condition clears. The possible values are:
  • A only
  • A or B
  • A and B
  • A then B

RST_LATCH_TIME (Floating point)

30

Access:

Configurable, Tuning

NVM:

Restored on Restart

The period, in seconds, for which RESET_A and RESET_B are latched if the RESET_OPT is set to A and B.

RST_LATCH_TIMER

(Floating Point)

0

NVM:

Preserved on Download

Countdown timer indicating how long before the latch on the reset is cleared.

STATE (Named Set)

Normal

NVM:

Preserved on Download

Indicates the current state of the block.
