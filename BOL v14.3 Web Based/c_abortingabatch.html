Aborting a batch

Aborting a batch permanently halts the operation of a batch and transitions the batch to the Aborted state. The abort command uses the abnormal or aborting logic defined for the phase. You cannot use the RESTART command with an aborted batch.

Aborting a batch typically occurs in an emergency situation. The operator terminates the batch and secures the equipment in a safe condition.

You can only abort a batch that is in one of the following states:

  • Running

  • Stopping

  • Holding

  • Held

  • Restarting

In the paint recipe, several equipment units are used, including MIX 1 and MIX 2. If, for example, there is an electrical fire in MIX1, the operator or supervisor can immediately put the batch into the Abort state. This terminates the batch production and this batch cannot be restarted.
