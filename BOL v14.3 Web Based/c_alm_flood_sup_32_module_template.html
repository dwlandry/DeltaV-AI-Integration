ALM_FLOOD_SUP_32 module template

The ALM_FLOOD_SUP_32 (alarm flood suppression) module template implements automatic suppression of redundant and consequential alarms resulting from a significant equipment failure or process disturbance, such as the trip of a compressor. When detected, a single common alarm is presented to the operator and all of the expected consequential alarms associated with the event are suppressed, assigned a different priority, or both.

The ALM_FLOOD_SUP module template consists of standard DeltaV function blocks and provides these capabilities:
  • Up to 32 participating alarms that can be configured for suppression and/or priority change.
  • Zero to eight configurable process conditions that must be true for suppression activation. Configurable options include on/off delay and error options.
  • Zero to eight configurable process conditions that represent votes to activate suppression. Configurable options include the number of needed votes, on/off delay, and error options.
  • Supervisor and operator enablement.
  • Configurable post-suppression time out behavior. Configurable behavior options include
    • re-suppress all participating alarms.
    • unsuppress all participating alarms.
    • unsuppress all participating alarms not currently in an active condition.
  • Auto reset capability.
Note: This module does not support phase alarms or alarms from other zones.
