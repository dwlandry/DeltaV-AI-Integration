DVBCMERRORCODE

Campaign Manager specific error codes (listed below) are mapped to well-formed Campaign Manager error strings. For example, the error code dvbcmErrorInvalidCampaignState returns the string: The Campaign is not in a valid state to complete this action. Otherwise, a generic COM error code is used. For example, if a caller passes an empty string to a method which requires that parameter, the error returned would be E_INVALIDARG and the error string returned would be, The parameter is incorrect.
