Starting the Recipe Simulator

Start Recipe Simulator to run tests of your batches. You must have completed the following before running Recipe Simulator:

  • Enable the Batch Executive from DeltaV Explorer.

  • Assign the phase to the unit and controller.

  • Set the phase's Simulate option (by clicking Simulate in the Phase Properties dialog).

  • Clear the Work in Progress check box (on the recipe's Properties dialog) to release the recipe to production.

  • Download the control network configuration to the controller (download the Batch Executive, the controller and the workstation, at the least).

When you start Recipe Simulator, it reads the equipment information that is specified for the current batch. If you modify Recipe Simulator configuration and want to save your changes, use the Save As command under the File menu. The file name extension must be .SIM. For example, you change the phase configuration requests and unit parameter values. Each time you simulate the PAINT recipe you want to use these settings, therefore, you save the file with these settings as PAINT.SIM. You can then open that file next time you simulate this recipe.

To start Recipe Simulator, click Start > DeltaV Batch > Recipe Simulator.

Note:

Recipe Simulator will not run using Windows Remote Desktop.
