Bulk editing classless module containing classless module

This example explains how to create and bulk edit classless modules that contain other classless modules. This example is similar to the CASCADE_MASTER and CASCADE_SLAVE module templates which consist of a control module template containing another control module template.

The methods explained here apply generally to other types of containing and contained objects. The steps necessary to complete this example are:

  1. Create a template and instantiate the template.

  2. Create format specification files for the containing and contained modules.

  3. Export the contained (lower level) modules.

  4. Export the containing (top level) module.

  5. Create new modules using Bulk Edit.

  6. Import the contained modules.

  7. Import the containing module.

Subtopics:

  • Create format specification files for the example
