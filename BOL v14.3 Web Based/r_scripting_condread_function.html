CondRead function

CondRead() reads a parameter path and returns either the parameter value or a specified fallback value (if the path fails the Exists() test).
Arguments
2
Argument Description
path string A literal or graphics expression that resolves to a DeltaV parameter path.
fallback value The value to return if the path string does not exist (fails the Exists() test).
Return values (string)
The value of the specified path, if Exists() returns True.
The specified fallback value, if Exists() returns False.
Syntax
DLSYS.CondRead(path string, fallback value)
Examples
The examples in this table demonstrate how to use CondRead() to replace data that cannot be read (has 'bad' data quality) with a designated fallback value.
Example Result 
DLSYS.condRead("MOD1/PID1/SP",DLSYS["MOD1/PID2/SP")
 The set point of MOD1's PID2 block. 
DLSYS.condRead("MOD1/PARAM1",DLSYS("MOD1/PARAM2")
 MOD2's PARAM2
This example demonstrates how to use CondRead() to extract bit-level data from data values that hold bit-packed information.
Example Result
Assume you have a running module that contains a Boolean Fan Output function block with four outputs. On a display, add a data link that allows online changes and whose expression is DLSYS["MOD2/BFO1/IN_INT.CV"]. Add a second data link with the following expression: 
DLSYS.WriteAsync("MOD2/BFO1/IN_INT", 16)Dsp.Text1.Label = 
DLSYS.condReadBit('MOD2/BFO1/IN_INT', 1, 1,'GoodNonCascade')Dsp.Text2.Label = 
DLSYS.condReadBit("MOD2/BFO1/IN_INT", 2,0)Dsp.Text3.Label = 
DLSYS.condReadBit("MOD2/BFO1/IN_INT",3,0)Dsp.Text4.Label = 
DLSYS.condReadBit("MOD2/BFO1/IN_INT",4,0)Dsp.Text5.Label = 
DLSYS.condReadBit("MOD2/BFO1/IN_INT",5,0)
 When the DeltaV Live user modifies the input value of the Boolean Fan Output block, the data link's label shows the bit-level data.
