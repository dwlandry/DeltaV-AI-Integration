High Performance MultiPoint vertical dynamo (HP_VertMultiPoint)

The HP_VertMultiPoint dynamo maps from 2 through 10 online control module parameters in a way that makes it easy for operators to observe when values deviate from the defined operating range.

This dynamo can be configured for a level 1, 2, or 3 display. It can also be configured to appear transparent by matching its background color to either the picture background color or an object’s foreground color.
