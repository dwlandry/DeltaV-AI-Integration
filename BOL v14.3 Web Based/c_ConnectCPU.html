Connect the CPU to the DeltaV system

In hazardous locations the CPU should not be removed or inserted into the carrier unless the input power has been deenergized for at least one minute.

The CPU performs control, communications, and power conversion for the Zone 1 I.S. system. It uses a pair of 100M fiber-optic Ethernet ports (100 Base-FX) to provide redundant communication with the DeltaV system. Each port must be converted from 100M fiber-optic media to the 10/100M ethernet twisted-pair media. If the CPU is located in a Zone 1 location, a media converter with fiber-optic ports certified to allow a cable to be routed to Zone 1 locations is required. Emerson offers the Single Port Fiber Switch which has the required certifications. Refer to the DeltaV TM M-series Hardware Installation and Reference manual for information on the Single Port Fiber Switch. Fiber cables (62.5/125 micron multimode) with standard MT-RJ style jacks connect directly to the CPU.
