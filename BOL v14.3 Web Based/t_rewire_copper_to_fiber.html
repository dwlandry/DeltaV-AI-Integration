Rewire a WIOC or CIOC carrier installed with a copper IOP with fiber-optic cable

The I/O Ports (IOPs) on the CHARM I/O Carrier (CIOC) and the WirelessHART I/O Carrier (WIOC) are removeable to allow either copper or fiber-optic cabling between carriers and switches.

  1. Remove the network cable (copper) from the standby WIOC or CIOC's secondary control network port.
  2. Remove the copper IOP from the standby WIOC or CIOC's secondary control network port by depressing the button next to the IOP and pulling the IOP out of the carrier.
  3. Install a fiber IOP in the standby WIOC or CIOC's secondary control network port.
  4. Connect fiber-optic cable between the fiber IOP and a DeltaV Four Port Fiber switch. Refer to the DeltaV TM M-series Hardware Installation and Reference manual for information on the DeltaV fiber switches.
  5. Connect copper cable between the DeltaV Four Port Fiber switch and the secondary control network switch.
  6. Remove the network cable (copper) from the standy WIOC or CIOC's primary control network port.
  7. Remove the copper IOP from the standby WIOC or CIOC's primary control network port by depressing the button next to the IOP and pulling the IOP out of the carrier.
  8. Install a fiber IOP in the standby WIOC or CIOC's primary control network port.
  9. Connect fiber-optic cable between the fiber IOP and a DeltaV Four Port Fiber switch.
  10. Connect copper cable between the DeltaV Four Port Fiber switch and the primary control network switch.
