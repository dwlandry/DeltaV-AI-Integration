Reporting alarm data

Alarm data can be audited through reports generated in the System Alarm Management application. Alarm reporting is available only on a Professional Plus workstation.

There are two report options available; Runtime and Difference. Both reports include the following features:
  • Alarms can be filtered by alarm type and functional classification.
  • Items such as node or area can be added.
  • Reports can be automated to run on a schedule.
Note: Report configuration parameters are exported and imported with the database.

Runtime Report

The Runtime Report lists basic run-time alarm parameters, regardless of their deviation from their configured values. The report format for a Runtime report includes:
Header
Displays the report name, report type, and the date and time the report was last run.
Alarms
Displays the alarm paths for the selected runtime alarms.
Filters Applied
Displays the filters applied and items selected for the report.

Difference Report

The Difference Report shows the differences between the run-time alarm parameters and their configured values. The report format for a Difference report includes:
Header
Displays the report name, report type, and the date and time the report was last run.
Summary
Displays summary information for the runtime alarms and the configured alarms.
Alarms
  • Displays configured alarms whose properties differ from its runtime values, and what those differences are.
  • Displays configured alarms that do not appear in runtime.
Filters Applied
Displays the filters applied and items selected for the report.
