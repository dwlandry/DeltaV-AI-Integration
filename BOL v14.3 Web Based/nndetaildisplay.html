Neural network detail display (NN_DT)

DeltaV Operate View of the Neural Network Function Block Detail Display (NN_DT)

The following items are contained in the Neural Network function block detail display:

  • Limits:

    • Corr_Lim - This area displays the maximum value of the correction limit..

    • Corr_Filter - This area displays the correction filter value.

  • Operating:

    • STDEV - This area displays the standard deviation of the Actual Value.

    • Corr_Bias - This area displays the bias applied to the correction.

  • I/O:

    • Follow - This area indicates whether following (output tracking the input or the input times gain) is active. True (1) means following is active; False (0) means following is not active.

    • Sample - This area displays the current sample value.

    • Delay - This area displays the delay value.

  • IN1 through IN20 - These fields display the descriptions and current values of the reference inputs to the neural network. (Only the inputs that have been configured appear.)
