Enhanced Device Control function block alarms

The EDC block supports the standard block alarm. The block sets the standard block alarm if the block goes into Local Override mode, into simulation, fails to read the feedback inputs, or encounters one or more feedback inputs with bad status.

Configure the alarm limits for the following standard alarms:
  • CFM_STATE0_TIME - The maximum time allowed to change from any state to State 0.
  • CFM_STATE1_TIME - The maximum time allowed to change from any state to State 1.
  • CFM_STATE2_TIME - The maximum time allowed to change from any state to State 2.
  • CFM_STATE3_TIME - The maximum time allowed to change from any state to State 3.
  • CFM_STATE4_TIME - The maximum time allowed to change from any state to State 4.
  • CFM_STATE5_TIME - The maximum time allowed to change from any state to State 5.
  • CRACK_TIME - The maximum time allowed to lose confirmation for the state previous to this transition.
  • DELAY_TIME - Specifies the delay time when SP_D is changed from the Confirmed Passive state to an Active state before the change is sent to PV_STATE logic.
  • RESTART_TIME - Specifies the delay time when SP_D is changed when the Enhanced Device Control block is not in the Confirmed Passive state. The value of OUT_D is held at the Passive state while DELAY_TIMER is active.
  • TRIP_TIME - The time that a state confirm can be lost before the confirmation is considered lost.

To monitor failed state transitions, use the block FAIL_ACTIVE parameter to indicate a state transition failure has occurred with the reason code stored in the FAILURE_STATE.

To monitor operation, use the ILK_SHUTD_ACTIVE parameter to indicate to the operator when there is an interlock or shutdown condition that changes the command OUT_D with reason code stored in OPERATION_STATE.

The block contains a WRITE_ERR_ACTIVE parameter to indicate to the operator when Write Alarm is present.

The block contains a SENTINEL parameter that is set when FAIL_ACTIVE or ILK_SHUTD_ACTIVE or WRITE_ERR_ACTIVE becomes True.
