Historian installation

You can install, enable, and run the DeltaV Continuous Historian, the default historian for DeltaV, on the following local (inside the DeltaV ACN) or remote workstations:

  • Local: ProfessionalPLUS workstation, Application Station, or Operator Station
  • Remote: Application Station or Operator Station

You can install, enable, and run the Advanced Continuous Historian on the following local (inside the DeltaV ACN) or remote workstations:

  • Local: Application Station
  • Remote: Application Station

You can install, enable, and run OSIsoft PI Server on the following local (inside the DeltaV ACN) or remote workstations:

  • Local: Application Station
  • Remote: Application Station or non-DeltaV workstation

Install and enable the DeltaV Continuous Historian

To install and enable the DeltaV Continuous Historian to run on an Application Station:

  1. While installing DeltaV, select the DeltaV Continuous Historian option in the Select Historian dialog.
  2. After installing DeltaV, start DeltaV Explorer, and then navigate to the Application Station node under System Configuration > Physical Network > Control Network > node_name > Continuous Historian in the DeltaV_System pane.
  3. Right-click Continuous Historian, and then select Properties to open the General tab of the Continuous Historian Properties dialog.
  4. Select the Enabled option and the Use DeltaV Continuous Historian option in the Continuous Historian Selection box.

When you install DeltaV on a ProfessionalPLUS or Operator Station, the DeltaV Continuous Historian is automatically installed by default. To enable the DeltaV Continuous Historian after installing DeltaV:

  1. Start DeltaV Explorer, and then navigate to the ProfessionalPLUS or Operator Station node under System Configuration > Physical Network > Control Network > node_name > Continuous Historian in the DeltaV_System pane.
  2. Right-click Continuous Historian, and then select Properties to open the General tab of the Continuous Historian Properties dialog.
  3. Select the Enabled option.

Install and enable the Advanced Continuous Historian

To install and enable the Advanced Continuous Historian to run on an Application Station:

  1. While installing DeltaV, select the Advanced Continuous Historian option in the Select Historian dialog.
  2. After installing DeltaV, start DeltaV Explorer, and then navigate to the Application Station node under System Configuration > Physical Network > Control Network > node_name > Continuous Historian in the DeltaV_System pane.
  3. Right-click Continuous Historian, and then select Properties to open the General tab of the Continuous Historian Properties dialog.
  4. Select the Enabled option and the Use Advanced Continuous Historian option in the Continuous Historian Selection box.

Install and enable PI Server

To install and enable PI Server to run on an Application Station:

  1. While installing DeltaV, select the Enterprise Historian option in the Select Historian dialog.
  2. After installing Deltav, install PI Server on the Application Station according to the documentation from OSIsoft.
  3. Start DeltaV Explorer, and then navigate to the Application Station node under System Configuration > Physical Network > Control Network > node_name > Continuous Historian in the DeltaV_System pane.
  4. Right-click Continuous Historian, and then select Properties to open the General tab of the Continuous Historian Properties dialog.
  5. Select the Enabled option and the Use Enterprise Historian option in the Continuous Historian Selection box.
  6. Configure PI Server to run on the Application Station according to the documentation from OSIsoft.

To install and configure PI Server to run on a non-DeltaV workstation:

  1. Refer to the documentation from OSIsoft.
