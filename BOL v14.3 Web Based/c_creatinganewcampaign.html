Creating a new campaign

After connecting to a Campaign Manager server, the first step is to get a new, blank campaign edit object. To acquire a blank campaign, the application must provide a unique campaign name to the Campaign Manager server. Typically the user will enter this information. Once a campaign name/ID has been entered, simply call the NewCampaign method providing the unique campaign name/ID.

The following is an example of this process written in Visual Basic that shows how to correctly create a new campaign.

Private Sub CreateCampaign()
    Dim strNewCampaignID As String
    Dim objCampaignEdit As IDVBCMCampaignEdit4
    ' Prompt the user for a unique campaign ID
    Call PromtUserForCampaignID(strNewCampaignID)
    ' Retrieve a blank campaign edit object
    Set objCampaignEdit = DVBCMClient.NewCampaign(strNewCampaignID)
End Sub

If the campaign name/ID passed in to the new campaign function is not unique, the call will fail. The NewCampaign method puts the new campaign into the defining state. At this point, the new campaign object has not been added to the Campaign Manager server and only the creating client application can work with the new object. Only after calling the DVBCMClient.AddCampaign method will the campaign be added to the server for all clients of the server to see.

After a campaign edit object has been retrieved, properties of the campaign; for example, prefix, suffix, description and maximum active batches, can be retrieved and set as the following code example shows.

Private Sub SetCampaignProp(ByRef objCampaignEdit As IDVBCMCampaignEdit4)
    Dim strPrefix As String, strSuffix As String
    Dim strDescription As String
    Dim lMaxActiveBatches As Long
    ' Retrieve batch properties from user
    Call GetCampaignPropertiesFromUser(strPrefix, strSuffix,
        strDescription, lMaxActiveBatches)
    ' Set new properties
    objCampaignEdit.Prefix = strPrefix
    objCampaignEdit.Suffix = strSuffix
    objCampaignEdit.Description = strDescription
    objCampaignEdit.MaximumActiveBatches = lMaxActiveBatches
End Sub
