Naming graphics configurations

Names are language-independent strings used to identify graphics configurations in Graphics Studio.

Naming displays, display sets, layouts, and GEM classes, standards, and functions

When you create a graphics configuration, Graphics Studio provides a default name for that configuration. When you create a display, display set, layout, or GEM class, its default name is highlighted in the Explorer view, where you can immediately enter a new name for that configuration. When you create a new standard or function, you must double-click its name in the Graphics Configuration pane to enter a new name.

When naming one of these configurations, the following naming conventions apply:
  • Names must be unique within the permanent library folder containing them. For example, display names must be unique within the Displays permanent folder.
  • Names must be from 1 to 48 UNICODE characters.
  • Names can contain only letters, numbers, $, or _.
  • Names must contain at least one alpha character (either lowercase or uppercase) letter
  • Names cannot contain spaces
  • Names are case insensitive

Naming languages and themes

New languages also have default names which can be changed in the Content pane's Name field. The names of languages and themes follow these naming conventions:
  • Names must be unique within the permanent library folder containing them. For example, display names must be unique within the Displays permanent folder.
  • Names must be from 1 to 3 UNICODE characters.
  • Names can contain only letters, numbers, $, or _.
  • Names must contain at least one alpha character (either lowercase or uppercase) letter
  • Names cannot contain spaces
  • Names are case insensitive
Note: To maintain consistency, it is recommended that language names follow the ISO 639-1 alpha-2 or 639-2 alpha-3 codes. For example, ru or rus for Russian and de or deu for German.
