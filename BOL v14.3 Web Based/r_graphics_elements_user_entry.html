User entry elements reference

User entry elements provide a variety of ways for DeltaV Live users to interact with the application and data sources presented.
Button

A button provides a control with which DeltaV Live users can trigger one or more actions. A button can also be configured with an icon image.

Check box

A check box provides a control that allows users to show, hide, or change parameters, variables, and such that should be interpreted as either on or off.

Combo box

A combo box is a combination of a list box (drop-down list) and a text box. It is used to map data source values to multi-language strings and then present these strings as options from which DeltaV Live can select.

If the combo box has been configured to allow writes, users can also modify the source values.

A combo box serves well when a large number of options need to be presented.

Radio button

A radio button is similar to a combo box, but presents an option as a button rather than a list selection.

Radio buttons serve well when a small number of options need to be presented.

Slew

A slew provides a means for DeltaV Live users to incrementally increase and decrease an information source value. The amount the value changes is proportional to how long the button is pressed.

Slider

A slider provides a means to visually show an information source value in the context of its full range.

If the combo box has been configured to allow writes, users can also modify the source values.

Text entry

A text entry provides a means for users to enter textual information while online. Text entries are commonly used in contextual displays, typically as text entry forms or dialogs.
