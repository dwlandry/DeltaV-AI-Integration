Download an SIS Controller

You must have the privilege to perform DOWNLOAD_CONFIG to download an SIS Controller. You do not need the equivalent SIS privilege.

  1. Navigate to an SIS Controller in the Control Network.
  2. Right-click and select Download > SIS Controller. The Confirm Total Download dialog appears.
    Note:

    If you select any of the other Download options, a similar dialog appears.

  3. Click Yes to start the download.
