Install and license DeltaV Simulate Suite

With each purchase of DeltaV Simulate, you receive DeltaV installation disks, a DeltaV Simulate Access Key and a DeltaV Simulate license. Use the DeltaV installation disks to install DeltaV Simulate.

Installing DeltaV Simulate requires administrator privileges. If your computer is connected to a Plant LAN, you must also have domain privileges to be able to log on after DeltaV Simulate is installed. For proper installation, the computer must meet the minimum requirements as outlined in the DeltaV Compatibility Chart for this release (located at http://www.emersonprocess.com/Systems/support and in your DeltaV software Media Pack). In addition, the computer must be running NTFS and have TCP/IP functionally installed even if it is isolated from any network.

Install DeltaV Simulate Suite

If you have a DeltaV Simulate Multinode license, the procedure to install DeltaV Simulate is the same as for a standard DeltaV workstation installation; after DeltaV installation, assign the DeltaV Simulate Multinode license.

If you have a DeltaV Simulate Standalone license, the procedure to install DeltaV Simulate is similar to a standard DeltaV workstation installation, except for the selection you make in the Select Your Workstation Type dialog. To install DeltaV for a DeltaV Simulate Standalone license, complete the following steps:

  1. Insert DeltaV installation disk #1 in the drive, and then proceed with DeltaV installation.
  2. When the Select Your Workstation Type dialog appears, select the Simulate for standalone laptop or workstation option.
  3. After the installation of DeltaV is complete, you will be automatically logged off.
  4. When you log back in, you will automatically enter the workstation configuration procedure of DeltaV installation.
  5. In the DeltaV Workstation Configuration dialog, confirm that Simulate for standalone laptop or workstation is selected in the Select Workstation Type options.

After the completion of DeltaV Workstation Configuration, select the option to log off. When you log back on, you should use your domain or workgroup name and password.

License DeltaV Simulate Suite

Before you can use DeltaV Simulate, you must install the DeltaV Simulate Access Key and assign the DeltaV Simulate license.

DeltaV Simulate Suite requires that the DeltaV Simulate Access Key be attached to your computer and the DeltaV Simulate license be loaded in DeltaV Explorer and assigned to your workstation.

After DeltaV Simulate has been installed and licensed, you can utilize DeltaV Simulate's capability to create DeltaV process control configurations. Also, you can assign and download modules to the ProfessionalPLUS workstation.
