Creating a procedural function chart (PFC)

Recipe Studio lets you create procedures using a PFC editor. A PFC is a graphic representation of the recipe's logic. You construct the PFC using steps, transitions and terminations as found on Recipe Studio Palette.

Each chart consists of steps and transitions as shown in the following figure.

PFC Steps and Transitions

Procedural Function Charts (PFCs) are the backbone of creating and modifying recipes. This subsection describes the basic tasks needed to create these charts. These tasks include:

  • Adding steps to each operation, unit procedure, and procedure.

  • Configuring each step.

  • Adding transitions.

  • Linking steps and transitions together.

  • Configuring each transition.

Information and instructions on these tasks are provided in the sections Defining Steps and Defining Transitions.

Once you create a PFC, you need to maintain it so it reflects your changing needs.
