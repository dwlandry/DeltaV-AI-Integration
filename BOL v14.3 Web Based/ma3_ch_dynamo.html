MA3_CH_ analog dynamo, 3 function blocks, horizontal combination bar graph

This dynamo can be used for analog values of analog modules (PID loops, AI indicators, ALM function blocks) where the output is not needed.

The following elements are present on the dynamo:

  • Alarm Icon

  • Combination (Combo) Bar Graph

  • Display Tag

  • Dynamo Background

  • Engineering Units Descriptor

  • Mode Icon

  • PV Data Field

  • Status Icon
