Adding files to the system tree

You can add files to the system tree by editing the bottom section of the SystemTree.CSV file. Use the table below entitled "File Attributes" as a guide to editing the file.

To add a file to the system tree:

  1. Open the SystemTree.CSV file located in the Local path.
  2. Insert a row in the bottom section of the file with the other files.
  3. Enter the information for the file in the attribute fields. For example, to add a text file called Alarm File within the Alarms folder enter the following:

    For the attribute...

    Enter...

    Key

    Alarms\Alarm File

    Key Type

    File

  4. Save the file in the Local path with a .CSV extension.
  5. Close DeltaV Operate.
  6. Select Run from the Windows menu and enter WorkSpace /unregserver in the Open field.
  7. Click OK.
  8. Restart DeltaV Operate.

Folder definitions include the attributes in the following table.

File Attributes

The attribute...

Defines...

Key

The names of the files that appear directly off the system tree root. By adding a new name, you add a new file to the system tree. If you want the file to appear inside a folder, enter the complete path. For example, to add a globals file called OEMGlobals to the Globals folder you would enter:

Globals\OEMGlobals

Key Type

Each entry as a file and always has the value FILE.

AppKey

An entry that is reserved for future use and can be left blank.

Vendor

A company name. When you add a file, enter the name of your company. Completing this attribute is optional.

Fix Path

The complete path to each file. This must be a FIX path and the file name.

If the file resides in an iFIX path, you can specify the path with a predefined alias, such as PDB_PATH or BASE_PATH. For example, if you are adding a globals file, enter PIC_PATH since all global files resides in the iFIX Picture path.

AutoLoad

Whether DeltaV Operate automatically opens the file on start-up. This attribute is set to TRUE for globals files only. Typically, this attribute is set to FALSE.

HiddenInTree

Whether the file is visible or hidden in the system tree. In general, you only want to set this attribute to TRUE for any non-modifiable globals file you add to the system tree. Typically, this attribute is set to FALSE.

NotInCollect

Whether the file should be included in a collection. A collection is one or more open ActiveX documents. Typically, you want to include all files except non-modifiable (system) globals files in collections. Consequently, you enter TRUE for system globals files and FALSE for any other file. Typically, this attribute is set to FALSE.

DisableClose

Whether the Close command on the file's right mouse menu is grayed out or enabled. Entering TRUE grays out the command; entering FALSE or leaving it undefined enables the command. Typically, this attribute is set to FALSE.

DisableShow

Whether the Show command on the file's right mouse menu is grayed out or enabled. Entering TRUE grays out the command; entering FALSE or leaving it undefined enables the command. Typically, this attribute is set to FALSE.

DisableSave

Whether the Save command on the file's right mouse menu is grayed out or enabled. Entering TRUE grays out the command; entering FALSE or leaving it undefined enables the command. Typically, this attribute is set to FALSE.

FileType

Whether the file is a globals file. If it is not a globals file, enter DEFAULT. If it is, enter USER for user-defined globals files or SYSTEM for non-modifiable globals files. Typically, you supply system globals to prevent these value from being changed.

ProgID

The program identification for your system and user globals files. This attribute is left blank or set to FIXGLOBALSSERVER.FIXGLOBALSSERVER.1

DisableRename&Delete

Whether the Rename and Delete commands on the file's right mouse menu is grayed out or enabled. Entering TRUE grays out the command; entering FALSE or leaving it undefined enables the command. This attribute is set according to user preference.
