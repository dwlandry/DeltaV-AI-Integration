setUTCMilliseconds function

Sets the milliseconds for a specified date, according to universal time.
Arguments
1
Argument Description
millisec An integer representing the milliseconds.

0-999 are the expected values, but -1 or 1000 can also be used.

Return value
A number (0-999) representing milliseconds.
Syntax
dateObj.setUTCMilliseconds(millisec)
Examples
Example Result
This script is added, as a custom script on an action, to any element with a Label property, such as a button. 
var d = new Date(); 
d.setUTCMilliseconds(987); 
this.Label = d.getUTCMilliseconds();
 Returns 987 on the element's label.
