Setup equipment for dynamic unit allocation

This is a relative order of how to configure your equipment. That is, equipment train classes can be created before unit classes, however you will have to go back to the equipment train class once the unit classes exist to associate the unit aliases with a unit class.

  1. Create the process cell class. Class-based process cells are required for the Batch Executive.
  2. Create the process cell and areas under the process cell.
  3. Define the unit classes (assigning phase classes as appropriate).
  4. Create unit modules (the instances of unit classes) in the appropriate process cells.
  5. Define the downstream units for each unit module.
  6. Create unit selection policies.
  7. Create equipment train classes.
  8. Define unit aliases in each equipment train class.
    Note:

    If switching from not using an equipment train to using an equipment train, the unit aliases defined in the equipment train must be typed exactly as they are used in the recipe.

    1. Associate each unit alias with a unit class.
    2. Select the downstream unit aliases for each unit alias in an equipment train class (optional, downstream unit aliases are not required.)
    3. The use of a unit selection policy for determining the resolution of the unit alias to a unit is optional; however, when using a unit selection policy, you must specify the policy (regardless of the initial selection mode).
    4. If using a unit selection policy, set the initial selection mode.
  9. Create individual equipment trains (instances of equipment train classes) under Control Strategies.
    1. Set the appropriate unit selection options (use all units or use selected units) for each unit alias in each equipment train.
    2. Order the selected units. The order is used when determining the First Available priority choice.
  10. In the Procedure Recipe Properties dialog, on the Unit Alias tab, select the Use Equipment Train option.
    Note:

    The unit alias names used here and the unit aliases in your recipe must be the same.

    1. Select the equipment train class on which this procedure will run.
    2. Choose whether the procedure can run on all trains in the class, or only on specific trains.
    3. If running on specific trains, select those trains.
    4. Verify that the unit classes in this train are appropriate for this recipe.
    5. Associate unit aliases with the unit procedures (steps) in the procedure. It is recommended that each unit alias within the train be assigned to at least one step in the recipe. 
  11. Assign all areas and recipes to the appropriate Batch Executive.
  12. Download the Batch Executive.
