General parameters (Smart Switch)

A number of parameters hold information written to the Smart Switch during commissioning. These parameters are configured and downloaded to the switch using the Network Device Command Center (NDCC). The serial port connection is no longer required for switch setup. The switch uses these values to customize its behavior for your DeltaV system. If you are replacing an existing switch, the values from these parameters are written to the replacement switch.

For all the following parameters:

  • The parameter category is Configuration
  • Restore parameter value after restart is false (unchecked)
  • The parameter filter is either Common Configuration or Advanced Configuration

Changes to these parameters in the module class are not automatically propagated to the switches. You must download the module to update the switch.

Parameter Type

Default Value

Allow instance value to be configured - Default Value

Notes:

A module download replaces the switch's values with the module's parameter values.

Description

BCK_TIME_IP_ADDR

String

(empty string)

No

You must use the module parameter to configure this address when the address is not on a DeltaV network; that is, when addresses other than 10.4.x.x, 10.5.x.x, 10.8.x.x, or 10.9.x.x (where x = a number).

A computer to be used as a backup NTP time server.

HTTP_DISABLE

Boolean

0 (false)

No

If true, disables HTTP (web page server) access.

LOC_DESCRIPTION

String

(empty string)

Yes

DeltaV description (typically location) for the switch.

MGINFO

String

(empty string)

Yes

DO NOT write to this parameter other than through NDCC. DO NOT delete the MGINFO parameter.

Doing either of these things will cause DeltaV to fail to communicate to the switch.

The encrypted switch management password. This parameter is written to when the user sets the switch management password in NDCC.

MGMT_IP_ADDR

String

(empty string)

Yes

You must use the Network Device Command Center (NDCC) to configure this address when the address is not on a DeltaV network; that is, when addresses other than 10.4.x.x, 10.5.x.x, 10.8.x.x, or 10.9.x.x (where x = a number).

Holds the management IP address for this switch. (During switch replacement, the same IP address is assigned to the replacement switch.)

NETWORK

8-bit unsigned integer

0

Yes

The network to which this switch is connected. This parameter is written to during commissioning and is used to determine where to display the switch in the NDCC application.

The values are
  • 0 - Unknown Network
  • 1 - ACN Primary
  • 2 - ACN Secondary
  • 3 - Remote Primary
  • 4 - Remote Secondary
  • 5 - Other network (for example, the Thin Client network or the Level 2.5 network)

PRI_TIME_IP_ADDR

String

(empty string)

No

You must use the module parameter to configure this address when the address is not on a DeltaV network; that is, when addresses other than 10.4.x.x, 10.5.x.x, 10.8.x.x, or 10.9.x.x (where x = a number).

A computer to be used as the primary NTP time server.

SYSLOG_IP_ADDR*

String

(empty string)

No

You must use the module parameter to configure this address when the address is not on a DeltaV network; that is, when addresses other than 10.4.x.x, 10.5.x.x, 10.8.x.x, or 10.9.x.x (where x = a number).

A computer hosting a syslog server which should receive switch event log records. Often is the same address as the TRAP_IP_ADDR setting for reporting both parameters to the same syslog server.

TELNET_DISABLE

Boolean

0 (false)

No

If true, disables Telnet access.

TRAP_IP_ADDR*

String

(empty string)

No

You must use the module parameter to configure this address when the address is not on a DeltaV network; that is, when addresses other than 10.4.x.x, 10.5.x.x, 10.8.x.x, or 10.9.x.x (where x = a number).

A system management host computer that should receive SNMP trap messages. Often is the same address as the SYSLOG_IP_ADDR setting for reporting both parameters to the same syslog server.

* These parameters exist to allow experienced users (or your Information Technology group) to use third party tools such as a Syslog Server or third party SNMP package to collect this information. Typical DeltaV users will not need to set these addresses.
