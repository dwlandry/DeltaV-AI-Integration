Changing switch module parameters in a running system

If you need to change a value in a switch module after the switch is commissioned you must do so in a particular way. The steps required depend on the setting of the switch module parameter Parameter download behavior property. For example, to change the value of HAC_HITEMP_LIM, follow these steps.

If the switch module parameter Parameter download behavior property is configured as Preserve user-defined and critical block values (the default value):

  1. Open the switch module instance in Control Studio On-line mode.
  2. Change the value of HAC_HITEMP_LIM in the running switch module.
  3. In DeltaV Explorer, navigate to the workstation the switch module is assigned to, select the module, and upload the change to the module instance.

    This changes the value in the configuration database to match the value in the running module.

  4. Download the switch module to update the value in the workstation running the module.

    This ensures that if the workstation restarts, the change to HAC_HITEMP_LIM is preserved.

If the switch module parameter Parameter download behavior property is configured as Use configured values:

  1. Open the switch module in DeltaV Explorer.
  2. Change the value of HAC_HITEMP_LIM.
  3. Download the switch module.
