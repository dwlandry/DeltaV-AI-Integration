Uninstall the Batch Historian software

The Batch Historian Server is uninstalled separately from the standard DeltaV software. Go to Control Panel > Add or Remove Programs. Select the Batch Historian from the list of programs to uninstall. Select Remove. You are presented with two options:

Uninstall Batch Historian Server only. This option only removes the executable files, leaving Microsoft SQL and the historical database intact for future use. This option should be used when upgrading from one version of the DeltaV software to the another.

Complete Un-installation of Batch Historian Databases. This will result in the loss of all historical data and should only be used when the data is no longer needed.

Note:

When reinstalling the Batch Historian, it is possible that you will not receive any campaign data. This is due to the campaign journal file (dvbcmjrnl.seq) located in DeltaV\DVData directory becoming out of step with the Batch Historian Database. Rename the dvbcmjrnl.seq file and allow it to be recreated. All the campaign data will now be collected successfully.
