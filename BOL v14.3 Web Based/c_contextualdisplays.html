Contextual displays overview

A contextual display is a special type of display whose content varies depending on the context in which it is opened. Contextual displays provide the means to create and maintain a single graphics configuration that can be shared by multiple DeltaV objects. Examples of contextual displays include faceplates, details displays, Batch controls, and so forth. Graphics Studio provides many out of the box contextual displays to be used with your other displays, as well as various graphics elements to help you build your own contextual displays. You may find GEMs useful for this purpose, as they already contain many of the faceplate or detail display elements needed to create contextual displays. Additionally, variables and actions can be configured on contextual displays as well.

Contextual displays are opened from within normal displays, usually by configuring an action on a graphics element that supports interactions, such as a data link, button, or GEM. The configured action's tag property (for example, Module Name or Tag) must be the name of the module/device/node associated with the referenced contextual display. This tag is also referred to as the display tag, and is used in references as Dsp.Tag. Additionally, to bind references configured within the contextual display to the correct module/device/node, parameter paths must use the display tag parameter. For example, ~Tag~/PID1/MODE.TARGET or ~Tag~/PID1/SP_WRK.CV.

To open a contextual display from another display, you must provide the name of a DeltaV module/device/node, which could have many similar instances. For example, to configure a GEM to open a specific faceplate, enter the tag of the module that contains the faceplate as a property. You can also configure an action to open a contextual display on any elements that support interactions. When a contextual display is used as a faceplate, detail, or primary control display, its name must match the names configured for the faceplate, detail, or primary control display configured for the desired DeltaV object. DeltaV Live online reads the module/device/node name and opens the appropriate contextual display.

You can also configure optional contextual information to show on a contextual display by entering parameters in an action's context property fields, and then referencing those parameters from a data link on the contextual display. This data appears only when this particular interaction is performed.
