Test communications between the internal and external network

Pinging is used to verify communications prior to creating rules in order to simplify troubleshooting.

  1. In the firewall's web UI navigate to Dashboard > Summary and click the Allow all button to open the firewall so you can easily ping between computers or devices.
  2. On each DeltaV workstation, open the command prompt and type ping -4 -t xxx.xxx.xxx.xxx (the external workstation's IP address) to create a persistent ping to each external workstation that will be communicating with a DeltaV workstation.
  3. Troubleshoot any non-working pings by checking that the routing is correct, the DeltaV workstation's NIC configuration is correct, and the IP address is correct.
  4. Verify that all computers and devices are communicating before setting up the protection rules for each application.
