Forced shutdown of individual batches

Under certain extreme circumstances it may be necessary to force a batch to be shut down immediately, without having to stop the Batch Executive or disrupting other batches. This can be accomplished from the Administer Batches tab on the Advanced dialog for the Batch Application Manager.

Important:

The recommended method for stopping a batch (in most circumstances) is through the Batch Operator Interface (or Batch Toolbar control) by issuing a Hold, Stop, or Abort command. The use of forced shutdowns should only be used when it is not possible to stop the batch through the batch commands.

A shutdown of a batch causes the batch to go to the Lost state. While in the Lost state, no communication takes place between the batch and its currently active phases. Active phases continue to run in the controller until the phase is complete or until the Fail Monitor logic trips (usually due to the watchdog parameter being set to Failed.

Only users with the Batch_Control_Stop function key can force a shutdown of a batch.

Lost batches can be removed or can be restarted.
