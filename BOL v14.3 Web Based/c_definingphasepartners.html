Defining phase partners

Phase partners are phases that communicate with other phases during execution. During phase class configuration, you must specify the number of partners with which the phase can communicate (excluding the current phase in the count). Based on the number of partners you specify (maximum allowed is 20), the recipe author can build a phase link group, which lists the phases that can communicate with each other in the recipe.

Phase Partners Defined on the Phase Class Properties Dialog
Note:

Any phase used in a link group must be based on a phase class with a number of partners greater than zero (0). Otherwise, the recipe will not be able to be loaded. The maximum number of phase partners allowed is 20.

Typically, a phase link group contains phases that must be synchronized. For example, you can synchronize transferring material out of one unit and into another. The synchronization is programmed into the phase logic using request codes to send a message from one phase to another. In an operation, when the message is received by its phase partner, the phases are in synch, and can begin execution.
