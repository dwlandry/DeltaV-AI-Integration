Define the Master Time Server node

The Master Time Server node broadcasts the system time to all workstations and controllers on the DeltaV Control Network. By default, the ProfessionalPLUS workstation is the Master Time Server node. However, any physical DeltaV workstation on the DeltaV Control Network can be defined as the Master Time Server node.

To define the Master Time Server node, complete the following steps:

  1. Navigate to System Configuration > Physical Network.
  2. Right-click Physical Network, and then select Properties.
  3. Click the Browse button on the System Time tab in the Physical Network Properties dialog, and then select a workstation on the DeltaV Control Network. You can also define the Backup Time Server node on the System Time tab in the Physical Network Properties dialog.
