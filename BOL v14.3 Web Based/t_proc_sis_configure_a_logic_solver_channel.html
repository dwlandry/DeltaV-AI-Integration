Configure an SLS 1508 Logic Solver Channel

When an SLS 1508 Logic Solver is created under the SIS Network, the channels default to the Undefined channel type. You must then configure the channels to define the type of I/O signal.

  1. Navigate to a channel in the Channels subsystem under a Logic Solver.
  2. Right-click, and then select Properties.
  3. In the Properties dialog, select the Enabled check box to enable this channel.
  4. Enter a description for the channel.
  5. Select a channel type.
  6. To select a Device Tag other than the default, click the Browse button next to the Device Tag field.
    Note: The Browse dialog displays the Unassigned I/O references of the appropriate type for the channel type.
  7. Select an I/O reference, and then click OK.
  8. Click OK in the channel Properties dialog.
