Configure secure parameter references

If you have a secure reference configured in an SIS module you can configure a secure parameter reference using these steps.

  1. Open a different SIS module.
  2. Drag a Secure Parameter Reference from the Special Items palette onto the function block diagram.

    A properties dialog opens for the secure parameter reference.

  3. Enter a name and select a parameter category.
  4. Click the Browse button.
  5. Browse to the Secure Parameter that you defined previously and click OK.
    Note:

    In SLS 1508 systems the database checks to make sure the Secure Parameter is in a Logic Solver on the local peer bus or in a Logic Solver publishing Secure Parameters globally. In CHARMs Smart Logic Solver systems the database checks to make sure the Secure Parameter is in a CSLS on the Local Safety Network.

    Multiple secure parameter references can refer to the same secure parameter.

  6. Click the Main button, then click Save.
