Create communication rules in normal mode

It is assumed that you have printed and completed the Worksheet for DeltaV applications and know the DeltaV workstation names and the external computer names.

  1. In the firewall's web UI navigate to Dashboard > Summary.
  2. Click the Normal button.
  3. Navigate to Protection and select either Inbound connections or Outbound connections.
  4. Select a DeltaV application from the Application drop-down list.
  5. Select the DeltaV workstation that uses this application.
  6. Enable logging on the rule. As you create each rule, ensure that the applications are communicating properly. These rules were tested with the DeltaV system and should communicate properly but it is always a good idea to exercise the applications to ensure they are communicating and the applications are working as desired.
  7. Continue to create and test the rules for DeltaV applications. When you have created all the required rules using the applications in the firewall's application list, you can create custom rules if required or complete the firewall configuration.
