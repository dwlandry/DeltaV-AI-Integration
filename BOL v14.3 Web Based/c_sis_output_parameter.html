SIS output parameter

Output parameters appear automatically as output connector when you create  composite blocks. The output parameter provides an output connection that allows you to send signals to other blocks, modules, or displays. In an SIS composite template or SIS module an Output Parameter can be one of the following types:

  • Floating point with status — a floating point value with a status indicator.

  • Boolean with status — a True or False value with status indicator.

  • 32-bit unsigned integer with status — a whole number without a positive or negative sign associated with it with a status indicator. 

  • Named Set — a value from 0 to 255 that displays an assigned text message.

When you create this parameter you configure whether its characteristic is Restore parameter value after restart or Preserve parameter value on download.
