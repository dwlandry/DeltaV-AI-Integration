Configure the BS-420

There are specific requirements to configure the BS-420 for use with the DeltaV software. The following are the steps to configure the BS-420/BC-420 within the AS configuration tool:

  1. Add two AUTROCOM_TCP_MODBUS_SLAVE units to both the BS-420 and BC-420 units.
  2. On the BS-420:
    1. Configure the two slaves to have the same IP address and netmask but different port number (502 and 503). For example, IP address 192.168.0.1 and netmask 255.255.255.0 and port numbers 502 and 503.
    2. Leave the Gateway field blank.
  3. On the BC-420:
    1. Configure the two slave IP addresses in the same way except on a different subnet from the BS420 slaves. For example, IP Address 192.168.1.1 and netmask 255.255.255.0 using the port numbers used for the BS-420, 502 and 503.
    2. Leave the Gateway field blank.
  4. Choose the correct Ethernet Interfaces that the Modbus cables are connected to within the panel (Ethernet 2 in the example above).
  5. Select the Command Handshake check box (on).
  6. Ignore the Fault Timer (sec) field.
  7. Make sure the Report Faults check box is not selected (off).
  8. Do not change the Slave Address or Slave ID fields.
Unit configuration tips:
  • Because Autronica does not enforce unique unit names, the Autronica CSV to Bulk Edit converter adds characters to the unit names to create unique Signal Names and unique Secure Parameter names for use in the DeltaV configuration.
  • Secure Parameter names in DeltaV are limited to 16 characters in length. Therefore, limit unit names in the Autronica Configuration tool to nine characters in length to allow for the renaming to unique Secure Parameter names.
