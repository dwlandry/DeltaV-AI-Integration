CDA_SDA_fp (Command/State-driven module faceplate)

Configuration view of the Command/State-driven module faceplate (CDA_SDA_fp)


The CDA_SDA_fp is used by modules with command-driven algorithms or state-driven algorithms. The following list describes the major components that are present on the CDA_SDA_fp.
Module information
Shows the following information about the module:
Zone name
If the faceplate or detail display contains an object in another zone, the zone name appears here.
Tag
The DeltaV database tag for the module/device/node associated with the faceplate or detail display.
Description
The user-configured description for the object. Descriptions do not appear on function blocks faceplates and detail displays.
Target
Shows the command currently executing.
PV
Shows the state currently running.
Run command
Shows the command selected to run.
Run button
Starts the currently selected command.
Restart Current Command button
Aborts the command currently executing, and then restarts a new instance of the command.
Rerun Current Sequence Group button
Refreshes the state information for the sequence group currently executing.
Applies only when using the faceplate for state-driven algorithms.
State information
Shows the state information for the sequence group currently executing. The state information includes the following values:
State
The current status of the current command.
Time
The number of seconds the current command block has been running.
Error
Shows 1 if the command generated an error or timed out.
Max Time Expired
Shows 1 if CFM_MAX_TIME has been exceeded; otherwise, shows 0.
Min Time Expired
Shows 1 if CFM_MIN_TIME has been exceeded; otherwise, shows 0.
Applies only when using the faceplate for state-driven algorithms.
Current Sequence
Applies only when using the faceplate for state-driven algorithms.
Alarm list (active)
Provides a condensed version of an alarm summary and scrollable list of the module's current active alarms.
  • Ack column --> Shows the state of the alarm, which is represented by one of the following symbols:
    Alarm state Ack column
    Active/unacked Empty field
    Active/acked Check mark
    Inactive/unacked Empty box
  • Param column --> Shows the alarm name or parameter. The text and colors are as configured for the alarm's current state.
  • Help column --> Indicates the type of Alarm Help available for the corresponding alarm. The column contains one of the following icons:
    Icon Description
    Alarm Help is enabled.
    Alarm Help is not enabled but the user has the privilege to edit Alarm Help.
    No icon Alarm Help is not enabled and the user does not have the privilege to edit Alarm Help, or the system does not have a license for alarm help.
Note: The alarm list on the Continuous Unit Module faceplate (UMC_fp) provides a full alarm summary rather than a modified one.
Icon buttons
Icon Description
Opens the module's detail display.
Opens the module's primary control display.
Opens the module in Control Studio.
Opens Process History View.
Acknowledges all alarms visible in the faceplate's alarm list.
