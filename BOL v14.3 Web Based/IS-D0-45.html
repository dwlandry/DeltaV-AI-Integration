I.S. DO 45 mA CHARM

Installation notes

  • This Intrinsically Safe CHARM requires an I.S. CHARM Terminal Block.
  • This CHARM can be configured for momentary output or continuous pulse output.
  • This CHARM has short circuit protection and supports line monitoring for sensing field wiring faults such as open and short circuits. Line monitoring is enabled in the configuration.

Specifications

I.S. DO 45 mA CHARM specifications
Item Specification
Channel type Intrinsically Safe Discrete output
Configuration options
  • Momentary output
  • Continuous pulse output
  • Line fault testing
On-state output rating 22 V to 25 V (open circuit); 11 V at 45 mA
Off-state leakage current 230 µA
Line fault detection levels
  • Guaranteed short circuit: <100 Ω load
  • Guaranteed good status: 150 Ω < r_load < 20 kΩ load
  • Guaranteed open circuit: 25 kΩ load
Line fault test timing 180 to 220 µsec
Channel isolation Galvanically isolated according to EN 60079-11, voltage peak value 375 VDC.
