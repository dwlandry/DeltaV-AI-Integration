Printing graphics configurations in Graphics Studio

In Graphics Studio, you can print graphics configuration documents of all types, as well as folder views, from the File menu to any printer defined on that workstation or to various types of documents (such as XPS or PDF). To print a configuration or folder, it must be selected as the active tab or selected in the Explorer view (with the appropriate pane having focus).

All printed documents include a title, item name or names, the user last modified by, the date and time the document was last modified, the page count, and the current page number.

When printing a display, contextual display, layout, or GEM class, the print document includes all of the graphics on that configuration. When printing languages, themes, or the contents of any folder (including a standards or functions folder), the folder contents are printed in a table format according to their filters and sort order. Folder contents are printed as they appear on the content pane. Individual library functions are printed in a special table format showing the inputs, calculations, and conversions for that function. You can also print translation guides and theme guides, which are printed just as they appear on the content pane.

The following options are provided for choosing your print content, scope, and appearance of the document:

Print scope

All Pages
Prints entire document.
User Pages
Prints specified page range.

Print content

Print Current Item
Prints only the active document or document selected in the Explorer view.
Print Similar items
Prints all graphics configurations of the same type as the active or selected document.
  • When printing folders, prints all top level folders.
  • When printing library items, prints similar items across all libraries.
  • When printing translation guides, prints all translation guides for all items of the same type.

Print appearance

Page Size
Choose from letter, legal, A4, or A5.
Scale down to fit paper
Scales the document down to fit the paper with a .2" margin.
Scale content to fit paper
Scales the document up or down to fit the paper with a .2" margin.
Don't do scaling
Prints the document at 100% of its configured size.
Landscape Orientation
Prints the document horizontally.
Portrait Orientation
Prints the document vertically.
Best Fit
The application determines the best orientation to display.

A print preview of the document is provided while choosing your print settings. The print preview reflects the options selected for page size, orientation, and scaling.
