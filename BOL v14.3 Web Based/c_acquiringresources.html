Acquiring resources

To control a resource, an operator must first acquire that resource. Operators can acquire a resource when the number of current owners is less than the maximum number of owners configured in DeltaV Explorer.

When an operator is finished using a resource, he must then release the resource to make it available for acquisition by other resources or running batches.

As an example, suppose an maintenance engineer needs to adjust a resource, AGITATE3, the agitator used by MIX3 in the PAINT recipe. This phase, however, is currently in use for a batch of paint. To ensure that the maintenance engineer can safely adjust the agitator without affecting the batch, the operator can request MIX3 (the unit where the unit phase, AGITATE3 runs), notify the maintenance engineer when it is acquired, and release it when the maintenance engineer is done.

The following steps occur when the operator acquires MIX3 from the Arbitration screen:

  1. The operator sets List Devices to Equipment and selects MIX3.

  2. T12-R456:\PAINT\... appears in the Owned By box, indicating that the unit is in use by Batch ID T12-R456.

  3. The operator clicks the Acquire button.

  4. The name Operator appears in the Priority List Needed By box.

  5. The Arbitration screen is static until the PAINT batch is done with the unit, at which time this unit is released.

  6. OPERATOR is now given ownership of MIX3. The name Operator appears in the Owned By box. Simultaneously, Operator is removed from the Needed By box.

  7. MIX3 is now owned by the operator. It's phases can be manipulated from the phase control screen, but not from a recipe.

  8. When maintenance is complete, the operator clicks the Release button on the Arbitration screen to release MIX3.

This completes the resource acquisition process.
