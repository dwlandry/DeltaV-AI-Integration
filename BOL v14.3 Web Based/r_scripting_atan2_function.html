atan2 function

The atan2 function returns the arc tangent of the quotient (y/x) of its arguments, y and x, where the signs of y and x are used to determine the quadrant of the result.

The result is expressed in radians and ranges from -pi to +pi.

Arguments
2
Argument Description
y First number.
x Second number.
Return value
The arctangent of the quotient of the given arguments.
Syntax
Math.atan2(y, x)
Examples
Example Result

  return Math.atan2(y, x) * 180 / Math.PI;
