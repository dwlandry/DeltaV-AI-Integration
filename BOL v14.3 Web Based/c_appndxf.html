Appendix F - the Campaign Manager control

The DeltaV Campaign Manager control provides the Application Programming Interface (API) for the DeltaV Batch Campaign Manager Server. This control is fully automation compliant. Therefore, it can be inserted into any ActiveX container (for example, Visual Basic, Excel, Internet Explorer, and so on). The Campaign Manager control provides all of the methods and properties necessary for a client application to drive the DeltaV Campaign Manager Server and monitor the results.

The Campaign Manager control can be thought of as a component that exports a series of automation objects, each supporting various interfaces to the DeltaV Campaign Manager Server.
