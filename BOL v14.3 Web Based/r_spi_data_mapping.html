Note:

If alarm values are set in SPI, ALM_ENABLE is set to True in DeltaV. If ALM_ENABLE is set to False in DeltaV, alarm data is not published to SPI.

Note:

All the SPI properties are on the Control System Tag Properties dialog on the Alarm and Range and Conditioning tabs.

1 CALIB_SCALE is not currently used by the DeltaV system but is provided as a reference to reflect SPI’s Calibration Scale values which may be appropriate values for XD_SCALE in certain circumstances. You can view the CALIB_SCALE values in Excel, determine if they are appropriate values for XD_SCALE, and modify the XD_SCALE default values to match CALIB_SCALE before saving to the DeltaV database.
2 The values of XD_SCALE are set to default values by the interface because there is no exactly matching parameter in SPI.
