Exporting graphics configurations

Graphics configurations are exported from Graphics Studio through the Export pane, while workstations and configuration databases are exported from DeltaV Live Administration through the Export dialog.

The export process creates an XML file (with an .ahc extension) for each exportable configuration you select and exports it to a folder specified by you in the Windows file system. Exports can be directed to either a local drive on the workstation performing the export or to a file share on another workstation. If an exported file has the same name as one already existing in the folder, the exported file overwrites the existing one.

If a user has previously exported content from a workstation, both applications remember the last export folder destination for that DeltaV user on that workstation and present it as the default Export to Folder path on the next export. You can also customize your export results using the Export Settings.

Only one export operation at a time can be performed in each instance of Graphics Studio or DeltaV Live Administration; however, you may continue to work on other tasks in these applications while an export is in progress. Other users may also continue to work in the configuration database during an export. Files that are open and unlocked for editing can still be exported because the export process takes the last saved version of the configuration.

Export progress and results information

During and after the export process, both applications provide updating information about the progress of the export, including:
  • Exporting to: Total number of items to export and number of items remaining to export
  • Export Started: Date/time the export started
  • Export Finished: Date/time the export finished
  • Export results per items, including:
    • Configuration name
    • Configuration type
    • Export status (succeeded, failed, skipped)
Note: When an exported item includes "last saved timestamp" meta-data, the timestamp is set to match the Date Modified property of the Windows file containing the export content.
Tip:
  • You can stop an export while it is still in progress by clicking Stop in the Export pane. If you click Stop, the operation halts after the export process completes for the item currently being exported.
  • You can save the Progress/Results information for later by copying and pasting the data from the Export pane into another application, such as Notepad or Excel. This information remains available in the Export pane until you start another export operation or close the current instance of Graphics Studio.

Naming conventions for files produced during export

All files produced during an export follow these naming conventions:
  • File names correspond to the configuration names in the database.

    If an configuration name conflicts with a Windows reserved file name, the file name is preceded by an '_' (underscore).

  • File names are given a suffix that distinguishes their configuration type:
    File suffix Configuration type
    .ws DeltaV Live workstations
    .lo layouts
    .flo layout folders
    .ds display sets
    .di displays
    .fdi display folders
    .al library language configurations
    File suffix Item type
    .ws DeltaV Live workstations
    .lo layouts
    .flo layout folders
    .ds display sets
    .di displays
    .fdi display folders
    .al library language configurations
  • All files are given the file extension ".ahc" to distinguish them as DeltaV Live Configuration exchange files.

The XML document (.ahc file)

The content of each exported .ahc file is a single, well-formed XML document that includes only the information needed to reproduce an exact copy of it when imported into another configuration database. The .ahc file can be viewed and edited using a text editor application.
