Create communications rules in Allow all mode to not disrupt existing communications

Use this procedure if you are installing the firewall in an existing network and cannot interrupt communications. In this procedure the firewall is placed in Allow all mode. It is recommended that you create rules to keep critical communications working through the firewall in Allow all mode first and after testing these rules, switch to Normal mode and create rules for non critical communications.

  1. In the firewall's web UI navigate to Dashboard > Summary.
  2. Click the Allow all button.
  3. Navigate to Protection and select either Inbound or Outbound connections.
  4. Select a DeltaV application that is considered a critical communication from the Application drop-down list.
  5. Select the DeltaV workstation that uses this application.
  6. Enable logging on the rule.
  7. Continue to create rules for critical communications in Allow all mode.
  8. When all rules for critical communications are created, follow the instructions for troubleshooting a communication rule. This procedure explains how to use log data to review the rule settings and ensure the rules are correct for your system. When you are sure that the rules are correct, reset the mode to Normal, retest the critical communications to ensure they are correct, and then create and verify rules for any remaining communications.
