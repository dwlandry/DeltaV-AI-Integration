Event Chronicle security functions

Access to individual Event Chronicle functions, such as exporting or deleting history data sets, is restricted to those users who have been granted an access key individually or who belong to a group that has been granted a key. In addition, user accounts for those who need access to Event Chronicle functions must have the DeltaV Event Chronicle Administrator check box enabled (the DeltaVAdmin user has access to these functions by default).

All Event Chronicle Administration operations are sitewide, requiring that <Sitewide> be assigned to the System Admin key in DeltaV User Manager (when assigning keys to a user or user group). However, the specific administration functions (such as deleting event history data sets) still require the appropriate key be granted to the correct areas.

Note:

For more information about locks and keys, refer to the User Manager application online help.

Event Chronicle security keys by function

Function Name

Controls whether the current DeltaV user (on this node) can:

ECHDS_EXPORT

export event history data sets

ECHDS_DELETE

delete event history data sets

ECHDS_EXTENDED

create extended event history data sets

ECHDS_BACKUP

back up current event history data sets to an off-line directory

ECHDS_RESTORE

restore current event history data sets from an off-line directory to primary storage
