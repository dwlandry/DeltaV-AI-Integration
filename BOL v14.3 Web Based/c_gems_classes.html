GEM classes overview

GEM classes are complex graphics elements used to represent process control equipment or other objects on a display. A GEM class provides a means to define a common appearance and behavior for all GEM instances that are linked to that GEM class. GEM classes are managed as library items in configuration libraries. They are available in the Palette pane for you to add to displays or other GEM classes. A GEM class is added to a display or other GEM class as either a linked GEM or an unlinked GEM. Linked GEMs remain linked to their GEM class; therefore, when a GEM class is modified and saved, the changes propagate to all instances linked to that GEM class.

The out-of-the-box GEM classes provided with DeltaV Live include both process GEM classes that are predefined to work with modules, function blocks, and so forth, as well as common GEM components that can be used to build your own GEM classes.

Creating GEM classes

When the GEM Classes folder is selected in a library, you can create a new GEM class using the ribbon's New > GEM Class command. GEM classes can also be created by converting a graphics element (or elements), group, or unlinked GEM to a GEM class. One or more levels of GEMs can be nested within a GEM class, but each GEM can be used only once within a class.

Configuring GEM classes

All GEM classes, including both out-of-the-box and user-created classes, share a set of common properties that are available for configuring in a GEM class's Graphics Configuration pane. These properties include metadata information, size, interactions, and variables. Each element contained in a GEM class can also be configured in the element's Graphics Configuration pane. GEM class properties can also be referenced by properties in display, layouts, or other GEM classes.

Additionally, GEM classes include a GEM Configuration Designer. The GEM Configuration Designer provides the tools for creating custom properties that appear on the GEM class's linked GEMs and whose values can be referenced by other properties on the linked GEM. These custom properties allow you to customize the GEM class for a specific application and define its most common characteristics; thus, they provide the means to quickly and simply configure a GEM class's linked GEMs. Out-of-the-box GEM classes are already customized to fulfill their specific application.

Unlinking GEMs

A linked GEM can be unlinked from its GEM class by either re-linking it to a different GEM class or converting it to an unlinked GEM. Re-linking to another GEM class changes the available configuration for that GEM instance because it is now linked to a different GEM class. Unlinked GEMs are no longer linked to any GEM class.

Deploying GEM classes

GEM classes cannot be published. When you modify and save a GEM class, the updates automatically roll out to all displays containing GEMs linked to that GEM class, but in only the configuration environment. Additionally, if you added any custom properties or modified their names in the GEM class's GEM Configuration Designer, these are also reflected in and available for configuration in the Graphics Configuration pane of all GEMs linked to that class. Then, the displays containing the updated linked GEMs must be published to deploy the updates online. If you are not ready to publish the changes, you can notify the affected displays to mark themselves as a Work in Progress. When you are ready to deploy the changes online, you can then publish the displays.
