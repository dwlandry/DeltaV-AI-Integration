Resolve a unit alias

Unit aliases are resolved at the instantiation of the unit module.

  1. Expand the unit module (under Control Strategies in the DeltaV Explorer hierarchy).
  2. Select the Aliases object.
  3. In the right pane, right-click the specific unit alias.
  4. Select Properties.
  5. Complete the Path field by browsing to the appropriate parameter (the module parameter or the parameter designated for history collection). 
Note:

Modifying the resolution of a unit alias requires downloading the unit module.
