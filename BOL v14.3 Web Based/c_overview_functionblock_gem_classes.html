Function block GEM classes

This section provides a reference for the function block GEM classes provided with DeltaV Live. In Graphics Studio, the function block GEM classes are found in the Library Explorer pane, in the GEM Classes\Emerson\AdvancedFunctionBlock and GEM Classes\Emerson\AdvancedControl folders.

In the individual GEM class topics, each image shows the GEM and its main components at a 200 percent magnification, for readability purposes. The component descriptions describe the GEM's online behavior.

The tables below show all of the GEMs contained in the Advanced Control and Advanced Function Block GEM class sets and their corresponding function blocks.

Advanced Function Block GEM classes
GEM class Function block Description
Any_Advanced_Function_Block_ Any advanced function block. Calls a custom faceplate for any advanced function block, primitive or composite.
Controller_AVTR_1Input_ AVTR Use with a 1oo1 analog voter (AVTR) function block.
Controller_AVTR_2Input_ AVTR Use with a 1oo2 or 2oo2 analog voter (AVTR) function block.
Controller_AVTR_3Input_ AVTR Use with a 1oo3 or 2oo3 analog voter (AVTR) function block.
Controller_AVTR_InputX_ AVTR Use with an analog voter (AVTR) function block and the Controller_AVTR_3Input_ GEM, when voting arrangements have more than three inputs.
Controller_CEM_Effect_ CEM Use with a Cause & Effect Matrix (CEM) function block. Can be used multiple times when the CEM block, producing multiple effects.
Controller_DVTR_1Input_ DVTR Use with a 1oo1 discrete voter (DVTR) function block.
Controller_DVTR_2Input_ DVTR Use with a 1oo2 or 2oo2 discrete voter (DVTR) function block.
Controller_DVTR_3Input_ DVTR Use with a 1oo3 or 2oo3 discrete voter (DVTR) function block.
Controller_DVTR_InputX_ DVTR Use with an analog voter (DVTR) function block and the Controller_DVTR_3Input_ GEM, when voting arrangements have more than three inputs.
Controller_SEQ_ SEQ Use with a Step Sequencer (SEQ) function block.
Controller_STD_ STD Use with a State Transition Diagram (STD) function block.
