DCC_fp (Discrete Control Condition function block faceplate)

The DCC_fp is used with the Discrete Control function block. This faceplate is divided into three tabs, with each tab listing the conditions configured for that type (Interloc, Permissive, or Force Setpoint), and showing information on each condition. Up to 16 conditions can be configured for each type.
