Connecting field wiring to Zone 1 Discrete I/O cards

The Discrete I/O card provides the interface to sixteen discrete input channels and eight discrete output channels. The discrete input channels are Intrinsically Safe dry contact inputs with the first two channels optionally supporting pulse count. The discrete output channels are Intrinsically Safe high-side DC outputs.
