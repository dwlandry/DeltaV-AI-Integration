Phase algorithm definition

The phase algorithm definition defines the base phase algorithm (that is, the states starting, running, stopping, and so on, of the phase and the logic associated with each state) for a phase class.

The phase algorithm definition includes:

  • The implicit phase algorithm state machine.

  • The sequential function chart (SFC) composites for the Run logic, Hold logic, Abort logic, and so on.

  • The function block composite for the failure monitor logic.

The phase algorithm definition works on the unit module when the unit phase is created, providing the logic that runs the unit.

Note:

When using aliasing in DeltaV Batch you must use the phase algorithm definition design.

The phase algorithm definition is created in the DeltaV Explorer. The logic is edited in Control Studio.
