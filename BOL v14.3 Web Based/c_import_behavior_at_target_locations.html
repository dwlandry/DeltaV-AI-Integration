SIS Composite Template behavior at target locations

If an SIS Composite Template by the same name already exists on the target system, the following things happen:

  • If the existing template is in a protected category, the existing template is not overwritten and an import error appears.

  • If the existing template is protected and used by any modules in the database, the existing template is not overwritten and an import error appears.

  • If the existing template is protected but not used by any modules in the database, the new template is imported.

  • If the existing template is protected but was not protected on the current source system, the existing template is not overwritten and an import error appears.

  • If the existing template is not protected and not in a protected category, the new template is imported.

The protected SIS Composite Template cannot be unprotected, edited to change anything about it, or copied.
