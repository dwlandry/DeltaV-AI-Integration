Edit class-based module data

Properties dialogs of parameters that are children of class-based control modules include a Use default value from library object check box. If this box is checked on a parameter of the item you exported, the parameter's value is enclosed in angle brackets in the exported file in the Bulk Edit add-in. Changing a value inside brackets has no effect. On import, the default value from the library object is assigned to the parameter. To change a value, remove the brackets and enter the desired value. When the file is imported the check box is no longer selected and the new value is assigned to the parameter in the imported object.

Adding angle brackets to a parameter value selects the check box. To cause the check box to be selected for a parameter with multiple fields, you must enclose all the fields' values in angle brackets before importing the file.

Edit the exported file in Excel using the Bulk Edit add-in:

  1. Start Excel.

  2. Open TEMPS.TXT using the Bulk Edit Open Data File command. The add-in converts the file from Unicode to ASCII and creates the ASCII version of the file TEMPS_ASCII.TXT.

    Note that the fields in the exported file include only those parameters that can be edited.

  3. In Excel, copy the first data row (row 2, TEMP-101) and paste it to an empty row.

  4. In the module_name column of the new row, rename the module to TEMP-102.

  5. Make other changes desired, including entering I/O references for AI1$IO_IN.REF.

  6. Use the Bulk Edit menu to save the file.

  7. Close the file.
