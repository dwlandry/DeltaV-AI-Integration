Does the system not function as expected?

Check the event log by clicking Start > Settings > Control Panel > Administrative Tools > Event Viewer. Look for a DeltaV log entry. If it indicates an error with a status of 5, you might be getting an access denied error from Windows. Here are a few things to check:

  • Do not change the DeltaVAdmin or SOFTPHASEUSER account passwords through DeltaV User Manager or Windows User Manager. Always use either the DeltaV Security Administration application (Start > All Programs > DeltaV > Installation) or the ServPwd utility (located in the \DeltaV\Bin directory). Several programs depend on these accounts to operate properly and this utility handles changing the password when needed.
  • Do not assign the node name of DeltaV to your machine.
  • From the Windows User Manager make sure that the DeltaVAdmin account is a member of the DeltaV group.
  • Grant Log on as service and Change system time privileges to the DeltaVAdmin account.
  • Grant at least Read Execute access to the \DeltaV\bin and \Deltav\lib directories to the DeltaV group.
  • Grant at least Write access to the \DeltaV\DVData directory and its subdirectories to the DeltaV group.
