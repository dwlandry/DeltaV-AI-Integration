Using animation to customize graphics configurations

Displays are intended to reflect real-time conditions in the control process. Live data is constantly changing, and operators need the ability to acquire and interpret this data in ways that can improve their understanding of and reactions to what is happening in the control process. You can animate various properties of graphics configurations to transform live date into a single value of a desired type, thus providing the means for operators to see display graphics dynamically change as online values change. Layouts, displays, GEM classes, and elements all contain certain animatable properties.

You can create three kinds of animations: simple animations, blink animations, or library animations. The property type determines the kind of animation you can create. These animations are configured in the Graphics Configuration pane by clicking the diamond next to the property you want to animate and selecting the desired kind of animation from the Diamond context menu.

The sections below provide information about kind of animation.

Creating simple animations

Simple animations are created by selecting Animate from the Diamond context menu and configuring the new properties that appear. These simple animations are embedded within the element (cannot be shared) and can be applied to property types of Boolean, percentage, measurement, degree, and font. For each property type, you can create an animation compatible with that type. The property type determines which new configurable properties you need to configure. The list below describes the kind of animation you can create for each property type.
Boolean
Boolean animations use a logical expression supporting multiple terms to produce a True/False result. The expression references a DeltaV parameter and sets the rule for when the parameter value is true or false. For example, you can animate the Visibility property on a data link to have the data link visible only when a certain condition is met. These conditions are defined in the logical expression. To animate a Boolean property, you must define a DeltaV parameter value and in some cases, a default value.
Percentage
Percentage animations convert a dynamic value to a scaled result ranging from 0 to 100 percent. This type of animation includes an expression defining what to fill, fill options, and scale information. For example, you could animate a Fill Percent property on any graphics element to show it as filled or partially filled. To animate percent property, you must define what is to be filled, DeltaV scaling parameter for the fill, a default scale, and a default value.
Measurement
Measurement animations use linear scaling to convert a dynamic value to a result within a specified range of measurement values. For example, you can animate the Vertical Position to make a pointer on a display move up and down on a display. To animate a measurement property, you must define a DeltaV parameter reference value, DeltaV scaling parameter for the measurement, a default scale, a start and end point, and a default value.
Degree
Degree animations use linear scaling to convert a dynamic value to a result within a range of angular measurements (in degrees). For example, you can animate the Rotation Angle to make a needle on a radial gauge appear to swivel. To animate a degree property, you must define a DeltaV parameter value, DeltaV scaling parameter, a default scale, a minimum and maximum degree bounds, and a direction of rotation.
Font
Font animations are a type of Boolean animation that use a logical expression to produce an alternate Font and font characteristics when certain conditions are met. These conditions are defined in the logical expression. For example, you can animate the font on a button to become bolded red when a certain condition is met. To animate a font property, you must define an alternate font, the condition that triggers the alternate font, and a default font.

When you select Animation, the property field and orange diamond indicate that an animation has been applied.

Creating blink animations

Blink animations, which are created only on color-type properties, allow an element to alternate between its normal color and its configured alternate color. Blink animations are created by selecting Blink Animation from the Diamond context menu and configuring the new properties that appear. When you select Blink Animation, the property field and orange diamond indicate that a blink animation has been applied.

To animate a color property, you must define the condition that triggers the alternate color, the normal and alternate color, the duration for the normal and alternate color, and a default color.

Creating library animations

Library animations are created by selecting Library Animation from the Diamond context menu and then selecting a library function from a pop-up list. Library animations can be applied to property types of Boolean, percentage, measurement, degree, and font. For each property type, you can reference a library function of the same type. If the function you need does not exist, you can create a new library function from the Library Explorer pane. After saving the new function, return to the Graphics Configuration pane to reference this function.
