Operators

Operators define some function that will be performed on the data in an expression. Operator precedence and semantics are defined by the JavaScript language specification. The following JavaScript language operators are fully supported in DeltaV Live graphics expressions and scripting.

Unary operators

Unary operators perform various operations, using only one operand, such as incrementing or decrementing a value by one, negating an expression, or inverting the value of a boolean.
Operator Description Syntax
+ Unary plus Converts to a number and then r eturns the sum of the values. + a
- Unary negation Converts to a number and then returns the negative of that number. - a
~ Bitwise NOT Inverts the bits of its value. ~(value)
! Logical NOT Combines two or more conditions, then returns the inverse of the expression's result (as true or false). For E.g.: !(>5) returns false !(value)

Arithmetic operators

Mathematical operators let you add, subtract, multiply, and divide two or more values. Using these operators, you can create a mathematical expression. You can also change the operator's order of precedence in the mathematical expression by using parentheses. Mathematical expressions are evaluated by determining the data value on each side of the mathematical operator and then performing the mathematical operation.
Operator Description Syntax
* Multiplication Returns the product of the values. a * b
/ Division Performs a division and returns the quotient. a / b
% Modulus (Remainder from implied division) Performs a division and returns the remainder. a % b
+ Numeric addition or string concatenation Returns the sum of the values. a + b
- Numeric subtraction Returns the difference of the values. a - b

Bitwise Shift operators

Bitwise operators treat their operands as a sequence of 32 bits (zeroes and ones) rather than as decimal, hexadecimal, or octal numbers. They perform their operations on these binary representations and then return standard JavaScript numerical values.
Operator Description Syntax
& Bitwise AND Performs a Boolean AND operation on each bit of its integer arguments. a & b
| Bitwise OR Performs a Boolean OR operation on each bit of its integer arguments. a | b
^ Bitwise XOR Compares each bit of its first operand to the corresponding bit of its second operand.

If one bit is 0 and the other bit is 1, the corresponding result bit is set to 1.

Otherwise, the corresponding result bit is set to 0.

a ^ b
<< Left shift Moves all the bits in its first value to the left by the number of places specified in the second value. a << b
>> Signed right shift The left value's value is moved right by the number of bits specified by the right value. a >> b
>>> Unsigned right shift Performs the same as the >> operator, except that the bits shifted in on the left are always zero. a >>> b

Relational operators

Relational operators test or define the kind of relationship between two entities, then return a Boolean value
Operator Description Syntax
< Less than Returns true if the first value is less than the second value. a < b
> Greater than Returns true if the first value is greater than the second value. a > b
<= Less than or equal Returns true if the first value is less than or equal to the second value. a <= b
>= Greater than or equal Returns true if the first value is greater than or equal the second value. a >= b

Equality operators

Equality operators compare their operands for strict equality or inequality. They behave similarly to relational operators but have lower precedence than them.
Operator Description Syntax
== Equal (after implicit type conversions) Returns true if the values are equal. a == b
!= Not equal (after implicit type conversions) Returns true if the values are not equal. a != b
=== Strict equal Returns true if the values are strictly equal. a === b
!== Strict not equal Returns true if the values are are not equal and/or not of the same type. a !== b

Binary Logical operators

Logical operators combine two or more conditions and then return a Boolean value.
Operator Description Syntax
|| Logical OR Returns true if at least one of the conditions returns true. a || b
&& Logical AND Returns true if all of the conditions return true. a && b

Conditional operators

The operator represents a conditional expression.
Operator Description Syntax
(?:)

Tests a condition and then evaluates one of two expressions. The expression evaluated depends on whether the condition tested evaluates to true or false.

condition ? a : b
