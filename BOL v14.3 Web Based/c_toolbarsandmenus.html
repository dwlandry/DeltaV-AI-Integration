The Recipe Studio ribbon and quick access toolbar

Recipe Studio uses both menus and toolbars. Each item on a menu and each button on a toolbar is a command that Recipe Studio executes. For example, if you want to save the current recipe (the one you are working on), you can select the File > Save option from the menus, or you can click the button on the toolbar. The same command is given to Recipe Studio, and the same function (saving the recipe) occurs.

The menus are fixed in place and cannot be moved. They are always in the same order and always appears across the top of your window. However, the toolbars can be moved around to better suit you and how you use Recipe Studio. For example, you might find that you use the PFC editing toolbar extensively when working with recipes.

You can move the toolbar to a convenient spot, such as, across the top of the window or to the Diagram View.
