The Batch OI Configuration Tool

The Batch OI Configuration tool sets which commands are enabled on this workstation when a client (such as the Batch Operator Interface or DeltaV Operate’s Unacknowledged Prompts control) runs. The settings configured here are set for this workstation.

Note: The option, Allow settings to be configured at the local client, must be enabled on the Batch Executive that you are connected to. If not selected, the local client cannot override the Batch Executive server’s selected options. To set this option (Allow settings to be configured at the local client), run DeltaV Explorer, expand the workstation that is the Batch Executive. Select Batch Executive. Right-click and select Client Configuration).
Default Batch Executive Node

This sets the default Batch Executive for all DeltaV Batch controls that run on this workstation. Select the Batch Executive from the list of all currently configured Batch Executives.

Note: This selection does not apply to the Batch Operator Interface.
DeltaV Batch Access Server Settings

Click the Advanced button to set the DeltaV Batch Access Server’s advanced options.

Important: Changing these options can change the frequency with which the DeltaV Batch Access Server connects to the Batch Executive, affecting the performance of the DeltaV Batch clients (Batch Operator Interface, DeltaV Batch controls, and so on).
Actions

Select the check boxes in the Enable column for the functions you want to enable in the Batch Executive client.

When enabled, a function is available in the client. For example, when the Start command is enabled and the Batch Operator Interface application is the client, the Start button on the button bar is available (provided the logged in user has the appropriate security access level as defined in DeltaV User Manager).

If an action is not enabled, the corresponding button is not displayed on the button bar and the function is grayed out on the related context menu, if applicable.
