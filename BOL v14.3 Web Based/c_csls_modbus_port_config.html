Configure LSNG Modbus ports

On the LSNG Modbus Port 1 and Modbus Port 2 properties dialogs:
  • On the General tab, enter a description of the ports, if desired.
  • On the Advanced tab, set the IP address and Subnet mask of the ports.
    Note:

    The IP address must be on the same segment as was configured for the device in the AS configuration tool. For example, if the IP address configured in the AS configuration tool is 192.168.0.1 for the device (on this port) the IP address here could be 192.168.0.2.

    Note:

    The IP address and subnet mask you configure must allow for the standby LSNG card's automatically configured IP address. The standby card's IP address is increased by one in the most significant 0 in the subnet mask. If the standby card's address rolls over into the next subnet, then the CONFIG ERROR bit is set and the subsystem has bad status. For example, if the subnet mask is 255.255.254.0 the standby card's address has 256 added to it. If you configure the address 10.20.1.200 standby's address is 10.20.2.200 which is a configuration error because it is not in the configured subnet.

It is possible to configure signals manually in DeltaV Explorer, and there may be some circumstances in which you may want to (adding or modifying a few signals) but the most efficient way is to use DeltaV Bulk Edit.
