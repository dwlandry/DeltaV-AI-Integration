Resetting a batch

Any batch (that is the top level recipe) that is in a terminal state (COMPLETE, STOPPED, ABORTED) can be reset using the Batch Controls in DeltaV Operate. (Specifically, the Batch Commands toolbar control together with the Batch List control.)

Resetting a batch puts the entire batch back in the READY state, making it possible to perform an Active Step Change on the batch. The contained steps of a reset batch are placed in the IDLE state.

Resetting a batch requires the operator has the key for the BATCH_RESET function. By default, this function is assigned to the Batch Operate lock.

The reset batch

  • Remains on the batch list

  • Retains the batch ID

  • Retains parameter values

  • Uses the Batch Application Manager configuration setting (Release Retained Resources for Reset Batch) to release or retain resources

  • Acquires the previously bound units again (unless a rebind is performed)

  • Appends the top-level recipe's run count with a -# (where the number increments starting at 2) for every time it is in the READY state

Note:

This function is not available in the Batch Operator Interface.
