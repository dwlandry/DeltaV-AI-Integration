Create a campaign

The procedure that follows outlines the basic steps for creating a campaign using the Create Campaign dialog, shown below:

To create a campaign:

  1. Enter a name in the Campaign Name field.
  2. Enter a number in the Number of Batches field.
  3. Enter a number in the Maximum Active Batches field.
  4. Enter a description in the Description field.
  5. Click the Select button to select the base recipe, scale the batch, change unit bindings, and enter parameter values.
  6. Select Continuous Iteration (only available after selecting the base recipe) to have this campaign run continuously.

    When continuous iteration is enabled, the Campaign Manager continues to add batches to this campaign based on the base recipe. This allows the campaign to continue until continuous iteration is turned off. Once continuous iteration is turned off, the Campaign Manager runs all the remaining batches in the campaign (without creating more). This allows you to set a cleanup batch to be run after all other batches complete and are removed.

  7. Enter a Batch ID Prefix, Sequence, and Suffix or use the default value for any of these fields.
    Note:

    The Batch ID Prefix field defaults to the first 22 characters of the campaign name. The Sequence number is a required field. It is a counter with a default starting value of 00001; it can be changed to any integer. The Suffix field defaults to the first 22 characters of the base recipe. Commas are not allowed as part of the Batch ID.

  8. Click Setup Batch (or Cleanup Batch) if you want to create a setup or cleanup batch for the campaign.
  9. On the Create Campaign dialog, click Create to create the campaign batches, including the setup and cleanup batches.
  10. If you wish to specify that completed batches should be automatically removed from the Batch Executive, open the Properties dialog for the campaign.
