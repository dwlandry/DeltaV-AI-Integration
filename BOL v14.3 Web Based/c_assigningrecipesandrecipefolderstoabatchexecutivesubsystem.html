Assigning recipes and recipe folders to a Batch Executive subsystem

You can assign recipes and recipe folders to run on multiple Batch Executives. A recipe can run in multiple areas but all the units required to run a recipe must reside on a single Batch Executive.

For example a recipe for a paint blending system can run on BatchExec_1, BatchExec_2, and BatchExec_3. You assign the recipes to these three Batch Executives. Also assigned to these three Batch Executives are Plant Area 1 (which is assigned to BatchExec_1), Plant Area 2 (which is assigned to BatchExec_2), and Plant Area 3 (which is assigned to BatchExec_3). All the units required to complete the recipe on BatchExec_1 must reside in Plant Area 1; all the units required to complete the recipe on BatchExec_2 must reside in Plant Area 2, and so on.

A recipe folder is a container for recipes of a single category type such as Procedure or Unit Procedure. When you assign a recipe folder to a Batch Executive, the entire contents of that folder is assigned to that Batch Executive. A recipe or recipe folder can be assigned to a Batch Executive only from the DeltaV Explorer; recipes cannot be assigned from Recipe Studio. You assign a recipe or recipe folder to a Batch Executive by dragging the recipe or recipe folder from System Configuration/Recipes in the hierarchy or from the context menu of the Assigned Recipes component under a Batch Executive.

The workstation must be enabled as a Batch Executive and downloaded before any changes can take effect.
