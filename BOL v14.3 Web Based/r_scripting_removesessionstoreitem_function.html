RemoveSessionStoreItem function

RemoveSessionStoreItem() discards data retrieved by AddSessionStoreItem() during this DeltaV Live session.
Arguments
1
Argument Description
key string The unique name of the data item to be discarded from the storage area. The key string is case sensitive.
Return values
None
Syntax
.RemoveSessionStoreItem(key string)
Examples
Example Result
If you want the layout-scope variable, MyVar, to revert to its configured default value when the layout configuration is refreshed, you could use the following expression: 
// next time we open, revert to the configured default value
DL.RemoveStoreItem("Lyt.MyVar")
 When the DeltaV Live user clicks the Refresh Configuration button, the variable, MyVar, reverts to its configured default value.
