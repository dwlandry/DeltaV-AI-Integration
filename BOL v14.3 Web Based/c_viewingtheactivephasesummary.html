Viewing the active phase summary

The Active Phase Summary screen displays an overview of the active phases (phases that are not in the IDLE or UNKNOWN states are displayed) configured in the area model. From this screen, operators can quickly identify units and their related phases.

Operators can selectively filter which columns of information are visible by configuring the Active Phase Summary screen from the System Configuration and Defaults screen. The data displayed in the columns of the screen can include the following:

Phase - a listing of all phases in the area model.

State - the current state of the phase.

Mode - the current mode of the phase, either MANUAL or AUTOMATIC.

Unit - the unit to which the phase belongs.

Step index - the current step of the active phase, displayed as a number on the Select Phase button.

Owner - the current controller of the phase.

Batch ID - the name of the batch to which the phase belongs.

Operator Message - informational message sent to the operator.

Failures - any instances where the phase did not function properly.

The Active Phase Summary screen functions as a display screen only. Interaction with the batch at the phase level must be done from the Phase Control screen.
