DeltaV workspace toolbars

The DeltaV Workspace toolbars are:

  • DeltaV Standard

  • DeltaV Edit

  • DeltaV Utilities

  • DeltaV Upgrade Picture Expert Toolbar

  • DeltaV Upgrade Trend Graph Pics toolbar

  • DeltaV Export To DeltaV Live toolbar

DeltaV Standard Toolbar

Use the DeltaV Standard Toolbar buttons to perform standard tasks such as creating new pictures from a template, opening, closing pictures, and so on. This toolbar also contains buttons that change the operating environment and provide quick access to the Task Wizard dialog box.

Click...

To...

New Picture from Template

Create a new picture from a template.

Open

Open a picture.

Close File

Close a picture. The data links are counted before the picture is closed. You will receive a warning if the number of data links in the picture exceeds the recommended limit of 899. You are allowed to close the picture but remember, an excess of 899 data links can degrade system performance.

Saves a Picture

Save the picture and count data links. (See the comments about data links in the description of the Close File button above.)

DeltaV Delete utility

Open the DeltaV Delete utility to delete graphics (.grf) files from folders.

DeltaV Recycle Bin utility

Open the DeltaV Recycle Bin utility to delete (permanently) graphics (.grf) files from the hard drive or to restore graphics files to their original location.

Print

Print the picture.

New Dynamo Set

Create a new dynamo set.

Note   You must use the File > Save As command to save and name the new dynamo set. Do not use the Save toolbar button because it fails to save the new dynamo set with the default name.

Full Screen

Use the full screen to create pictures.

Switch to Run

Switch to DeltaV Operate in Run mode.

Task Wizard

Open the Task Wizard dialog box which provides quick access to Experts and Wizards.

DeltaV Edit Toolbar

Use the DeltaV Edit toolbar buttons  to perform basic editing tasks such as Cut, Copy, Paste, and Undo. This toolbar also contains buttons to hide the System Tree (to create a larger work area) and to set user preferences for the startup environment.

To..

User Settings

Set user settings such as preloading faceplate, detail, and trend pictures, and customizing the startup environment.

Toggle System Tree

Show or hide the System Tree. This is a useful feature if you need a larger work area.

Cut

Cut an object.

Copy

Copy an object

Paste

Paste an object.

Undo

Undo an action performed on an object.
