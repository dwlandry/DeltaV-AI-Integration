Bulk editing local I/O cards and channels

This section outlines one way to bulk edit local I/O cards and channels. This section does not explain how to bulk edit remote I/O cards. 

To successfully import bulk edited cards, the controller to which you are assigning the cards must already be in the database. Similarly, to import bulk edited channels, the cards must already be in the database. 

The general procedure to bulk edit local I/O cards and channels is:

  1. Create one card of a type you want to edit.

  2. Configure the card's channels.

  3. Use the Card.fmt format specification file to export the card or create your own format specification file.

  4. Use one of the channel format specification files or create your own and export a channel of the type you want to bulk edit.

    Format Specification files can allow existing card configurations to be overwritten in the database.  

  5. Edit the cards in the bulk edit Excel add-in.

  6. Edit the channels in the bulk edit Excel add-in.

  7. Import the cards.

  8. Import the channels.
