PlacementAlignment enum

The PlacementAlignment enum is recommended as the means for using descriptive names for the alignment options in a Placement object. The PlacementOption enum includes the following values: 
enum PlacmentAlignment {
    Right	  = 0B0001,
    Left	  = 0B0010,
    Center	  = 0B0011,
    Bottom	  = 0B0100,
    Top	  = 0B1000,
    Middle	  = 0B1100,
    Centered  = 0B1111,  // both Horz. Center and Vert. Middle
}
