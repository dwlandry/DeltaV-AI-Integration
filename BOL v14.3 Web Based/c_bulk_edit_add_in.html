The bulk edit add in

User-defined exports and imports transfer configuration data to and from text files. DeltaV provides a Bulk Edit Excel add-in you can use to edit the configuration in a spreadsheet. With bulk editing you can easily create or modify large amounts of configuration data, such as I/O channels. 

Note:

The Bulk Edit add-in requires Excel 2013 software and Visual Basic for Applications.

The remainder of this section explains how to install the software and provides an overview of using bulk edit.
