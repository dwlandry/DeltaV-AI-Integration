LS CHARM types

To specify the location and type of LS CHARMs associated with the field measurement, you configure the LS CHARM and the Device Signal Tag (DST) of the input or output parameter. The following LS CHARM classes are available in CSLSs.

Discrete Output

Drives the output to a discrete value and holds the output at that value. Outputs immediately reflect the output value that was received.

Two-State DVC Output

Drives a digital valve controller output device with an On value of 20 mA. The Off value is configurable: either 0 mA or 4 mA (to allow for HART communications).
