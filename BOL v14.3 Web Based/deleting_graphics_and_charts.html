Deleting and restoring graphics and charts

The DeltaV Delete Utility and the DeltaV Recycle Bin utility provide the means to delete or restore graphics and charts without the need for workstation downloads. These utilities are accessed only from DeltaV Operate Configure mode or Process History View on Professional or ProfessionalPLUS workstations. To access these utilities, users must be assigned to either the Basic configuration or Basic operator role, and have permissions to delete, restore, and purge items.
Note: The utilities cannot be accessed from remote workstations.

You can delete graphics (.grf files) and charts (.phv* files ) from the \DeltaV\DVData directory using the DeltaV Delete Utility. To delete graphics, launch the utility from DeltaV Operate Configure mode. When launched from here, only .grf files contained in the DeltaV\DVData\Graphics-iFix\Pic folder are listed in the utility. To delete charts, launch the utility from Process History View. When launched from here, only .phv* files deleting_graphics_and_charts.html#concept_60C91F934FAE4CD18D484A02ACBAF346__phv_fn contained in the DeltaV\DVData\Charts folder are listed in the utility.

When you delete graphics and charts using this utility, they propagate to all workstations in the system, including remote workstations, without the need for workstation downloads. The deleted files are then dumped in a centralized trash location called the DeltaV Recycle Bin. The DeltaV Recycle Bin stores the deleted files until you purge them from the bin, thus permanently deleting them from the hard drive, or until you restore them to their original location. Deleting and restoring from the DeltaV Recycle Bin also propagate to all workstations in the system, including remote workstations, without the need for workstation downloads.

Use the Auto-Update Diagnostics application to view real-time events of delete and restore propagation. You can launch this application from DeltaV Diagnostics by selecting Tools > Auto-Update Diagnostics. You can view additional details, such as file locations, for delete and restore propagation in the YellowPages.log file located in \DeltaV\DVData. Click Log File in the Auto-Update Diagnostics application to open YellowPages.log.

VCAT for Displays enabled

If the DeltaV system has VCAT for Displays enabled, the DeltaV Delete utility displays all .grf files contained in the DeltaV\DVData\DisplayWorking\Pic folder. When files are deleted using this utility, they are still dumped in the DeltaV Recycle Bin but can also be viewed from the Recover - Purge dialogue. With VCAT for Displays enabled, you can choose to purge and restore graphics through either the VCAT Recover-Purge dialog or the DeltaV Recycle Bin utility. The following tables outline the specific purge and restore behaviors for each tool.
Purging and restoring graphics using the VCAT Recover - Purge dialog
Action in the Recover - Purge dialog What happens in the DeltaV Recycle Bin
Select to purge the first entry (last deleted version). The corresponding file is purged from the DeltaV Recycle Bin.
Select to purge any entry other than the first. The corresponding file is not purged from the DeltaV Recycle Bin.
Select to restore any version. The corresponding file from the DeltaV Recycle Bin is restored.
Purging and restoring graphics using the DeltaV Recycle Bin utility
Action in the DeltaV Recycle Bin What happens in the Recover - Purge dialog
Select a file to purge. The first entry (last deleted version) of the corresponding file is purged.
Select a file to restore. The first VCAT entry (last deleted version) is removed .
Note: A download is required each time a restore is performed.

Propagation behavior

When files are deleted or restored, they propagate to all workstations in the system without workstation downloads. They also propagate across remote workstations. When the ProfessionalPLUS is offline, changes propagate to all workstations once the ProfessionalPLUS comes back online and synchronizes with the workstation where the action occurred. Similarly, when a workstation is offline, changes propagate to that workstation once it comes back online and synchronizes with the ProfessionalPLUS. If a file is currently being used in another application or on another workstation, it attempts to propagate until it is able to complete its operation.
Important: Deleting a file directly from the DeltaV\DVData\Graphics-iFix\Pic, DeltaV\DVData\DisplayWorking\Pic, or DeltaV\DVData\Charts directories is not considered a valid operation and the files will not be dumped in DeltaV Recycle Bin.
