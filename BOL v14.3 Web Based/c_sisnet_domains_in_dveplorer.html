SLS 1508 SIS Network domains in DeltaV Explorer

In DeltaV SIS networks, Logic Solvers are configured in SIS Network domains. These are not physical groupings, but there will usually be some correspondence between SIS Network domains and SIS Network rings. By default, the SIS Network contains one SIS Network domain that cannot be deleted (it can be renamed). You can create an additional 14 domains.

Nothing in the DeltaV Explorer view of SIS Network domains indicates anything about the physical connections between Logic Solvers or domains. Because publishing and referencing of secure parameters depends on physical connections between Logic Solvers, you must know the physical connections between Logic Solvers before you can configure SIS Network domains and your safety logic.

The following figure shows how two SIS Network domains under the SIS Network, BOILER1 and BOILER2, appear in DeltaV Explorer.

SIS Network domain Configuration Example

Logic Solvers in SIS Network domain folders are associated on a one to one correspondence with Logic Solver cards on DeltaV I/O Interface Carriers. For example, Logic Solver SLS1 is associated with the Logic Solver card in controller CTLR1 in card slot C01. After one Logic Solver card on a node has been associated with a SIS Network domain, none of the other Logic Solver cards on that node can be associated with another SIS Network domain.
