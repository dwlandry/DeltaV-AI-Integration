Date Time Event function block

The Date Time Event (DTE) function block provides time of day functions and event timer functions. Use the time of day functions to obtain date and time information in various formats. Use the event timer functions to schedule future events at a specified date and time. The block is supported by the expression functions TIME, TIME_TO_STR, and STR_TO_TIME. In a module you can use Calc block expressions to set DTE block parameter values.

There are no modes or alarm detection in the block.
