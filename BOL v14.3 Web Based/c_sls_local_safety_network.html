CHARMs Smart Logic Solver Local Safety Network (LSN)

The Local Safety Network subsystem under a DeltaV SIS Controller contains:
  • Unassigned CHARMs Logic Solvers subsystem
  • CHARMs Smart Logic Solvers (as many as 16).

The figure shows an expanded view of the Local Safety Network subsystem.

CSLS Local Safety Network


The Unassigned Logic Solvers folder contains CSLSs that are physically connected to the Local Safety Network on this SISCTLR but that are not yet assigned to the SISCTLR. The contents view of Unassigned Logic Solvers shows the type, model, and revision of the unassigned CSLSs.

CHARMs Smart Logic Solvers appear below the Unassigned Logic Solvers folder. The appearance of the icons depends on assignment and commissions status. In the figure:
  • CSLS-2 has not been assigned to a physical CSLS.
  • CSLS-3 has been assigned to a physical CSLS but not yet commissioned.
  • CSLS1 has been assigned to a physical CSLS and has been commissioned.

CSLS placeholders can be created from the Local Safety Network context menu. The placeholders can be assigned to physical CSLSs in the Unassigned CHARMs Logic Solvers folder.

Once a CSLS has been assigned to a physical CSLS, it can be commissioned.
