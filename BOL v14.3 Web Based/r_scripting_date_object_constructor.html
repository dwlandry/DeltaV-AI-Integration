Date object constructor

You can also create Date objects using the Date object constructor. The Date object constructor is the %Date% intrinsic object and the initial value of the Date property of the global object. When called as a constructor, it creates and initializes a new Date object instance.

The following prototype functions, which can be used on Date object instances, are supported in DeltaV Live graphics expressions and scripting. The Graphics Studio Script Assistant provides help in constructing valid expressions for using these functions.
Name Description Syntax
Get functions
getDate() Returns the day of the month (0–31) for the specified date, according to local time. dateObj.getDate()
getDay() Returns the day of the week (0–6) for the specified date, according to local time. dateObj.getDay()
getFullYear() Returns the year (four digits for dates between year 1000 and 9999) for the specified date, according to local time. dateObj.getFullYear()
getHours() Returns the hour (0–23) for the specified date and time, according to local time. dateObj.getHours()
getMilliseconds() Returns the milliseconds (0–999) for the specified date and time, according to local time. dateObj.getMilliseconds()
getMinutes() Returns the minutes (0–59) for the specified date and time, according to local time. dateObj.getMinutes()
getMonth() Returns the month (0–11) for the specified date, according to local time. dateObj.getMonth()
getSeconds() Returns the seconds (0–59) for the specified date and time, according to local time. dateObj.getSeconds()
getTime() Returns the number of milliseconds between midnight of January 1, 1970, and the specified date. dateObj.getTime()
getTimezoneOffset() Returns the time difference between UTC time and local time, in minutes. dateObj.getTimezoneOffset()
getUTCDate() Returns the day of the month (1–31) for the specified date, according to universal time. dateObj.getUTCDate()
getUTCDay() Returns the day of the week (0–6) for the specified date, according to universal time. dateObj.getUTCDay()
getUTCFullYear() Returns the year (four digits for dates between year 1000 and 9999) for the specified date, according to universal time. dateObj.getUTCFullYear()
getUTCHours() Returns the hour (0–23) for the specified date and time, according to universal time. dateObj.getUTCHours()
getUTCMilliseconds() Returns the milliseconds (0–999) for the specified date and time, according to universal time. dateObj.getUTCMilliseconds()
getUTCMinutes() Returns the minutes (0–59) for the specified date and time, according to universal time. dateObj.getUTCMinutes()
getUTCMonth() Returns the month (0–11) for the specified date, according to universal time. dateObj.getUTCMonth()
getUTCSeconds() Returns the seconds (0–59) for the specified date and time, according to universal time. dateObj.getUTCSeconds()
Set functions
setDate() Sets the day of the month (0-31) for a Date object, according to local time. dateObj.setDate(day)
setFullYear() Sets the full year (four digits for dates between year 1000 and 9999) for a specified date, according to local time. dateObj.setFullYear(year, month?, day?)
setHours() Sets the hours for a specified date, according to local time. dateObj.setHours(hour, min?, sec?, millisec?)
setMilliseconds() Sets the milliseconds for a specified date, according to local time. dateObj.setMilliseconds(millisec)
setMinutes() Sets the minutes for a specified date, according to local time. dateObj.setMinutes(min, sec?, millisec?)
setMonth() Sets the month for a specified date, according to local time. dateObj.setMonth(month, day?)
setSeconds() Sets the seconds for a specified date, according to local time. dateObj.setSeconds(sec, millisec?)
setTime() Sets the date and time for a specified date by adding or subtracting a specified number of milliseconds to or from January 1, 1970, 00:00:00 UTC. dateObj.setTime(time)
setUTCDate() Sets the day of the month for a specified date, according to universal time. dateObj.setUTCDate(day)
setUTCFullYear() Sets the full year (four digits for dates between year 1000 and 9999) for a specified date, according to universal time. dateObj.setUTCFullYear(year, month?, day?)
setUTCHours() Sets the hour for a specified date, according to universal time. dateObj.setUTCHours(hour, min?, sec?, millisec?)
setUTCMilliseconds() Sets the milliseconds for a specified date, according to universal time. dateObj.setUTCMilliseconds(millisec)
set UTC Minutes() Sets the minutes for a specified date, according to universal time. dateObj.setUTCMinutes(min, sec?, millisec?)
setUTCMonth() Sets the month for a specified date, according to universal time. dateObj.setUTCMonth(month, day?)
set UTC Seconds() Sets the seconds for a specified date, according to universal time. dateObj.setUTCSeconds(sec, millisec?)
Conversion functions
toDateString() Converts the "date" portion of a Date object into a string. dateObj.toDateString()
toString() Converts a Date object into a string. dateObj.toString()
toTimeString() Converts the "time" portion of a Date object into a string. dateObj.toTimeString()
toUTCString() Converts a Date object into a string, according to universal time. dateObj.toUTCString()
valueOf() Returns the primitive value of a Date object. dateObj.valueOf()
