Granting keys to recipe authorization function locks

A batch operation is associated with a specific lock to which a key is granted on a group or user level. The recipe authorization function locks (RECIPE_APPROVAL_01 to RECIPE_APPROVAL_05) are assigned to User Locks 06 -10 by default. You can change this assignment if you wish. Use the DeltaV Explorer to modify the function lock assignments (Setup/Security/Function Security/Properties).

Before you can use the recipe authorization function, you must assign keys to the recipe authorization function locks. You might consider assigning recipe authorization keys to groups based on job function. A group or individual with a recipe authorization key is called a signer. For example you might assign one set of keys to a signer group called managers, (Signer Description is managers) a second set to a signer group called supervisors, (Signer Description is supervisors) and so on. You can create up to five signer groups for recipe approval. Suppose that you use three signer groups: managers, supervisors, and lead operators in your recipe authorization scheme. You give managers the key to the RECIPE_APPROVAL_01 lock, supervisors the key to the RECIPE_APPROVAL_02 lock, and lead operators the key to the RECIPE_APPROVAL_03 lock. A recipe is considered authorized for download when signers with these three keys approve it.

Use the DeltaV User Manager application to assign keys. Click Start > DeltaV Engineering > User Manager to open the User Manager application.

Note:

Recipe authorization tracking is improved when both Full Name and User Name are specified in User Manager. Be sure to complete the Full Name field in the DeltaV User Manager for any account that will have signatory rights on a recipe.
