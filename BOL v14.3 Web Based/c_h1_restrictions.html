Restrictions on automatic assignment of function blocks

Automatic assignment of function blocks to the H1 card is not supported:

  • On Series 1 H1 cards.

  • On H1 4-port Plus cards.

  • On Module Classes and Module Instances.

  • For Bulk Edit.

  • In modules containing a connection to an input or output parameter that was made visible on the block through the Show Parameter command. Parameters made visible through the Show Parameter command can be visible on the block; however, they cannot be wired to.

  • In modules containing any parameters with Process Learning enabled.

  • On the Module Properties dialog in DeltaV Explorer. It can be enabled from  the Modules Properties dialog in Control Studio only.

Conditional Alarming is disabled on blocks assigned to the H1 card.

Note:

Use the PID_FP faceplate rather than the FFPID_FP faceplate with a PID block assigned to run in the H1 card.
