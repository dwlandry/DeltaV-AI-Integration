String object

The following String object values and functions are supported in DeltaV Live graphics expressions and scripting. See the subtopics under String object for more details about each function.

String object value

Value Description
length Returns the number of characters in the string value represented by this string object.

String object functions

Function Description Syntax
String() Converts a value to a string. String(value)
concat() Combines the characters in two or more strings and returns them as one new string. str.concat(string1?, string2?, …, stringN?)
indexOf() Returns the position of the first found occurrence of a specified value in a string. str.indexOf(search string, position?)
lastIndexOf() Returns the position of the last found occurrence of a specified value in a string. str.lastIndexOf(search string, position?)
substring() Takes two arguments and returns a subset of a string between two specified indices. str.substring(start, end?)
