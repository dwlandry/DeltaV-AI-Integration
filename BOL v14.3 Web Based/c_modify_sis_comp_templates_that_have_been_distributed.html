Modify SIS composite templates after deployment

If a problem is found with one of the released SIS Composite Templates and it needs to be modified, tested, and then redistributed to the other engineering locations, use the following steps:

At the engineering location where the template was originally developed

  1. An engineer copies and unprotects the template.

  2. The engineer renames the copy if desired.

  3. The engineer edits the template as required and saves it.

  4. The engineer opens the SIS module originally used to test the composite in Control Studio.

  5. For each block that uses the template, the engineer selects Convert > To Existing Object and then browses to the newly edited template.

    The parameter overrides of matching named parameters are retained during the conversion process. 

  6. The engineer downloads the SIS Module, opens the SIS Module in Control Studio and debugs the functionality.

    The edit, download, and debug cycle continues until the SIS Composite Template is fully tested and is ready for distribution. 

  7. When the template is fully tested and ready for distribution, the engineer protects the template.

  8. The engineer exports the template and the .fhx file produced is sent to other engineering locations.

At a target engineering location

  1. The engineer imports the new SIS Composite Template. 

  2. The engineer selects the original protected SIS Composite Template in DeltaV Explorer, selects References, and then prints or records the list of SIS modules that use the template.

  3. The engineer opens each SIS module in Control studio.

  4. For each block in a module that uses the template, the engineer selects Convert > To Existing Object and then browses to the newly edited template.

    The parameter overrides of matching named parameters are retained during the conversion process. The only editing option available  on the embedded block is to set the parameter values of exposed parameters. 

  5. Use the References dialog to confirm that all uses of the original protected SIS Composite Template have been changed. 

  6. Delete the original protected SIS Composite Template if required.

The protected SIS Composite Template cannot be unprotected, edited to change anything about it, or copied.
