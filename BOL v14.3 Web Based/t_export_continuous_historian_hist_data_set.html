Export a historical data set

Current and extended historical data sets can be exported. If only an active data set is available, you can use Create New Active Data Set to create a new active data set and convert the existing active data set to a current data set that can be exported.

To export one or more current or extended data sets, the user must have the DeltaV security key for the HDS_EXPORT function, and then complete the following steps:

  1. Select the current data set(s) you wish to export. To select more than one data set, hold down the CTRL or SHIFT key while selecting.
  2. Click the Export History Data Set(s) icon on the toolbar or select Export Data Set(s) from the Tools menu. You can also right-click the data set and select Export History Data Set(s) from the context menu.
  3. On the Browse dialog, browse for the directory to which you want to export the data sets. It is recommended that you select a directory location on the current workstation, but outside the DeltaV system. The Export History Data Set(s) dialog shows the progress of the export.

    If you interrupt the process by clicking the Abort button, the export in progress is not completed; however, any data sets already exported are not affected.

  4. Click Close to close the Export History Data Set(s) dialog. Note that exporting data sets does not automatically delete them from Primary storage.

The data sets that are exported are not deleted from the Primary storage area. If the data set is again exported to the same directory, the export is given a unique name, appending -n to the name. The newly exported data set does not overwrite the existing one. It is common for the size of exported data sets to be different from the size of the original data set.
