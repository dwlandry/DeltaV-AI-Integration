User accounts

The first user who logs in to the system (prior to installing DeltaV) starts off with a default user name of either Administrator or Emerson. This person has administration privileges associated with the computer. Once DeltaV is installed, the Windows user logged into the system for the Workstation Configuration step has full access to all DeltaV functions, such as configuring hardware, configuring the process system, downloading the configurations, and so on. Therefore, the Windows user that was logged in for Workstation Configuration must configure the ProfessionalPLUS workstation.

Note: You cannot change the default administrator account's privileges unless you have created another user with equal privileges.

If you are the first user after the workstation has been configured, log in to Windows as the administrator that ran Workstation Configuration and also log into DeltaV as the same administrator. In a domain environment, this must be a domain administrator because you will be creating domain-level accounts.

Some thought should be given to the overall user access scheme. If more than just one or two users will be accessing the system, you might want to limit their ability to change the process configuration or perform downloads. To do this, you need to set up user names and access privileges in the User Manager.

Click Start > DeltaV Engineering > User Manager.

The DeltaV installation creates default DeltaV interactive user accounts that are disabled by default.
