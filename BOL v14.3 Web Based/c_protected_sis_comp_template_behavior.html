Protected SIS composite template behavior

The .fhx file of a protected SIS Composite Template is in a form that cannot be edited to have its protection removed, its password changed (if present), its originating system information changed or its configured contents changed. The password (if it exists) is encoded so that it is not readable in the .fhx file. 

A protected SIS Composite Template cannot have the following actions performed on it:

  • Unprotect, unless it is on the same DeltaV system where it was protected.

  • Modify by any application such as DeltaV Explorer, Control Studio or Bulk Edit.

  • Rename. The name of the protected SIS Composite Template is how it is identified in the different engineering locations.

  • Cut

A protected SIS Composite Template can have the following actions performed on it only if it is not used as an Embedded Composite in the  DeltaV system where the action is being performed.

Actions that can be taken on a protected SIS Composite Template

Action

On the system where it was originally protected

On another system

Unprotect

Yes. Users (including DeltaV Administrators) must have the SIS Can Configure key to unprotect the template. In addition, if the template was protected with a password, users who are not DeltaV Administrators must know the password. 

No

Modify by Import

Yes, if the imported SIS Composite Template is protected and the originating system information of the imported SIS Composite Template matches the originating system information of the existing SIS Composite Template.

Delete

Yes. You must unprotect the template first.

Yes. (The template does not have to be unprotected.)

You can copy a protected SIS Composite Template on the system where it was originally protected using Copy/Paste from DeltaV Explorer and Save As from Control Studio. The newly created SIS Composite Template is protected with the same password (if any) as the original SIS Composite Template.
