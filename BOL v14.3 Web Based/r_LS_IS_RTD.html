LS RTD / Resistance input (Intrinsically Safe) CHARM specifications

Installation notes

  • The LS RTD / Resistance input (I.S.) CHARM requires the I.S. CHARM Terminal Block.
  • This CHARM can be configured for 2, 3, or 4-wire applications.
