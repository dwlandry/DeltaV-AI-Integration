High Performance MA3_CV_SL_ analog dynamo (HP_MA3_CV_SL_)

This dynamo can be used for analog indication where general percent of scale is important. Vertical space on the display is limited but horizontal (width) space is available. Used with PID loops, AI indicators, and ALM function blocks.

The following elements are present on the dynamo:

  • Alarm box

  • Alarm icon

  • Display tag

  • Dynamo background

  • Combination (Combo) bar graph

  • PV and SP data fields

  • Status box

  • Abnormal status icons
