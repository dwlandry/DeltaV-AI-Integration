Connect the Remote Desktop client to DeltaV through a Remote Desktop Gateway

This procedure describes the settings to select on the Remote Desktop Connection dialog when using a Remote Desktop Gateway.

Your Remote Desktop Gateway (RD Gateway), IIS Manager, and Remote Desktop Client must all be configured with the appropriate certificates before using this procedure.

  1. Log on to the computer from where you will run the Remote Desktop Connection as a user (a local administrator is not required).

    This is the computer that is not a DeltaV node or the Remote Desktop Gateway. It is the computer from which you will connect to the DeltaV node using Remote Desktop.

  2. Start a Remote Desktop Connection. Start > All Programs > Accessories > Remote Desktop Connection.
  3. i n the Remote Desktop Connection dialog, click Show Options.
  4. On the Advanced tab, click Settings.
  5. On the RD Gateway Server Settings page, use the following settings and then click OK .
    • Connection Settings: Select Use these RD Gateway server settings.
    • Server name: Enter the RD Gateway's computer name. For example, RDG-SRV.domain.com.
    • Logon method: Pick the one appropriate to your login method (for example, Smart Card).
    • Bypass RD Gateway server for local addresses: Clear check box.
    • Use my RD Gateway credentials for the remote computer: Clear check box (unless the users are the same).
  6. On the General tab, in the Computer field, type the name of the DeltaV computer, and then click Connect.
    Note:

    When connecting using a Smart Card, verify that Smart Card is selected as valid local device for the connection on the Local Resources tab.

    Local Resources > Local devices and resources > More… > Smart Cards
  7. In the Windows Security dialog, type the username and password, and then click OK.

    This is the user that is authorized to connect through the RD Gateway to the DeltaV system as defined in the RAP and CAP policies.

    Tip:

    If an error occurs stating the Smart Card logon is not supported for your user account, contact your system administrator. The issue could be with how the certificate is configured on the DeltaV domain controller.

  8. If the connection is successful, you are prompted to log into the remote computer (the DeltaV Remote Desktop Server).
    Note:

    The DeltaV system supports the use of Smart Cards for logging on to the DeltaV system. This feature can be enforced through the Smart Card Required option on the FlexLock drop-down menu. If the option is enabled, users must log on to the DeltaV system using a smart card and PIN on this workstation. If the option is not enabled, users may log on with a card (if a card reader is installed) or without a card. The setting also affects logging on to the Windows desktop from the FlexLock Windows Desktop button.
