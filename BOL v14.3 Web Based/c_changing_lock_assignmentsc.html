Changing lock assignments

Field and parameter lock associations are maintained in DeltaV Explorer under System Configuration\Setup\Security\[SIS Parameter Security, SIS Field Security, or SIS Function Security]\Properties. Parameters have a default lock that is selected in the SIS Parameter Security Properties dialog. The default lock (SIS No Access) is the lock that is assigned when an explicit assignment has not been made. Any user with a key to the default lock can write to that field or parameter or perform that function. If an explicit assignment has been made, then the key to that lock is required. If the explicit assignment is deleted (the item no longer appears in the SIS Parameter Security Properties dialog), then the default lock has control over access.

The following examples illustrate the effect of changing or removing parameter and field lock assignments.

Example 1: Attempt to write SIS101/MYPARAM.CV

  • Field name is CV. CV does not have an explicit assignment listed in the SIS Field Security Properties dialog.

  • Parameter name is MYPARAM. MYPARAM does not have an explicit assignment in the SIS Parameter Security Properties dialog.

  • The default lock for parameters is changed to SIS Can Configure.

Result: The lock in effect is SIS Can Configure. Users with the SIS Can Configure key in SIS101's plant area can write SIS101/MYPARAM.CV.

Example 2: Attempt to write SIS101/MYPARAM.CV

  • Field name is CV. CV does not have an explicit assignment in the SIS Field Security Properties dialog.

  • Parameter name is MYPARAM. MYPARAM is assigned the SIS Control lock in the SIS Parameter Security Properties dialog.

  • The default lock for parameters is changed to SIS Can Configure.

Result: The lock in effect is SIS Control. Users with the SIS Control key in SIS101's plant area can write SIS101/MYPARAM.CV. Users with the SIS Can Configure key in SIS101's plant area cannot write SIS101/MYPARAM.CV. The parameter's explicit lock takes precedence over the default lock.
