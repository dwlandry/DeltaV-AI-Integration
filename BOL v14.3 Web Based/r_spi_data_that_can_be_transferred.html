1 XD_SCALE range and units for conventional AI is always 0 to 100 percent of scale.
2 In DeltaV software PULSE value is defined as the quantity per pulse in engineering units. In SPI the equivalent property is defined as the number of pulses per engineering unit. The DeltaV interface automatically does this conversion. In SPI the Pulse area of the Conditioning tab of the Control System Tag Properties dialog contains the equivalent values. You must select units from one of s, min, h, d (equivalent to seconds, minutes, hours and days respectively). Any other unit results in the conversion assuming seconds as the time Unit of Measure.
