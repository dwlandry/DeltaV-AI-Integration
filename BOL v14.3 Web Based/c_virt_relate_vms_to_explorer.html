Relate virtual hardware to items in DeltaV Explorer

The node names of the virtual machines you create in DeltaV Virtual Studio do not appear in DeltaV Explorer. As you create virtual machines they appear in DeltaV Explorer as unassigned hardware and are identified only by MAC address.

If it is important that you know which virtual machine corresponds to a particular item in DeltaV Explorer. create a table of VM names and MAC addresses of the virtual hardware you create. Then as you populate the configuration in DeltaV Explorer, you can ensure that the names in DeltaV Virtual Studio and Explorer are the same.

As you create VMs DeltaV Virtual Studio assigns MAC addresses to them randomly. After a VM is created its MAC address appears in the dialog about the virtual machine. In the dialog the MAC address of the VM is reported in the area that shows network assignments as the primary network MAC address for the device type. The table shows the MAC address location for the node types. Note that the names in italic depend on how you name your networks.

Virtual machine MAC address location by node type
Node type The node's MAC address is specified by...
SZ controller ACN Primary MAC address
CSLS LSN Primary MAC address
LSNB LSN Primary MAC address

As you create and name virtual machines, create a table of node names and MAC addresses. As you populate DeltaV Explorer name the placeholders with the node names used in DeltaV Virtual Studio and assign each placeholder the unassigned hardware item with the corresponding MAC address.

If your situation requires that the names in DeltaV Virtual Studio be different than the names used in DeltaV Explorer, add a third column to the table to record those names. Because the example uses the same names in both Virtual Studio and DeltaV Explorer, the table looks like the following.
