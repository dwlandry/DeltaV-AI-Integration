Inputs tabs (LSMON faceplate)

The following items are contained on the tabs of the faceplate. The Inputs 1-16 tab is present by default. If there are more than 16 inputs, the faceplate also includes an Inputs 17-32 tab.

  • A text value for the output description, DESC_OUTn.
  • The output value of OUT_Dn. The faceplate is associated with one of eight OUT_D parameters on the LSMON block.
    Value of OUT_D Conditions

    Normal

    Logic type is positive and OUT_Dn is 0.

    Logic type is negative and OUT_Dn is 1.

    Tripped

    Logic Type is positive and OUT_Dn is 1.

    Logic Type is negative and OUT_Dn is 0.

  • The description of each input, DESC_INn.
  • The value (Normal or Tripped) of each input, IN_Dn. This depends on the logic type.

    Value of IN_D

    Conditions

    Normal

    Logic type is positive and IN_Dn is 0.

    Logic type is negative and IN_Dn is 1.

    Tripped

    Logic Type is positive and IN_Dn is 1.

    Logic Type is negative and IN_Dn is 0.

  • The Reset First-Out button is visible if:
    • FIRSTOUT_OPT is set to Clear on Reset and FIRSTOUT_VAL is not 0.
    • FIRSTOUT_OPT is set to Clear on Reset when Normal and FIRSTOUT_VAL is not 0 and ACTIVE_INPUTS is 0.

  • A red arrow to the left of the input that has tripped, causing the block to trip.
