Function block dynamos, faceplates, and detail displays

Many of the display elements designed for use with library modules can also be used with individual function blocks. When a control module is created using the Create > New option, it can have pop-up displays for the operator that are associated with function blocks added to the module's function block diagram.

Pop-ups for modules are particularly useful when datalinks on the pop-up display reference parameters of more than one function block in the module. One example is the detail display for motor and valve modules with interlocks. You can use pop-ups for function blocks whenever all of the datalinks on a given faceplate or detail display come from the same function block. It is often more convenient to build an entire strategy in one control module. If that strategy contains multiple function blocks, each needing its own faceplate, it is possible to do with function block pop-ups.

You might want to have separate modules for each PID block, for example, in order to have loop tags that correspond to control modules in your database. The same might apply to analog and discrete monitors as well as motors and discrete valves. However, you might want the names of your control modules to correspond to control strategies and function block usage names to correspond to your tags. If so, you can use the DeltaV function block pop-up displays. Multiple function blocks in the same module can have their own faceplate and detail display. The usage names of these function blocks are not restricted to their default names.

The DeltaV system has a faceplate display for the PID, Fieldbus PID, Pulse Input, Analog Input, Device Control, and Input Selector function blocks. It also contains a detail display for the PID, Fieldbus PID, and Device Control blocks. The Analog Input faceplate contains detail display information. There is a dynamo set for the function blocks called frsFncblk that is similar to the dynamo set for module templates (frsModules). In addition to dynamos for the PID and AI blocks, there are multiple dynamos to be used with the Device Control block having various orientations of motor, pump, and valve symbols. The Discrete Input function block has a dynamo in the frsFncblk dynamo set, but it does not have a faceplate or detail display. The frsFncblk dynamo set also has a dynamo for the Enhanced Control Selector, Fieldbus PID, and Input Selector function blocks and one for the PT compensation composite function block template.
