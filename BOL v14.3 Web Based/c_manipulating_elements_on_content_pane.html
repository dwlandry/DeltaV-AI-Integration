Manipulating graphics elements on the Content pane

When creating and modifying displays, layouts, and GEM classes, Graphics Studio provides various tools to help you add, design, and manipulate the elements on the Content pane. This topic provides a list of the basic operations you may use when designing these graphics configurations and the various places to find the tools for these operations.
Adding elements to a display, layout, or GEM class
Drag and drop from the Palette pane (applies to all elements).
Add a shape from the ribbon: Insert tab > Shapes group.
Add a text element from the ribbon: Insert tab > Text Box group.
Add either a shape or a text element from the ribbon: Format / Drawing Tools tab > Insert Shapes group.
Selecting elements
Select the element directly on the Content pane. Press and hold Ctrl to select multiple elements.
Select the element in the Selection pane. Press and hold Ctrl to select multiple elements.
Use the Select commands in the ribbon: Home tab < Editing group.
Resizing elements
Use the mouse to drag the element's handles.
Modify its width and height in the Graphics Configuration pane (Basics tab > Geometry group).
Modify its width and height in the ribbon: Format / Drawing Tools tab > Size group.
Rotating elements
Use the Rotate commands in the ribbon: Home tab > Drawing group or Format / Drawing Tools tab > Arrange group.
Modify an element's Rotation Angle property in the Graphics Configuration pane (Basics tab > Geometry group).
Cutting, copying, and pasting elements
Use the Cut, Copy, and Paste commands in the ribbon: Home tab > Clipboard group.
Use the Duplicate command in the ribbon: Format / Drawing Tools tab > Insert Shapes group.
Use an element's right-click context menu from the Content pane or Selection pane.
Deleting an element from the Content pane
Use an element's right-click context menu from the Content pane or Selection pane.
Use the Cut command in the ribbon: Home tab > Clipboard group.
Select an element and press Delete on the keyboard.
Arranging elements
Moving elements:
  • Drag an element on the Content pane.
  • Modify an element's horizontal and vertical positions in the Graphics Configuration pane (Basics tab > Geometry group).
Changing the z-order of elements:
  • Use the Bring Froward and Send Backward commands in the ribbon: Home tab > Drawing group or Format / Drawing Tools tab > Arrange group.
  • Use an element's right-click context menu from the Content pane. Applies only when multiple elements are selected.
Managing the settings for the alignment grid:
  • Use the alignment grid settings in the ribbon: View tab > Show group.
Aligning text on an element:
  • Use the Align commands in the ribbon: Home tab > Paragraph group.
Formatting text on an element
Use the Font commands in the ribbon: Home tab > Font group or Format / Drawing Tools tab > Text Styles group.
Modify the element's text properties in the Graphics Configuration pane (Text tab).
Formatting an element's fill, border, and background
Modify am element's fill and line properties in the Graphics Configuration pane (Basics tab).
Use the Fill, Border, and Background commands in the ribbon: Home tab > Drawing group or Format / Drawing Tools tab > Shape Styles group.
Using connection points
Insert a line or connector from the ribbon (Format tab > Insert Shapes group) and draw from a connection point on one element to a connection point on another element.
To create connection points on a GEM class, use the Connection Point Tool in the ribbon: Format / GEM Class Tools tab > Connection Points group.
To create connection points on an unlinked GEM, use the Connection Point Tool in the ribbon: Format / GEM Tools tab > Connection Points group.
Hiding and unhiding an element
Modify an element's Visibility property in the Graphics Configuration pane (Basics tab > Visibility group). Applies also to online mode.
Use the element's right-click context menu from the Content pane or Selection pane. Applies to only configuration mode
Click the eyeball icon next to the element in the Selection pane. Applies only in configuration mode.
Locking and unlocking an element
Use the element's right-click context menu from the Content pane or Selection pane. Applies only in configuration mode.
Click the lock icon next to the element in the Selection pane. Applies only in configuration mode.
Controlling the magnification of the content
Use the Zoom commands in the ribbon: View tab > Zoom group.
Use the Zoom commands in the bottom right corner of the Graphics Studio status bar.
Press Ctrl while moving the mouse wheel to zoom in (wheel up) or zoom out (wheel down).
