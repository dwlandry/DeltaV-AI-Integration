Implementing SLS 1508 DeltaV SIS systems

The following list is a suggested order to perform the tasks required to install, setup, and configure an SLS 1508 DeltaV SIS system:
  1. Install the DeltaV hardware and connect it to support your domain strategy.
  2. Install the DeltaV software and set it up for your needs.
  3. Enable SLS 1508 Logic Solvers.
  4. Create user accounts if needed.
  5. Assign DeltaV SIS keys and locks as needed.
  6. Configure the logic solvers.
  7. Configure logic solver channels.
  8. Configure logic solvers into the SIS domains you need.
  9. Configure physical logic solver cards.
  10. Commission logic solvers.
  11. Assign logic solvers to logic solver cards.
  12. Create SIS modules to execute the logic your safety strategy requires.
  13. Create operator graphics for your SIS system.
  14. Download the configuration.
  15. If necessary, use DeltaV diagnostics to troubleshoot your SIS system.
