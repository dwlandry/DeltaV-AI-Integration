High Performance Radar Plot dynamo (HP_Radar)

The HP_Radar dynamo maps from 3 through 12 online control module parameters in a way that makes it easy for operators to observe when values are deviating from the defined operating range.
This dynamo can be configured for a level 1, 2, or 3 display. The table below lists all of the elements that may be present on the HP_Radar dynamo. Click the link to see a description of the element.
