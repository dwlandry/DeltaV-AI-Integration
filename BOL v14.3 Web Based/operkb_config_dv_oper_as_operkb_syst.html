Configure DeltaV Operate to Run as an Operator Keyboard System

To configure DeltaV Operate to run as an Operator Keyboard system,

  1. Enable Operator Keyboard on the User Settings Dialog
  2. Edit and save DeltaV_OK_Picture.Template, the Layout file that is to be used with an Operator Keyboard system Refer to  The Layout Templates  for information on how to use this file.
