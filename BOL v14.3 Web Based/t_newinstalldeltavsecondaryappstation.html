Install the DeltaV software on the secondary Application Station (the preferred standby)

  1. Using the DeltaV installation disks, run the setup program on the secondary Application Station.
  2. When prompted to select your workstation type, select the Local Application Station option, and then click Next.
  3. When prompted to provide the workstation configuration file that you made earlier in DeltaV Explorer, click Browse, navigate to the exported workstation configuration file, and double-click it.
  4. Select the workstation name, and then click Next. The following message appears: A node with a Redundant Subsystem has been selected. Is this the preferred active Application Station? As this is the SECOND application station (the preferred standby), click NO.
    Important:

    When configuring a pair of Application Stations for the first time, you must respond Yes to this prompt when configuring one of the two Application Stations, and respond No when configuring the other Application Station. When you respond Yes, the Application Station is given the name that you specified when creating it in DeltaV Explorer; when you respond No, the characters _S are appended to the Application Station name.

  5. Follow the on-screen instructions to complete the installation of the second Application Station
