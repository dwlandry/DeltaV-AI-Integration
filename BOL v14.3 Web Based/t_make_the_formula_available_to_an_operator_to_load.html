Make the formula available to an operator to load

Before you can use the formula in a batch, you need to make it available to an operator to load. To open the Properties dialog for the formula, use one of the following two methods:

  • Select and right-click one of the values in the formula, and then select Formula Properties from the context menu.
  • Select and right-click the formula in the DeltaV Explorer, and then select Properties from the context menu.

To make the formula available to an operator, complete the following steps:

  1. Open the Properties dialog for the DARK formula.
  2. Select the Operator can load check box, and then click OK.
  3. Repeat steps 1 and 2 for the LIGHT and MEDIUM formulas.
  4. Save and download the recipe.
Note:

Whenever you make changes to a recipe, you need to save and download it before you can use it.
