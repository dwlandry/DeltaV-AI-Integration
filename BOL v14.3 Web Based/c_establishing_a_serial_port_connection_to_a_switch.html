Establishing a serial port connection to a switch

To connect to the switch you need a terminal (or a PC with terminal emulation software such as HyperTerminal). If the switch is already installed in the DeltaV network, use a Management station and terminal emulation software. The comm settings for the terminal or terminal emulation software should be:

  • 9600 baud
  • 8 data bits
  • no parity
  • 1 stop bit
  • no flow control

You also need a serial interface cable purchased from Emerson (or refer to DeltaV S-series and CHARMs Hardware Reference for information on building your own serial interface cable):

  1. Connect power to the DeltaV Smart Switch and wait for the Run light on the switch's front panel to stop flashing and turn green.
  2. Connect the terminal, PC, or Management station to the switch's serial port with the serial interface cable.

    If you are using HyperTerminal emulation software, complete steps 3 through 7. If you are using a terminal, skip to step 8.

  3. Start a HyperTerminal session.
  4. On the Connection description dialog, name the connection and click OK.
  5. On the Connect To dialog, set the Connect using field to the computers comm port and click OK.
  6. On the comm port Properties dialog, make sure the settings are correct.
  7. Click OK.
  8. Press Enter.

    The User prompt appears. Switches have two built-in accounts:

    • admin — A read/write account with the default password Emerson1
    • user — A read-only account with the default password Emerson1

    The two accounts have different access. This example uses the admin account.

  9. Enter admin at the User prompt and press Enter.

    The Password prompt appears.

  10. Enter the current password for the admin account.

    The Emerson prompt appears. The prompt is (Emerson NNNN) >, where NNNN indicates the switch type (MD for an MD switch, FP for an FP switch, and RM for an RM switch) and the switch model number.

To see a list of available commands, press ? (question mark).
