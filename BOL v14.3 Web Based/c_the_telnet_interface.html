The Telnet interface to the Smart Switch

The recommended way to interact with DeltaV Smart Switches is through the Network Device Command Center (NDCC). The only changes you should make from the Telnet interface are:

  • admin account password.
  • user account password.
  • the local offset to Universal Coordinated Time.

If you need to change other switch settings use the Network Device Command Center or configure the switch module classes or instances.

This section explains how to connect to a commissioned switch and use the command line interface to interact with it.

  1. From the Network Device Command Center, select a switch, then from the context menu select Advanced Device Operations > Telnet to Switch.

    The user prompt appears.

  2. Enter admin.

    The Password prompt appears.

  3. Enter the current admin user password (the default is Emerson1).

    The Emerson prompt appears. The prompt is (Emerson NNNN) >, where NNNN indicates the switch type (MD for an MD switch, FP for an FP switch, and RM for an RM switch) and the switch model number.

  4. Enter DeltaV to open the DeltaV Setup wizard.
