Filtering alarms by area

You can filter on and off the areas for which you want to view alarms using the Alarm Filter display (Area Alarm Filtering). This display is opened from either the Alarm List or Alarm Suppress display.

The Alarm Filter display can show up to 250 areas, through tabs, and includes both local and remote zone areas. The order is determined by the area sequence number. You can change the sequence number for an area in DeltaV Explorer using the Area Properties dialog for a specific area. Or, you can assign sequences for all areas using the Area Sequence Properties dialog.

Use the Alarm Filter picture to filter alarms in your DeltaV system through the following steps:

  • Select the check box next to an area to show that area's alarms in the Alarm Banner, Alarm List, Alarm Suppress, and Alarm Filter displays.

  • Deselect the check box next to an area to prevent that area's alarms from showing in the Alarm Banner, Alarm List, Alarm Suppress, and Alarm Filter displays.

  • Click the All On button to see alarms from all areas that can be turned on. Click the All Off button to prevent showing alarms from all areas.

  • Click an alarm area to see detailed information about the alarms for that area (for example, time of alarm, module, description, parameter, alarm description, and message).

  • In the detailed information area, click an alarm's Description column to open the associated module's faceplate, primary control display, or both. This method of opening the faceplate and primary control display is called Alarm Direct Access. You can enable or disable Alarm Direct Access in an alarm banner.

Next to the plant area name and at the top of the alarm details section, the total count of unacknowledged alarms, active alarms, and suppressed alarms are shown for all areas that are checked.

When an area is filtered out, or an alarm is suppressed, an indicator appears on a alarm banner's Acknowledge Alarm button. The following table describes the meaning of each indicator:
Indicates that one or more areas are being filtered out.
Indicates that one or more alarms are being suppressed.
Indicates that an alarm is being suppressed and an area is being filtered.
Note:
  • Alarm filtering affects only what is seen through DeltaV Live. It does not affect the Event Chronicle or the association between workstations, users, and alarms that is defined in the DeltaV Explorer or the area keys assigned in User Manager.
  • Alarm filtering affects only the current user on the current workstation. If you filter alarms and then log off the machine, the next user to log on does not see alarms from the areas that you filtered.
