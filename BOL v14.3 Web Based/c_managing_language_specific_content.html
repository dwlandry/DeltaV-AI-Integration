Managing language-specific content

Language-specific content includes all configurable strings, such as display titles, labels, abbreviations, tooltips, descriptions, and so forth. Configurable strings can be translated into any active language using the Graphics Studio Translation Guide. When configuring a graphics configuration, you can switch to the Translation Guide view to configure the strings for that configuration. Only the content for the active configuration is available in the Translation Guide.

All language-specific content belongs to the graphics configuration on which it is configured, rather than to the language. For example, assume you have a text element on a display, with strings configured in English, German, and French. These language-specific strings belong to the text element rather than to the languages, English, German, or French. If you were to copy the text element and paste it as a new instance on this or another display, all language-specific strings configured for the text element are copied to the new instance. Similarly, deleting a text element removes all of its language-specific strings.

Choosing the Display Configuration Language

In Graphics Studio, you can choose the language in which to view all language-specific strings. This language is called the display configuration language. By default, the display configuration language is the system default language. If a system default language is not provided, English is used as the default display configuration language, provided it is present as an active language. If multiple active languages exist in the database, you can switch the display configuration language from the Application Preferences drop-down menu. Additionally, you can also switch the display configuration language on individual string properties using the Language Selector drop-down next to each string field. This option changes the language for only that string.
Note: Multi-language configuration is supported only in DeltaV Live applications.
