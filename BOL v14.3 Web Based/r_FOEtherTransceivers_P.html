Fiber-Optic Ethernet Transceivers

Specifications

The GLC-FE-100FX transceiver can be used with only the Cisco 2960-8TC-L switch. The GLC-GE-100FX transceiver can be used with the Cisco 2960-24-TC-L and the 2960-48-TC-L.
