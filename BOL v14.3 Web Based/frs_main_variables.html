Main variables

Main_glb contains process graphic related definitions. In addition to declaring the variables, this file also creates the process graphic window. The following table lists the variables declared in Main_glb. Changes to these global variables are made either in the User_Ref picture or the Layout file. Refer to Customizing the DeltaV Operate Environment.
