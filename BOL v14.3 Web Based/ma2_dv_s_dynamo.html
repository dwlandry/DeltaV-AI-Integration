MA2_DV_S_ analog dynamo, 2 function blocks, small vertical deviation bar graph

This dynamo can be used for analog indication where deviation from SP is important and vertical space on the display is limited. Used with PID loops and ALM function blocks.

The following elements are present on the dynamo:

  • Alarm Icon

  • Display Tag

  • Dynamo Background

  • Engineering Units Descriptor

  • Mode Icon

  • PV Data Field

  • PV-SP Deviation (comparison) Bar Graph

  • Status Icon
