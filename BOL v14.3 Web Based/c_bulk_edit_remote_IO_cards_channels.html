Bulk editing remote I/O cards and channels

This example shows one way to bulk edit Zone 1 and Zone 2 remote I/O cards. This example does not explain local I/O cards. 

To successfully import bulk edited cards, the zones to which you are assigning the cards must be defined in the database. Similarly, to import bulk edited channels, the cards must already exist in the database. 

There are a few things to note when bulk editing remote I/O cards:

  • The common fields exported are identical except that Zone 1 cards have a rioz1_card_type field and Zone 2 cards have a rioz2_card_type.

  • Zone 1 cards have two valid card types that are unique to Zone 1. Valid card types for Zone 2 are a subset of the card types that are valid for local I/O.

  • The Channel object type is common for all I/O cards. If you want to edit channel level parameters you must specify the subtype for the channel type you are editing when you create a format specification file.

The general procedure to bulk edit remote I/O cards and channels is:

  1. Create one card of a type you want to edit.

  2. Configure the card's channels.

  3. Use an existing format specification file to export the card or create your own format specification file.

  4. Use one of the channel format specification files or create your own and export a channel of the type you want to bulk edit.

    Use the Must Exist dialog when creating Format Specification files to preven existing card configurations being overwritten in the database.

  5. Edit the cards in the bulk edit Excel add-in.

  6. Edit the channels in the bulk edit Excel add-in.

  7. Import the cards.

  8. Import the channels.
