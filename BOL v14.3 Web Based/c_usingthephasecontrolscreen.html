Using the phase control screen

The Phase Control screen lets operators view a batch from an equipment-based view. The Phase Control window graphically displays areas. By selecting any of the areas, the process cells within that area are displayed. By selecting a process cell, the units are displayed. When a specific unit is selected, the right side of the screen displays information about the corresponding phase, including its owner and its current state.

From the Phase Control screen, operators can manually control the execution of phases. Operators can place a phase in SEMI-AUTO (SINGLE_STEP) mode in order to diagnose problems or failures. In this mode, the operator can move step by step though the phase, which will pause automatically at each pause point.

Note:

You must have programmed these pause points into the phase logic.
