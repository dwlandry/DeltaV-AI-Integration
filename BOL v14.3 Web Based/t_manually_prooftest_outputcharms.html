Manually proof test output LS CHARMs

The following procedure should be used for manually proof testing output CHARMs. Appropriate steps should be taken in the SIS module and/or the process to ensure a trip does not occur when proof testing.

  1. The LS CHARM can be manually reset only when the CSLS is Unlocked. Select the CSLS in Diagnostics Explorer. If the value of the Locked parameter is Yes in the contents pane, right-click the CSLS and select Unlock. Click Confirm in the Secure Write Confirmation dialog.
  2. Right-click the LS CHARM and select Force Proof Test Reset. When prompted, click OK in the Exploring DeltaV Diagnostics dialog. Then click Confirm in the Secure Write Confirmation dialog.
    • For a DTA LS CHARM, observe that the Final element changes state either at the device or via feedback into the SIS module.
      Important: Safety outputs are de-energized during proof testing. Be sure to take appropriate precautions before proceeding.
    • For redundant DTA LS CHARMs, it is necessary to observe that the Final element changes state for both LS CHARMs. You can either force a proof test one one LS CHARM and observe that the Final element changes state while the LS CHARM is in its proof test cycle (then repeat for the partner) or unplug one of the pair and observe that the Final element changes state (repeat for the other LS CHARM in the pair).
      Important: Safety outputs are de-energized during proof testing. Be sure to take appropriate precautions before proceeding.
    • For an ETA LS CHARM, drive the value in the SIS module to ensure the final element can be energized.
      Important: Safety outputs are energized when driving the value ON from the SIS module. Be sure to manually isolate the process before proceeding.
    • For redundant ETA LS CHARMs, it is necessary to ensure that either of the LS CHARMs can energize the final element when required. You can either force a proof test on one LS CHARM and drive the output from the other while the LS CHARM is in its proof test cycle (then repeat for the partner) or unplug one of the pair and drive the value in the SIS module to ensure the final element can be energized (repeat for the other LS CHARM in the pair).
      Important: Safety outputs are energized when driving the value ON from the SIS module. Be sure to manually isolate the process before proceeding.
