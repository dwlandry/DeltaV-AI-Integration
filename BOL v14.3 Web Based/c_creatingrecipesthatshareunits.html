Creating recipes that share units

Class-based recipes are designed to run on a unit class and not on a specific unit. Class-based recipes let you share units within a class. The operator selects the unit at runtime, depending on the other recipes in production and the available units. When designing recipes to share units, you must define each unit within the unit class to have the same phase modules.

The class properties are shared with each instance (unit) of the unit class. However, each instance can define its own unit-specific information, such as the phase logic and the unit parameter definition.

The unit class also acts as a placeholder and template for a specific unit. As a result, when the procedure containing the class-based operation is scheduled, the operator is prompted to select a unit from the unit class specified for the operation or unit procedure. This allows the DeltaV system to bind a specific unit to the recipe and begin production.

Note:

Units are assigned to process cells which are, in turn, assigned to areas. Areas are assigned to a Batch Executive. The recipe is also assigned to a Batch Executive. In order for a class-based recipe to run using class-based equipment, all units required by the recipe must be assigned to the same Batch Executive (by way of process cell and area) as the recipe. The recipe will not run if all required units are not found on the same Batch Executive.
