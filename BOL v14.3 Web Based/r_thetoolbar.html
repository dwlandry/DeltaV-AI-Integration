The toolbar

The Batch Operator Interface toolbar is a group of icons used to navigate among the various Batch Operator Interface screens. To move from one window to another, simply click an icon on the toolbar. Tool tips are enabled on all icons, so you can easily identify the screen each icon opens. This information is also duplicated in the feedback/status line on the lower left-hand corner of all screens.

The following table describes the icons of the toolbar and their associated screens.
