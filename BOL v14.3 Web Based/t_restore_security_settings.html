Restore the security settings

Follow this procedure to restore security settings from a previously created backup.

The following procedure requires the MMC snap-in (Microsoft Management Console), and it only applies to workstations and servers in a domain environment. You must have privileges to write to the file system where you are storing the backed up settings.

Note: Re-running Workstation Configuration does not re-apply the default settings; therefore, you must restore the settings from an archive/backup to return to the DeltaV default installed settings.
  1. Go to Start > Run and type Group Policy Management Console. Press Enter.

    The application can also be launched by typing GPMC at the command prompt (CMD.exe) and then press Enter.

  2. In the Group Policy Management Console (GPMC) console tree, go to the forest and domain containing the Group Policy object (GPO) you want to restore and expand the GPO.
  3. Right click the GPO and select Import Settings.
  4. Follow the instructions in the Import Settings Wizard.
