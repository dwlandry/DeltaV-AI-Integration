Implementing a named set

Once named sets are configured, recipe formulators can implement them as follows:

  1. During recipe development, formulators can select from a named set to assign phase parameter values to a recipe.

  2. During batch execution, operators can select from a named set in response to an operator message.

The following figure illustrates how named sets can be configured and implemented in a sample paint application. In this example, the recipe author takes advantage of the flexibility built into the XFER_IN phase. The XFER_IN phase uses an Ingredient named set, which enables the recipe formulator to build one recipe that can produce several colors of paint. Named sets are used to select the appropriate color additive depending on the color of paint being made. For example, if the operator selects RED DYE as the ingredient, the DeltaV Batch system sends a value of 0 to the phase logic. This action instructs the controller to open the valve for the tank containing the RED DYE.
