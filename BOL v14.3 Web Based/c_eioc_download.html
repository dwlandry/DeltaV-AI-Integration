EIOC download options

There are several download options for EIOCs. Downloading the:

  • EIOC results in a total download of the card.
  • Individual modules results in a partial download of the selected modules.
  • Port results in a partial download of the port and all devices and signals configured under the port; only devices with configuration changes are affected by the port download.
  • Physical device results in a partial download of the device and all its logical devices and signals. For the Ethernet/IP Control Tag Integration protocol, control tags are included.

The following lists how a download affects a running process.

Port

A port download with any of the following changes results in communication to the device being reestablished (an interruption in communication occurs):
  • a changed port number
  • a changed IP address
  • a changed subnet mask

A port download with changed device configuration only affects those devices.

If none of the above changes were made, a port download has no affect on communications with the attached devices.

A change to the IP address results in communications being stopped and reestablished using the new IP address. This is similar to a total download.

Note:

A port number change (which is fixed on 61850) has a similar impact, as does changing the protocol.

A port download with changed device configuration only affects those devices.

If none of the above changes were made, a port download has no affect on communications with the attached devices.

A port download with any of the following changes results in communication to the device being reestablished (an interruption in communication occurs):
  • a changed IP address
  • a changed subnet mask
  • a change on a certificate
  • a change on issuers
  • a change on the revocation list

A port download with changed device configuration only affects those devices.

Physical device

A physical device download with logical device and/or signal changes causes the physical device to reestablish communications.

If no changes were made, a physical device download has no affect on communications with the attached devices.

A change to the IP address results in communications being stopped and reestablished using the new IP address. This is similar to a total download.

Note:

A port number change (which is fixed on 61850) has a similar impact, as does changing the protocol.

Additional changes and their affect are as follows:
  • Changing either a logical device and/or the signals underneath only affects those specific items. Device communications are not affected.
  • Any changes to the logical device affects all underlying signals.
  • Changes to individual signals will only affect that signal.

If none of the above changes were made, a physical device download has no affect on communications with the attached devices.

A port download with changed device configuration only affects those devices.

Note:

Critical function block parameters are preserved during a partial EIOC download for any function block supported in the EIOC that is also in the Critical function block parameters preserved during partial download table (refer to the Downloading data topic).
