GEMs (linked and unlinked) overview

When a GEM class is added to a display or another GEM, it becomes either a linked GEM or an unlinked GEM. A linked GEM remains linked to its GEM class, so that when the GEM class is modified and saved, its changes propagate to all instances linked to that GEM class. An unlinked GEM, on the other hand, does not remain linked to a GEM class. Therefore, once it is unlinked from its class, it no longer receives updates from it.

All linked and unlinked GEMs share a set of common configurable properties, which include the Information, Geometry, and Visibility property groups. Additionally, any custom properties that were configured in the GEM class's GEM Configuration Designer also appear in the GEM instance's Graphics Configuration pane.

Configuring linked and unlinked GEMs

You can configure a single instance of a linked GEM by modifying its properties in the Graphics Configuration pane. A linked GEM's configurable properties include the custom properties created on the GEM class. If you want to make a change to all GEMs linked to a GEM class, open the GEM class, make your changes there, and save the GEM class. The changes are propagated to all GEMs linked to that class. You can also add additional custom properties to the GEM class, and once saved, all GEMs linked to that class are updated with the new properties.
Note:

The Linked to property in the Graphics Configuration pane shows to which GEM class the instance is linked.

In the GEM Configuration Designer, if you modify the default values of custom properties already existing on the GEM class, the new default values appear only on new instances of the GEM class. They do not propagate to linked GEMs already on displays.

An unlinked GEM's configurable properties also include the custom properties created on the GEM class. However, because an unlinked GEM is no longer linked to its class, it has its own GEM Configuration Designer. You can use the Designer to further customize the unlinked GEM. Note, however, that you cannot configure or modify default values in an unlinked GEM's GEM Configuration Designer.

Converting GEMs

A linked GEM can be unlinked from its GEM class by either re-linking it to a different GEM class or converting it to an unlinked GEM. Re-linking it to another GEM class changes the configurable properties for that GEM instance because it is now linked to a different GEM class. A converted unlinked GEM retains all of the configurable properties it had as a linked GEM, but it no longer receives updates from a GEM class.

Likewise, an unlinked GEM can either be converted to a linked GEM by creating a new GEM class, or it can be relinked to an existing GEM class. In both cases, the converted linked GEM takes on the properties of the GEM class to which it is linked.

All GEM instances, linked and unlinked, can also be added to an unlinked GEM already on the display. The added GEM is nested under the GEM to which it is added, and the bounding box of the GEM to which it is added expands to include the added GEM.

All GEM instances, linked and unlinked, can also be converted to a group. When converted to a group, it is no longer a GEM; therefore, it takes on the properties of a group while losing the GEM Configuration Designer form and all of its custom properties.
