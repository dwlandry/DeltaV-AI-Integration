Add a display to a display set as a non-hierarchical display

This topic explains how to add a display to an existing display set as a non-hierarchical display.

  1. Open the display set to which you want to add displays.
  2. From the Graphics Explorer pane, drag and drop a display into the Non-hierarchical Displays pane.
  3. Repeat step 2 for each display you want to add as non-hierarchical.
  4. Click the Save button to save your changes.
    Note:
    • A display may belong to multiple display sets but may be included only once in a single display set.
    • If you want to include all displays that are not already in the hierarchy as non-hierarchical displays, select the Include All Displays check box.
