Conditions Meaning Mapping Impacts Integrity
Control Data Mismatch Between Cores The control subsystems have determined a mismatch in dynamic data other than outputs and secure parameter values. Advise Y
Modules Not Executing At Configured Scan Rate The logic solver has set the actual scan rate longer than the configured scan rate based on the estimate of execution time at download. Maintenance Y
