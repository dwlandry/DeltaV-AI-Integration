DLSYS object

The DLSYS object provides functions related to reading and writing DeltaV parameters that use the DeltaV Live parameter field path syntax, and that are accessible in or from this DeltaV system.
Restriction: The DLSYS object works only with parameters using the DeltaV Live parameter field path syntax. For graphics configurations that have been migrated from DeltaV Operate and contain parameters using the DeltaV Operate syntax, use the DVSYS object and its functions.
The following DLSYS object functions are supported in DeltaV Live graphics expressions and scripting. See the subtopics under DLSYS object for more details about each function.

DLSYS object functions

Function Description Syntax
Exists() Determines if the parameter (and field) can be resolved and read, and then returns a Boolean value. DLSYS.Exists(path string)
CondRead() Reads a parameter path and returns either the parameter value or a specified fallback value (if the path fails the Exists() test). DLSYS.CondRead(path string, fallback value)
GetBit() Extracts the value of the specified bit from the test value. DLSYS.GetBit(test value, bit number)
Read() Reads the specified DeltaV parameter path and immediately returns the status of the read attempt, and if successful, the requested value. DLSYS.Read(path string)
ReadAsync() Reads the specified DeltaV Operate-style parameter path and immediately returns the status of the read attempt. DLSYS.ReadAsync(path string)
