Configure BS-420 devices in DeltaV Explorer

In DeltaV Explorer, navigate to the Modbus ports of an LSNG. Select Modbus Port 1 and from the context menu, select Device. The Properties dialog for the device on the selected port opens. Configure both the General and Advanced tabs for both devices.

On the General tab

Configure the following:
Name
You can accept the default name or enter a name that is unique in the configuration.
Description
Enter information about the device, if desired.
Manufacturer
This read-only field contains Autronica.
Device Model
This read-only field contains BS-420/BC-420.
Comparison Partner
This read-only field contains the configured name of the device connected to the other Modbus port of this LSNG.

On the Advanced tab

Configure the following:
IP Address
IP address for the device
Note:

This IP address should be the same as that configured in the AS tool.

Ports
The device's TCP/IP ports that the left and right cards the LSNG redundant pair use. Use the default values.
Poll Period
This read-only field is set to 1 second. The Modbus poll period does not affect the Secure Parameter Publisher broadcast period on the LSN which is always 50 msec.
Timeout
This is a required field. If no response is received after this time elapses, the status is set to Bad. The recommended value is 500 msec.
System Status Register
It is recommended that you enter a value in this field. This field is the Modbus Address of the status register for the device. An address of zero means disabled (status defaults to Good).
Watchdog Register
This is a required field. The Modbus Address of the device's watchdog register. This register increments every poll period. If it does not, all data from the device is marked bad status.
Unit Status Block
This is a required field. The block of contiguous Modbus registers within the device that hold the detector data. The AutroSafe register start address must be 30011 or greater. There is a maximum of 382 registers due to the publisher limit of 766 Boolean values.
  • Modbus Registers Start - The first register for the block.
  • Modbus Registers End - The last register in the block.
  • Number of Registers Allocated - This read-only field contains the number of registers the block contains.
Device Commands
It is recommended that you use these fields. This area maps a 32-bit unsigned Secure Parameter in a CSLS on the LSN that can write Parameter 1 and the command word to the BS-420. Parameter 2 is not supported. Configure logic in DeltaV software to build these parameters. The Cmd and Param 1 fields are summarized below and described in more detail in the Autronica documentation.
  • Modbus Registers Cmd Word - The Modbus address of the register that holds the command word.
  • Modbus Registers Param 1 - The Modbus address of the register that holds Parameter 1.
  • Secure Parameter Reference - Browse to the Secure Parameter that contains the command word and Parameter 1.
Command Ready Secure Parameter
It is recommended that you use these fields. This parameter is a feedback to the command logic signals that the device is ready to accept another command.
  • Name - The configured name of the secure parameter.
  • Type - This read-only field is Boolean with status, the only type the supported by the device.

A value of 0 (zero) indicates that the device is ready for a command and a value of 1 (one) indicates that it is not ready.

Note:

These are Boolean with status parameters and count against the number of Booleans that are published by the LSNG. If these parameters are configured for both ports then only 766 signals can be published.

Now configure the device on Modbus Port 2.

Note:

Because the two devices are paired, only a few fields on the Modbus Port 2 device are configurable. Many of the fields in the second device (Port 2) must match exactly with the fields in the first device (Port 1) because the LSNG is comparing the data received between them. The Device Command data will be unique because the devices can be commanded separately (if necessary). Note that with interconnected devices, this is not always necessary.
