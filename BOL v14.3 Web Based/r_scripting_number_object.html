Number object

The following Number object values and functions are supported in DeltaV Live graphics expressions and scripting. See the subtopics under Number object for more details about each function.

Number object values

Value Description
.MAX_VALUE Returns he largest positive representable number.
.MIN_VALUE Returns the smallest positive representable number.

Number object functions

Function Description Syntax
Number() Converts a value to a number. Number(value)
toString() Returns a string representing the specified Number object. numObj.toString(radix?)
toFixed() Returns a string representing the given number and using fixed-point notation. numObj.toFixed(fractionDigits?)
toExponential() Returns a string representing the Number object in exponential notation. numObj.toExponential(fractionDigits?)
toPrecision() Returns a string representing a given number and written with a specified length. numObj.toPrecision(precision?)
