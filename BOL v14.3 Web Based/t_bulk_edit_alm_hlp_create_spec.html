Create alarm help format specification files

If the existing format specification files do not meet your needs, or if you have modules that contain alarms that are different from the alarms supported in Module_AlmHlp.fmt, you can create your own format specification files. The following is an example of how to create a format specification file for custom modules in a configuration. In this example, the configuration has a ModuleTemplates category named Local that contains two module templates, MODULE_1 and MODULE_2. 

MODULE_1 has alarms ALARM_1 and ALARM_2 defined. MODULE_2 has alarms ALARM_A and ALARM_B defined. You can create an alarm help format specification file for each module, but if you want to be able to bulk edit alarms for both types of modules in one text file you can create a format file that includes alarm information for both modules:

  1. Open the Format specification dialog (in DeltaV Explorer select File > Format Specification > New).
  2. Enter a meaningful name for the file and click Next.
  3. In the Object type field select Module.
  4. Click the Browse button next to the Subtype field and navigate to the Local ModuleTemplates folder. 
  5. Select one of the module templates and click OK.
    Note:

    You can also browse to a module created from the template.

  6. In the Field names area select the module_name field.

    Because you are editing only alarm-related information and are not creating new modules, this is the only field that is required to exist in the format file. You can add other fields if you want. 

  7. In the Field names area select the alarm parameters under Alarms.
  8. Click the Browse button next to the Subtype field and navigate to the Local ModuleTemplates folder.
  9. Select the other module template and click OK.
  10. In the Field names area select the alarm parameters under Alarms.
  11. Click Next.
  12. Click Next to accept the field order.
  13. Click Finish.

In DeltaV Explorer you can now navigate to an area that contains instances of these modules and export the alarm information for them.
