The DVBCMCampaignEdit/Info objects

The DVBCMCampaignEdit and DVBCMCampaignInfo objects are used to edit or read information about a specific campaign within the Campaign Manager's campaign list. These objects cannot be instantiated unto themselves. Instead, both must be retrieved using the appropriate DVBCMClient object method, either get_CampaignEdit or get_CampaignInfo.

The DVBCMCampaignEdit object encapsulates all data of a specific campaign on the Campaign Manager server. It has read and write capabilities and is used to configure, change, and manipulate the campaign and its properties. This object has a lock method, DVBCMCampaignEdit.LockEdit, so only one user at a time is able to edit the campaign's data. The object can be used to edit a campaign's prefix, suffix, description, or maximum active batches; to add batches; to retrieve a batch edit object or base recipe edit object; to view the campaign's batch list; to lock or unlock the campaign for edit; or to view the campaign's name, batch count, state, and so on. Only use the edit object when editing a campaign's data. To view a campaign's data, an info object should be used to save resources and avoid lockout problems.

The DVBCMCampaignInfo object encapsulates all data of a specific campaign on the Campaign Manager server. It has read-only capabilities and is used to view all properties of a campaign. The object does not have a lock method since it is read only. The object can be used to view a campaign's name, prefix, suffix, description, maximum active batches, batch count, or state; to retrieve a batch edit info or base recipe info object; or to view a campaign batch list. When only reading (not writing) a campaign's data, always use an info object rather than an edit object to save system resources and avoid lockout problems.
