IDVBCMClient::connect

Method Signatures

  

C\C++

HRESULT Connect(BSTR bstrCMNode, VARIANT_BOOL bStartEvents)

VB

Public Sub Connect(bstrCMNode As String, bStartEventsAs Boolean)

This method must be called before any of the other methods on this interface can succeed. It actually connects the control to the specified Campaign Manager Server.

Return Values

S_OK - SUCCESS

else - failed

Memory Allocation

none

Parameter Name

Purpose

bstrCMNode

Computer node name of the Campaign Manager server. The string passed in must be a valid computer node (as defined by the domain's DNS) that also must have a Campaign Manager server installed and running.

bStartEvents

Optional. Used to tell the server if application wants to receive events. If the application is one time read only a value of false may be passed in to save resources.
