Bulk editing redundant wireless (WIOC)

This section outlines how to bulk edit DeltaV Redundant Wireless objects.

One general procedure to bulk edit redundant wireless objects (both wireless I/O cards and WirelessHART devices combined) is:

  1. Create a wireless I/O card (WIOC). 

  2. Configure at least one of each type of WirelessHART device you want to bulk edit. 

  3. Use the WIOC_IO.fmt format specification file to export the WIOC or create your own format specification file. 

    The export file contains one line for each of the devices in the WIOC.

  4. Edit the file in the bulk edit Excel add-in. 

  5. Import the file. 

You can also bulk edit wireless I/O cards and WirelessHART devices separately.
