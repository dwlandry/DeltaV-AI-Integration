DeltaV Smart Switches overview

DeltaV Smart Switches are used to construct DeltaV Control Networks according to the IEEE 802.3 Local and Metropolitan Area Networks standards.

The DeltaV Smart switches are

  • DeltaV MD base Smart Switches and media modules
  • DeltaV RM100 base Smart Switches and media modules
  • DeltaV RM104 Smart Switches
  • DeltaV RM1040 Smart Switches
  • DeltaV FP20 8-port Smart Switches

DeltaV Smart Switches are intended for plug-and-play use with a DeltaV system as unmanaged switches. No configuration is necessary unless you want to use the Network Device Command Center (NDCC) to manage the switches (commission and decommission, lock switches and ports, and so on). If you do not use the NDCC, or you need to perform some initial switch setup such as configuring an IP address before the NDCC is available, you can use the switch’s command line interface by connecting a terminal or a Management station running a terminal emulator to the switch's serial port. A serial interface cable is required to connect the switch’s serial port to the Management station. The serial interface cable can be purchased separately from Emerson Automation Solutions or you can build the cable assembly. Once the switch has an IP address you can access it from a Telnet session or monitor it from the web browser interface. Note, however, that after configuring an IP address using the switch's command line interface instead of the NDCC, you must then decommission the smart switch before it is available for configuration using the NDCC.

Refer to the topics on DeltaV Smart Switches in Books Online for information on the Network Device Command Center, for information on configuring, monitoring, and accessing the switches with Telnet, and for information on downloading Java software.

Before installing and using DeltaV Smart Switches and media modules, read all safety instructions for DeltaV Smart Switches and media modules.
