Interacting with graphics elements online

Interactions are a collection of actions that define how DeltaV Live users can interact with graphics on running displays. Graphics Studio provides the means to customize these interactions through an Interactions tab in the Graphics Configuration pane. Actions can be configured for the typical user entry controls, such as buttons and check boxes, as well as for other elements like data links and images. Each action defines the relationship between a specific mouse-pointer event, such as a primary click or double-click, and a corresponding behavior that is triggered by that mouse-pointer event online. You can configure mouse pointer events to trigger various online behaviors, including writing a value to a specified destination; opening displays and contextual displays; opening primary control displays, faceplates, and detail displays; launching applications; viewing tooltips; selecting tags; or running a custom script.

You can configure multiple actions for an element as well as multiple actions for the same type of mouse pointer event. For example, you can configure a button to open a faceplate and run a custom script when double-clicked. Mouse pointer events can be designated as clicks, double-clicks, secondary-clicks, or hovers.

Interaction areas

When at least one action is configured for an element and its Active property is True, an interaction area is active online. The interaction area defines the mouse pointer hotspot for an element. When you point your mouse inside the interaction area, it is indicated by a black border. If you have a configured action that for some reason you do not want active, set its Active property to False. Setting Active to False disables and hides the interaction area.
Note: If the Visibility property on a graphics element is False, the Interaction Area is disabled in DeltaV Live online.

The above rules apply for interaction areas on groups or GEMs when at least one action is configured for at least one element in the group or GEM. In Graphics Studio, the interaction area for a group or GEM is the bounding rectangle that encompasses all elements in the group or GEM and that are configured to be present online. Online, the interaction area automatically re-sizes based on the current size and position of all elements in the group or GEM. When actions are configured for individual elements in a group or GEM, the group or GEM's interaction area is lower, by default, in the z-order than that of its individual elements' interaction areas.

Sometimes elements may overlap on a display, creating multiple interaction areas at the position where a mouse-event occurs. If the same mouse-event is configured for interaction areas that overlap, the top-most element in the z-order performs its behavior. To prevent confusing behavior, consider moving one or more elements to a different position.
