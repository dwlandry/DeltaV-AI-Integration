Set up OSIsoft PI Server with a new DeltaV system

To install and set up OSIsoft PI Server with a new DeltaV system, complete the following steps:

  1. Install DeltaV and set up an Application Station.
    Important:

    When the Select Historian dialog appears, select the Enterprise Historian option.

  2. If you plan to run PI Server on the Application Station in the DeltaV Area Control Network (ACN), complete step t_setup_enterprise_pi_server_new_deltav_system.html#task_51B674B970AF4F56901608D74F08397E_unique_53__substep_ADBBD4809A6D4731943AF51851B2E2C6 below. If you plan to run PI Server on a remote Application Station or a non-DeltaV workstation outside the DeltaV ACN, complete step t_setup_enterprise_pi_server_new_deltav_system.html#task_51B674B970AF4F56901608D74F08397E_unique_53__substep_B3E21B98D3D646DBBE35B983F6D84681 below.
    1. Install and configure PI Server and the PI Asset Framework (PI AF) Server on the Application Station in the DeltaV ACN according to the documentation provided by OSIsoft.
    2. Install and configure PI Server and the PI AF Server on the remote Application Station or a non-DeltaV workstation outside the DeltaV ACN according to the documentation provided by OSIsoft. Alternatively, you can use existing PI Server and the PI AF Server software that meets all version requirements.
  3. Install the DeltaV Smart Connector on the Application Station in the DeltaV ACN according to the documentation provided by OSIsoft.
  4. Enable PI Server in DeltaV Explorer by right-clicking the Continuous Historian subsystem under the Application Station where you installed the DeltaV Smart Connector, and then selecting Properties. On the General tab, select the Enabled check box, and then select the Use Enterprise Historian option.



    Important:

    You will not be able to successfully download the workstation unless you selected the Enterprise Historian option in the Select Historian dialog, as instructed in t_setup_enterprise_pi_server_new_deltav_system.html#task_51B674B970AF4F56901608D74F08397E_unique_53__step_980B47629C8F486D8CBC8D5532223503_unique_43.

  5. Download the Physical Network containing the Application Station where you installed the DeltaV Smart Connector.
Note:

To configure the parameters on the Advanced tab of the Continuous Historian Properties dialog, use the PI System Management Tools (PI SMT).
