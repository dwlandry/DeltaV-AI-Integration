SIS module and function block custom faceplates

The procedure for creating custom faceplates for SIS modules is similar to that for creating custom faceplates for DeltaV modules. To open the SIS module faceplate template, double-click SIS_Faceplate template in the Templates folder. SIS module faceplates are opened in run mode using the alarm banner or the Open Faceplate toolbar button.

The SIS_ faceplate template consists of an empty main display area, a "close picture" button, a pushpin button, the SIS module tag and description, and command buttons. The pushpin button appears when multiple faceplate capability has been enabled in UserSettings.grf. When multiple monitor capability has been enabled, a display selector appears to the right of the pushpin. The command buttons from left to right include "open detail display," "open control display," "open CSOnline," "open PHV," and "Ack All Alarms."

The procedure for creating custom faceplates for SIS function blocks is similar to that for creating custom faceplates for DeltaV function blocks. for more information. For SIS function blocks, use the Any_SIS_Block dynamo in the dynamo set named frsSIS on the display. To open the SIS module faceplate template, double-click SIS_FaceplateFB template in the Templates folder.

The SIS_FaceplateFB template consists of an empty main display area, a "close picture" button, a pushpin button, an "open module faceplate" button, and the function block path. The pushpin button appears when multiple faceplate capability has been enabled in UserSettings.grf. When multiple monitor capability has been enabled, a display selector appears to the right of the pushpin.

Note: Any writeable datalinks on the custom faceplates must be added using the SIS Data Entry Expert.
