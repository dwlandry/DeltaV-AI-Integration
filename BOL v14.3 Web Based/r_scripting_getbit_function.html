GetBit function

GetBit() extracts the value of the specified bit from the numeric value.
Arguments
2
Argument Description
test value A numeric value that holds bit-encoded information.
bit number

A number identifying the bit to be extracted from the <test value>.

The <bit number> is rounded to an integer from 0 to 31, with 0 representing the least significant bit of the <test value>.

Return values (Boolean)
0 or 1, the specified bit of the <test value>.
The return value is equivalent to the JavaScript shift and bit mask operators, (test value >>> bit number) & 1.
Syntax
DLSYS.GetBit(test value, bit number)
Examples
Example Result 
DLSYS.GetBit(DLSYS["FIC101/PID1/BAD_ACTIVE.CV"],7)
 Bit 7 of FIC101/PID1/BAD_ACTIVE.CV

(DLSYS["MOD1/PID1/IO_OPTS.CV"],0),5)
