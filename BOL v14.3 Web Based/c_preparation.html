Preparation for manually commissioning the Smart Switch

In DeltaV Explorer:

  • Configure the Smart Switch module classes SWITCH_STDCFG_$X (for switches on the primary network) and SWITCH_SECCFG_$X (for switches on the secondary network) as required for your installation.
  • Configure other parameters as required in both module classes.

Create a spreadsheet or other document that relates switch name, switch IP address, MAC address, and optionally location or other descriptive information about each of the switches you are going to commission.

Note:

Smart Switch names must end in _$X and can contain only A through Z, 0 through 9, $, -, and _.

Refer to DeltaV S-series and CHARMs Hardware Reference for the allowable IP addresses you can assign to switches. Decide on your addressing strategy. You may want to create a spreadsheet or other document that relates the IP address to the name you will give the switch module and the switch description for each switch in your system.

Note:

If you commission switches from Network Device Command Center (NDCC), it assigns IP addresses from the ranges 10.x.129.x. Do not use addresses in these ranges if you are manually commissioning switches.
