Analog Voter (AVTR) function block

The AVTR function block provides an analog voter function. A voter block monitors a number of input values and determines if there are enough votes to trip. The AVTR block monitors as many as 16 analog inputs. If a configured number of the inputs vote to trip, the block trips and sets the output of the block to 0 (zero).

For example, a process shutdown might be required if a tank exceeds a certain temperature. Three temperature sensors are installed in the tank and an analog voter block is configured to monitor the sensors and trip if two of the three transmitters detect a high temperature.

The AVTR block does not support modes.

The normal operating value of the output is 1 (On) and the tripped value is 0 (Off).
