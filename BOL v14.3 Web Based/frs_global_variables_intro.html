FRS global variables

Much of the DeltaV environment is defined by the FRS global variables (under Globals > frsVariables in the system tree). You can customize aspects of the operating environment for your operators through a UserSettings picture and DeltaVPicture.Template file which are read at startup. The global variables that are typically customized are already included in a picture file called User_Ref (under Pictures > Standard in the system tree) which can be modified and saved as UserSettings. Additional customization can be done by referencing other global variables (from frsVariables) in the UserSettings picture file and changing their default initial values. 

For more information on customizing DeltaV Operate, refer to Customizing the DeltaV Environment.

The following topics list the global definition files. The global variables have been grouped logically and placed in separate files for easier access. All that is used of the files is the "Commands on Opening" script, which is used to declare and initialize some global variables. Startup.glb defines variables for window positioning and size and then opens the next global definition file, Apps.glb. Startup.glb remains open until the initialization sequence is completed.

To replace the following variables' default values with your own, you must use the frsSetPictureCoordinates function in your UserSettings file's VBA script or in any other script that uses the following frsVariables.

Note:

The maximum x/y coordinates are based on the screen resolution (for example,1024×768) and must be contained within those limits. The starting point for x and y is the top left of the picture you are positioning (for example the faceplate). You must test this position to be sure the picture you are opening and positioning can be opened entirely on your screen.
