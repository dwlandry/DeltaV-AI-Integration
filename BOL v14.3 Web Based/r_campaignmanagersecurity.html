Campaign Manager security

Campaign Manager security is part of the overall DeltaV security scheme. Access to individual Campaign Manager operations, such as adding or modifying a campaign, is restricted to those users who have been granted an access key individually or who belong to a group that has been granted a key. In addition, user-defined locks can be created, and campaign operations can be assigned to the new locks. By default, all Campaign Manager operations are associated with the Batch Operate lock.

All Campaign Manager operations are site wide, requiring <Sitewide> be assigned to the Batch Operate lock in DeltaV User Manager when granting keys to your users and user groups. However, the specific Batch functions (such as adding a batch) still require the appropriate key granted to the correct areas. All campaign functions are in the Batch Operate lock, along with other batch functions. In order to assign <Sitewide> for some functions and a specific area for others, you will need to reassign functions to new locks (user locks). That way you can assign <Sitewide> for the campaign and most of the batch operational functions and still assign a specific area for others (Batch_Add for example).

Note:

For more information about locks and keys, refer to the User Manager application online help. For more information about configuring locks and operation level security, refer to the topic.

Campaign Manager Security by Function

Function Name

Controls whether the current DeltaV user (on this node) can:

CAMPAIGN_ADD

add a campaign to the Campaign Manager's list

CAMPAIGN_CONTROL_START

start the Campaign Manager service

CAMPAIGN_CONTROL_STOP

stop the Campaign Manager service

CAMPAIGN_MODIFY

modify a campaign

CAMPAIGN_MODIFY_BATCH

modify a batch in a campaign

CAMPAIGN_OI_START

start the Campaign Manager Operator Interface

CAMPAIGN_OI_STOP

stop the Campaign Manager Operator Interface

CAMPAIGN_REMOVE

remove a completed campaign from the Campaign Manager's list

CAMPAIGN_UNLOCK

unlock a campaign and all batches associated with that campaign
