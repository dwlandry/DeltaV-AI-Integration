Modifying the Hosts file

The Hosts file can be modified when an application needs to use a computer name rather than the network address to access the computer. The Hosts files is easy to modify as the file is a text file that you can edit in Notepad. Because your Hosts file is a system file, you must run Notepad as an administrator when you edit it. To run Notepad as an administrator, find Notepad in your start menu, right click it, and select Run as administrator.

Not all versions of Windows store the Hosts file in the same location. It is usually located in c:\windows\system32\drivers\etc\hosts. You can search the hard drive for the filename.

We recommend that you make a backup of the Hosts file before modifying it.

An open Hosts file in Notepad should look similar to the following: 

# Copyright (c) 1993-2009 Microsoft Corp.
#
# This is a sample HOSTS file used by Microsoft TCP/IP for Windows.
#
# This file contains the mappings of IP addresses to host names. Each
# entry should be kept on an individual line. The IP address should
# be placed in the first column followed by the corresponding host name.
# The IP address and the host name should be separated by at least one
# space.
#
# Additionally, comments (such as these) may be inserted on individual
# lines or following the machine name denoted by a '#' symbol.
#
# For example:
#
#      102.54.94.97     rhino.acme.com          # source server
#       38.25.63.10     x.acme.com              # x client host

# localhost name resolution is handled within DNS itself.
#	127.0.0.1       localhost
#	::1             localhost
