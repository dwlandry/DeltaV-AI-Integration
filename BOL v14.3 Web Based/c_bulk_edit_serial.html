Bulk editing serial ports and datasets

This section outlines how to bulk edit serial ports and datasets. 

The general procedure to bulk edit serial objects is:

  1. Create a serial card.

  2. Configure the card's ports.

  3. Under the ports, create a serial device.

  4. Create and configure serial datasets under the device as required.

  5. For each level (serial port and dataset) use the sample format specification files or create your own and export data from the existing configuration.

    Use the Format Specification file Must Exist dialog to prevent existing card configurations from being overwritten in the database.

  6. Edit the ports in the bulk edit Excel add-in.

  7. Edit the datasets in the bulk edit Excel add-in.

  8. Import the ports.

  9. Import the datasets.
