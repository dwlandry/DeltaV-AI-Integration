Redundant H1 4-port Plus Terminal Block specifications

Installation notes

  • This terminal block is used to terminate wiring for a redundant pair of S-series H1 4-port Plus cards. Set the terminal block key to D2 before installing the card.

Specifications

Redundant H1 4-port Plus Terminal Block specifications

Item

Specification

Voltage rating

35 VDC

Maximum current

500 mA maximum

Mounting

Assigned slots on the I/O carrier. The lower slot number must be odd and the upper slot number must be the next higher even number. For example, slots 1 and 2, slots 3 and 4, and slots 5 and 6 are valid pairs. Slots 2 and 3 are not a valid pair.
