Bulk editing expressions

When exporting, editing, and importing configuration data that contain expressions (in Calc blocks, for example) there are a couple of things to be aware of. After you open a file that contains expressions, check the expression cells. If the cells contain a string of pound signs (#), the length of the exported expression exceeds Excel limits; otherwise, expressions are visible in cells.

Before you copy and paste, for each column that contains a cell full of pound signs, do the following:

  1. Select the column in which the cell is located.

  2. Right-click and select Format Cells.

  3. In the Number tab, select Number in the Category list.

  4. Set Decimal places to 0.

  5. Click OK. 

    The expression is now visible in the cell. 

Now you can copy the row, paste it as many times as desired, and edit the copies as required. 

Note:

If you do not make the expressions visible before you copy and paste, pound signs (#) are pasted into the copied cells.

Every time you open a file that contains expressions that exceed Excel limits, the expressions appear as a string of pound signs (#).

On export, Bulk Edit replaces tabs with <tab> and carriage returns with <CR>. It can be confusing to edit these expressions in Excel and keep the formatting as intended. It is much easier to edit expressions after importing because the formatting is restored. If you do edit expressions in Excel, note that the case of <tab> and <CR> must be as shown. Also note that Bulk Edit does not support the use of ALT+ENTER to create carriage returns. You must use <CR> to create carriage returns in Excel.

However, if you edit an expression in Bulk Edit and the resulting expression exceeds Excel limits, the cell is populated with pound signs (#) when you move off the cell. Before you save the file you must follow the steps above to make sure the expression is visible. If you do not, the expression does not import properly and errors result.
