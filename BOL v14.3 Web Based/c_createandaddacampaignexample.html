Creating and adding a campaign example

This section describes how to connect a client application to a Campaign Manager server and how to create a new campaign with batches. The following items are covered in this example:

  • How to get a new campaign and set all of its properties, including its recipe object properties.

  • How and when to add batches and their properties.

  • How to add the campaign to the Campaign Manager server.

  • How to set the campaign's execution mode.

  • What order the events should follow.

  • What errors might be encountered.

Note:

The use of the Campaign Manager control and the following examples is not intended as a replacement for the Campaign Manager Operator Interface. There are features of the Campaign Manager that are not included in these examples.
