Create a DeltaV workstation in an Independent DeltaV Domain Controller environment

This procedure highlights the steps required when creating a DeltaV workstation in an Independent DeltaV Domain Controller environment.

When the domain controller is an Independent DeltaV Domain Controller you must select the Independent DeltaV Domain Controller during Workstation Configuration. This will join the workstation to the existing domain. This means the Independent DeltaV Domain Controller must be configured and the domain created before you can join any DeltaV node to the domain.

The first workstation you usually install is the ProfessionalPLUS. All other DeltaV workstations require that the DevData.cfg file be exported from the ProfessionalPLUS database. However, multiple DeltaV workstation installations can occur concurrently. You will simply pause at the Workstation Configuration step until the DevData.cfg file is available.

Because the ProfessionalPLUS is the first workstation to complete the process, it is used as the example DeltaV node here.

Tip:
  • When installing DeltaV, you must be logged in as (at the least) a local administrator (even in a domain environment). However, if you want to use the domain administrator credentials, you can, if (and only if) the computer is already a domain member.
  • If the computer was not joined to the domain prior to running Workstation Configuration, you are only able to log in as a local administrator. Workstation Configuration prompts you for domain administrator credentials at the point it needs to join the computer to the domain.
  • The user who ran the Independent DeltaV Domain Controller setup application is added to the domain DeltaV Admins group. When running Workstation Configuration, at the time you are logging into the domain for the first time (after it has joined to the domain and a reboot has occurred), log in using the same user that created the IDDC (the first domain DeltaV Admins group member).
  1. Insert the DeltaV installation media into the drive on the ProfessionalPLUS computer.
  2. Select the DeltaV workstation type to install.
    • ProfessionalPLUS
    • ProfessionalPLUS as Remote Client Server
  3. When Workstation Configuration runs at the end of the installation, select Domain: Independent DeltaV Domain Controller.
  4. Enter or select (if the list is available) the root domain name from the FQDN you entered when creating the Independent DeltaV Domain Controller. The root domain name format adheres to Domainname.xxx; where xxx is either com, or org or another valid domain name extension. You can verify the computer has been added to the domain by going to the domain controller and running Active Directory Users and Computers. The computer's name will be listed under DeltaV Workstations.
  5. After installation and Workstation Configuration completes, download the ProfessionalPLUS.

Once the ProfessionalPLUS is created and downloaded, configure the remaining DeltaV nodes in the database, create the DevData.cfg file and use that file to finish the installation of the other workstations.
