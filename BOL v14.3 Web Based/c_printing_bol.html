Printing Books Online topics

Note:

Terms that have been highlighted due to a search may not print as expected. To remove highlighting from a single topic, right-click Refresh.

To print a single section, a section and all of its subsections, or an entire book from the Contents tab:
  1. Select the book, topic, or sub-topic that you want to print.
  2. Click Print.
  3. To print the current topic, select Print the selected topic. Select Print the selected topic and all sub-topics to print the current topic and all topics contained by it.

    The Print dialog opens.

  4. Select the printer and printer options.
  5. Click Print on the Print dialog.
To print a topic from the Search or Index tab:
  1. Select the topic or sub-topic from the list.
  2. Click Print.

    The Print dialog opens.

  3. Select the printer and printer options.
  4. Click Print on the Print dialog.
Tip:

Topics with large figures print better if you set the printable area to its maximum size. Open Internet Explorer, and then click File > Page Setup to open the Page Setup dialog. In the Margins box, specify 0 inches for Left, Right, Top, and Bottom. Internet Explorer then substitutes the minimum allowable margin for each setting.
