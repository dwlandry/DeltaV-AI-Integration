Configuring Modbus TCP devices and signals

The port defines the protocol that is used in the device network. Physical devices, their logical devices, and device signals are configured under the port. Refer to the device documentation and the context sensitive help for all EIOC dialogs in DeltaV Explorer for configuration information.

Modbus physical device configuration consists of specifying the physical device's primary and secondary IP addresses.

Modbus logical devices are groups of functions for the physical device. Logical device configuration involves defining the characteristics of the device data represented by the logical device. Among the items configured in the logical device is the Number of values which defines how many contiguous registers are accessed in this logical device's data grouping. Refer to the device documentation for the specific values to use to configure the device.

The device signals are used to access the device data. The proper number of signals is automatically created under the logical device when it is initially saved based on the "Number of values" that is specified for the logical device. The signals are automatically populated with the appropriate configuration information included in the logical device.
