Pulse monitor detail display (PI_DT)

DeltaV Operate View of the Pulse Monitor Detail Display (PI_DT)

The Pulse Monitor detail display provides you with access to frequently modified parameters for a Pulse Monitor module as well as status and diagnostics information.
