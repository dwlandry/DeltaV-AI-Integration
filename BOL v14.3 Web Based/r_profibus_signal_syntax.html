Valid Field Values for Profibus Signals

Field

Valid Values

Required for Import

description

As many as 255 characters using any keyboard characters

No

node_name

Any valid node name.

Yes

card_slot

1 through 8

Yes

profibus_dev_tag

As many as 16 characters. This string must contain one alphabetical character and can include the following: $, -, _

Yes

profibus_dev_manufacturer

Manufacturer of this Profibus device

Yes

profibus_dev_model

Model of this Profibus device

Yes

profibus_dev_revision

Revision level of this Profibus device

Yes

profibus_dev_addr

The address of the Profibus device

Yes

profibus_slot_module_num

The Profibus module number

Yes

profibus_slot_definition

The definition of the module installed in this slot

Yes

profibus_sig_name

Any name that is valid for Profibus signals

Yes

profibus_sig_tag

The device signal tag associated with this signal

No

profibus_sig_use_diag_chan

Number of the channel to use for diagnostics

No

profibus_sig_diag_channel

Valid channel number

No

profibus_sig_stand_net_byte_order

T = Big Endian

F = Little Endian

No

profibus_sig_dir

input or output

Yes

profibus_sig_byte_offset

The byte location of the start of signal information

No

profibus_sig_data_type

The type of data this Profibus signal represents

Yes

profibus_sig_use_scaling

T or F

No

profibus_sig_low_scale_value

The signal value for 0% of scale

No

profibus_sig_high_scale_value

The signal value for 100% of scale

No

profibus_sig_start_bit

The first bit to read data from

No

profibus_sig_num_bits

The number of bits in the data word

No
