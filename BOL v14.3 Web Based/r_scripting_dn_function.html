DN function

DN() evaluates and returns the argument as a string. When the argument is a literal string, the DN() authorizes display rename tracking to automatically update the string argument to match the new name. If the argument is anything other than a single literal string, it does not participate in display rename tracking.
Arguments
1
Argument Description
DisplayName A literal or graphics expression that resolves to the name of a display or contextual display.
Return values (string)
The name of a display or contextual display.
Syntax
DL.DN(display name)
Examples
Example Result 
DL.DN("Reactor1")
 Shows the string, Reactor1. 
DL.OpenContextDisplay(DL.DN("Loop_fp"), "FIC-101")
 Opens the contextual display with the name Loop_fp, and with FIC-101 as the module name on the faceplate.
