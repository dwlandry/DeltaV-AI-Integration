DeltaV picture toolbars

The DeltaV picture toolbars are available when a picture is open in configure mode. To choose whether or not to display a toolbar, click WorkSpace > Toolbars, then select Picture as the owner, and select the check boxes for the toolbars you wish to display. The available picture toolbars are:

  • DeltaV Shapes

  • DeltaV Picture

  • DeltaV Text

  • DeltaV Toolbox

  • DeltaV Operating Experts

  • DeltaV Animation Experts

  • DeltaV Tools

  • DeltaV Advanced

  • DeltaV Batch Controls

  • Tools

For more information on the DeltaV Operating Experts, refer to DeltaV Operate Experts.

DeltaV Toolbox

By default, many of the most often used toolbar buttons appear in a Toolbox, so that you can quickly select the buttons you want from one place. You can let the Toolbox float on top of your picture, or you can dock it on any of the edges. To move it, drag it by its title bar. To resize it, click and drag one of its sides.  As with any toolbar, you can customize it by removing buttons you don't use, adding buttons you use often, and rearranging the button locations to suit your preferences. Refer to Modifying Existing Toolbars for information.

DeltaV Tools

Use the DeltaV Tools toolbar buttons to add and format data links, build a dynamo set, and to manipulate objects.

Click...

To...

Datalink Stamper

Add a data link to a picture.

Variable

Create a variable for the current picture or create a global variable.

Bring to Front

Displays a list of open applications and lets you choose one to move to the front of the display stack. Similar to pressing the Alt and Tab keys in the Windows operating system.

Note  If the application that is brought to the front covers the DeltaV Operate alarm banner, the operator will not be able to see a new alarm. The alarm horn sound will still be heard. The operator should not maximize any other application such that it covers the entire DeltaV Operate picture.

DeltaV Batch Controls

Use any of the DeltaV Batch Control buttons to insert that control into the picture. These are ActiveX controls that can be customized using the configuration dialog. After inserting the ActiveX object, select it, right-click, and select Properties from the context menu. Click Help on the dialog box for additional information.

Click...

To...

Batch List

Adds the DeltaV Batch List control to the picture. This view is used to add and control batches.

Batch Commands toolbar

Adds the Batch Commands toolbar to a picture. This control should be linked with either the Batch List control or the Batch Operator Comments control for optimum use.

Batch List Control Linker

Links or unlinks the selected Batch List objects on a picture. Use to link/unlink the Batch List, Batch Commands toolbar, Batch Comment objects.

Batch Prompts List

Adds the DeltaV Batch Prompts List control to the picture. This view is used to view and acknowledge batch runtime prompts.

Batch Operator Comments

Adds the DeltaV Batch Operator Comments control to the picture. This control is used to add operator comments to a batch.

Batch Hierarchy and Phase Control

Adds the Batch Hierarchy object to a picture. This control is used to view phases within the batch hierarchy.

Batch Manual Phase toolbar

Adds the Manual Phase toolbar object to a picture. This control should be linked to the Batch Hierarchy and Phase Control object to allow the operator to manually control phases.

Batch Step List

Adds the Batch Step List object to a picture. This control should be linked to the Batch PFC Command toolbar object and also the Batch PFC object. Without the Batch PFC Command toolbar, you cannot execute Active Step Changes.

Batch PFC

Adds the Batch PFC object to a picture. This control should be linked to the Batch PFC Command toolbar object or the Batch Step List object (or both). Without the Batch PFC Command toolbar, you cannot execute Active Step Changes.

Batch PFC Command toolbar

Adds the Batch PFC Command toolbar to a picture. This control must be linked to either the Batch PFC object or the Batch Step List object (or both).

Batch PFC Control Linker

Links or unlinks the selected Batch PFC objects on a picture. Use to link/unlink the Batch Step List, Batch PFC and Batch PFC Command toolbar objects.

Batch Manual Phase Control Linker

Links or unlinks the selected Batch Phase objects on a picture. Use to link/unlink the Batch Hierarchy and Manual Phase toolbar.

Batch Active Phase Insertion Wizard

Adds the Batch Hierarchy and Phase Control object to a picture with the Active Phase view as the default view. This control is used to view active phases within the batch hierarchy.

Batch Alarm Summary Insertion Wizard

Adds the Batch Hierarchy and Phase Control object to a picture with the Phase Alarm Summary view as the default view. This control is used to view phases in alarm within the batch hierarchy.

Batch Event Journal Control

Adds the Batch Event Journal object to a picture. This control is used to view batch events in a tabular format.

Batch Arbitration Control

Adds the Batch Arbitration object to a picture. This control is used to arbitrate equipment in a batch process.
