Ethernet Isolation Ports specifications

Installation notes

  • The Dual Universal Safety Carrier and SZ Controller Carrier house a primary and secondary Ethernet Isolation Port (EIP).
  • When the Dual Universal Safety Carrier holds a Local Safety Network Bridge, each EIP consists of a Global Safety Network Port for connections to the Global Safety Network and a Safety Network port for connections to the Local Safety Network.
  • When the Dual Universal Safety Carrier holds an SZ Controller, each EIP consists of an Area Control Network port for connections to the DeltaV Area Control Network and a Safety Network Port for connections to the Local Safety Network.
  • When the Dual Universal Safety Carrier holds an SZ Controller for standalone safety applications, each EIP consists of a Modbus TCP port and a Safety Network Port for connections to the Local Safety Network.
  • The EIPs are removable. To remove an EIP, depress the button next to the EIP and push it out of the carrier.
