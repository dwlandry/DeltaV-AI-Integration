Abort logic

The abort logic is the logic that is used to get the process to a safe state when an Abort command is received The state changes to ABORTING and whatever logic was running is stopped and the abort logic is executed. When the abort logic completes, the state changes to ABORTED and remains ABORTED until a Reset command is received.

Note:

There is no way to return to the RUNNING state from ABORTED.
