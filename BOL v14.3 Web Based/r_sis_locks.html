SIS locks

The initial locks that are assigned to SIS parameters, fields, and functions are listed in the following table, along with a description of each lock's function when it is used as initially assigned. (These lock assignments can be changed in the DeltaV Explorer using the Modify button on the Properties dialogs for SIS Parameter Security, SIS Field Security, or SIS Function Security.) The keys to these locks are assigned to users and user groups in the DeltaV User Manager application.

Initial Assignment of SIS Locks

Lock

Initial Assignment

SIS Alarms

Controls who can acknowledge SIS alarms and perform SIS control functions. By default, the SIS Alarms lock affects access to the MACK, NALM, and SUPTMR fields.

SIS Can Calibrate

Controls who can use AMS Device Manager device configuration and calibration features. (Grants the AMS SIS Write key.)

SIS Can Configure

Controls who can perform any SIS configuration functions, such as create and assign Logic Solvers, configure Logic Solver channels; configure SIS named sets and alarm types; and create, import, modify, and assign SIS modules and templates. (Also grants the AMS SIS Write key.)

Decommissioning Logic Solvers requires both the SIS Can Download and the SIS Can Configure keys.

SIS Can Download

Controls who can lock and unlock Logic Solvers and download and commission Logic Solvers. No downloads are allowed with this key from the Physical Network. (Also grants the AMS SIS Write key.)

Decommissioning Logic Solvers requires both the SIS Can Download and the SIS Can Configure keys.

SIS Control

Controls who can perform SIS control functions. 

SIS Diagnostic

Controls who can access SIS diagnostic information maintained by the system, such as parameters that reset instance counts or perform Logic Solver switchovers.

SIS No Access

For new parameter security, this default lock is initially assigned to new SIS parameters that do not have a lock explicitly assigned to them. This lock does not have an associated key that can be assigned in User Manager.  

SIS Restricted Control

Controls who can write to SIS parameters to configure the process. Typically used by supervisors and engineers; operators usually do not write to these parameters. 

SIS User Locks 01 through 10

These user-defined locks provide flexibility to your security scheme.

SIS Version Control

Controls who can write to SIS parameters that concern Version Control.
