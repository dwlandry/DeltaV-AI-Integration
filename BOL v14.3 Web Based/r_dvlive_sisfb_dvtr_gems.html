DVTR GEM classes

The SIS Function Block GEM class set contains four dynamos for the LSDVTR function block. For the common voting arrangements (1oo2, 2oo3, 1oo1, 2oo2, and 1oo3), use an LSDVTR block with one, two, or three input parameters, as shown in the following table:
Voting arrangement Use this GEM
1oo1 voter DVTR_1Input_
1oo2 or 2oo2 voter DVTR_2Input_
1oo3 or 2oo3 voter DVTR_3Input_

The one- and two-input DVTR GEMs are similar but have one or two fewer rows than the three-input GEM. When you add an DVTR GEM to a display, the faceplate name defaults to SIS_DVTR_fp. If you prefer to use a custom faceplate rather than the default faceplate, enter the faceplate name in the Faceplate Name field.

The DVTR_InputX is an input-only GEM that can be added to the DVTR_3Input_ GEM for voting arrangements having more than three inputs. For example, for a 6oo8 voter, add the DVTR_3Input_ to a display; then add five instances of the DVTR_InputX_ to the DVTR_3Input_, positioning each beneath the existing input lines, for a total of eight inputs.
