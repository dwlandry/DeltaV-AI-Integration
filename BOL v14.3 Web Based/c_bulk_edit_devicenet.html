Bulk editing DeviceNet ports, devices, and signals

This section outlines how to bulk edit DeviceNet ports, devices, and signals. 

The general procedure to bulk edit DeviceNet objects is:

  1. Create a DeviceNet.

  2. Configure the card's port.

  3. Under one of the ports, create and configure a DeviceNet device of the type you want to bulk edit.

  4. Configure the DeviceNet signals that appear under the device.

  5. For each level (DeviceNet port, device, and signals) use the sample format specification files or create your own and export data from the existing configuration.

  6. Edit the ports in the bulk edit Excel add-in.

  7. Edit the devices in the bulk edit Excel add-in.

  8. Edit the signals in the bulk edit Excel add-in.

  9. Import the ports.

  10. Import the devices.

  11. Import the signals.
