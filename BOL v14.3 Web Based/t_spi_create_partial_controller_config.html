Create partial controller data in SmartPlant Instrumentation and retrieve it to the DeltaV database

It is possible to create a partial configuration in SmartPlant Instrumentation, retrieve it into the Excel worksheet, and save it into the DeltaV database. For example, you may need to add more instruments and their configuration information to an existing controller:

  1. Create the configuration in SmartPlant Instrumentation.
  2. Publish the configuration.
  3. In Excel, select DeltaV > SPI Interface > Retrieve from SPI.
  4. Browse to and select the file you published from SPI.

    The Select Load Format dialog appears.

  5. Select any required columns that are not already selected and click OK.

    The workbook containing the data appears.

  6. Enter the word Partial in the value column of the node row, overwriting any text already in the cell.
  7. Select DeltaV > I/O Support > Data Manager.

    Because you have told the software that this is a partial controller configuration, you cannot load or save the workbook, you can only reconcile the workbook against an existing controller. 

  8. Click Reconcile.

    The Excel add-in merges the information you retrieved from SPI with the information from the DeltaV database. Items that are different from the database are flagged as comments.

  9. Review the changes and if you are satisfied, save the merged information to the database.
    Note:

    The Partial Controller Reconcile feature assumes that all existing objects in the DeltaV Database should remain. Any object that is in the DeltaV database which is not found in the file retrieved from SPI is simply fetched in to the Excel worksheet. Do not attempt to rename or delete any objects when working with a partial controller.
