Worksheet functions for DeltaV Reporter

DeltaV Reporter provides dialogs to help in configuring the worksheet functions. The dialogs are:

  • Configure Single Value Function – enables you to configure a worksheet function to retrieve a single sample for a tag in the DeltaV Continuous Historian database at a specified time (previous sample, next sample, or interpolated)
  • Configure Raw Data Function – enables you to configure a worksheet function to retrieve available samples for a single tag in the DeltaV Continuous Historian database within a time period
  • Configure Interpolated Data Function – enables you to configure a worksheet function to retrieve a number of interpolated samples for a single tag in the DeltaV Continuous Historian database at regular intervals within a time period
  • Configure Calculated Data Function – enables you to configure a worksheet function to retrieve calculated data relating to a single tag in the DeltaV Continuous Historian database within a time period divided into a number of subintervals of equal duration
  • Configure Events Function – enables you to configure a worksheet function to retrieve filtered events from the Event Chronicle database for one or more shifts within a time period
  • Configure Event Count Function – enables you to configure a worksheet function to retrieve a total count of filtered events from the Event Chronicle database for one or more shifts within a time period
