Logic Solver Analog Input function block parameters

The following table lists the system parameters for the LSAI function block:

LSAI Function Block System Parameters

Parameter

(Data Type)

Default Value

(Units)

Characteristics

Description

BLOCK_ERR

(Option bitstring)

None

NVM:

Preserved on Download

Bitstring parameter that indicates the following  information:

  • Input Failure/Bad PV

  • Simulate Active

FIELD_VAL

(Floating point with status)

0

(Percent)

NVM:

Preserved on Download

The value and status from the I/O card or from the simulated input when simulation is enabled.

IO_IN

(I/O Reference)

None

Access:

Configurable

Defines the input DST for the I/O used for the PV.

L_TYPE

(Named Set)

Indirect

Access:

Configurable

NVM:

Restored on Restart

Linearization type. Choices are:

  • Direct

  • Indirect

  • Indirect Square Root

OUT

(Floating point with status)

0

(EU of OUT_SCALE)

NVM:

Preserved on Download

the analog output value and status. The value and status are the same as for PV.

OUT_SCALE

(Scaling)

0.0 to 100.0

Access:

Configurable, Tuning

NVM:

Restored on Restart

The high and low scale values, engineering units code, and number of digits to the right of the decimal point associated with OUT.

PV

(Floating point with status)

0

(EU of OUT_SCALE)

NVM:

Preserved on Download

The process variable after conversions and filtering.

PV_FTIME

(Floating point)

0

(Seconds)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The time constant of the first-order PV filter. It is the time required for a 63% change in the FIELD_VAL to be reflected in the PV. A value of 0 turns off filtering.

SIMULATE

(Simulate)

Disabled, 0, GoodNonCascade

Access:

Configurable, Tuning

When SIMULATE is Enabled you can specify a simulated input value and status.

You can enable SIMULATE only when the module containing this block is downloaded to a ProfesssionalPLUS workstation (a simulated Logic Solver).

STATUS_OPTS

(Option bitstring)

None

Access:

Configurable, Tuning

NVM:

Restored on Restart

Status options. Allow you to select options for status handling and processing. The supported status options are:

  • Bad if Limited 

XD_SCALE

(Scaling)

0.0 to 100.0

(Percent)

None

This is the transducer scale. It is not used by block execution. It is fixed and cannot be changed.
