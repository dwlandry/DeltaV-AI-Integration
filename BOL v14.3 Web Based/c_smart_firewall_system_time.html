System time menu - initial configuration settings

If a GPS network time server is in use, obtain the IP address of the network time server. The IP address can be on the internal or external network. If it is on the external network, ensure that the computer can access the firewall.

If a GPS network time server is not in use, you can synchronize system time for all workstations and controllers on the DeltaV Control Network in the DeltaV System Time dialog by running deltav\bin\SystemTime.exe.

CAUTION:

Do not attempt to change system time by using the Windows Date and Time utility, accessed from the Control Panel or the Taskbar clock. The Windows Date and Time utility does not synchronize system time on all workstations and controllers in the DeltaV Control Network. Use the Windows Date and Time utility only to specify the local time zone and to enable the Automatically adjust clock for Daylight Saving Time option.
