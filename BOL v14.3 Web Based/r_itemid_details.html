SLS 1508 ItemID details

There are two types of items whose values you can simulate using OPC:
  • Logic solver I/O channels
  • Two levels of Global Secure Parameter References:
    • Logic Solver level
    • Secure parameter level.

This section explains the ItemIDs for these items.
