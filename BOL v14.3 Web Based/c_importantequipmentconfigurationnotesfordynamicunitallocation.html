Important equipment configuration notes for dynamic unit allocation

Multiple batches can auto-select the same unit if the maximum owners property of the unit (on the Arbitration tab in the Unit Properties dialog) is set to greater than one.

Convergent paths, in which there is no intersection of possible units, are not supported with equipment trains.  When divergent paths converge, the operator or unit selection policy can only select units that are in common with all possible upstream paths.

Parallel paths that do not have common downstream units (either because the downstream unit aliases or downstream units are different) will display all units possible to the operator. That is, the system will display all units that are in the intersection of the unit classes (in the case of downstream units aliases being different) or all unit modules in the downstream lists of all upstream units in all parallel paths.

Security is not checked when unit selection policies are used. The selections are performed by the system and not by the operator therefore there is no security to check. Changes to unit selection (when prompted) and selection modes do require the appropriate keys.

Example Circular Equipment Configuration

When a recipe is circular (one step is used both before and after another step), the downstream units must be configured accordingly.

Unit1 -> Unit2 -> Unit3 -> Unit2 -> Unit4

Where the Unit Class Configuration is

UnitClass1 contains Unit1 

UnitClass2 contains Unit2

UnitClass3 contains Unit3 

UnitClass4 contains Unit4

And the Unit Aliases Are Assigned as

UnitAlias1 is assigned to UnitClass1 

UnitAlias2 is assigned to UnitClass2 

UnitAlias3 is assigned to UnitClass3 

UnitAlias4 is assigned to UnitClass4

Requires Circular Equipment Train Unit Alias Configuration

UnitAlias1 has UnitAlias2 as a downstream unit alias

UnitAlias2 has UnitAlias3 AND UnitAlias4 as downstream unit aliases

UnitAlias3 has UnitAlias2 as a downstream unit alias

UnitAlias4 does not have any downstream unit aliases

And Requires Circular Downstream Unit Configuration

Unit1 has Unit2 as a downstream unit

Unit2 has Unit3 AND Unit4 as downstream units

Unit3 has Unit2 as a downstream unit

Unit4 does not have any downstream units.
