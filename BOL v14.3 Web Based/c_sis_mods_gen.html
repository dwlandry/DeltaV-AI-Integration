SIS modules

DeltaV SIS modules contain DeltaV SIS module parameters, DeltaV SIS alarm parameters, and DeltaV SIS function blocks. In addition, SIS modules can contain user-defined parameters, composite function blocks (one level deep, no nesting) and alarm groups.. DeltaV SIS modules hold the logic for performing the actions required in a safety instrumented system and can be downloaded only to Logic Solvers.

A Logic Solver has locked and unlocked modes. When the Logic Solver is unlocked and an SIS module is being viewed in debug mode of Control Studio, forced inputs are allowed. When the Logic Solver is locked, Control Studio exits debug mode and any forced inputs are removed.

DeltaV SIS modules cannot contain other SIS modules and can contain only user-defined parameters, SIS function blocks, and SIS composite blocks (which can contain only SIS function blocks and user-defined parameters).

The only algorithm type supported for DeltaV SIS modules is the function block diagram.

DeltaV SIS software does not support class-based modules. Your application may require many modules that are similar or identical. Use DeltaV SIS module templates to reduce engineering time and promote reuse of engineering work.

DeltaV SIS module history collection works the same as DeltaV module history collection. History is not collected from the Logic Solver so you cannot keep histories of I/O or diagnostic information.
