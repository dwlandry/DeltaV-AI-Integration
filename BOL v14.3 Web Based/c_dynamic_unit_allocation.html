Dynamic unit allocation

Dynamic unit allocation is the selection of units based on the configuration database's representation of the physical connectivity of units (by way of the equipment train and downstream units list) and, when programmatic allocation is enacted, the selection criteria defined in the unit selection policy. Equipment trains are required for dynamic unit allocation.

Dynamic unit allocation

  • Allows the connectivity of units to be configured so that physical constraints are known to the DeltaV system and can be used to facilitate equipment allocations.

  • Allows logical dependencies between the units to be configured so that recipe constraints are known by the DeltaV system and can be used to facilitate equipment allocations.

  • Allows automated unit allocations that require no operator intervention.

  • Allows soft constraints to be configured so that information (such as, least recently used and clean status) can be used for automated equipment allocations.

  • Simplifies the operator's task in selecting the equipment to be used for running a batch by offering only feasible (connected) sets of equipment.

Note:

Batches that are running stand-alone unit procedures (or operations) on a single unit do not make use of dynamic unit allocation. Recipes that are not using equipment trains do not make use of dynamic unit allocation.

In DeltaV the unit module is the representation of the process unit. A unit module is the instantiation of of a unit class.
