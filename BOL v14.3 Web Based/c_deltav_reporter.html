DeltaV Reporter

DeltaV Reporter is an Excel add-in that enables you to create detailed worksheets containing historical data read from the DeltaV Continuous Historian or Event Chronicle database. The worksheets created can include historical values read directly or interpolated from the DeltaV Continuous Historian database or filtered events from Event Chronicle database for a specified shift period. Worksheets can also include time stamp and status information associated with values from a DeltaV Continuous Historian database. DeltaV Reporter also enables you to write data to a DeltaV Continuous Historian database.
