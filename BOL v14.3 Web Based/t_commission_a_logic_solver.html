Commission the SLS 1508 logic solver

A logic solver under the SIS Network must be assigned to a physical logic solver card under the Physical Network or to a ProfessionalPLUS workstation before it can be commissioned. If the logic solver is not assigned, the Commission menu item is disabled.

  1. Navigate to the logic solver to commission under SIS Network.
  2. Right-click and select Commission.

    Note that you use the Decommission selection on the same context menu to decommission a logic solver.

  3. Click Yes on the dialog asking if you want to commission the logic solver.
  4. Click Confirm on the Confirmation dialog.

After commissioning, the Logic Solver can accept a download. The Logic Solver icon appears yellow, rather than grayed-out.

After a logic solver has been commissioned, it cannot be renamed,  unassigned, or upgraded until it is decommissioned. In addition, the card slot and redundancy of a physical logic solver card cannot be changed if the logic solver is commissioned.
