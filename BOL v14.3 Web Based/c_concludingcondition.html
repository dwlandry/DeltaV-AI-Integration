Concluding condition

The concluding condition defines the condition that ends the loop and continues to the next step of the recipe. When the looping condition is false and the concluding condition is true, the recipe breaks out of the sequence loop and continues to the next step in the recipe.

For example, the sample application needs to do the following tasks while making the paint base:

  1. Mix the ingredients for the base together.

  2. Test the pH level.

  3. Add more pH additive if the pH level is too high or too low.

  4. Transfer the base to another unit for mixing with the required coloring.

The following figure shows the PFC representing the operation that handles these tasks.

Sample Sequence Loop

When this recipe runs, base ingredients are added to the mixer and then mixed during the AGITATE phase. At the same time, the COOL phase controls the temperature of the paint base.

Once the base ingredients are mixed, a sample is drawn from the mixer to test the base's pH level. The operator is then prompted to enter the pH with the phase parameter SAMPLE. If the value entered is too high or too low, the recipe loops back, adds some pH additive, and continues mixing the base. Otherwise, the recipe transfers the base to the reactor to be mixed with the required coloring.
