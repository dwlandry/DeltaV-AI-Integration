Configure VIM Ethernet devices

At this point you should have configured the serial cards, ports, devices, and datasets through the DeltaV tab of the Dataset Properties dialog.

  1. Open the PLC tab of the dialog. 

    On this tab, specify the DF1 command type to be used to read/write the dataset:

  2. Enter a Device data type that matches the PLC you are communicating with.
  3. Enter a Data start address, specifying where in the PLC table where data is read. This can be any valid PLC specific table address.
  4. Enter a Number of values value. This parameter determines the registers read or written. The start address plus the number of values must not exceed the maximum table size.
  5. Open the Special data tab.
  6. Enter the value or values required by your application.
