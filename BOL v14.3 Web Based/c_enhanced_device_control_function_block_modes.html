Enhanced Device Control function block modes

The Enhanced Device Control function block supports two modes:
  • Automatic (Auto)
  • Cascade (CAS)

Mode transitions are standard. The mode of the device is specified through the MODE parameter.

The actual mode changes to Local Override (LO) in the following instances:
  • when TRK_IN_D is True
  • when SHUTDOWN_D is True
  • when the interlock is lost (the Interlock device option is selected and INTERLOCK_D is False)
  • when there is no permit (the Permissive device option or the Permissive to Any State device option is selected and PERMISSIVE_D is False) and the device state is Confirmed State n, where n is the state number corresponding to the passive state for the Permissive device option and can be any state for the Permissive to Any State device option.

When OPERATION_STATE is Locked, the mode is kept in Local Override.
