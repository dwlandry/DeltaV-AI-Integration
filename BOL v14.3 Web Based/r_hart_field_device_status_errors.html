HART field device status errors (CHARMs I/O)

Tables A and B below list the values expected for diagnostic parameters when the following field device status errors are detected by DeltaV Diagnostics:

  • Device malfunction

  • Configuration changed

  • Cold start

  • More status avalable

  • Loop current fixed

  • Loop current

  • Non-Primary Variable out of limits

  • Primary Variable out of limits
