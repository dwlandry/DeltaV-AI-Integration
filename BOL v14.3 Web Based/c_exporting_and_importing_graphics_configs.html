Exporting and importing graphics configurations

DeltaV Live provides importing and exporting capabilities that allow you to transport graphics configurations from one system to another and easily integrate them with configurations in other systems. These capabilities lessen the configuration effort and provide other benefits as well. For example, you can maintain a backup of DeltaV Live graphics configurations to be used when upgrading, uninstalling, and re-installing DeltaV software or when replacing ProfessionalPLUS hardware. You can also use an open documented representation of graphics configuration with external tools to perform activities such as generating specialized reports, performing comparison analyses and searches, or converting graphics to other graphic data formats (such as converting displays into Microsoft PowerPoint slides).

The export process is supported only for configurations created in Graphics Studio or in DeltaV Live Administration using the Workstation Management dialog, while the import process is supported only for .ahc files produced by these same applications. Graphics or files produced by any other method or modified after exporting from these applications cannot be guaranteed to successfully export or import.

The following components can be exported and imported using DeltaV Live Graphics Studio:
  • Languages
  • Themes
  • Library configurations (GEM classes, standards, and functions)
  • Displays, display sets, contextual displays, and layouts
  • Folder organization in the Graphics Explorer and Library Explorer panes

The following components can be exported and imported using DeltaV Live Administration:
  • DeltaV Live-enabled workstations (using the Workstation Management dialog)
  • Full configuration database (includes all exportable items in the database)
