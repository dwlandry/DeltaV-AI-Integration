Download status

Before downloading a node or subcomponent of a node with a blue triangle () or a blue triangle with a question mark () status indicator beside it, you can review detailed download status information by opening the Pending Download Changes dialog. To open the Pending Download Changes dialog, right-click a node or subcomponent of a node, and then select Download Status > Show Details.

If there is a blue triangle () or a blue triangle with a question mark () status indicator beside a node or subcomponent of a node, you can update its download status before downloading by right-clicking the item, and then selecting Download Status > Update. To update the download status of a node or subcomponent of a node and also open the Pending Download Changes dialog, right-click the item, and then select Download Status > Show Details.

The Pending Download Changes dialog lists the following detailed download status information:
  • The selected node or subcomponent of a node
  • If a node is selected, any subsystem of the selected node that needs to be downloaded
  • A list of all modified download scripts contributing to the pending download of a selected item
  • The reason that a download is needed: Add, Delete, or Modify
Note: All download status information is updated before the Pending Download Changes dialog opens.

In the Pending Download Changes dialog, you can copy detailed information about download status to the Clipboard, and then save it as tab-delimited text or as XML-encoded data.
