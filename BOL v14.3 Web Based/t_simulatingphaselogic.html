Simulate phase logic

You can specify a phase for simulation only. This enables you to run the phase logic in the Recipe Simulator (instead of in the controller) to test the recipe without affecting the plant.

To mark a unit phase for simulation,

  1. Select the unit phase in DeltaV Explorer.
  2. Right-click and select Properties.
  3. Check the Simulate check box to enable simulation.
  4. Click OK.

To mark a phase logic module for simulation,

  1. Open the module in Control Studio.

  2. Click inside the Diagram View area.

  3. Right-click and select Properties.

  4. Select the Simulate check box.

Unit Phase Properties with Simulate Enabled

Once the Simulate check box is selected, any time the phase logic is used as a phase in an operation, the Batch Executive accesses the Recipe Simulator for information about the phase rather than looking at the phase logic in the controller. The Batch Operator Interface displays DVBSIM in the status bar. This indicates to the operator that some simulation is in effect and recipes might not be in control for some phases.

However, the phase logic running in the controller is not affected by the Simulate function. It is still downloaded to the controller and can still be operated by setting its OWNER parameter to external. The operator can then control the phase manually from a faceplate on the operator's workstation.

Whenever you change the phase logic to or from Simulate, you must download the workstation on the Batch Executive node.

Run the Recipe Simulator on the same machine as the Batch Executive to simulate the phase logic.
