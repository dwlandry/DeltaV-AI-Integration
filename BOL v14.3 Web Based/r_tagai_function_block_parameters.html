Tag Analog Input (TAGAI) function block parameters

The following table lists the parameters for the function block.

Tag Analog Inputfunction block system parameters

Parameter

Units

Description

ABNORM_ACTIVE

None

Can indicate one of the following:

  • A block error condition not selected in BAD_MASK (at the function block level) is True (Active).
  • An error condition (at the module level) not selected in MERROR_MASK is True (Active).
  • A module status not selected in MSTATUS_MASK is True (Active).

BAD_ACTIVE

None

Can indicate one of the following:

  • A block error condition selected in BAD_MASK (at the function block level) is True (Active).
  • An error condition (at the module level) selected in MERROR_MASK is True (Active).
  • A module status selected in MSTATUS_MASK is True (Active).

BAD_MASK

None

The set of active error conditions that triggers a user-defined Bad condition. The user selects a subset of block error (BLOCK_ERR) conditions in the BAD_MASK parameter. When any of these conditions are True, the BAD_ACTIVE parameter becomes True. When any of the BLOCK_ERR conditions that are not included in BAD_MASK are True, ABNORM_ACTIVE becomes True.

BLOCK_ERR

None

Can indicate that the block has a bad input through the Input Failure/Bad PV error.

DEV_HIHILIM

EU of PLC control tag scale

The configured high-high alarm limit in the PLC control tag (PSet_HiHiLim).

DEV_HILIM

EU of PLC control tag scale

The configured high alarm limit in the PLC control tag (PSet_HiLim).

DEV_LOLIM

EU of PLC control tag scale

The configured low alarm limit in the PLC control tag (PSet_loLim).

DEV_LOLOLIM

EU of PLC control tag scale

The configured low-low alarm limit in the PLC control tag (PSet_LoLoLim).

EUMAX

EU of PLC control tag

The configured high scale of PLC control tag engineering units (Cfg_PVEUMax).

EUMIN

EU of PLC control tag

The configured low scale of PLC control tag engineering units (Cfg_PVEUMin).

EUSTR

EU of PLC control tag

The configured units type string of PLC control tag engineering units (Cfg_EU).

OUT

EU of OUT_SCALE

The analog output value and status from the final output value after limiting of the PLC control tag (Val).

OUT_SCALE

EU (default=none)

The mirrored high and low scale of the PLC control tag EU scale. Only the decimal point is tunable (this is used in default displays). The system does not user 100% of scale and 0% of scale values or the Engineering unit values configured in the OUT_SCALE Properties dialog. Instead, the system populates scale values at runtime using values from the PLC tag. The Engineering unit field is empty at runtime, the EUSTR parameter displays the engineering units configured in the PLC tag.

STATUS

None

The status reported from the PLC control tag (SrcQ).
