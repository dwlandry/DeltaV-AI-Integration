The DeltaV Security Administration application overview

The DeltaV Security Administration application provides a single application to manage the following security and auditing tasks for your DeltaV system:
  • Managing built-in user accounts
  • Review and oversight for Windows services
  • Reporting and auditing for DeltaV application (essential) files
  • Enabling rules for Windows firewall
Note:

Before making any changes, you must understand how these changes can impact the performance or robustness of the DeltaV software. Test the changes before deploying in a production system.

Access to DeltaV Security Administration requires the currently logged on Windows user to be both a Windows administrator (that is, a member of the Windows Administrators group) and a DeltaV administrator (that is, a member of the DeltaV Admins group). When in a domain, you must be a domain administrator to manage the domain user accounts.

Note:

This may require a download of the Professional or ProfessionalPLUS workstation so that the user account is established in the DeltaV database.

You should run the DeltaV Security Administration on every DeltaV workstation, performing all the tasks pertinent to the workstation (users enabled/disabled, auditing of the files and services, managing the Windows firewall rules, and so on).

Launch the DeltaV Security Administration from the Start menu on a DeltaV workstation. Start > DeltaV Installation
