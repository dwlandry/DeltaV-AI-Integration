Binding equipment

Recipes built referencing a unit class must have the unit selected when that step goes active. This task is performed when adding the batch, when rebinding equipment, and if prompted, during the execution of a batch.

When unit aliases are used in a recipe, the alias resolution is defined in the recipe as either Fixed (only a single unit is selectable for the unit alias), Defer (the unit can be selected at runtime), or From_Policy (the system selects a unit). The unit alias is class-based; therefore, those units that are appropriate for the step to use all belong to the same unit class. Unit aliases are resolved when adding the batch, when rebinding equipment, when prompted to select a unit during the execution of a batch, and when a unit selection policy executes.

To select the unit for a step, the operator (either the user that is currently logged in or the verifier if verification is enabled) must have the BATCH_ADD key for the area containing the unit that is required by the recipe. That area (containing the unit) must be assigned to the same Batch Executive as the recipe. Therefore, if the list is blank, either the unit class referenced by the recipe does not have a unit in the area assigned to the Batch Executive, or the user (operator or verifier if verification is enabled) does not have the appropriate privileges (BATCH_ADD key) for that area.

Note:

When binding equipment, the user that is logged in (or the verifier if verification is enabled) must have permissions in the area where the unit resides. If rebinding, the permissions are for the area where the newly rebound unit resides.

If User ID Verification is enabled for adding a batch, a Change User button is available. This button enables you to temporarily change the user who will be performing the function (adding/creating a batch and binding/rebinding equipment). Any security checks (area privileges, and so on) are performed on the changed user. When confirmation is enabled, the system checks the security for the confirmer. Once the function is complete, the logged in user's privileges are checked. Normally the user is changed to a person capable of confirming or verifying the action.

Note:

Batches with recipes that use equipment trains cannot be created in the Batch Operator Interface; they must be added using the DeltaV Operate Batch Controls only.

When creating a batch, the specific units can be selected or set to {Defer}. When set to {Defer}, the system prompts the operator to select a unit. The operator can also change or select units prior to the step running, or at anytime that the step is not active if the Batch Executive option, Allow change to the acquired unit for a step, is enabled.

Additionally, if changing the binding on a unit alias, no step that uses that unit alias can be active at the time of rebinding.

To change or select the unit binding, place the recipe in Manual mode and click the Rebind button (or Select Equipment button) on the Command Button bar. For each step, select the unit binding. Click Update. Any step that has a list of units in this dialog can still have the equipment binding (or rebinding) performed. If the step does not have a unit list then it is either a unit-specific step; the step is active, the unit class referenced by the recipe is not in the area assigned to the Batch Executive; or, the user does not have the appropriate privileges (BATCH_ADD key) for that area.

Important:

When rebinding equipment that is being retained by a unit procedure that has already run (that is, the unit procedure has the option, Retain unit after completing unit procedure, enabled), you must release the batch's ownership of the first unit using the Arbitration screen.
