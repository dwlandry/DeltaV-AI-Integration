The Campaign Manager server

The Campaign Manager Server controls the execution of a campaign, maintains all the runtime information about each campaign, and forwards the data to the DeltaV Batch Historian.

The Campaign Manager Server is configured in DeltaV Explorer by selecting the node on which the Campaign Manager server will run. You can also define the client properties for Campaign Manager Operator Interface clients that connect to this server under the Campaign Manager Server node in DeltaV Explorer.

The Campaign Manager Server is started and stopped using DeltaV Application Manager (Start > DeltaV Batch > Application Manager). To start the Campaign Manager Server, start the Application Manager, select the Executive tab and start the Batch Executive. Then select the Campaign Manager tab and click the Start button. 

Refer to the DeltaV Application Manager help topics for more information on setting up the Batch Executive and starting the servers. The help system also contains specifics about configuring the Campaign Manager Server, including such actions as setting and clearing campaign locks and clearing the purge persistence. Clearing the purge persistence clears the campaign journal files and the Campaign Manager's current state. This is equivalent to a cold restart of the Campaign Manager server since the last known state of the server is cleared.
