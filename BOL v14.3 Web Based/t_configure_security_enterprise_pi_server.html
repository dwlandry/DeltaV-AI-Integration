Configure security options for OSIsoft PI Server

On the workstation where you installed OSIsoft PI Server, use the PI System Management Tools (PI SMT) application to complete the following steps:

  1. Navigate to Security > Security Settings, and then disable or set all security options to their lowest level.
  2. Navigate to Security > Mappings & Trusts > Trusts, select the Trusts tab, and then specify DeltaVAdmin for PI User or specify DeltaV for PI Groups.
  3. If you installed PI Server on a remote Application Station or a non-DeltaV workstation outside the DeltaV Area Control Network (ACN), navigate to Security > Mappings & Trusts, select the Mappings tab, and then create a mapping between the account under which the DeltaV Smart Connector is running on the Application Station (typically, the DeltaVAdmin account) and a PI User with write access to PI Server database, such as piadmin. To initiate communications using the new mapping, ensure that it is enabled in the PI System Management Tools, and then restart the Application Station where you installed the DeltaV Smart Connector.
