Module detail displays

This section provides a reference for the module detail displays provided with DeltaV Live. In Graphics Studio, the module detail displays are found in the Graphics Explorer pane, in the Contextual Displays\Detail Displays folder.

The following table lists the module detail displays and their corresponding module templates:
Detail display Module templates
AALM_dt AALARM (alarm monitoring)
AI_dt ANALOG (monitoring)
ALM_FLD_SUP_dt ALM_FLOOD_SUP and ALM_FLOOD_SUP_32 (alarm flood suppression)
ALM_FO_SUP_dt FO_ALM_SUP (first out alarm suppression)
ALM_STATS_dt ALM_STATISTICS (operator statistics)
CDA_dt Modules with command-driven algorithms.
CT_dt8 CT-UNIM_F300 (three-state motor)
DL_dtx All motor and valve module templates that do not have interlocks (that is, that do not contain _ILOCK in their name).
Dnet_CMNDR_SK_DT CMNDR-SK-DNET, for DeviceNet devices
Dnet_E3RELAY_dt Allen Bradley E3 Overload Relay motor, for DeviceNet devices
DTC_dt PID_DEADTIME
EDC_dt VLV_DCC_EDC
FFLP_dt FF_PID_LOOP (fieldbus loop analog control)
FLC_dt FLC_LOOP and SIM_SR_FLC (fuzzy logic control)
GS_dt PID_GAINSCHED
Loop_dt CASCADE_MASTER, CASCADE_SLAVE, PID_AT, PID_GAINSCHED, PID_LOOP (analog control)

SIM_SR_PID (simulation)

Loop_RAMP_dt PID loop module templates CASCADE_MASTER, CASCADE_SLAVE, PID_AT, PID_GAINSCHED, PID_LOOP (analog control)

SIM_SR_PID (simulation)

LOOPM_dt MPC_LOOP (analog control)
PI_dt PULSE (monitoring)
PLM_dt Phase Logic Module
Profi_CMNDR_SK_DT CMNDR-SK-DNET, for Profibus devices
Profi_SIMOCODE_DT Siemens SIMOCODE-DP motor, for Profibus devices
TAGAI_dt TAGAI_MONITOR (TagIntegration, Tag Analog Input monitor)
TAGAO_dt TAGAO_MONITOR (TagIntegration, Tag Analog Output monitor)
TAGDI_dt TAGDI_MONITOR (TagIntegration, Tag Discrete Input monitor)
TAGDO_dt TAGDO_MONITOR (TagIntegration, Tag Discrete Output monitor)
UM_dt Batch Unit modules
UMC_dt Continuous Unit modules
