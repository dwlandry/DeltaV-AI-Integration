Templates overview

Note: In this topic, displays includes contextual displays.

DeltaV Live templates provide a means for you to define a common appearance and behavior that you always want to have in a group of displays or layouts. You can then use a template as a starting point for creating a new display or layout. Graphics Studio provides some out of the box templates and the tools to create your own templates.

Templates are managed in configuration libraries and have all the same configuration behaviors as normal displays and layouts, with a few exceptions. Templates cannot be:
  • published.
  • tested online.
  • referenced from somewhere else (such as, from a display link or other display).

Templates also have the same behaviors as other library items, with one exception: you cannot create subfolders under a template's library folder.
