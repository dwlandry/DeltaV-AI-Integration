Adding Hosts file entries

You will need the IP addresses and full computer names of the computers on the external network to create the Hosts file entries. Full computer names are in the form: Name.company.org or name.company.com. The full computer name can be found on the Control Panel's System page or on the System Properties dialog.

As an example, if the full computer name is batch_manager_server.pharma_co.com and the IP address is 192.168.1.24, the entry in the Hosts file would be: 192.168.1.24 batch_manager_server.pharma_co.com as shown in the following example Hosts file. 

For example:
#
#      102.54.94.97     rhino.acme.com          # source server
#       38.25.63.10     x.acme.com              # x client host

# localhost name resolution is handled within DNS itself.
#	127.0.0.1       localhost
#	::1             localhost
192.168.1.24  batch_manager_server.pharma_co.com

Be sure to save the modified Hosts file after adding new entries.
