The column ordering tab

When the Use local client configuration option is checked on the General tab, the user can:

  • Select the fields to be displayed at each level in the hierarchy and change the order in which the fields are displayed

  • Change the order of fields on the display by dragging the field name in the column headings to a new position on the right side of the window

If the Use local client configuration option is not selected, or is not permitted based on the Client Configuration options on the Campaign Manager Server, all changes must be made on the Campaign Manager Server.

The Restore Column Settings button restores the column settings to the defaults as configured on the Campaign Manager server's Client Configuration.
