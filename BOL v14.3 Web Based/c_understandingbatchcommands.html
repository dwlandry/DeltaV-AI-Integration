Understanding batch commands

To control a batch, operators issue batch commands from the Batch Operator Interface screens. These commands include:

  • Start

  • Hold

  • Restart

  • Abort

  • Stop

Batch commands apply to the currently selected batch. Operators must assume the responsibility for confirming which batch they are issuing commands to by examining the batch display in the lower-right corner of the Batch Operator Interface screens. Batch commands can be issued from the Batch List screen, the Procedure as PFC screen, or the Procedure as Table screen. For detailed information about the screens and their command buttons, refer to the Batch Operator Interface online help system.

The batch only responds to the batch commands that are valid for the batch's current state. For example, an aborted batch will not accept a command to restart.
