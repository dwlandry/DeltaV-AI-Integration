DeltaV Live workstations

A DeltaV Live workstation is a DeltaV workstation authorized to run DeltaV Live software and participate in DeltaV Live configuration deployment (publishing). After installing DeltaV Live, the DeltaV ProfessionalPLUS workstation is enabled by default and automatically authorized to run the DeltaV Live configuration database and all DeltaV Live applications. The ProfessionalPLUS workstation is always enabled as a DeltaV Live workstation; this status cannot be changed. Workstations that need to run DeltaV Live must be manually enabled as DeltaV Live workstations.

You can configure certain online behaviors for a DeltaV Live workstation, such as which layout, display sets (if any), or themes (if any) are available for use on that workstation/session. DeltaV Live workstations are configured in DeltaV Live Administration (Workstation Management dialog). Updates to DeltaV Live workstation configuration must be published before they can be deployed to the running system. If you remove a DeltaV Live workstation, the affected workstation remains active until all DeltaV Live applications running on it are closed.

To provide a more secure operating environment, a DeltaV workstation can be configured as a dedicated DeltaV Live workstation, limiting operators to the DeltaV Live application and to those applications available to the user through DeltaV Live. When the user logs on to a dedicated DeltaV Live workstation, it automatically switches to the DeltaV Desktop and launches directly into DeltaV Live.

To configure a dedicated DeltaV Live workstation, the following conditions must be true:
  • The DeltaV Live workstation is configured to start in Full Desktop mode
  • These FlexLock settings are selected:
    • Autoswitch Desktop
    • Autorun DeltaV Live
The online applications you select to use determine where the FlexLock settings are configured.
If the workstation is configured to use… FlexLock settings are configured in…
DeltaV Live only DeltaV Live Administration
Both DeltaV Operate and DeltaV Live FlexLock Application
Note: DeltaV Live applications are not supported on Application Stations, Remote Operator Stations, Remote Application Stations, or Inter-Zone Servers.
