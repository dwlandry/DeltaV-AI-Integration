Smart Commissioning for HART devices

Smart Commissioning enables you to configure control strategies and safety logic using only the Device Signal Tags (DSTs), eliminating the need to define the physical location of the I/O. Each I/O function block is linked to a DST that is not assigned to any particular I/O channel. In a traditional configuration approach, I/O references within control strategies are bound to specific channels, creating unnecessary dependencies in the project schedule. With Smart Commissioning, you can configure HART devices and CHARM properties without defining specific CHARM locations.

Smart Commissioning consists of the following four components:

  • Auto-sensing devices: Devices are identified by the device tag. The wiring or channel position is no longer relevant for device identification purposes. It does not matter if the device was pre-tagged by the vendor or tagged on site before mechanical completion. Automatic Device Identification, or auto-sensing, is performed using DeltaV Device Commissioner.
  • Automatic binding to control or safety logic: Once the device has been identified, it is automatically bound to the right control strategy based on the device tag. Binding is performed using DeltaV Device Commissioner.
  • Automatic device configuration: Either late configuration changes or the whole device configuration can be applied on site in just a few minutes. Automatic device configuration is performed using I/O Studio.
  • Automatic loop test. Devices are tested using HART commands to set the device output and the response verified all the way to the control or safety logic. Automatic loop testing is performed using DST Simulate.

Smart Commissioning consists of the following DeltaV applications:

  • I/O Studio: Create device placeholders and manage the I/O Studio Library.
  • DeltaV Device Commissioner: Commission field devices, CHARMs, and other DeltaV hardware. Auto-sense connected field devices without first having to configure and download CHARMs.
  • Device Signal Simulator: Test the control logic and displays without having to configure I/O or have I/O hardware present.
