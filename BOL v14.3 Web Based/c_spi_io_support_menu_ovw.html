SmartPlant Add-in I/O Support menu overview

The I/O Support menu items are:

  • Convert to DeltaV – Convert the current workbook to be compatible with the DeltaV software. This option is visible when an SPI XML file is retrieved.

  • Data Manager – Connects to the DeltaV database and opens the Data Manager dialog.

  • Library – Opens the Library Manager dialog. From this dialog you can regenerate selected libraries.

    Note:

    If you make changes to the DeltaV database libraries after you install the add-in, regenerate the libraries from the Library Manager dialog. Open the dialog by selecting DeltaV > I/O Support > Library from the Excel main menu.

  • Delete and Restore – Delete and restore objects in the Excel workbook. The available submenus depend on current context.

    Note:

    Do not use the Excel Delete commands to delete cards, devices, datasets, IO module slots, or signals. Use the DeltaV > I/O Support > Delete command instead. To delete a card, for example, select a cell within the card configuration, then select DeltaV > I/O Support > Delete > Card. The text changes to gray italic to indicate the configuration has deleted from the workbook. Restore can be used to undelete this card. 

  • Collapse – Uses Excel's Outline capability to hide information for some configuration items. To use, select Collapse from the menu. Use the plus signs (+) that appear in the left of a workbook to selectively view hidden information.

  • Find Next Error – If the current workbook contains errors, use this choice to find the next cell that contains an error.

  • Books Online – Opens DeltaV Books Online.

Note:

This add-in is primarily intended to support the SmartPlant Instrumentation application interface. It is not intended for general purpose bulk editing. It is expected that user-defined import/export will be used for general purpose bulk editing.
