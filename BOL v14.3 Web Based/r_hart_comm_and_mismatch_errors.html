HART communication and mismatch errors (CHARMs I/O)

Tables A and B below list the values expected for diagnostic parameters when the following HART communication and mismatch error conditions are detected by DeltaV Diagnostics:

  • HART server error

  • HART communication error

  • Device revision mismatch

  • Loop current mismatch

  • Scale mismatch

  • Diagnostics in progress

  • Non-Primary Variable out of limits

  • Stale
