Batch states

The following are batch states supported by the DeltaV system:

Aborted - Emergency shutdown has completed.

Aborting - Emergency shutdown is in progress.

Complete - Normal operation sequence has completed.

Held - Temporary stop operation sequence has completed, and is ready for restart.

Holding - Temporary stop operation sequence is in progress.

Ready - No operation sequence is in progress, and is ready for start command.

Restarting - Sequence for recovery from HOLD or LOST is in progress.

Running - Normal operating sequence is in progress.

Stopped - Permanent (but not emergency) shutdown has completed.

Stopping - Permanent (but not emergency) shutdown is in progress.

Loading - Loading the batch to the Batch Executive. Occurs when creating the batch.

Load_Failed - Batch creation failed. To view the reason, open a DeltaV operator batch environment (such as, the Batch List graphic in DeltaV Operate) and right click the batch.

Lost - The batch has been forced to shut down from the Batch Application Manager or has otherwise lost communication with the Batch Executive.

Unloading - Unloading the batch from the Batch Executive. Occurs when the batch is removed from the batch list.

Recovering - The batch is attempting to recover to its previous state (either from Lost or after a Batch Executive warm restart).

Recover_Failed - Recovery of batch failed. To view the reason, open a DeltaV operator batch environment (such as, the Batch List graphic in DeltaV Operate) and right click the batch.

ASC_Pending - Pending the start of an Active Step Change.

ASC_Working - The execution of an Active Step Change is in progress.

ASC_Failed - The execution of an Active Step Change failed.
