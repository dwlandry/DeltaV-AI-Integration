Send a file to a printer

Most print to file functions save the file in PostScript format and will require a PostScript-compatible printer to print the file properly.

  1. Open a command prompt.

  2. Navigate to the directory where file is stored.

  3. Type: copy filename\\PrintServerName\printername

    (where PrintServerName is the print server and printername is the PostScript printer name as configured on the computer's Printer settings.)
