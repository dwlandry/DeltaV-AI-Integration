System Power Supply LEDs

This table describes the LED indicators for the System Power Supply (AC/DC) and the System Power Supply (Dual DC/DC).

System Power Supply LEDs
LED Correct Operating Conditions Fault Indications Probable Cause Corrective Action
Green – Power On Off 1. Power is not supplied to unit. Possible line power problem. 1. Check supply power and connections.
2. Internal fault 2. Contact technical support.
Red – Error Off On 1. Outputs are outside of tolerance. Verify loading calculations.
2. Input over voltage. Unit shuts down. 2. Check input supply voltages.
