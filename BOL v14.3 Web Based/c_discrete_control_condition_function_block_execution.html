Discrete Control Condition function block configuration and execution

The following sections cover aspects of DCC block configuration and their effect on block execution.

The DCC block supports up to 16 interlock conditions, 8 permissive conditions, and 8 force setpoints. For each condition configure the following:
  • Description
  • Expression
  • Delay On
  • Delay Off (interlock and permissive only)
  • If a reset is required (interlock only)
  • The interlock state (interlock only)
  • The force setpoint value (force setpoint only)
  • If the condition is disabled
  • Prevent interlock conditions from being disabled by a configurable parameter (higher managed) (Interlock only)
Note:

The three condition types have several similar parameters describing different properties of each condition. When discussing these similar parameters in general the following convention is used: a_PARAMn. For example a_OUT_Dn. OUT_D is the parameter root, a represents the three types of conditions (I, P, and F), and n represents the condition number. For example, a_OUT_Dn represents instances of I_OUT_D_[1-16], F_OUT_D_[1-8], and P_OUT_D_[1-8].
