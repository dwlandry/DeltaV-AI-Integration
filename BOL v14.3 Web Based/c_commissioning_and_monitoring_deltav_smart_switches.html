Commissioning and monitoring DeltaV Smart Switches

The DeltaV Smart Switches are commissioned using the Network Device Command Center (NDCC) application. Network Device Command Center is accessed from an icon in the toolbar of the DeltaV Explorer or Diagnostics or from the utilities menu of DeltaV Operate. Commissioning from NDCC includes:

  • Automatically assigning an IP address to the switch
  • Automatic Instantiation of a corresponding switch module
  • Downloading the switch module

There are four interfaces you can use to change and monitor switch parameters:

  • Network Device Command Center (NDCC) — A DeltaV application to commission and manage smart switches.
  • Serial Port Interface — A command line interface from a terminal or terminal session on a PC connected by a serial cable. (For example, DeltaV part KJ1611X1-MA1.)
  • Telnet interface — A command line interface from a Telnet session from a Management station.
  • Built-in Browser — A Java-based read-only browser.

The four interfaces to switches have overlapping functionality. That is, some tasks cannot be performed with all methods. The NDCC application is the more powerful and easier to use because it runs on DeltaV workstations. It is recommended that you use NDCC to configure and manage smart switches. However, a few tasks—such as changing the user account passwords--can be performed only from the serial port or Telnet interface.

Networks monitored by NDCC

Network Device Command Center (NDCC) is capable of discovering (and therefore, commissioning, monitoring, and managing) DeltaV Smart Switches from the following networks (provided there is no routing or redirecting of the network traffic):
  • DeltaV Area Control Network (the ACN), primary and secondary
  • DeltaV Remote Network, primary and secondary
  • DeltaV level 2.5 network
  • Thin Client network (for virtual DeltaV workstations), primary and secondary

Switch modules

The DeltaV Smart Switch module classes hold common switch setup information and hardware alarm behavior configuration for Smart Switches. You can modify parameter settings of the classes to tailor them to your needs. Switch modules are created from two control module classes:

  • SWITCH_STDCFG_$X — Modules for switches on the primary network are created from this class.
  • SWITCH_SECCFG_$X — Modules for switches on the secondary network are created from this class.

During commissioning of a switch on the DeltaV ACN or DeltaV Remote networks, NDCC detects if the switch is on the primary or secondary network and creates the switch module from the appropriate module class.

If you do not need different module classes for the primary and secondary networks, you can rename SWITCH_SECCFG_$X. If NDCC does not find SWITCH_SECCFG_$X all switch modules are created from SWITCH_STDCFG_$X.

Classes are provided for switches on both primary and secondary networks because you may need to have different values for the following parameters on the two networks:

  • PRI_TIME_IP_ADDR — The IP address of the switch primary Network Time Protocol (NTP) server.
  • BCK_TIME_IP_ADDR — The IP address of the switch secondary NTP server.
  • TRAP_IP_ADDR — The IP address switch trap messages are sent to.
  • SYSLOG_IP_ADDR — The IP address switch system log messages are sent to.

TRAP_IP_ADDR and SYSLOG_IP_ADDR parameters exist to allow experienced users (or your Information Technology group) to use third party tools such as a Syslog Server or third party SNMP package to collect this information. Typical DeltaV users will not need to set these addresses.

Important:

NDCC only detects the primary and secondary network for the DeltaV ACN and DeltaV Remote networks. For all other networks, it uses the SWITCH_STDCFG_$X module.

Therefore, if you need to have any parameters set for these other networks, you must set the module class to allow for the instance to be configured, and you must set the correct IP addresses for things such as the SYSLOG or NTP servers for those networks (that is, the subnets must be appropriate for the switch's network).
