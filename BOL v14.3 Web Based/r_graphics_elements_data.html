Data elements reference

Data elements bring live, read-only data of various types into displays and GEM classes.
Alarm list

While DeltaV Live provides an out-of-the-box Alarm List display, the alarm list element provides a means for you to add an alarm list to other displays or GEMs. An alarm list shows the active alarms in an operator's scope of responsibility and provides the means for operators to respond efficiently to these alarms. All alarm list elements, whether on the Alarm List display or other displays, are configured like other graphics elements. An alarm list's Graphics Configuration pane lets you define things such as the type of alarms to show; the appearance of the alarm list, alarm priorities, and alarm classifications; the available alarm filters and toolbar buttons; and the interactions that operators can perform from an alarm list.

Up to 17 alarm list elements can be active at the same time in DeltaV Live. This limit includes full-size displays, such as the Alarm Filter, Alarm List, Alarm Suppress, and Alarm Summary displays, as well as alarm list elements on GEMs or contextual displays (such as faceplates). Having more than 17 active alarm lists can result in some of them being unable to receive alarm information.

Chart

A chart element provides a means to present multi-pen charts that show trends of historical versus real-time data in DeltaV Live. You can add up to 20 charts on a display, GEM class, or unlinked GEM without negatively impacting performance. Charts can be configured with up to 10 pens, which collect data from the real-time server and a history data server of your choosing. Charts can read data from the DeltaV Continuous Historian, the Advanced Continuous Historian, or a PI Server enterprise historian.

When configuring a chart, you can define various features such as appearance, time divisions, legend, desired parameter references for trending (pens), appearance and behavior of each pen, historical data server, and status colors. A chart can also be configured to allow DeltaV Live users to modify its contents and presentation while online.

An action bar, which is present on all charts, provides a means for DeltaV Live users to perform actions such as manipulating the visible time span or changing certain chart settings.

Online modifications to the content of a chart persist for the duration of that user's DeltaV Live session. For example, if a user adds a parameter to a chart on a display, closes the display, and then reopens it again before closing that DeltaV Live instance, the added parameter is still present. For example, if the DeltaV Live user adds a parameter to a chart in a display, then closes and reopens the display, the added parameter is still present. However, when the next user logs into DeltaV Live, the added parameter is no longer present.

Data link

A data link provides an easy-to-configure means for showing real-time values from information sources, as well as an optional means for users to modify the data online. The Graphics Configuration pane provides configurable properties for the most commonly used data links in a DeltaV system, which include string, numeric, scaled numeric, named set, mode, and scaling data links. You can also use the Script Assistant to configure other types of data links.

Date time

A date time element shows the date and time on a display. You can configure it for the desired time zone, format, and culture-specific format specifiers.

Display link

A display link provides a navigation control that is used to open a display from within a display. The click event is pre-configured to launch the target display specified during configuration.

Display link placeholders can be created for displays that do not yet exist by entering a display name in the Link Target field. Then, if and when a display with that name is created and published, the display link reference begins working online. However, if the workstation has an active display set, the new display must also be added to that display set and the display set published.

If you delete a display that has a display link referencing it, the reference continues working online until the layout configuration is reset.

Multi-point

The multi-point element provides an easy-to-configure means for showing real-time values in a horizontal or vertical bar graph format. You can plot from 3 through 12 online control module parameters on the multi-point, in a way that makes it easy for operators to observe when values deviate from the defined operating range. Plot values are mapped from left to right (on a horizontal multi-point) or from top to bottom (on a vertical multi-point) and at equal relative intervals.

You can also define the various components you want visible on the multi-point, such as operating ranges and alarm limits, and info boxes. You can even define interactions for each parameter, allowing DeltaV Live users to interact with the parameter. See the multi-point element reference for more details about its components.

Radar plot

The radar plot element provides an easy-to-configure means for showing real-time values in a format that makes it easy for operators to observe when values are deviating from the defined operating range. You can plot from 3 through 12 online control module parameters on the radar plot. The first plot value appears at the 12 o'clock axis position, with additional plot values appearing clockwise at equal relative angles. You can also define the various components you want visible on the radar plot, such as operating ranges and alarm limits. See the Radar plot element for more details about its components.

Sparkline

A Sparkline is used to present related real-time and/or historical data in a compact trend chart. It is designed to show a large amount of data in a small space, giving an uncluttered and high-level overview of what happened to the data over time or showing the value of a process variable at a glance.

Tab

A tab element behaves similarly to a Windows tab control. It provides a means to have multiple elements, when they do not need to be visible at the same time, share a common area. It also provides a means for the DeltaV Live user to switch between collections of elements on a display.

A tab element can contain from 1 through 32 tab items, with each item containing its own collections of elements. Each tab item can be configured, if desired, with a custom means for tab selection. For example, you can use a button or any element that supports configurable actions, or even configure a tab item to automatically be selected based on process data. If you want to allow DeltaV Live users to interact with the tab items, you can opt to show a tab strip on the tab element.

Web browser

A web browser element provides a means for users to access specified web from within a display. In DeltaV Live, when users open a display containing a web browser element, they see the appropriate web content rendered within it. For example, if the web browser, placed on an overview display, contains a URL for a web video feed, the user sees the video embedded in his overview display. Or, if the web browser contains a URL pointing to another application on his local machine, such as Process History View (PHV), the user sees PHV embedded in the display. Users do not see the URLs.

The web browser element does not contain an address bar, title bar, or window chrome. It does provide forward and backward buttons for navigating between URLs, as well as a refresh content button.

By default, a web browser allows access to only URLs on the local machine. To allow access to URLs external to the local machine, a system whitelist library standard, $UrlWhiteList, must be created and configured with the URLs users are allowed to access. Then, each web browser element must also list, in the Whitelist field, the URLs that users on that machine are allowed to access. The user can access only URLs listed in both the $UrlWhiteList standard and the web browser element's Whitelist field.
