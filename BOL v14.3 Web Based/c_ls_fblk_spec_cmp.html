Logic Solver Comparator function block

The LSCMP function block compares two values (DISC_VAL and COMP_VAL1) and sets a Boolean output for each of the following comparisons: LT (Less Than), GT (Greater Than), EQ (Equal To), NEQ (Not Equal).

Additionally, the LSCMP function block compares the DISC_VAL against the range defined by COMP_VAL2 and COMP_VAL1 to determine the Boolean output, IN_RANGE.

The LSCMP function block does not support modes or alarm detection.
