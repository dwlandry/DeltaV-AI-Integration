Address Plug

Installation notes

  • The Address Plug (1-8) installs in the CHARM Address Terminal in the dedicated slot on the CHARM Baseplate.
  • Install Address Plug 1 on the first baseplate, Address Plug 2 on the second baseplate, Address Plug 3 on the third baseplate, and so on.
