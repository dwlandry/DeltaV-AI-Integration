Basic database functions

The Database Administrator tools fall under three groups: Basic, Utilities, and Configuration.

Basic database management functions include:

  • creating new, empty databases
  • copying database files
  • renaming database files
  • deleting database files

These functions are the most basic database functions but are not necessarily the most frequently-accessed functions. The following sections describe the Basic database functions.

Important: Never use Windows Explorer to copy, move, create or delete a database. Always use the Database Administrator Tools. Access to the correct database could be compromised if you use Windows Explorer.
