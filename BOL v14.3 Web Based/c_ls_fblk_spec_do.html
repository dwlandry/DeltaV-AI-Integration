Logic Solver Discrete Output function block

The LSDO function block drives a Logic Solver output channel (for example, a Discrete Output channel) to manipulate a solenoid or other final element. In a typical application the block's input is from an output of a Logic Solver Cause and Effect Matrix (LSCEM) block.

CAUTION:

Avoid renaming any LSDO block in a running system. If you do, and REQUIRE_RESET is True, the block's output OUT_D will be de-energized when the block is downloaded.

The LSDO block does not support modes.
