Legacy Historian data conversion

The Legacy Historian is no longer supported as a DeltaV option.

To migrate from the Legacy Historian in DeltaV version 11.3.1 or earlier to the DeltaV Continuous Historian, you must use the Continuous Historian Data Conversion utility to convert your Legacy Historian archive data to a format that can be used with the DeltaV Continuous Historian.

The Continuous Historian Data Conversion utility is a standalone application; it does not require that DeltaV system software be present on the same computer. However, Legacy Historian software must be installed on the system and its services must be running in order to use the conversion utility. The offline Legacy Historian archive data must be loaded into the online Legacy Historian system before the conversion utility can convert the Legacy Historian archive data. The conversion utility presents a list of archive files available for conversion and allows you to specify where the converted data is to be stored. The conversion utility converts your Legacy Historian archive date files to exported historical data sets with a file extension of .xfc. The generated files are named after the converted archive name; for example, the archive file piarch.001 would result in a converted file of piarch001_start_time.xfc. The conversion utility indicates the progress of the conversion as it is being done. After conversion, the files can be brought into the Primary storage area by using the Create Extended History Data Sets in the Continuous Historian Administration application.

Alternatively, you can migrate from the Legacy Historian to the Advanced Continuous Historian or OSIsoft PI Server. The historian selection that is best for you depends on your specific requirements for historian functionality. Consult with your local representative or Emerson service provider if you need assistance selecting the historian that best meets your needs.

Important:

For more information about migrating from the Legacy Historian to a supported historian, refer to the DeltaV Historian Upgrade Planning Guide white paper on the Emerson web site, also available from your Emerson field sales office or local business partner.
