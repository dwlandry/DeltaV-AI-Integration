The DVBCMBatchEdit/Info objects

The DVBCMBatchEdit and DVBCMBatchInfo objects are used to edit or read information about a specific batch within a given campaign. These objects cannot be instantiated unto themselves. Instead, both must be retrieved using the appropriate DVBCMCampaignEdit or DVBCMCampaignInfo method (get_BatchEdit or get_BatchInfo).

The DVBCMBatchEdit object encapsulates all data of a specific batch of the campaign edit object from which it was derived. It has read and write capabilities and is used to configure, change, or manipulate all properties of a batch. The object has two lock methods: DVBCMBatchEdit.LockControl and DVBCMBatchEdit.LockEdit. All properties of the batch edit object are read only except Index. The batch edit object can be used to view the batch's state, ID, and so on. The object can be used to view or set lockout info. The object can also be used to determine if the batch is a setup or cleanup batch (refer to the Order of Execution section for more information). When only reading (not writing) a batch's data, always use an info object rather than edit object to save system resources and avoid lockout problems.

The DVBCMBatchinfo object encapsulates all data of a specific batch of the campaign info object from which it was derived. It has read-only capabilities and is only used to view the properties of a batch. The object does not have a lockout property since it is read only. The object can be used to view a batch's state, index, ID, and so on; to retrieve the batch's recipe info object; to view recipe properties of the batch; or to view lockout info. When only reading (not writing) a batch's data, always use an info object rather than an edit object to save system resources and avoid lockout problems.
