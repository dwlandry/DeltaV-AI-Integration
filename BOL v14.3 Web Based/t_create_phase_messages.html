Create the phase messages

  1. In DeltaV Explorer, select the DRAIN phase class.
  2. Right-click, and then select New > Phase Message from the context menu.
  3. In the Phase Message Properties dialog, enter the message text as shown, and then click OK.

    Note that the message ID is automatically assigned number 1.

  4. Create message 2 using the following message text: How many gallons would you like to release?
