Set up a DeltaV workstation and install the system identifier

Setting up a DeltaV workstation involves connecting its components, installing the DeltaV system identifier, and optionally installing an Uninterruptible Power Supply (UPS). The system identifier gives each DeltaV system a unique identification that allows you to download changes to the system.

  1. Follow the instructions supplied with your workstation to connect the monitor, keyboard, and mouse to the central processing unit (CPU). Refer to the documentation supplied with your workstation for details on the I/O ports.
  2. Install the system identifier on the parallel printer port or Universal Serial Bus (USB).
  3. Connect the workstation and its associated peripherals to one AC power distribution and system ground.
