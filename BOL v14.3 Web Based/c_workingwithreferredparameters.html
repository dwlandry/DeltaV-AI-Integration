Working with referred parameters

Recipes (all levels) can contain referred parameters. A referred parameter is one where the value of the parameter is passed up the recipe hierarchy to another report parameter.  The referred parameter value cannot be set by the operator, only the phase that initiates the report parameter sets the subsequent referred parameters.

The procedure-level referred parameter value can be used for unit selection decisions (such as in a unit selection policy expression). A referred parameter can be used in recipe transitions on all levels. Additionally, the referred parameter at the procedure level can be the source value for a deferred input parameter thereby passing data up from one phase and across and down to another. That is, a report parameter value from Phase_A is passed (referred) to the operation, unit procedure and procedure. At the procedure level, the value of that referred parameter is passed down (deferred) to a phase input parameter in Phase_Z.

When the report parameter is uploaded, the value is passed up the referral chain. When the phase completes, an upload occurs. An upload request can be programmed during the execution of a phase using phase request codes; however, be aware that at phase completion, the upload occurs again, overwriting the value that was uploaded previously.

Note:

The report parameter must be calculated and uploaded before any subsequent element of the batch (for example, a deferred input parameter, a transition expression, a  unit selection policy) needs that value. If not available, the recipe will not execute in the manner expected (the operator is prompted for a value, or the expression does not deterministically evaluate, for example).

It is recommended that you do not write to the same recipe parameter from multiple sources. For example, when referring two phase parameters (CAPACITY) from two parallel phases (Phase_A and Phase_B) to the same procedure recipe, create two recipe parameters (CAPACITY_A and CAPACITY_B) in that procedure. This will eliminate any ambiguity as to the source of the recipe parameter value.
