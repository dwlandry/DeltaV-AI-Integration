Effect of HART error conditions on diagnostic parameters (Classic I/O)

This section lists the effect of HART error conditions on DeltaV Diagnostic parameters. For ease of use the information is organized into two tables. This table lists the status returned to the following Diagnostics parameters as a result of HART error conditions:

  • COLD_START

  • CONFIG_CHANGED

  • DEV_CFG_MISMATCH

  • DEV_MALFUNC

  • HINTEG

  • MORE_STATUS

  • NO_COMM
