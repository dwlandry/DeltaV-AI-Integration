Create format specification files for the example

To successfully bulk edit modules containing other modules, you must create format files for each individual module. The example requires format files for MASTER_CAS_1 and SLAVE_CAS1. The steps to create format files for a contained module are slightly different than the steps to create a containing module so both are detailed below.

To create a format file for a contained module:

  1. In DeltaV Explorer, select File > Format Specification > New.

  2. In the Filename field, enter SLAVE_CAS to create a format file for the SLAVE_CAS module.

  3. Select Include Column Headers.

  4. Specify the Object type as Module.

  5. Click the Apply Filter button and make sure the appropriate filters are selected for your purpose.

  6. Click the Browse button for the Subtype field.

  7. In the Object Type field of the Browse dialog, select Module Templates.

  8. Browse to and select the module template SLAVE_CAS.

  9. In the Select fields dialog, select module parameters you want to bulk edit. You must at least include area, module_name, and module_subtype.

  10. Open the Parameter List and include block parameters you want to bulk edit, if any.

  11. Select items in the Format specification - Must exist dialog, if desired.

  12. Click Finish to save the format specification file and close the dialog.

To create a format file for a containing module:

  1. In DeltaV Explorer, select File > Format Specification > New.

  2. In the Filename field, enter MASTER_CAS to create a format file for the MASTER_CAS module.

  3. Select Include Column Headers.

  4. Specify the Object type as Module.

  5. Click the Apply Filter button and make sure the appropriate filters are selected for your purpose.

  6. Click the Browse button for the Subtype field.

  7. In the Object Type field of the Browse dialog, select Module Templates.

  8. Browse to and select the module template MASTER_CAS.

  9. In the Select fields dialog, select module parameters you want to bulk edit. You must at least include area, module_name, and module_subtype.

  10. Open the Parameter List in the Select fields dialog.

  11. Select the SLAVE_CAS/MODULE_BLOCK_BINDING.MNAME field.

  12. Select any block parameters you want to bulk edit.

  13. Select items in the Format specification - Must exist dialog, if desired.

  14. Click Finish to save the format specification file and close the dialog.
