LS DVC Terminal Block specifications

Installation notes

  • The LS DVC Terminal Block holds a single LS DVC HART DTA CHARM and provides the keying and field wiring connections for the CHARM.
  • The terminal block's keying mechanism is fixed to allow only a LS DVC HART DTA CHARM.
