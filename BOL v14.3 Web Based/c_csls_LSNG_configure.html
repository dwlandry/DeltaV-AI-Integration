Configure the LSNG

Configuring an LSNG consists of setting a few things on the tabs of the LSNG Properties dialog.

On the LSNG Properties dialog:
  • Enter a description of the LSNG, if desired.
  • If you have created the LSNG placeholder by dragging an LSNB from the Unassigned Safety Nodes folder, Select Gateway in the Node Type field.
  • If you want a standby card's revision to automatically change to the correct revision when it is inserted, select the Enable Automatic Upgrades check box.
  • Configure the Alarms and Displays tab and the Proof Testing tab as desired.
