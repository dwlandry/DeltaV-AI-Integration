Manual phase control from DeltaV Operate

Manual control of phases may be done from the Phase Control screen in the Batch Operator Interface or from DeltaV Operate using the Phase Control objects.

Under normal operating conditions, it is recommended to use the Phase Control screen in the Batch Operator Interface or the Phase Control objects in DeltaV Operate to control phases manually.

However, you can also control phases through the phase faceplate and detail display (which are accessed through the unit module's faceplate and detail display). You can either configure displays at the class level (Unit Class, right-click and select Properties. Click the Displays tab) or at the instantiation of the unit class; that is, the unit module (again in the Properties dialog on the Displays tab). Additionally, the operator can click the faceplate button (if available) at runtime and enter the unit name.
