Explorer view

From the Explorer view, you can manage and view all graphics configurations in the configuration database. This view contains two panes, the Library Explorer pane and the Graphics Explorer pane. The panes can be floated, moved, or docked to another location on the interface, or docked as tabs in the Content Tabs view. Double-click an item in the Explorer view to see its contents in the Content pane and to open it as a Content tab. These two panes share some ribbon commands; therefore, to perform certain operations, the appropriate pane must be selected as active.

Graphics Explorer pane

The Graphics Explorer pane provides a folder structure for managing and viewing displays, contextual displays, display sets, and layouts. This pane contains a permanent, top-level folder for each type of configuration. Additional subfolders can be created under each configuration's permanent folder.

You can do the following from the Graphics Explorer pane:
  • Create graphics configurations and subfolders (under their respective folders)
  • Rename graphics configurations and user-created folders
  • Move graphics configurations and user-created folders
  • Delete graphics configurations and user-created folders

Library Explorer pane

The Library Explorer pane provides a folder structure for managing and viewing languages, themes, and library configurations (GEM classes, standards, and functions). This pane contains a permanent, top-level folder for languages, for themes, and for each configuration library. Each configuration library contains a permanent folder for each type of library configuration.

You can do the following from the Library Explorer pane:
  • Create new configuration libraries
  • Create subfolders under each library item's root folder
  • Add new languages, themes, GEM classes, standards, and functions (under their respective folders)
  • Rename configuration libraries, library items and user-created folders
  • Move library items and user-created folders
  • Delete library items and user-created folders
