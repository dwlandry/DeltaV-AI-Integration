Batch elements reference

Batch elements provide the Batch controls available for adding to displays and GEM classes.
Active phase
The Batch Active Phase view is used to view active phases within the batch hierarchy.

Alarm summary
The Batch Phase Alarm Summary view is used to view phases in alarms within the batch hierarchy.

Arbitration
The Batch Arbitration is used to arbitrate equipment in a batch process.

Command toolbar
When linked to either the Batch List or the Batch Operator Comments elements, the Batch Commands Toolbar allows DeltaV Live users to interact with the control.

Comments
The Batch Operator Comments is used to add operator comments to a batch.

Hierarchy and phase
The Batch Hierarchy and Phase is used to view phases within the batch hierarchy.

Journal
The Batch Event Journal is used to view batch events in a tabular format.

List
The Batch List view is used to add and control batches.

Manual phase toolbar
When linked to the Batch Hierarchy and Phase Control elements, the Batch Manual Phase Toolbar allows DeltaV Live users to manually control phases.

PFC
When linked with either the Batch PFC Command toolbar object or the Batch Step List object (or both), the Batch PFC allows DeltaV Live users to execute active step changes.

PFC Command toolbar
When linked with either the Batch PFC or the Batch Step List, the Batch PFC Command Toolbar allows DeltaV Live users to execute active step changes.

Prompts
The Batch Prompts is used to view and acknowledge batch runtime prompts.

Step list
When linked to the Batch PFC Command toolbar element and the Batch PFC element, the Batch Step List allows DeltaV Live users to execute active step changes.
