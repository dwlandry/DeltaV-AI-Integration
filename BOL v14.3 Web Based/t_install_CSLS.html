Install CHARMs Smart Logic Solvers onto the carrier

CHARMs Smart Logic Solvers (CSLS) install in the CSLS Carrier.

  1. Align the shallow opening on the bottom of the CSLS with the tab on a carrier slot and align the top of the CSLS with the housing on a carrier slot.


  2. Push the CSLS to snap it into the slot. Install two CSLS for redundancy.
  3. To remove a CSLS, depress the button on the top of the CSLS and pull it out of the slot.
