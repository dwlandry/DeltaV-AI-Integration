ParameterName function

ParameterName() extracts the name of a specified parameter from a DeltaV parameter path string.
Arguments
1
Argument Description
path string A full or partial DeltaV parameter path.
Return values (string)
The substring preceding the first field delimiter, when only a field delimiter (.) is present.
The substring following the last block/parameter delimiter, when one or more block/parameter delimiters (/) are present.
The substring between the last block/parameter delimiter and the first field delimiter, when one or more block/parameter delimiters (/) and a field delimiter (.) are present.
An empty string, otherwise.
Syntax
DLPATH.ParameterName(path string)
Examples
The following examples demonstrate how to extract a parameter name and show it as the label on a text element.
Example Result 
DLSYS.Text1.Label = DLPATH.ParameterName("ZONE1%FIC101/PID1/MODE.ACTUAL.STR")
 Returns "MODE" as the label text. 
DLSYS.Text2.Label = DLPATH.ParameterName("THISUSER/ALMCNT[12][15].CV")
 Returns "ALMCNT[12][15]" as the label text. 
DLSYS.Text3.Label = DLPATH.ParameterName("TIC200/BLK1/BLK2/OUT")
 Returns "OUT" as the label text. 
DLSYS.Text4.Label = DLPATH.ParameterName("ALARMS[1].PRI")
 Returns "ALARMS[1]" as the label text. 
DLSYS.Text5.Label = DLPATH.ParameterName("LIC330")
 Returns "".
Note:
  • If the argument path is an ambiguous partial path, a block name may be returned.
  • If the argument path includes array parameter syntax, that syntax is included in the result to specify the parameter element.
