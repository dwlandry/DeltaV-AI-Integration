exp function

The exp function commands DeltaV Live to return the value of E to the power of x.
Arguments
1
Argument Description
x A number.
Return value
A number representing ex, where e is Euler's number.
Syntax
Math.exp(x)
Examples
Example Result 
var Num = DLSYS["U012-FICA-5625-C/DIFF.CV"];
this.Label = Math.exp(Num);
 Returns "1.648...". 
Math.exp(-1)
 Returns "0.36787944117144233".
