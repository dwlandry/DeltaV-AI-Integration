Using parameters

You can include a unit parameter in a transition condition. Each unit has physical characteristics, such as the speed of the motor, the size of the tank, and so on. To represent these characteristics, parameters are defined for each unit.

When you include a unit parameter in a Boolean condition, use one of the following:

'unitname/parametername'
'unitname/parametername' operator value

You can specify a unit parameter in a Boolean condition whenever moving from one step to another depends on a value represented by the unit parameter. For example, suppose an operation requires the speed of the mixer to be running at 500 RPM or higher before adding any ingredients.
