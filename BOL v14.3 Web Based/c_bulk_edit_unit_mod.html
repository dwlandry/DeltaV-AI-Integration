Bulk editing unit modules

Unit modules can be contained in process cells, and can in turn contain equipment modules and control modules.

When you create the specification file you must specify a subtype. Use the Browse button to browse to the instance of the unit module you want to export.

The unit_mod_class field must be included if the process cell is in a batch application.

Classes you enter in the unit_mod_class field must already exist in the database. If you do not enter a unique equip_id value the import assigns a unique ID. 

To create the unit module in a process cell, include the process cell name in the area field in the form AREA/PROC_CELL.  If the area you specify does not exist, the process cell is imported into AREA_A.
