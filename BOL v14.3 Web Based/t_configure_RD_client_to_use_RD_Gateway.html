Configure the Remote Desktop client

The Remote Desktop client is the computer that will connect to the DeltaV workstation using Remote Desktop Connection by going through the Remote Desktop Gateway.

You must have an SSL-compatible x.509 certificate that was exported from your Remote Desktop Gateway (RD Gateway) computer. If you do not have one, please return to the previous sections on the certificates.

  1. Configure the TCP/IP properties of the NIC that will connect to the Remote Desktop Gateway server (see table of network addresses you created earlier).
  2. Connect this NIC to the appropriate switch/hub/firewall (based on in your network map).
  3. Copy the Remote Desktop Gateway's server certificate to the RD Client computer and make note of where you copy it to.

    The certificate is exported from the RD Gateway server to the default location of c:\users\administrator\Documents\RDG-SRV.cer (where RGD-SRV is the name of our example Remote Desktop Gateway machine).

    Note:

    You can also install the certificate when the RD Client computer connects to the RD Gateway. Remote Desktop Connection informs the user that the certificate is not installed and prompts if you want to install it then. However, to be sure that the correct certificate is used, it is strongly recommended that you configure the clients with the appropriate certificate before connecting to the DeltaV node.

  4. Install and establish a root certificate trust for on the Remote Desktop client.
