Installing a Redundant Controller

Note:

A simplex controller cannot be made redundant by using the following steps after VCAT is enabled.

  1. Assign an appropriate redundancy license to the simplex controller you want to make redundant in DeltaV Explorer.
  2. Insert the power supply module into the right power module slot in the P-series carrier.
  3. Insert a matching controller into the right slot of the P-series carrier. The controller type must match what is already installed.
  4. The added controller's Power LED should turn on and the Error LED should blink for a few seconds. The newly inserted controller must go through its power on self test.
  5. Download the ProfessionalPLUS workstation in DeltaV Explorer.
  6. Download the setup data to the controller. The LEDs will flash appropriately. Wait for all LEDs to return to a steady green light. The Standby Controller is now ready to take over if the Active Controller fails.
