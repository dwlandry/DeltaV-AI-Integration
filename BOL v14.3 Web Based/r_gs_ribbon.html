Publish graphics configurations (deploy them online.) Graphics
All Publish menu options open the Publish dialog. In the following descriptions, the word eligible indicates configurations that have publishable changes pending.
  • Publish > Publish - Publish eligible graphics configurations that are directly selected (in either the Explorer pane or as an active tab).
  • Publish > Verify and Publish - Verify that the selected graphics configurations contain no errors and then publish them.
  • Publish > Publish x Contained - Publish all eligible graphics configurations contained in the selected parent folder.
  • Publish > Publish All Pending - Publish all eligible graphics configurations.
  • Publish > Re-Publish - Re-publish the active graphics configuration. Use this option to publish configurations that do not have publishable changes pending.
  • Publish > Un-Publish - Remove a published graphics configuration from online.

Format / Display Set Tools tab

This table describes the commands available in the Format / Display Set Tools tab when a display set is selected as the active tab.
Action Ribbon group Additional information

Organize displays in the navigation hierarchy of a display set.

  • Add Display - Add a placeholder to the navigation hierarchy for a level 2, 3, or 4 display.
  • Add Overview - Add a placeholder to the navigation hierarchy for an overview display.
  • Promote - Move the display up one level in the hierarchy.
  • Demote - Move the display down one level in the hierarchy.
  • Move Up / Move Down - Move a display up or down in the display sequence while maintaining the hierarchy level.
Organize
