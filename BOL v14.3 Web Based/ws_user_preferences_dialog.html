The User Preferences dialog

Select User Preferences from the Workspace menu to open the 8-page User Preferences dialog . This dialog can be used to quickly configure many settings for the DeltaV Operate environment.

Picture, Shape, and Chart Preferences

Picture preferences include the default size and background color of new pictures, whether they should have a title bar and system bar, and whether they should be resizable. (Note that these preferences apply only to new pictures that are not created from templates, such as the main template.)

Shape preferences let you specify the default foreground, background, and edge color of new objects in a picture. You can also specify the default font, point size, fill style, edge style, and edge width.

Chart preferences let you select the defaults for chart objects. These defaults include the number of ticks per axis, the number of labels per axis, the direction in which the chart scrolls, and the length of time the chart displays.

Auto-Save Backup Files

Each time you save a file, DeltaV Operate copies the previous version to a back-up subfolder and saves the new version. If a back-up file already exists for the current file, the new back-up replaces it.

Back-up subfolders reside inside the system tree folders but do not appear in the system tree. For example, the Pictures back-up subfolder resides inside the Pictures folder and contains back-ups of modified pictures.

Depending on the amount of free disk space you have and the size of your pictures, you may want to disable the back-up option to save space.

Run-Time Preferences

You can set several run-time preferences using different tabs on the User Preferences dialog. The changes to run-time preferences take effect the next time DeltaV Operate is started.

  • Saving your open documents automatically when you switch to the run-time environment - Using this feature, you can toggle between the configure and run environments without worrying about saving your changes. By default, this option is disabled. If you enable it and want to test a change to a picture or schedule without saving the modification, you must disable the preference before switching to the run-time environment. If you do not, DeltaV Operate automatically saves the change.

  • Displaying DeltaV Operate full-screen - This feature provides maximum screen space for creating and displaying pictures. When you display DeltaV Operate full-screen, it hides its menu bar, system tree, and any docked toolbars. Floating toolbars remain visible.

  • Opening specific pictures automatically when DeltaV Operate starts in the run-time environment - Use this option to define the specific pictures you want to open automatically for your operators.

  • Opening specific schedules to run in the background - Use this option to indicate the files you want the FixBackgroundServer task to load on start-up.

Startup Mode Preference

On the General tab you can specify whether you want DeltaV Operate to start in configure or run mode. By default, DeltaV Operate starts in configure mode. However, when you have finished configuration tasks, you may want to configure DeltaV Operate to start in the run mode automatically.

Defaults for Animation Data Errors

Each animated object in a picture uses OPC protocols to receive data and report errors. The animation error preferences define the default error strings and values that the object uses when an error occurs. For example, by default, when a communication error occurs, Data links display the text "@@@@".

You can customize the animation error defaults by entering new values in the Animations Data Error Defaults tab. By changing the defaults, you make the default error messages more intuitive for your industry. For example, when a communication error occurs, you can have Data links display the following text by entering it into the Comm field of the Format Animation Object Defaults area:

Cannot communicate with server
