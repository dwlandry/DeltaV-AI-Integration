Groups overview

When you use the Group command to group one or more graphics elements, a group element is automatically created. The elements used to create the group are nested within the group element and become members of that group. Group elements provide several advantages, such as allowing you to perform certain configuration-time behaviors that apply to all members of the group, like moving together or rotating together. A group also contains its own configurable properties that apply to the group as a whole. Another advantage groups provide is that, by default, they are not published with their containing graphics configuration and therefore do not consume resources online. If you do want to include the group when publishing the configuration, mark it as Present Online during configuration

Groups can also be nested under other groups, and you can add other graphics elements to an existing group using the element's context menu in the Selection pane.

Selection behavior

When a group is selected, you can configure the properties that apply to the group as a whole, such as the group's height or width. You can also select an individual member of the group and configure the properties for only that member. When a member of a group is selected, that member's bounding box is visible and the group's bounding box shows as a dashed line.

Additionally, you can configure the properties for all members of the group or certain members of the group simultaneously by multi-selecting all of the group members. For example, you can configure all the members to be red by multi-selecting them and selecting red as the fill color.

Performing group commands

Interaction areas

Actions can be configured for the group, selected group members, or both. In Graphics Studio, the interaction area for a group is the bounding box that encompasses all elements in the group and that are configured to be present online. Online, the interaction area automatically resizes based on the current size and position of all elements in the group. When actions are configured for individual elements in a group, the group's interaction area is lower, by default, in the z-order than that of its members' interaction areas.
