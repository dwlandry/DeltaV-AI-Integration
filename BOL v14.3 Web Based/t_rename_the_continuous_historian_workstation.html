Rename the Continuous Historian workstation

  1. On the Continuous Historian workstation, select Start > Settings > Control Panel > Administrative Tools > Services.
  2. Stop the DeltaV services (including DVCHScan.exe, DVHistorianserver.exe andDVHistorianserver_2.exe.
  3. Run the Continuous Historian Administration application.
  4. Create a new Active dataset. This allows you to export the currently Active dataset.
  5. Export all Current and Extended datasets to the local drive.
  6. Close the Continuous Historian Administration application.
  7. Rename the workstation.
    Note: Restarting the workstation after running DeltaV Workstation Configuration will restart the DeltaV services on this computer.
  8. Stop the DeltaV services again.
  9. Rename the existing Continuous Historian database directory (for example, DeltaVHistory to DeltaVHistory-old).
  10. Copy the C:\DeltaV\fdbhist directory and paste it as the new D:\DeltaVHistory.
  11. Open a Command Prompt window and run the following Objectivity command to register the new database for use: 
    C:\ooinstallfd -nocheck -standalone -lockserverhost COMPUTERNAME X:\DeltaVHistory\DvCHdb.hdb
    where COMPUTERNAME is the new name of the Continuous Historian workstation and X: is the drive where the \DeltaVHistory folder exists.
  12. Reboot the machine.
  13. Run the Continuous Historian Administration application.
  14. Restore all the exported datasets.
