Downloading CHARMs Smart Logic Solvers SIS system components

SIS Controller

Downloading an SIS controller does not download the CSLSs in the Local Safety Network. Downloading the SIS controller also downloads:
  • CHARMs assigned to CIOCs that need to be downloaded.
  • Devices assigned to WIOCs that need to be downloaded.
  • Remote I/O cards on the Remote I/O node.

CHARMs Smart Logic Solver

Note:

Downloading a logic solver may result in a value and/or status change of non-secure parameters. The effect on production depends on what the references for the non-secure parameters are used for.

The CHARMs Smart Logic Solver (CSLS) supports only total downloads. You cannot download individual SIS modules or LS CHARMs.

CRCs are maintained for the CHARM I/O configuration, each SIS module, and the overall configuration. When a download results in a difference to the overall CRC you are prompted that a download change was detected and that a full functional test of the SIF may be required. You can then check the SIS module and I/O CRCs to determine if a functional test is really required and what the scope of it may be.
