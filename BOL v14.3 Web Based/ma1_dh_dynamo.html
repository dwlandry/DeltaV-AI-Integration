MA1_DH_ analog dynamo, 1 function block, horizontal deviation bar graph

This dynamo can be used for loop indication of PID loops where deviation from SP is important.

The following elements are present on the dynamo:

  • Alarm Box

  • Alarm Icon

  • Display Tag

  • Dynamo Background

  • Engineering Units Descriptor

  • Mode Icon

  • OUT Bar Graph

  • PV and SP Data Fields

  • PV-SP Deviation (comparison) Bar Graph

  • Ramp Status Icon

  • Status Box

  • Status Icon
