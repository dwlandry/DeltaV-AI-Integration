Lab Entry function block Operator Keyboard faceplate (LAB_FP_KB)

DeltaV Operate View of the Lab Entry Function Block Operator Keyboard Faceplate (LAB_FP_KB)

The Lab Entry Function Block Operator Keyboard faceplate contains the following items:

  • Sample Time – This field displays the time the last sample was taken.

  • Sample Value bar graph – This field indicates the value of OUT, which is the same as the value displayed in the Sample Value field.

  • Sample Value – This field displays the value of the last sample taken. The background color of the field changes from gray to orange or red when the status becomes uncertain or bad, respectively.

  • Detail Display button – This button opens the detail display for the Lab Entry block.

  • Trend Display button – This button opens the trend display for the Lab Entry block. A trend display is a popup picture that shows a one second trend trace for each of the module's main operating parameters. The trend traces start when the picture is opened and stop when it is closed.
