Create the Independent DeltaV Domain Controller

This procedure creates the Independent DeltaV Domain Controller (either primary or additional domain controller) for use with a DeltaV domain-based system.

Before starting the installation, consider the following:
  • The built-in administrator account cannot be used when creating the Independent DeltaV Domain Controller.
  • The network cards should all be named to match your DeltaV ACN, like DeltaVPrimary and DeltaVSecondary. This will simplify selecting the network cards later.
  1. Log on to the computer as a local administrator that is not the built-in administrator.
  2. Insert the DeltaV installation media.
  3. Select Set Up Independent DeltaV Domain Controller from the menu.

    If the menu does not appear, browse to the DeltaV media's DV_Extras\IDDC folder.

    Right click and select Run as administrator from the context menu.

  4. Fix any issues found (for example, a pending reboot needed).
    1. Cancel setup.
    2. Fix the errors.
    3. Restart setup.
  5. Select one of these choices:

    • Add a new forest - Select this when you are creating the first domain controller for the DeltaV domain (the domain will not exist until the primary domain controller is established).

    • Add a domain controller to an existing domain - Select this when you are creating an additional (backup) domain controller and adding it to the existing DeltaV domain.

  6. Click Next.
  7. Complete the information needed.

    • When creating a new domain, you are providing to the setup application the information about what to name the domain and what network cards to configure.

      A fully qualified domain name. This names the domain. The format is DeltaV system name.System.company name.local (Where DeltaV system name, System, and company name are names you provide).

    • When joining an existing domain (for the additional domain controllers), you are giving the software the location of the existing domain controller (as a fully-qualified domain name) and what network cards to configure.
    Important: Only select the DeltaV ACN network cards for your domain.
  8. Click Next.

    An estimate of the time is given.

  9. Click Continue to start the configuration and installation of needed components. If you do not click Continue, the installation will start in the time listed (counted down).
  10. Enter the Directory Services Restore Mode (DRSM) password.
    Note:

    The Directory Services Restore Mode (DSRM) password is required to be able to perform a safe mode boot option on your domain controller. DSRM allows an administrator to repair or restore an Active Directory database.

  11. Once promoted to a domain controller, a restart is required. Click Restart Now.
  12. Log in using the domain administrator. This is the same account name prefaced with the domain name (myDomain\MyUserName).

    The account you logged in as to run the Independent DeltaV Domain Controller setup application was promoted to be a domain administrator when the computer was promoted to a domain controller.

    A time estimate is displayed.

  13. Click Continue to proceed with the remaining steps.
  14. Once the accounts are created, a restart is required. Click Restart Now.
  15. Log in as the same domain administrator.
  16. Enter a password for the DeltaV Services account. This sets the password for the account and click OK. The setup application continues setting the NTP services and installing any operating system updates.
  17. Once complete, review the results and click Close on the setup window.
You can now create additional domain controllers or install DeltaV workstations and join them to this domain.
