Using OPC

This section describes user and system requirements to successfully interface to OLE for Process Control (OPC) servers for DeltaV software. DeltaV supports version 2.05A of the OPC Data Access (OPC DA) server. For more information, refer to OLE for Process Control Data Access Custom Interface Standard Version 2.05A.

An OPC server for DeltaV software provides an interface to the run-time and historical databases in a DeltaV control network. OPC is based on Microsoft Component Object Model (COM) and .NET technology. Through this technology, a DeltaV OPC server gives programmers the ability to perform the following tasks:

  • Connect to a DeltaV OPC DA server
  • Connect to a DeltaV OPC Historical Data Access (OPC HDA) server
  • Connect to a DeltaV OPC Alarms and Events (OPC AE) server
  • Connect OPC servers together through DeltaV OPC Mirror
  • Read and write to DeltaV runtime data
  • Read and write to the DeltaV Continuous Historian
  • Request exception reporting
  • Browse for available data fields
  • Use Microsoft Windows Communication Foundation (WCF) and .NET methods for user authentication and authorization
