ALM_STATISTICS module template

The Operator Statistics module template (ALM_STATISTICS) is used to gather and compute statistics for active, shelved, stale and acknowledged alarms. The ALM_STATISTICS module requires some additional configuration in order to set it up; it is intended that the module will be configured by an experienced DeltaV control engineer familiar with Visual Basic and DeltaV Operate (Configure) schedules.

The ALM_STATISTICS module template consists of an action block (SYSTEM-TIME), a calculation block (KPI_CALC) and a schedule (ALM_STATS_CALC.evs) for the DeltaV Operate Scheduler. The SYSTEM-TIME block parses the system time while the KPI_CALC block computes the sum and average of active, shelved, stale and acknowledged alarms. There are four input blocks (MM, DD, HH, YYYY) that are wired to the input parameters on the KPI_CALC block.
  • IN1 -> MM (Months)
  • IN2 -> DD (Days)
  • IN3 -> HH (Hours)
  • IN4 -> YYYY (Years)
The schedule allows for periodic reading of alarm statistics. It includes an event based entry that counts the active, shelved, stale and acknowledged alarms and is triggered every 1 a.m. and 1 p.m. of each day. The counted alarms are then used to compute the alarm averages in the Operator Statistics Module. ALM_STATS_CALC.evs is a background schedule run by FixBackgroundServer.exe and therefore must be added manually to the Scheduler in DeltaV Operate Configure. ALM_STATS_CALC.evs is located in DeltaV > DVData > Graphics-iFix > PDB.
Warning:
  • When upgrading from one build to another build, ALM_STAT_CALC.evs is removed from the background schedule and must be re-added to the schedule after the upgrade.

The ALM_STATISTICS module template includes the following parameters:

Parameters for the ALM_STATISTICS module template
Parameter Description
ACK_ALM_AVG

The calculated average of acknowledged alarms for last month which is computed in the CALC block.
The ACK_ALM_KPI is result of this expression:

'^/SUPP_ALM_SUM.CV' / SNAPSHOT_CNT.CV;
ACK_ALM_SUM Running total of ACK_ALMS computed every 1am and 1pm of each day of the month. ACK_ALM_SUM resets to 0 at the beginning of each month.
ACK_ALMS Acknowledged alarms count
ACTIVE_ALM_AVG

The calculated average of active alarms for last month which is computed in the CALC block.
The ACTIVE_ALM_KPI is result of this expression:

'^/ACTIVE_ALM_SUM.CV' / SNAPSHOT_CNT.CV
ACTIVE_ALM_SUM Running total of ACTIVE_ALMS computed every 1am and 1pm of each day of the month. ACTIVE_ALM_SUM resets to 0 at the beginning of each month.
ACTIVE_ALMS Active alarm count (up to 250 alarms)
DD

Parsed LOCALTIME by the SYSTEM-TIME block.
DD - Days
HH

Parsed LOCALTIME by the SYSTEM-TIME block.
HH - Hours
LOCALTIME System time in seconds parsed by the SYSTEM-TIME block
MM

Parsed LOCALTIME by the SYSTEM-TIME block.
MM - Months
MONTH_RPT_DONE Flag to indicate if the average has already been computed for the month
SCHED_STAT_CURR Flags to indicate if the scheduler (which updates ACTIVE_ALMS, SHELVED_ALMS, ACK_ALMS and STALE_ALMS) is still running.
SCHED_STAT_PREV Flags to indicate if the scheduler (which updates ACTIVE_ALMS, SHELVED_ALMS, ACK_ALMS and STALE_ALMS) is still running.
SHELVED_ALM_AVG

The calculated average of shelved alarms for last month which is computed in the CALC block.
The SUPP_ALM_KPI is result of this expression:

'^/SUPP_ALM_SUM.CV' / SNAPSHOT_CNT.CV;
SHELVED_ALM_SUM Running total of SHELVED_ALMS computed every 1am and 1pm of each day of the month. SHELVED_ALM_SUM resets to 0 at the beginning of each month.
SHELVED_ALMS Shelved alarms count
SHIFT_ADD_DONE Flag to indicate if the sum has already been computed on 1am or 1pm. This is to make sure that the sum will only be computed once during 1am or 1pm.
SNAPSHOT_CNT Number of times the sum for the four alarms types have been computed for the month. This will start at 0 at the beginning of each month and increments every time the sum is computed.
STALE_ALM_AVG

The calculated average of stale alarms for last month which is computed in the CALC block.
The STALE_ALM_KPI is result of this expression:

'^/STALE_ALM_SUM.CV' / SNAPSHOT_CNT.CV;
STALE_ALM_SUM Running total of STALE_ALMS computed every 1am and 1pm of each day of the month. STALE_ALM_SUM resets to 0 at the beginning of each month.
STALE_ALMS Stale alarms count (active alarms for more than 24 hours)
STATION_NAME Node where Operator Statistics Module is Assigned
YYYY

Parsed LOCALTIME by the SYSTEM-TIME block.
YYYY - Years

Open the module in Control Studio Off-Line mode to modify the module parameters and in Control Studio On-Line mode to view the current values of the module's parameters.
