Configuring custom or array PLC tag definitions

Prerequisites:

  • In the System Preferences application under Networking, select Ethernet I/P Integration with Tags.

  • Export control tag definitions from the PLC. For Rockwell devices, this is a .L5X file.

  • Copy the file you exported from the PLC to the ProfessionalPLUS. You can place the file anywhere on the workstation. When you configure the physical device later in the configuration process, the software copies it to the DeltaV\DVData\ControlTags folder.

  1. In DeltaV Explorer, navigate to DeltaV_System > Library > PLC Tag Definitions.
  2. Right-click Rockwell Logix, then click New PLC Tag Definition. The software displays the New Control Tag Definition dialog.
  3. Select the Tag Type (Custom or Array).
  4. Click Browse for file.
  5. Select a PLC definition file, then click Open.
  6. Click Browse for definition. The software displays the Add-on instruction definitions available in this file.
  7. Select a definition from the top selection box. The software displays the parameters for the selected definition in the bottom selection box.
  8. Select as many as 10 parameters (for a custom-type definition). Select one parameter for an array-type tag. Array tags can have one parameter with 2 to 64 elements (non-string data types) or 10 elements (string data type).
  9. Click OK on the selection dialog.
  10. Click OK on the New Control Tag Definition dialog.
    Tip: The New Control Tag Definition dialog also supports a manual Add button. This enables you to add a specific parameter if do not have a PLC definition file at this time but you know the valid parameter names.
  11. Browse to or create an EIOC. Make sure the EIOC port protocol is set to Control Tag Access and a physical and logical device are present.
  12. Right-click the EIOC's logical device, then click New Ethernet I/O Control Tag. The software displays the New Control Tag dialog.
  13. From the Tag Definition list, click the custom tag definition you created in this procedure. The software creates the definition tags, tag signals and device tags under the logical device. You can reference the device tags in your control logic.
  14. If you configured an L5X file, click the Browse button next to the Tag Name field to select a name. The software displays the tags of the selected type (if any exist in the file).
  15. Connect the PLC to the EIOC port.
  16. Download the EIOC card.
