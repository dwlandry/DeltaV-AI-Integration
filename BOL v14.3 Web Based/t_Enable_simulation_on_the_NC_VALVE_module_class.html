Enable simulation on the NC_VALVE module class

  1. Open DeltaV Explorer.
  2. Navigate to the NC_VALVE control module class under the DeviceControl category in the Advanced Definitions section.
  3. Right-click NC_VALVE, and then select Configure from the context menu.
  4. Select the Parameters tab.
  5. Click Add.
  6. Browse to DC1/SIMULATE_D, and then click OK.
  7. Select the DC1$SIMULATE_D parameter and click Modify to open the Properties dialog (or double-click the parameter name).
  8. Select Enabled under Simulate Enabled/Disabled.
  9. Click OK on the Properties dialog, and then close the Configure dialog.
