The serial port interface to the Smart Switch

The recommended way to interact with DeltaV Smart Switches is through the Network Device Command Center (NDCC). However, if you must make the following changes, you will need to use the serial port interface.

  • admin account password.
  • user account password.
  • the local offset to Universal Coordinated Time.

If you need to change other switch settings use the Network Device Command Center (NDCC) or configure the switch module classes or instances.
