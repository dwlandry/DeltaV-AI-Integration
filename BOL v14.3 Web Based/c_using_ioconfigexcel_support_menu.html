Using the SmartPlant Add-in I/O support menu

The DeltaV > I/O Support menu provides an interface to move configuration information between the Excel workbook and the DeltaV database. 

The Deltav_Xl_Support Add-in that creates this menu creates a local in-memory copy of the DeltaV database controller configuration (the Database Snapshot). The add-in manages and refreshes the snapshot based on your actions while you work in Excel. The add-in preserves the snapshot if you save the workbook before you close Excel. When you re-open Excel you can open the saved Database Snapshot.
