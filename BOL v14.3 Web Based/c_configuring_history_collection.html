Configure history collection

History collection is the definition of the module parameters or node parameters to be monitored and stored by the Continuous Historian subsystem. History tags are strings that uniquely identify a data source for which historical data can be captured. In the DeltaV system, history tags are the full path string that identifies a DeltaV parameter and field. There is at most one history collection configuration for any DeltaV parameter/field history tag. History collection can be defined using the DeltaV Explorer or Control Studio. Users assign areas to the Continuous Historian subsystem in the DeltaV Explorer to complete the association to the specific historical data server.

History collection configuration belongs to the module or node. If you copy a module, the new module includes the history collection from the original module. Library template modules also include history collection. Creating a module from a library template copies the history collection configuration to the new module. You can add to or modify the history collection configuration.

Because a DeltaV system can contain more than one historian, including the DeltaV Continuous Historian, the Advanced Continuous Historian, or OSIsoft PI Server, the history collection configuration for a history tag can be used by more than one type of historian at the same time.

Important:
When naming modules to be historized in the Advanced Continuous Historian or a PI Server enterprise historian, follow these rules:
  • The tag name must be unique.
  • The beginning character of the tag name must be an English alphanumeric character, underscore (_), or percent sign (%).
  • A tag name begining with a hyphen (-) or dollar sign ($) character is supported; however, DeltaV prepends the character x to the beginning of the tag name.

To evaluate the comprehensive configuration for DeltaV history collection, right-click the Continuous Historian subsystem for the workstation in DeltaV Explorer, and then select History Collection from the context menu. This opens the History Collection (Read-Only) window, listing all historical values to be collected for the historian installed on this workstation.

Selecting a node before clicking History Collection provides access to node parameter fields. Selecting an area or module before clicking History Collection provides access to module parameter fields.
