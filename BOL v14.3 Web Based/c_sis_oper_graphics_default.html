DeltaV SIS operator graphics

This section contains information on DeltaV Operate as it pertains to DeltaV SIS systems.

The DeltaV SIS operator graphics documentation builds on the DeltaV documentation as described in the Books Online topics under Operator Basics and Graphics Configuration. The information in this section documents only the features in DeltaV SIS systems that are unique or different than those in the standard DeltaV system. It includes descriptions of SIS function block dynamos, module dynamos, faceplates, and alarm summary display.

In DeltaV Operate configure mode, the SIS building blocks are available and visible regardless of whether SIS has been enabled as a system preference.

In DeltaV Operate run mode, SIS pieces become visible when either of the following is True:

  • SIS display objects have been created on pictures.

  • SIS modules and/or Logic Solvers in the runtime system have active or unacknowledged alarms.

The SIS related items in DeltaV Operate include the following:

  • Dynamos associated with SIS function blocks

  • A faceplate display for SIS function blocks

  • A generic faceplate for SIS modules

  • A faceplate for Logic Solvers

  • A faceplate display for SIS HART devices

  • An alarm list display for SIS alarms (SIS modules and Logic Solver device modules)
