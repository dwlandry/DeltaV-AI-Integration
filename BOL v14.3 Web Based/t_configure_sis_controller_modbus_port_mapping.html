Configure SIS Controller Modbus port Data set mapping

This topic assumes you have already configured registers from the Modbus Port Properties dialog. You can map registers interactively from DeltaV Explorer using the Register mapping dialog. However, because of the potentially large numbers of register to map it is recommended that you use Bulk Edit to map registers initially.

To map registers from DeltaV Explorer:

  1. Select the Modbus port.
  2. Right click and select Map Registers.
  3. On the Register mapping dialog, select a register to map and click the Map button.
  4. On the Map Register dialog, browse to the parameter to map the selected register to.
  5. Click OK to accept the mapping and close the dialog.
  6. Repeat steps t_configure_sis_controller_modbus_port_mapping.html#task_51B674B970AF4F56901608D74F08397E_unique_122__step_A72D8824F64A4A7C805E0E2C7BAFEE03 through t_configure_sis_controller_modbus_port_mapping.html#task_51B674B970AF4F56901608D74F08397E_unique_122__step_8CCD3662A82D46188849E7C2755CB1F0 for other registers you want to map.
  7. Click Close on the Register mapping dialog to accept your changes.
