Campaign Manager toolbar icons

The Campaign Manager toolbar is a group of icons used to perform tasks in Campaign Manager. Tool tips are enabled on all icons; pausing your cursor over an icon will display the name of the icon. The icons are not always active. Their availability depends on the object selected in the hierarchy and the current state of the object. The following table describes the icons and the functions or commands they represent.

Campaign Manager Toolbar Icons

New Campaign

Opens the Create Campaign dialog where you specify the details for a new campaign, including the name of the campaign, the number of batches, and the base recipe to be used. On this dialog, you can also specify that a setup batch and/or cleanup batch will be added to the campaign.

Remove Campaign

Removes the selected campaign from the campaign list in Campaign Manager.

Terminate Campaign

Terminates the selected campaign. No additional batches can be released to the Batch Executive. Any batches that have already been released continue to be under control of the Batch Executive and can only be accessed by the operator through the Batch Operator Interface.

Campaign Properties

Displays the Properties dialog, from which you can change the campaign execution mode. You can also view the base recipe details by clicking the Details button on the Properties dialog.

Manual Mode

Specifies that batches are to be released and started manually (by the user or an external program). Batches must be released in order.

Auto Release Mode

Specifies that batches are to be released automatically to the Batch Executive. Only one batch from a campaign will be released at a time. The batch must be started manually (by a user or external program).

Auto Start Mode

Specifies that each batch in the campaign is to be released automatically to the Batch Executive. A released batch is started automatically if the number of active batches within the campaign is less than the maximum number of active batches defined for the campaign.

New Batch

Adds a batch to the selected campaign. The new batch is given the next available Batch ID at the end of the current sequence.

Delete Batch

Deletes the selected batch from the campaign.

If a batch is on the Batch Executive batch list, it must be removed before it can be deleted. Once a sequence number has been deleted, it cannot be reentered. If a new batch is added, it is given a Batch ID at the end of the current sequence, skipping any previously used numbers.

Add a User Comment

Displays the Add Comments dialog. You can add a comment to a campaign or a batch. When adding comments to a batch, it must be in an active state. Previous comments are saved and displayed on this dialog.

Add Batch to Executive

Releases the batch to the Batch Executive.

The campaign must be in Manual mode for the user to be able to manually release the batch to the Batch Executive.

Start Batch

Starts a batch that has been added to the Batch Executive manually. Only batches that are in Manual mode and in the Ready state can be manually started.

Remove Batch from Executive

Removes the batch from the Batch Executive.

The campaign must be in Manual mode for the user to be able to manually remove the batch from the Batch Executive. The batch must have completed normally in order to remove it manually from the Batch Executive using the Campaign Manager.

Batch Operator Interface

Opens the Batch Operator Interface, which allows the operator to control most batch operations, such as starting, stopping, and restarting batches.

Help Topics

Displays online help for the Campaign Manager application.

Online Books

Opens Books Online, which contains DeltaV system reference information.
