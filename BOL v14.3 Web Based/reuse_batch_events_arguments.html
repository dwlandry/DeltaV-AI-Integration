REUSE_Batch events arguments

Argument Description
object An object expression that evaluates to a control in the Controls applied to list.
bstrExecutive The connected to Batch Executive name.
bstrCreateId The unique ID of the selected (active) batch.
bSuccess The result of the requested command.
bstrStatusMessage Information regarding the cause of failure if the request did not succeed.
bstrBatchId The ID of the Batch.
bstrPath The path of the step.
bstrName The name of the equipment item selected in the NeededBy list.
iResourceID The Equipment ID for the selected item.
iResourceType An integer, 0-9, identifying the resource type. 0 - Operator 1 - External 2 - DeltaV Batch 3 - Phase logic module 4 - Unit phase 6 - Unit module 7 - Process cell 8 - Area 9 - Other
bstrRecipe The recipe name.
bstrFormula The formula name.
actionResult The result of the action.
1SelectedRow
1SelectedCol
bIsSuccess
bstrMessage
bstrPhase The name of the selected phase. Unit phases are represented as UNIT/PHASE. PLMs are represented as PHASE.
iPhaseID The arbitration ID of the selected phase.
bstrItem
1Type
bstrJournalFile
bstrModule
The module name for which the user has requested the primary control display to be shown.
Note: This parameter is valid for the ShowControlDisplay events on multiple monitor systems only.
lMonitor

Determines which monitor shows the primary control display. Use 0 to show the primary control display on the same monitor. It is 1 to show the primary control display on the opposite monitor.

bstrStep The step name.
bstrUnit The unit name.
bstrAlias The recipe alias.
bOOS Indicates whether the unit is or is not Out of Service.
lCommandMask The set of valid commands.
lState The set of valid states.
lMode The mode of the step.
lBatchState The state of the batch.
lBatchMode The mode of the batch.
bstrTransition The name of the selected transition
bDisabled The status of the transition. (Disabled = True, Enabled = False)
