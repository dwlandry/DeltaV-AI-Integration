Create and instantiate an example template

Follow these steps to create a template from the class, then create an instance of the module from the template.

  1. Drag the TTLZER_CL equipment module class to a category under Module Templates.

    The Module Templates hierarchy should look similar to the following figure.

    Note that the text in the parentheses next to the contained modules' name is the name of the contained modules in the TTLZER_CL class. To determine the class a module or template is based on, right-click the module or template and select Properties. The Class name field contains the class the module or template is based on.

  2. Rename the module template TTLZER_CL_1 to TTLZER_TMP (for template).

  3. Select TTLZER_TMP.

  4. Select File > Properties and change the SubType to TTLZER_TMP.

    Note:

    The Subtype must be entered in all capital letters. The user-defined import uses the Subtype to identify the module templates when it creates modules.

  5. Rename FLO_CTRL_CNT1 to FLO_CTRL_TMP.

  6. Set the FLO_CTRL_TMP module SubType to FLO_CTRL_TMP.

  7. Rename TTL_FLO_CNT1 to TTL_FLO_TMP.

  8. Set the TTL_FLO_TMP module SubType to TTL_FLO_TMP.

  9. Create an instance of the template by dragging TTLZER_TMP to AREA_A.

    • Rename TTLZER_TMP_1 to TOTALIZER.

    • Rename FLO_CTRL_CNT1 to FLOW_CONTROL.

    • Rename TTL_FLO_CNT1 to TOTAL_FLOW.
