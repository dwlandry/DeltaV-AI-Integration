Toolbar Builder expert

  Use the Toolbar Builder button from the DeltaV Utilities Toolbar to create toolbars for the operator. Clicking this button opens the following dialog.

Toolbar Builder Dialog

To create a new operator toolbar

  1. Click the Toolbar Builder button on the DeltaV Utilities toolbar.
  2. Give your new toolbar a name.
  3. Select the toolbar template.
  4. Pick a toolbar button set from the available sets.
  5. Select the buttons you want on the operator's toolbar.
  6. Click the right chevron button to move the selected items to your new toolbar list.
  7. If necessary, select a new toolbar template or button set.
  8. Add more buttons to your new toolbar.
  9. Reorder the buttons on your new toolbar by using the up and down arrows.
  10. Remove buttons from your new toolbar by selecting the button and clicking the left chevron button.
  11. Click OK when completed.

The new toolbar is saved in the Pictures > Standard folder of the DeltaV Operate system tree.
