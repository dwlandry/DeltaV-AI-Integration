Module detail displays reference

The following topics provide a description of each module detail display provided with DeltaV Live.
Note: The following detail displays are similar in appearance and function to the PID Loop detail display (Loop_dt), so only Loop_dt is documented:

  • FFLP_dt (Fieldbus Loop module detail display)

  • FLC_dt (Fuzzy Logic Control module detail display)

The detail display images show all of the main components that can be configured on the display. The component descriptions describe the detail display's online behavior.

Subtopics:

  • AALM_dt (Alarm module detail display)
  • AI_dt (Analog Input monitoring detail display)
  • ALM_FLD_SUP_dt (Alarm flood suppression module detail display)
  • ALM_FO_SUP_dt (First-out alarm suppression module detail display)
  • ALM_STATS_dt (Operator statistics module detail display)
  • CDA_dt (Command-driven module detail display)
  • CT_dt8
  • DL_dtx (Motor and valve module detail display)

  • Loop_RAMP_dt (Loop Ramp module detail display)
  • LOOPM_dt (MPC loop module detail display)
