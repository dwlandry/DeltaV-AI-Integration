DeltaV RM1040 Smart Switches

Installation notes

  • The RM1040 Smart Switches can be mounted on a 19-inch rack or on a wall. If the switch is mounted on a 19-inch rack, be sure to install sliding mounting rails to properly hold the switch.
  • Ensure that there is at least one free rack space (approximately 5 cm) above and below the switch because heat is discharged through the switch housing.
  • The RM1040 Smart Switches have a fixed number of ports (16).
  • The RM1040 Smart Switches support redundant input power.

Port information

Port information for the DeltaV RM1040 Smart Switches
Model Number and types of ports Image
RM1040 Smart Switch
  • Sixteen 10/100/1000 mb/s twisted-pair ports with RJ45 connectors
  • Sixteen 100/1000mb/s SFP-based ports

Only one port in each TP/SFP port pair can be used at a time. Either the TP or the SFP port in each of the 16 pairs can be used, so that up to 16 of the 32 ports can be used simultaneously.
