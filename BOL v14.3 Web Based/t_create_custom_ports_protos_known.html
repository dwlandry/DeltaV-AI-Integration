Create custom rules when the ports and protocols are known

It is assumed that you have printed and completed the Worksheet for custom applications.

Note: As you create each custom rule, check to see if the applications are communicating properly. Since these rules are not pre-tested you must exercise the applications to ensure they are communicating and working as expected.
  1. On the firewall's web UI navigate to Configuration > Applications and click the Add new application button.
  2. For each custom application on the Worksheet for custom applications, complete the information requested on the Add new application to the rules drop-down selection list page.
  3. On the Protection tab select either Inbound connections or Outbound connections and enable logging for each application.
  4. Troubleshoot the communication rules if the applications are not working as expected. When you complete the rules using the entries from the pre-built firewall application list, you can create another set of custom rules for applications with unknown ports and protocols or complete the configuration.
