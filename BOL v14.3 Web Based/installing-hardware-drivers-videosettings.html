Setup the display properties

  1. Right click on the desktop and select Personalize.

  2. Click Display Settings to open the Display Settings dialog.

  3. Set the screen resolution, color depth, and refresh rate by monitor:

    • Screen resolution can be:
      • 1024×768 on monitors with the traditional 4:3 aspect ratio
      • 1280×1024 on monitors with the traditional 5:4 aspect ratio
      • 1680x1050 for widescreen monitors with a 16:10 aspect ratio
      • 1920x1080 for high definition 1080p monitors with a 16:9 aspect ratio
      Remember that all screens in a four monitor layout must use the same display resolution.

      Using a display resolution other than the supported resolutions with a display created from the DeltaV Operate templates is not supported. DeltaV Operate opens the display, but the resolution differences causes picture distortion. All standard DeltaV Operate graphics are created from the DeltaV Operate templates.

    • Color depth defaults to 32 bit.

    • Refresh rate should be set according to the type of monitor used. For Flat Panel/LCD monitors, the refresh rate is typically 60 Hz.

    Note:

    If you change the screen resolution, it may be necessary to reset the color depth setting to 32 bit.

  4. Click OK.

Note:

To open DeltaV Operate across all monitors, click the Restore Down button in the upper right-hand corner of the DeltaV Operate window and then hold down the Ctrl key as you click the Maximize button . These steps must be performed every time DeltaV Operate is closed and reopened.

Calibrating and configuring the touch screens

The touch screens must be calibrated and configured before use with the DeltaV Four Monitor workstation. Refer to the 3M TouchWareTM Software for Windows User Guide for complete information on calibrating and configuring the touch screens.
