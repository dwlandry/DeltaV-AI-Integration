CHARM 3-Wire AI Fused Injected Power Terminal Block specifications

Installation notes

  • The CHARM 3-Wire AI Fused Injected Power Terminal Block installs on the CHARM Baseplate and holds a single AI 4-20 mA HART CHARM. It provides the keying and field wiring for the CHARM when connected to a device in a 3-wire configuration.
  • The third terminal on this terminal block provides a connection for negative conductors for 3-wire devices.
  • The fuse of the terminal block protects field wiring from damage caused by short circuits.
  • The fuse cannot be replaced when the terminal block is under power in a hazardous environment.
  • The CHARM 3-Wire AI Fused Injected Power Terminal Block keying mechanism is factory set to match the type of CHARM that can be installed.
  • If you are using multiple bulk power supplies, the return for injected power on the CHARM 3-Wire AI Fused Injected Power Terminal Block and the return for the CIOC power supply should be as close to each other as possible on the common ground bar.
  • Removing the CHARM from the CHARM 3-Wire AI Fused Injected Power Terminal Block does not disconnect field power from connected devices. In order to disconnect field power, you must remove the fuse from the CHARM 3-Wire AI Fused Injected Power Terminal Block.
  • The following CHARM can use the CHARM 3-Wire AI Fused Injected Power Terminal Block :
    • AI 4-20 mA HART CHARM
