Enable and setup recipe authorization

The recipe authorization function is enabled and set up in Version Control Audit Trail. Version Control is accessed through the DeltaV Database Administrator application. Remember that Version Control must be installed and setup to use the recipe authorization function.

The process of enabling Version Control can take a significant amount of time.

  1. Click Start > DeltaV Engineering > Database Administrator, and then double-click the Version Control Configuration icon to open the Version Control Configuration dialog.
  2. Enable Version Control if not already enabled (the check box is selected).
  3. Click the Recipes must be authorized before downloading check box.
  4. Select Enable signature propagation to referenced recipes if you want signers to have the option of sending their signature to lower level (referenced) recipes.

  5. Click the Signers button to open the Recipe Authorization Signers dialog. Then click Add to add at least one signer (for example managers or supervisors).

    Note:

    When you add a new signer description, VCAT automatically unauthorizes all previously authorized recipes until the new signer approves them.

    When you delete a signer description, VCAT automatically authorizes all recipes that have approvals from all other remaining signers.

  6. Click OK on the Version Control Configuration dialog to enable Version Control (if not already enabled) and recipe authorization and to setup recipe authorization.

If not already created, the DeltaV system creates a Version Control database and populates it with items in your current configuration database.

If VCAT was already running, this procedure adds Recipe Authorization functionality to the SQL database.
