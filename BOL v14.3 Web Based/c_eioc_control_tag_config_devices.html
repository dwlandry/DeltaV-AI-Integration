Configuring Ethernet/IP Control Tag Integration devices and signals with tag definitions

The EIOC port defines the protocol used in the device network. Physical devices, their logical devices and device signals are configured under the port. The following sections provide a high-level description of the tasks required to integrate PLC data through Control Tags using the standard tag definitions that are included with DeltaV software. Refer to the PLC documentation for device information. Refer to DeltaV Explorer help information on the EIOC dialogs and for specific configuration tasks.

Set preferences to support control tag integration

In the System Preferences application under Networking, select Ethernet I/P Integration with Tags.

Export control tag definitions from your PLC

Export control tag definitions from the PLC. For Rockwell devices, this is a .L5X file.

Copy the control tag definitions file to the ProfessionalPLUS workstation

Copy the file you exported from the PLC to the ProfessionalPLUS. You can place the file anywhere on the workstation. When you configure the physical device later in the configuration process, the software copies it to the DeltaV\DVData\ControlTags folder.

Set the port protocol for the EIOC port to Ethernet/IP Control Tag Integration

In the Ethernet I/O Port Preferences Properties dialog, on the Advanced tab, click Ethernet/IP Control Tag Integration under the Protocol drop-down list.

Create a physical device on the EIOC port to communicate with the PLC

Right-click the port and click New Ethernet I/O Physical Device.

Specify a control tags file for the physical device

On the physical device properties dialog, under the Advanced tab, click Browse to specify the Control Tag File that you exported previously.

Create a logical device under the physical device for specific groups of control tag information

On the Properties dialog for the logical device, specify the rack number, slot number and other properties of the device.

Add Ethernet I/O control tags to the EIOC logical device

Under the logical device, add new Ethernet I/O control tags. This links a device tag from the PLC export file to a DeltaV tag definition.

Tag definitions are part of the DeltaV library templates (Library\PLC Tag Definitions). The table shows the standard tag definitions included with DeltaV software and the Rockwell Logix Add-On instructions to which they correspond. The standard tag definitions are read-only. Writing values requires a custom tag.

If the tag definitions included with DeltaV software are not sufficient for your control strategy, you can create your own custom or array tag definition. You can do this in one of two ways: by creating a library definition in the DeltaV Explorer hierarchy and choosing it when you add a control tag to the EIOC logical device (custom and array tag definitions are included in the drop-down list along with standard tag definitions), or by creating it new when you add a control tag to the logical device.

You create a custom or array tag definition using a PLC export file, or you can enter the data manually. If you use an export file, it must be on your workstation. The New Control Tag Definition dialog enables you to select the export file (Definition File). Once you select the file, you can browse for a specific Add-On instruction. If you want to use a tag in the export file that is not an Add-On instruction, you must type it in manually.

Using control tag data in your control strategy

You can assign a signal DST to a parameter in an EIOC-resident control module. The DSTs and the control module parameters (or function block parameters) must be associated with the same EIOC.

Non-Boolean input signal DSTs can be referenced as a FIELD_VAL parameter. Boolean input signal DSTs can be referenced as a FIELD_VAL_D parameter. String input signal DSTs can be referenced as a FIELD_VAL_S parameter. Similarly, output signal DSTs can be referenced as an OUT parameter for non-Boolean and an OUT_D parameter for Boolean.

Using Tag I/O blocks and TagIntegration module templates in your control strategy

The DeltaV Explorer library contains four TagIntegration module templates that use the TAG I/O blocks and alarm blocks to form the basis or a working monitoring module. You assign the tag block to an Ethernet I/O control tag (of the appropriate type) you created under the logical device.

Control Studio includes TAG I/O blocks on the IO palette (TAGAI, TAGAO, TAGDI, TAGDO). In addition, there is a TAGIO block that converts to the appropriate TAG block when you assign it to specific EIOC control tag signal.

You can build your own module using these blocks if you do not use a template.

Connect the PLC to the EIOC device network port

Physically connect the PLC to the EIOC port.
