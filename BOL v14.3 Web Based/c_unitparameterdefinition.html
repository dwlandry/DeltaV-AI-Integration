Unit parameter definition

The unit parameter definition contains the name of a class of unit-level parameters for Batch Executive. The unit parameter definition also defines the type of parameter (for example, integer, Boolean, floating point, named set, or parameter reference) that is created in all unit modules based on the unit class.

The unit parameters are constants or variables available to all phase algorithm definitions. These unit parameters can be used to define minor differences between units that share the same unit class. For example, a unit parameter can be an integer that defines maximum tank capacity; a Boolean that defines whether or not a secondary agitator is present, or a tag that reads a value of a control module, and so on. The unit parameters are also used to send requests between phases running on the same unit.

The names of the unit parameters are not system wide. They are restricted to the parent unit class. The names are shared with the names of the other parameters in the unit modules that are based on the same unit class. Therefore, the name must be unique within this scope.

In most cases, the configured initial (downloaded) value for unit parameters is distinct for each unit in a unit class. Therefore, configuring the value at the class level (unit parameter definition) is not recommended. One exception is the use an external reference parameter. When aliasing is used, configuring the external reference parameter to use an alias name is recommended. This technique allows the unit to look up the alias name in the alias resolution table and use that value for the parameter.

It is possible to configure default values (appropriate to parameter type) for unit parameters. Configuring with default values allows for class-based configuration of external reference parameters, which permits other parameter types to be configured with safe values by default. However, specifying the default value does not prevent that value from being changed once the parameter is derived from a unit class. Furthermore, if the default value for a unit parameter definition is changed, it does not change the configured values of unit parameters already created.
