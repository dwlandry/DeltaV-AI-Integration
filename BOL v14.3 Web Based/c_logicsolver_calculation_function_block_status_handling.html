Logic Solver Calculation function block status handling

The block's outputs are initialized to Bad. You must explicitly set the status of outputs by writing to the .ST field of an OUTn parameter. The .ST field is not automatically written when the .CV field of an OUTn parameter is written.

If the LSCALC function block executes a divide by zero expression, the block's BLOCK_ERR Configuration Error bit is set. This, in turn, sets the SIF module's SIF_ERRORS bit 'Memory Failure' or 'Config Error' bit set in BLOCK_ERR in a Calc/Logic block.
