tan function

The tan function returns the tangent of x in radians.
Arguments
1
Argument Description
x A number representing an angle in radians.
Return value
The tangent of the given number.
Syntax
Math.tan(x)
Examples
Example Result 
var Num = DLSYS["U012-FICA-5625-C/DIFF.CV"];
this.Label = Math.tan(Num);
 Returns "0.546...". 
Math.tan(1)
 Returns "1.5574077246549023". 
function getTanFromDegrees(degrees) {
  return Math.tan(degrees * Math.PI/180);
}
Dsp.Button1.Label = getTanFromDegrees(45)
 Returns "0.9999999999999999".
