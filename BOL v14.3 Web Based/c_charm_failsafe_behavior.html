LS CHARM failsafe behavior

All LS CHARMs have a failsafe behavior. The LS DO and LS DVC CHARMs failsafe behavior is different than other CHARM types.

If an LS DOUT or LS DVC CHARM fails to receive a valid output message from the CSLS for 400 milliseconds (communications is interrupted, or the output module is deleted), then it enter failsafe. The failsafe behavior is as follows:

LS DOUT CHARM:
  • DTA CHARM: Output de-energizes.
  • ETA CHARM: Output holds last value.
LS DVC CHARM:
  • DTA CHARM: Output de-energizes.

Failsafe behavior is the same for simplex and redundant CHARMs.
