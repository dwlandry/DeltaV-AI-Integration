Bulk editing EIOC physical devices

The EIOC card and port must be defined in the database before you can import EIOC physical devices. Create a format specification file or use the appropriate EIOC physical device FMT file and export the physical devices that were created when you configured the EIOC port in DeltaV Explorer. Edit the exported data as required, making sure that the values are consistent with those in the database.

The EIOC physical device FMT files are:
  • Physical_Device_CTA.fmt
  • Physical_Device_EIP.fmt
  • Physical_Device_IEC_61850.fmt
  • Physical_Device_Modbus.fmt
  • Physical_Device_OpcUa.fmt
