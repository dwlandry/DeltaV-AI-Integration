Publishing configurations

Updates to most graphics configurations, as well as workstation configurations, are not available online prior to publishing. Publishing, a command initiated by users, authorizes graphics configurations and DeltaV Live workstations to be deployed for use online and on all DeltaV Live workstations that should have it. When a graphics configuration or workstation is published, it is marked as available for a workstation to retrieve it. Workstations that are communicating retrieve configurations as soon as they are published. Workstations that are not communicating retrieve published configurations as soon as the workstations begin communicating. Operators receive an indication that updates have arrived, but to ensure that publishing does not interrupt their normal workflow, they choose when to accept those updates.

The following configurations, when created or modified, must be published for their updates to be available online:
  • DeltaV Live workstations
  • Languages
  • Themes
  • displays
  • Display sets
  • Contextual displays
  • Layouts
  • Standards
  • Functions
Note:
  • GEM classes do not require publishing. Instead, when a GEM class is modified, the displays containing the GEMs linked to that GEM class must be published.
  • Items within a configuration cannot be published on their own. For example, graphics elements or GEMs located within displays, or screens located within layouts, are only published as part of their containing display or layout.

When you select a Publish command, the Publish dialog opens. The check boxes are automatically selected next to all items that are eligible for publishing and that meet the selected publishing command's criteria. Displays that are set as a Work in Progress appear in the Publish dialog but are not automatically selected for publishing. If you are not ready to publish an item on the list, deselect the check box next to it.

Setting displays as a Work in Progress

If you are not ready to publish changes you made to a display, you can set it as a Work in Progress. When you modify a GEM class, you can also notify the displays containing that class's linked GEMs that you want those displays to be set as a Work in Progress. Then, if you attempt to publish displays set as a Work in Progress, they are automatically deselected in the Publish dialog. You can still choose to publish them by selecting the appropriate check box.

The Publish Pending indicator

The icon indicates that a configuration has publishable changes pending, and the icon indicates that a container or folder contains at least one configuration with publishable changes pending. When a configuration has been added or modified, a publish pending indicator appears next to its name in the Explorer view, or for workstations, in the Workstation Management dialog. When a GEM class is modified, the displays containing its linked GEMs, rather than the GEM class, show a publish pending indicator.

Un-Publishing configurations

If you want to remove a published graphics configuration or workstation from online but not from the configuration database, you can un-publish it. Once you un-publish a configuration or workstation, it is no longer running on any workstations.
Note: To delete a configuration or workstation from the configuration database, you must first un-publish it.
