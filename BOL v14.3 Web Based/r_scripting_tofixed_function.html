toFixed function

The toFixed function returns a string representing the given number and using fixed-point notation.
Arguments
0–1, Optional arguments are indicated by a ? following the argument name.
Argument Description
fractionDigits?

The number of digits (between 0 and 20) to appear after the decimal point.

If fractionDigits? is omitted or undefined, it assumes the value of 0.

Return values (string)
A string representing the given number and using fixed-point notation.
Syntax
numObj.toFixed(fractionDigits?)
Examples
Example Result 
function financial(x) {
  return Number.parseFloat(x).toFixed(2);
}
this.label = financial(0.004));
Returns "0.00" . 
2.34.toFixed(1);
 Returns "2.3". 
(-2.34).toFixed(2);
 Returns "-2.34".
