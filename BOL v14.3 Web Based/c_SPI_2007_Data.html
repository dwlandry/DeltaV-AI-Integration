Data that can be moved between Excel and SPI

The information that can be exchanged between the DeltaV system and SmartPlant Instrumentation depends on the object type. The following lists show the information for each supported object. The column name in the worksheet where the information is stored appears in parentheses.

For controllers:

  • Name (node)

  • Description (description)

  • Redundancy (redundant)

For DeltaV Classic I/O cards:

  • Slot position (card)

  • Class, Type,and Series (definition)

  • Description (description)

Note:

SIS Logic Solver cards are not supported in this release of the interface.

For classic I/O channels:

  • Type (definition)

  • Enabled (enabled)

  • DST (dst)

  • Description (description)

  • Slot(channel) 

For fieldbus I/O cards:

  • Description (description)

  • Slot (card)

  • Series (definition)

For fieldbus port information:

  • Enabled (enabled)

  • Description (description)

  • Schedule Macrocycle (schedule macrocycle)

For devices:

  • Device manufacturer (device manufacturer)

  • Device type (device type)

For HART devices:

  • Manufacturer (device manufacturer)

  • Type (device type)

  • Revision (device revision)

  • Device tag (device)

Note:

ASi-bus, DeviceNet, Profibus, and Serial devices are not supported in this release of the interface.

For fieldbus devices:

  • Port Number (channel)

  • Name (device)

  • Address (address)

  • Description (description)

  • Manufacturer (device manufacturer)

  • Type (device type)

  • Revision (device revision)

  • Backup Link Master (backup link master)

  • Alarms Enabled (alarms enabled)

For fieldbus function blocks:

  • Tag (block tag)

  • Block Index (block index)

  • Description (description)

For signals:

  • Enabled (enabled)

  • Description (description)

For signal parameters:

  • Signal name (attribute)

  • Value (value)

  • EU 0 (0% of scale)

  • EU 100 (100% of scale)

  • Engineering Unit (engineering unit)

Note:

In addition to the fields listed above, many items have an SPI uid or SPI uid2 associated with them that appear in the workbook. Do not edit or delete these items. These IDs are used internally by SPI, the SPI interface, and DeltaV software.
