PK controller and carrier specifications

The PK controller carrier can control either the 4-wide I/O carrier shipped with the kit or up to eight 8-wide I/O carriers. I/O carriers connected to the PK controller carrier can contain any non-I.S. DeltaV I/O cards.

Item Specification
Input power requirement through the PK controller carrier +24 VDC ±10% at 350 mA maximum; 700 mA maximum for redundant
Externally applied backup power for real-time clock +5.0 to +12.6 VDC at 15 uA typical

Isolation None. All circuits are referenced to the +24 VDC return
