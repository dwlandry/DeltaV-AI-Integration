Date object

The Date object can be used to represent arbitrary dates and times, get the current system date, and calculate differences between dates. The following Date object functions are supported in DeltaV Live graphics expressions and scripting.

Date object functions

Date object syntax: 
new Date();
new Date(value);
new Date(dateString);
new Date(year, month?, day?, hours?, minutes?, seconds?, milliseconds?);
Function Description Syntax
now () Returns the time value (as a number) designating the UTC date and time from the occurrence of the call to now. Date.now()
parse() Parses a date string and returns the number of milliseconds since January 1, 1970. Date.parse(date string)
UTC() Returns the number of milliseconds in a date since midnight of January 1, 1970, according to Universal time. Date.UTC(year, month, day?, hour?, minute?, second?, millisecond?)
