SPI: conventions on tags publishable from DeltaV software

Device Signal Tags created in DeltaV software must follow the conventions applicable to SPI Control Systems Tags.

Instrument Tags are created automatically in DeltaV for conventional and HART Instrument Devices by analyzing the DST tag and making standard replacements. This is done for new DSTs created in DeltaV that do not have an Instrument retrieved from SPI. The text in the DST tag is used to create Instrument tags using the following replacements.
