Unit module detail display (UM_DT)

The unit module detail display allows the user to do the following:

  • See unit details (enable/disable alarms, # of reserved phases, FREMEM value)

  • View diagnostics

  • Monitor unit alarms

  • Acknowledge alarms

  • Create and start new phases in the unit module

  • View the faceplate for the active phases

  • Select the default monitor on which to present the detail display

Unit Module Detail Display (UM_DT) in DeltaV Operate

The preceding figure shows the detail display for a batch unit module as used in DeltaV Operate. The unit alarm list shows active or unacknowledged alarms in modules contained by the unit. Up to 10 alarms are shown on each tab, with a maximum of 50 being visible. A tab with visible alarms has a dim red horizontal bar. The alarms are sorted in the same priority order as is used for the alarm banner.

Each alarm in the list has a button with the module tag on the left and a text field showing the alarm name on the right. Click the tag button to open the faceplate for that module. If the alarm is unacknowledged, the button blinks the priority color and an ACK button is visible in the left margin. Click the ACK button to acknowledge all alarms on the same row. This causes the ACK button to disappear and the tag button to stop blinking. An inactive, unacknowledged alarm has a hatched appearance. Inactive acknowledged alarms disappear from the list. The ACK button at the top of list can be used to acknowledge alarms in all modules on the selected tab.

The diagnostics section displays visible text for active conditions in the module's MERROR, MSTATUS, and BLOCK_ERR parameters. There is a tab for each parameter. The parameter name on the tab is underlined when an active condition for that parameter is displayed. When an error has occurred in the module, a Clear Error button is displayed on the MERROR tab. Click this button to clear active errors.
