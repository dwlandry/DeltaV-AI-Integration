Version Control and CSLS SIS systems

When Enable Version Control for DeltaV SIS is selected in the Version Control Configuration dialog CHARMs Smart Logic Solvers (CSLS) are added to Version Control Audit Trail (VCAT). Enabling VCAT for DeltaV SIS does not include SIS Controllers in version control.

Note:

To include SIS Controllers select Enable Version Control on the Version Control Configuration dialog.

Some notes about Version Control and CSLS SIS components when VCAT is enabled:
  • Changes to a Modbus Port object (property values, add/update/delete or register mappings and so on) check out the parent SIS Controller.
  • Any changes made to LS CHARMs check out the parent CSLS rather than the LS CHARM itself.
  • Adding modules to the DeltaV SIS Controller does not check out the DeltaV SIS Controller. The module has the checkout status.
  • Adding modules to an AREA does not check out the AREA. The module has the checkout status.
  • Adding SIS modules to a CSLS does not check out the CSLS. The SIS module has the checkout status.
  • DeltaV SIS Controllers and CSLSs can be checked out and in individually.
  • The Show All Charms and Show Only Defined CHARMs choices are disabled on the CSLS CHARMs context menu.
