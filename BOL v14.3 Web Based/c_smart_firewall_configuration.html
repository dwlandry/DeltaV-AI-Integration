Gathering information to configure the Smart Firewall

The following topics help you to gather the information that is required to configure the firewall and provide suggestions on how to select from the firewall's setup options to ensure that the firewall works correctly within the existing or proposed network architecture after you configure the firewall. After gathering all of the necessary information, follow the procedures in Setting up and configuring the Emerson Smart Firewall to configure the firewall.

In order to install the Emerson Smart Firewall and get it up and running properly in your network we suggest that you:

  • Gather the information needed to setup the firewall and to setup communications.
  • Configure the firewall parameters to enable the firewall to work within the existing or proposed networks.
  • Establish communications between the computers on either side of the firewall.
  • Create the communication rules to ensure only authorized communications are allowed through the firewall. Creating communication rules comprises the protection phase of firewall configuration.

Firewall configuration can be done on the bench or after the firewall is installed in the network. If the firewall is to be installed in an existing network to replace a router, switch, or existing firewall, it is best to do the configuration on the bench prior to installing the firewall in the existing network. If the firewall is to be installed in a new network, the configuration can be done either on the bench or with the firewall installed in the network.

It will be necessary to work with your IT department to obtain the information needed to configure the firewall. Corporate or site-wide IT network and security policies must be followed to ensure the setup conforms (as much as possible) with the policies. You will also need IT support to establish communications between the computers on either side of the firewall. It is always a good idea to include your IT department anytime you connect to their networks or use their networks to move data or to give users external access to the DeltaV system.

Note:

The Emerson Smart Firewall creates a secure environment in which the addition of new connections or new computers to the system requires deliberate action by the system administrator. This prevents unauthorized users from easily gaining access to the system without the knowledge of the administrator. We recommend using firewall settings that encourage or enforce a more secure environment rather than settings that might create a more automatic, plug and play environment. It is up to the individual user to decide if and how a more secure environment is enforced.

Note:

In this document DeltaV workstation means any computer connected to the DeltaV 2.5 LAN whether or not DeltaV is installed on the computer.
