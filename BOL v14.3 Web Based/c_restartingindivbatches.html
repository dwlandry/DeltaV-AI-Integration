Restarting individual batches

When restarting a batch, you are asked to select the type of restart, Warm or Cold. You must have the Batch_Control_Start key to be able to restart a batch. Before restarting the batch with a warm restart, is important to have cleared the problem that caused the batch to stop running. If the problem still exists, then the batch will repeat the same behavior (stop running).

The following are valid choices for individual batch restarts:

  • Warm Restart - puts the batch in the Held state in Manual mode. The warm restart method is the preferred restart method. You can then restart the batch using the Restart button or perform Active Step Changes to alter the sequence of steps in the batch. An active step change may need to be performed to return the batch to a specific step due to a problem in the execution of that particular step.

  • Cold Restart - puts the batch in the Ready state, as if it were a new batch. You can start the batch using the Start Batch button. Make sure that the batch is, in fact, in a physical state where it can be restarted from the beginning. Any phases that were running in the controller and waiting on a response from the operator or Batch Executive could still be running. You must manually unload the phase, which can be accomplished from the unit phase faceplate.

During a warm or cold restart of an individual batch, the batch will maintain ownership of the equipment it had previously acquired. Other batches waiting for the equipment will remain in the queue until the equipment is released.

Note:

A batch that is in the process of programmatically acquiring a unit (that is, the request has been made to multiple units but no single unit has been acquired) will retain those requests after the cold restart. This could result in the batch owning more than one unit (even though it only used one). The operator must force a release of the unused but acquired units so that other batches can use them.

Batches can also be restarted with recipe resynchronization (if enabled on the Batch Executive).
