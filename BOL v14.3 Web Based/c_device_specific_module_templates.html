Device-specific module templates

DeltaV includes several module templates that illustrate configuring a module to access diagnostic data from a specific device. You can use these module templates as a starting point for configuring a module that accesses diagnostic data from a Profibus DP, DeviceNet, or fieldbus device. To open one of the device-specific sample module templates for two-state motors, for example, start DeltaV, navigate to Library/Module Templates/Motors-2State in the Hierarchy pane, and drag one of the following module templates to an AREA in System Configuration/Control Strategies:

Module template

Device

CMNDR-SK-DNET

Control Techniques Commander SK Motor

E3RELAY-DNET

Allen Bradley E3 Overload Relay Motor

SIMOCODE-DP

Siemens SIMOCODE-DP Motor
