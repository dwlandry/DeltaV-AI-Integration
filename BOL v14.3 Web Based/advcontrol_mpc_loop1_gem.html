MPC_LOOP_1_ GEM class

MPC_LOOP_1_ GEM


This figure shows the GEM at a 200 percent magnification.
Alarm box
A thick-colored rectangle that surrounds the GEM and indicates the highest priority alarm for that module. The alarm box is visible as long as an active or unacknowledged alarm exists for that module.
Status box
A thick-colored rectangle that surrounds the GEM and indicates that a condition needing attention exists (abnormal status). The status box is visible only when there are no active or unacknowledged alarms. Otherwise, the alarm box shows.

The conditions that set the status icons and the suppressed alarm icon also set the visibility of the status box.

The GEM can be configured to show or not show the status box when an applicable condition is active, including Bad IO, Module Not Running, Simulation Active, Analog Mode not as Expected and DC Mode not as Expected.

Alarm icon
The alarm icon shows the highest priority alarm for that module.
Abnormal mode status icon
Provides indication when Mode is not as expected. It is visible when either of the following is true:

  • the Actual mode of the PID block is not equal to the Normal mode

  • the Actual mode of the PID block is not equal to the Target mode

For DC and EDC modules, the mode icon is visible when Mode is anything other than Normal or Permissive Active. (Permissive Active also causes mode = LO.)

CNTRL1 value
Provides indication when Mode is not as expected. It is visible when either of the following is true:

  • the Actual mode of the function block is not equal to the Normal mode

  • the Actual mode of the function block is not equal to the Target mode

The CNTRL1 value of the MPC block's Controlled Variable.
SP1 value
The SP1 value of the MPC block's Controlled Variable.
MNPLT1 value
The MNPLT1 value of the MPC block's Manipulated Variable.
