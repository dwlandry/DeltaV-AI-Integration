Configure an SLS 1508 logic solver

The SLS 1508 logic solver card and logic solver are configured in different places in the DeltaV Explorer. After you create the logic solver assign it to the logic solver card.

  1. Navigate to a SIS Network Domain in the SIS Network in DeltaV Explorer.
  2. Right-click and select New Logic Solver.
  3. On the General page of the Properties dialog that opens, enter a name and description for the Logic Solver. The default name is SLSn, where n is the next unique number, beginning with 1.
  4. Select a Scan Rate from the drop-down list. Refer to the DeltaV SIS Safety Manual for guidelines on choosing the scan rate.
  5. If desired, select the Enable fast I/O updates to the DeltaV Controller check box.
  6. If you want secure parameters published by this logic solver available to logic solvers in other nodes, select the Publish secure parameters globally checkbox, then select whether to publish as SIS Network Domain globals or system globals.
  7. If you want to have this logic solver publish 16 secure parameters, select the High-Density Secure Parameters checkbox. 
  8. On the Alarms and Displays tab, enter or browse for the displays to be used for the Primary Control, Detail, and Faceplate displays.
  9. On the Proof Testing tab, set the Proof Test Interval in years and days and set the Proof Test Reminder Alert in days.
    Note:

    For more information on proof testing, refer to the DeltaV SIS Safety Manual.

  10. Click OK. 

The Logic Solver now appears in the DeltaV Explorer hierarchy under a SIS Network Domain in the SIS Network, but the icon is grayed until it is commissioned to a Logic Solver card. 

You can also create a Logic Solver by dragging and dropping a Logic Solver card from an I/O subsystem onto a SIS Network Domain (which assigns the Logic Solver as well). Right-click the Logic Solver and select Properties to complete the properties information.
