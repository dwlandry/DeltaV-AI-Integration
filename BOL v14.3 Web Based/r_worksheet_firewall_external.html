Configure the external network
1 This can be any name and does not have to be the actual computer name; however, it is prudent to use the actual computer name as part of the workstation name so it can be easily found.
2 If any users are making remote desktop connections to the DeltaV system, the addresses of the remote computers need to be configured in the firewall. Be sure to include the addresses of remote computers here.
3 The IP address is obtained by accessing the external computer or requested from IT. These addresses should be static. Emerson recommends that point-to-point connections are used. Addressing that allows any computer in a subnet to gain access through the firewall should not be used.
