Backing up supporting data

The DeltaV system contains important data that is not backed up by any of the DeltaV backup applications or commands. However, this data should be backed up regularly using the Windows Backup utility or a comparable third-party tool. This data is stored in subdirectories of the DeltaV directory. Following table lists the major subdirectories and files in the DeltaV directory and what information they contain.

DeltaV\DVData\amsdevices

Directory containing fieldbus device files.

DeltaV\DVData\amshartdevices

Directory containing HART device files.

DeltaV\DVData\Bulkedit

Directory containing the template, sample format specification files, and sample .txt files for bulk edit.

DeltaV\DVData\Charts

Directory containing saved Process History View charts

DeltaV\DVData\Charts\Lib

Directory containing predefined E+Chart files for module and faceplate parameters. For example, AI_fp.phve contains a chart of the PV parameter of the Analog Input function block and an event log for the module. Process History View opens these files when an operator presses the E+Chart button on the module or function block's faceplate.

DeltaV\DVData\Databases

Directory containing the active configuration database and any backup databases

DeltaV\DVData\download

Directory containing the download scripts for the last downloaded configuration

DeltaV\DVData\Expressions

Directory containing expressions created in Control Studio

DeltaV\DVData\Graphics-iFIX

Directory containing operator displays and historical data files

DeltaV\DVData\Graphics-iFIX\Pic

Directory containing pre-existing graphics as well as user-created pictures that are used in operator displays

DeltaV\DVData\Import-Export

Directory containing files that have data exported from the configuration database

DeltaV\DVData\POWERUP

Directory containing download files.

DeltaV\DVData\sound

Directory containing *.wav files for audible alarms
