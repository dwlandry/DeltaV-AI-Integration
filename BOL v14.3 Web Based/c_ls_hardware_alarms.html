Logic solver hardware alarms

Logic Solvers have four hardware alarms:

Hardware Alarm Alarm Word Description

COMM_ALM

COMM

The Logic Solver is not communicating.

FAILED_ALM

FAILED

The Logic Solver is no longer functioning.

MAINT_ALM

MAINT

The Logic Solver has determined that it requires maintenance or a Logic Solver in a redundant pair is not available.

ADVISE_ALM

ADVISE

The Logic Solver has detected a condition that does not fall into the other categories but warrants the attention of plant personnel.

Logic Solver hardware alarms are enabled by default and you cannot disable them. You can set the priority and the shelving timeout of the alarms using the System Alarm Management application or DeltaV Explorer.

The system displays Logic Solver hardware alarms in the following places:
  • SIS Alarm List Display
  • alarm banner
  • SIS Logic Solver faceplates
  • Process History View.
You can also add Logic Solver alarms to operator graphics. Use the standard Data Link Stamper and browse to the Diagnostic Parameters on the SIS Network to find the Logic Solver hardware alarms. The Condition Summary application provides a list of the Logic Solver hardware alarm conditions (when one exists). You can launch the Condition Summary application from the DeltaV Alarm Summary control or the Hardware Alarm faceplate.
