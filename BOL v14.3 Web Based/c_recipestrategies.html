Recipe strategies

Before you create recipes for your process, you need to develop a recipe strategy. This strategy identifies requirements of recipes you need and the associated logic.

Use the following approaches to develop flexible and reusable recipes:

  • Build a set of well designed phases with appropriate parameters so that they are versatile and can accomplish required tasks in a modular way.

  • Build a library of generic operations that can be reused in multiple recipes.

  • Create recipes that can run on multiple units. This type of recipe is called a class-based recipe. Unit selection is done at runtime.

  • Know your plant's design and how it will affect the recipe design. For example, placement of the equipment in the plant affects what units are required for a recipe.
