CHARMs Logic Solvers preference

This preference enables or disables the following features of DeltaV SIS software:

DeltaV Explorer

  • New menu from Control Network contains SIS Controller.
  • New menu from Local Safety Network contains CHARMs Logic Solver and LSN Bridge.
  • SIS items are added to the Library and Setup.

Control Studio and DeltaV Operate

  • SIS Module and Module Template choices added to the New dialog.
  • SIS function block palettes are available when creating SIS modules.
  • Secure Write mechanism added for making changes from Control Studio online and DeltaV Operate.

Diagnostics

  • Interface to DeltaV SIS diagnostic parameters.
Note: If you import a configuration that contains DeltaV SIS items, or if your configuration contains DeltaV SIS items, the DeltaV SIS items are visible whether DeltaV SIS software is enabled or not. However, full DeltaV SIS functionality is available only if it is enabled.
