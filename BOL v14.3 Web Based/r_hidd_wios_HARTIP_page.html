wireless I/O card Properties dialog (HART-IP tab)

Note:

A download of the WIOC is required after making any changes to the HART-IP communications options on the wireless I/O card Properties dialog's HART-IP page. Initial configuration requires a total download; any subsequent change only requires downloading the setup data.

The dialog has the following fields and controls

Enable HART-IP communications
Enables HART-IP communications for this card. All other fields on this dialog are disabled until you enable communications.
The HART-IP traffic bypasses DeltaV and goes directly to the HART server. Therefore, DeltaV has no way of throttling the number of HART-IP messages. Be aware that a large number of messages could cause performance issues for control data.
HART-IP Port
Allows you to change the HART-IP port for this card. Select one of the valid entries from the list.
Note:

Changing the HART-IP port requires a restart of the HART server. The restarting process reforms the network meaning the devices will disconnect and reconnect. This can take some time to complete and results in a loss of control during this period (from a few minutes to a few hours).

Access Control List (workstations and servers IP)
Creates a list of approved nodes (a whitelist) that can communicate through this card on the specified port with the HART server.

The access control list has a limit of 10 nodes.

Add... button
Opens a dialog where you enter the node's name and IP address to be added to the access control list.
Modify... button
Edits the selected entry's node name and IP address.
Delete button
Removes the selected entry from the list.
