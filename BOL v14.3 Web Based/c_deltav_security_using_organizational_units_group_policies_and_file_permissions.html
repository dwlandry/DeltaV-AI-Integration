DeltaV security using Organizational Units, Group Policies, and file permissions

Some of the security features of Windows Active Directory have been integrated into DeltaV systems installed in domains. In DeltaV systems, Windows user rights and permissions are controlled by NTFS file access permissions, Organizational Units (OUs), and Group Policies.

Note: NTFS file security can be applied in both workgroup and domain systems. Organization Units and Group Policies are implemented in domain systems only.
