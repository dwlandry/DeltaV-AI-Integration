max function

The max function compares zero or more values and returns the number with the largest value.
Arguments
0- n, Optional arguments are indicated by a question mark following the argument name.
Argument Description
x? through n? One or more numbers to compare
Syntax
Math.max(x?, y?, z?, n?)
Examples
Example Result 
var Num = DLSYS["U012-FICA-5625-C/DIFF.CV"];
this.Label = Math.max(Num, 1);
 Returns "1". 
Math.max(10, 20)
 Returns "20". 
Math.max(-10, -20)
 Returns "-10".
