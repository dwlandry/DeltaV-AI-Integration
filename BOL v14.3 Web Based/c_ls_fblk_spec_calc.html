Logic Solver Calculation function block

The LSCALC function block evaluates an expression you define to determine the block's outputs. You can use mathematical functions, logical operators, constants, and parameter references in the expression. There are no modes or alarm detection in the Calculation/Logic function block.

LSCALC Function Block

IN1 through INn are the inputs to the block (as many as 16 inputs).

OUT1 through OUTn are the block outputs (as many as 16 outputs).
