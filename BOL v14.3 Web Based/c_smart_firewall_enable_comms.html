Information needed to enable communications through the Smart Firewall

The firewall requires that routing is configured on the external workstations since the external workstations are on different subnets from the DeltaV workstations. Routing provides the communications path from the external workstations to the internal workstations. If routing is not configured, the external workstations cannot find the internal workstations.

The network administrators can add routing information to the devices that route network traffic such as routers or use the route add command on each external workstation to allow external workstations to locate internal workstations.

In a network architecture where the external workstations are two or more network hops away from the firewall (workstations communicating through two or more routers or firewalls) the IT department will need to add routing information to the routing devices to allow the external workstations to communicate with the internal workstations.

Consult with your IT department and obtain the following information required to enable communications through the firewall. We recommend that you record this information on the worksheets.

  • Are any of the external workstations across subnets (multiple routing devices)? If yes, assistance from the IT department is required.
  • Will routing be added to network devices?
  • Will each external workstation be configured with a route add statement?
