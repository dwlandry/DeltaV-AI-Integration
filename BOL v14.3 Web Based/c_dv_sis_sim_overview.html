SLS 1508 SIS Simulate task overview

This section includes information on creating an SIS Simulation system from configuration through download and system checkout. The suggested steps to create an SIS Simulation configuration are:

  1. Install DeltaV software on the ProfessionalPLUS and Application workstations.

  2. In DeltaV Explorer, create the Application Stations you need to simulate other controllers in your system.

  3. Install the appropriate multi-node simulation licenses on all workstations.

  4. Set the Controller alias name on each workstation's Simulated Logic Solver subsystem properties dialog.

  5. Create simulated logic solver cards under the Simulated Logic Solvers subsystem in each workstation.

  6. Configure Logic Solvers under the SIS Network subsystem.

  7. Define Logic Solver channels.

  8. Assign Logic Solvers to the simulated Logic Solver cards.

  9. Create your SIS configuration (modules, links, displays, and so on).

  10. Download the workstations.

  11. Commission and download the logic solvers.

    Note:

    You can download an SIS Simulation system only if your workstation has the appropriate license.

  12. Perform the system functional test.

If you have a DeltaV SIS Simulate Professional license you can also read and write process data to and from SIS modules in the simulation using OPC.
