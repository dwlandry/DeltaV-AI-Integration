MPC Constraint Variable function block faceplate (MPCAV1_FP)

DeltaV Operate View of the MPC Constraint Variable Faceplate

The following items are contained in the faceplate:

  • Constraint Variable - This field displays the CNSTRn value of the MPC block in yellow. The background color of the 3-D box changes from gray to orange or red when the CNSTRn status becomes uncertain or bad, respectively. The CNSTRn value is visible in the decimal format provided by CNSTRn_SCALE.DECPT.

  • Units - This area provides the engineering units description used for the Constraint Variable as defined in the CNSTRn_SCALE parameter.

  • EU 100 - This value corresponds to 100% of scale for the Constraint Variable.

  • Target Mode – This field contains a word in white text that describes the target mode for the loop. 

  • Actual Mode – This field contains a word in yellow text that describes the ACTUAL mode of the loop. 

  • EU 0 - This value corresponds to 0% of scale for the Constraint Variable.

  • Tick marks - Use this vertical arrangement of black lines to indicate percentages of CNSTRn scale.

  • CNSTRn bar graph - This field indicates the value of the CNSTRn parameter for the MPC block, which is the same as the value displayed in the Constraint Variable display box.

  • Limits - These arrowheads are vertically positioned relative to the CNSTRn bar graph to indicate the High and Low Constraint Limits. Although these arrows cannot be dragged with the mouse, the values they indicate can be modified by using the detail display.

  • Detail Display button – This button opens the detail display for the block.

  • MPC Operate Overview button – This button is used to open the MPC Operate picture for this block.

  • Limit Information - This field displays a word in yellow text representing the AV_ACT[n] value of the MPC block. The background color of the 3-D box changes from gray to blue when the SPWRK_ACT[n] value is non-zero. The text displayed represents the following values:
