SPI interface menu introduction

The options on this menu give you the capability for bi-directional exchange of DeltaV I/O configuration information with SPI including:

  • controllers

  • cards

  • channels

  • device signal tags (DSTs)

  • conventional, HART and fieldbus instrument devices and their scaling, options and assignment to I/O channels. 

  • Fieldbus I/O configuration including segment address and function blocks.

The following is a brief explanation of the SPI Interface menu options:

  • Retrieve from SPI – Opens an xml file published from SmartPlant Instrumentation and converts it to a worksheet for use in the Deltav_Xl_Support Add-in.

  • Publish to SPI – Creates an xml file from configuration data in the DeltaV database. This file can be retrieved into SmartPlant Instrumentation.

  • Create Definitional XML – Convert fieldbus and HART device fhx files to xml files to retrieve into SmartPlant Instrumentation. Use this option to add new fieldbus and HART device definitions to SmartPlant Instrumentation.

    Note:

    If you see a message saying that the file msxsl.exe was not found, download the file from the Microsoft Download Center web site and copy it to the C:\Windows directory (or wherever Windows is installed) of the workstation.

  • Convert XML file – Opens a dialog from which you transform xml files from one format to another using XSL translations.

  • Books Online – Opens DeltaV Books Online.
