Installing new Smart Switch software

If you have upgraded your DeltaV system and have Smart Switches that were installed with the previous release, it is required that you install the latest version of the switch software on all Smart Switches in your network.

Installing new switch software is recommended to fully support all the switch features available with Network Device Command Center (NDCC). For full compatibility, we recommend the following switch software versions:
  • RM100 at version 04.2.14 (or later)
  • RM104 at version 08.0.09 (or later)

Please refer to KBA AK-1000-0022, DeltaV Smart Switch and Safety Switch Software Release Information, for more information about the most recent switch software.

Note: To support emergency network maintenance operations (replacing a failed controller, for example) the NDCC supports unlocking Smart Switches with an earlier version of the switch software installed.

The NDCC does not support locking switches with an earlier version of the switch software installed.

The recommended method for updating the Smart Switch software is with Network Device Command Center (NDCC). NDCC does not decommission the switch; therefore, you can update the switch without it becoming unmanaged or unconfigured. Instructions for upgrading the software are found in the NDCC online help.

You can use the switch's serial interface, if preferred. For information on installing new Smart Switch software using the serial interface, refer to the Knowledge Base Article, AK-1000-0014.
