Select which alias to use on a unit module

A unit alias can be used on one unit module and not in another. Therefore you can create all the aliases that the unit class will use and, at the unit module, select which unit aliases are not to be used by selecting the Ignore option.

Note:

Only unit aliases that you create at the unit class can be set to Ignore. Unit alias that are created in the unit class (and inherited at the unit module) from control or equipment modules cannot be ignored.

  1. Expand the unit module (under Control Strategies in the DeltaV Explorer hierarchy).
  2. Select the Aliases object.
  3. In the right pane, right-click the specific unit alias.
  4. Select Properties.
  5. Select the Ignore check box. You do not have to select a parameter path when the alias is set to Ignore.
Important:

Leaving the parameter reference path blank without selecting the Ignore check box will result in errors when verifying the unit module. When downloading the unit module, the download occurs even when the Path and Ignore fields are blank.
