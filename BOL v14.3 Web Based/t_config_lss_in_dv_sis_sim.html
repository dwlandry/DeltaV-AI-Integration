Configure SLS 1508 logic solvers in DeltaV SIS Simulate

The configuration of SLS 1508 logic solvers (under the SIS Network) is identical to that used in the physical system. To create logic solvers:

  1. Select the SIS Network in DeltaV Explorer.
  2. Select New Logic Solver from the context menu. 
  3. Configure the properties (Scan rate, secure parameter global publish, and high-density secure parameters) exactly as if you were configuring for the physical system. 

There is one difference that has no effect on the simulation or the ability to transfer the configuration to a physical system. In a simulated system the logic solvers run at 10 times the configured scan rate (50 ms configured runs at 500 ms, and so on). This change in actual scan rate ensures that the workstation hardware can run the simulation. Even though the modules execute at 10 times the configured scan rate timers work correctly: They time out in the configured amount of time (they do not take 10 times as long to time out).

This ensures that timing-related interactions between logic solvers in the simulated system are identical to the interactions in physical systems (that is, if logic is written that relies on a relationship between the scan rates of different logic solvers, the logic works identically in the simulated and real systems). Diagnostics and other DeltaV applications show the time based on the configured scan of the logic solvers (not the actual scan it is running). If the logic is too large to work at the configured scan rate the effect will be the same in the simulated environment as in the physical environment, and the real-world impact of adjusting the scan is apparent.
