SIS locks assigned to parameters and fields

All writeable SIS function block parameters and fields have assigned locks that determine who can access the parameters and fields. In DeltaV Explorer you can change the lock assignments made by the system using the Modify button on the Properties dialogs for SIS Parameter Security and SIS Field Security. The default locks assigned to SIS function block parameters are either SIS Control or SIS Restricted Control. The default locks assigned to SIS fields are either SIS Alarms or SIS Restricted Control.

Note:

SIS module-level parameters (including user-defined parameters) do not appear in the parameter list and are therefore assigned the default lock. The default lock is SIS No Access. Users cannot write to these parameters unless you change the default lock or add the parameters to the parameter list and assign them a lock that users have the key for.
