User Manager reports

From the Reports menu in DeltaV User Manager, you can select from the following options to produce a variety of reports containing user account information:

  • Accounts Summary > DeltaV Database Accounts

    Generates a report listing information about all accounts with access to the DeltaV database.

  • Accounts Summary > All Accounts

    Generates a report listing information about all DeltaV accounts.

  • Rights and Privileges

    Generates a report listing rights and privileges information for specified DeltaV users.

  • Export Accounts and Privileges
    Exports a tab-delimited text file containing a list of user account information for one or more of the following categories:
    • DeltaV and local Windows accounts
    • DeltaV groups and keys
    • DeltaV users and keys
