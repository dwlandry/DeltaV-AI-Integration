Drawing with connection points and tips

Lines, connectors, and arcs are often used on a display to represent process piping while other elements are used to represent process vessels. Connection points and tips provide both visual and graphical cues that help you connect lines, connectors, and arcs with these other elements. When you attach a connection tip to a connection point on another element, they snap together and form a perfectly aligned connection. If the element is moved to a different position on the Content pane, the connection remains attached and moves with it.
Tip: When drawing a line or connector, hover over the element to which you are connecting to see its connection points.
The following table shows which elements have connection points or connection tips:
Element Has connection points Has connection tips
Arc Yes Yes
Chord Yes No
Connector Yes Yes
Display Link Yes No
Ellipse Yes No
Image Yes No
Line Yes Yes
Pie Yes No
Rectangle Yes No
Polygon Yes No
Rounded Rectangle Yes No
Text Yes No
Trapezoid Yes No
Triangle Yes No

While a group element has no connection points or tips of its own, you can still use the connection points and tips of all the group's nested members.

A GEM has connection points only if they have been added to its GEM class. Once added to a GEM class, connection points are available on any GEMs linked to it. If a linked GEM is converted to an unlinked GEM, it retains its connection points.

Drawing with the Connector element

The connector element draws three segments, with elbows, that are each constrained to be either horizontal or vertical. The direction of the first segment is determined by the direction you drag the connection tip when you first begin drawing with the connector.

Using configurable endpoints

All elements with configurable endpoints, such as arcs, lines, or connectors, have both connection points and connection tips at their start and end points. This configuration can be useful, for instance, when you need to show a long pipe flowing in one direction. These elements, each with an arrow endpoint, can be chained together to indicate the continuous flow.
