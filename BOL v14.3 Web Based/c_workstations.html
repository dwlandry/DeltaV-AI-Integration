The Continuous Historian subsystem

Historical data servers are available on all DeltaV workstation types, local or remote. No more than one Continuous Historian subsystem can be enabled on a single DeltaV workstation. The DeltaV Continuous Historian is the only historian supported on the ProfessionalPLUS workstation and Operator Station nodes. On Application Stations, you can use the DeltaV Continuous Historian, the Advanced Continuous Historian, or OSIsoft PI Server. You can also install an PI Server on a non-DeltaV workstation, either inside (Level 2.5) or outside (Level 3) of the DeltaV control system firewall.

Historian client support is available on DeltaV local or remote workstation nodes, including remote terminal sessions hosted by a DeltaV workstation. Communications between client application nodes and historian data-serving nodes is provided by .NET remoting facilities. Historian performance varies depending on the speed of network connections.

The table below summarizes the node support for the DeltaV Continuous Historian, the Advanced Continuous Historian, or an enterprise historian:

Workstation type Local workstation (inside DeltaV ACN) Remote workstation
ProfessionalPLUS workstation The DeltaV Continuous Historian N/A
Application Station The DeltaV Continuous Historian, the Advanced Continuous Historian, or PI Server The DeltaV Continuous Historian, the Advanced Continuous Historian, or PI Server
Operator Station The DeltaV Continuous Historian The DeltaV Continuous Historian
non-DeltaV workstation N/A PI Server

The Legacy Historian

The Legacy Historian is no longer supported as a DeltaV option. If you are using the Legacy Historian, you can migrate to the DeltaV Continuous Historian, the Advanced Continuous Historian, or PI Server. The historian selection that is best for you depends on your specific requirements for historian functionality. Consult with your local representative or Emerson service provider if you need assistance selecting the historian that best meets your needs.

Important:

Before migrating from the Legacy Historian in DeltaV version 11.3.1 or earlier to the DeltaV Continuous Historian, you must use the Continuous Historian Data Conversion utility to convert your Legacy Historian archive data to a format that can be used with the DeltaV Continuous Historian.
