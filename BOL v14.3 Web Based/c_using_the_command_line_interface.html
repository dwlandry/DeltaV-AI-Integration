Using the command line interface on the Smart Switch

You may need to use the switch command line interface, either through the serial port interface or the Telnet interface. For example, the only way to change the admin and user account passwords is through the command line interface. Additionally, you must use the command line interface to set the UTC settings.

Note:

Do not use the command line interface to set any switch configuration information that is configured either in the Network Device Command Center (NDCC) or in the switch control module directly. This includes, but is not limited to, the switch SNMP password, IP address, SysLog IP address, Trap IP address, the time server IP address, and so on.

Every time you use the DeltaV command the following is the fourth prompt you encounter: 

DeltaV: Disable Network Switch Discovery? (y/n)
[Recommended for use with DeltaV v10.x systems] [Default = y]:

Press n to enable network switch discovery. If you disable switch discovery you cannot flash switch LEDs from NDCC (Network Device Command Center).

Once you respond to this prompt you cannot back out or quit. The next prompt is: 

DeltaV: Advanced Configuration? (y/n)

Regardless of how you respond to this prompt any changes you have made to the previous prompts are saved to the switch.
