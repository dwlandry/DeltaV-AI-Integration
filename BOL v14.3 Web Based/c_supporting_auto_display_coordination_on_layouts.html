Supporting automatic display coordination on layouts

A layout can be configured to support automatic display coordination, which provides a means for operators to maintain situational awareness of the plant's overall view while easily viewing related content. Automatic display coordination is configured through a layout's display frames and applies only to displays included in a workstation's active display set. Will this frame have a navigation bar?

A navigation bar in a layout provides operators with tools that help them navigate between the displays available on their workstation. When a workstation has an active display set, these tools participate in the layout's automatic display routing and coordination.

A layout can have multiple navigation bars, if you have enabled them on multiple display frames. Each layout, however, must have at least one navigation bar enabled. If you have more than one display frame with a navigation bar enabled, each one can be uniquely configured.

A navigation bar can include the following tools:
Display call-up buttons

When a layout is using an active display set, display call-up buttons can be used to open hierarchical displays included in the active display set. Non-hierarchical displays included in the display set do not appear as display call-up buttons. They must be opened using the Search feature.

You can configure how you want these buttons to appear on the navigation bar through a display frame's Navigation Source property. They can appear as either a flat list (drop-down) or a display hierarchy. When configured to appear as a display hierarchy, you must also configure the highest level you want to show in the hierarchy, as well as how many levels you want to show and how many rows you want the display call-up buttons to appear in.

For example, if the operator should see only level 2 and 3 displays in a display frame, set the highest level to 2 and the number of levels to 2. Or, if the operator should see only level 1 and 2 displays in this frame, set the highest level to 1 and the number of levels to 2. If a layout contains only one navigation bar and you want the operator to be able to use these buttons to open any display in the active display set, you should set the highest level to 1 and the number of levels to 4.

When a workstation does not have any display sets assigned to it or does not have an active display set, display call-up buttons appear as a flat list, even if the Navigation Source property is configured as Display Hierarchy. In this case, all published displays are available from this list.

Display history buttons
Display history buttons are an optional feature and apply only to the display frame containing the navigation bar. These buttons include forward and backward arrows that operators can use to navigate between previously-opened displays, as well as an upward arrow for navigating to a parent display.
Home button
The Home button is another optional feature that applies only to the display frame containing the navigation bar. This button automatically opens the initial display in that frame.
Display relocation button
The display relocation button, which provides operators with the ability to move displays from one frame to another, gives operators the flexibility to view their displays in any area of the layout, regardless of the layout's configuration.
Alarm rollup
You can also configure a navigation bar to show an alarm rollup next to each display call-up button. The alarm rollup shows all active or unacknowledged alarms in modules, devices, and nodes from both the parent display and its child displays, according to the display set hierarchy. You can choose to include alarms from an area, unit, or equipment module in the plant hierarchy or from a specific display.

Can this frame automatically open displays of a certain hierarchy level?

The Auto-open Display Levels option allows you to designate a display frame as the default destination for all displays assigned to a specific hierarchy level. Then, all displays assigned to that level open in that display frame. For example, if you enable Auto-open Display Levels on a display frame and specify that it open level 2 displays, then all level 2 displays open in this frame, regardless of where they were opened from.

It is also beneficial to specify one display frame as the default destination for Other Displays. Then, when you open a non-hierarchical display, it opens in this display frame. If you do not configure at least one display frame in a layout for Other Displays, then non-hierarchical displays open as popup windows rather than in a display frame.

A display frame can also be assigned to open all non-hierarchical displays included in the display set by designating the frame for Other Displays rather than for a specific hierarchy level.

Auto-coordinate higher levels

When an operator opens a display, it may sometimes be helpful for him to see all the displays hierarchically related to the requested display. Enabling Auto-Coordinate Higher Levels on the display frames in a layout allows displays that are hierarchically related to each other appear together in the layout.

When Auto-Coordinate Higher Levels is enabled on a display frame, and a display opens in that frame, its parent display opens in another display frame. (If Auto-open Display Levels is enabled, parent displays open in the display frame designated for the parent's level. If Auto-open Display Levels is not enabled, parent displays open as 'other displays.'

For example, let us assume that a layout has four display frames. Each display frame is designated as the default destination for a different hierarchy level, and all four display frames have Auto-coordinate Higher Levels enabled. When the operator opens a level 3 display that is in the workstation's active display set, the following occurs:
  • The requested display opens in the display frame designated for level 3 displays.
  • The immediate parent display of the requested display automatically opens in the display frame designated for level 2 displays.
  • The grandparent of the requested display automatically opens (if not already open) in the display frame designated for overview displays.
  • The most recently viewed child display of the requested display automatically opens in the display frame designated for level 4 displays.
If a display frame does not have Auto-coordinate Higher Levels enabled, then that display frame does not participate in auto-coordinating higher levels. For example, in the scenario above, if the display frame designated for level 2 displays does not have Auto-coordinate Higher Levels enabled, then the immediate parent of the requested level 3 display does not open (because its display frame does not have Auto-coordinate Higher Levels enabled).

Participate in external coordination

External coordination allows displays requested in one display frame to open in a different frame. However, preventing external coordination applies only when displays are requested using a display frame's navigation bar.

When external coordination is prevented on a display frame (check box is checked), a display requested using this frame's navigation bar opens that display only in this frame. Displays are prevented from opening in any other frame.

When external coordination is not prevented on a display frame (check box is unchecked), a display requested using this frame's navigation bar allows that display to open in a different display frame.

Because a display frame preventing external coordination blocks displays from opening elsewhere, it can serve as a standalone workspace where operators can open any display. However, allowing external coordination does not apply to Open Display actions from within a display. If an Open Display action specifies that the display open in a certain display frame, the new display opens in the specified frame.
Tip: It is recommended that you disable the display relocation button if you are using automatic display coordination. In other words, if you enable the display relocation button, you should select the Prevent External Coordination check box.

Relocate displays from one frame to another frame

The display relocation button, which provides operators with the ability to move displays from one frame to another, gives operators the flexibility to view their displays in any area of the layout, regardless of the layout's configuration. For example, relocating displays allows operators to view multiple displays of the same level at the same time. Another example?

The display relocation button provides three options for moving displays around within the layout. These options are:
  • Option 1: Open the current display in a new window while still keeping it open in the display frame (Live Snippet).
  • Option 2: Swap the current display with a display in another display frame.
  • Option 3: Copy the current display to another display frame.

The following example demonstrates how operators can use the relocation options to view multiple displays of the same level at the same time.

Assume that you want to view two level 3 displays at the same time and that you have Auto-open Display Levels enabled on all display frames. One way to accomplish is to do the following:
  1. Open one of the level 3 displays (L3_1) in the frame designated for level 3 displays.
  2. Swap the L3_1 display with the display in the display frame containing the navigation bar.
  3. Open the other level 3 display (L3_2) in the frame designated for level 3 displays.

Then, if you still want to view the overview display here, you can move the L3_2 display to another frame by doing one of the following:

  1. Copy L3_1 to another frame
  2. Open the OverviewDsp from the display call-up buttons.
OR
  1. Open L3_1 as a new window (Live Snippet), then
  2. Open the OverviewDsp from the display call-up buttons.
Note: Enabling a navigation bar on multiple display frames provides further flexibility in relocating displays.
