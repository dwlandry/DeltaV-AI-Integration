Bulk editing PK controller's logical devices

The PK controller's port (PO1) and physical devices must be defined in the database before you can import logical devices. Create a format specification file or use the appropriate logical device FMT file and export the logical devices that were created when you configured the physical device in DeltaV Explorer. Edit the exported data as required, making sure that the values are consistent with those in the database.
Note:

Only the Ethernet/IP and Modbus TCP protocols are supported for PK controller.

The logical device FMT files are:
  • Logical_Device_EIP_Class1.fmt
  • Logical_Device_EIP_Class3.fmt
  • Logical_Device_EIP_Class3PCCC.fmt
  • Logical_Device_EIP_UCMM.fmt
  • Logical_Device_Modbus.fmt
