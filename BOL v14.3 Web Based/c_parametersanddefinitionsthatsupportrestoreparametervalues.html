Parameters and definitions that support the Restore parameter values feature

The following parameter and definitions support the restore feature:

  • User-defined, module-level parameters of valid type

  • Function block parameters of valid type

  • Batch Input Parameters on phase logic modules

  • Batch Report Parameters on phase logic modules

  • Unit parameter definitions
