Using multiple monitors on a Remote Client node

In general, you have all the normal DeltaV operating capabilities from a remote client that you would have at a LAN-connected Operator Station. However, the following considerations apply when running DeltaV Operate in a multiple monitor configuration through a remote connection:

  • The remote client must be running version 6.0 of the Remote Desktop Connection client.

    Remote Desktop Connection is available in Windows workstation and Windows Server operating system software.

  • The multiple monitors must be configured in a horizontal orientation (1×2, 1×3, or 1×4).
  • The total screen resolution of all monitors must be no greater than 4096×2048 pixels.

    Therefore, with multiple widescreen monitors configured for a screen resolution of 1680×1050, you are limited to a 1×2 layout; with multiple 5:4 aspect ratio monitors configured for a screen resolution of 1280×1024, you are limited to a 1×3 or 1×2 layout; with multiple 4:3 aspect ratio monitors configured for a screen resolution of 1024×768, you can have a 1×4, 1×3, or 1×2 layout.

  • To have the desktop of the remote client span multiple monitors, run the Remote Desktop Connection program with the /span option by typing the following at a command prompt: 
    Mstsc /span
