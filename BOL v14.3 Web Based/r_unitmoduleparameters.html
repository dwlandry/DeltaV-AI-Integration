Unit module parameters

The following parameters are specific to the unit module. Other module parameters are also used in the unit module. Those parameters are defined in the Module-level parameters topic. The phase logic also has parameters specific to the phase level.

Unit module parameters can be affected by controller phases but not by simulated phases or external phases (for example, the NUMPHASES parameter is not incremented when an external phase is executing). Conversely, external phases and simulated phases are not affected by the unit module parameters (for example, setting the $AVAILABLE parameter to a non-zero number does not affect the external or simulated phase's ability to run on a unit module.)  It is important to note that the unit selection policy's priority choice of Least Recently Used reads the value of $IDLE_TIME to select a unit. Any unit selection policy that can resolve a unit alias to a unit that has an external or simulated phase needs to take this into consideration.

Unit Module-Specific Parameters

Parameter

Units

Data Type

Description

ABNORM_ACTIVE

None

Boolean

ABNORM_ACTIVE is set to TRUE when an MERROR condition not selected in MERROR_MASK is TRUE, or an MSTATUS condition not selected in MSTATUS_MASK is TRUE.

ALARMENB

None

Boolean

Determines whether or not any unit alarming can be done. ALARMENB set to True allows alarming to occur.

ALARMENB will not clear any existing alarms when it is set.

AUTO_RESTART

None

Boolean

Set to instruct all loaded phases whether or not to auto-restart from a holding condition.

If a phase is HELD and AUTO_RESTART is set to TRUE, the phase will immediately execute its RESTART_LOGIC and go back to RUNNING (without the operator clicking Restart).

An operator can restart a phase from DeltaV Operate while the phase is still under DeltaV Batch control.

AUTO_RESTART propagates down from the unit module to all its phases.

The default value is FALSE. The phase must be in either the HOLDING or HELD state to set this parameter to TRUE.

AD_ACTIVE

None

Boolean

BAD_ACTIVE BAD_ACTIVE is set to TRUE when an MERROR condition selected in MERROR_MASK is TRUE, or an MSTATUS condition selected in MSTATUS_MASK is TRUE.

BA_HOLD

None

Named Set

Uses the named set ba_hold_state to let Batch Analytics know to pause (or resume) stage monitoring for the stage currently active on this unit.

When BA_HOLD has a value of zero (0), Batch Analytics monitors the stage.

When the value is non-zero, Batch Analytics pauses stage monitoring. Returning to 0 releases the monitoring hold and BatchAnalytics resumes monitoring.

BA_PRODUCT

None

String

Written by the phase logic as the name of the product being made where, if used by the Batch Analytics monitoring service, the value and case must match the Product Name defined in the Batch Analytics Model Builder in order for the correct batches to be monitored.

BA_STAGE

None

String

Written by the phase logic at the beginning of each stage, where, if used by the Batch Analytics monitoring service, the value and case must match the Stage Name defined in the Batch Analytics Model Builder in order for the stage model to be executed and results displayed for the stage.

Maximum of 32 characters.

BATCH_ID*

None

String

BATCH_ID Records the ID of the batch for the phase at run-time.

BLOCK_ERR

None

Option bitstring

There are 16 possible block errors. Each function block that has the BLOCK_ERR parameter reports one or more of these errors.

Note Errors can be set by the assigned fieldbus device. Refer to the device reference manual for specific device generated error definition.

The module-level BLOCK_ERR parameter reports the same errors as the function block parameter. A true bit in the module parameter indicates that one or more function blocks in that module have that BLOCK_ERR bit set. Please refer to the Books Online Configuration Manual for specific information about how this parameter is used.

EXEC_TIME

Microseconds

32-bit signed integer

The time it takes to execute the module.

FREMEM

None

32-bit unsigned integer

A diagnostic parameter used to show the free memory of a device through the unit (without knowing in which device the unit is running).

MAX_RESERVED

None

8-bit unsigned integer

Determines the maximum number of concurrent phases in a recipe that can be started manually or externally.

For example, the maximum number of concurrent phases is 10. If MAX_RESERVED is set to 2, the maximum number of concurrent phases is 8. 2 slots (in this example) are reserved for external or manual control.

The initial value is one (1) providing one assignment slot available for an external or manual phase initiation. This guarantees that one slot is always available for an emergency shutdown phase that can be run manually, if and when you needed to run the phase.

If set to 0, the Batch Executive has priority over the use of the slots and Manual control might not be possible. If set to 10, then no phases can be executed by recipes.

MCOMMAND

None

Named Set

Allows users to enable or disable the module by setting the module state to In Service or Out of Service. When a module is Out of Service execution of the function blocks in the module stops and function block parameter values and status do not change. A parameter's status will not indicate an out of service condition unless the function block containing it was taken out of service before the module.

Note Out of Service does not affect external references used to read the output of other modules, controllers or devices, into the active module. The external reads continue even in Out of Service mode, but are not processed by the module.

MERROR

None

Option bitstring

Indicates if the module has a problem. The parameter continues to indicate a module error as long as errors are present. When the error condition is no longer present, MERROR returns to a value of Okay (zero). Possible error states are: Algorithm Error - a configuration problem with the algorithm. An example is a calc/logic block with no configured expression. IO Input Error - a component block cannot read the I/O. An example is an unconfigured DI function block.

IO Output Error - a component block cannot write the I/O. An example is an unconfigured ISEL block. Input Transfer Error - a problem exists in transferring values between function blocks. An example is an unresolved external reference type input parameter feeding an input to a transfer function block Output Transfer Error - a problem exists in transferring a value between a function block and a module parameter. An example is an unresolved external reference type output parameter fed from the output from a transfer function block.

Alarm Processing Error - a configuration error on an alarm definition. FBBadActive - a problem exists in one of the function blocks in this module. That function block will have the BAD_ACTIVE parameter set to True. An example is a DO function block, set to Out of Service mode, with BAD_MASK having Out of Service set true.

MERROR_MASK

None

Option bitstring

You configure this option bit string to determine what subset of MERROR events or conditions cause the BAD_ACTIVE parameter to be TRUE. The MERROR events and conditions which are not included in this mask will cause the ABNORM_ACTIVE parameter to be TRUE.

NUMPHASES

None

8-bit unsigned integer

Contains the number of phases that are currently loaded on the unit. This parameter cannot be changed by the user.

OPERATION*

None

String

Returns the name of the operation associated with the unit.

PROCEDURE*

None

String

Returns the name of the procedure associated with the unit.

UNITPROCEDURE*

None

String

Returns the name of the unit procedure associated with the unit.

VERSION

None

32-bit unsigned integer

Displays the version of the object as stored in the Version Control database, if Version Control is enabled. Otherwise, stores any integer you set it to.

$AVAILABLE

None

Named Set

Contains a value of the named set equipment_availability. The default set contains the value OK = 0 and Not Available = 255. Other values can be defined to represent reasons why the equipment is not available. Any non-zero number is evaluated as not available.

If deleting a unit module that has been assigned to a node and when the running batch might use the unit, then set this parameter to a non-zero value first or change MSTATUS to OOS. Otherwise, the batch will go to HELD if the batch tries to run on this unit.

$IDLE_TIME

Seconds

32-bit unsigned integer

Records the time (in seconds) that the unit has been idle. Resets to zero (0) when NUMPHASES is non-zero. The display is updated every 60 seconds or every scan rate if slower than 60 seconds. This parameter clamps at a 365 day limit.

This parameter is not affected by phase logic modules (PLM) or external phases (such as Soft Phases).

Additionally, this parameter is not incremented when the unit module is out of service (MSTATE = OOS)

* This parameter's value is written when the batch acquires the unit (that is, the operation's initial step completes). This parameter's value is cleared when the unit is released by the batch. If the option to acquire the unit prior to starting the unit procedure is selected, the value is not cleared until a unit procedure without the option selected runs on the unit.

Note:

The data types used in these parameters refer to standard DeltaV parameter data types.

These parameters are filtered.
