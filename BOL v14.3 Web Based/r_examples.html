Examples

  • The following command backs up all the current event data sets to the \DeltaV_EC_Backups directory on the C: drive. If the directory does not exist, it will be created as part of the backup process.

        ECBackup c:\DeltaV_EC_Backups

  • A UNC path may also be defined for the backup directory. The shared folder should have full control permissions.

        ECBackup \\server\share

  • The following command backs up all current event data sets and deletes all backed up event data sets whose end times are prior to 15 days before the backup.

        ECBackup c:\DeltaV_EC_Backups  /DeleteIfGTDays:15

  • The following command backs up all current event data sets whose Backup Status is "Modified." In the Event Chronicle Administration application, the Backup Status field changes from "Modified" to "Backed Up."

        ECBackup c:\DeltaV_EC_Backups  /OnlyIfModified

  • The following command backs up all current event data sets and allows for retries if certain error conditions exist. The retry rate is once per minute and must be greater than or equal to 0 and less than 721. If the switch is not specified, the backup utility defaults to 5 retries. If the database does not become available during the retry period, an error will be logged stating that the retry period was exceeded.

        ECBackup c:\DeltaV_EC_Backups  /Retries:20
