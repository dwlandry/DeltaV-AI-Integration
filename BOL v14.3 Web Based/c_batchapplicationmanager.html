Batch Application Manager

You can monitor the running of the Batch Executive through the Batch Application Manager. This application displays a current snapshot of the status of all functions handled by the Batch Executive. To open the Batch Application Manager, click Start > DeltaV Batch > Application Manager.

Note:

In a Redundant Batch system, run the Batch Application Manager on the active node (either active Batch Executive or active Campaign Manager) to be able to start, stop or access advanced functions for that server.

The fields on the Batch Executive tab of the Batch Application Manager dialog are described below.

Administer Section

  • Executive Name - Enables selection of a Batch Executive. There can be up to four enabled Batch Executives on a DeltaV system and some or all of the Batch Executives can run simultaneously.

  • Start - Click this button to start the Batch Executive.

  • Stop - Click this button to stop the Batch Executive.

  • Advanced - click this button to open the Batch Executive Advanced dialog which lets you administer individual batches (including the ability to force a shutdown of a batch) and change configuration settings.

Batch Executive Status Section

  • Started At - Displays the date and time the Batch Executive was started.

  • Version - Displays the version number for the Batch Executive.

  • Batch Count - Displays the number of batches currently in the batch list.

  • Service Status - Displays the status of the Batch Executive.

  • Connected Clients - Displays the number of clients currently connected to the Batch Executive.

  • Prompts Count - Displays the number of prompts issued by the Batch Executive.

Phase Server(s) Status Section

  • Displays information about the other servers (such as a Soft Phase Server) connected to the Batch Executive. The server name and status are listed for each attached server.

Phase Verification Section

  • Total Phase Count - Displays the total number of phases.

  • Bad Phase Count - Displays the number of bad phases.

  • Phaseswindow - Displays the phases with a status of Bad after running the Verify Phases process.

  • Verify Phases button - Runs through each phase processed by the Batch Executive, counts the number of phases, and verifies their status.

Messages Section

  • Displays messages about the Batch Executive's status and availability.

Once you have started the Batch Executive service and have completed the verification of its status, close the Batch Executive Manager. The Batch Executive service will continue to run.

Advanced Button

Clicking the Advanced button opens a new dialog with the advanced features for managing your Batch Executives.

The advanced features include:

  • Snapshot Logs - takes a snapshot of all the pertinent runtime information (the batch's runner directory, EVT file and the standard batch log files) about a batch using the Snapshot Logs button on the Administer Batches tab of the Advanced dialog. The files are copied into a folder under the DeltaV\DVData\Batch\Logs folder.

  • Force Shutdown - forces a shutdown of a batch without stopping the Batch Executive.

  • Configuration Settings - settings to customize the operation of your Batch Executive.

  • Revoke Equipment - manual release of equipment currently owned by a batch.
