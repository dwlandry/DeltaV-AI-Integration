SIS Composite Blocks

The only valid SIS composite block type is embedded. Linked composites are not supported. From Control Studio you can create templates for SIS composites in the library for reuse or you can create individual SIS composites while editing an SIS module. You can protect templates to prevent unauthorized changes to the logic of embedded composites.

Because SIS composites are embedded, an embedded composite does not change if you subsequently modify the template it was created from. The embedded composites are separate, standalone blocks.

Use composite blocks to encapsulate portions of logic that are used multiple times in a configuration. SIS composite blocks cannot be nested and can contain only SIS function blocks and items from the Special Items palette.
