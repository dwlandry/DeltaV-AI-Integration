toTimeString function

Converts the time portion of a Date object into a string, according to local time.
Arguments
0
Return values (string)
A string, representing the time portion of the Date object.
Syntax
dateObj.toTimeString()
Examples
Example Result
This script is added, as a custom script on an action, to any element with a Label property, such as a button. 
var d = new Date(); 
this.Label = d.toTimeString();

Returns "13:45:55 GMT-0600 (Central Standard Time)” on the element's label.

(The return value is adjusted for current local time.)

With Button2 nested inside a GEM, this script is added as a custom script on a Button2 action. 
var event = new Date('August 19, 1975 23:15:30');

Gem.Button2.Label = event.toTimeString();
Returns "23:15:30 GMT+0200 (CEST)" on Button2's label

(Your time zone may vary.)

With Button1 on a display, this script is added as a custom script to a Button1 action. 
var d = new Date(1993, 6, 28, 14, 39, 7);
Dsp.Button1.Label = d.toTimeString();
 Returns "14:39:07 GMT-0600 (PDT)" on Button1's label.
