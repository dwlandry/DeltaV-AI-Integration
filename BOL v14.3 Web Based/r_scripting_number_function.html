Number function

The Number function converts a value to a number.
Arguments
0–1, Optional arguments are indicated by a ? following the argument name.
Argument Description
value? The value to be converted to a number.
Return values (number)
A number representing the given value.
NaN, if the value cannot be converted to a legal number.
0, if no argument is provided.
Syntax
Number(value)
Examples
Example Result
Assuming you have:
  • the module parameter, CONTROL1/VALUEPLUSEU.CV
  • a button (Button1) on a display
  • the following script added as a custom script to a Button1 action 
Number(DLSYS.["CONTROL1/VALUEPLUSEU.CV"])
 Returns "NaN" on Button1's label.
Assuming you have:
  • the module parameter, U012-FICA-5625-C/PID1/PV.CV, with a value of 20
  • a button (Button1) on a display
  • the following script added as a custom script to a Button1 action 
Number(DLSYS["U012-FICA-5625-C/PID1/PV.CV"])
 Returns "20" on Button1's label.
