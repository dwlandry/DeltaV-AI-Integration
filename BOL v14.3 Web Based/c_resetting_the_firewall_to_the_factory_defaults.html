Resetting the firewall IPD to factory default settings

If a configuration change has been made and the firewall IPD no longer operates properly, you may need to reset the firewall IPD to factory default settings. First you must determine whether the firewall IPD is causing the problem. For example, if there is no communication to controllers, reset the firewall IPD, temporarily bypass the firewall IPD with a jumper cable, or replace the firewall IPD. If removing or replacing the firewall IPD solves the problem, try resetting the firewall IPD to factory default settings.

Note: You can perform this procedure while the firewall IPD is online. However, it causes a reboot and communications will be lost on the affected DeltaV network (Primary or Secondary) for approximately 30 seconds. Rebooting the firewall IPD while it is online is similar to rebooting a managed Ethernet switch on the network. Ensure that you do it at an appropriate maintenance time.

Complete the following steps to reset the firewall IPD to factory default settings:

  1. With the serial terminal attached to the V.24 port on the firewall IPD, remove power to the firewall IPD and closely watch the serial terminal monitor. Within a few seconds after the reboot, the following line is briefly displayed: Press <1> to enter System Monitor 1...
  2. Press 1 immediately to display the System Monitor 1 menu.
  3. Press 5 to erase the main configuration menu.
  4. Press Return to delete the file and reset the firewall IPD to factory default settings.
Note: If other configurations were customized for your site, you must reenter the IP address and configurations.

When this procedure is complete, reconnect the firewall IPD and determine if communications have been restored. If not, return the firewall IPD for replacement.
