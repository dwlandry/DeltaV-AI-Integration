Install DeltaV Reporter

DeltaV Reporter can be installed on a DeltaV workstation or on an office computer capable of connecting to the Continuous Historian or Event Chronicle node. DeltaV Reporter users must have a valid DeltaV user account.

You must install .NET Programmability Support before you install DeltaV Reporter. See the following procedures for information on installing .NET Programmability Support and DeltaV Reporter.

Install the .NET Programmability Support

  1. Use the Control Panel in Windows to open Programs and Features.
  2. Select Microsoft Office, and then click Change.
    Note: The version number for Microsoft Office might be included in the item, for example, Microsoft Office 2016.
  3. In the Office Setup dialog, select Add or Remove Features, and then click Continue.
  4. Expand Microsoft Excel on the list of Microsoft Office programs.
  5. Click the down arrow on .NET Programmability Support.
  6. Select the Run from My Computer option, and then click Continue.
  7. After the configuration process concludes, click Close.
  8. Close the Programs and Features window.

Install DeltaV Reporter

  1. Insert the DeltaV installation disk #1 in the drive, and then navigate to the DV_Extras\DeltaVReporter folder. To run the DeltaV Reporter Setup Wizard, double-click the setup.exe program.
  2. If you are prompted to install the Shared Add-in Support Update for Microsoft .NET Framework, click Install.
  3. On the Welcome screen, click Next.
  4. On the .NET Programmability Support screen, click Next.
  5. On the Select Installation Folder screen, click Next to accept the default directory for installation.
  6. On the Confirm Installation screen, click Next to start the installation.
  7. After the installation concludes, click Close.

By default, DeltaV Reporter is installed in the C:\Program Files (x86)\Emerson Process Management\DeltaV Reporter folder. During the installation of DeltaV Reporter, important sample Excel workbook files are copied to the C:\DeltaV Reporter\Definitions folder. You can use these as examples of using the DeltaV Reporter worksheet functions and as templates to create report definition files for automatically generating scheduled reports from the Event Chronicle database.

The .NET Programmability Support must be installed before Excel is used with DeltaV Reporter. If Excel is started without .NET Programmability Support, you should follow the steps above to add the required support and then reactivate DeltaV Reporter by running the ExcelAddIn.reg file from the installation folder (by default, C:\Program Files (x86)\Emerson Process Management\DeltaV Reporter).

Note:

Refer to the Release Notes KBA for compatibility information. Office Service Packs and Microsoft Office updates may be required for proper operation of Excel.

DeltaV Reporter must be uninstalled and reinstalled with each upgrade of the DeltaV System to a new version. You can uninstall DeltaV Reporter by either using the Programs and Features applet in Control Panel or by rerunning the DeltaV Reporter setup.exe program in the DeltaV\bin\DeltaVReporter folder and selecting the Remove option.
