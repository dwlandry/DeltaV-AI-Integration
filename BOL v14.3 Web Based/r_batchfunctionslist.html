Batch functions list

The following table lists the batch operation functions, what the function does, which is the default lock this function is associated with, and if the function is area specific.

Function Name

What the Function Allows

Default Associated Lock

Is Function Area Specific?

BATCH_ABORT

abort a running batch.

Batch Operate

Yes

BATCH_ACK_PROMPT

acknowledge an operator prompt.

Batch Operate

Yes

BATCH_ACQUIRE_RELEASE

acquire and release equipment.

Batch Operate

Yes

BATCH_ACQUIRE_REORDER

reorder the batch in the needed by equipment arbitration list.

Batch Operate

Yes

BATCH_ACTION_VERIFY

verify an action (usually supervisors are granted the key to the lock associated with this operation).

Batch Operate

Yes

BATCH_ACTIVE_STEP_CHANGE

access the Active Step Change function.

Also allows user to force a recipe transition.

Batch Operate

Yes

BATCH_ADD

select a recipe and load a batch.

Batch Operate

Yes

BATCH_AUTO_MANUAL

change the auto/manual status of a running batch.

Batch Operate

Yes

BATCH_CHANGE_SELECTION_MODE

change the selection mode of a unit alias when creating a batch or rebinding equipment.

Note:  When user ID verification is enabled, the system checks the confirmer's privileges for this function's key.

System Admin

No. Must have Area_A or <Sitewide> assigned

BATCH_CLEAR_FAILURES

clear all failures on a running batch.

Batch Operate

Yes

BATCH_CONTROL_START

start the Batch Executive.

Batch Operate

No. Must

have Area_A or <Sitewide> assigned

BATCH_CONTROL_STOP

force a shutdown of individual batches.

Note: Stopping the Batch Executive requires that the logged in user have Windows Administrative rights.

Batch Operate

No. Must

have Area_A or <Sitewide> assigned

BATCH_HISTORY_COMMENT

add a comment to the batch history.

Batch Operate

No. Must

have Area_A or <Sitewide> assigned

BATCH_HISTORY_GOLDEN_BATCH

set the delete protection on a batch in the Batch Historian. If delete protection is set, the batch can be archived but not deleted. Delete protection is set by a Batch History View user by selecting the Mark As Reference option in the Batch History View application.

System Records

No

BATCH_HOLD

put a running batch on hold.

Batch Operate

Yes

BATCH_MODIFY_PARAMETER

modify locked recipe parameters after the batch has been created.

Batch Operate

Yes

BATCH_MODIFY_LOCKED_PARAMETER

modify locked recipe parameters at batch creation and after the batch has been created.

Batch Operate

Yes

BATCH_OI_CONFIGURE

access the Batch OI Configuration tool and the Batch Application Manager's Advanced functions.

Can Configure

No

BATCH_OI_START

start the Batch Operator Interface.

Batch Operate

No. Must

have Area_A or <Sitewide> assigned

BATCH_OI_STOP

exit the Batch Operator Interface.

Batch Operate

No. Must

have Area_A or <Sitewide> assigned

BATCH_PHASE_CONTROL

perform manual phase control.

Batch Operate

Yes

BATCH_RECIPE_DOWNLOAD

perform partial downloads of recipes from DeltaV Explorer and Recipe Studio.

Build Recipes

No

BATCH_RECIPE_EDIT

create/rename/delete/copy recipe

change recipe properties

change other recipe parameter properties

create/rename/delete recipe formula

change recipe formula properties

change value of a recipe parameter for a formula

Build Recipes

No

BATCH_REMOVE

remove a completed batch from the Batch list.

Batch Operate

Yes

BATCH_RESET

resets a top-level batch from a terminal state (COMPLETE, STOPPED, ABORTED) back to READY. Applies to a batch where the top-level batch owns equipment.

Batch Operate

Yes

BATCH_RESTART

restart a held batch.

Batch Operate

Yes

BATCH_RESYNC_RECIPE

resynchronize a batch on restart (either warm or cold restart).

Batch Operate

No. Must

have Area_A or <Sitewide> assigned

BATCH_REVOKE_EQUIP

revoke a batch through the Batch Application Manager.

Batch Operate

No. Must

have Area_A or <Sitewide> assigned

BATCH_SEL_EQUIP_TRAIN

Reserved for future use.

Batch Operate

BATCH_SELECT_UNIT

Reserved for future use.

Batch Operate

BATCH_START

start a loaded batch.

Batch Operate

Yes

BATCH_STOP

stop a running batch.

Batch Operate

Yes

RECIPE_APPROVAL_01 through RECIPE_APPROVAL_05

approve a recipe for download. A recipe is authorized for download when all approvals are signed. Up to 5 approvals are allowed.

User Lock 06 through User Lock 10. (User Lock 06 is the default lock for RECIPE_

APPROVAL_01, User Lock 07 is the default lock for RECIPE_

APPROVAL_02, and so on.)

No. Must have Area_A or <Sitewide> assigned.

VC_DOWNLOAD_UNAUTHORIZED

download an unauthorized recipe.

System Admin

No
