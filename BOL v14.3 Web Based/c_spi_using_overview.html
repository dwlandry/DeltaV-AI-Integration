SPI: using the add-ins

If you have a SmartPlant Instrumentation version specified in SmartPlant Excel Interface you can move configuration information in both directions between SPI and the DeltaV configuration database.

One possible work flow for using the SmartPlant Instrumentation interface to configure DeltaV instrumentation configuration is the following. Set up the system:

  1. Create card and channel configurations in DeltaV Explorer.

  2. Set up the Excel add-ins.

  3. Install the Intergraph components.

  4. In DeltaV Explorer, import SPI compatible engineering units fhx file into the DeltaV database.

  5. In Excel, regenerate the engineering units.

The SPI compatible engineering units are now available in Excel.

  1. In Excel, publish to SPI.

  2. In SPI, retrieve the card and channel configurations.

  3. Configure instrumentation using the SmartPlant Instrumentation application and associate it with the I/O configuration.

  4. In SPI, publish the instrumentation configuration.

  5. In Excel, retrieve the instrumentation configuration.

  6. Make any changes required in Excel.

  7. In Excel, save the instrumentation configuration to the DeltaV database.

  8. In DeltaV Explorer, configure control strategies and assign I/O parameters to DSTs and fieldbus blocks.

  9. Commission the system.

Finally, to update the Excel and SPI versions of the configuration to match the DeltaV database:

  1. In Excel, publish the configuration to SPI.

  2. In Excel, load the controller configuration into the workbook.

  3. In SPI, retrieve the configuration.
