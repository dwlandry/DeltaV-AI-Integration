Verify the location of the DeltaV OPC Data Server

On the client machine, the DeltaV OPC Data Access Server application, FrsOpcDv, must be set to run on the server machine. This is set up automatically when OPC Remote is installed, and can be verified by completing the following steps:

  1. Run the executable file, dcomcnfg.exe. The Component Services window opens.
  2. In the left pane, open Component Services. A Computers folder appears.
  3. Open the Computers folder. The My Computer icon appears.
  4. Open the My Computer icon. Several folders appear.
  5. Open the DCOM Config folder.
  6. In the list of applications, right-click FrsOpcDv, and then select Properties.
  7. Select the Location tab. The Run application on the following computer check box should be selected and the name of the server machine should be listed.
