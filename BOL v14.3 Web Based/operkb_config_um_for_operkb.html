Configure unit modules for Operator Keyboard

Be sure that you have read about alarm management for the Operator Keyboard. The person responsible for configuration configures modules and module alarms and assigns modules to specific units based on logical groupings of plant equipment or processes. This person also creates a unique Primary Control Display for each module and unit, assigns each unit to the unit alarm button in  DeltaV Operate, and uses this and other dynamos to create a display called the Operator Keyboard screen from which screen navigation and operation is managed. When a module goes into alarm, the associated button flashes on the Operator Keyboard screen and alerts the operator. In this way, Operator Keyboard software provides operators rapid access to modules in alarm.

  1. Open DeltaV Explorer (Start > DeltaV Engineering > DeltaV Explorer).

  2. Under Control Strategies, select an area, click the right mouse button, and click New > Unit Module.

  3. Configure the unit module in the New dialog box. Use the New dialog box's context sensitive help or the DeltaV Explorer online help for help on configuring the unit modules.

  4. To create modules under the unit module, select the unit module, click the right mouse button, and select New Module.

  5. Create the new module and click OK.

  6. To configure a module's properties, including its Primary Control Display, right click the module and select Properties.

  7. Continue to add and configure modules as required for your process.

Important:

A module can belong to only one unit.

To configure module alarms

Configure module alarms in DeltaV Control Studio

  1. Open Control Studio (Start > DeltaV Engineering > Control Studio).

  2. Right click in the Alarm View area and select Add to add an alarm to a module.

Refer to the Control Studio online help and to Books Online for more information on adding and using alarms.
