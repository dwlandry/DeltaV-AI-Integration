High Performance AT valve dynamo (HP_AT_VLV_)

The foreground color of the control valve is the active state color (based on the DeviceControl_ColorGrey threshold table) when PID block's OUT is greater than the value of global variable gn_AVLV_Open (default = 2). Otherwise, the foreground color is the passive state color.

The edge color of the control valve is per the DCEdge Color in the NamedColors threshold table.

This dynamo can be used for control valve indication with PID loop modules.

The following elements are present on the dynamo:

  • Alarm box

  • Alarm icon

  • Display tag

  • Dynamo background

  • OUT bar graph

  • Abnormal status icon
