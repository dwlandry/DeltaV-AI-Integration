# About BooksOnline

BooksOnline is DeltaV’s documentation system. We have a local HTML-based version:
- 10,000+ HTML files
- Hierarchical navigation
- Covers installation, configuration, and diagnostic help

We plan to parse and index it for AI-driven semantic search.
