setDate function

Sets the day of the month for a specified date object, according to local time.
Arguments
1
Argument Description
day An integer representing the day of a month.

1–31 are the expected values, but 0, -1, or 32 can also be used.

Return value (number)
A number representing the number of milliseconds between the date object and midnight January 1 1970.
If the argument is 0, returns the last day of the previous month.
If the argument is -1, returns the day before the last day of the previous month.
If the argument is 32, and the month has 31 days, returns the first day of the next month.
If the argument is 32, and the month has 3o days, returns the second day of the next month.
Syntax
dateObj.setDate(day)
Examples
Example Result
This script is added, as a custom script on an action, to any element with a Label property, such as a button. 
var d = new Date();  
d.setDate(15);  
this.Label = d.getDate();
 Returns 15 (the day of the month) on the element's label, replacing the current day.
