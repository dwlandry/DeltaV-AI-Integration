MA3_CV_ML_ analog dynamo, 3 function blocks, medium thick vertical combination bar graph

This dynamo can be used for analog indication where general percent of scale is important and both vertical and horizontal space on the display is available. Used with PID loops, AI indicators, and ALM function blocks.

The following elements are present on the dynamo:

  • Alarm Icon

  • Combination (Combo) Bar Graph

  • Display Tag

  • Dynamo Background

  • Engineering Units Descriptor

  • Mode Icon

  • PV Data Field

  • Status Icon
