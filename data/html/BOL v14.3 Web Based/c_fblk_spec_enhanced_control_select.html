Enhanced Control Selector function block

The Enhanced Control Selector (ECTLSL) function block selects one of sixteen control signals as the master of the slave controller when multiple masters are available to perform override control to a PID function block.

The Enhanced Control Selector function block supports mode control. The outputs are calculated based on the actual operation mode, which is determined by the value of parameters and the status of input values.

There are no standard alarms in the Enhanced Control Selector function block. Custom alarms are supported.

Enhanced Control Selector function block

BKCAL_IN: The analog input value and status from the BKCAL_OUT output of a downstream function block that is used for backward output tracking with bumpless transfer.

OP_SELECTION: If not set to Auto selection, selects the corresponding input. If set to Auto selection, the algorithm specified by SEL_TYPE selects the input.

SEL_1: The first input value to the selector.

SEL_2: The second input value to the selector.

SEL_3: The third input value to the selector.

OUT: The analog output value and status.

SELECTED: Indicates the selected input.

BKCAL_SEL1: The selector output value associated with SEL_1 for backward output tracking to an upstream PID function block.

BKCAL_SEL2: The selector output value associated with SEL_2 for backward output tracking to an upstream PID function block.

BKCAL_SEL3: The selector output value associated with SEL_3 for backward output tracking to an upstream PID function block.
