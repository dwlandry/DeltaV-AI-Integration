Create and distribute a protected SIS composite template

The protected template is created at one engineering location and distributed to other engineering locations.

At the location where the template is developed

The general steps to create a protected SIS Composite Template  are:

  1. An engineer creates a new SIS Composite Template and an SIS Module that uses it. 

    Parameters within the composite that need to be written to from outside the composite must be promoted to composite-level parameters. The parameters must be included in SIS Parameter Security or the default lock for SIS Parameters must be changed from SIS No Access.

  2. The engineer then downloads the SIS Module, opens the SIS Module in Control Studio, and debugs the functionality of the template.

  3. If changes are required, the engineer edits and saves the template. 

  4. The engineer edits every block in the SIS module that uses the template and selects Convert > To Existing Object to update the Embedded Composite to the latest version.

  5. The engineer downloads the SIS Module, and continues debugging in Control Studio.

  6. When the template is fully tested and ready for distribution, the engineer protects the template.

  7. The engineer exports the template and the .fhx file produced is sent to other engineering locations.

If you are including protected SIS Composite Templates in modules you are creating for distribution, you must protect the templates before you add them to modules. If you protect an SIS Composite Template after you create modules that contain the embedded templates, the composites in the modules are not protected.

At target engineering locations 

The SIS Composite Template is imported. The newly imported protected SIS Composite Template can be included in SIS Modules in Control Studio when adding an embedded block or converting an existing embedded block to use an existing template. The only editing option available on the embedded block is to set the parameter values of exposed parameters.

Note:

Any SIS Protected Composite parameters whose values are to be changed must be included in SIS Parameter Security or the default lock for SIS Parameters must be changed from SIS No Access.

The protected SIS Composite Template cannot be unprotected, edited to change anything about it, or copied.
