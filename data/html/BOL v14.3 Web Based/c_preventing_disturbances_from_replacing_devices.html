Preventing process disturbances after replacing devices

To prevent process disturbances, carefully follow these instructions before automatically replacing fieldbus devices.

For Processes not Performing Control

  • Ensure that the replacement device matches the manufacturer, type, revision, and device tag of the device to be replaced.

  • Select the data master for automatic device replacement in the DeltaV System Properties dialog. This selection determines the direction of data transfer during the replacement process.

  • Connect the device to the segment.

  • Ensure that the control's input values are in the expected nominal range.

  • Check Process History View to verify that the device replacement was successful.

For Processes Performing Critical Control

  • Do not assign a device tag to the replacement device.

  • Select the data master for automatic device replacement in the DeltaV_System Properties dialog. This selection determines the direction of data transfer during the replacement process.

  • Ensure that all control loops are in Manual mode.

  • Connect the device at a standby address and use a handheld device or the DeltaV system to preconfigure (calibrate, check sensors, and so on) the device. Assign the device tag after calibrating the device to ensure it is functioning properly.

  • Attach the device to the fieldbus segment.

  • Ensure that the control's input values are in the expected nominal range.

  • Return the control loops to their normal operating mode.

  • Check Process History View to verify that the device replacement was successful.

For Processes Performing Control that is not Critical

  • Ensure that the replacement device matches the manufacturer, type, revision, and device tag of the device to be replaced.

  • Select the data master for automatic device replacement in the DeltaV_System Properties dialog. This selection determines the direction of data transfer during the replacement process.

  • Place the control loop in Manual mode. Automatic mode is acceptable but Manual mode is preferred.

  • Connect the device to the segment.

  • After the device is successfully replaced, check that the control's input values are in the expected nominal range.

  • If the loop was placed in Manual mode, return it to its normal operating mode.

  • Check Process History View to verify that the device replacement was successful.
