Configure the secondary Application Station (the preferred standby)

  1. On the Application Station that you deleted in DeltaV Explorer earlier, apply the workstation configuration file by clicking DeltaV/Installation/DeltaV Workstation Configuration on the Start menu.
  2. When the introductory DeltaV Workstation Configuration dialog appears, click Next.
  3. When prompted to select your workstation type, select the Professional / Operator / Application / Base / Inter-Zone Server option, and then click Next.
  4. When prompted to provide the workstation configuration file that you made in DeltaV Explorer, click Browse, navigate to the exported workstation configuration file, and double-click it.
  5. In the DeltaV Workstation Configuration dialog, select the workstation name, and then click Next. The following message appears: A node with a Redundant Subsystem has been selected. Is this the preferred active Application Station? Respond No to this prompt now. When you respond No, the characters _S are appended to the name specified for the Application Station in DeltaV Explorer.
    Important:

    When the message appears, advising you that any historical database stored on this Application Station will be deleted, click Yes to continue with this procedure, if you have no historian data sets to protect. Otherwise, click No to discontinue this procedure until you have backed up or exported historian data sets. After backing up your historian data sets, restart this procedure of importing the workstation configuration file.

  6. Follow the on-screen instructions to complete the installation of the second Application Station.
