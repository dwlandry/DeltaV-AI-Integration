Module detail displays

The module library includes several pop-up detail displays that can be invoked from the pop-up faceplate (instrument) displays. After the faceplate has been opened by selecting the faceplate icon on the process graphic, the detail display can be opened by selecting the icon in the lower left part of the faceplate. The detail displays, like the faceplates, are located in the DELTAV\DVDATA\GRAPHICS-iFIX\PIC\DETAIL subdirectory. The following faceplates are stored in the DETAIL subdirectory:

AALM_dt

Used by the AALARM monitoring module template.

AI_dt

Used by the ANALOG monitoring module template.

ALM_FLD_SUP_dt

Used by the Alarm flood suppression module templates.

ALM_FO_SUP_dt

Used by the First out alarm suppression module template.

RMT_SPM_dt

Used by the Rosemount Statistical Process Monitoring module templates.

CDA_dt

Used by modules with command-driven algorithms

DL_dt0

Used by the motor and valve module templates that do not have interlocks (that is, that do not contain _ILOCK in the name).

DL_dt1 

DL_dt2

DL_dt3

DL_dt4

DL_dt5

DL_dt6

DL_dt7

DL_dt8

Used by the motor and valve module templates that have interlocks (that is, do contain _ILOCK in the name). The difference in these displays is in the number of interlock condition descriptions shown.

DTC_dt

Used by the PID_DEADTIME module template.

FFLP_dt

Used with the fieldbus loop module template, FF_PID_LOOP. Similar to Loop_DT.

FLC_dt

Used with the Fuzzy Logic Control templates, FLC_LOOP and SIM_SR_FLC. Similar to LOOP_DT.

GS_dt

Used by the PID_GAINSCHED module template.

Loop_dt

Used by the PID Loop module templates (PID_LOOP, CASCADE_MASTER, CASCADE_SLAVE).

LOOPM_dt

Used by MPC loop modules

PI_dt

Used with the PULSE monitoring module template.

PLM_dt

Phase Logic module detail display.

SDA_dt

Used by modules with state-driven algorithms.

SR_FLC

Used by the FLC Simulation module template, SIM_SR_FLC.

SR_PID

Used by the PID Simulation module template, SIM_SR_PID.

TAGAI_dt

Tag AI integration module detail display.

TAGAO_dt

Tag AO integration module detail display.

TAGDI_dt

Tag DI integration module detail display.

TAGDO_dt

Tag DO integration module detail display.

UM_dt

Batch Unit module detail display.

UMC_dt

Continuous Unit module detail display.

It is recommended that you use the Update Popup Pictures button on the DeltaV Utilities toolbar if you modify pop-up pictures. Refer to Updating Pop-up Pictures and Dynamos in the topic Working with Pictures - Additional Functions for more information.

Note:

The DISCRETE monitoring module template does not have a detail display. All necessary information is incorporated in the faceplate display.
