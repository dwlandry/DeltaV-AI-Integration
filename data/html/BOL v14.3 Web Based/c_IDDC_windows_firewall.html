Firewalls and the Independent DeltaV Domain Controller

Windows Firewalls

On all DeltaV nodes, the Windows Firewall is disabled on the DeltaV ACN NICs (Network Interface Cards). This must occur on the Independent Domain Controller as well.

For non-DeltaV networks, (such as the 3rd NIC on the IDDC), configure the Windows Firewall to allow only the domain authentication traffic through.

Physical Firewalls

To protect the DeltaV ACN, an optional, physical Firewall-IPD is available with rules to allow only the domain authentication and time synchronization traffic through. The Emerson Firewall-IPD is used on the DeltaV ACNs (primary and secondary, where exists). It is connected between the Independent DeltaV Domain Controller (IDDC) and the rest of the DeltaV workstations.

Firewall Rules for all Firewalls

The following table outlines the rules to configure on your firewall. These rules ALLOW communication through the firewall on the ports specified in the direction specified (where the Independent DeltaV Domain Controller is the point of reference). The Emerson Firewall-IPD comes with the rules configured. Other firewalls (including the Windows firewall) might also need the rules to be created.
