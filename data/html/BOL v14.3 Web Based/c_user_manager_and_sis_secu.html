DeltaV User Manager and SIS security

The DeltaV User Manager allows you to manage Windows users and DeltaV users without accessing the Windows User Manager application. The procedure for assigning keys to SIS locks is identical to that for DeltaV basic process control system locks.

When DeltaV System Preferences for SIS is enabled, an additional set of locks, called SIS locks, appears in a new pane on the main window for DeltaV User Manager.  There are three SIS groups (SIS Engineering, SIS Operate, and SIS Supervise). By default, the SIS Engineering group has all SIS keys and the SIS Operate and SIS Supervise groups have some SIS keys.

An additional default user account, SIS_Configure, is added when the DeltaV software is installed. You must manually enable this account to use it. This user account belongs to the SIS Engineering group which has all SIS keys except SIS User LockXX and SIS Version Control.

Members of the SIS Engineering group have the SIS Can Configure key. Any user with the SIS Can Configure key can assign SIS keys to any other user, including himself.

The default system administrator account has no SIS keys assigned; however, the administrator user can assign SIS keys and groups to any user including himself.
