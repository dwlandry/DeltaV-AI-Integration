Simplex H1 4-Port Terminal Block

Installation notes

  • The Simplex H1 4-Port Terminal Block provides wiring terminations for the simplex Fieldbus H1 4-Port Series 2 Plus card.
  • Set the keys on the terminal block to D2 to match the simplex Fieldbus H1 4-Port Series 2 Plus card.
