Verify the firewall configuration

For troubleshooting purposes, Emerson support personnel may ask for the firewall's configuration file. To obtain this file, use the Management station's web browser such as the Internet Explorer to log into the firewall and download the configuration text file DELTAV DEFAULT 1-311. The following instructions explain how to save the configuration text file to a disk on the Management station:

  1. Open the Management station's web browser and enter the firewall 's IP address, for example https://10.5.128.xx:443 (where xx is the IP address you assigned using the serial port.
  2. The Security Alert dialog opens. Read the information on this dialog and click Yes.
  3. The Connect to dialog opens. Enter admin as Username and the default password if these have not changed from the factory settings. Otherwise, enter your Username and Password and click OK.
  4. The firewall's Welcome page opens.
  5. Find the System folder on the left side of the Welcome page and expand the folder.
  6. Select Configuration-Profiles to open the System Configuration Profiles page.
  7. In the Name column, find DELTAV DEFAULT x-xxx (where x-xxx is the version number) and click Download.
  8. A File Download dialog opens. Read the information on this dialog and click Save.
  9. The Save As dialog opens. Chose a file name and location and click Save. This is the file that can be sent to Emerson support for analysis.
  10. If the Download complete dialog opens, click Close.
