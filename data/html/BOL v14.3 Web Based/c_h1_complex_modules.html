More complex modules that meet requirements

Example Module with Multiple Control Loops

This example shows a module with multiple control loops. Notice how the requirements have been met in this module: the DeltaV function block is in a synchronized control path in both loops; the loops' execution order follows the information flow in the control; all blocks support automatic assignment, and the input and output links are of the same parameter types.

Example Module with Feedforward Loop

This example  shows a module with a Feedforward loop that meets all the requirements for Automatic Assignment. Notice that AI2 is not assigned to a fieldbus device. The requirement specifies that at least one input and one output block in the module is assigned to a fieldbus device. Since AI1 is assigned to a fieldbus device, this requirement has been met in this example.
