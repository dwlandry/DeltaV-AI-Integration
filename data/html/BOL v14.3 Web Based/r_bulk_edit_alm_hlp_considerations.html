Alarm help bulk edit considerations

There are a few things to be aware of when bulk editing alarm help.

<NULL> Field Values

It is possible to have a large number of fields in an alarm help bulk edit file that are <NULL>. This is not a problem. In most cases it indicates that a particular alarm is not in the object. For example, if you use the Module_AlmHlp.fmt file to export alarm information, not every module has every alarm. Each line (module) in the bulk edit file contains <NULL> values for the alarms that the module does not contain.

Three fields in alarm help bulk edit files correspond to named sets. In the bulk edit export/import file, the named states in a named set are represented by their state values. Alarm Help across zones

Alarm Help is available across zones in read-only mode; it must be configured, or bulk-edited, in the system where the alarm originates. When using Alarm Help across zones, the named sets need to be identical in all systems to ensure that the Alarm Help labels are consistent across zones. The system does not force this consistency.
