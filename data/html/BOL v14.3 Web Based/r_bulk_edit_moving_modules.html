Moving modules using bulk edit

In addition to creating modules with Bulk Edit, you can also move existing containing and contained Equipment and Control Modules with some limitations. To move a module structure (containing and contained modules) edit the Area column of the exported module structure. For example, to move Equipment Module EQ1 containing Control Module CTR1 from AREA_A to Process Cell PCELL1 under AREA_A, make the following changes to the Area column of the modules' export files.
