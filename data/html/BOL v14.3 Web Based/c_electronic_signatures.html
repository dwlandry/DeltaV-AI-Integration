Signature Policies preference

Note:

Disabling the Signature Policies option in the System Properties dialog does not disable electronic signatures on modules. To disable electronic signatures on modules you must remove the signature policy on each module before disabling the Signature Policies option in the System Properties dialog.

This preference enables or disables the following features of electronic signature policies:

DeltaV Explorer

  • An Electronic Signatures container under the Security object.
  • Dialogs for creating signature policies and assigning polices to modules.

Control Studio (online) and DeltaV Operate

  • Dialogs that allow operators to enter an electronic signature before writing to parameters and fields listed in signature policies.
    Note: To enable electronic signatures system-wide you must:
    1. Enable the Signature Policies option in System Preferences.
    2. Enable electronic signatures in the Electronic Signatures Properties dialog for ElectronicSignatures under the Security container in DeltaV Explorer. You can also enable electronic signatures in DeltaV Operate and DeltaV Control Studio in the Electronic Signatures Properties dialog.
    3. Enable the Enable Electronic Signature option in the Properties dialog for the Area in DeltaV Explorer. For example, if the modules requiring electronic signatures are in Area_A, enable the Enable Electronic Signature option in the Area_A Properties dialog.
