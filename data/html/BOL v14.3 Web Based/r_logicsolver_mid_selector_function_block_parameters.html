Logic Solver Mid Selector function block parameters

The following table lists the system parameters for the function block:

LSMID Function Block System Parameters

Parameter

(Data Type)

Default Value

(Units)

Characteristics

Description

DEV_ACT

(Boolean)

False

NVM:

Preserved on Download

DEV_ACT is True if any good, non-disabled input deviates from the mid-selected input by more than DEV_LIM.

DEV_HYS

(Floating point)

0

(Percent of IN_SCALE)

Access:

Configurable, Tuning

NVM:

Restored on Restart

Hysteresis used for clearing DEV_ACT once it has been set. Value is in percent of IN_SCALE.

DEV_LIM

(Floating point)

0

(Determined by supplying block or source)

Access:

Configurable, Tuning

NVM:

Restored on Restart

Limit value in engineering units used to determine how far the good, non-disabled inputs are from the selected input. A value of 0.0 disables the DEV_ACT calculation.

DISABLEn

(Boolean)

False

Access:

Tuning

NVM:

Preserved on Download

When True, the input is not used in the mid selection algorithm.

INn

(Floating point with status)

0

(Determined by supplying block or source)

Access:

Tuning

NVM:

Restored on Restart

Input to select.

IN_SCALE

(Scaling)

0.0 to 100.0

Access:

Configurable, Tuning

NVM:

Restored on Restart

Scaling parameter common to all inputs.

OUT

(Floating point with status)

0

(Determined by supplying block or source)

NVM:

Preserved on Download

Selected/calculated output.

SELECTED

(Discrete with status)

0

NVM:

Preserved on Download

SELECTED is the number of the selected input. When MID is computed from an even number of inputs SELECTED is the number of the lowest valued of the two mid-valued inputs.
