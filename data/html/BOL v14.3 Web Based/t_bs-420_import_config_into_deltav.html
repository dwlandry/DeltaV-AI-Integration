Import the BS-420 configuration into DeltaV Explorer

This section explains how to import the BS-420 configuration export from the Autronica software into DeltaV Explorer.

  1. From DeltaV Explorer, select File > Import > Convert > Autronica CSV to Bulk Edit Format. The Autronica Convert dialog appears.
  2. In the LSN Gateway field enter the target LSNG name
  3. Make sure the delimiter is set to semicolon (;).
  4. In the Autronica file (.csv) field, browse to the CSV file exported from the AS configuration tool.
  5. In the Format file (.fmt) field, browse to the Bulk Edit format file LSNG_Signal.fmt.
  6. In the Output file name field, enter or browse to a file name to contain the signal data in a Bulk Edit file (.txt).
  7. Click Convert and verity that the conversion succeeded.
  8. Select File > Import > User Defined Format.
  9. Browse to and select the LSNG_signal.fmt file.
  10. Click Next and browse to and select the converted .txt file created in step t_bs-420_import_config_into_deltav.html#task_51B674B970AF4F56901608D74F08397E_unique_107__step_B46FE30F697341C2835A0D36362397CD
  11. On the Import data source dialog, click Next.
  12. On the Import results dialog, click Import.
  13. Verify the import by viewing the LSNG Signals dialog.
