SIS locks assigned to functions

Locks are also assigned to various SIS functions, such as downloading, uploading, changing the configuration database, and so on. Functions are assigned default locks initially. In DeltaV Explorer, use the Modify button on the Properties dialog for SIS Function Security to change the lock associated with an SIS function.

SIS_EDIT_DOWNLOAD_MODULES

SIS Can Edit

Permits the following actions for SIS modules assigned to the SIS nodes that have the SIS Can Edit key:
  • Edit SIS Modules assigned to the SIS node
  • Download the CSLS or SLS node
  • Upload changes to the SIS modules assigned to the SIS nodes
  • VCAT for SIS or CSLS checkout/checkin for SIS modules assigned to the SIS nodes
  • VCAT for SLS or CSLS download

This key is node-specific. You can assign this key to a specific node or assign it to all nodes (sitewide).

SIS_EDIT_IO_AND_SETUP_DEVICES

SIS Can Setup Devices

Permits the following functions for IO assigned to the nodes that have the SIS Can Setup Devices lock:
  • Edit IO properties, channel and LS Charm
  • Autosense LS Charms
  • Autosense HART devices
  • Reconcile HART device
  • Lock/unlock HART 7 device through HART command
  • AMS Device Manager
    • Change AMS Device Manager database
    • Sending reconciled data to the device
    • Sending the command to start bulk transfer
    • Opening the device in AMS Device Manager and editing device information
  • Edit Hart Device Placeholder
  • Download the CSLS if the request is made from the DeltaV Device Commissioner
  • Enable other functionality, if needed, for Automatic Loop Tests
  • VCAT functionality to checkout/checkin and download while checked out

This key is node-specific. You can assign this key to a specific node or assign it to all nodes (sitewide).

In order for the logged in DeltaV user to be able to edit or set up I/O and devices, the I/O and devices must be assigned to a node to which this key is assigned.
