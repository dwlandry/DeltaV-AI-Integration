Module classes

Module classes define the properties (algorithms, conditions, alarms, and displays) for a group of similar modules. Modules based on a class are referred to as instances or class-based modules. The module class remains linked with its instances so that, in general, changes to the module class propagate to the instances.

All module types (unit modules, equipment modules and control modules). support classes. Module templates can also be class-based. The system stores module classes in the DeltaV Explorer hierarchy under Library/Advanced Definitions. Consider using module classes for any modules that require the same algorithm and alarms.
