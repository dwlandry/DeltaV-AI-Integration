Defining phase parameters

Phase parameters are user-configurable parameters, of the types input, report, and phase algorithm. Phase parameters are created at the phase class level. Every phase created inherits the phase parameter defined for its class. Input parameters are used to transfer recipe data from the Batch Executive to the phase logic. Report parameters are used to transfer data from the controller to the batch journal. Phase algorithm parameters define variables for the unit module's phase algorithm and are not inherited by the phase logic module.

If the parameter has a named set data type, you must configure the named set to be used for this parameter.

Input Phase Parameters

Input phase parameters specify values that are downloaded to the phase logic in the controller when the phase runs. The phase logic then uses these values to control the unit in which the phase runs. Phase parameter values can be specified in the recipe, included in recipe formulas, or requested from the operator at run time.

Input Phase Parameter Properties Dialog
Note:

If creating a scalable batch, use the integer or real data type for the input phase parameter.

Report Phase Parameters

Report phase parameters are typically used to capture and report actual process values or batch values used by the phase. From the phase logic in the controller, batch report values are uploaded to the DeltaV Batch Executive when the phase completes and can be used for batch history purposes, provided the Batch Historian subsystem is enabled.

Phase Algorithm Parameter

Phase algorithm parameters are used in the phase logic in the controller when the unit phase runs. The phase algorithm parameter provides intermediate storage during calculations in the phase logic.

The phase algorithm inherits phase algorithm parameters when a unit module is created.

Phase algorithm parameters can be of the same parameter types as any user-defined parameter in DeltaV software.
