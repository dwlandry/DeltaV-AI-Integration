Recipe resynchronization on restart

When it is necessary to change configuration of a running batch, the version of the recipe can be changed and the batch can be restarted to use the most current version of its recipe. This is accomplished by performing a restart with resynchronization of the recipe. This option is only available when using the DeltaV Operate Batch controls.

The following changes are incorporated when a recipe is successfully resynchronized:

  • Recipe data

  • Formula data

  • Phase servers

  • Batch server properties (for the batch runner the changes can be hold propagation limit, allow change to acquired unit for step, enforcing the batch's maximum scaling, and so on)

  • Equipment; such as, available units and phases for the batch runner, and downstream unit information

  • Equipment train information (that is, class and instance information, downstream alias information, selection policies, and so on)

  • Named sets

In order for a recipe to be resynchronized successfully, the following conditions must be met:

  • The Batch Executive property, Allow Recipe Resynchronization, must be selected and the Batch Executive downloaded.

  • The recipe changes meet the guidelines for valid recipe changes.

  • The new recipe version has been downloaded to the Batch Executive running the batch.

  • The logged-on user must have the Batch_Resync key to perform a warm or cold restart with resync.

Note:

We strongly suggest that the batch be safely shutdown before performing a recipe resynchronization.  Safely shutting down the batch means disabling all active transitions in the batch and having all steps in a terminal state so that no new steps can go active. It may require waiting for the active step to complete or executing a hold command before forcing a shutdown of the batch.

The disable transition feature is found on the Batch PFC and the Batch Step List control (in DeltaV Operate). The Force Shutdown is performed from the Administer Batches tab on the Advanced dialog for the Batch Application Manager. You must have the Batch_Active_Step_Change key to use these options.
