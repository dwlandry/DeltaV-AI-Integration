IDVBCMExecParamInfo::editable

Method Signatures

  

C\C++

HRESULT get_Editable(

long lWait,

VARIANT_BOOL *bEditable)

VB

Public Property Get Editable(

ByVal lWait As Long) As Boolean

This property returns whether or not the parameter is editable.

Return Values

S_OK - success

else - failed

Memory Allocation

none

Visual Basic Usage Example

Private Sub Button1_Click()
    Dim bEditable As Boolean
    Dim objExecParamInfo As DVBCMExecParamInfo
    Call GetExecParamInfoObject(objExecParamInfo)
    bEditable = objExecParamInfo.Editable
End Sub

Parameter Name

Purpose

lWait

Optional. Default = 30000. Time to wait for a server resource in milliseconds.

bEditable

Is parameter editable or not.
