Restarting a batch from the held state

Use the Restart command to restart a batch that is in the Held state. Once the batch is restarted, it transitions to the Restarting state and then to the Running state, as shown in the following figure.

Restarting a Batch from the Held State

You can only restart a batch in the Held state if no phases associated with the batch have failed or are being controlled externally.
