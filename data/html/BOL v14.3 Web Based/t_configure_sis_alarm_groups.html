Configure SIS alarm groups

  1. With the SIS module open in Control Studio, on the Home tab, in the Alarms group, click Alarm Groups Configuration.
  2. Click New to create a new alarm group.
  3. With the alarm group selected, click Modify.
  4. Modify the alarm group name and enter the primary control, detail and faceplate displays for the alarm group. The alarm group name must be unique within the DeltaV system.
  5. Create additional alarm groups as needed.
  6. If blocks are available in the module, you can assign them to the alarm groups. To do this, select an alarm group and click the Assignments tab. Select a block or blocks from the Available Items list that you want to assign to this alarm group. If blocks are not available, you can make the assignments at a later time.
  7. Click Assign.
  8. Click Apply.
  9. Click Close.
