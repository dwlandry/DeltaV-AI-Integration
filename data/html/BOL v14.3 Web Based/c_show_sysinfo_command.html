show sysinfo command

This command displays detailed information about the switch hardware and software and the types of modules installed in the switch. It also displays serial numbers. The output varies with switch and module types.

Emerson support personnel may request this information for troubleshooting and call tracking purposes. Some of the information in the following output example has been deleted.
