Batch Executive events

The Batch Executive creates an entry in the Event Chronicle when significant batch events occur. These events are available to client applications through the DeltaV OPC Alarms and Events server. 

To enable Journaling of Batch Executive events, open the Batch Application Manager by clicking Start > DeltaV Batch > Application Manager. Then, with the Batch Executive selected, click the Advanced button to open the Advanced dialog for the Batch Application Manager. Select the Configuration Settings tab. Double-click Enable Alarm and Events Journaling to toggle the setting from No to Yes (or, to disable journaling, toggle from Yes to No).

The Batch Executive creates an entry in the Event Chronicle for the following significant Batch Executive events:

  • Batch Load (batch created in the batch list)

  • Batch Remove (batch removed from the batch list)

  • Mode change for any recipe in a batch

  • Operation Finished

  • Operation Started

  • Operation Started with Equipment Acquired

  • Phase Finished

  • Phase Started

  • Phase Started with Equipment Acquired

  • Procedure Finished

  • Procedure Started

  • Recipe State Changed for any recipe in a batch

  • Resource Acquired by Recipe

  • Resource Released by Recipe

  • Unit procedure Finished

  • Unit procedure Started

  • Unit Procedure Started with Equipment Acquired
