Using the SPI Interface menu

Use the SPI Interface menu to move configuration data between the Intergraph SmartPlant Instrumentation application and the DeltaV configuration database.

Note:

You must have the SmartPlant Instrumentation version specified in SmartPlant Excel Interface to move data from the DeltaV configuration database to the SmartPlant application .

After you configure DeltaV I/O and instrument data within SmartPlant, you export this data for the DeltaV system. The data is grouped by controller. The interface supports conventional and fieldbus instruments.

The data is transferred as XML files. You do not need to translate the data in any way. The interface applications do all the necessary mapping between the databases.
