Simulating CHARM I/O

You can simulate CHARM I/O for I/O and logic checkout as part of Factory Acceptance Testing. The following simulation methods are supported:

  • Simulate CHARM I/O by putting the CHARM I/O Card (CIOC) in simulate mode, downloading the CIOC setup data, and using the CHARMs Simulate application.

  • Simulate CHARM I/O by running a virtual image of the CIOC in a workstation.
