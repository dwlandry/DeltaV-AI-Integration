The phase control and active phase summary screens

From the Phase Control screen, the operator can focus on a particular phase in a batch and execute it manually. This screen displays the areas, process cells or units, allowing close control of each phase. If the area or process cell is blank, it appears on the display but is grayed out.

Phase Control Screen
Note:

If the unit has an MMI picture defined, the unit is marked with an asterisk on this screen. You can open the picture in DeltaV Operate by clicking the View button. DeltaV Operate (run mode) must have been started first, before Batch Operator Interface is launched. This will not work on a Remote Desktop Services machine.

The Batch Operator Interface also includes an Active Phase Summary screen from which the operator can immediately see all active phases. This overview allows operators to quickly identify units and their related phases.
