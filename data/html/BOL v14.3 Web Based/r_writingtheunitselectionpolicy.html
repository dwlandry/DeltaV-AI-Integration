Writing the unit selection policy

The unit selection policy is an expression that evaluates as part of the auto-selection algorithm for From_Policy unit aliases. The unit selection policy discards units for which the expression does not evaluate to true.  Any unit alias in the equipment train can be configured to use a specific unit selection policy. The unit selection policy is evaluated by the system when a procedure starts executing a step that is using an auto-selected unit alias (unit alias selection mode = From_Policy). Unit selection policies are not alias-specific and can be shared between different aliases on the same or different equipment train classes, and between different recipes.

The following references can be used within the unit selection policy expression:

  • User-defined procedure-level recipe parameters

  • Unit module and unit class parameters that you can browse to from the Selection Expression Assistant dialog (NUM_PHASES, $AVAILABLE, and so on)

  • Unit class relative parameters ('^/')

  • Batch run-time parameters (BATCH_ID, BATCH_FORMULA, and BATCH_SCALE)

The unit selection policy is evaluated once and is only repeated if the selection algorithm is repeated (which occurs after a 10 second time out for acquiring a unit). Because a unit selection policy is evaluated only once, a frequently changing parameter is not recommended in the unit selection policy expression. The unit selection policy's expression length is limited to 2000 characters.

The unit selection policy expression times out after a period of 5 seconds if any of the following circumstances exists.

  • A unit under evaluation is unassigned.

  • The expression contains a lot of conditions.

  • Connection to controller is lost.

Any parameters used in a unit selection policy must be defined (uploaded, assigned, and so on) when the expression evaluates or the expression will evaluate to FALSE. For example, if a parameter used in the unit selection policy does not have a value referred up to it or is trying to assign an alias before a phase is loaded the expression evaluates to FALSE. If this evaluation results in all units being filtered out from the valid unit list, the operator is prompted to select a unit from the list of all units in the equipment train.

Note:

Phase logic modules and external phases do not affect the unit's $IDLE_TIME parameter because they do not increment the NUMPHASES parameter on the unit. Therefore, if you use a unit selection policy in this case, the auto-selection disregards the usage of phase logic modules and external phases while sorting for Least Recently Used.
