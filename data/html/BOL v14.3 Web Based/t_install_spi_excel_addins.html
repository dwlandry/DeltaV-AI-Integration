Install the SmartPlant Excel Add-in

The SmartPlant Instrumentation Excel Add-in works with Excel 2013. For specific requirements refer to the DeltaV Compatibility Chart in the Release notes KBA for this release. In addition:

  • The add-ins must be installed and run on a DeltaV ProfessionalPLUS or Professional node to connect to and transfer data between the DeltaV database and SPI software.

  • The add-ins should only be used with the version of DeltaV software that provided them.

Note:

Excel 2013 supports all of the SPI features that DeltaV software requires. If you use other features of SPI software, refer to its documentation for versions of Excel that it supports.

To install the add-ins:

  1. Open Excel.
  2. Select File > Options.
  3. Click Add-Ins.
  4. Make sure Excel Add-Ins is selected in the Manage field, and then click Go.
  5. On the Add-Ins dialog, click Browse and navigate to \DeltaV\DVData\SmartPlant\Instrumentation\Deltav_Xl_Spi.xla.
  6. On the Add-Ins dialog, click Browse and navigate to \DeltaV\DVData\SmartPlant\XLSupport\Deltav_Xl_Support.xla.
  7. Click OK on the Add-Ins dialog.

Loading the add-ins creates the DeltaV menu command under the Excel Add-Ins tab and creates the I/O Support and SPI Interface menus below it.

Important:

If you are upgrading to a newer release of Excel be sure to remove the add-ins before you upgrade and reinstall the add-ins after the upgrade.
