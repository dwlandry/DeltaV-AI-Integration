Create unit procedures (UP_BLEND and UP_COLOR)

  1. In Recipe Studio, click the Main button, and then click New. Select Unit Procedure as the recipe object type.
  2. Create the unit procedure as shown in the following diagram.
  3. Select BLENDER as the unit class.
  4. Finish the unit procedure by filling in the Properties dialog.
  5. Save the recipe as UP_BLEND.
  6. Create a unit procedure named UP_COLOR. This unit procedure contains only one operation, OP_COLOR. Use COLOR for the unit class.
