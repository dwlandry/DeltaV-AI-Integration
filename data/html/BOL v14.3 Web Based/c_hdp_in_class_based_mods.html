History data points in class-based modules

From DeltaV Explorer you can create history data points in module classes that propagate to module instances. However, from bulk edit, you can only create history data points at the module level. The ability to modify history data points in class-based modules is determined by values in two fields in the exported history point data, hdp_type and use_default.

Note:

The hdp_type and use_default fields are relevant only for history data points defined in a module class. For all other history data points (including those defined in instances of class-based modules) these fields can be ignored.

Do not modify the hdp_type values. Depending on the hdp_type value for an HDP you can do the following from Bulk Edit:

  • Configurable — You can change the use_default value from T to F and modify other fields. You cannot create new Configurable history data points.

  • Override — You can modify field values. You cannot create new Override history data points.

  • Definition — You cannot make any changes.

  • Instance — You can create new instances or modify field values of existing instances.
