Unit alias selection states

The following states are supported by the unit alias and are used only by DeltaV batch during the resolution of the unit alias in an equipment train. It is only visible to the operator using the DeltaV Operate Batch controls.

Open - A unit has not been selected yet. This is the initial state at batch creation for unit aliases that are not fixed. If the unit selection mode is set to Defer, the operator is able to make the unit selection. If the unit selection mode is From Policy, the operator is able to change the selection mode to Defer and then select a unit.

Selecting - A unit is being selected. When the unit selection mode is Defer, an operator prompt has been issued but a response has not been made. When the unit selection mode is From Policy, the system is executing the unit selection policy. Once the unit selection policy is executed or the operator has responded to the prompt, the system sends a request to acquire the unit(s) which sets the state to SELECTED.

Selected - A unit (or list of potential units) has been selected and a set of requests to acquire the units have been sent, but the unit alias has yet to acquire a unit.

Committed - A unit has been selected and acquired.

Note:

If the Batch Executive Allow change to the acquired unit for a step option is selected, then the unit alias selection state goes from COMMITTED to SELECTED when the step (with the From_Policy selection mode) completes (that is, when the unit is released).
