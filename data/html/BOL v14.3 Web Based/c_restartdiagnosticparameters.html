Restart diagnostic parameters

The controller supports the following diagnostic parameters related to power failure and restart. Unless otherwise specified, they are available through the DeltaV Diagnostics application:

  • ColdRestart – true if the node is in the cold restart state.

  • ColdStrtSrc – the source from which download data is received during a cold restart. The possible values are Controller (that is, controller nonvolatile memory), Workstation (that is, ProfessionalPLUS download scripts), Not Configured (if Cold Restart Perform Within is equal to zero), CIOC (that is, the internal flash memory of the CHARM I/O Card), or WIOC (that is, the internal flash memory of the wireless I/O card).

  • ColdStrtStat – the status of cold restart memory (or download). Possible values are Not Available, Requesting, Available, and Invalid.

  • FreeNVM (Free Nonvolatile Memory) – the amount of memory (in bytes) that can be allocated to parameters that use the restore parameter values feature.

  • LastPfDur – the duration of the last power failure experienced in seconds.

  • NVM_Status – the status of non-volatile memory.

  • PfCount  – the count of power failures since being commissioned or reset.

  • SecsLastPf – the number of seconds since the controller lost power.

  • UserRestart – true if the node is in the user restart state.

Note:

The value of the LastPfDur or SecsLastPf parameter is valid and meaningful only after a power failure—that is, when the value of the PfCount parameter is equal to or greater than 1. The reported value of the LastPfDur or SecsLastPf parameter is not accurate, for example, following first download, after a switchover, or after the standby controller is reseated with the Cold Restart option enabled because all of these conditions are accompanied by a PfCount value of 0.
