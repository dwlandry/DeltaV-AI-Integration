Splitter function block advanced information

When the Splitter block is configured to address split range applications, the upstream block that provides the Splitter setpoint regulates one downstream block at any given time. If the downstream block currently being regulated is switched out of Cas mode the upper stream block output has no impact until its output changes a value required to operate the other downstream block. To avoid any delay in control response that this may cause, you can switch the second downstream block momentarily out of Cas and back to Cas mode and thus force the upstream block to initialize based on the second downstream block. Alternatively, you can switch the upper block to Man and adjust its output value until the splitter setpoint is in the region of operation associated with the second output.
