I/O License Demand dialog

Summary

Capacity
Shows the total number of licenses, by type, that have been loaded into the system.
Configured
Shows the total configured demand for I/O licenses by type.
Difference
Shows the difference between the total number of loaded licenses and the total configured demand for I/O licenses.

Details

The first row shows the total configured demand for I/O licenses by type. The remaining rows show either: subtotals for the parents of the I/O components or I/O components and associated I/O references. An asterisk (*) or pound sign (#) indicates the reason the system does not require a license for this I/O reference.

Copy selected rows
Copies the selected rows in the Summary and Details list controls to the clipboard.
