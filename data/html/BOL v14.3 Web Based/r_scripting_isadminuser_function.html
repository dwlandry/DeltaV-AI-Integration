IsAdminUser function

IsAdminUser() returns True if the currently logged on DeltaV user is considered an administrator.
Note: The .IsAdminUser function returns the same string as the DeltaV Operate data link path, THISUSER/IS_ADMIN_USER.B_CV.
Arguments
0
Return values (Boolean)
True, if the DeltaV user currently logged on to the workstation/session where this instance of DeltaV Live is running is an administrator.
False, otherwise.
Syntax
ENV.IsAdminUserName()
Examples
Example Result 
if (ENV.IsAdminUser()) 
{
// code to execute for administrators
}
 If the currently logged on DeltaV user is an administrator on this machine, the "code to execute for administrators" is executed.
