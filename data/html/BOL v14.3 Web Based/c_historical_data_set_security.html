Historical data set security

Historical data set security is part of the overall DeltaV security scheme. Access to individual Continuous Historian Administration options, such as exporting or deleting historical data sets, is restricted to those users who have been granted an access key individually or who belong to a group that has been granted a key. In addition, user-defined locks can be created, and Continuous Historian Administration options can be assigned to the new locks.

All Continuous Historian Administration options function on a site-wide level, requiring that <Sitewide> be assigned to the System Admin key in DeltaV User Manager when assigning keys to a user or user group. However, the specific options, such as creating a new active data set, still require the appropriate key be granted to the correct areas.

Note:

For more information about locks and keys, refer to the online help for the User Manager application.

Security keys by function

Function name

Controls whether the current DeltaV user can:

HDS_ACTIVE

Create a new active data set

HDS_EXPORT

Export historical data sets

HDS_DELETE

Delete historical data sets

HDS_EXTENDED

Create extended historical data sets

HDS_BACKUP

Back up all current historical data sets to an offline directory

HDS_RESTORE

Restore current historical data sets from an offline directory to Primary storage

HISTORICAL_DATA_ENTRY

Write data to a DeltaV Continuous Historian database using DeltaV Reporter

HISTORICAL_REMOTE_ACCESS

Read DeltaV Continuous Historian data from a non-DeltaV workstation or from a DeltaV workstation in a different DeltaV system using DeltaV Reporter
