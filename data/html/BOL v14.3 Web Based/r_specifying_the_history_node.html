Specify the history node for Process History View

Parameter: /histnode

Specifies the historical data server to which you want to connect. The DeltaV Continuous Historian, the Advanced Continuous Historian, or OSIsoft PI Server, should be enabled and running on this node.

Type: Continuous Historian Node

Applies to: Event, Chart, and E+Chart

Value:
  • defaulthost

    The historical data server specified on the Continuous Historian tab in the Set Default Data Servers dialog in Process History View.

  • localhost

    The workstation where you are running Process History View.

  • A node name (quoted, not case sensitive)

    This can specify a remote workstation—for example, in a DeltaV Zones environment or when the historian is installed on a non-DeltaV workstation.

  • The string "<none>" (must be quoted, case sensitive)

    Process History View connects only to the DeltaV OPC Server for real-time data, not to any historical data server.

Examples:

CHS /new Chart /histnode "CHmachine"

CHS ChartXYZ.phvc /histnode "node949"
