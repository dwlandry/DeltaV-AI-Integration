DeltaV Live terminology

The following terms or features are either new in DeltaV Live (did not exist in DeltaV Operate) or are known by another name in DeltaV Operate.
Term Corresponding DeltaV term DeltaV Live description
DeltaV Live product None Refers to the whole suite of applications (DeltaV Live Administration, Graphics Studio, and DeltaV Live Online).
DeltaV Live / DeltaV Live Online DeltaV Operate Runtime Refers to the operations application included in the DeltaV Live product.
Graphics Studio DeltaV Operate Configure Refers to the configuration application included in the DeltaV Live product.

Language New in DeltaV Live Defines the language-specific content for configurable strings that exist within a DeltaV Live configuration database.
Theme Themed color sets Refers to a set of theme-specific values that can be used in place of standards, allowing the same graphics configuration to appear differently on different workstations or at different times on the same workstation. Themes can be created for entire displays, including all graphics elements contributing to the display.
GEM class Dynamos A complex graphics element used to represent process control equipment or other objects on a display. A GEM class provides a means to define common appearance and behaviors for the linked GEMs created from a GEM class.
Linked GEM New in DeltaV Live An instance of a GEM class that has been added to a display, contextual display, or other GEM and remains linked to its GEM class. When a GEM class is modified and saved, all GEMs linked to it are immediately updated with the changes.
Unlinked GEM New in DeltaV Live An instance of a GEM class that has been added to a display, contextual display, or other GEM and unlinked from that GEM class. An unlinked GEM does not receive updates from the GEM class it was created from.
Standard frsVariables Provides a means to ensure a consistent graphics appearance within a DeltaV Live system by allowing you to create, name, and organize these values in libraries, where they are then available to be referenced by properties in displays, layouts, or GEM classes.
Library configurations New in DeltaV Live Refers to all configurations contained in configuration libraries, which include GEM classes, standards, and functions.
Conversion function Look up tables and animation tables Provides a means to create logic that converts values of one type into values of a different type. Functions are available from the configuration library to be referenced by properties in display, layouts, or GEM classes.
Display Pictures Presents process information to operators in DeltaV Live. It can also provide operators with situational awareness over some part of the process through a hierarchical set of displays, where each display presents a different level of detail.

A displays also provides operators with a means to take typical actions affecting that part of the process, such as responding to alarms.

Contextual display Faceplates, detail displays, and trend displays A display whose content varies depending on the context in which it is opened. Examples of contextual displays include faceplates, details displays, Batch controls, and so forth.
Display set New in DeltaV Live Defines the displays that will be deployed to a designated Operator Workstation. The displays within a display set are intended to match the specific responsibilities of the control room they are used in and the operator roles for which they are created.

Display sets also designate the navigation level of a display. Using display sets is optional.

Layout Layouts Arranges and purposes regions of the available display surface on workstations and remote client sessions.
Variable Global variables A variable is created on a display, layout, group, or GEM class, and can be referenced from any element on its containing display, layout, group, or GEM.
Graphics elements Shapes The graphics components used to build displays, contextual displays, and layouts.
Screen Monitors A graphics elements used to create layouts. Each screen represents the size and relative position of a physical screen on a workstation's monitor. Screens also serve as containers for display frames.
Display frame New in DeltaV Live Designates regions of a screen to show different kinds of content online, as well as determines where displays appear in a layout.
Publish Download A direct action performed by users that authorizes configurations to be deployed, as soon as possible, for use into the online environment. Configurations that must be deployed to the online environment, either after users create or modify them, include graphics configurations, library configurations, and DeltaV Live Workstation configurations.
Interactions A collection of actions that define how DeltaV Live users can interact with graphics on running displays. Graphics Studio provides the means to customize these interactions through an Interactions tab in the Graphics Configuration.
Alarm List element DeltaV Alarm Summary object A graphics element used on displays to show the active alarms in operators' scopes of responsibility and provide the means for them to respond efficiently to these alarms.
Display Alarm Rollup New in DeltaV Live A graphics element used on displays to show operators a summary of alarms associated with a certain display.
