System configuration settings for DeltaV Reporter

In Excel, security settings must be configured such that report definition and output files for automatically-generated, scheduled reports are stored in trusted locations. Otherwise, Excel will not calculate the formulas in DeltaV Reporter worksheet functions or generate reports successfully. To make the report definition and output folders (by default, C:\DeltaV Reporter\Definitions and C:\DeltaV Reporter\Reports, respectively) trusted locations, complete the following steps:

  1. Open the Excel Options dialog.
  2. In the Excel Options dialog, select Trust Center in the options panel, and then click Trust Center Settings.
  3. In the Trust Center dialog, select Trusted Locations in the options panel, and then click Add new location.
  4. In the Microsoft Office Trusted Location dialog, browse to your report definition folder (C:\DeltaV Reporter\Definitions, by default), and then click OK twice to return to the Trust Center dialog.
  5. In the Trust Center dialog, click Add new location, and then browse to your report output folder (C:\DeltaV Reporter\Reports, by default).
Note: To also make subfolders of a specified folder trusted locations, enable the option in the Microsoft Office Trusted Location dialog for: Subfolders of this location are also trusted. For example, if you use the default folders for report definition and output files, you can simply make the C:\DeltaV Reporter folder and all of its subfolders trusted locations.

The DeltaV Reporter user scheduling reports must have access to the Scheduled Tasks folder (C:\Windows\Tasks, by default).

You must select the interactive user account to run Microsoft Excel. This ensures that reports are generated and stored correctly. To specify the interactive user account:
  1. Open Component Services.
  2. In the console tree of the Component Services administrative tool, select Component Services > Computers > My Computer > DCOM Config.
  3. Right-click Microsoft Excel Application and click Properties.
  4. On the Identity tab, click The interactive user.
  5. Click OK.

To use DeltaV Reporter from a non-DeltaV workstation in a domain, either a one-way trust relationship must be configured with the DeltaV domain trusting the non-DeltaV domain; or, user accounts must be configured with the same user names and passwords on both the DeltaV domain and the non-DeltaV domain. In either case, a DeltaV user must be configured for the matching Windows account.

By default, Excel as a COM object can only be activated by the Administrator, System, or Interactive accounts. Therefore, it is possible that a scheduled report will fail to run correctly under the following conditions:

  • You configure a scheduled report using a different user account than the one currently logged on.
  • You configure a scheduled report to run unattended, at a time when the user specified in the Run as field of the Scheduled Report Properties dialog of DeltaV Reporter is not logged on.

To prevent this possibility, complete the following steps to edit the DCOM configuration settings for the Microsoft Excel Application object:

  1. Use Control Panel to open Component Services in Administrative Tools.
  2. In the console tree of the Component Services administrative tool, select Component Services/Computers/My Computer/DCOM Config.
  3. In the list COM+ server applications, right-click Microsoft Excel Application, and click Properties on the shortcut menu.
  4. On the Security tab of the Microsoft Excel Application Properties dialog, select Customize in the Launch and Activation Permissions group, and then click Edit.
  5. In the Launch Permissions dialog, add the DeltaV Reporter user who needs to configure scheduled reports, and then enable the Local Launch and Local Activation permissions for this user.
  6. Return to the Security tab of the Microsoft Excel Application Properties dialog, select Customize in the Access Permissions group, and then click Edit.
  7. In the Access Permissions dialog, add the DeltaV Reporter user who needs to configure scheduled reports, and then enable the Local Access permissions for this user.
  8. Return to the Microsoft Excel Application Properties dialog, select the Identity tab, and then enable the following option: The launching user.
Important: For a scheduled report to run successfully on a DeltaV or non-DeltaV workstation, the user specified in the Run as field of the Scheduled Report Properties dialog of DeltaV Reporter must be logged on, either locally or remotely through a connected or disconnected session, at the time the Task Scheduler attempts to execute the scheduled report task.

The DeltaV Reporter user scheduling reports must be included in the User Rights Assignment list of users with the Log on as a batch job policy. To check this setting, use Control Panel to open the Local Security Policy settings window, and then select Local Policies/User Rights Assignment in the console tree.
