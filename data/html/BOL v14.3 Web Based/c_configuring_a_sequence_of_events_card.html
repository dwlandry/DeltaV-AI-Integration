Configuring a Sequence of Events (SOE) Card

Sequence of Events (SOE) Card captures events from devices in the field. Events captured by an SOE card are time-stamped using 0.25 millisecond resolution. The card is capable of buffering a maximum of 32 events per second. These events are communicated to the controller where the timestamp is resolved using the network time server to ensure accuracy. The controller then passes each time stamped event to the workstation where it is logged into the Event Chronicle.

The card's SOE discrete input channel works with DI and Device Control function blocks as input I/O references when reading a discrete (On/Off) signal.

Configuring the card for operation requires the following:

  • In DeltaV Explorer, define a named set that defines the states for the associated discrete device.

  • In DeltaV Explorer, set the channel's properties: make sure the channel type is set to SOE Discrete Input Channel, that it is enabled and that the named set is defined.

  • Systems that include the SOE card must have a network time server.

  • Define one of the workstations as the SOE data collector. By default, the events will be collected by the ProfessionalPLUS workstation. Refer to DeltaV Explorer help for information on how to select a different workstation.
