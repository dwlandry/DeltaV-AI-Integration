Add a parameter to record the blender's initial level

  1. Open the CHG_COLOR phase class in Control Studio and drill down into the running logic.
  2. Right-click in the Parameter view, and then select Add > Phase algorithm parameter.
  3. Name the parameter INIT_LEVEL.
  4. Leave the Type as floating point and the value as 0.
  5. Save the phase class now to be able to browse for the new parameter when creating the running logic.

Now you can configure the running logic for CHG_COLOR and DUMP.
