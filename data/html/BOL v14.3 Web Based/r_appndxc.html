Appendix C - batch system capacities

The following tables contain the fixed and recommended capacities of the DeltaV Batch subsystem.

The values in the Fixed Limit column are limits imposed by the system that the user cannot exceed. The values in the Maximum Recommended Limit column are values that are recommended that the user not exceed and are to be used as a guideline when determining your system's performance.

It is important to note that the combination of items and the configuration of those items in a system and other variables (such as available memory in the controller and recipe or phase logic size) can effect whether or not a fixed or maximum recommended limit can be reached on a system; and, may also have an effect on the performance of a particular configuration. For example, a system may exceed the maximum recommended limit for one item without noticing any change in performance. However, if a particular configuration nears the maximum recommended limit of several items in combination, the potential for a change in performance is increased.

Batch Executive System Capacities

A DeltaV system can include up to four enabled Batch Executives, four enabled Batch Historians, and four enabled Campaign Managers.

On Redundant Batch systems, a pair of Application Stations running the Batch Executive counts as one Batch Executive. Similarly, a pair of Application Stations running the Campaign Manager counts as one Campaign Manager.
