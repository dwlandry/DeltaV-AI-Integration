Example unit selection policy expressions

These example unit selection policy expressions are samples of the types of expressions possible.

The following expression uses a unit relative parameter (U_EQUIP_STATUS) and a value from the EQUIP_STATUS named set to determine the clean condition of the unit. If there is more than one unit that meets this criteria, the priority choice narrows it to one unit.

'^/U_EQUIP_STATUS' = 'EQUIP_STATUS:Clean'

This next expression uses the batch run-time parameter, BATCH_FORMULA, and a unit module parameter, TOTAL_CAPACITY, to determine which of three possible reactors is appropriate, depending on the product being made and comparing it to the unit's total capacity.

((BATCH_FORMULA = "PRODUCT A" OR
  BATCH_FORMULA = "PRODUCT B" OR
  BATCH_FORMULA = "PRODUCT C") AND
 '^/TOTAL_CAPACITY' < 501)
OR 
((BATCH_FORMULA = "PRODUCT D" OR
  BATCH_FORMULA = "PRODUCT E") AND
 '^/TOTAL_CAPACITY' >= 501)
