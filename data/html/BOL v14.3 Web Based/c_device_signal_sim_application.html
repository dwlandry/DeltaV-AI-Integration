Device Signal Simulator application

The Device Signal Simulator enables you to simulate I/O signal values so that you can test your control system and safety logic without physical devices, controllers or I/O nodes. Simulation does require controller and I/O placeholders in Explorer, as well as virtual controllers (M-series, S-series, SIS, and PK controller VMs).

Most I/O signals referenced by a control module or SIS module can receive a simulated value. Simulated device signals can be HART or non-HART. Only references to HART_FIELD_VAL or FIELD_VAL_PCT for HART devices are supported. Bus-connected devices such as FOUNDATION Fieldbus are not supported. The devices may or may not already be assigned to CIOCs, CSLSs and WIOCs. Unassigned I/O References and Unallocated Devices are supported as well.

Here is what you need to use device signal simulation:
  • A control module or SIS module with I/O references.
  • The DeltaV Device Signal Simulator application (installed with DeltaV software).
  • Virtual controller placeholder in DeltaV Explorer (S-Series, M-Series, and PK controller for control system logic, SIS controller and CSLS for safety logic).
  • A virtual controller VM of the same type as your placeholder.
  • Optionally: placeholder cards (traditional I/O cards, CIOC and CHARMs or WIOC).
OPC servers also support device-parameter-field paths that can be used by clients to read and write simulated device parameter fields. This enables clients to drive DeltaV control logic and displays without device hardware. The following parameters are supported:
  • FIELD_VAL_PCT
  • HART_FIELD_VAL
  • FIELD_VAL
  • COUNTER_IN
  • FREQUENCY
  • OUT
  • ON_TIME
  • FIELD_VAL_D
  • OUT_D

Refer to the Device Signal Simulator application help for more information.
