Advanced Function Block GEM classes

Graphics Studio provides a set of advanced function block GEM classes (Advanced Function Block) to be used with advanced function blocks in non-SIS modules. Advanced function block GEMs are designed for use on displays depicting a single interlock (one or more modules that include advanced functions, with common final elements). 
Note: These GEMs can be used only with function blocks in non-SIS modules. For SIS modules, use the SIS Function Block GEM class set.

The topics in this section provide a description of each GEM class in the Advanced Function Block set, except for the Any_Advanced_Function_Block GEM class. The Any_Advanced_Function_Block GEM class is used to open a custom faceplate for any advanced function block. It contains only a group element configured with an action to open a contextual display.

Subtopics:

  • Controller_AVTR_1...3Input_ (analog voter GEM classes)
  • Controller_DVTR_1...3Input_ (discrete voter GEM classes)
  • Controller_CEM_Effect_ (cause and effect matrix GEM class)
  • Controller_STD_ and Controller_SEQ_ (state transition diagram and step sequencer GEM classes)
