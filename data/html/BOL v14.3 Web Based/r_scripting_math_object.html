Math object

The following Math object values and functions are supported in DeltaV Live graphics expressions and scripting. See the subtopics under Math Object for more details about each function.

Math object values

Value Description
.E Returns the number value for e, the base of the natural logarithms (approximately 2.718).
.LN10 Returns the number value for the natural logarithm of 10 (approximately 2.302).
.LN2 Returns the number value for the natural logarithm of 2 (approximately 0.693).
.LOG2E Returns the number value for the base-2 logarithm of e, the base of the natural logarithms (approximately 1.442).
.LOG10E Returns the number value for the base-10 logarithm of e, the base of the natural logarithms (approximately 0.434).
.PI Returns the number value for pi, the ratio of the circumference of a circle to its diameter (approximately 3.14).
.SQRT1_2 Returns the number value for the square root of ½ (approximately 0.707).
.SQRT2 Returns the number value for the square root of 2 (approximately 1.414).

Math object functions

Function Description Syntax
abs() Returns the absolute value of x. Math.abs(x)
acos() Returns the arc cosine of x as a value between 0 and pi radians. Math.acos(x)
asin() Returns the arc sine of x as a value between -pi/2 and pi/2 radians. Math.asin(x)
atan() Returns the arc tangent of x as a numeric value between -pi/2 and pi/2 radians. Math.atan(x)
atan2() Returns the arc tangent of the quotient (y/x) of its arguments, y and x, where the signs of y and x are used to determine the quadrant of the result.

The result is expressed in radians and ranges from -pi to +pi.

Math.atan2(y,x)
ceil() Returns x, rounded up to the nearest integer. Math.ceil(x)
cos() Returns the cosine of x in radians. Math.cos(x)
exp() Returns the value of E to the power of x. Math.exp(x)
floor() Returns x, rounded down to the nearest integer. Math.floor(x)
log() Returns the natural logarithm (base E) of x. Math.log(x)
max() Given zero or more arguments, returns the number with the highest value. Math.max(x?, y?, z?, n?)
min() Given zero or more arguments, returns the number with the lowest value. Math.min(x?, y?, z?, n?)
pow() Returns the value of x to the power of y. Math.pow(x, y)
random() Returns a random number between 0 and 1. Math.random()
round() Returns x rounded to the nearest integer. Math.round(x)
sin() Returns the sine of x in radians. Math.sin(x)
sqrt() Returns the square root of x. Math.sqrt(x)
tan() Returns the tangent of x in radians. Math.tan(x)
