Configure DeltaV Smart Switch remote logging using the switch module

Switch events can be written to a standard reporting format log file that is then saved to a remote server as historical data. A syslog server application must be installed on the computer accepting the logging information and that computer's IP address must be known and accessible to the switch.

There are many types of syslog server software packages available, from no cost, open source versions to more costly private versions. If your IT department does not have a syslog server preference, we suggest that you install a simple syslog server, such as the free KIWI Syslog Server and use it to collect and archive firewall logs for security analysis.

Note:

Users are responsible for acquiring the syslog daemon and must install and run the syslog daemon per the manufacturer's instructions.

Emerson provides no support or warranty for any syslog daemon. The KIWI Syslog Server has been tested to work with the DeltaV system and the DeltaV Smart Switch. The free KIWI Syslog Server for Windows is available at http://www.kiwisyslog.com/.

  1. Open DeltaV Explorer.
  2. Select the switch module.

    There are two methods to setting the SYSLOG_IP_ADDR parameter's value.

    • At the class level - to do this, select the switch module class (under Libary > Advanced Definitions > Control Module Classes > Switches.
    • At the instance level - to do this, select the instance of the switch module in the area. The module class must have the Allow instance value to be configured option selected.
    Tip:

    When managing switches on multiple networks, select the Allow instance value to be configured option in the module class. This allows you to configure different IP addresses for each switch, as not all switches will be able to connect to the same syslog server because the subnets will be different on the switches.

  3. Right click the SYSLOG_IP_ADDR parameter and select properties.
    Note:

    This parameter is only visible in the switch module instance if the module class has the Allow instance value to be configured option selected.

  4. Enter the IP address of the syslog server computer in the Value: field.
  5. Click OK.
  6. Download the switch.

    If configuring the module class and no switches are commissioned yet, the download during commissioning will set this address.
