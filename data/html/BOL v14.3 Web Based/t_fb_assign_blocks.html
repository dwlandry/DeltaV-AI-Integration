Assign blocks to fieldbus

Now we will assign the AI block to a fieldbus device. Remember that for fieldbus, blocks can run in either the controller or the fieldbus devices. The decision about where to run the blocks is based on your requirements, and there are pros and cons to each method.

  1. Right-click the block in Control Studio and select Assign I/O > To fieldbus. (To run the blocks in a controller, select Assign I/O > To Signal Tag.)

  2. Click the Browse button and find the device to which you want to assign this block. Navigate through the controller, I/O card, port, and device to get to the blocks. Some devices may have more than one AI block because the device may be capable of outputting more than one variable. In this image, the device, PDT2, has two AI blocks: FFAI1 and FFA12.

  3. Select one of the AI blocks and click OK. Now that the block has been assigned to a device, we will configure a parameter for the device.

The Using InSight Tuning with fieldbus Devices topic has information on how assigning blocks to fieldbus devices affects loop performance and how you can achieve maximum performance.
