Bulk editing Profibus ports, devices, slots, and signals

This section outlines how to bulk edit Profibus ports, devices, slots, and signals. 

The general procedure to bulk edit Profibus objects is:

  1. Create a Profibus card.

  2. Configure the card's port.

  3. Under the port, create and configure a Profibus device of the type you want to bulk edit.

  4. Create or configure Profibus slots under the device as required.

  5. Create or configure Profibus signals under the slots as required.

  6. For each level (Profibus port, device, slot, and signal) use the sample format specification files or create your own and export data from the existing configuration.

  7. Edit the ports in the bulk edit Excel add-in.

  8. Edit the devices in the bulk edit Excel add-in.

  9. Edit the slots I/O in the bulk edit Excel add-in.

  10. Edit the signals I/O in the bulk edit Excel add-in.

  11. Import the ports.

  12. Import the devices.

  13. Import the slots.

  14. Import the signals.
