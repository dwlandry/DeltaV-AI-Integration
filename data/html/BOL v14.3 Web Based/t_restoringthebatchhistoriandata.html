Restoring the Batch Historian data

Restoration of the Batch Historian database can only be performed using the SQL Server Management Studio. All Batch Historian applications must be shut down before restoring data.

  1. Open the SQL Server Management Studio.
  2. Connect to the local SQL server.
  3. Expand Databases.
  4. Right-click the DVHisDB database.
  5. Select All Tasks.
  6. Select the Restore Database menu option.
    CAUTION:

    If the main database is restored, the database will only contain the data present at the time of the backup. All data added to the main database since that backup will be overwritten and potentially lost. If the data still exists in the form of Batch Executive .EVT files or still exists within the Event Chronicle, it will be added to the main database again.

  7. Restore any active archives by selecting and right-clicking the archive, selecting All Tasks, and then clicking the Restore Database menu option.
    Note:

    If you restore only the archive, there can be a mismatch between what is actually in the archive and what the main database shows is in the archives. Restore the main database and the archives together.
