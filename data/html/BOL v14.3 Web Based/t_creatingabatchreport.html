Create a batch report

The intent of this exercise is to demonstrate how to connect to the DeltaV Batch Historian and request data from the Historian's database. The specific data requested, along with how it is handled after retrieval from the database, is up to the individual user. The user may want to query data from other sources as well to include in the final report.

Note:

The example provided in this exercise reads a batch ID and prints out any parameters that were used during the batch, along with the associated parameter values. It uses Microsoft Word to format, output and save the report information. Comments to the code are shown here in green and are preceded by a single quote ( ' ).

  1. Define the variables that will be used by the program to generate the report.
  2. Create a way for users to request a batch report (e.g. an input dialog).
  3. Read the data entered by the user.
  4. Connect to a Batch Historian (using the DSN defined for that historian).
  5. Ask for a list of available batches (using SQL to query the historian's database).
  6. Open an application to use for outputting the data (e.g. Microsoft Word).
  7. Read some batch data (using SQL to query the historian's database).
  8. Format and output the data to the application.
  9. Save the report (optional).
