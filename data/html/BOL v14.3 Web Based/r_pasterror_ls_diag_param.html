PastError diagnostic parameter

Parameter name in Diagnostics Explorer

Context in Diagnostics Explorer

Runtime path

Description

PastError

Card

CTL_NAME/IO1/Cxx/PAST_ERROR

The fatal error that caused the most recent reset of the logic solver card

PastError condition text

Condition Text in PastError

Meaning

Action

Mapping to Alert Condition

Program Assertion

Unspecified internal software error, e.g. corruption of program causes a null pointer to be returned.

If the fatal condition is persistent, do a manual reset of affected card and contact technical support. If the fatal condition was momentary, contact technical support to report the error.

Bits map directly to identical bits in FAILED_ALERTS in a simplex logic solver.

Resource Error

System software could not obtain a hardware or software resource.

Memory Test Failure

Failure detected in periodic main processor RAM test or powerup test of RAM and NVM.

Uncommanded Switchover

Active logic solver has gone through reset (becoming Standby) because it was not communicating with controller.

Control Subsystem Compare Error

The main processors detected a mismatch in outputs or secure parameter data.

Timeout on Inter-Processor Link Between Main Processor 1 and Main Processor 2

Number of scans exceeded for a main processor to respond to the other.

Timeout Between Main Processor 2 and I/O Processor

Number of scans exceeded for IOP to respond to MP2. Fatal errors detected by IOP are revealed by this condition.

Main Processor 2 Compare of I/O Processor Data Failed

MP2 validates the calculations being done by IOP. A mismatch in the results of the calculations causes this condition.

Main Processor 2 Compare of I/O Processor Frequency Failed

MP2 has detected that IOP is communicating at an improper rate.

Task Checkpoint Error

A control or communications task did not have a timely or proper completion.

Hardware Watchdog Failure

A powerup test failed on a watchdog timer or a processor did not arm its watchdog within the window during operation.

Unspecified Hardware Error

Unspecified hardware error such as failure of the commission circuitry.

Control Subsystem Scheduling Error

MP2 is unable to complete writing of output values prior to beginning new control execution.

Change to a slower logic solver scan rate and re-download.

Dual Active Logic Solvers

One logic solver of a pair has gone through reset because both logic solvers were in the active role.

Probably due to an issue with the redundancy link. Problem could be with either logic solver (not necessarily the one that reset). Start by replacing the standby unit, then perform a switchover to it. If the condition returns, replace the other logic solver.
