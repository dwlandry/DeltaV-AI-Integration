Other switch-management tasks

From the Network Device Command Center you can:

  • View diagnostic information from switches that have been commissioned.
  • Receive active PlantWeb alarms and alarm conditions from switches that have been commissioned.
  • Lock Smart Switches (prevent unauthorized devices from being connected to any port on the switches).
  • Decommission switches (return them to DeltaV factory default settings in anticipation of removing a switch that is no longer needed).

For more information on how to use the Network Device Command Center, refer to its online help.
