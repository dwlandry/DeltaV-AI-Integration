Configuration libraries overviews

Configuration libraries, managed in the Library Explorer pane of Graphics Studio, provide a structure for creating and managing configuration library items. Library items include GEM classes, templates, standards, and functions. DeltaV Live provides one out-of-the-box configuration library containing all out-of-the-box library items. This library is permanent and cannot be deleted.

To further organize and manage your library items, you can create additional configuration libraries. These libraries provide a means for you to create multiple versions of your library items and use them within the same system, or to exchange them, through import and export, between other DeltaV systems. For example, assume you want to create a standard color for a commonly used color, orange. You create a color called Orange in the Standards folder in a library called DeltaVSystem1. Because you want to use that same color, Orange, with a GEM class that will be exported from DeltaVSystem1 to DeltaVSystem2, you copy and paste Orange into the Standards folder in DeltaVSystem2.
Note: The name of each library must be unique within the Library Explorer root folder, DeltaV_System.
Each configuration library contains four permanent library folders called GEM Classes, Templates, Standards, and Functions. All out-of-the-box and user-created library items are managed from these folders. These permanent folders cannot be renamed or moved to a different library. Items within each folder, however, can be renamed, deleted, or moved. You can also delete an entire library, with the exception of the out-of-the-box library. If you delete a library, everything in that library is deleted. Additional subfolders can be created under a GEM Classes, Standards, or Functions folder; subfolders can be renamed, deleted, or moved.
Note: The name of each library item must be unique within its own configuration library.
