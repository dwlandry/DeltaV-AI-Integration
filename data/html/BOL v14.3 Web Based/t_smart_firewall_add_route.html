Add a static route to a workstation

The route add command is used to add a route to a computer's routing table. This topic presents basic information about the format of the route add command. Before using this command, consult with your IT department or network administrator for the correct network addresses and subnets used in your organization and for more information on using the route add command.

Note: The route add command is effective on computers that are one hop from the firewall. If your computers are more than one hop from the DeltaV 2.5 LAN then you should consult with your IT department to ensure the proper routing is set up for these computers to access the firewall.
Open a command prompt and enter route add -p Destination mask Netmask Gateway.
  • Route add: adds the route to the routing table in the computer.
  • -p: makes the specified route persistent on the computer so the route survives a reboot.
  • Destination:the address of the network on the other side of the firewall to which this computer needs to communicate.
  • mask: the subnet mask of the Destination network.
  • Gateway: The gateway to the Destination network. For the Smart Firewall this is the IP address of the external port on the firewall.
