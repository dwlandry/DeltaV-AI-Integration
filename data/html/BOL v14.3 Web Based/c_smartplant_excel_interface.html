SmartPlant Excel Interface

The DeltaV software includes Excel add-ins that are the interface you use to exchange instrumentation configuration data between the Intergraph SmartPlant Instrumentation (SPI) application and the DeltaV configuration database. 

The add-ins create the following menus under DeltaV in Excel:

  • SPI Interface — Supports the exchange of data between the SPI application and the Excel worksheet. The interface supports SPI 2013 and SPI 2016

  • I/O Support  — Supports creation and manipulation of configuration data in the Excel worksheet and the exchange of data between the worksheet and the DeltaV configuration database. 

The add-ins are included on the DeltaV installation media and they do not require any additional licensing or DeltaV software. They also do not require any of the other DeltaV Excel add-ins (DeltaV Reporter, for example) to function.

Note:

The Excel DeltaV > I/O Support menu is not intended for general purpose bulk editing. Some features in this add-in may be removed or altered to support the SmartPlant Instrumentation interface as it evolves.

There are two additional components from Intergraph that work with SPI that support moving data from the DeltaV software to the SmartPlant Instrumentation software:

  • Intergraph SmartPlant Instrumentation Schema Component

  • Intergraph SmartPlant Instrumentation Client.

These components are also included with the DeltaV software.
