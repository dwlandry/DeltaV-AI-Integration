parseInt function

The parseInt function parses a string argument and returns an integer of the specified radix (the base in mathematical numeral systems).
Arguments
2
Argument Description
string The string to be parsed.
radix

A number (from 2 through 36) that represents the numeral system to be used.

If this argument is omitted or undefined, it assumes the value of 10.

Return values (number)
An integer of the specified radix.
If the first character cannot be converted to a number, NaN is returned.
Syntax
parseInt(string, radix)
Examples
Example Result 
parseInt('15 * 3', 10)
 Returns "15". 
parseInt('Hello', 8);
 Returns NaN.
