Example phase-to-phase message

To configure the example of phase-to-phase messaging used here, the following steps are required.

  1. In the DeltaV Explorer, set the number of phase partners in the Phase Class Properties to be 1or more. The number does not include the phase itself.

  2. In Control Studio, design the phase logic using the request 5xxx codes according to the phase request codes table as illustrated in the phase-to-phase message example, below.

  3. In Recipe Studio, for each recipe that uses phase-to-phase messaging, define phase link groups that identify which phases are to communicate with each other.

Phase-to-phase messaging is often used to transfer materials. In this example, we will dump a color from a storage tank and charge the color to a blending tank.

The Batch Executive coordinates communications between the two phases, DUMP_COLOR and CHARGE_COLOR, through the use of REQUEST parameters written in the running logic. The number of phase partners in each of the phase classes (DUMP and CHARGE_COLOR) is set to 1.

The phase request codes used in this example are listed in the following table. As you can see, 40nn and 42nn are paired; nn is the resource's equipment ID (number 01 for this example). Additional parameters can be used in the phase-to-phase messages that would use the REQDATA1..5 parameters, as described in the phase request codes table.
