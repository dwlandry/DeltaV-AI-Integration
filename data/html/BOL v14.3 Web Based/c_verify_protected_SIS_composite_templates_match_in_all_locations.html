Verify that protected SIS composite templates match in all locations

To verify that all locations are using the same version of protected templates, at the location where the templates were created:

  1. Open DeltaV Explorer.

  2. Select an SIS Composite Template category.

  3. Record the template names and CRC values in the Contents pane of DeltaV Explorer.

  4. Repeat steps 2and 3 for other template categories.

  5. At the locations where the templates were distributed, repeat steps 2 through 4.

  6. Compare the CRC values at all locations.

The CRC values for each template should match at all locations.
