Graphics elements overview

Graphics Studio provides various types of graphics elements that can be used to create displays, layouts, and GEM classes. Instances of these elements are added to these configurations from the Palette pane. You can then configure these instances to provide their desired appearance and behavior when running online. All properties available on an element can be configured in the Graphics Configuration pane. Additionally, the Graphics Studio ribbon provides various tools and commands to help you configure graphics elements and interact with them on a display.

This section describes all of the graphics elements provided in Graphics Studio.
