Editing object data for each level

The following lists the tasks required to create two copies of the example hierarchy. You do not have to perform these tasks in a specific order, but doing them from the top down may help you keep track of the object names you are creating.

In the process cell data:

  • Change the values in the proc_cell_name field for the two new process cells to PROC_CELL_1 and PROC_CELL_2.

In the unit module data:

  • Edit the area field values to include the process cell names you created -- AREA_A/PROC_CELL_1 and AREA_A/PROC_CELL_2.

  • Change the values for the unit_mod_name field to UNIT_MOD_1 and UNIT_MOD_2. 

In the equipment module data:

  • Edit the area field values to include the names of the parent process cells and unit modules.  

  • Change the module_name field values to EQUIP_MOD_1 and EQUIP_MOD_2. 

  • Because the equipment module contains two control modules the data has two binding name fields.

  • Change the CNT_MOD_LVL_1A binding name field values to CNT_MOD_LVL_1A1 and CNT_MOD_LVL_1A2. 

  • Change the CNT_MOD_LVL_1B binding name field values to CNT_MOD_LVL_1B1 and CNT_MOD_LVL_1B2. 

  • Prepend the binding name field values with a tilde (~).

In the CNT_MOD_LVL_1A data:

  • Edit the area field values to include the names of the parent process cells, unit modules, and equipment modules. 

  • Change the module_name field values to CNT_MOD_LVL_1A1 and CNT_MOD_LVL_1A2. 

  • Change the CNT_MOD_LVL_2A binding name field values to CNT_MOD_LVL_2A1 and CNT_MOD_LVL_2A2. 

  • Change the CNT_MOD_LVL_2B binding name field values to CNT_MOD_LVL_2B1 and CNT_MOD_LVL_2B2. 

  • Prepend the binding name field values with a tilde (~).

In the CNT_MOD_LVL1B data:

  • Edit the area field values to include the names of the parent process cells, unit modules, and equipment modules. 

  • Change the module_name field values to CNT_MOD_LVL_1B1 and CNT_MOD_LVL_1B2. 

In the CNT_MOD_LVL_2A data:

  • Edit the area field values to include the names of the parent process cells, unit modules, equipment modules, and control modules. 

  • Change the module_name field values to CNT_MOD_LVL_2A1 and CNT_MOD_LVL_2A2. 

In the CNT_MOD_LVL_2B data:

  • Edit the area field values to include the names of the parent process cells, unit modules, equipment modules, and control modules. 

  • Change the module_name field values to CNT_MOD_LVL_2B1 and CNT_MOD_LVL_2B2.
