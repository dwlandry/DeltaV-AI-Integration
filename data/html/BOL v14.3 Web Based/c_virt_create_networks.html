Set up Virtual Networks

Remember, the naming convention used in this example is not required.

If you have not already done so, in DeltaV Virtual Studio create and name the networks that your situation requires. Refer to the DeltaV Virtual Studio documentation for detailed information on creating virtual networks.

For the example system the networks are:
  • ACN Primary
  • ACN Secondary
  • LSN01 Primary
  • LSN01 Secondary
  • LSN02 Primary
  • LSN02 Secondary
  • GSN Primary
  • GSN Secondary
