DeltaV SLS 1508 hardware

DeltaV SIS hardware for SLS 1508 systems includes the following products:

  • Logic Solvers (SLS 1508) — run the SIS modules you configure. SLS 1508 logic solvers mount in M-series carriers and require an M-series controller.

  • SLS Terminal blocks — for I/O to Logic Solvers.

  • SISNet Repeaters — provide communication between Logic Solvers that are attached to different controllers.

  • Fiber optic cable/ring — SISNet Repeaters connected to one DeltaV Controller communicate with SISNet Repeaters connected to a different controller over a fiber-optic ring.

  • Terminated one-wide carriers — terminate the local peer bus at the final carrier.
