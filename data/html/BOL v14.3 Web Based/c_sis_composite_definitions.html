SIS composite definitions

Connect multiple function blocks to form a composite block. If you create an SIS composite template in the Library you can reuse it multiple times. You can also create individual composite blocks using the Composite Block assistant in the Special Items palette. You cannot copy or reuse composite blocks created with the Composite Block assistant.

After you put a composite block in a function block diagram, you can view the composite block in the diagram and drill down in the composite to see and modify its structure. You can also step into a composite block when you are viewing a downloaded module online. 

Like in any diagram within the DeltaV system, you can edit the parameter information when in the online view unless the composite was created from a protected template. Because all SIS composites are embedded, an exact copy of the library composite is made and placed within the module. From that point forward, all links back to the original library composite are broken.
