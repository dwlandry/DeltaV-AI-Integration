Bulk editing recipe parameters

Recipe parameter descriptions can be contained in recipe parameters, which in turn are contained by recipes.

When you create the specification file you must specify a subtype. Use the Browse button to browse to the instance of the recipe parameter whose description you want to export.

The following rules apply when bulk editing recipe parameter descriptions:

  • The recipes must exist in the DeltaV database. That is, recipes cannot be created by Bulk Edit.

  • The Bulk Edit FMT and TXT files must be in English, using valid English characters. Non-English, language-specific files are not importable, even on a localized DeltaV system.

  • For existing recipe parameters, if the field is not editable in the DeltaV sysytem, it cannot be edited by Bulk Edit.

  • When an item is marked as Must Exist, it cannot be changed by Bulk Edit. Attempting to change a Must Exist field results in the entire import failing.

  • Exceeding field length limits results in the field being truncated upon import.

  • During import of data, Bulk Edit validates the data file for complianc to the FMT structure and Must Exist flags. If errors are present, the FHX file is not created and the import fails.

  • Fields that allow mixed case (upper and lower case) in the DeltaV system are case-sensitive when importing. For example, if the Category field is named CategoryOne in the DeltaV system, the import file must have the same case structure. CATEGORYONE will be seen as a new field value, different from CategoryOne.
