Or sequence selection and sequence loop execution flow

It is possible for a step to have more than one transition following it. This occurs when Or sequence selections or sequence loops are defined in a PFC. Or sequence selections and sequence loops execute as follows:

  1. A step with multiple transitions starts to run.

  2. The DeltaV system arms each transition following the current step.

  3. Once armed, the DeltaV system monitors the value of each transition.

  4. When one of the transitions evaluates to true, the DeltaV system stops the step that is running and starts the next step.

  5. All of the previous transitions are disarmed and the next transition is armed.

For example, the sequence loop in the sample application, shown in the following figure, tests the pH level of the paint base and executes as follows:

  1. When the phase QA_TEST runs, the DeltaV Batch Executive arms each transition following it.

  2. Once armed, the DeltaV Batch Executive monitors the value of each transition.

  3. The recipe prompts an operator to enter a value for the phase parameter, SAMPLE.

  4. Once a value is entered, the DeltaV Batch Executive evaluates each transition to determine which one is true.

If the value entered is less than 6.5 or greater than 7.5 then:

  • The QA_TEST phase stops.

  • The XFER_IN phase runs again so that more pH additive can be added to the paint base.

If the value entered is between 6.5 and 7.5, inclusive, then:

  • The phase is complete.

  • The XFER_OUT phase runs so that the paint base can be mixed with the required coloring.

Note:

Create all branching and looping after the second step. This allows the recipe to be put into manual mode before the loop or branch begins, permitting an Active Step Change. With an Active Step Change, you must put the step preceding the one you want to control into manual mode. Since the first step in a recipe is a placeholder, it cannot be put into manual mode. If the second step is where the loop or branch begins, you can never perform an Active Step Change on that loop or branch. Therefore, begin the loop or branch at the third step. The second step can then be put into manual mode when needed for control of the anteceding step.
