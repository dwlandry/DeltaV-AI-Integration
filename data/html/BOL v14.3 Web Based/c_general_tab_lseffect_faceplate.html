General tab (LSEFFECT faceplate)

This tab includes:

  • A text value for the output description, DESC_OUT.
  • The output value of OUT_D.
  • The description of each input (DESC_INn).
  • The value of INPUT_STATE (Disabled, Normal, Delayed, Tripped) for each input.
  • IN_Dn.
  • RESET_A button.
  • RESET_B button.
  • A counting Delay timer for each input is visible to the left of the description. It is visible when Input_state is deplayed.
  • When an override is present, Overrides is underscored in red.
