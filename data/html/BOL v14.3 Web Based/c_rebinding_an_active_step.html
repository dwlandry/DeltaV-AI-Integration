Rebinding an active step

To rebind an 'active' step, you must use the Active Step Change function on the Batch PFC Control in DeltaV Operate. This requires putting the recipe in Manual mode, deactivating the step you want to rebind, activating the step you want to run, and executing the ASC. When you execute the ASC, you can select a new unit.

If there are multiple active steps that are using the same unit alias and the operator is only rebinding one of those steps, the rebind will not work. This is because the system is trying to rebind the unit alias for all steps that reference the alias. To perform a rebind in this instance, the operator can either wait until only one step is active; or, perform an ASC on all active steps referencing the unit alias and then rebind the alias from one of the steps. Once the rebind has occurred, the operator can complete the ASC for all the steps currently inactivated.
