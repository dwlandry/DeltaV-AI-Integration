Bulk editing fieldbus ports and devices

This section outlines how to bulk edit fieldbus ports and devices. 

The general procedure to bulk edit fieldbus objects for a single fieldbus card is:

  1. Create a fieldbus card.

  2. Configure the card's ports.

  3. Under one of the ports, create and configure a fieldbus device of the type you want to bulk edit.

  4. For each level (fieldbus port and device) use the sample format specification files or create your own and export data from the existing configuration.

    Use the Format Specification file Must Exist dialog to prevent existing card configurations from being overwritten in the database.

  5. Edit the ports in the bulk edit Excel add-in.

  6. Edit the devices in the bulk edit Excel add-in.

  7. Import the ports.

  8. Import the devices.

You can extend this method to configure the ports and devices for multiple fieldbus cards with one bulk edit text file.
