When to download

The DeltaV Explorer marks the physical objects that require a download with the blue triangle () symbol. However, if you are making changes to the setup data, you see the blue triangle next to the ProfessionalPLUS workstation (at the node level only). The setup data are global data. The changes you make to the setup data affect all of the controllers and workstations. You must download ProfessionalPLUS setup data (or changed setup data) in order for the setup data to be distributed to all workstations and controllers.

CAUTION:

For blocks assigned to non-bus I/O cards (excluding Provox and RS3 I/O), only the channels that have been modified will be affected by a download. All other channels will hold their values and status during the download to prevent disruption to the I/O. For blocks tied to bus cards (AS-I, DeviceNet, H1 fieldbus, Profibus DP, Serial), a download can potentially bump the I/O and cause the controller to hold values. To prevent bumped I/O or held values during a download, place the block producing the output in Manual mode before downloading. Be sure to determine if the process can withstand this temporary disruption. To ensure the safety of the process, it might be necessary to delay the download of the configuration changes until the process can be shut down.

Refer to the following table for a complete list of changes that require you to download.

Note:

A full download of each controller node must be performed before any partial download is allowed.

The following table lists examples of changes you can make in the Explorer that would require a download.

Database changes and their corresponding downloads

When you make this change in the database:

You must perform this download function:

Assign a module to a controller.

Download the module to the controller node. This updates the local module table in the ProfessionalPLUS workstation.

Unassign a module from a controller.

  1. Select the module in the Assigned Modules subsystem of the controller. Delete the assignment.
  2. Click the Download Status > Update command for the controller. This results in a blue triangle for the ProfessionalPLUS workstation.
  3. Click the Download > Changed Setup Data command for the ProfessionalPLUS. This downloads the module table.

Assign a module from one controller to another.

Download the module to the destination controller node. This removes that module from the source node.

Add a workstation node.

Create the workstation node, export the workstation configuration data to removable media, run workstation configuration on the new node, and then download the new workstation.

Add a controller node.

Download the new controller.

Add a card to a controller.

Download the I/O Card.

Modify a card.

Download the I/O Card. For serial cards, also download control modules that reference the card.

Modify a channel.

Download the I/O Card.

Edit a module.

Download the modified module to the controller node.

Add an alarm type.

Download the ProfessionalPLUS setup data.

Modify an alarm type.

Download the ProfessionalPLUS setup data.

Modify an alarm priority.

Download the changed setup data for the control network.

Modify parameter security or field security.

Automatically propagated to other workstation nodes through workstation synchronization

Add a new named set.

Download Changed Setup Data on the Control Network.

Modify or delete a named set.

Download Changed Setup Data on the Control Network.

Add a named state to a named set used by a command-driven or state-driven module.

Perform a partial download of the effected module within the controller.

Perform a download of the setup data for the controller in which the module resides.

Assign an area to a workstation.

Download the workstation node.

Unassign an area from a workstation.

Download the workstation node.

Commission a controller.

Download the controller node. If other controller nodes were downloaded prior to commissioning this controller, download the setup data for those controllers. Until the setup data has been download, modules in those controllers cannot communicate with modules in the recently downloaded controller.

Add or remove a key from a user or group.

Download the ProfessionalPLUS workstation.

Add or remove a user.

Download the ProfessionalPLUS workstation.

Add or remove a user from a group.

Download the ProfessionalPLUS workstation.

Add or remove a group.

Download the ProfessionalPLUS workstation.

Add a second (redundant) controller to a simplex controller.

Redundancy detection is automatic and does not require decommissioning. After installing the standby controller, open DeltaV Explorer. Right-click the newly redundant pair icon, and then select Download > Setup Data. This turns on redundancy for the pair but does not disrupt any existing process control.

Remove a node from the DeltaV network.

Download the setup data to all nodes. Also, stopping and restarting of services such as the Batch Executive may be required.

Note:

There are other times when you must download that are not signaled by a change in the database. You only need to perform a full download for the affected node. A power outage requires that the node without power be downloaded again after power returns. Also, replacing a controller requires a download for the replaced controller. The system auto-senses controller when it is connected.
