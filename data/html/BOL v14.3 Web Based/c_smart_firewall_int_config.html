Information needed to configure the internal network

There is a network on the DeltaV workstations connected to the DeltaV port on the firewall whether you have one or many workstations connected to the port. In a DeltaV system, the network between the Emerson Smart Firewall and the DeltaV workstations is called the 2.5 LAN.

It is important that the network addresses used for the DeltaV workstations' Network Interface Cards (NICs) connected to the 2.5 LAN do not conflict with existing network addresses in other networks in the facility. Your IT department can provide guidance in what addresses are available for use in the 2.5 network.

The firewall's internal network (the 2.5 LAN) can be configured with either static or dynamic IP addressing. Emerson recommends static IP addressing with no DNS server entries. If dynamic IP addressing is used, ensure the firewall's external interface address is created statically with no DNS servers. With dynamic IP addressing using DHCP (Dynamic Host Configuration Protocol), the firewall serves the IP addresses to the workstations in the internal network. If dynamic IP addressing is used, the internal workstations' NICs must be set to Obtain an IP address automatically. Also when dynamic IP addressing is used, the firewall administrator must know the maximum number of internal IP addresses that will be generated. Emerson suggests that you set the DeltaV workstations' third NIC to Use the following DNS server addresses and leave the addresses blank so the DNS server does not create the DNS information in the NIC.

With static IP addressing, the workstations are assigned an IP address by the administrator; not served an IP address by the firewall. If static IP addressing is used, the internal workstations' NICs must be set to Use the following IP address and the firewall administrator must enter the required information (IP address, Subnet mask, and Default gateway) at each workstation. Emerson suggests that you set the DeltaV workstations' third NIC to Use the following DNS server addresses and leave the addresses blank so the DNS server does not create the DNS information in the NIC.

Important: If the DeltaV workstations' third NICs are connected to an existing network, you should understand the network architecture and how the DeltaV workstations' network addresses have been assigned before setting up the network. It is highly recommended that you consult with your IT department or with those responsible for the existing network to determine how to install and configure the firewall in the existing network. It is possible that the existing network architecture will require modifications before the Smart Firewall can be installed.

Questions to ask when configuring the internal network for static IP addressing

Consult with your IT department and obtain the following information required to configure the firewall's internal network for static IP addressing where the firewall administrator assigns the network addresses. We recommend that you record this information on the Worksheet for internal workstation names and IP addresses.

  • What is the range of IP addresses for the internal network? An example range is 192.168.1.100 to 192.168.1.200.
  • What is the subnet mask for the network? An example subnet mask is 255.255.255.0.
  • What IP address will be configured as the firewall's gateway address. This address becomes the network address of the firewall's web UI. This address should be selected from the range of addresses assigned to the internal network. Typically it is the first address in the range.

Be sure that no DNS information is configured for the NICs.

Questions to ask when configuring the internal network for dynamic IP addressing

Consult with your IT department and obtain the following information required to configure the firewall's internal network for dynamic IP addressing where the firewall assigns the network addresses. We recommend that you record this information on the Worksheet for internal workstation names and IP addresses.

  • If the firewall serves the IP addresses to the internal workstations (DHCP), what is the starting address that is used to generate the network addresses for the DeltaV workstations? This must be the first address in the subnet; typically xxx.xxx.1.1.
  • What is the subnet mask for the address?
  • How many workstations will have network addresses assigned? To prevent unauthorized connections this number should be the exact number of DeltaV workstations.

When you have gathered all the necessary information and completed the worksheets, you are ready to configure the internal network.
