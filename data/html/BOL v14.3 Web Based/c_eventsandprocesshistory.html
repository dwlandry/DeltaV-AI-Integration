Events and process history

In the DeltaV system, information is generated about each batch added to the Batch List. The Batch Executive creates an event (.EVT) file at run time. These event files can be viewed from the Batch Operator Interface's Event Journal screen.

Note:

Some mode changes performed by the system are attributed in the batch event journal to the logged-on user. For example, in the case of the Batch Executive being shut down and restarted the recipe's mode is changed. The event journal displays the logged-on user in the User column for this change.

The Batch Operator Interface sends a request to the Batch Executive to archive events when a batch is removed from the Batch List. The Executive opens a list of the event files (.EVT), processes the event files individually, and saves the changes. This information is then used by the Batch Historian for reporting purposes.

The Batch Operator Interface and the Batch Historian work together through the event files generated by the Batch Executive. The connection between the two applications is visible by understanding the following chain of events:

  • Operators can customize what information is displayed in the Journal by configuring the System Configuration window in the Batch Operator Interface.

  • Operators can view Journal information from the Batch Operator Interface.

  • By removing a batch from the Batch Operator Interface's Batch List, the Executive archives the event files to the Batch Historian.

Note:

The Batch Historian must be enabled in order for the event files to be archived.
