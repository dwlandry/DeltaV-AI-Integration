Security configuration

To configure the security for the Campaign Manager server, run the DeltaV Explorer (Start > DeltaV Engineering > DeltaV Explorer). Select the Campaign Manager subsystem under the desired node, right-click and select Properties. On the Action Confirmation tab, configure the confirmation and verification options to use on the Campaign Manager server. Refer to the DeltaV Explorer help and Books online for more information.

There are two main configurable security options available. For several of the actions exposed by the Campaign Manager API, you can select to have the actions confirmed and verified. If the Campaign Manager server determines that a given action requires confirmation then the server requires the corresponding method to pass in a confirmer's Windows username and password to check security rights. For example, if the Campaign Manager server has been configured so that starting a batch requires both a confirmation and a verification, then the DBBCMCampaignEdit.StartBatch( ) method requires valid usernames and passwords to be passed to the server. It is up to the application using the API to determine if the confirmer or verifier strings are needed and, if so, to retrieve them from the user. If any of the strings are required and are not passed in, or if the username/password pairs are invalid, then the corresponding call will fail with one of the following error codes:

dvbcmErrorConfirmerCannotPerformAction - The confirmer passed in does not have the rights to perform the action.

dvbcmErrorVerifierCannotVerify - The verifier passed in does not have verifier rights.

dvbcmErrorInvalidConfirmer - The confirmer username and password pair do not represent a valid Windows user account.

dvbcmErrorInvalidVerifier - The verifier username and password pair do not represent a valid Windows user account.

The actions that require a security check are as follows:

dvbcmConfiguredActionConfigureClient

dvbcmConfiguredActionStartClient

dvbcmConfiguredActionStopClient

dvbcmConfiguredActionAddCampaign

dvbcmConfiguredActionDeleteCampaign

dvbcmConfiguredActionModifyCampaign

dvbcmConfiguredActionUnlockCampaign

dvbcmConfiguredActionAddBatch

dvbcmConfiguredActionStartBatch

dvbcmConfiguredActionModifyBatch

dvbcmConfiguredActionRemoveBatch

dvbcmConfiguredActionUserComment

dvbcmConfiguredActionUserSelect

dvbcmConfiguredActionModifyLockedParameter

The first three actions are used by the Campaign Manager Operator Interface and can be ignored by a custom API. The last nine can be used to determine if a confirmer or verifier name and password will be needed.

When one of the actions is about to take place the GetConfigureActionInfo method can be used to determine if the program will need to prompt for anything. The method takes three parameters. The first is a memeber of DVBCMConfiguredAction enumeration (constants shown above) and the last two are Boolean flags to tell if a confirmer or verifier is needed for that action. If the flags return FALSE then the API needs nothing. If any of them return TRUE then some action will need to be taken by the program as the next example shows. 

Private Sub StartBatch(strNodeName As String, ByRef objCampaignEdit As _
    IDVBCampaignEdit4, strBatchID As String)
    Dim bIsConfirmerRequired As Boolean
    Dim bIsVerifierRequired As Boolean
    Dim strConfirmerName As String
    Dim strConfirmerPassword As String
    Dim strVerifierName As String
    Dim strVerifierPassword As String
    Dim strComment As String
    ' Check to see if confirmer and verifier are needed to start a batch
    Call DVBCMClient.GetConfigureActionInfo(dvbcmConfiguredActionStartBatch, _
        bIsConfirmerRequired, bIsVerifierRequired)
    ' If a confirmer name and password are needed, prompt user
    If bIsConfirmerRequired Then
        Call PromptUserForConfirmer(strConfirmerName, strConfirmerPassword)
        ' If a verifier name and password are needed prompt user
        If bIsVerifierRequired Then
            Call PromptUserForVerifier(strVerifierName, strVerifierPassword)
        End If
        Call PromptUserForComment(strComment)
    End If
' Start the batch, giving confirmer and verifier info if needed
ObjCampaignEdit.StartBatch2(strBatchID, strConfirmerName, _
    strConfirmerPassword, strVerifierName, strVerifierPassword, _
    strComment)
End Sub
