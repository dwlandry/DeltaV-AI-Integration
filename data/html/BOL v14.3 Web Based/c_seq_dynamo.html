SEQ dynamo

The LSSEQ function block has a single dynamo similar to the LSSTD function block dynamo. When you add this dynamo to a picture, the Dynamo Properties dialog prompts you to enter the path to the LSSEQ block. If you prefer to use a custom faceplate rather than the default faceplate, enter its name in the Faceplate display name field. The Dynamo Properties dialog is shown below:
