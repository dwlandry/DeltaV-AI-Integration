Scenario: Create a new SIS CSLS system

In this scenario there is no existing SIS CSLS system. A new system is being created. The strategy required to implement this scenario includes the following:
  1. Create the virtual safety system.
  2. Check out the logic.
  3. Disable all SIMULATE_IN parameters and turn off Debug mode for all modules.
  4. Record the module CRCs.
  5. Decommission and unassign all virtual hardware.
  6. Export the entire DeltaV system configuration.
  7. Import the configuration into the production system.
  8. Assign, commission, and download physical hardware in the production system.
