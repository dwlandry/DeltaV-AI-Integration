Edit the exported data

To create two new modules you must edit both exported files. Editing the containing module is slightly different than editing the contained module so both are detailed below.

To bulk edit a contained module:

  1. Use the DeltaV Bulk Edit menu to open SLAVE_CAS.TXT.

  2. Click OK on the Unicode Detected popup.

    The file opens. Note that only the fields you specified in the format file appear as columns in the spreadsheet.

  3. Copy line 2 of the spreadsheet and paste it back into the spreadsheet into line 3.

  4. In the area column, remove /MASTER_CAS from both lines, leaving only AREA_A.

  5. In the module_name field, rename the two modules to SLAVE_CAS2 and SLAVE_CAS3.

  6. Edit any other parameters you exported as you require.

  7. Save the file using the DeltaV Bulk Edit menu.

  8. If SLAVE_CAS_ASCII.TXT is not already selected, select it.

  9. Click Save.

  10. Click Yes to replace the existing copy of the file.

  11. Close the spreadsheet but leave Excel and the Bulk Edit Add-in open.

To bulk edit a containing module:

  1. Use the DeltaV Bulk Edit menu to open MASTER_CAS.TXT.

  2. Click OK on the Unicode Detected popup.

    The file opens. Note that only the fields you specified in the format file appear as columns in the spreadsheet.

  3. Copy line 2 of the spreadsheet and paste it back into the spreadsheet into line 3 of the spreadsheet.

  4. In the module_name column, rename the two modules to MASTER_CAS_2 and MASTER_CAS_3.

  5. In the SLAVE_CAS/MODULE_BLOCK_BINDING.MNAME column, change the two rows to ~SLAVE_CAS2 and SLAVE_CAS3.

    The spreadsheet should look like the following figure.

    This step binds each the MASTER_CAS modules to specific instances of SLAVE_CAS created when you import the edited files. The tildes (~) at the beginning of each module name cause the bulk edit software to discard extra modules created during import. If you do not use the tildes an extra copy of all the contained modules remain in the hierarchy after import.

  6. Edit other parameters if necessary.

  7. Save the file using the DeltaV Bulk Edit menu.

  8. If MASTER_CAS_ASCII.TXT is not already selected, select it.

  9. Click Save.

  10. Click Yes to replace the existing copy of the file.

  11. Close the spreadsheet and close Excel unless you have more files to bulk edit.

Note:

You can also use Bulk Edit to move existing containing and contained modules, with some limitations.
