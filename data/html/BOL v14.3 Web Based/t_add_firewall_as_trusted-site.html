Adding the Smart Firewall to Internet Explorer's trusted sites

  1. Open Internet Explorer
  2. Click Tools Internet Options.
  3. Click the Security tab, select Trusted Sites, and click the Sites button. The Trusted Sites dialog opens:
  4. Copy and paste the firewall's IP address to Add this website to the zone: and click the Add button. The firewall's address appears in the Websites: list.
  5. Select Require server verification (https:) if it is not already selected.
  6. Close the Trusted Sites dialog
  7. Click OK on the Internet Options dialog.
