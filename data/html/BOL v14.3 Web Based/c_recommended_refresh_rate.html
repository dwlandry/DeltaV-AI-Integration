Recommended refresh rate for the Picture Converter

The Picture Converter defaults to a refresh rate of 0.0 seconds for all objects containing data. However, it is recommend that you use a 1 second refresh rate for most objects. Although you can configure objects to refresh at a faster rate (.5 seconds), run process data is provided to the workstation at a rate no faster than 1 second. A faster refresh rate does not increase the rate data is provided to the workstation and a slower refresh rate does not decrease the rate data is provided. Click the Refresh Rate Expert Toolbar button . In the Refresh Rate Expert dialog, select Entire Picture, select Refresh Rate, click the down arrow, and then select 1.0.

Repeat this procedure on each graphic after all engineering is complete.
