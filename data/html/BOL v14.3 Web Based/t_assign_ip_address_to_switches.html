Assign IP address to switches

To connect to the switch you need a terminal (or a PC with terminal emulation software such as HyperTerminal). If the switch is already installed in the DeltaV network, use a Management station and terminal emulation software. The comm settings for the terminal or terminal emulation software should be:

  • 9600 baud
  • 8 data bits
  • no parity
  • 1 stop bit
  • no flow control

You also need a serial interface cable purchased from Emerson (or refer to DeltaV S-series and CHARMs Hardware Reference for information on building your own serial interface cable):

  1. Connect power to the DeltaV Smart Switch and wait for the Run light on the switch's front panel to stop flashing and turn green.
  2. Connect the terminal, PC, or Management station to the switch's serial port with the serial interface cable. If you are using HyperTerminal emulation software, complete steps 3 through 7. If you are using a terminal, skip to step 8.
  3. Start a HyperTerminal session.
  4. On the Connection description dialog, name the connection and click OK.
  5. On the Connect To dialog, set the Connect using field to the computers comm port and click OK.
  6. On the comm port Properties dialog, make sure the settings are correct.
  7. Click OK.
  8. Press Enter. The User prompt appears.
  9. Enter admin at the User prompt. The Password prompt appears.
  10. Enter Emerson1. The Emerson prompt appears. The prompt is (Emerson NNNN) >, where NNNN indicates the switch type (MD for an MD switch, FP for an FP switch, and RM for an RM switch) and the switch model number.
  11. Enter DeltaV default at the Emerson prompt to make sure the switch is reset to factory settings. The switch responds with: 
    Clearing configuration will interrupt switch operation for about 10 seconds.
Are you sure you want to clear the configuration? (y/n)
  12. Press Y to clear the setup. After a few seconds the User prompt reappears.
  13. Enter admin at the User prompt. The Password prompt appears.
  14. Enter Emerson1. The Emerson prompt appears.
  15. Enter DeltaV at the switch prompt. The switch responds with: 
    DeltaV: Enter DeltaV IP address for the Switch [Currently 0.0.0.0]:
  16. From your list, enter the IP address you are assigning to the switch.

    The switch responds with: 

    DeltaV: Enter Name for the Switch [max. 63 chars]:

    Entering a name is not required. If you do not enter a name the switch generates a name based on the switch type and the last six characters of the MAC address. After you commission the switch the name is overwritten by the switch module name.

  17. Enter a name if desired. The switch responds with: 
    DeltaV: Enter Location for the Switch [max. 63 chars]:

    Entering a location is not required. Any value you enter is overwritten by the value of the switch module LOC_DESCRIPTION parameter.

  18. Enter a location if desired. The switch responds with: 
    DeltaV: Disable Network Switch Discovery? (y/n)
[Recommended for use with DeltaV v10.x systems] [Default = y]:

    Press N to enable network switch discovery. If you disable switch discovery you cannot flash switch LEDs from NDCC.

    Once you respond to this prompt you cannot back out or quit.

  19. After you answer the previous prompt the switch responds with: 
    DeltaV: Advanced Configuration? (y/n)
  20. Regardless of how you respond to this prompt any changes you have made to the previous prompts are saved to the switch. The switch returns to the Emerson prompt.
  21. Unless you are continuing to advanced configuration, repeat steps 1 through 20 for all Smart Switches in your system.
  22. Wire all switches into the DeltaV primary and secondary networks

All Smart Switches should now have IP addresses assigned to them. The Network Device Command Center (NDCC) application now detects the switches and their corresponding switch modules. The names of all switches are the names you configured for their switch modules. If there are no alarms, the switch icon is now . All switch alarm and displayable parameters are presented normally and are available for use in displays.

If the switch is not running, or if the IP address in the switch does not match the IP address in the module, a COMM_ALM is active on the switch module and NDCC shows the COMM alarm icon for the switch. There will also be a number of ??? indicators for values that cannot be read from the switch.
