Configuring IEC 61850 devices and signals

IEC 61850 physical devices, their logical devices, and device signals are configured under the port.

IEC 61850 physical device configuration consists of specifying the physical device's primary and secondary IP addresses.

IEC 61850 defines specific names to identify data. Data is contained in Intelligent Electronic Devices within logical devices in logical nodes. The logical devices and signals defined under IEC 61850 devices include the information needed to identify which data element within a logical node of a logical device is to be accessed.

Among the items configured for logical devices that use the IEC 61850 protocol are the logical device name and logical node name. The logical device name identifies the logical device within the Intelligent Electronic Device that contains the logical nodes holding data to be accessed by the logical device's signals. The logical node name defines the container that holds the attribute data to be accessed by the logical device's signals. Refer to the device documentation for the strings to use for the logical device name and the logical node name and refer to the context sensitive help in DeltaV Explorer for configuration information.

The device signals are used to access the device data. IEC 61850 signals make use of common properties such as signal direction, data type, byte order and offset and so on.

Note: Make sure the parameter name is correct. Incorrect names can result in a Reject PDU message from the server in the MMS response rather than bad status on the signal itself.
