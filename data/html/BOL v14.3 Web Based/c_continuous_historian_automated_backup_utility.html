Automated backup utility

The DeltaV Continuous Historian includes an automated backup utility that can be used to perform scheduled backups of DeltaV Continuous Historian data from the Windows Scheduler or from a third party application. You can also run the automated backup utility manually from a command prompt. The automated backup utility accesses the DeltaV Continuous Historian Server to extract data from its database and backs this data up safely to local or networked storage.

The automated backup utility includes support for the following tasks:

  • Back up the active data set to local or network storage
  • Back up all current data sets to local or network storage
  • Back up all extended data sets and the current data set to local or network storage
  • Create a new active data set before performing the backup
  • Limit the data sets to be backed up according to their age
  • Delete backed up data sets in the target directory according to their age
Note: As an alternative to using the automated backup utility, you can use the Schedule DeltaV Continuous Historian Data Backup option in the Continuous Historian Administration application. The interface for this option includes additional options, not included in the automated backup utility.
