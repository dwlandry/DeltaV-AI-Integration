Steps to recipe building

Building a recipe is a straightforward process and requires the following steps:

  1. Open Recipe Studio. A new PFC is automatically opened. If Recipe Studio is already running, click the Main button, click New, and then select the type of recipe (operation, unit procedure, or procedure).
  2. Define the steps. Assign the individual units, unit classes or unit aliases (if in procedure level recipe) to the step you are creating.
  3. Add transitions to move the recipe from one step to another. Write specific expression logic or use the default transition feature.
  4. Set the values for the step parameters. If the step is a phase, the parameters are inherited from the phase class. You can leave the default value, change the default value, set the Origin to Operator (default applies also), set the Origin to Defer and the Source as one of the recipe parameters, or set the Destination to Refer (for report parameters) and set the Target to one of the recipe parameters.
  5. Create recipe parameters. You can define type, low and high limits, default value, engineering units, scalability, and category for each parameter.
    Note:

    When deferring or referring a step parameter value, the recipe parameter is created when you set the Origin and Destination on the step parameter. The category and type of the recipe parameter must match the category and type of the step parameter in order to defer/refer the value.

  6. If this is a recipe that you will use as a top-level recipe, define any recipe formulas needed. These formulas override default values of the recipe parameters. If this is not a top-level recipe, the recipe parameters at this level can be considered step parameters at the next level up. You can then create recipe parameters and recipe formulas at that next level.
  7. Complete the recipe properties. This step is required to verify the recipe. The following fields must be completed:

    • Version

    • Author

    • Equipment

  8. If this recipe is the top-level recipe and needs to be available to the operator to run, assign the recipe to a Batch Executive. Do not assign lower level recipes.
  9. Save the recipe. Each recipe must have a name. This allows you to reference the recipe easily in higher levels and allows the operator to easily select the recipe to run.
  10. Verify the recipe. Verifying the recipe ensures the recipe is defined correctly. If it is not, Recipe Studio identifies the problems so you can correct them.
