Assigning a plant area to a Batch Executive subsystem

To better organize and manage equipment, you create a process cell under an area and list all of the batch equipment needed under that process cell. When you assign a plant area to a particular Batch Executive you are also assigning all the objects contained in that area (process cell and equipment) to that Batch Executive. A Batch Executive can control only the equipment assigned to it. Plant areas can be assigned to only one Batch Executive at a time.

Note:

Because areas are assigned to one and only one Batch Executive at a time, and the Batch Executives do not communicate with each other, it is very important that you assign the equipment to the appropriate areas. A recipe will not run if all the required units are not found on the same Batch Executive as the recipe.

You can assign a plant area to a Batch Executive subsystem by dragging the area to the Assigned Areas component under a Batch Executive or by using context menu commands. To use the context menu, select and right-click the area, select Assign > Batch Subsystem, and then browse to the desired workstation. Alternatively, select the workstation and under the Batch Executive subsystem, Assigned Areas, right-click, select Assign Area, and then select the area that you wish to assign to this workstation. The workstation must be enabled as a Batch Executive and downloaded before any changes can take effect.

If you reassign an area to another Batch Executive subsystem, the original assignment is removed from the configuration database but is not removed from the Assigned Areas component until you download the Batch Executive subsystem.
