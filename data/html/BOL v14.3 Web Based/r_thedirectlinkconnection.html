The Direct Link connection

The Direct Link option is a direct, private, gigabit connection between the Redundant Batch partners. This link transfers the batch redundancy system data between the two partners faster and with less traffic than using the DeltaV ACN. If the Direct Link connection fails for any reason, the batch redundancy system data is switched to the DeltaV ACN until the Direct Link connection is reestablished.

In the event of a Direct Link connection failure, the Redundant Batch communication is tried first on the DeltaV secondary ACN and then, if the secondary is not available, communication is established on the DeltaV primary ACN. Communication remains on the DeltaV ACN path found until the Direct Link connection is reestablished or the current path also fails.

Cable and NIC specifications (that is, cable lengths, cable shielding, crossover cabling and supported Ethernet cards) are the same as the DeltaV ACN. You must use a crossover cable for the Direct Link connection.

The Direct Link connection uses a dedicated, gigabit Ethernet card with the assigned IP address in the 10.12.x.x address range for the preferred active node and the 10.13.x.x address range for the preferred standby node.

To configure the system to use the Direct Link connection (which sets the Direct Link IP addressing for the node), follow these steps:
  1. Enable Direct Link on the Redundancy tab of the Application Station Properties dialog.
  2. Download the Application Station's setup data Object > Download > Setup Data.
  3. Export the workstation configuration file (File > Export > Workstation Configuration).
  4. Re-run Workstation Configuration (Start > DeltaV Installation > Workstation Configuration) for both the preferred active and preferred standby nodes.
Note:

If you disable Direct Link, you must repeat the above steps.
