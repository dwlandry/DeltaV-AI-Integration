Migrate from the Legacy Historian or the Advanced Continuous Historian to OSIsoft PI Server

The Legacy Historian is no longer supported as a DeltaV option. After upgrading DeltaV on a system where you have been using the Legacy Historian or the Advanced Continuous Historian, you can migrate to OSIsoft PI Server by completing the following steps:

  1. Upgrade DeltaV on the Application Station where you were using the Legacy Historian or the Advanced Continuous Historian.
  2. If you plan to run PI Server on the Application Station in the DeltaV Area Control Network (ACN), complete step t_migrate_legacy_ach_to_enterprise_pi_server.html#task_51B674B970AF4F56901608D74F08397E_unique_55__substep_1E31FAD4A5D64F35B495B46FDF44CF6C_unique_1 below. If you plan to run PI Server on a remote Application Station or a non-DeltaV workstation outside the DeltaV ACN, complete step t_migrate_legacy_ach_to_enterprise_pi_server.html#task_51B674B970AF4F56901608D74F08397E_unique_55__substep_62182FB947084AB3A612A2C134B02973_unique_1 below.
    1. Install and configure PI Server on the Application Station in the DeltaV ACN according to the documentation provided by OSIsoft.
    2. Install and configure PI Server and the PI Asset Framework (PI AF) Server on the remote Application Station or a non-DeltaV workstation outside the DeltaV ACN according to the documentation provided by OSIsoft.
  3. Install the DeltaV Smart Connector on the Application Station in the DeltaV ACN according to the documentation provided by OSIsoft.
  4. Enable PI Server in DeltaV Explorer by right-clicking the Continuous Historian subsystem under the Application Station where you installed the DeltaV Smart Connector, and then selecting Properties. On the General tab, select the Enabled check box, and then select the Use Enterprise Historian option.
  5. Download the Application Station where you installed the DeltaV Smart Connector.

The configuration of the Legacy Historian or the Advanced Continuous Historian that you were previously using on the Application Station is preserved and migrated to the new installation of PI Server.

Important:

Any historical data previously collected with the Legacy Historian or the Advanced Continuous Historian is not merged into the PI Server database. For more information, refer to the DeltaV Historian Upgrade Planning Guide white paper on the Emerson web site, also available from your Emerson field sales office or local business partner.
