Scenario: Add SIS CSLS hardware that interacts with existing hardware

In this scenario An existing system is being expanded. The new safety system hardware interacts with the existing safety system requiring some reconfiguration and downloading of existing hardware.

Note:

The configuration changes and download of the existing hardware in this scenario requires that the production system be shut down before exporting the configuration for use in the virtual system.

The strategy to implement this expansion is:
  1. Shutdown the existing system.
  2. Decommission and unassign the hardware that will be affected by the updated configuration.
  3. Export the entire existing DeltaV system configuration from the production system.
  4. Ensure that the ProfessionalPLUS of the virtual system matches that of the production system.
  5. Import the system configuration into the virtual system.
  6. Add the new safety system hardware to the virtual system.
  7. Check out the logic.
  8. Disable all SIMULATE_IN parameters and turn off Debug mode for all modules.
  9. Record module CRCs.
  10. Decommission and unassign all virtual hardware.
  11. Export the entire DeltaV virtual system.
  12. Import the configuration into the production system.
  13. On the import dialogs that ask "Would like to update the existing object in the database…" click Yes only for the new physical hardware and the existing physical hardware affected by the configuration changes. Click No for all other objects.
  14. Assign, commission, download the physical hardware.
  15. Verify that module CRCs are the same as in the virtual system.
