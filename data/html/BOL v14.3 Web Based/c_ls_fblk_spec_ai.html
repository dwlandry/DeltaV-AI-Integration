Logic Solver Analog Input function block

The LSAI function block accepts a single analog input signal from an input and makes it available to other function blocks.

LSAI Function Block 

The LSAI block provides an interface to analog input devices connected to Logic Solvers that are on the same controller. Some typical analog devices are differential pressure, flow, temperature, and level transmitters. 

The function block performs scaling and provides a square root function for the input data. In SLS 1508 systems the input specified can be one of the 16 channels on this logic solver or an input channel on a logic solver on the same controller. In CHARMs Smart Logic Solver systems the input specified can be any LS CHARM of any CSLS in the Local Safety Network.

Analog inputs can be from conventional or HART channels. This function block does not use digital values from HART channels.

The LSAI block does not support mode and does not have alarms.
