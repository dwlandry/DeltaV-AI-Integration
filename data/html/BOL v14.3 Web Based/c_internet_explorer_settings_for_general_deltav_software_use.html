Internet Explorer settings for general DeltaV software use

The DeltaV setup program installs Microsoft Internet Explorer on all workstations. The first time you use Internet Explorer, the software enables you to choose settings. Select the following settings during Internet Explorer setup for general use. Certain DeltaV web-based applications may require additional settings. Those settings are specified in the documentation for those applications.

Setting

Recommended selection

Internet search provider

Select Keep my current default settings.

Phishing Filter

Keep the default setting (the check box is cleared to disable the setting).

Activate ClearType

Keep the default setting (the check box is selected to enable the setting).

Language and Region

Click English (for English-language versions of DeltaV software).

Join the Customer Experience Improvement Program

Keep the default setting (the check box is cleared to disable the setting).

Add-on support (you may be prompted to allow support for various Add-ons).

DeltaV does not support Internet Explorer Add-ons.

After you save these settings, make sure the Disable Phishing Filter option is selected. This option is under Tools > Internet Options > Advanced.
