Batch Executive Server's client configuration

The Batch Executive Server's Client Configuration allows you to enable or disable commands that the operator can access in a Batch Executive client. By default all batch run-time commands are enabled. 

Note:

Batch Executive clients are any application that connects to a Batch Executive. The Batch Operator Interface is a Batch Executive client as is the Operator Prompts display in DeltaV Operate.

The client configuration is configured for each Batch Executive. As a client connects to the Batch Executive, it inherits the configuration. However, if you select Allow settings to be configured at the local client, then the client can override these settings with local settings set for the workstation. For example, when the client is the Batch Operator Interface, the settings can be overridden from the System Configuration and Defaults dialog.
