PID simulation module detail display (SR_PID)

The following figure shows the detail display for a module named SIMPID created from the template SIM_SR_PID.

Detail Display for the Module Template SIM_SR_PID

The simulation downloads in steady-state conditions. You can customize the process by changing the parameters under Simulation Setup.

Tuning the Loop and Measuring the Performance

To tune the control loop, press the button next to Tuning to start DeltaV InSight. After tuning, you can test the results in several ways. With the loop in Auto, change the setpoint from InSight or the faceplate. Observe the response in InSight or open the trend or chart display from the faceplate.

The detail display quantifies the loop's performance. The simulation module calculates the percent overshoot on setpoint changes as a percentage of the setpoint change (not as a percentage of EU range). The simulation module also calculates the integrated error as the integral of the absolute error (IAE). IAE is the absolute value of SP-PV accumulated each module scan. The percent overshoot value is reset whenever the setpoint is changed. IAE is reset whenever any of the Reset buttons are pressed.

Generating Load Disturbances

You can generate load disturbances by changing the inlet temperature or product flow. Making such a change is done by changing the endpoint value. The disturbance can be shaped by adjusting the time constant or ramp rate. The disturbance variable moves from the current value to the endpoint as a step, a first order response, or a ramp, depending on the value of time constant and ramp rate.

Changing the inlet temperature provides a bias to the process. Changing the product flow rate affects the process gain. The dynamic response of a disturbance in inlet temperature is a function of the disturbance generator, the transmitter's distance from the heater, and the transmitter time constant. The dynamic response of a product flow disturbance is a function of the above factors, plus the time constants for heat transfer.

Customizing the Process

You can create any type of self-regulating process model by manipulating the parameters in Simulation Setup. The gain of the process is a function of the steam enthalpy, liquid (product) heat capacity, and product flow. The deadtime is a function of the transmitter's distance from the heater and the product flow. You can manipulate the four time constant values to create a first through a fourth order process model. The parameters under Simulation (Actual) are read-only and reflect the actual process gain and deadtime as well as the two time constants for heat transfer.

Adding Hysteresis and Noise

You can further manipulate the process by adding hysteresis to the steam valve and/or noise to the outlet temperature measurement.

The hysteresis value is the percent change in OUT (of the PID or FLC block) required to take up all the backlash in the valve so that further changes in OUT in the same direction result in a change in steam flow. As OUT changes direction, the amount of remaining backlash varies between zero and the entered hysteresis value.

Noise is entered as the maximum bias in outlet temperature. The noise is added to or subtracted from the calculated outlet temperature using a random number function. The random number is filtered using the value of the transmitter time constant.

Resetting the Simulation

There are two ways to reset the simulation. If you want to create steady-state conditions based on the current output of the PID or FLC block, click Reset Dynamic Elements. If you want to reset the simulation to the initial steady-state conditions (product flow, steam enthalpy, liquid heat capacity, inlet temperature, and outlet temperature setpoint), click Reset To Initial Steady-State. Note that resetting to initial steady-state conditions does not change the parameters affecting dynamic response. To restore all the default values, download the module again.

Adding Feedforward Action to the Control Block

Feedforward action is enabled or disabled by clicking the word YES or NO next to Feedforward Enable under Tuning. Clicking the word YES or NO toggles the enable status to the other word. When feedforward action is enabled, the feedforward value in units of steam flow appears above the controller symbol in the process diagram. The feedforward model calculates the required steam flow from the outlet temperature setpoint, the inlet temperature, the product flow, the product heat capacity, and the steam enthalpy.

Changing the Form and Structure

For modules created from SIM_SR_PID, click the form or structure value field under Tuning to open the data entry dialog. You can enter the new value as an integer or as text (exactly as shown below). The control block must be in Man or OOS mode to change the value. InSight reads the form when calculating tuning parameters, so be sure to tune again whenever the form is changed.

  • Form

    0 - Standard

    1 - Series

  • Structure

    0 - PID action on error

    1 - PI action on error, D action on PV

    2 - I action on error, PD action on PV

    3 - PD action on error

    4 - P action on error, D action on PV

    5 - ID action on error

    6 - I action on error, D action on PV

    7 - Two Degrees of Freedom Controller
