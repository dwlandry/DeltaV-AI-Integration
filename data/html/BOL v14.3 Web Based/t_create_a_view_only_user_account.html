Create a view-only user account

A view-only user account is an optional account that enables the user to view alarms but does not allow the user to write values. (Can also be called zero span of control user.) This account may be appropriate as the default account associated with the screen saver for security purposes.

Specifically, the account:
  • Shows active alarms in the alarm banner (and other alarm displays) for specified plant areas.
  • Does not allow the user write new values to parameters in most modules.
  • Enables the user turn off the horn.
  • Enables the user to use the disable horn button.
  1. Using the DeltaV User Manager application, designate one of the unused locks (for example, User Lock 10) for the view-only account.
  2. Right-click User Lock 10 and rename it to View Only.
  3. Create a new account and grant the View Only key.
  4. Download setup data for the appropriate workstation. The example below provides information about horn privileges.

User account with view only and horn privileges

A DeltaV NEWUSER account requires view-only privileges for alarms in plant areas AREA_A, AREA_B, and AREA_C. To grant the privileges:
  1. In User Manager, double-click NEWUSER. The software displays the properties dialog.
  2. Choose the Keys tab.
  3. Select View Only item in the list of all locks on the left.
  4. Click Grant Key.
  5. Select AREA_A and click OK.
  6. Grant the same key for AREA_B and AREA_C .

This enables NEWUSER to see the alarms from plant areas AREA_A, AREA_B, and AREA_C in the alarm banner (assuming that these areas were also assigned to this workstation's Alarm & Events subsystem and that the areas were not turned off in the alarm area filtering display). If the horn was enabled, and sound files were configured for the alarm priorities, then the horn would sound.

At this point, NEWUSER can not turn off an active horn. The default configuration is to attach the Control lock to the HORN parameter name. Since NEWUSER does not have the Control lock in plant area 0 (AREA_A), then an attempt to write that parameter would be prevented. To enable NEWUSER to turn off the horn it is necessary to change the lock assignment of the HORN parameter through DeltaV Explorer to the View Only lock. Refer to Explorer help for information about defining locks for module parameters.

NEW USER can not disable the horn (the horn disable button writes the HENAB field of the HORN parameter). To enable NEWUSER to disable the horn, it is necessary to change the lock assignment of the HENAB field through DeltaV Explorer to the View Only lock. Refer to Explorer help for information about defining parameter field locks.
