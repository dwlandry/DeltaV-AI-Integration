Starting the Batch Operator Interface

There are two ways to start the Batch Operator Interface: from the Start menu and from the command line.

The most common way to start the Batch Operator Interface is from the Start menu. Select Start > DeltaV Operator > Batch Operator Interface. The application starts with the Batch List screen as the default.

Note:

When running the Batch Operator Interface, it is recommended to login using only a domain account. However, if local account is used then a matching local account must be created on the Batch Executive machine.

To start the Batch Operator Interface from the command line, enter the following at the DOS prompt: 

DVBCLIENT

This will launch the application in the Batch List screen. If you want to specify the screen to start with, use the following syntax: 

DVBCLIENT /vVIEW_xxx

(where xxx is the screen specifically wanted. Refer to the table for a list of screens that can be specified.)

Note:

The 'v' (of /v) must be in lower case. The rest of the statement is not case-sensitive. If something invalid appears after the /v, or if no /v parameter is given, the Batch Operator Interface will use the Batch List screen as default.
