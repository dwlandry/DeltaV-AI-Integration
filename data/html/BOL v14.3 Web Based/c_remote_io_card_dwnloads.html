Remote I/O downloads options

There are  two download options for remote I/O cards:

  • Physical Card – this download option on the card in the I/O Network downloads the physical card to the Remote I/O Node.

  • Card Assignment – this download option on the card placeholder in the Assigned I/O subsystem downloads the physical card to its Remote I/O Node and downloads the card's assignment to the controller.

Note:

If the configuration has not changed since the last download, either the physical card or the physical card and card assignment can be downloaded. However, if the configuration has changed since the last download, the physical card and card assignment are downloaded even if Download physical card only is selected.
