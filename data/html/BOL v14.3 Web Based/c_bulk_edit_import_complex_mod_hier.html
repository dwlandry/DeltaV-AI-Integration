Importing complex module hierarchy data

You must import the data in a specific order to successfully create copies of the example hierarchy. Generally, import process cells and unit modules from the top down, import equipment and control modules from the bottom up. After you import each level you may want to refresh DeltaV Explorer to make sure the changes appear.

  1. Import the process cell data.

    PROC_CELL_1 and PROC_CELL_2 appear below AREA_A.

  2. Import the unit module data.

    UNIT_MOD_1 and UNIT_MOD_2 appear under PROC_CELL_1 and PROC_CELL_2 respectively.

  3. Import the CNT_MOD_LVL_2A data.

    CNT_MOD_LVL_2A1 and CNT_MOD_LVL2A2 appear below AREA_A.

  4. Import the CNT_MOD_LVL_2B data.

    CNT_MOD_LVL_2B1 and CNT_MOD_LVL2B2 appear below AREA_A.

  5. Import the CNT_MOD_LVL_1A data.

    CNT_MOD_LVL_1A1 and CNT_MOD_LVL_1A2 appear below AREA_A.

    CNT_MOD_LVL_2A1 and CNT_MOD_LVL2B1 move below CNT_MOD_LVL_1A1.

    CNT_MOD_LVL_2A2 and CNT_MOD_LVL2B2 move below CNT_MOD_LVL_1A2.

  6. Import the CNT_LVL_1B data.

    CNT_MOD_LVL_1B1 and CNT_MOD_LVL_1B2 appear below AREA_A.

  7. Import the equipment module data.

    EQUIP_MOD_1 and EQUIP_MOD_2 appear below UNIT_MOD_1 and UNIT_MOD_2 respectively.

    CNT_MOD_LVL_1A1 and CNT_MOD_LVL_1B1 move under EQUIP_MOD_1.

    CNT_MOD_LVL_1A2 and CNT_MOD_LVL_1B2 move under EQUIP_MOD_2.
