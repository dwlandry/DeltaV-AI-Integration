Floating License Manager overview

The Floating License manager displays the floating licenses that are either in use or available for use. The Floating License manager also displays the number of valid temporary licenses and permanent licenses. Floating licenses and temporary licenses are types of seat licenses.

Click the plus sign (+) next to an item to display additional information about the item.

The Copy toolbar button copies expanded data and columns to the clipboard in an Excel-compatible format. The Print toolbar button prints the expanded data as a tabular report. The View All Temporary Licenses button displays detailed information about the temporary licenses.

Note: When an In Use item is expanded, the time format for the duration of use is d hh:mm. When a Valid Temporary Licenses item is expanded, the date format for start and expiration of the license is YYYY/MM/DD.
