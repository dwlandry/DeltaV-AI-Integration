Setting DCOM Services on the Non-DeltaV Node for Soft Phases

If your soft phase connects to other DCOM services, you might need to configure the DCOM launch and access permissions for those applications to allow the SOFTPHASEUSER launch and access rights. In addition, you will need to set the DCOM Identity property for the DeltaV Soft Phase Broker application.

  1. Launch dcomcnfg.
  2. Open the DCOM Config folder and select the DeltaV Soft Phase Broker.
  3. Right-click and select Properties.
  4. Select the Identity tab.
  5. Select the This User radio button.
  6. Set the user to SOFTPHASEUSER with the same password as found on the DeltaV node.
  7. Click OK until all dialogs are closed.
  8. Close the DCOM Config application.
