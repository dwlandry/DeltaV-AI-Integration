Scenario: Add SIS CSLS hardware that does not interact with existing hardware

In this scenario An existing system is being expanded. There is no interaction between the existing system and the new hardware. The strategy to implement this expansion is:
  1. Export the entire existing DeltaV system configuration from the production system.
  2. Ensure that the ProfessionalPLUS workstation of the virtual system matches that of the production system.
  3. Import the system configuration into the virtual system.
  4. Add new safety system hardware to the virtual system.
  5. Check out the logic.
  6. Disable all SIMULATE_IN parameters and turn off Debug mode for all modules.
  7. Record the module CRCs.
  8. Decommission and unassign all virtual hardware.
  9. Export the entire system configuration from the virtual system.
  10. Import the configuration into the production system.
  11. On the import dialog that asks "Would like to update the existing object in the database…" click No to All.
  12. Assign, commission, and download the physical hardware in the production system.
  13. Verify that module CRCs are the same as they were in the virtual system.

After the import the configuration of the original production system is unaffected because it was not changed.
