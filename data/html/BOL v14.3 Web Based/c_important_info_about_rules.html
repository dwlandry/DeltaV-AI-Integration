Important information about communication rules

While communication rules can be created without the applications running and communicating through the firewall, you will be unable to test and verify the rules which is an important step in the rules creation process. Therefore, it is recommended that the firewall is installed and the applications are communicating between the computers on either side of the firewall before creating rules. Ensure that any existing communications between external workstations and DeltaV workstations can be interrupted while the communications rules are created. If you cannot interrupt existing communications while creating communication rules, the firewall can be placed in Allow all mode. In Allow all mode applications can continue to communicate even if the rule is incorrect. It is possible to use data from the log to troubleshoot rules.

In Normal mode the firewall only allows communications when a rule allows the computers listed in the rule to communicate. If no rules are created in normal mode, no communications are allowed through the firewall. When creating rules in Normal mode, the behavior of the applications provides immediate feedback. That is the applications may not function at all or may not function properly if the communications rule does not have the correct ports and protocols configured.
