Installing the DeltaV I/O Interface

To install the I/O interface, install the I/O terminal blocks on the I/O interface carrier and connect field wiring to the I/O terminal blocks. Next, install the I/O cards on the I/O interface carrier. The steps for installing both simplex and redundant terminal blocks are discussed in the following procedures.

  • Installing an I/O Card
