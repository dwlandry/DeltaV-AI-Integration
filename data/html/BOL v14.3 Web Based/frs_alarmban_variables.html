Alarm banner variables

AlarmBan_glb contains Alarm Banner related definitions. The following table describes the variables declared in AlarmBan_glb. Changes to these global variables are made either in the User_Ref picture or the Layout file. Refer to Customizing the DeltaV Operate Environment. Changes to AlarmBan_glb global variables affect all alarm banners used in DeltaV Operate (including, ABDV1.grf, ABPOAR.grf, and ABDVP1.grf for common console systems).

Variables Declared in AlarmBan_glb

Variable

Description

gb_ab_ackAllVis

AckAll button on Alarm list is visible

gb_ab_ackOneVis

AckOne button on Alarm list is visible

gn_abADADisplay

Is 1 if the Primary Control picture should be viewed when an Alarm button is selected, else 0

gn_abADAIA

Is 1 if the Faceplate should be viewed when an Alarm button is selected, else 0

gn_abAlwaysOnTop

This variable is discontinued.

The alarm banner is programmatically set to always be on top.

gn_abAlwaysOnTop2

This variable is discontinued.

The alarm banner is programmatically set to always be on top for Monitor 2.

gn_abInfoBtnSelected

Indicates the Alarm Information button that is selected

gn_DeviceAlarmThreshold

The alarm banner displays device alarms above this number. The horn only sounds for new alarms above this number. Valid ranges are 4-14. The default is set to 7; that is, only annunciate device alarms greater than priority 7.

gn_ProcessAlarmThreshold

The alarm banner displays module alarms above this number. The horn only sounds for new alarms above this number. Valid ranges are 4-14. The default is set to 3; that is, only annunciate device alarms greater than priority 3.

gs_ab_current

= frsvariables.gs_std_path.CurrentValue & "AlarmBan"

gs_ab_current2

= frsvariables.gs_std_path.CurrentValue & "AlarmBn2"

gs_ab_help

= frsvariables.gs_hep_path.CurrentValue & "Albanhlp"

gs_ab_help2

= frsvariables.gs_hep_path.CurrentValue & "AlrmBhp2"

gs_ab_hornDisabled

= "hornDisabled"

gs_ab_hornEnabled

= "hornEnabled"

gs_ab_nodeStat

= frsvariables.gs_std_path.CurrentValue & "nodeStat"
