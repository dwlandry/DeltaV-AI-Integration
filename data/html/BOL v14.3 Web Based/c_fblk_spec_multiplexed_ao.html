Multiplexed Analog Output (FFMAO) function block

The Fieldbus Multiplexed Analog Output (FFMAO) function block makes its eight input parameters available to the I/O subsystem. The block has fault state features that enable it to hold last value or use a configured value after a delay time.

The Fieldbus Multiplexed Analog Output function block supports mode control.
