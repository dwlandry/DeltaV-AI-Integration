Bulk editing HART devices

One way to bulk edit HART objects is:

  1. Create a HART-capable card.

  2. Set one of the card's channels to be a HART channel

    The device tag changes to a HART device tag.

  3. From the HART device tag, open the Properties dialog.

  4. Fill in the fields with the information for a HART device.

  5. Use the sample format specification file or create your own and export the HART device.

  6. Edit the device in the bulk edit Excel add-in.

  7. Import the devices.

Note:

Even though the condition masks are exported, it is not practical to edit the masks using Bulk Edit because it is not easy to determine how the bits map to conditions. If you need to change condition masks create a new template after configuring the conditions as desired.

Controllers and HART enabled cards must be defined in the database before you can import HART device configurations. When you create a format specification file for a HART device you must select a subtype to specify whether you are editing SIS or non-SIS devices.
