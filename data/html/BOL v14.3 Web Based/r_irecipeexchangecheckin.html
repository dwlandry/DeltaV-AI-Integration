Public Sub

CheckOut (

ByVal rType As RecipeExchangeType,

ByVal recipeName As String,

ByVal bRecursive As Boolean

ByVal bstrComment As String,

ByVal bIgnoreCheckedOutUser As Boolean

)

This method checks the specified recipe into the Version Control database.

Return Values

S_OK - success

E_NOT_CONNECTED - Please call Connect First.

E_CHECKIN_FAILED - The recipe check in Failed.

E_VC_NOT_ENABLED - The version control feature not enabled.

E_INVALID_TYPE - The type is not supported.

else - failed

Memory Allocation

None

Visual Basic Usage Example

Private Sub Button1_Click()

  Dim myRecipeExchange As RecipeExchange
  Set myRecipeExchange = New RecipeExchange
  myRecipeExchange.Connect
  
  Dim itemType As tagRecipeExchangeType
  itemType = Procedure
  Dim itemName As String
  itemName = "OP_CS_ADDITION"
  Dim bRecursive As Boolean
  bRecursive = True
  Dim strComment As String
  strComment = " "
  Dim bIgnoreCheckedOutUser As Boolean
  bIgnoreCheckedOutUser = True
    
  Call myRecipeExchange.CheckIn(itemType,
                                itemName, 
                                bRecursive,
                                strComment,
                                bIgnoreCheckedOutUser)
  
  myRecipeExchange.Disconnect

End Sub

Parameter Name

Purpose

rType

The type of the specified recipe to be checked in.

recipeName

The name of the specified recipe to be checked in.

This name should include the path.

e.g., "operationFolder1/op1", "procedure1/formula1".

bRecursive

=True, recursive check in to the VCAT database.

=False, not recursive check in to the VCAT database.

strComment

The checked in comment.

bIgnoreCheckedOutUser

=True, check in the items checked out by others.

=False, do not check in the items checked out by others.
