Downloading Java software for use on a Management Station

Note:

Java is not an approved DeltaV application so the management station should be a non-DeltaV node on the network.

DeltaV workstations, including the Management station, should never be connected to the Internet. Java software is required for some Management station functions. To install Java software onto a Management station, you must first download the Java software from the Java website to a USB flash drive or other portable media on a computer that is not connected to the DeltaV Control Network and then install Java onto the Management station from the portable media.

  1. Go to the Java website.
  2. Navigate to the link to download Java for your operating system.
  3. Click the link and follow the prompts to save the Java software to your USB flash drive or other portable media.
  4. Scan your USB flash drive or other media with your anti-virus software. Be sure that you have the latest anti-virus updates.
  5. Connect the USB flash drive to the Management station's USB port and install Java from the USB flash drive or other media to the Management station.

    You may be prompted to install the MSN toolbar. Installing the MSN tool bar is not recommended.

The DeltaV Smart Switch must be configured with an IP address before the web browser on the Management station installed with Java can be connected to the switch.
