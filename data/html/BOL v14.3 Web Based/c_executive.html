DeltaV Batch Executive

The Batch Executive coordinates the execution of all recipes run within the DeltaV Batch subsystem. The Batch Executive handles:

  • Phase Requests

  • Phase Messaging

  • Hold Propagation

  • Process Inputs

  • Process Outputs

  • Process Reports

  • Batch Inputs

  • Batch Reporting

  • Alias Resolution

  • Report Archiving

  • Operator Prompts

The Batch Executive typically runs on the Application Station, but can run on any DeltaV workstation. You can enable up to four Batch Executives in a DeltaV system.
