Create virtual hardware from templates

After the virtual networks are defined, create the virtual machines (controllers, CSLSs, and so on) your system requires. Follow the instructions in the DeltaV Virtual Studio online help. For each virtual machine you create you specify the following:
  • The DeltaV Version or Release Independent.
  • The node type (SZ controller, CSLS, LSNB, etc.).
  • The node name.
  • The network assignments for the virtual machine.
CAUTION:

Allow the creation of each virtual machine to finish before creating another virtual machine. Create all virtual machines before assigning and downloading modules and testing configuration logic. Attempting to create multiple virtual machines simultaneously may cause virtual CSLSs into reduced operations mode.

The DeltaV Virtual Studio online help for the dialog contains detailed information about creating virtual machines.
