Supply voltage (DeltaV RM100/RM104 switches)

The supply voltage is electrically isolated from the housing.

  • Use only undamaged parts.
  • The device does not contain any service components. Internal fuses are only triggered if there is a fault in the device. If the device is not functioning correctly, or if it is damaged, switch off the voltage supply and return the device to the plant for inspection.
  • Only switch on the device when the housing is closed.
  • Only use connection cables that are permitted for the specified temperature range.
  • Relevant for North America:
    • Only use copper wire/conductors of class 1, 60/75°C or 75°C.
    • Only connect a supply voltage that corresponds to the type plate of your device.
    • Install an input fuse in the ungrounded voltage cables for every voltage supply connection. For the AC input of the AC/DC power units, use a nominal rating of 3 A, characteristic B.
  • Make sure that the disconnecting device is easily accessible so that the RM100 device can be disconnected from the mains voltage. If you disconnect the device from the mains voltage using either the plug in the socket or an on/off switch, it must be easily accessible.
Note: For devices with redundant voltage supply, both non-heating appliance plugs must be pulled to disconnect the device from the mains voltage.
