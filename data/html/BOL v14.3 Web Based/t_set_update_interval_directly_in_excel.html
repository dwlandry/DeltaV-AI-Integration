Set the update interval directly in Excel

  1. Select the cell where you want to store and display the update interval.
  2. Select the Formulas tab.
  3. In the Defined Names group, click Define Name and then select Name > Define Name ...
  4. Type DVUpdateInterval.
  5. Select the scope (workbook or a worksheet) and click OK.
  6. Enter the update interval in the cell.
    Note: To determine whether an update interval named range has already been defined, select the Home tab and, in the Editing group, click Find & Select > Go To. Then select DVUpdateInterval.
