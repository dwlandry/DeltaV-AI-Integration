ByVal bIsAutoRemove As Boolean,)

This event is fired whenever a campaign's execution mode changes. Note that a campaign can either be in manual or one of the automatic modes. It cannot be in both manual and any of the automatic modes. Also, auto-start implies auto-release.

Return Values

none

Memory Allocation

none

Visual Basic Usage Example

Private Sub DVBCMClient1_OnCampaignExecutionModeChanged(ByVal _
        bstrCampaignID As String, ByVal bIsManual As Boolean, _
        ByVal bIsAutoRelease As Boolean, ByVal bIsAutoStart As Boolean, _
        ByVal bIsAutoRemove As Boolean)
    Call TellUserAboutNewExecutionMode(bstrCampaignID)
End Sub

Parameter Name

Purpose

bstrCampaignID

The unique Campaign ID of the campaign that changed.

bIsManual

True if the campaign is in manual.

bIsAutoRelease

True if the campaign is in auto-release.

bIsAutoStart

True if the campaign is in auto-start.

bIsAutoRemove

True if the campaign has AutoRemove enabled for the AutoRelease and AutoStart Modes.
