Supported card and device types

This add-in supports configuration of all card and device types in this release of DeltaV software except the following:

  • DeviceNet Devices

  • Remote I/O Zone 1
  • Remote I/O Zone 2
Note:

The XML generated by SmartPlant Instrumentation does not support the following types of objects:

  • SIS Logic Solver Cards

  • ASi-bus devices, DeviceNet devices, Profibus devices, and Serial devices.
