Class-based equipment

The ability to create class-based equipment allows you to create reusable and maintainable equipment. If your plant has multiple, similar units, you can save configuration effort by implementing a class-based design. In the DeltaV system, process cells, equipment trains, units, control modules. equipment modules, and phases are defined at both the class level and the instance (individual) level. The class level defines common properties that apply to all instances of that equipment entity. The instance level defines information that ties the equipment to the physical equipment.

This usage of the same type occurs at several different levels. For example, a reactor (equipment module) can have several inlet valves (control module) that are of the same type (control module class) with control strategies that are also of the same type (phase class). At a higher level, a part of the plant can have several reactors (equipment module class) of the same type (unit class).  A plant can have several regions (as in process cells) where batch processes are carried out in a similar way (process cell class).

Note:

Areas are not class-based objects.

When the class concept is used for equipment definition, recipes are created that work on any equipment of the same class.

Instances - When an item (or object) is created using a class definition, that item is referred to as an instance of the class. Also, the item is said to be instantiated from the class.

DeltaV Batch uses this class concept to achieve efficient configuration where equipment of the same type is used at these levels. This first task of configuration is to define classes as follows:

  • Process cell classes, from which process cells are created.

  • Equipment train classes, from which equipment trains are created.

  • Unit classes, from which unit modules (or units) are created. Unit classes can contain equipment modules, control modules. Additionally, phase classes are assigned to unit classes.

  • Phase classes, from which unit phases or phase logic modules are created.

  • Control module classes, from which control modules are created. Control module classes can contain other control modules (derived from a class or not).

  • Equipment module classes, from which equipment modules are created. Equipment module classes can contain control modules (derived from a class), and other equipment modules (derived from equipment module classes).

Categories - The DeltaV Explorer allows you to divide your class definitions into categories. The strategy or concept used to define these categories is at the discretion of the user and does not effect the control strategy.
