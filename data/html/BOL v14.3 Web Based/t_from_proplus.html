From the ProfessionalPLUS workstation

To set up the SOA Gateway you must first configure the application station that is going to be designated as the gateway:

  1. Open DeltaV Explorer on the DeltaV system's ProfessionalPLUS workstation.
  2. If you need to create an application station to use as the gateway, select Control Network, and then select New > Application station from the context menu.
  3. In the Properties dialog, name the application station and select other options as desired, and then click OK.
  4. Select Physical Network, and then select Properties from the context menu. 
  5. In the Properties dialog, select the Gateway tab. 
  6. Browse to or enter the name of the application station you want to be the gateway, and then click OK.
  7. Select File > Export > Workstation Configuration.
  8. Save the workstation configuration file.
