DARU (Display Alarm Roll-up) object

The DARU object provides functions related to accessing information about alarms related to displays. The DARU object accesses this information through the a module's primary control display. The following DARU object functions are supported in DeltaV Live graphics expressions and scripting. See the subtopics under the DARU object for more details about each function.
Functions for the DARU object
Function Description Syntax
ActiveAlarms() Returns the count of active alarms that are associated with the designated display and, optionally, within the specified priority level range. DARU.ActiveAlarms(DisplayName, ChildDisplays, MinPriority, MaxPriority)
SuppressedAlarms() Returns the count of suppressed alarms that are associated with the designated display and within the specified priority level range. DARU.SuppressedAlarms(DisplayName, ChildDisplays, MinPriority, MaxPriority)
TopAlarmPriority() Returns the priority level of the top active or unacknowledged alarms that are associated with the designated display. DARU.TopAlarmPriority(DisplayName, ChildDisplays)
TopAlarmState() Returns the alarm state (as a number) of the top active or unacknowledged alarms that are associated with the designated display. DARU.TopAlarmState(DisplayName, ChildDisplays)
UnackedAlarms() Returns the count of unacknowledged alarms that are associated with the designated display and within the specified priority level range. DARU.UnackedAlarms(DisplayName, ChildDisplays, MinPriority, MaxPriority)
