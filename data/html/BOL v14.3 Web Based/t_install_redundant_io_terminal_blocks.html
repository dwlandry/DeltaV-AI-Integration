Install redundant I/O terminal blocks

The DeltaV system supports redundant Analog Input, Analog Output, Discrete, H1, and Interface terminal blocks. (Follow the Related information links for specifications.)

  1. Make sure that 24 VDC field power is provided to the carrier.
  2. Check the key settings on the corresponding Series 2 cards and set the keys on the terminal block to match.
  3. Locate the assigned slot location on the I/O interface carrier. Remember that the lower slot number must be odd, and the upper slot number must be the next higher even number. Place the tabs on the back of the redundant terminal block through the slots on the carrier and push the terminal block up to lock it into place.
  4. Connect the field wiring for the redundant terminal blocks. as shown in the Series 2 card wiring diagrams and redundant terminal block figures.
