Designing SIS modules

There are several things to consider when you design your SIS modules:

  • You are limited to four modules per SLS 1508 Logic Solvers or 16 per CSLS.

  • Keep related Safety Instrumented Functions (SIF) together.

  • You can create multiple alarm groups within a module and assign related function blocks to the same alarm group.

  • If possible, confine all the logic for each safety strategy in the modules in one Logic Solver. If the logic is spread across multiple Logic Solvers, the probability of failure becomes greater, and in some cases, system response time increases.

DeltaV SIS module naming rules are identical to naming conventions for non-SIS modules. Logic Solvers, SIS modules, other DeltaV modules, and DeltaV controllers must have unique names.
