AdviseAlerts

SLS

SLS_NAME/ADVISE_ALERTS

Advisory alert status of the logic solver, combination of both cards when redundant

AdviseAlerts condition text

Condition Text in AdviseAlerts

Meaning

Action

SISNet High Error Rate

High peer bus error rate detected by MP1 or MP2.

Can be due to an environmental specification being exceeded. Contact technical support if the condition persists.

I/O Processor Communication Error

MP2 sees a high percentage error rate in communications with the I/O processor.

Can be due to an environmental specification being exceeded. Contact technical support if the condition persists.

Non-volatile Memory Alert

Non-volatile Memory availability for parameter change records is low or exhausted.

Use DeltaV Explorer to upload recorded parameter changes for the logic solver, then re-download.

High Railbus Error Rate

MP1 sees a high percentage error rate in communications with the controller.

Can be due to an environmental specification being exceeded. Contact technical support if the condition persists.

High Redundancy Link Error Rate

MP1 sees a high percentage communications error rate on the redundancy link.

Can be due to an environmental specification being exceeded. Contact technical support if the condition persists.

I/O Processor Integrity Error

The I/O Processor is reporting a calibration or self-test error.

Check the value of IO_DEV_STATUS. If an incomplete self-test error persists, contact tech support. A calibration issue requires a hardware return.

Self-Test Incomplete

A periodic memory test did not complete in the allotted time.

Check the value of DIAG_STATUS and IO_DEV_STATUS to determine if the issue is with the main processors or I/O processor. Contact tech support if the issue persists or repeats.

Configuration Mismatch Between Logic Solver and Controller

Controller sees mismatch between configured and reported DEV_CRC.

If redundant, do a switchover of the logic solver. If the condition does not clear or the logic solver is simplex, download the logic solver.

Internal Communications Error

There is a high percentage error rate in communications between the main processors.

Can be due to an environmental specification being exceeded. Contact technical support if the condition persists.

Non-Critical Mismatch Between Main Processor Data

The main processors have determined a mismatch in dynamic data other than outputs and secure parameter values.

The logic solver will still be able to respond to a demand if this condition is active. If the condition persists, do a switchover of the logic solver or download it. Contact technical support if the condition does not clear.

Proof Test Reminder is Active

The number of days since the last proof test is approaching the required proof test interval.

If an automatic proof test has been configured, this alert indicates the test will begin in five minutes. Otherwise, a manual test should be scheduled.

Proof Test is Overdue

The number of days since the last proof test has exceeded the required proof test interval.

Perform a manual proof test.

CPU Free Time Low < 20%

The idle time on one or both of the main processors is less than 20% of the total task time.

Change to a slower logic solver scan rate and re-download.

Task Checkpoint Alarm

A non-critical task has not completed properly in one of the subsystems.

Contact tech support if this condition repeats.
