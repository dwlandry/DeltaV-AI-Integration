Ratio function block modes

The Ratio function block supports multiple modes:

  • Out of Service (OOS)

  • Initializing Manual (IMan)

  • Local Override (LO)

  • Manual (Man)

  • Automatic (Auto)

  • Cascade (Cas)

  • Remote Cascade (RCas)

You can configure the Man, Auto, Cas, and OOS modes as permitted modes for operator entry.
