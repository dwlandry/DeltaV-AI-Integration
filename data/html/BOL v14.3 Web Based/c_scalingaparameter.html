Scaling a parameter

In addition to entering information about the parameter, you also have the option of making it scalable. By scaling the value of a parameter, you make the recipe more flexible and allow varied amounts of your product to be manufactured.

When you enable scaling it allows the operator to scale the batch by a specified percentage at run-time. This percentage is then applied to all parameters that have scaling enabled. If you plan to scale batches, enable scaling for those parameters that need to be scaled. Typically, parameters that specify ingredient amounts should have scaling enabled. For example, if the operator sets the batch scaling percentage to 50 percent, all parameters representing ingredient amounts are cut in half. This retains the correct ratio of all ingredients for the recipe. However, it retains the other parameter values, such as mixing time, which do not have scaling enabled.

Note:

When scaling an integer parameter, a rounding effect is seen on the scaled value.

Parameter Scaling Enabled

When deferring parameters, the parameter to which you are deferring sets the value, including applying any scaling, if enabled.  For example, if the original parameter is not scalable, but the parameter to which it is deferred is scalable, the value used is the scaled value. Conversely, if the original parameter is scalable but the parameter to which it is deferred is not scalable, the value used is not scaled.  As a result, any parameter that is deferred and scalable most likely should be deferred to a parameter that is scalable.

Operator parameters, when deferred from the phase level, prompt with the scaled value. If the scaled value puts the parameter out of range, the prompt contains the low or high limit; whichever limit the value exceeded (that is, the low limit value is used if the scaling places the parameter below the low limit. The high limit value is used if the scaling places the parameter above the high limit, which is only possible with negative values).   

Note:

When scaling causes a parameter to be outside of the parameter's range, the batch will not load (goes to Load_Failed).
