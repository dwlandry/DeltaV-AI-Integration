Alarms syntax table

Valid Field Values for alarms
Field Valid Values Required for Import
module_name Module name. As many as 16 characters. The string must contain one letter and can include the following: $, -, _. Yes
module_type A string containing any keyboard characters. No
module_subtype An existing module subtype. Yes1
area Any valid area name. If the area does not exist or is not specified, the module is imported into AREA_A. No2
alarm_name The name of the alarm. Yes
alarm_type Any valid alarm type. No
pri Alarm priority No
enab Alarm enabled? T or F. No
inv Alarm inverted? T or F. No
alarm_attr The parameter that the alarm monitors. No
msg_param1 Alarm message parameter 1 No
msg_param2 Alarm message parameter 2 No
suppress_timeout Alarm shelving timeout No
functional_classification An integer from 0 to 10. No
alarm_help_enabled DeltaV alarm lists indicate help is available for view using the icon. T or F. No
alarm_description User-configured alarm description. As many as 255 characters (approximately the first 36 characters are visible in the DeltaV alarm banner). No
time_to_respond An integer from 0 to 255. Indicates the number of minutes allocated for an operator response. 255 indicates there is no defined response time. No
consequence_of_inaction An integer from 0 to 255. No
user_help_text1 A string containing up to 500 unicode compliant text characters. No
user_help_text2 A string containing up to 500 unicode compliant text characters. No
user_help_text3 A string containing up to 500 unicode compliant text characters. No
1

This field is required. If you do not provide this field, the system imports an empty module with default parameters. The name in this field must match the name of the module template that the structure of the new module is based on.

2

Any valid area name. If the area does not exist or is not specified, the module is imported into AREA_A.
