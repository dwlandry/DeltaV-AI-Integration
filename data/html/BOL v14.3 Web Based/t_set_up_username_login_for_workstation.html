Set up Username/Password logon for an OPC UA workstation server

In order for Username/Password logon authentication to work on a DeltaV workstation server, you must trust the OPC UA client certificate.

  1. Go to Start > DeltaV Engineering > User Manager.
  2. In User Manager > File > New > User.
  3. Select OPC UA User.
  4. Enter a user name. You are defining the name at this point. This is not an existing name.
  5. Enter a password.
  6. Click OK. The software displays the user name you created. The software displays a message asking you to perform a full download and log on again.
  7. Click OK.
  8. Using DeltaV Explorer, download the ProfessionalPLUS workstation.
  9. Using DeltaV Explorer, click the OPC UA Server and right-click Properties.
  10. Click Username/Password Logon.
  11. Click Set Users. The software displays the Set Users dialog.
  12. Select the user name you created from the drop-down list.
  13. Click Add.
  14. Click OK.
  15. Click OK the OPC UA Server dialog.
  16. Download the workstation’s OPC UA subsytem.
  17. Select the OPC UA client physical device (PDT) and right click Properties.
  18. Click the Primary tab.
  19. In the Authentication section, select Username from the drop down list.
  20. Enter the username and password you created previously.
  21. Download the physical device.
  22. Test the OPC UA client-side communications.
