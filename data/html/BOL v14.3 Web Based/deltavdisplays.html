Creating group displays

The ModGrp dynamo set in DeltaV Operate contains dynamos that create group displays. You can arrange instances of these short, wide dynamos on a picture to present data from multiple modules in a columnar, spreadsheet-like format. Use one dynamo in the set as a header for the top of each spreadsheet-like group display. There is a module dynamo created from each of the four major module template types of the standard DeltaV library. There is also a dynamo that works for any control module. You can stack up to 20 instances of these dynamos on a single picture.

When you drag and drop a dynamo (other than the header dynamo) from the ModGrp set on a picture, enter the name of the module in the edit box. Arrange instances of the dynamos in a columnar format, leaving one or two pixels between them.

The following module information is common to all of the module dynamos in the ModGrp set:

  • Description - Displays up to 24 characters of the module's DESC property. You can open the faceplate, detail display, or primary control picture by clicking the description and then selecting the corresponding icon in the upper left of the picture (if the picture was created from the main template).

  • Tag - Displays up to 12 characters of the module's name. You can open the faceplate, detail display, or primary control picture for the module by clicking the tag and then selecting the corresponding icon in the upper left of the picture (if the picture was created from the main template).

  • ALARMS[1] - Displays the alarm word of the module's highest priority active alarm in its priority color. The word blinks if the alarm is unacknowledged. Whenever a blinking alarm word appears, a visible alarm Ack button is displayed to the left of the word. Clicking this button acknowledges only the alarm corresponding to the visible alarm's priority word. When all of the alarms in the module have been acknowledged, the Ack button disappears.

  • See Detail - A red check mark appears when the module's BAD_ACTIVE parameter is True. A blue check mark appears either when the module's ABNORM_ACTIVE parameter is True or when the module's alarm priority is adjusted (PRIAD>0). Only one check mark can appear for a module. The conditions are listed in decreasing priority. The check mark prompts you to open the module's detail display and get more information. If the module does not have a detail display configured, open the faceplate for additional information.

This module information is specific to the following dynamos:

  • Loop Dynamo

  • Motor and Valve Dynamo

  • Analog Input Dynamo

  • Discrete Input Dynamo

Loop Dynamo

The Loop dynamo applies to modules created from the PID_LOOP, CASCADE_MASTER, CASCADE_SLAVE, and PID_GAINSCHED module templates.

The PV column shows the value of the process variable in yellow with the number of decimal places as configured in PID1/PV_SCALE.DECPT.

The SP column shows the value of the setpoint in white with the number of decimal places as configured in PID1/PV_SCALE.DECPT. The SP field is available when the target mode is AUTO, MAN, or OOS.

Between the PV and SP columns is a vertical bar graph showing the PV in yellow on the left and the SP in white on the right. The bar graph shows the values in percent of scale (PID1/PV_SCALE).

The OUT column shows the value of the output in cyan with the number of decimal places as configured in PID1/OUT_SCALE.DECPT. The OUT field is available when the target mode is MAN or OOS.

The Mode column shows the PID block target mode in white and the actual mode in yellow. If the target or actual mode is not the configured normal mode, the target or actual mode is shown in a blue background. You can enter information into the target mode field by clicking on the target mode field and selecting the appropriate mode button.

In addition to the check marks common to all modules, the See Detail column has a blue check mark that appears when simulation is enabled in the PID block.

Motor and Valve Dynamo

The Motor and Valve dynamo applies to modules created from any of the motor or valve module templates in the standard DeltaV library.

The PV column shows the state name of DC1/PV_D in yellow.

The SP column shows the state name of DC1/SP_D in white. When the target mode is AUTO, you can enter information into the SP_D field by typing one of the SP_D named set state names.

The Mode column shows the DC block target mode in white and the actual mode in yellow. If the target or actual mode is not the configured normal mode, the target or actual mode is shown in a blue background. You can enter information into the target mode field by clicking on the target mode field and selecting the appropriate mode button.

In addition to the check marks common to all modules, the See Detail column has a red check mark that appears when an interlock condition is a bypassed and a blue check mark that appears when simulation is enabled in the DC block.

Analog Input Dynamo

The Analog Input dynamo applies to modules created from the ANALOG monitoring module template.

The PV column shows the value of the process variable in yellow with the number of decimal places as configured in AI1/OUT_SCALE.DECPT.

The Mode column shows the AI block target mode in white and the actual mode in yellow. If the target or actual mode is not the configured normal mode, the target or actual mode is shown in a blue background. You can select a new target mode by clicking on the target mode field and selecting the appropriate mode from the dialog box.

In addition to the check marks common to all modules, the See Detail column has a blue check mark that appears when simulation is enabled in the AI block.

Discrete Input Dynamo

The Discrete Input dynamo applies to modules created from the DISCRETE monitoring module template. When the dynamo is pasted on a picture, enter the PV_D zero-state and one-state words in addition to the module tag.

The PV column shows the value of DI1/PV_D using the state names defined when the dynamo was pasted (default is Off and On). The PV_D state name is shown in red if in the alarm state (that is, if PV_D has the same numeric value as DI1/DISC_LIM). Otherwise, it is shown in green.

The Mode column shows the DI block target mode in white and the actual mode in yellow. If the target or actual mode is not the configured normal mode, the target or actual mode is shown in a blue background.

In addition to the check marks common to all modules, the See Detail column has a blue check mark that appears when simulation is enabled in the DI block.
