Authorize recipes

Remember that a recipe can only be authorized when it is checked in to Version Control and that a recipe is authorized when it has all of its required approval signatures.

Recipes can be authorized from the DeltaV Explorer and the Recipe Studio applications. The steps are the same; the only difference is the access to the Recipe Authorization dialog. This topic documents the procedures from DeltaV Explorer. (To authorize a recipe from Recipe Studio, open the recipe and on the Home tab, in the Version Control group, click Authorization.

  1. Click Start > DeltaV Engineering > DeltaV Explorer.
  2. Select the recipe that you want to authorize, right-click, and select Version Control > Authorization to open the Recipe Authorization dialog.

  3. To add an approval signature, select the Signer Description for which you have the key, and then click the Approve button.
  4. Enter a comment, username, and password, and then click OK. The Status on the Recipe Authorization dialog changes to Approved, and the User, Comment, and Node columns are updated. Notice that a Version Control message appears indicating the signature status change.
  5. Have the other signers add their approval signatures until all approvals are in place.
  6. Click the Close button when all signatures are in place. The recipe is now considered authorized.
