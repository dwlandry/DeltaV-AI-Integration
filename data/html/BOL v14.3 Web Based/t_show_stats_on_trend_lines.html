Show statistics on a trend line

You can show statistical markers on the graph for selected trends. Available statistics for each trend include its minimum and maximum values, time-weighted average, and totalized value. The following steps explain how to show statistics for the minimum, maximum, and time-weighted average on the trend line.

  1. Click Chart > Configure Chart.
  2. In the Configure Chart tab, select the Show Statistics check box next to each parameter reference for which you want to show statistics. The trend's minimum value, maximum value, and time-weighted average are shown on the trend line.
  3. To modify which statistics are shown on a trend line, select a trend and click Details.
  4. Deselect the check box for any values (Min, Max, Time Average) you do not want to show on the trend line.
  5. If you want to show the totalized value on the trend line, select the Total check box.
    1. Enter the Multiplier and Engineering unit to use for the totalized value.
  6. Click OK.
