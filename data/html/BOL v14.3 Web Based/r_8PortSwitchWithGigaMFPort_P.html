8-Port 10/100Mbit Switch with 1 Gigabit Multi-Function Port

Item Specification
Model

Cisco 8-Port 10/100Mbit twisted pair (Catalyst 2960-8TC-L)1

Type
  • 8, 10/100Mbit twisted pair ports
  • 1, gigabit multi-function port that can be used as either a 10/100/1000Mbit twisted pair port or a SFP-based port.
Note: Either the twisted pair port or the SFP-based port can be used. Both ports cannot be used at the same time.
