Smart HART Discrete Input function block I/O selection

When you configure the Smart HART Discrete Input function block, you select the I/O channel associated with the discrete measurement by configuring the Device Signal Tag (DST) of the IO_IN parameter to one of the Smart HART Discrete input variables as shown below. Note that HART_DV_DIn can only be bound to the IO_IN parameter of the SHDI block.

SHDI variables that can be bound to IO_IN:
  • HART_DV_DI0
  • HART_DV_DI1
  • HART_DV_DI2
  • HART_DV_DI3
Note:

SIMULATE_IN_D is a STATE value from the list of named set codes for SHDI and SHDO blocks.
