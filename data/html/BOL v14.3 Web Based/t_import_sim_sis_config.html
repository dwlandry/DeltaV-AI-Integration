Import the simulated SLS 1508 SIS configuration

On the real system:

  1. Create controller placeholders if they do not already exist.
  2. Create logic solver cards in the correct place in the controllers if the cards do not already exist.
  3. Import the SIS Network subsystem you exported from the simulation system (default export file name is SIS Network.fhx). 

    Areas and SIS modules are created as required and the modules are assigned to logic solvers.

  4. Commission controllers if they are not already commissioned.
  5. Download the controllers.
  6. Commission logic solvers.
  7. Download the logic solvers.

    The DownloadProgress.log file includes the message that the logic solver download was different from the last download.

  8. Record SIS-related CRCs and verify they are identical to the CRCs recorded in the simulation system.
  9. Perform a functional test on the real system.
Note:

An explanation of Functional Testing is beyond the scope of this topic. Functional Testing is covered in the DeltaV SIS Safety Manual.
