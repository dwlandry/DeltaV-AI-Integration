Recipe contents

The Recipe Studio builds all master recipes used in batch production. Master recipes that have been assigned to a Batch Executive are available to operators for production.

Each recipe, regardless of its type, consists of the following five parts that when combined together provide all of the information needed to produce the batch product:

  • Header - contains all administrative information for a recipe, including the name, version number, author, issue date, and the status.

The DeltaV system maintains administrative information, including the recipe and product names, the author's ID, update date, and the default batch size.

  • Formula - contains a list of process parameters, such as mixing time or temperature. In the DeltaV system, each parameter is defined and then is associated with a specific piece of equipment (unit) and a phase. This is done through either the DeltaV Explorer or Recipe Studio.

  • Equipment Requirements - defines a list of the equipment required to produce a batch product. In the site and general recipes, this list is a general guideline. In the DeltaV system, the master recipe contains a list of the equipment that can produce the batch product. The control recipe, created at run time, defines the specific equipment used to produce the batch.

  • Procedure - defines the process strategy. General and site recipes include procedures as shown in the Process Model section. Master and control recipe procedures use the structure defined in the Procedure Control Model section.

A DeltaV system procedure defines the unit procedures, operations, and phases to be executed on the equipment specified in the recipe's equipment requirements. In the DeltaV system, each level of the procedure is considered a recipe, allowing you to reuse unit operations and in multiple procedures. The DeltaV system also lets you create class-based recipes that you can execute on any unit listed in the equipment requirements.
