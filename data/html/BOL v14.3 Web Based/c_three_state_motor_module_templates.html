Three-state motor module templates

This category includes templates for forward/reversing and fast/slow motors that have two latching discrete outputs or three momentary discrete outputs. There are variations of each type for motors with and without interlock conditions. If you are not familiar with the motor control module templates in the Library, read Two-state motor module templates before proceeding.

Quick Config parameters for the Three-State Motors module templates

Parameter

Description

IO_IN_1

An I/O Reference parameter that configures the DST for the Forward or Fast running status from the motor starter.

IO_IN_2

An I/O Reference parameter that configures the DST for the Reverse or Slow running status from the motor starter.

IO_OUT_1

An I/O Reference parameter that configures the DST for the latching FORWARD or FAST output to the motor starter (or the momentary STOP output when the module has momentary outputs).

IO_OUT_2

An I/O Reference parameter that configures the DST for the latching REVERSE or SLOW output to the motor starter (or momentary FORWARD or FAST output when the module has momentary outputs).

IO_OUT_3

An I/O Reference parameter that configures the DST for the momentary REVERSE or SLOW output to the motor starter (not applicable when the module has latching outputs).

CFM_ACT1_TIME

The amount of time in seconds for the motor to confirm that it is running Forward or Fast following a command to the Forward or Fast state. If the motor does not confirm within this time, a fail condition occurs. The default is 5 seconds.

CFM_ACT2_TIME

The amount of time in seconds for the motor to confirm that it is running Reverse or Slow following a command to the Reverse or Slow state. If the motor does not confirm within this time, a fail condition occurs. The default is 5 seconds.

CFM_PASS_TIME

The amount of time in seconds for the motor to confirm that it has stopped following a command to Stop. If the motor does not stop within this time, a fail condition occurs. The default is 5 seconds.

DEVICE_OPTS

Configuration options for the Device Control block. The option that defaults to enabled for modules without interlock conditions is SP Track. The options that default to enabled for modules with interlock conditions are SP Track, Permissive, and Interlock. Passive on Active Timeout is enabled for the modules with latching outputs. Device options that are not enabled as a default, but are applicable to three-state motors, include Trip and Reset Required.

RESTART_TIME

A Quick Config parameter in the Forward/Reversing motor module templates. When SP_D in the Device Control block is changed from Forward to Reverse or from Reverse to Forward, OUT_D is driven to Stop for this period of time, in seconds. The default is 5 seconds.
