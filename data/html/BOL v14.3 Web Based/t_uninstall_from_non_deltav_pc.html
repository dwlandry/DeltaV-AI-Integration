Uninstall the SOA server from a non-DeltaV computer

To uninstall the SOA server from a non-DeltaV computer, follow these steps.

Note:

You do not need to use this procedure on a DeltaV computer. The DeltaV uninstall will remove the Secure SOA server from the DeltaV computer.

  1. Navigate to Programs and Features.
  2. Select Secure SOA Server from the list.
  3. Click Change/Remove.
  4. Follow any dialogs that are displayed.

The DeltaV system and the web services (Campaign Manager Web Service, Recipe Exchange Web Service, and Monitor Service) will not be able to communicate through this server when the SOA server software is uninstalled.
