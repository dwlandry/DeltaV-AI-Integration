Display sets overview

A display set defines a collection of displays that match the responsibilities of the operators assigned to the DeltaV Live-enabled Operator Station on which that display set will be available. A display set also provides built-in navigation tools that help operators efficiently navigate their displays. These navigation tools, which are accessible through a layout's navigation bar, provide automatic routing and coordination for displays, according to their position in the hierarchy.

Hierarchical and non-hierarchical displays

A display set can contain zero or more hierarchical displays. A display may belong to multiple display sets but may be included only once in a single display set. A display that belongs to multiple display sets can be placed at a different level in each display set's hierarchy. Additionally, while a hierarchy can be at most only four levels deep, you can have multiple displays at one level within a hierarchy, or you can have multiple hierarchies within a display set. (Note that a hierarchy can have only one overview display.) Multiple hierarchies can be helpful, for example, if you want to build a single plant-wide display set that contains a different hierarchy for each process area. Each hierarchy would then contain an overview display and sub-hierarchy, but all would be contained within one display set.

Important: Be aware, however, that the relative placement of displays at the same level is significant, as their position in the hierarchy determines the positioning of display selection buttons in a navigation bar.

You can also add placeholders to a display set for displays that have not yet been created. Rename the display placeholder to match the name of the future display and then publish the display set. Once you create the actual display and publish it, the display set automatically picks up the change in DeltaV Live and starts using the new display. The display set containing the placeholder does not need to be republished.

Display sets may also contain 0 or more non-hierarchical displays. These displays do not appear in the navigation bar. If a navigation bar is configured in the layout to show display call-up buttons, non-hierarchical displays appear as a drop-down list from which to select the displays available on that workstation. You can also use the search tool to find and open non-hierarchical displays. Non-hierarchical displays open either in display frames designated for other displays or as popup windows (if no display frame is configured for other displays).

Using display sets in DeltaV Live

A display set becomes available on a DeltaV Live-enabled Operator Station when it is assigned to that workstation through Workstation Management. You can assign more than one display set to a workstation, but whether you have one or multiple display sets, you must select one display set as the initial display set to use when DeltaV Live opens. Only one display set at a time can be active on a workstation, but operators have the ability to switch between the display sets available on their workstations.

When a new instance of DeltaV Live starts, the initial display set used is determined by the following rules:
  • If no DeltaV user is currently logged on, the initial display set configured for that DeltaV Live workstation is used.
    • If no display set is configured as the initial display set, the first one in the list is used.
  • If the current DeltaV user has not previously switched display sets on this workstation or session, the initial display set configured for that DeltaV Live workstation is used.
  • If the current DeltaV user has switched display sets on this workstation or session, and the display set last selected by the current user is still available, that display set is used.
  • If the current DeltaV user has switched display sets on this workstation or session, and the display set last selected by the current user is no longer available, the current initial display set is used.
Sometimes a workstation does not have a display set assigned to it or the active display set does not contain any hierarchical displays. When a workstation has no display set assigned to it, the following scenarios are true:
  • All published displays are available for use on that workstation (through the search tool).
  • Navigation bar tools and automatic display coordination are unavailable (because these are determined by displays' hierarchical positions in a display set).
  • All available displays open as popup windows.

When a workstation has an active display set but the display set contains only non-hierarchical displays, all non-hierarchical displays open in the display frame designated for Other Displays. If no display frame is configured for other displays, non-hierarchical displays open as pop-up windows.

Creating and configuring display sets

A display set is created, configured, and managed in Graphics Studio, then published and assigned for use on DeltaV Live-enabled Operator Stations and remote client sessions. After creating a new display set, you can add displays to it by dragging them from the Graphics Explorer pane and dropping them in the desired position of the Navigation Hierarchy, or you can drop them in the Non-hierarchical Displays pane. In the content pane, you can see a preview of what the display selection buttons will look like for hierarchical displays in DeltaV Live. In the Graphics Configuration pane, you can add a title or description for the display set.
