Special Items Palette

The Special Items palette helps you create algorithms.

Input Parameter — A value from another function block, a sequential function chart (SFC), or a field device supplied to a module for use in execution.

Output Parameter — A value calculated or triggered by the module and sent to other function blocks, SFCs, or field devices.

Internal Read Parameter — A parameter, normally used only within a module.

Internal Write Parameter — A parameter, normally used only within a module.

Custom Block — A tool that enables you to add embedded or linked composites, module blocks, function blocks, and extended function blocks to your diagram.

Physical Block — A tool that enables you to add a block that exists in a fieldbus device and automatically assign it to the device in one step.
