Export the equipment hierarchy

Equipment hierarchy information enables OSIsoft PI Server to store and display parameter values in the context of the DeltaV system equipment hierarchy.

To export equipment hierarchy information, use the File > Export > Equipment Hierarchy command in DeltaV Explorer on the ProfessionalPLUS workstation.

To export the equipment hierarchy, you must have the Can Configure key. For more information about manually exporting an equipment hierarchy, refer to the online help for DeltaV Explorer.
