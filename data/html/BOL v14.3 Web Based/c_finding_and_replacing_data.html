Finding and replacing data

The Find and Replace feature allows you to search for data throughout your plant according to the criteria you specify. It has the capability to search for any substrings of any of the following:
  • Display references
  • Module/device/node references
  • DeltaV Live writeable variable references
  • Content language string literals
  • Language neutral string literals
  • Module/device/node names
  • Graphics expressions
  • Other scripting

By default, Find and Replace searches the subset of selected items in the currently active configuration (a display or layout, for example) or in the subset of selected configurations. Alternatively, you can choose to search in one or more selected configurations, in only the active (current) configuration, or in all similar configurations.

After specifying the string to search for, you can also limit the search to match the same letter case, to find only the whole word, or to match a pattern you define using regular expression functionality. Additionally, you can also specify a new string to replace the searched for string.

When a search is complete, any strings found matching the specified criteria are listed in the dialog. From this list, you can select a string and click Replace to replace it with the string specified in the Replace with field. Or, you can double-click an item in the list to open its containing configuration (if not already open) and activate the property field where this string resides.

What Find and Replace does not do

This feature does not search the following property types:
  • Arrow
  • Boolean Literal
  • Color Literal
  • Degree Literal
  • Datalink
  • Double precision float
  • Font Literal
  • Graphics Studio Interaction Level
  • Horizontal Alignment
  • Horizontal Position
  • Integer Literal
  • Line Style
  • Measurement Literal
  • Percent Literal
  • Size (Small/Medium/Large)
  • Time Span
  • Vertical Alignment
  • Vertical Position
  • Z-ordering

You can, however, multi-select elements on the Content pane and bulk-edit the desired properties in the Graphics Configuration pane.

The Find and Replace feature also does not search references to library configurations, such as functions or standards.

Finding and replacing data within the Script Assistant

The Script Assistant contains its own Find and Replace feature that searches and replaces data only in scripts. It searches all unhidden strings and headers found within the active tab. Headers, however, cannot be replaced using this feature.
