SIS composite strategy

There are several ways that composites help to create SIS modules. In addition to their manageability, composites can perform the following functions:

  • improve readability of a large SIS module by allowing you to group the elements into logical tasks

  • allow SIS logic to be reused

  • provide a mechanism to develop SIS logic segments one time, store them in the library, maintain them in a single location, and still use that logic in a number of different modules

In addition, SIS Composite Templates can be protected to prevent unauthorized modification after they are in use.
