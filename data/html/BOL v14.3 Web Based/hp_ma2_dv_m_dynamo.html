High Performance MA2_DV_M_ analog dynamo (HP_MA2_DV_M_)

This dynamo can be used for analog indication where deviation from SP is important and vertical space on the display is available. Used with PID loops and ALM function blocks.

The following elements are present on the dynamo:

  • Alarm box

  • Alarm icon

  • Display tag

  • Dynamo background

  • Engineering units descriptor

  • PV data field

  • PV-SP Deviation (comparison) bar graph

  • Abnormal status icon
