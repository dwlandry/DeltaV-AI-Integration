Uninstall a historian

If one of the following scenarios occurs, you may need to uninstall a historian and, in some cases, you may also need to uninstall DeltaV:

  • You need to reinstall the historian on a workstation
  • You decide to run a different historian on a workstation
  • You elect to use the workstation without a historian installed

Uninstall the DeltaV Continuous Historian, the Advanced Continuous Historian, or PI Server from an Application Station

There is no procedure required to uninstall the DeltaV Continuous Historian from an Application Station. However, if you decide to run the Advanced Continuous Historian or PI Server on the Application Station instead of the DeltaV Continuous Historian, you must uninstall and reinstall DeltaV.

If you need to uninstall the Advanced Continuous Historian from an Application Station, refer to the Uninstall the Advanced Continuous Historian topic for step-by-step instructions. After uninstalling the Advanced Continuous Historian, you must also uninstall DeltaV.

To uninstall PI Server from an Application Station, refer to the documentation from OSIsoft. After uninstalling PI Server, you must also uninstall DeltaV.

Uninstall the DeltaV Continuous Historian from a ProfessionalPLUS workstation or Operator Station

There is no procedure required to uninstall the DeltaV Continuous Historian from a ProfessionalPLUS workstation or Operator Station.

Uninstall PI Server from a non-DeltaV workstation

To uninstall PI Server from a non-DeltaV workstation, refer to the documentation from OSIsoft.
