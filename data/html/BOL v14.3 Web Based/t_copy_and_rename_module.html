Copy and rename a module

The tank process has a pump with a two-state (on or off) motor. The motor interlocks under certain conditions. In this procedure, you will use DeltaV Explorer to copy a module template from the Library to the TANK-101 area and rename it. Later, you will use Control Studio to modify the module. (Modifying includes specifying the conditions for the interlocks.)

  1. In DeltaV Explorer, open Library > Module Templates > Motors-2State, and select MTR-11_ILOCK.
  2. Drag the MTR-11_ILOCK module onto the TANK-101 plant area.
  3. Open TANK-101 and select MTR-11_ILOC_1. The name is highlighted.
  4. Click the module name a second time (or right-click, and then select Rename from the context menu).
  5. Enter the new name for the module: MTR-101. You now have a control module in your TANK-101 plant area.
  6. Click the Minimize button in the upper right corner to minimize DeltaV Explorer.
