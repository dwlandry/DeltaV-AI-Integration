Save a snapshot of the firewall

If Emerson support asks for a snapshot of the entire firewall setup, you can save it to disk as well. To save a snapshot to disk:

  1. Open the Management station's web browser and enter the firewall 's IP address, for example https://10.5.128.18:443.
  2. The Security Alert dialog opens. Read the information on this dialog and click Yes.
  3. The Connect to dialog opens. Enter admin as Username and the default password if these have not changed from the factory settings. Otherwise, enter your Username and Password and click OK.
  4. The firewall's Welcome page opens.
  5. Find the Support folder on the left side of the Welcome page and expand it.
  6. Select Snapshot under the Support folder.
  7. Click Download on the Support Snapshot page.
  8. A Download dialog opens. Click Save to save the file as snapshot[1].tar. This file can be sent to Emerson support for analysis.
