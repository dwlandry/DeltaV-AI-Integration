Install the EnTech Toolkit

After installing DeltaV, you can install one or more application modules from the EnTech Toolkit on any DeltaV workstation. To install an application module, complete the following steps:

  1. Insert DeltaV installation disk #1 in the drive.

    The DeltaV Install dialog appears.

    Note:

    If the Windows Autorun feature is disabled, preventing the DeltaV Install dialog from appearing when you insert the DeltaV installation disk #1 in the drive, run Autorun\DVAutorun.exe.

  2. Click the Other DeltaV Products button.
  3. Click the EnTech Toolkit button.
  4. Click the EnTech Collect, EnTech Tuner, or EnTech Analyse button for the application module you want to install.
    Important:

    Do not install the EnTech Toolkit License Manager program on a workstation within a DeltaV system. The License Manager program is only required to install and register licenses for the EnTech Toolkit on a non-DeltaV system.

  5. Accept the default for each dialog that appears during installation.
    Note:

    If you are prompted to restart your computer, select the Yes, I want to restart my computer now option, and then click the Finish button.

  6. Repeat the preceding steps for each application module from the EnTech Toolkit to be installed.

For additional information about using the EnTech Toolkit, see the application help for each application module and the documentation files listed in the following Start menu locations:

  • Start > EnTech Toolkit > Collect
  • Start > EnTech Toolkit > Tuner
  • Start > EnTech Toolkit > Analyse

Uninstall the EnTech Toolkit

Uninstall one or more application modules from the EnTech Toolkit using the following steps:

  1. Select Control Panel > Programs and Features.
  2. In the list of applications, select the module you want to uninstall.
    • Analyze
    • Collect
    • Tune
  3. Right click and select uninstall.
  4. If prompted that this will uninstall the application, click OK.
  5. Click Finish when the process completes.
  6. Continue uninstalling other EnTech modules.
  7. When done uninstalling, close Control Panel.
