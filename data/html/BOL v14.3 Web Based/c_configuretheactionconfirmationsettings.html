Configuring the action confirmation settings

Confirmation and verification preferences for Campaign Manager actions are configured in the Action Confirmation tab of the Campaign Manager's Properties dialog. Actions are those events that either an operator or administrator might perform from the Campaign Manager Operator Interface. For example, if you select the Confirm check box for the Start Batch option, when a user attempts to add a batch, a confirmation dialog box is displayed. The action will not be started until a valid user ID and password are entered.

The check boxes in Prompt column enable a prompt to the user for the action. For example, "Are you sure you want to start this batch?" is issued when the Start Batch button is selected if a prompt is enabled for Start Batch. No user ID or password is required for a prompt.

The check boxes in the Confirm column are used to determine if a confirmation dialog box is displayed for the user to confirm that the action should be performed.

The Verify column adds another level of verification to the selected command. If the Verify option is selected, a dialog is displayed for the user to verify that the action should be performed.

The Confirmer and Verifier can be the same person. The Electronic Signatures Properties dialog in the DeltaV Explorer is used to configure Confirmer and Verifier to be the same person. topic for more information.
