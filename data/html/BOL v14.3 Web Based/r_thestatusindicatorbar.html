The status indicator bar

The status indicator bar, located at the bottom right-hand corner of the Batch Operator Interface and DeltaV Operate Batch Controls windows, displays the recipe component for the current batch as well as the current status of the connected Batch Executive and that Executive's connection to DeltaV services, the Batch Recipe Simulator, and the DeltaV Batch SoftPhase Server. The last two panes are used to display the node name of the connected Batch Executive and the current time from the Batch Executive node. The color and text displayed in these panes varies depending on the status of the connection to the Batch Executive.

To the left of the Batch Executive node's pane are up to three panes that display the status of the connection between the Batch Executive and DeltaV Services (DELTAV), the Recipe Simulator (DVBSIM), and the Soft Phase Server (SoftPhase) if configured. The color of these panes varies depending on the connection status between the server and the Batch Executive:
