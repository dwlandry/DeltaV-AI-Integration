For other parts of the picture, use the dynamos in the following table and arrange them as shown in the earlier illustration of the process graphic. Be sure to read the table footnotes for the block valve and regulatory valve. The topic on creating a pump using a dynamo explains how to animate the color for the regulatory valve if you have forgotten how to do so.

Create a pump using a dynamo
1 In the Valve Dynamo dialog for the block valve, choose Animate Valve Color, and set two colors, as you did earlier for the Pump Dynamo.
2 In the Valve Dynamo dialog for the regulatory valve, choose Animate Valve Color. In the Color By dialog, choose Color by Current Value. Under the Color Threshold, select Range and set the colors as follows: 0-50 is red; 50-100 is green.
