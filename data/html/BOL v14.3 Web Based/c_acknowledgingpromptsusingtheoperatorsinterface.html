Acknowledging prompts using DeltaV Operate

The operator can acknowledge prompts when running the phase from DeltaV Operate either by using the DeltaV Batch Unacknowledged Prompts control or the unit phase's detail display (depending on the method used on the operator picture).

To acknowledge a prompt using the DeltaV Batch Unacknowledged Prompt control, select the prompt by double-clicking it. Respond to the prompt using the Acknowledge Prompt dialog.

Prompts involved in the same phase request are grouped together to make acknowledging large numbers of prompts easier. To acknowledge a group of prompts, select one of the prompts in the group and right-click. Select Acknowledge Group from the context menu. Enter the appropriate prompt responses on the Acknowledge Group Prompt dialog. Click Acknowledge Group. The entire request group is acknowledged with the values listed. 

To acknowledge only one request in the group you can

  • select one of the prompts and click the Acknowledge button

  • select one of the prompts and right click. Select Acknowledge from the context menu (instead of Acknowledge Group).

  • double click the prompt in the list.

Note:

The context menu must be enabled on the Operator Prompts control on your DeltaV Operate picture to display the right-click (context) menu.

DeltaV Operate Unacknowledged Prompts Dialogs for Batch

To acknowledge a prompt using the detail display for the phase, select the ACK button. This acknowledges the prompt and clears the value.

Note:

The ACK button is only available when the phase has External ownership and the Request register (REQUEST parameter) is greater than zero (0).
