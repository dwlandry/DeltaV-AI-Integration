Logic Solver Analog Voter function block parameters

The following table lists the system parameters for the function block:

LSAVTR Function Block System Parameters

Parameter

(Data Type)

Default Value

(Units)

Characteristics

Description

A_NUM_TO_TRIP

(8-bit unsigned integer)

0

NVM:

Preserved on Download

The actual number of votes needed to trip or pre-trip. This can differ from NUM_TO_TRIP if there are bypassed inputs and the BYPASS_OPTS option A maintenance bypass reduces the number to trip is selected.

AVTR_ALERTS

(Option bitstring)

None

NVM:

Preserved on Download

Parameter containing the runtime values of alarm conditions set by the block (inactive = 0, active = 1). The conditions are:

  • Trip Active 

  • Pre-Trip Active

  • Bypass Active 

  • Startup Override Active 

  • Deviation Limit Exceeded 

  • Expiration Reminder 

  • Bypassed Input Pre-Tripped 

  • Bypassed Input Tripped 

  • Input Bad 

  • Inhibited

For a description of the alerts and information on how to access them, refer to AVTR_ALERTS below this table.

BYPASSn

(Boolean)

False

Access:

Tuning (SLS 1508 and CSLS major revision 1)

Operating (CSLS major revision 2 or higher)

NVM:

Preserved on Download

If BYPASSn is True, INn is excluded from voting to trip and pre-trip.

BYPASS_OPTS

(Option bitstring)

None

Access:

Configurable, Tuning

NVM:

Restored on Restart

Configurable options for maintenance and startup bypass behavior. Options are kept in a bitstring internally. The options are:

  • A maintenance bypass reduces the number to trip

  • Multiple maintenance bypasses are allowed

  • Maintenance bypass timeout is for indication only

  • Startup bypass preset is allowed while active

  • Startup bypass expires upon stabilization

  • Reminder applies to startup bypass

  • Startup bypass duration is event based.

  • Bypass permit is not required to bypass

  • Bypass permit control should be visible in operator interface

BYPASS_PERMIT

(Boolean)

False

Access:

Tuning

NVM:

Preserved on Download

Must be True for any BYPASSn parameter to be True when the BYPASS_OPTS option  Bypass permit is not required to bypass is not selected. When this option is selected, the block ignores BYPASS_PERMIT.

BYPASS_TIMEOUT

(Floating point)

0

(Seconds)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The number of seconds any BYPASSn can be True before the block sets all BYPASSn parameters to False unless the BYPASS_OPTS option Maintenance bypass timeout is for indication only is selected. If that is true or if the value of BYPASS_TIMEOUT is 0.0, the block will not remove bypasses.

BYPASS_TIMER

(Floating point)

0

(Seconds)

Access:

Tuning

NVM:

Preserved on Download

Countdown timer for the bypass function in seconds.

BYPASS_TIMER_H

(Floating point)

0

(Hours)

NVM:

Tuning

Preserved on Download

Countdown timer for the bypass function in hours.

DELAY_TIMER

(Floating point)

0

(Seconds)

NVM:

Preserved on Download

Countdown timer for the TRIP_DELAY and NORMAL_DELAY parameters to determine if the output is tripped or normal.

DESCn

(String)

None

None

Configurable label for INn.

DETECT_TYPE

(Named Set)

Greater Than

Access:

Configurable

NVM:

Restored on Restart

Determines the type of trip and pre-trip limit, either Greater Than or Less Than TRIP_LIM.

DEV_HYS

(Floating point)

0

(Percent of scale)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The deadband in percent of IN_SCALE applied to the deviation limit for resetting the deviation condition in AVTR_ALERTS. Valid range is 0 to 50.

DEV_LIM

(Floating point)

0

(Engineering Units)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The maximum expected difference between the highest and lowest INn values. When the limit is exceeded, AVTR_ALERTS Deviation Limit Exceeded is set.

INn

(Floating point with status)

None

(Engineering Units)

Access:

Tuning

NVM:

Restored on Restart

Process value in engineering units typically from a single sensor. INn is extensible from 1 to 16. The default input count is 3.

IN_SCALE

(Scaling)

0.0 to 100.0

Access:

Configurable, Tuning

NVM:

Restored on Restart

Scaling parameter common to all inputs.

LOGIC_TYPE

(Named Set)

Negative

Access:

Configurable, Tuning (CSLS major revision 2 or higher)

Indicates whether the tripped state is TRUE (Positive) or FALSE (Negative).

Only CSLS major revision 2 or higher supports this parameter.

NORMAL_DELAY

(Floating point)

0

(Seconds)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The number of consecutive seconds before OUT_D or PRE_OUT_D changes to the normal operation value after the number of votes to trip falls below the number required to trip or pre-trip.

NUM_TO_TRIP

(8-bit unsigned integer)

2

Access:

Configurable, Tuning

NVM:

Restored on Restart

The configured number of votes needed to initiate a trip condition.

OUT_D

(Discrete with status)

0

NVM:

Preserved on Download

The output of the block, either Normal (1) or Tripped (0) as determined by the trip vote function.

OUT_D_NOBYPBASS

(8-bit unsigned integer)

0

NVM:

Preserved on Download

The value OUT_D would have if all BYPASSn parameters were False and a startup bypass were not active.

PRE_DELAY_TIMER

(Floating point)

0

(Seconds)

NVM:

Preserved on Download

Countdown timer for the TRIP_DELAY and NORMAL_DELAY parameters to determine if the output is pre-tripped or normal.

PRE_OUT_D

(Discrete with status)

0

NVM:

Preserved on Download

The output of the block, either Normal or Tripped as determined by the pre-trip vote function.

PRE_TRIP_LIM

(Floating point)

80

(Engineering Units)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The pre-trip limit value in engineering units compared to INn. PRE_TRIP_LIM is common to all inputs.

PRE_TRIP_STATUS

(Named Set)

Normal

NVM:

Preserved on Download

Indicates the status of the pre-trip vote and startup inhibit functions:

  • Normal

  • Pre-Tripped

  • Pre-Trip Inhibited

  • Voted to Pre-Trip - Delayed

  • Voted Normal - Delayed

PRE_VOTE_INn

(Boolean)

False

NVM:

Preserved on Download

The result of the pre-trip limit check for INn. True indicates a vote for a pre-tripped condition, which is typically used for alarming.

PRE_VOTES

(8-bit unsigned integer)

0

NVM:

Preserved on Download

The number of inputs that have voted to indicate pre-tripped. Bypassed inputs are not included in the total.

REMINDER_TIME

(Floating point)

0

(Seconds)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The configured amount of time an alarm is active prior to the timeout of a maintenance or startup bypass timer.

REPORT_OPTS

(Option bitstring)

None

Access:

Configurable, Tuning

NVM:

Restored on Restart

Configurable options for block reporting features.

  • Alarm conditions do not roll up to module level.

  • Event records are not generated.

These options apply only to block alarms and events and not user-defined module alarms.

STABLE_TIME

(Floating point)

0

(Seconds)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The time configured to allow for process stabilization during a startup bypass. This is the number of consecutive seconds without a vote to trip while the startup bypass is active. Optionally, the startup bypass expires when the actual stabilization time reaches the configured allowed time.

STABLE_TIMER

(Floating point)

0

(Seconds)

NVM:

Preserved on Download

The actual number of consecutive seconds without a vote to trip while the startup bypass is active.

STARTUP

(Boolean)

False

Access:

Tuning

NVM:

Preserved on Download

Inhibits trip detection during startups. On a rising edge of STARTUP, the block keeps OUT_D and PRE_OUT_D in the normal operating state for STARTUP_TIME seconds when the BYPASS_OPTS option Startup bypass duration is event based is not selected.

When the BYPASS_OPTS option Startup bypass duration is event based is selected, a startup bypass is active when STARTUP is True and inactive when STARTUP is False).

STARTUP_TIME

(Floating point)

0

(Seconds)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The number of seconds the startup inhibit function is in effect following a rising edge of STARTUP.

STARTUP_TIMER

(Floating point)

0

(Seconds)

Access:

Tuning

NVM:

Preserved on Download

Countdown timer for the startup inhibit function.

STATUS_OPT

(Option bitstring)

Always Use Value

Access:

Configurable, Tuning

NVM:

Restored on Restart

Determines the behavior when the status of any INn is Bad. Choices are:

  • Always Use Value

  • Will Not Vote if Bad

  • Vote to Trip if Bad.

TIME_TO_STABLE

(Floating point)

0

(Seconds)

NVM:

Preserved on Download

The total number of seconds during a startup bypass until the inputs became and remained stable.

TRIP_DELAY

(Floating point)

0

(Seconds)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The number of consecutive seconds with enough votes to trip or pre-trip before OUT_D or PRE_OUT_D changes to the trip state value.

TRIP_HYS

(Floating point)

0.5

(Percent of scale)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The deadband in percent of IN_SCALE applied to the trip limit for resetting a vote to trip or vote to pre-trip. Valid range is 0 to 50.

TRIP_INH_DELAY

28800

(Seconds)

Access:

Configurable, Tuning

NVM:

Restored on Restart

Determines the time at which TRIP_INH_TIMER causes the output to go to bad status and to the tripped value.

TRIP_INH_TIMER

0

(Seconds)

None

Starts counting when TRIP_STATUS goes to the Trip Inhibited state. This parameter causes the output to go to bad status and to the tripped value based on TRIP_INH_DELAY.

TRIP_LIM

(Floating point)

90

(Engineering Units)

Access:

Configurable, Tuning

NVM:

Restored on Restart

The limit value in engineering units used to compare to INn to determine whether the input has voted to trip. TRIP_LIM is common to all inputs.

TRIP_STATUS

(Named Set)

Normal

NVM:

Preserved on Download

Indicates the status of the trip vote and startup inhibit functions:

  • Normal

  • Tripped

  • Trip Inhibited

  • Voted to Trip - Delayed

  • Voted Normal - Delayed

  • Voter Inhibited

TRIP_VOTE_INn

(Boolean)

False

NVM:

Preserved on Download

A True value indicates INn is voting to trip.

TRIP_VOTES

(8-bit unsigned integer)

0

NVM:

Preserved on Download

The number of inputs that have voted to trip. Bypassed inputs are not included in the total.

AVTR_ALERTS

The following table shows the alerts that can appear for an LSAVTR block, an explanation of each alert, the bit position of each alert, and how to access the alert bit from DeltaV Operate.

Bit Value

Explanation

Bit Position

Access from DeltaV Operate

Trip Active

Inactive when OUT_D is in the normal operating state, active when OUT_D is in the trip state.

0

AVTR_ALERTS.F_CV[1]

Pre-Trip Active

Inactive when PRE_OUT_D is in the normal operating state, active when PRE_OUT_D is in the trip state.

1

AVTR_ALERTS.F_CV[2]

Bypass Active

Active when there is a maintenance bypass on any input (any BYPASSn parameter is True).

2

AVTR_ALERTS.F_CV[3]

Startup Override Active

Active whenever the startup bypass is active.

3

AVTR_ALERTS.F_CV[4]

Deviation Limit Exceeded

Active when the difference between the highest and lowest non-bypassed INn value exceeds DEV_LIM. Forced inactive when DEV_LIM is 0.0.

4

AVTR_ALERTS.F_CV[5]

Expiration Reminder

Active when either a maintenance bypass or a startup bypass is about to expire.

5

AVTR_ALERTS.F_CV[6]

Bypassed Input Pre-Tripped

Active if one or more bypassed inputs have exceeded the pre-trip limit.

6

AVTR_ALERTS.F_CV[7]

Bypassed Input Tripped

Active if one or more bypassed inputs have exceeded the trip limit.

7

AVTR_ALERTS.F_CV[8]

Input Bad

Active if any input has bad status.

8

AVTR_ALERTS.F_CV[9]

Inhibited

Active when TRIP_STATUS is Voter Inhibited or Trip Inhibited.
