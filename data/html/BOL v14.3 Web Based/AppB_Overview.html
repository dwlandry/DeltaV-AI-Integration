Carrier Specifications

The DeltaV system supports horizontal carriers, vertical carriers, Intrinsically Safe carriers and the Fieldbus H1 Carrier. There are two types of vertical carriers: Legacy and VerticalPLUS. VerticalPLUS carriers can be used for both DeltaV basic process control systems and DeltaV Safety Instrumented Systems (SIS). DeltaV SIS is not supported on Legacy Vertical carriers. Refer to Appendix M for more information on vertical carriers. Refer to the Installing Your DeltaV Safety Instrumented System Hardware manual for instructions on installing an SIS system.
