Install the DeltaV software on the new (secondary) Application Station (the preferred standby)

  1. Use the DeltaV installation disks to run the setup program on the new Application Station intended as the secondary Application Station (the preferred standby).
  2. When prompted to select your workstation type, select the Local Application Station option, and then click Next.
  3. When prompted to provide the workstation configuration file that you made in DeltaV Explorer, click Browse, navigate to the exported workstation configuration file, and double-click it.
  4. In the DeltaV Workstation Configuration dialog, select the workstation name, and then click Next. The following message appears: A node with a Redundant Subsystem has been selected. Is this the preferred active Application Station? Respond No to this prompt as this is the secondary Application Station (the preferred standby). When you respond No, the characters _S are appended to the appended to the name specified for the Application Station in DeltaV Explorer.
  5. Follow the on-screen instructions to complete the installation of the new Application Station.
