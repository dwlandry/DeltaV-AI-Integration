Protected SIS composite templates in DeltaV Explorer and Control Studio

Protected SIS Composite Templates have an effect in a number of areas in DeltaV Explorer and Control Studio.

References Dialog

The References dialog for SIS Composite Templates includes an is used by column to show which SIS Modules reference the SIS Composite Template. This column is populated only for protected SIS Composite Templates. If an SIS Module is listed in the dialog its corresponding Embedded Composite is identical to the protected SIS Composite Template.

Category Details View

In DeltaV Explorer the Details view of a Category in SIS Composite Templates includes a Protected column with values of Yes or No and a CRC column with a numerical value (if Protected is Yes) or blank (if Protected is No). Use the output of this view to check that the SIS Composite Templates match on all DeltaV systems that use the templates.

SIS Modules

Embedded Composites created from protected SIS Composite templates cannot be modified in SIS modules. In Control Studio the Edit Object menu option on a block using a protected SIS Composite Template is disabled (grayed out). You can use the Drill Down menu option on a protected SIS Composite Template, but the only editing option available is to set the parameter values of exposed parameters. Any other menu options or editing features are disabled.

Version Control

SIS Composite Templates and SIS Modules are maintained as individual items in the Version Control system. The Embedded Composites of an SIS Module are considered part of the SIS Module in Version Control. The Version Control database retains an association between a protected SIS Composite Template and the Embedded Composites that are a copy of it so that the rules about interaction with category protection and editing of SIS modules can be maintained.

To ensure that the Embedded Composites in an imported SIS module match the SIS Composite Templates in the database, the .fhx file for each Embedded Composite includes a CRC. If this CRC does not match the CRC of the protected SIS Composite Template the association between the template and the Embedded Composite is not made. The CRC does not include the password (if present) of the SIS Composite Template so that an SIS Module can be reverted to a different version or recovered if the contents of the SIS Composite Template match but its password has been changed.

This same behavior applies to manually maintained and imported .fhx files.

Protecting, unprotecting, or changing the password of an SIS Composite Template is considered a change to the internal data of the template. The Version Control response depends on whether Version Control is enabled, whether the template is already checked out, and the privileges of the user attempting to make the change.  

If you roll back to a previous version of an SIS Composite Template, the protection state and password (if any) of the template are as they were when that version of the template was checked in.
