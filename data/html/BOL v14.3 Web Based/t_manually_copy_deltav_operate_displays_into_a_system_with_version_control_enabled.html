Manually copy DeltaV Operate displays into a system with Version Control enabled

There are times when you will need to copy a display file from one DeltaV system to another DeltaV system (for example, when creating DeltaV Zone capable displays). To do this when Version Control for Displays is enabled, follow these steps:

Important: You cannot rename any DeltaV Operate files using Windows Explorer. All files must be renamed from within DeltaV Operate using the Save As function. Renaming using Windows Explorer or any method other than DeltaV Operate makes that graphic unusable by DeltaV Operate.
  1. Copy the file from the source workstation to the destination workstation using Windows Explorer (you may need to use a storage device such as a memory stick if the two systems are not connected).
  2. Paste the file into the DeltaV\DVData\DisplayWorking\Pic folder on the destination workstation (the one that has VCAT for DeltaV Displays enabled).
  3. Open DeltaV Operate on the destination workstation.
  4. From the DeltaV Operate system tree in the Pictures folder, open the picture that was just pasted into the DisplayWorking\Pic folder.
  5. Close the picture. Version Control for DeltaV Displays adds that picture to the VCAT database.

Continue with all pictures you added to the destination workstation so they are added to the VCAT database. You can then download your workstations to propagate the displays to the Operator Stations.
