Bulk editing Ethernet I/O Cards (EIOC)

This section outlines how to bulk edit EIOC nodes, ports, physical and logical devices, and signals. The general procedure to bulk edit EIOC objects is:

  1. Create an EIOC card.
  2. Configure the card's ports.
  3. Under the port create and configure a physical device of the type you want to bulk edit.
  4. Under the physical device create and configure a logical device of the type you want to bulk edit.
  5. Under the logical device configure the signals.
  6. For each level (EIOC, logical device, physical device, signal) use the sample format specification files or create your own and export data from the existing configuration.
    Note: The EIOC port is bulk edited with the EIOC.
  7. In DeltaV Explorer, select the EIOC object that you want to export and select File > Export > User Defined to create a text file for import.
  8. Edit the text file for the EIOC object in the bulk edit Excel add-in.
  9. Import the text file for the EIOC object into the DeltaV Explorer.
