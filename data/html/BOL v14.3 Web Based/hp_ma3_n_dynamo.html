High Performance MA3_N_ analog dynamo (HP_MA3_N_)

This dynamo can be used for analog data display with analog modules (PID loops, AI indicators, ALM function blocks)

The following elements are present on the dynamo:

  • Alarm icon

  • Display tag

  • Dynamo background

  • PV and SP data fields

  • Abnormal status icons
