S-series mass terminal blocks

The DeltaV system supports the following types of S-series mass terminal blocks:

  • 16-Pin Mass Terminal Block
  • 24-Pin Mass Terminal Block
  • 40-Pin Mass Terminal Block
  • Simplex Analog Input 48-Pin Mass Terminal Block
  • Simplex Analog Output 48-Pin Mass Terminal Block
  • Redundant Analog Input 48-Pin Mass Terminal Block
  • Redundant Analog Output 48-Pin Mass Terminal Block
  • Redundant Discrete Input 40-Pin Mass Terminal Block
  • Redundant Discrete Output 40 Pin Mass Terminal Block

The DeltaV mass terminal blocks allow you to connect external marshalling panels and termination assemblies to your DeltaV system, significantly reducing wiring costs. The mass terminal blocks provide a method to route the wiring within an enclosure and are used with low-level signals that are conducted over 0.093 mm2 (28 AWG) off-the-shelf, flat 3 m ribbon cable or round ribbon cable. For distances over 3 m, standard 20 and 24-pin, 6 meter long, round ribbon cable, 0.14 mm2 (26 AWG) is available. The 16-pin, 24-pin , 40-pin, and 48-pin mass terminal blocks interface to a feed-through IDC-to-discrete-wire module such as the Phoenix Contact FLKM20 VARIOFACE ribbon connector module. For more information on these modules, visit the Phoenix Contact website. The Phoenix Contact FLKM20 VARIOFACE ribbon connector module is an Emerson Alliance Program product.

The 40-Pin Mass Terminal Block, the Redundant Discrete Output 40 Pin Mass Terminal Block, and the Redundant Discrete Input Mass Terminal Block interface to cable or round ribbon cable with 20 connectors.

Termination-fault detection is implemented for the DI 32-channel 24 VDC dry contact Plus card connected to the Redundant Discrete Input 40-Pin Mass Terminal Block and the DO 32-channel 24 VDC high-side Plus card connected to the Redundant Discrete Input Mass Terminal Block.

To configure either card and Mass Terminal Block combination to detect termination faults, enable the T1_FAULT_DETECT and T2_FAULT_DETECT parameters in DeltaV Explorer. T1_FAULT_DETECT is for the ribbon cable connection to channels 1-16, and T2_FAULT_DETECT is for the ribbon cable connection to channels 17-32. Setting these parameters to True enables termination-fault detection to detect a faulty ribbon cable connection, missing power input to the Mass Connection Board, or a missing Mass Connection Board.

If you need to connect supported cards to IS barriers, you can use HiC and HiD Series Boards from Pepperl+Fuchs instead of Mass Connection Boards.. The HiC and HiD Series Boards from Pepperl+Fuchs are Emerson Alliance Program products. In addition to the termination faults listed above, the card and mass terminal block can also detect fault conditions on an IS barrier residing on the Pepperl+Fuchs HiC or HiD Series Board. For more information on these boards and IS barriers, visit the Pepperl+Fuchs website.

You can disable termination-fault detection using a jumper on a Mass Connection Board or an HiC or HiD Series Board from Pepperl+Fuchs.

The Redundant Analog Input 48-Pin Mass Terminal Block and the Redundant Analog Output 48-Pin Mass Terminal Block interface through ribbon cable or round ribbon cable with 24-pin connectors. HiC and HiD Series Boards from Pepperl+Fuchs are also available if you need to connect supported AI and AO cards to IS barriers.
