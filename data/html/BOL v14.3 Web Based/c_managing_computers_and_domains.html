Managing computers and domains

It is possible to create domain-specific accounts in which users have fully qualified names such as DomainName\BSmith. Including the domain name with the user name ensures that the DeltaV user is the same user as the Windows user and avoids the use of passthrough authentication from other domains. A drop down list for assigning users to computers and domains is on the General tab on the New User dialog in the DeltaV User Manager application. The Manage Computers/Domains dialog, also accessed from the General tab, allows you to add and delete computers and domains to the DeltaV system.

Note: It is possible to configure local workstations in a domain environment and remote workstations in a workgroup environment. Be aware that if you create local, domain-specific accounts with fully qualified names, remote users in a workgroup environment will be unable to log onto the remote workstation's operating system because their user IDs are not domain-specific.
