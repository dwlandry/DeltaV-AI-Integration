LAB_Block_1_ (Lab Entry GEM class)

LAB_Block_1_ GEM


Note: This figure shows the GEM at a 200 percent magnification.
The LAB_Block_1_ GEM, used with the LE function block, allows operators to enter a lab analysis value and the time the grab sample was taken. The block computes the delay between the time the grab sample was taken and the time the operator entered the analysis results. If both the analysis value and the calculated delay are within their maximum and minimum ranges, the dynamo writes the sample value to the OUT parameter of the LE block and writes the calculated delay to the DELAY parameter of the LE block. If either of these values is outside its valid range, a dialog notifies the operator that the entry was not accepted.
Abnormal mode status icon
Provides indication when Mode is not as expected. It is visible when either of the following is true:

  • the Actual mode of the function block is not equal to the Normal mode

  • the Actual mode of the function block is not equal to the Target mode

Sample value
The lab analysis value.
Sample time
The time the lab analysis sample was taken.
EU descriptor
Shows the A_UNITS field of the applicable scaling parameter.
