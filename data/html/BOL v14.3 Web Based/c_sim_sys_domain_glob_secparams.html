At some point during configuration you may need to test a module that references a global secure parameter in a logic solver assigned to a workstation that does not physically exist. In the example module SIS1contains references to secure parameters SIS3/SECPARAM1 and SIS4/SECPARAM1 (shown in bold in the table). The workstations simulating the controllers and logic solvers that contain these parameters do not exist. To test the logic of module SIS1 these parameters must be simulated. 

The workstation holding the secure parameter does not have to physically exist. Only the placeholder in DeltaV Explorer must exist. To simulate a global secure parameter requires the following:

  • The secure parameter must be configured in a module.

  • The module it is in must be assigned to an SLS under the SIS Network.

  • The logic solver publishing the secure parameter must be publishing in the appropriate scope (Domain or System) for the reference.

  • The SLS must be assigned to an SIS card on a workstation other than the one holding the reference.
