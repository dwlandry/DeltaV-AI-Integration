OpenContextDisplayAsTooltip function

OpenContextDisplayAsTooltip() opens the specified contextual display in a tooltip-style window, providing it with the primary context information (tag), optional additional context information, and optional initial placement rules.
Arguments
3–9, Optional arguments are indicated by a ? following the argument name.
Argument Description
display element
CDisplayName A literal or graphics expression that resolves to the name of a contextual display.
tag A literal or graphics expression whose value is placed in the contextual display's Tag Description property immediately before starting to run in DeltaV Live.
context 1? A literal or graphics expression whose value is placed in the contextual display's Context 1 property immediately before starting to run in DeltaV Live. If a context 1? value is not present in the expression, the contextual display's Context 1 Default Value is used.
context 2? A literal or graphics expression whose value is placed in the contextual display's Context 2 property immediately before starting to run in DeltaV Live. If a context 2? value is not present, the contextual display's Context 2 Default Value is used.
context 3? A literal or graphics expression whose value is placed in the contextual display's Context 3 property immediately before starting to run in DeltaV Live. If a context 3? value is not present, the contextual display's Context 3 Default Value is used.
context 4? A literal or graphics expression whose value is placed in the contextual display's Context 4 property immediately before starting to run in DeltaV Live. If a context 4? value is not present, the contextual display's Context 4 Default Value is used.
X? A number indicating the X coordinates for the contextual display's trigger point.
Y? A number indicating the Y coordinates for the contextual display's trigger point.
Return values
True, if CDisplayName (case-insensitive) matches a published contextual display available to be opened by this instance of DeltaV Live.
False, otherwise.
Syntax
DL.OpenContextDisplayAsTooltip(DisplayElement, cDisplayName, tag, context1?, context2?, context3?, context4?, X?, Y?)

Examples
Example Result 
DL.OpenContextDisplayAsTooltip("loop_tip",Dsp.Context);
Note: Tooltip-style pop-up windows in DeltaV Live have a distinctive appearance and automatic closing behavior, as compared to normal pop-up windows. Tooltip-style pop-up windows in DeltaV Live do not support minimization.
