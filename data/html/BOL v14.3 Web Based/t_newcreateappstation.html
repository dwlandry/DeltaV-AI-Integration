Create an Application Station

  1. In DeltaV Explorer, create a single Application Station by right-clicking Control Network under System Configuration/Physical Network, and then selecting New > Application Station.
    Note:

    This will be the preferred active node. The preferred standby is created by enabling the redundant subsystem in the Properties dialog of this workstation. Do not create two Application Stations in DeltaV Explorer.

  2. On the General page of the Properties dialog, specify a name for the Application Station.
    Important:

    As a general rule, do not specify an Application Station name that ends with the characters _S.  When the DeltaV system creates a pair of Application Stations for redundant subsystems, it appends these characters to whatever name you specify as the base name for the Application Station. Having a pair of Application Stations named nodename_S and nodename_S_S could result in misleading or undesirable results.

  3. On the Redundancy page of the Properties dialog, select the Enable a redundant subsystem option, and then select the Batch option.
    Important:

    After enabling the redundant subsystem feature on a pair of Application Stations, you cannot also enable any other subsystems, either redundant or simplex on this Application Station.

    Before enabling the Unattended Workstation Reboot on Failover or Manual Switchover option, read the topic, Operational Considerations for Redundant Batch Subsystem.

  4. You can optionally enable the Unattended Workstation Reboot on Failover or Manual Switchover option, if, for example, either of the Application Stations will be located in an unmanned facility.
  5. Select Enable Direct Link for Batch Synchronization if you are connecting the pair with a direct connection.
  6. Click OK to close the Properties dialog for the Application Station.
  7. Export a workstation configuration file for the new Application Station. (Click File > Export > Workstation Configuration).
  8. Save the workstation configuration file to removable media or to a network location that can be accessed from the Application Stations you will be configuring. You can use the default name for a workstation configuration file, DevData.cfg, or specify a different file name.
