Copying OPCHDAAuto.dll to the client

The OPCHDAauto.dll file must be present and registered on any client machine that is to run a VB client for OPC HDA. After installing OPC Remote, copy the OPCHDAauto.dll file to the client. To copy and register the file, do the following:

  1. Copy the OPCHDAauto.dll file from the DeltaV workstation to the %WINDIR%\SYSTEM32 directory on the client machine.
  2. Change to the %WINDIR%\SYSTEM32 directory.
  3. On the client machine, run the command: regsvr32 OPCHDAauto.dll.
