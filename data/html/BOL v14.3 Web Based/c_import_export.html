User-defined export, import, and bulk editing

The following list outlines the tasks required in User-Defined Export, Import, and Bulk Edit:

  1. Select, create, or modify a format specification file (.fmt) to define the data to be exported and imported. Use the Format Specification wizard (from DeltaV Explorer select File > Format Specification) to create or modify a format specification file.

  2. If you are exporting and importing modules, create a module template from the object you want to bulk edit.

  3. Select the object (card, port, signal, and so on) in DeltaV Explorer that you want to export and select File > Export > User Defined.

  4. Follow the prompts in the User Defined Export dialogs, and select the format specification file (.fmt format) that you created in step c_import_export.html#c_import_export__li_DA1FEF712EC84BCC97D361663C446951 to create a text file for import.

  5. Open the text file with the Excel add-in and edit it.

  6. Import the edited text file into the DeltaV Explorer.
