toString function

The toString function returns a string representing the specified Number object.
Arguments
0–1, Optional arguments are indicated by a ? following the argument name.
Argument Description
radix?

A number (from 2 through 36) that represents the numeral system to be used.

If this argument is omitted or undefined, the radix assumes the value of 10.

Return values (string)
A string representing the given number.
Syntax
numObj.toString(radix?)
Examples
Example Result
Assuming you have:
  • the module parameter, U012-FICA-5625-C/PID1/PV.CV, with a value of 20
  • a text entry (Text2) on a display
  • the following script added as a custom script to a Text2 action 
var PV = DLSYS("U012-FICA-5625-C/PID1/PV.CV")
Dsp.Text2.Label = PV.tostring()
 Returns "20" on the Text2 label.
Assuming you have:
  • the module parameter, U012-FICA-5625-C/PID1/SP.CV, with a value of 5.56789
  • a text entry (Text2) on a display
  • the following script added as a custom script to a Text2 action 
var SP = DLSYS["U012-FICA-5625-C/PID1/SP.CV"];
this.Label = SP.toFixed(2);
->returns 5.57
 Returns "5.57" on the Text2 label.
