The DeltaV command (Telnet interface) for the Smart Switch

Use the DeltaV command to access advanced configuration for the switch. You must respond to four questions to reach the advanced configuration. Because the switch is already commissioned, you must not make any changes to these settings:

  1. Enter DeltaV at the Emerson prompt.

    The switch responds with: 

    DeltaV: Enter DeltaV IP address for the Switch [Currently nn.nn.nn.nn]:
  2. Enter an IP to continue without changing the IP address.

    The switch responds with: 

    DeltaV: Enter Name for the Switch [max. 63 chars]:
  3. Press Enter to continue.

    The switch responds with: 

    DeltaV: Enter Location for the Switch [max. 63 chars]:
  4. Press Enter to continue.

    The switch responds with: 

    DeltaV: Disable Network Switch Discovery? (y/n)
[Recommended for use with DeltaV v10.x systems] [Default = y]:
  5. Press N to enable network switch discovery. If you disable switch discovery you cannot flash switch LEDs from Network Device Command Center (NDCC).

    The switch responds with: 

    DeltaV: Advanced Configuration? (y/n)
  6. To save your changes and continue to advanced configuration, press Y.

    Any other response saves your changes and returns you to the Emerson prompt.
