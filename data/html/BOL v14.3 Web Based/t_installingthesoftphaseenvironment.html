Install the Soft Phase environment

The DeltaV Soft Phase environment consists of three elements: the Soft Phase Broker, the Soft Phase DLL and the user written Soft Phase application (the executable file).

To install the DeltaV Soft Phase environment, follow these steps:

  1. Close all applications.
  2. Insert the DeltaV installation disk #1.
  3. Open the DV_Extras\SoftPhaseTemplates folder.
  4. Double-click Setup.exe. This initiates the DeltaV Soft Phase installation program. The installation defaults to C:\DeltaV\SoftPhases.
  5. When the installation is complete, click Finish to restart the computer.
  6. When running soft phases on a non-DeltaV node, you must register the DVBSPBrokerPS.dll and DVBSPSps.dll (regsvr32 DVBSPBrokerPS.dll and regsvr32 DVBSPSps.dll).

    When registering the DLL(s) on a 64-bit operating system, you must use the 64-bit version of regsvr32.exe. This can be found at C:\Windows\SysWOW64\regsvr32.exe.

Note:

Installing the Soft Phase environment on non-DeltaV nodes requires a minimum of Windows 7 or Windows Server 2008.

The DeltaV installation adds the SOFTPHASEUSER account to your system. This user is created without privileges and is a DeltaV User account. If your soft phase requires specific privileges, you must assign those privileges to the SOFTPHASEUSER account through the Windows User Manager application. 

The SOFTPHASEUSER account password is pre-assigned in your system. Never change the SOFTPHASEUSER account password from Windows User Manager. For DeltaV computers, use the DeltaV Security Administration to manage the password. On non-DeltaV computers, use the ServPwd.exe utility (found in the DeltaV\bin directory and copied to the non-DeltaV computer) for changing this password.

Important:

Only change the SOFTPHASEUSER account password using DeltaV Security Administration or the ServPwd utility.
