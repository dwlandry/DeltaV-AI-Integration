OpenContextDisplayAsync function

OpenContextDisplayAsync() opens the specified contextual display, providing it with the primary context information (tag), optional additional context information, and optional initial placement rules.
Arguments
2–9, Optional arguments are indicated by a ? following the argument name.
Argument Description
CDisplayName A literal or graphics expression that resolves to the name of a contextual display.
tag A literal or graphics expression whose value is placed in the contextual display's Tag Description property immediately before starting to run in DeltaV Live.
placement? A Placement object or array of Placement objects whose values define the initial placement of the contextual display when it opens. The Placement objects override the default pop-up window placement rules.
context 1? A literal or graphics expression whose value is placed in the contextual display's Context 1 property immediately before starting to run in DeltaV Live. If a context 1? value is not present in the expression, the contextual display's Context 1 Default Value is used.
context 2? A literal or graphics expression whose value is placed in the contextual display's Context 2 property immediately before starting to run in DeltaV Live. If a context 2? value is not present, the contextual display's Context 2 Default Value is used.
context 3? context 1? A literal or graphics expression whose value is placed in the contextual display's Context 3 property immediately before starting to run in DeltaV Live. If a context 3? value is not present, the contextual display's Context 3 Default Value is used.
context 4? A literal or graphics expression whose value is placed in the contextual display's Context 4 property immediately before starting to run in DeltaV Live. If a context 4? value is not present, the contextual display's Context 4 Default Value is used.
X? A number indicating the X coordinates for the contextual display's trigger point.
Y? A number indicating the Y coordinates for the contextual display's trigger point.
Return values (Boolean)
True, if CDisplayName (case-insensitive) matches a published contextual display available to be opened by this instance of DeltaV Live.
False, otherwise.
Syntax
DL.OpenContextDisplayAsync(cDisplayName, tag, placement?[], context1?, context2?, context3?, context4?, X?, Y?)
Examples
Example Result 
DL.OpenContextDisplay("loop_fp", "FIC-101", "1")
 Opens the contextual display with the name Loop_fp, with FIC-101 as the module tag on the faceplate, and ??? 
DL.OpenContextDisplay(DL.DN("LOOP_DT"), Dsp.Context)
 Opens the contextual display with the name LOOP_DT and ??? as the tag name.
Note: If contextual displays use this function to open as pop-up windows in DeltaV Live, then when minimized, they appear in a group on a layout's menu bar. Faceplate and detail displays each appears in its own group in the menu bar.
