Create a display from scratch

  1. Select the Graphics Explorer pane as the active pane in the Explorer view.
  2. On the ribbon's Home tab, in the Graphics group, click New > Display > Create New Blank Display. The display opens as a content tab and becomes available for editing in the content pane.
  3. Rename the display, if desired.
  4. Configure the display's properties in the Graphics Configuration pane.
  5. Add graphics elements to the display by dragging them from the Palette pane and dropping them on the content pane.
  6. Configure each element's properties in the Graphics Configuration pane.
  7. Click Save.
