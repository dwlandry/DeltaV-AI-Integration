8-Wide VerticalPLUS I/O Interface Carriers

8-wide VerticalPLUS I/O interface carriers hold I/O cards and Logic Solvers and contain connectors for inserting system and field power. For carrier numbering and card addressing positions, refer to Carrier Numbering and Addressing Positions. The following figure shows the 8-wide VerticalPLUS I/O interface carriers.
