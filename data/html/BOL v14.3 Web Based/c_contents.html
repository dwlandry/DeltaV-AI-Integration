FlexLock overview

The available desktops are the Windows desktop and the DeltaV desktop. A user with a DeltaV account type of either DeltaV Administrator, Windows Administrator, or Windows Desktop Access (and who exists as a user account in Windows) has privileges to access both the DeltaV desktop and the Windows desktop. The Windows desktop includes all the DeltaV programs as well as all programs available in Windows. A user who does not have the appropriate DeltaV account type has access to only the DeltaV desktop. The DeltaV desktop limits the user to the operator interface program and to those programs available to the user through the operator interface program. To secure your operating environment, consider giving operators access to the DeltaV desktop and other users, such as engineers, access to both the DeltaV and Windows desktops.

Note: You must also consider access to the underlying Windows account especially when logged on with Windows Administrator Account privileges. When you log off of DeltaV, be sure to also log off of Windows, especially if you are logged on with Windows Administrator privileges. Until you log off of Windows, the next user to log on to DeltaV operates under the Windows Administrator account. The Windows Administrator account grants the user the right to perform actions that could interfere with the operation of DeltaV. In the Windows User Manager, consider creating an administrator group for users with unrestricted rights and an operator group for users with restricted rights.

When the current user logs off of the DeltaV software, the next user sees the FlexLock application with the DeltaV Desktop button depressed. This indicates that FlexLock switched the user to the DeltaV desktop. If the current user has the appropriate DeltaV account type, the user can select the Windows Desktop button from FlexLock and switch to the Windows desktop (provided that user account exists in Windows). If the current user does not have the appropriate DeltaV account type, he can only access the operator interface program. Users without the appropriate DeltaV account type who attempt to switch to the Windows desktop receive a message indicating that they lack the proper privileges and are prompted to enter an administrator name and password. If the user enters an appropriate user name and password, FlexLock switches him to the Windows desktop.

Users with the appropriate DeltaV account type (DeltaV Administrator, Windows Administrator, or Windows Desktop Access) can prevent FlexLock from automatically switching to the DeltaV desktop on subsequent logons by deselecting the Autoswitch Desktop menu item.

If you exit the FlexLock application from the Windows desktop, click Start > All Apps > DeltaV Engineering > FlexLock to open the FlexLock application. You cannot exit the FlexLock application from the DeltaV desktop.
