Creating the format specification file

When you create the format specification file you must specify a subtype. Use the Browse button to browse to the template on which the module you want to export is based.

From DeltaV Explorer, select File > Format Specification and create a format specification file that defines the data to export and import.

  1. Specify the Object type as Module.

  2. For the Subtype field, browse to the module template TEMPS_F_C. 

  3. Select fields in the Select Fields dialog.

  4. Select items in the Format specification - Must exist dialog, if desired.

  5. Save and close the format specification file.
