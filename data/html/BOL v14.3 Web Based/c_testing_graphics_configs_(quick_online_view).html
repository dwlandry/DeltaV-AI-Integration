Testing graphics configurations online prior to publishing

In addition to verifying configurations before you publish, you can also see how your graphics configurations appear and behave online using the Quick Online View feature.

Displays, display sets, and layouts are tested online by adding them to the Quick Online View using the ribbon's Quick Online View command. The displays and layouts in Quick Online View also reflect and test any standards and functions referenced by these displays and layouts as well as any GEMs contained by the displays. Active languages and themes can also be tested in conjunction with displays by switching the theme or language in Graphics Studio to see how they look. Languages and themes must also be assigned to the workstation on which they are being tested, and the workstation settings must be published. You can test multiple displays simultaneously to see how they work together, such as when you want to test opening a contextual display from a button on a different display.

The Manage Quick Online View pop-up lists all configurations that have been added to Quick Online View for all instances of Graphics Studio; all items on the list are available to be tested in Quick Online View. The first item you add to the Manage Quick Online View list opens the DeltaV Live Quick Online View instance. From that point, each time you add a new item to the list, the Quick Online View instance receives the new content. Configurations remain in the list until you click Remove All in the pop-up or close all instances of Graphics Studio, along with the Quick Online View instance.

You can test any layout or display set regardless of which layout or display set is assigned to that workstation; testing configurations that are not assigned to that workstation does not change the workstation's assignments. Only one layout and one display set at a time can be tested, however, because only one of each can be available online. The Manage Quick Online View list reflects the layout and display set most recently added to the list.

Configurations can still be edited after they have been added to Quick Online View, but you must re-add them to Quick Online View to make the changes available for testing. Configurations that are locked for editing can still be added to Quick Online View.
