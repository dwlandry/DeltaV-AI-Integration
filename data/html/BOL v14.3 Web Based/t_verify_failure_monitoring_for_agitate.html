Verify failure monitoring for AGITATE

Since the AGITATE_TIME parameter is set to only 30 seconds, you may want to increase this a little to allow yourself more time to trip the failure condition before the phase goes to complete.

  1. In Control Studio, open the UM_BLEND_500 unit module.
  2. On the Home tab, in the Diagram Mode group, click On-line.
  3. Drill down into the AGITATE > FAIL_MONITOR block.
  4. Open the Batch picture in DeltaV Operate.
  5. Load and start the AGITATE phase for the unit module UM_BLEND_500.
  6. Trip a failure condition by opening XV_BASE_500 (in the Process picture). (XV_BASE_500 must be in Auto mode.)
  7. In Control Studio, verify that the FAIL_INDEX parameter is set and that AGITATE goes to Held. (XV_BASE_500 closes as part of the Hold logic FAIL_SAFE instructions.) 
  8. Clear the failure by clicking the Clear Failures button on the command list.
  9. Send a Restart command.
  10. Verify that the AGITATE phase transitions from the Restarting state to the Running state.
  11. When the AGITATE phase goes to Complete, send a Reset command.
  12. You can verify other failure conditions using the same general procedure. When you are finished, reset the phase to Idle.
  13. Unload the AGITATE phase.
