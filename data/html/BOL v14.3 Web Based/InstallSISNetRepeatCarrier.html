Install the carriers

Note: For vertically-mounted systems, DeltaV SIS hardware is supported on VerticalPLUS carriers only. It is not supported on legacy vertical carriers. Refer to the DeltaV TM M-series Hardware Installation and Reference manual for information on installing VerticalPLUS carriers.
  1. Install the 2-wide power/controller carriers and the 8-wide I/O interface carriers on the DIN rails. Install a DeltaV controller and power supply on the 2-wide power/controller carrier. Refer to the DeltaV TM M-series Hardware Installation and Reference manual for installation instructions. Read the following Important information and be sure that you are using the correct 2-wide power/controller carrier
    Important: Be sure that you are using the 2-wide power/controller carrier numbered KJ4001X1-BA3 or higher. DeltaV SIS hardware requires this version. A small white rectangle is printed on the front of this carrier to distinguish it from earlier versions. The topic on installing the terminal blocks includes an image that will help you to determine if you are using the correct 2-wide carrier.
  2. Install the 2-wide SISNet Repeater carriers on the DIN rails if remote communication is required. SISNet Repeater carriers can be installed anywhere between the 2-wide power/controller carrier and the terminated one-wide carrier. The 2-wide SISNet Repeater carrier installs exactly like a 2-wide power/controller carrier. The topic on terminating the local peer bus provides information on the one-wide carrier.
  3. Connect the carriers to any adjacent carriers by sliding together the 48 pin connectors on the sides of the carriers.
  4. If you are installing carriers on separate DIN rails, you will need to connect two (left and right) one-wide carriers and then connect extender cables to extend the LocalBus and local peer bus. You can also add carriers to an existing operational system.
