Creating an example template and instantiating it

Follow these steps to create a template, then create an instance of the module from the template.

  1. In DeltaV Explorer, navigate to Library/Module Templates/AnalogControl.

  2. Right-click and select New Module Template.

  3. In the New dialog, name the template MASTER_CAS and make sure the Object type is set to Control Module or Template.

  4. Click OK.

  5. Right-click MASTER_CAS and select New Module Template.

  6. In the New dialog, name the template SLAVE_CAS and make sure the Object type is set to Control Module or Template.

  7. Click OK.

  8. Right-click MASTER_CAS and select Properties.

  9. In the SubType field of the Properties dialog, enter MASTER_CAS.

    Note:

    The Subtype must be entered in all capital letters. The user-defined import uses the Subtype to identify the module templates when it creates modules.

  10. Right-click SLAVE_CAS and select Properties.

  11. In the SubType field of the Properties dialog, enter SLAVE_CAS.

    Again, use all capital letters.
