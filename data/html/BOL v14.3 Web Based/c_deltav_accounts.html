DeltaV accounts

There are two types of accounts in DeltaV: custom and built-in. Custom accounts are created by you to allow access to the system and its resources. Built-in accounts are created during the installation of DeltaV.

The accounts are further classified as follows:

  • DeltaV user accounts – These are DeltaV database accounts; they are not Windows accounts.
  • DeltaV application accounts – These accounts provide assistance for the functionality of standard DeltaV applications, optional DeltaV applications, and DeltaV Extras (add-in accounts for Emerson applications installed after DeltaV is installed). These accounts should not be modified, deleted or used to log on except as otherwise explained in the DeltaV documentation.
  • DeltaV services account – This account is created when DeltaV is installed and is used by the DeltaV services as their “Run as” account. This account should not be modified or deleted or used to log on except as otherwise explained in the DeltaV documentation.

DeltaV User Accounts

To use a DeltaV user account, you must make it a Windows account and assign a password. This can be done in the DeltaV User Manager application.

If you set up Windows group membership for the built-in Configure, Maintainer, Operator, SIS_Configure, or Supervisor user accounts, it is recommended that you add them to the DeltaV group in Windows.

Note:

The only exception to the disabling of the interactive-user account is the Emerson account, which is created on Windows workstation operating system computers only. Before installation disables the Emerson account, it will check to see if the Windows Administrator account is disabled. If it is, then the Emerson account will remain enabled. If the Administrator account is enabled, then the Emerson account will be disabled.

Although the DeltaV Administrator account is not assigned to any DeltaV groups, it is assigned all non-SIS DeltaV keys by default. No DeltaV SIS keys and SIS groups are assigned to the Administrator account by default. However, while no SIS keys are assigned to the DeltaV Administrator account by default, the DeltaV Administrator can assign SIS keys and SIS groups to any user account including the DeltaV Administrator account.

DeltaV services account

During installation, DeltaV creates only one account that is used to authenticate all DeltaV services.

The DeltaV services account should not be modified or deleted or used to log on. Change the password on this account only with the DeltaV Security Administrator application or the ServPwd utility (located in the \DeltaV\Bin folder).
