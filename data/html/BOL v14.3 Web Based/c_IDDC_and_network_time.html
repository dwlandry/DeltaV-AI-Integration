Network time and the Independent DeltaV Domain Controller

It is critical that the Independent DeltaV Domain Controller (IDDC) and all the DeltaV nodes remain time synchronized. DeltaV uses Network Time Protocol (NTP) to maintain time synchronization between the DeltaV workstations and the DeltaV controllers. The Independent DeltaV Domain Controller setup application disables the Windows Time Service and installs/configures the NTP service such that it listens to the DeltaV master time server (the ProfessionalPLUS by default). This ensures that the IDDC remains time synchronized with all other DeltaV nodes.
Important:

If the Independent DeltaV Domain Controller is also connected to a network level other than the DeltaV ACN, you must block any NTP/Time communications from that non-ACN network using a firewall (physical or Windows).
