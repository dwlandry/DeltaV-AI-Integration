Enabling the Campaign Manager Server

To run campaigns, you must enable the Campaign Manager subsystem. Once the Campaign Manager subsystem is enabled and configured (from the subsystem Properties dialog), you must download the workstation for the change to take effect.  You must also start the Campaign Manager server for this node using the Batch Application Manager.

Each Campaign Manager server can be enabled for only one Batch Executive. That is, with multiple Batch Executives, you have multiple Campaign Managers. It is a one-to-one relationship. You must select a Batch Executive node for this Campaign Manager from the list (or click Browse and browse to the Batch Executive node).
