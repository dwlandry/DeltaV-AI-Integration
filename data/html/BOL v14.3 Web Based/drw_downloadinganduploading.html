Downloading and uploading operator displays

Operator pictures can be used and edited on any workstation in the DeltaV control network that has the appropriate license. Because changes can be made to pictures on multiple workstations, you must keep display versions synchronized throughout the DeltaV system. You can use the Auto-Update Service to control which workstations receive updated displays and charts during downloads. For more information on the Auto-Update Service and how downloading affects the data on workstations, refer to Workstation Synchronization.

Note:

Pictures files are copied to the downloaded workstation after the download is complete. This may take some time, depending on the system size, the number and complexity of the pictures being copied, and other factors. 

How you synchronize displays depends on where you edited the operator picture.

  • If you created or modified a display on the ProfessionalPLUS workstation, go to DeltaV Explorer on any workstation and download each workstation that you want to have the new or updated display.

  • If you created or modified a display on a workstation, go to DeltaV Explorer on that workstation and upload the display to the ProfessionalPLUS workstation. Then, download each workstation that you want to have the new or updated display.

Synchronize process history view charts and trends in a similar manner.

You can also update a workstation with the most recent pictures using the Upload command. The Upload command compares the dates of the pictures in one workstation with those in the ProfessionalPLUS workstation. If you want the pictures to be uploaded, the system copies the most recent files to the ProfessionalPLUS workstation. If you do not want the pictures to be uploaded, you can replace the display files with the versions on the ProfessionalPLUS workstation using the Download command, provided that the displays on the ProfessionalPLUS workstation are newer.
