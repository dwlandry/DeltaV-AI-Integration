BadConfigErrorr_hart_command_errors.html#r_hart_command_errors__footnote3_unique_1

1 Any time configured variables have a nonzero status in response to Command 9, only the status of those variables is set to BAD.
2 Any time a dynamic or device variable is not reported by the device or is not configured, the status of those variables is set to BAD. If PV is BAD, OINTEG is also set to BAD.
3 Unless ignored by configuration.
4 Unless disabled by configuration.
5 Any condition that causes the analog value FIELD_VAL_PCT to have bad integrity or status will also cause HART_FIELD_VAL to have bad integrity and status.
6 This channel parameter is not supported in devices implementing the HART Protocol prior to revision 7. Therefore, any HART command error appearing in DeltaV Diagnostics for a device that implements an earlier level of the HART protocol can be disregarded.
