Ethernet Isolation Port LEDs

The SZ Controller Carrier and Dual Universal Safety Carrier house a primary and secondary Ethernet Isolation Port (EIP). Each EIP on the SZ Controller Carrier consists of a Control Network port for connections to the DeltaV Area Control Network and a Safety Network port for connections to the Local Safety Network. Each EIP on the Dual Universal Safety Carrier consists of a Global Safety Network port for connections to the Global Safety Network and a Safety Network port for connections to the Local Safety Network.
Note: The Dual Universal Safety Carrier can hold either SZ Controllers or Local Safety Network Bridges.

The LED color and pattern is the same for the Control Network and Global Safety Network ports.


Control Network port and Global Safety Network port LED on the Ethernet Isolation Port
LED color and pattern Description and corrective action
Flashing green The link is established and active Ethernet traffic is being transmitted and received. This is the normal operating condition.
Solid green The link is established, but no Ethernet traffic is occurring. This indicates that the EIP is connected to a network switch, but may not be connected to a controller, Local Safety Network Bridge or ProfessionalPlus workstation. This typically occurs during initial installation when network connections are not yet complete.
Off The EIP is not communicating on the network. Verify that the:
  • Network cable is properly connected
  • EIP is properly seated in the carrier
  • SZ Controller or Local Safety Network Bridge is properly installed in the carrier
  • SZ controller or Local Safety Network Bridge is properly powered
For redundant controllers, verify that the ACN LEDs are flashing. If the LED remains Off after ensuring the items in the preceding list, replace the EIP.
Safety Network port LED on the Ethernet Isolation Port
LED color and pattern Description and corrective action
Flashing green The link is established and active Ethernet traffic is being transmitted and received. This is the normal operating condition.
Solid green The link is established, but no Ethernet traffic is occurring. This verifies the physical wire and connection integrity. Also occurs for a short time at power up. Verify both the Safety Network Port and SZ controller or Local Safety Network Bridge are fully seated. Check to see if the Ethernet network has a CSLS powered and connected on the Safety Network Port.
Off The Safety Network Port is not physically connected, neither SZ Controller or Local Safety Network Bridge are present, or both SZ Controllers or Local Safety Network Bridges are unpowered. Verify that at least one SZ Controller or Local Safety Network Bridge is installed and powered. Ensure that the connection back to the Ethernet switch is correct and that the switch is powered.
