Siemens SIMOCODE-DP motor module template

The SIMOCODE-DP module template is designed as a starting point for configuring a module that accesses diagnostic parameters for a Siemens SIMOCODE-DP motor. The diagnostic data can then be used in control logic, such as creating an alarm to signal the need for operator intervention. 

Device diagnostic parameters

The SIMOCODE-DP module template uses the Motor and Valve Module Faceplate (DL_FP) faceplate and the Profi_SIMOCODE_dt detail display, which is functionally identical to the Motor and Valve Module Detail Display (DL_DTx) detail display, except that it creates an additional tab, named DEVICE, in the Diagnostics area of the detail display.
