Configure the internal network

You will need the information from the Worksheet for internal workstation names and IP addresses to configure the internal network. It is assumed that you have the firewall installed, powered up and the network cables correctly installed and the firewall is able to access the DeltaV workstations and the external network.

  1. In the firewall's web UI navigate to the Configuration > Network settings.
  2. Set up the internal network information from the Worksheet for internal workstation names and IP addresses.
    • If you change the internal network address from 192.168.1.1 to another address the web UI will disconnect and you will have to log in again using the new address.
    • If you use a different subnet from the firewall default, the PC will need a new address in its Network Interface Card (NIC) to access the firewall. The PC's NIC information is updated by the firewall if the firewall is set to automatically assign addresses. If not, you will have to set up the PC's NIC manually by editing its IPv4 properties.
    • If the firewall is set to provide an address automatically you may need to force the firewall to update the computer. The easiest way is to unplug the network cable from the PC and wait a minute or two and then reconnect the cable. This will alert the firewall that there is a new device and it will assign a new address.
    • If you are using static network addressing, use the information from the setup sheet to configure the NIC on the PC.
  3. The next step is to configure static addressing on DeltaV workstations.
