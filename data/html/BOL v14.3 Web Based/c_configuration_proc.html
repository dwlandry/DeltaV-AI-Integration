Setting up and configuring the Emerson Smart Firewall

There are three tasks required to install the Emerson Smart Firewall and get it properly functioning in your network:

  • Configuring the firewall parameters so the firewall works within the existing networks
  • Establishing communications between the computers on either side of the firewall
  • Creating communications rules to ensure only the authorized communications are allowed through the firewall

This document provides suggested procedures for using the information from the Smart Firewall configuration worksheets to configure the firewall, establish communications and setup the protection rules. We encourage you to print and complete these worksheets because the information recorded on the worksheets will be used to configure the internal and external networks and create communication rules.
