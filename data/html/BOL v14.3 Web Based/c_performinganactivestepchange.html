Performing an active step change

To initiate an active step change, the batch must be in MANUAL mode. Once the active step change is complete, the batch can be returned to AUTOMATIC mode, as long as the batch is in a state where that is possible according to the rules of the PFC. If, for example, the batch is in the middle of executing an AND convergence, the batch cannot be placed into AUTOMATIC mode until that step is complete. 

With the Batch Application Manager setting Allow Implicit Mode Change, set to Yes, the batch is placed in Manual mode when the ASC button is clicked.

Important:
To perform an active step change the following must be true:        
  • The step you are performing the active step change from must be in a terminal state; that is, Complete, Stopped, Aborted, Stopped_NC, or Aborted_NC.
  • The parent steps of the one you are changing from must be in one of the following states:  Held, Running or Ready
  • The active step change cannot be performed if the batch or the parent step is in a terminal state (Complete, Stopped, Aborted). However, the operator can reset the batch (putting it back into Ready) if the batch is in a terminal state.

You can also repeat a step using the active step change functions. Do this by using the same steps as an active step change, only use the Rerun command from the Active Step Change commands button bar.
