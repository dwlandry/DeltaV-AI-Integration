View and add alarms to the list

When the application first opens, the alarm list is empty. You can add alarms to the list through either the View > By... commands or the Edit > Add to List command.

If you want to add alarms to the existing list, select Edit > Add to List and then choose the appropriate filter (Area, Module, Unit, Safety Node, or Node). In the Browse dialog, select one or more of the appropriate items.

If you want to replace alarms already on the list with new alarms, select View and then choose the appropriate filter (By Area, By Module, By Unit, By Safety Node, or By Node). In the Browse dialog, select one or more of the appropriate items.

Tip:
  • Use the Shift key to select multiple items in the Browse dialog.
  • The View command can also be used when the alarm list is empty.
