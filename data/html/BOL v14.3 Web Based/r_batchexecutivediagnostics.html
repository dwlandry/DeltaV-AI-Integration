Batch Executive diagnostics

Only top-level diagnostic information about the health/performance of the Batch Executive is available as diagnostic parameters and visible in the Diagnostic Explorer. Diagnostic parameters expose status Booleans or numeric levels that give users a means to use custom alarm logic to draw more attention to problems.

The Batch Executive subsystem exposes the following parameters:

Name

Type

Usage

BALARM

Int32

The number of batch alarms.

BFAIL

Int32

The number of batches in the LOAD_FAILED and RECOVER_FAILED states.

BLOST

Int32

The number of batches in the LOST state.

CLIENT

Int32

The number of batch client applications connected to the server.

DONE

Int32

The number of batches, still in the batch list, that have reached a terminal state (completed, aborted, stopped).

DVSRV

UInt16

The status of the DeltaV process server. The DeltaV process server can have one of the following states:

  • GOOD - the DeltaV batch server can communicate with the DeltaV process server.

  • BAD - the DeltaV batch server cannot communicate with the DeltaV process server.

  • SUSPECT - at least one data item on the DeltaV process server cannot be accessed. This information is only available for process servers that are in use. If the area model has no reference to the DVBSIM or SOFTPHASE servers this information does not appear.

EXEC

Int32

The number of batches that are in the IDLE or a non-terminal state. (Terminal states are: COMPLETED, ABORTED, and STOPPED.)

HELD

Int32

The number of batches that are in the HELD state in the batch list.

LOADED

Int32

The number of batches loaded in the batch list.

OInteg

Boolean

Indicates if this component or components below this level have integrity problems. Bad OInteg occurs in the Batch subsystem if the DeltaV Batch Server cannot communicate with one of the following:

  • DeltaV Process Server

  • Simulation Process Server

  • SoftPhase Process Server

PROMPT

Int32

The number of unacknowledged prompts.

SIMSRV

UInt16

The status of the batch simulation process server. The batch simulation process server can have one of the following states:

  • GOOD - the DeltaV batch server can communicate with the batch simulation process server.

  • BAD - the DeltaV batch server cannot communicate with the batch simulation process server.

  • SUSPECT - at least one data item on the batch simulation process server cannot be accessed. This information is only available for batch simulation process servers that are in use. If the area model has no reference to the DVBSIM or SOFTPHASE servers this information does not appear.

  • LOST - the batch simulation process server has lost its connection to the DeltaV batch server.

SPHSRV

UInt16

The status of the batch SoftPhase process server. The batch SoftPhase process server can have one of the following states:

  • GOOD - the DeltaV batch server can communicate with the SoftPhase process server.

  • BAD - the DeltaV batch server cannot communicate with the SoftPhase process server.

  • SUSPECT - at least one data item on the process server cannot be accessed. This information is only available for process servers that are in use. If the area model has no reference to the DVBSIM or SOFTPHASE servers this information does not appear.

  • UNLICENSED - an Advanced Batch or Professional Batch license is required to use the batch SoftPhase process server.

STPHLD

Int32

The number of running batches with steps that are HELD.

SWREV

String

The DeltaV software revision number; for example, "10.3.0.3295.xr."
