Bulk editing with the add-in

The Bulk Edit add-in makes it easy to edit data files for import into the configuration database. The sample format specification files and sample .txt files are installed in the \DeltaV\DVData\BulkEdit folder.

Note:

An Excel worksheet can contain up to 16,384 columns.

To use the Bulk Edit add-in, perform the following steps:

  1. Open Excel.

  2. Use the Open Data File command to open the exported data .txt file. (Do not use the normal Excel File Open icon or the File > Open menu selection.)

    If the file you open is a Unicode file, a pop-up appears telling you that the add-in creates an ASCII file with _ASCII appended to its name. The add-in creates an ASCII version for you to edit, save, and import. The original Unicode file remains unchanged. 

  3. Copy rows of exported data and paste into as many rows as required to create the items you want.

  4. Edit the file as desired. You can add rows, delete rows, and modify the data in rows.

  5. Use the Save Data File command to save the data. Remember that the name of the saved file is the original file name with _ASCII appended to it (if you started with a Unicode file).

    If you need to make further changes or additions to the text file, you can open the *_ASCII.txt file from Excel.
