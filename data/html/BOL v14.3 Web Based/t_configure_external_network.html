Configure the external network

Note: If you will be communicating to devices other than computers, such as network printers, it is necessary to ensure these devices can communicate through the firewall. Refer to the device instructions to ensure they are configured correctly to communicate through the firewall.
  1. Navigate to Configuration > Network settings > External workstations.
    If Then
    static addressing is used enter the workstation names and IP addresses from the Worksheet for external workstation names and IP addresses .
    dynamic addressing is used you must be connected to the external network and the external network routing must be configured correctly for the firewall to obtain this address. There are two ways to establish routing:
    • Use the route add command to configure a route in each external workstation
    • Configure the router on the external LAN to route traffic for the DeltaV 2.5 network addresses to the external address of the firewall. Routing must be completed before testing communications on either side of the firewall
  2. In the firewall's web UI navigate to Configuration > Network settings and depending upon input from your IT department either select or deselect Allow users on the external interface to access through HTTPS (read only).
  3. Navigate to Configuration > Summary and ensure the information is correct.
  4. Navigate to Configuration > Internal workstations and if dynamic addressing is used for DeltaV workstations, ensure that these workstations are listed. If you do not see any or all of the DeltaV workstations that are connected to the firewall ensure that the network cables are connected properly and the workstations' NICs are set to Obtain an IP address automatically. Remember that if static IP addressing is used for the DeltaV workstations, the workstation name and IP address is entered directly into the firewall through the firewall's web UI.
