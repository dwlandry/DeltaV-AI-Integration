Test a soft phase

After writing the soft phase, you can test it using the Soft Phase Tester application.

  1. Start the Soft Phase Tester and select File > New.
  2. Enter the name of the soft phase (without the .exe extension) that you are testing. If you already have the configuration saved for this phase, select File > Open and select the Soft Phase Tester (.SPT) file.
  3. Under the Commands section, click the Start button to begin the phase.

    All phases start with a 1000 request.

  4. Click the Ack Request button to acknowledge that request and any time you are prompted with a request.
  5. Respond to operator prompts by entering the value in the Prompt Info fields and clicking Ack Request. The Messages field lists the text of the message or any debug message that you have programmed into the soft phase.
  6. The batch commands (stop, abort, hold, clear failure, and restart)  are issued through the Soft Phase Tester by clicking the appropriate button.
  7. Test the Watchdog by clicking the Disconnect button. This simulates a communications failure between the Soft Phase Server and the Batch Executive.
  8. Change the parameter values (once the parameters are configured) by selecting the parameter, entering the new value, and clicking the Ack Request button. Use the Prev and Next buttons to flip through the pages of parameters (if your list exceeds 10 parameters).
Note:

The Reset button removes the soft phase from the computer's memory and should be used before exiting the Soft Phase Tester or starting the soft phase again.

Tips

  • Keep a list of Phase Request Codes to refer to. The Phase Request Codes are found in the DeltaV Batch Book Online.

  • Write debug messages in your soft phase, especially for the operator prompts. These debug messages display in the messages display. Your operator messages are not available to you in the Soft Phase Tester because the Batch Executive is not being used.

  • Periodically clear the messages display by clicking the Clear button.
