Retrieving data from SmartPlant Instrumentation

After you have configured instrument data in the SmartPlant Instrumentation application and have published it to an xml file, you can retrieve the data into an Excel worksheet. If you have not previously generated the libraries you are prompted to do so before you can continue. It is recommended that you regenerate the libraries once at the beginning of each session unless you are sure that there have been no changes to the database since your last session.

  1. Select the SPI Interface > Retrieve from SPI option to load the xml file.

    After selecting the file, the Select Load Format dialog appears.

    By default all the columns necessary for the SmartPlant Instrumentation interface are selected.

    Note:

    Do not change the default selections in the Select Load Format dialog. Modifying the selections may cause errors when you attempt to save configurations created in SmartPlant Instrumentation to the DeltaV Database.

    If errors appear during retrieve do not save the data to the DeltaV database. Make a note of the errors and close the worksheet without saving it. Return to SmartPlant Instrumentation, correct the errors, and re-publish the data. 

    SPI now has the capability to add user-defined rules in its Rule Manager. Contact your database administrator to get appropriate rules added for working with DeltaV.

  2. Click OK to load the data into the worksheet.

    At this point you can edit the information in the workbook—configure items that are configurable, bind instrument data to I/O channels, and so on.

  3. After you have completed your edits, open the Data Manager dialog (DeltaV > I/O Support > Data Manager) to save the data in the workbook to the DeltaV database.
