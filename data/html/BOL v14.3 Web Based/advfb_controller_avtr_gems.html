Controller_AVTR_1...3Input_ (analog voter GEM classes)

Controller_AVTR_3Input_ GEM


Controller_AVTR_InputX_ GEM


The Advanced Function Block GEM class set contains four GEMs for the AVTR function block. The one-, two-, and three- input AVTR GEMs are identical, except that each contains a different number of rows for voting conditions. (Figure 1 shows the Controller_AVTR_3Input_ GEM.) The number of rows corresponds to the input number in the GEM's name. For the common voting arrangements (1oo2, 2oo3, 1oo1, 2oo2, and 1oo3), use an AVTR block with one, two, or three input parameters, as shown in the following table:
Voting arrangement Use this GEM
1oo1 voter Controller_AVTR_1Input_
1oo2 or 2oo2 voter Controller_AVTR_2Input_
1oo3 or 2oo3 voter Controller_AVTR_3Input_

The Controller_AVTR_InputX, as seen in Figure 2, is an input-only GEM that can be added to the Controller_AVTR_3Input_ GEM for voting arrangements having more than three inputs. For example, for a 6oo8 voter, add the Controller_AVTR_3Input_ to a display; then add five instances of the Controller_AVTR_InputX_ to the Controller_AVTR_3Input_, positioning each beneath the existing input lines, for a total of eight inputs.

When you add an AVTR GEM to a display, the faceplate name defaults to AVTR_fp. If you prefer to use a custom faceplate rather than the default faceplate, enter the faceplate name in the Faceplate Name field.
