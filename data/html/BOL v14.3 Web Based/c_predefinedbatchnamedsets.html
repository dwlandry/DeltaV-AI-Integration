Predefined batch named sets

The DeltaV system supplies predefined named sets for use with the batch subsystem. They are equipment_availabilty, phase_command, phase_owner_id, phase_restart_types, phase_state, phase_wdog_state, phase_failures, phase_boolean, and recipe_state.

Changes to named sets do not affect running batches, even when setup data is downloaded. Each running batch retains the named set as defined at the creation of the batch, for the duration of the batch.
