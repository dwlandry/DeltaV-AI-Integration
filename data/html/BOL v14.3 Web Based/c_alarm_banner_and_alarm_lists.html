Zones alarm banner and alarm lists

The DeltaV Operate Area Alarm Filtering display supports a total of 250 local and remote zone areas and shows all Remote Zone areas (by the remote shared name) and indicates those whose alarms the current user is eligible to see. You can filter out alarms from Remote Zone Areas as well as local areas. Once alarms are visible in a local system, the filter works on remote zone areas as if they were local areas.

Alarm banner and alarm summary alarm message strings appear based on the alarm types defined in the originating zone. Because workstations are merging alarms from different zones into a single display, alarm priority behavior (priority words, horn sound files, alarm banner alarm filtering configuration) is determined by the alarm configuration of the zone displaying the alarm. Alarm priorities 3 through 15 are the same in all DeltaV zones, so alarms from other zones use the displaying zone's alarm priority text for the corresponding numeric priority level. 

It is recommended that all DeltaV systems connected with Inter-Zone Servers have a common alarm strategy (identical alarm priority and alarm type definitions). You can accomplish this by exporting and importing alarm priorities and types between zones.

Common alarm priorities ensure that each alarm appears in the alarm banner and alarm lists of every system with the same behavior. If the alarm priority of an alarm is not defined in a system, the alarm adopts the next highest alarm priority configured in the system. If the alarm priority is configured in the system but has different properties, the alarm adopts the behavior of the alarm priority in the system in which it appears. The locally configured alarm type is used by the Inter-Zone Servers to ensure the alarm appears with the same alarm word and message in all zones where it is viewed. Having consistent alarm types in all zones ensures that alarms have consistent appearance and behavior.

When an alarm is from another zone the alarm extended information button includes a satellite dish: . Clicking the button displays the following information about the alarm:

  • Alarm timestamp

  • Module description (if configured with the alarm)

  • Parameter in alarm (in the form zone%module/parameter)

  • Alarm Word

  • Alarm Priority

The DeltaV Alarm Summary control includes a Zone column so that you can add it to alarm summaries to show the zone in which an alarm originates. The default versions of the alarm-related pictures (AlarmSum.grf, AlarmList.grf, AlmSupp.grf, and so on) do not include the Zone column. You may want to make your own versions of the alarm-related pictures to include the Zone column if your module and node name tags are duplicated between zones. Without the Zone column operators have no way of determining the zone in which an alarm is generated.

After you make new versions of the alarm-related pictures you will need to edit the UserSettings.grf picture and the layout template file to call your pictures instead of the default versions.
