Scenario 2: Remote workstation is in a workgroup and DeltaV Server is in a domain

Follow this procedure to configure the user accounts for workgroup-to-domain communication in a DeltaV Remote Workstation system.

In order to connect to the database server (the ProfessionalPLUS) from the remote workstation in a workgroup-to-domain environment the following items must be configured (following the steps will configure these items):

  • The Windows user on the remote workstation must have a Windows account on both the remote workstation and the DeltaV RAS server with the same username and password.
  • The Windows user on the remote workstation must have a DeltaV account on both the remote workstation and the DeltaV RAS server.
  • The DeltaV user on the remote workstation must have a DeltaV account and a Windows account on the server with the same username and password as on the remote system.
  • The Windows user on the remote workstation must exist on the DeltaV ProfessionalPLUS workstation and any other workstation to which you are acquiring data (for example, historical data from a historian on a different computer than the one to which you are connecting).
  • The DeltaV user on the remote workstation must have a Windows account on the remote system.
  • The remote workstation user (Windows account and DeltaV account) must be a member of all appropriate DeltaV groups on the non-remote DeltaV system (for example, must be a member of the DVBHisUser group if accessing DeltaV Batch Historian).
  • The local DeltaVAdmin account on the remote workstation must remain password synchronized with the local DeltaVAdmin account on the DeltaV node to which you are connecting AND to the domain DeltaVAdmin account on the DeltaV server.

Set up a remote system in a workgroup-to-domain configuration

  1. Create the Windows user account on the remote workstation using Windows User Manager:
    • Create the Windows user account on the remote workstation. Refer to your Windows documentation for details.
    • Add the user to the appropriate DeltaV Group (DeltaV, DeltaV Access, DeltaV Admins).
  2. Create the user accounts on the DeltaV server using DeltaV User Manager:
    • Create the Windows and DeltaV user accounts.
    • Use the same username and password for the DeltaV RAS server and Windows server accounts as on the remote account.
    • Set the DeltaV User Manager Computer/Domain option to <Unspecified>.
  3. Create the remote user as a local user on the DeltaV ProfessionalPLUS (if not the same computer as the DeltaV server).
  4. Create a local DeltaVAdmin account on the DeltaV node to which you are connecting. Set the password to match
    • The remote workstation's local DeltaVAdmin account.
    • The DeltaV domain-level DeltaVAdmin account.
