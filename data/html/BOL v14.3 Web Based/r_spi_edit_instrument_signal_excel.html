Editing instrument and signal data in Excel

After you have retrieved instrumentation configuration from SPI and saved it to the DeltaV database from the Data Manager you can edit the following items in Excel. Other rows and columns are visible, but do not edit them or delete them from the worksheet. To edit user-definable columns that are not included in the table (node, card, and channel, for example) it is more efficient and easier to make changes in DeltaV Explorer, then reload the controller into the worksheet.
