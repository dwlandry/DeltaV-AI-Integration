SLS 1508 logic solver level global secure parameter reference ItemIDs

ItemIDs for logic solver level global secure parameter references are of the form:

SISNET/SLxx/field

where:

xx is the Slot ID (33 through 64 for Domain Globals, 65 through 80 for System Globals)

The only field for this form is RSB_TYPE that sets whether the logic solver contains high-density (16) parameters or not. Values for RSB_TYPE are:

0 = the logic solver has 8 secure parameters.

1 = the logic solver has 16 high-density secure parameters. 

If you are not simulating high-density secure parameters you do not have to set RSB_TYPE because its default value is 0. However, if you are simulating high-density secure parameters you must set RSB_TYPE to 1 before setting other values. 

Note:

Because the valid range of status and revision values for secure parameters depend on whether the parameters are high density or not, it is recommended that you remove all items in a group before changing RSB_TYPE.

An example of this type of ItemID is:

SISNET/SL33/RSB_TYPE
