State information parameters (Smart Firewall)

A number of parameters hold state information in the firewall module. These parameters are not intended to be configurable.

For all the following parameters:
  • The parameter category is one of Alarm, Operating, Misc or none
  • Allow instance value to be configured is false (unchecked)
  • Restore parameter value after restart is false (unchecked)
  • The parameter filter is On-line

HACACTCNT

32-bit unsigned integer

0

The number of (unsuppressed) active hardware alarm conditions in the firewall. (The number of active conditions shown in the Condition Summary application for this firewall.)
