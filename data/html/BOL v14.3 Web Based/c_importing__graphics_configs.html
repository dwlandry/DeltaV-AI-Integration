Importing graphics configurations

Graphics configurations are imported into Graphics Studio through the Import pane, while workstations and configuration databases are imported into DeltaV Live Administration through the Import dialog.

The DeltaV Live import process imports .ahc files from their Windows folder into the active DeltaV Live configuration database, creating new configuration components or replacing existing ones within that database. You can import single .ahc files, all .ahc files within a selected folder or compressed folder, or migration-formatted DeltaV Operate graphics within a selected folder.

If a user has previously imported content from a workstation, both applications remember the import folder destination for that DeltaV user on that workstation and presents it as the default Import From path on the next import. You can also customize your import results using the Import Settings.

Only one import operation at a time can be performed in each instance of Graphics Studio or Workstation Management; however, you may continue to work on other tasks in these applications while an import is in progress. Other users may also continue to work in the configuration database during an import. Files replacing configurations that are open and unlocked for editing can still be imported because the import replaces the last saved version of a configuration already existing in the active database. However, imports fail for configurations that are "locked" for editing.

Import progress and results information

During and after the import process, Graphics Studio and Workstation Management provide updating information about the progress of the import, which includes:
  • Importing from: Total number of items to import and number of items remaining to import.
  • Import Started: Date and time the import started
  • Import Finished: Date and time the import finished
  • Import classification (New or Replaced)
  • Warnings (if any)
  • Import status (succeeded, failed, skipped)
Note: The Last Saved timestamp is determined by content in the .ahc file, not from the Windows Date Modified attribute, unless the Last Saved timestamp is omitted from the file content. In this case, the Windows Date Modified attribute is used as the Last Saved timestamp.
Tip:
  • You can stop an import while it is still in progress by clicking Stop in the Import pane. If you click Stop, the operation halts after the import process completes for the item currently being imported.
  • You can save the Progress/Results information for later by copying and pasting the data from the Import pane into another application, such as Notepad or Excel. This information remains available in the Import pane until you start another import operation or close the current instance of Graphics Studio.

If the .ahc file has been modified in a text editor, the import process ignores any unrecognized elements or properties found in the document. The document imports normally, omitting the unrecognized information. However, any unrecognized or out of range values found in the document are considered errors and cause the import to fail. When a file fails to import, it has no effect on the configuration database into which you are importing.

For example, assume that an .ahc file named Display1 contains a RoundedRectangle element whose Corner Radius property value has been edited to have an unrecognized decimal separator character. When importing Display1.ahc to replace Display1 in a configuration database, this unrecognized character is considered an error, and Display1.ahc fails to import. The existing configuration for Display1 is not affected.
