Defining unit properties - arbitration

Use the Arbitration tab to manage the use of shared plant equipment by batch recipes. Unit arbitration refers to how the unit is owned and released through different phases of the recipe. For example, Reactor Tank 1 is filled from Charge Tank A and Charge Tank B, but it can only be filled from one tank at a time. If Charge Tank A has not finished transferring the substance into Reactor Tank 1, then the step that controls discharging Charge Tank B must wait. How Charge Tank B waits is partially defined by the arbitration properties of Reactor Tank 1 (the components of waiting are controlled by how the phase logic and the recipe phases are defined).

All PLM-based units (as well as process cells and unit modules) configured in DeltaV Explorer are assigned a unique equipment ID. The DeltaV system uses these IDs to arbitrate equipment and service requests for ownership.

The Maximum Owners setting defines the maximum number of requesters that can simultaneously own or use the unit. Requesters can include (1) the operator acquiring the equipment directly, through the arbitration or phase control screen, (2) a recipe, which acquires units and phases as part of recipe operation, or (3) another equipment entity that has this unit identified in its Equipment Needed field and has been requested by one of the first two methods.

By default, this number is set to one, meaning that only one requester can own this piece of equipment at any one time. Increasing this number is not recommended for Phase Logic Modules since a phase logic module cannot be successfully run by multiple owners at the same time.

The Equipment Needed setting specifies additional equipment items that are required in order for this unit to execute and is needed only where equipment arbitration is an issue. You can assign needed equipment to a process cell, a unit, or a phase. The needed equipment items must be configured in DeltaV Explorer before they will be available in this dialog.

To define the arbitration properties of the unit, select an equipment ID from the list. Enter the maximum owners. If any additional units are required along with this unit, click the Add button and select the units needed. Click OK when done or go to the General tab.

Equipment ID: To define a unique ID for resources used in a Batch control, select an available number in the range of 1 through 65535 in the Equipment ID box. The system uses equipment IDs to acquire and release resources. The number specified here can be referenced by the phase logic modules and unit phases. The resources that have IDs are: units modules, process cells, unit phases, phase logic modules, equipment modules and control modules. Control and equipment modules must have equipment IDs when used for Batch control.

Maximum owners: Specifies the number of requesters that can use this resource simultaneously. Enter the number in the Maximum Owners box.

The maximum number of owners setting defines the maximum number of requesters that can simultaneously use the resource. By default, this number is set to one, which is sufficient for most applications. Increasing this number allows multiple requesters to use the resource simultaneously.

Note:

The same phase can not run more than once concurrently on a unit even if the maximum owners is set to more than 1. Maximum owners allows different recipes to own the same unit and run on that unit simultaneously.

Equipment needed: Displays the resources used by this resource. Before this resource can be acquired, it must first acquire all the items in Equipment Needed.

Add button: Adds a resource to the list. Click Add and browse for all the valid options. The valid options include unit modules, unit phases, phase logic modules, equipment modules and control modules.

Delete button: Deletes a resource from the list. Select the resource on the list and click Delete.
