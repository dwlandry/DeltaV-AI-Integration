SLS 1508 SIS Simulation system testing

You can test or verify the logic of SIS modules using the Debug and On-line View modes of Control Studio. Note that the On-line/Debug commands available for SIS modules are a subset of those available for DeltaV modules.

Note:

The testing covered in this topic is not the same as Functional Testing. Functional Testing is covered in the DeltaV SIS Safety Manual.

You can view and debug SIS modules from Control Studio whether the modules are downloaded to a simulated Logic Solver (a Logic Solver created in a workstation) or a physical Logic Solver card.
