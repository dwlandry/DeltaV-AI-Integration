MPCPro Disturbance Variable function block faceplate (MPCPROINPUT_FP)

DeltaV Operate View of the MPCPro Disturbance Variable Faceplate

A red border around the faceplate indicates this required input is disabled or has failed; a yellow border indicates a fail condition exists but the configured fail action is for no action (not required) or simulate.

The following items are found on the MPCPro Disturbance variable faceplate:

  • Disturbance variable – This field displays the DV value of the MPCPro module in yellow. The background color of the 3-D box changes from gray to orange or red when the DV status becomes uncertain or bad, respectively. The background blinks red when the DV Bad Alarm is unacknowledged. The DV value is visible in the decimal format provided by SCALE_ATTR_INn.A_UNITS.

  • Units  – This area provides the engineering units description used for the DV as defined in the SCALE_ATTR_INn.A_UNITS parameter.

  • Tick marks - Use this vertical arrangement of black lines to indicate percentages of DV. 

  • EU 100 – This value corresponds to 100% of scale for the DV.

  • Connected block mode – This field displays the actual mode of the connected block.

  • EU 0 – This value corresponds to 0% of scale for the DV.

  • Disable button - Disables or enables this output during control.

  • MPCOperPro button – Opens the MPCOperPro application for the block.

  • MPCDiagnostics button –  Opens the MPCDiagnostics application for the block.
