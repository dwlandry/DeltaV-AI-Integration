Implementing security for a DeltaV OPC UA server

When you implement security on the server, you need to perform the following tasks.

When using self-signed certificates:
  • Generate a self-signed certificate and assign it to the server
  • Exchange certificates with the clients
When using CA-signed certificates:
  • Import a CA-signed server certificate
  • Optionally, import CA CRLs.

To assign a CA-signed certificate to the server, you must send a certificate signing request to a third-party certificate authority. After receiving the signed-certificate from the CA, import it to the server.

Additionally, you can set up user authentication for the communications between clients and servers. User authentication requires that client/server communications use a DeltaV user account with OPC UA authority.
