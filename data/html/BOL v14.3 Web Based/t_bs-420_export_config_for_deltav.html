Export the BS-420 configuration

After you have completed the configuration of all the fire detection devices in the AutroSafe configuration tool you can export the BS-420 configuration for use in DeltaV Explorer.

Note:

You need to perform these steps on only one of the four Modbus units you have configured.

  1. In the left pane of the AutroSafe Configuration Tool select Autrocom TCP MODBUS SLAVE under the BS-420.
  2. In the right pane of the configuration tool, click Data.
  3. Click Generate Modbus Indexes.
  4. Click Export Modbus indexes.
  5. Save the file as a .csv file.
