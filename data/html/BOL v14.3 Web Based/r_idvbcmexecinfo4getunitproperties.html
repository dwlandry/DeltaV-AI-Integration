Public Sub GetUnitProperties(

ByVal bstrUnitId As String,

ByRef  vArea As Variant,

ByRef vPCell As Variant,

ByRef plResourceID As Long,

ByRef vUnitClass As Variant,

ByRef plMaxOwners As Long,

ByRef vOutOfService As Variant,

ByRef vAMMIPicture As Variant,

ByRef plAvailable As Long,

ByRef vArrayDownstreamUnits As Variant,

ByRef vArrayDownstreamUnitsID As Variant,

lWait As Long)

This method returns the properties of a unit with downstream units.

Return Values

S_OK - success

else - failed

Memory Allocation

The caller is responsible for releasing the vArrayDownstreamUnits and vArrayDownstreamUnitsID safearrays.

Visual Basic Usage Example

Private Sub Button1_Click()  
    Dim objUnitId As String
    Dim vArea As Variant
    Dim vPCell As Variant
    Dim plResourceID As Long
    Dim vUnitClass As Variant
    Dim plMaxOwners As Long
    Dim vOutOfService As Variant
    Dim vAMMIPicture As Variant
    Dim plAvailable As Long
    Dim vArrayDownstreamUnits As Variant
    Dim vArrayDownstreamUnitsID As Variant
    Call objUnitInfo .GetUnitProperties (bstrUnitId, vArea, vPCell, plResourceID, vUnitClass, plMaxOwners, vOutOfService, vAMMIPicture, plAvailable, vArrayDownstreamUnits, vArrayDownstreamUnitsID)
End Sub

Parameter Name

Purpose

bstrUnitId

The string of the unit's ID property.

vArea

The area where this unit is assigned.

vPCell

The process cell where this unit is assigned.

plResourceID

The unit's equipment resource ID.

vUnitClass

The name of the unit class from which this unit is derived.

plMaxOwners

The configured value of the MaxOwners parameter for this unit.

vOutOfService

The value of the MSTATE parameter for this unit (either In Service or Out of Service).

vAMMIPicture

The name of the display (MMI) picture configured for this unit.

plAvailable

The value of the $AVAILABLE parameter for this unit.

vArrayDownstreamUnits

Safearray of the names of the units configured as downstream of the current unit.

vArrayDownstreamUnitsID

Safearray of the IDs of the units configured as downstream of the current unit.

lWait

Optional. Default = 30000. Time to wait for a server resource in milliseconds.
