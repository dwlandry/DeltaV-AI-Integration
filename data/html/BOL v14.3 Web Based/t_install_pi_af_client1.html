Install PI AF Client support for embedded trend objects in DeltaV Operate

If you are using the Advanced Continuous Historian or an OSIsoft PI Server enterprise historian and configure an Embedded Trend object to display a trend chart of historical data in DeltaV Operate, you must install PI Asset Framework (AF) Client software on each DeltaV workstation where an Embedded Trend object is configured.

To install the PI AF Client, complete the following steps:

  1. Log on as a user with Windows Administrator account privileges.
  2. Insert the Advanced Continuous Historian installation disk in the drive.
  3. Click Start > Run.
  4. After the Run dialog appears, click the Browse button.
  5. Navigate to the Advanced_Continuous_Historian\AF Client folder.
  6. Select the PI-AF-Client_2016-R2-SP1_.exe setup program, and then click the Open button.
  7. In the Run dialog, click the OK button. In general, you can accept the defaults during the installation of the PI AF Client; for example, notification symbols related to the availability of optional PI AF Client features can typically be disregarded.
  8. When the Default Servers dialog appears, specify the name or IP address of a system where the Advanced Continuous Historian or PI Server is installed in the Default Data server field.

    If needed, you can specify additional systems from which to retrieve historical data for an Embedded Trend object in DeltaV Operate by using the PI SDK Utility to add them to the known servers table. To start the PI SDK Utility, click Start > PI System > PISDKUtility.

  9. When the Customer Experience Improvement dialog appears, read the scrolling text in the information window, and then select whether or not to participate in this program sponsored by OSIsoft. For additional considerations, consult with your system administrator.
