Finish the demotion

  1. Assign licenses for the Application Station as needed.
  2. Enable the Batch Executive (or Campaign Manager, or both) on the workstation (previously the preferred active).
  3. Download the workstation.

    If keeping both computers on the DeltaV network, you will need to

    1. Add the second computer (previously the preferred standby) to the control network in DeltaV Explorer.

    2. Assign licenses, enabled subsystems, and assign areas, modules, and so on, to the workstation as needed.

    3. Export the configuration file.

    4. Run Workstation Configuration on the workstation.

    5. Download the workstation.
