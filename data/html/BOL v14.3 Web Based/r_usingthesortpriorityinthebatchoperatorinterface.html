Using the sort priority in the Batch Operator Interface

In the DeltaV system, the Sort Priority defines the order of information in the following Batch Operator Interface screens:

  • Batch List

  • Unacknowledged Prompts

  • Alarm Summary

  • Active Phase Summary

  • Event Journal

You can also set the sort priority for the following auxiliary tabbed windows in the Procedure as PFC and Procedure as Table screens:

  • Prompts

  • Parameters

  • Reports

The Sort Priority for all screens is configured from the System Configuration and Defaults screen. The only exception is the Event Journal. A sort priority can be configured locally, in the Event Journal screen, for the current Event Journal file.

If batches have identical information in the first column of information sorted, the sort then proceeds to the second column of information in the list.

The data in the first column of information is sorted using the following criteria:

Sort Priority

Type of Data

1

Numerical data

2

Upper-case letters

3
