PST tab (LSDVC faceplate)



The following items are contained on the PST tab of the LSDVC function block faceplate:

  • PST state - A value field and text label for PST_STATE.

  • Run Manual Test button - Visible if PST_STATE is Idle or Armed.

  • Configured time between periodic tests - A text label and data entry box for PST_PERIOD_TIME.

  • Time until next periodic test - A text label and value field for PST_NEXT_TIMER is visible if PST_STATE is Armed.

  • Time since last successful test - A text label and value field for PST_SINCE_TIMER.

  • Alert Limit - A text label and data entry box for PST_REQ_INTERVAL.

  • PST Results - If supported by the field device, this indicates a user-configurable result of the most recent partial stroke test. The possible values are:
    • None - a PST has been started
    • Green - user configured in the device
    • Yellow - user configured in the device
    • Red - user configured in the device

  • PST Alerts - A text label that is always visible. The following messages may appear under PST Alerts, depending upon which bits are set in PST_ALERTS:

    • Last partial stroke test failed - Visible if that bit is set.

    • Last partial stroke test failed - Visible if that bit is set.

    • Last partial stroke test was denied - Visible if that bit is set.
