SIS module object syntax

Refer to the following table when creating format specification files for and bulk editing SIS modules.

Valid field values for SIS modules

Field

Valid Values

Required for Import

description

As many as 255 characters using any keyboard characters. Note that only the first 24 characters appear in faceplates.

No

logic_solver

The Logic Solver this module is assigned to. If the Logic Solver does not exist, the module is imported but not assigned.

No

area

Any valid area name. If the area does not exist or is not specified, the module is imported into AREA_A.

No

module_name

As many as 16 characters. The string must contain one letter and can include the following: $, -, _.

Yes

work_in_progress

T or F

No

module_type

A string containing any keyboard characters

No

module_subtype

An existing module subtype

Yes

primary_display

Any valid picture name

No

detail_display

Any valid picture name

No

faceplate_display

Any valid picture name

No

risk_red_factor

Risk reduction factor

No
