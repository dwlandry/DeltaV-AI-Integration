IP addressing for the Independent DeltaV Domain Controller

The Independent DeltaV Domain Controller (IDDC) uses the following IP address ranges. Please note that the IP address assigned to the NIC is a static address. The NIC uses IPv4 only. IPv6 is disabled for the DeltaV networks.

Tip: The Independent DeltaV Domain Controller does not support having connections to any network level other than the DeltaV ACN (L2). Therefore, you should uninstall drivers for any unused NICs (Network Interface Cards) in the computer. This prevents network routing from selecting an unused (disconnected) card.
