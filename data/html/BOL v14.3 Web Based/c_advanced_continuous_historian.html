The Advanced Continuous Historian

The Advanced Continuous Historian is powered by technology from OSIsoft. For DeltaV system upgrades, you can migrate to the Advanced Continuous Historian from the DeltaV Continuous Historian or from the Legacy Historian to continue using OSIsoft technology.

Note: The Legacy Historian is no longer supported as a DeltaV option.

The DeltaV Continuous Historian remains the default DeltaV system historian, but the Advanced Continuous Historian can be used in addition to the DeltaV Continuous Historian on a DeltaV Application Station. For all other DeltaV workstation types, the DeltaV Continuous Historian is the only historian selection. A DeltaV system can have multiple instances of the Advanced Continuous Historian and the DeltaV Continuous Historian, with the total number of historians limited only by the number of available DeltaV Application Stations. However, only one type of historian can exist on a single DeltaV workstation. The Advanced Continuous Historian can be configured for up to 60,000 parameters on each DeltaV Application Station.

The Advanced Continuous Historian is compatible with the following OSIsoft client applications:

  • PI DataLink
  • PI Manual Logger
  • PI to PI

These OSIsoft client applications are available on the Advanced Continuous Historian installation disk. Up to 10 copies of PI DataLink and up to two copies of PI Manual Logger can be used with the Advanced Continuous Historian in each DeltaV system. Other OSIsoft client applications are not compatible with the Advanced Continuous Historian.
