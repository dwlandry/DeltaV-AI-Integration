SIS module debugging

You can open any SIS module downloaded to a logic solver (CSLS or SLS 1508) in Control Studio Debug mode. In SLS 1508 simulation systems, you can open an SIS module downloaded to a workstation in debug mode. The Logic Solver must be unlocked for a module to be opened in Debug mode.

The debug commands available depend on what is selected and whether the SIS module is downloaded to a simulated Logic Solver or a physical logic solver. The following table summarizes the debug commands available for both.
