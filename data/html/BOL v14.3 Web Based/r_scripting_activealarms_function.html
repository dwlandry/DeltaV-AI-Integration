ActiveAlarms function

ActiveAlarms() returns the count of active alarms that are associated with the designated display and, optionally, within the specified priority level range.
Arguments
1–4, Optional arguments are indicated by a ? following the argument name.
Argument Description
DisplayName A literal or graphics expression that resolves to the name of a display.
ChildDisplays A literal or graphics expression whose value is interpreted as true or false. When evaluated to:

True, the return count includes active alarms for the specified display, as well as from all direct and indirect child displays of the specified display in the display set.

False, the return count includes active alarms in only modules, nodes, and devices whose primary control display is the specified display.

If this argument is omitted or undefined, the assumed value is false.

MinPriority A literal or graphics expression whose value is interpreted as a minimum priority level number. When this argument is present, the count returned includes only active alarms whose priority level is greater than or equal to this value. If this argument is omitted or undefined, the assumed value is the minimum active alarm priority.
MaxPriority A literal or graphics expression whose value is interpreted as a maximum priority level number. When this argument is present, the count returned includes only active alarms whose priority level is less than or equal to this value. If this argument is omitted or undefined, the assumed value is the maximum active alarm priority.
Return values (number)
The number of active alarms that satisfy the argument criteria.
0, if DisplayName is not a primary control display for some module, node, or device in this DeltaV system.
0 with a bad data quality status, if DisplayName cannot be resolved.
Syntax
DARU.ActiveAlarms(DisplayName, ChildDisplays, MinPriority, MaxPriority)
Examples
Example Result 
DARU.ActiveAlarms(DL.DN("Reactor1"))
 Shows the number of active alarms on the Reactor1 display. 
DARU.ActiveAlarms(Gem.DisplayName, true, 12,15);
 Shows the number of active alarms with a priority of 12 through 15 for all modules, nodes, and devices associated with the ??? display and its child displays.
