Customizing the Process History View

The Process History View Command Line Interface (CLI) allows you to customize the initial startup of the DeltaV Process History View from DeltaV Operate. Its primary purpose is to enable you to create Operator Interface toolbar buttons or other pictures to launch Process History View in context with the picture currently displayed in Operator Interface.
