Advanced switch configuration (serial port interface)

  1. If you entered Y at the previous prompt the switch responds with: 
    Entering Advanced configuration. If you hit <Return> at any of the
questions the corresponding value will not be changed. Entering
0.0.0.0 as an IP address will clear the current setting. Entering q
will quit the wizard without further action.
    and prompts you in turn about advanced configuration items.
    Note:

    Only make changes to the user account passwords or UTC offsets. All other configuration is performed using the Network Device Command Center.

    • Change the default admin password.
      Note: If you change the admin password you must not forget it. To recover, you must restore the switch to its default settings, then recommission the switch. This restores the admin password to the default of Emerson1.
    • Change the default user password.
    • Set the local offset to UTC (Universal Coordinated Time) in minutes.
  2. At each option prompt, to continue without making a change, press Enter. Otherwise, press Y or N or enter a value to set the option.

    After all the advanced questions have been answered, you must answer yes (by pressing Y) to save the configuration. If you answer no (by pressing N) or press Enter, the setup, including the initial setup is not saved.

  3. To view current information about the switch, including the IP address, switch name and location, enter show sysinfo. The setup is not saved if the Configuration state is not in sync. To save the configuration, enter DeltaV at the switch prompt.

    This completes advanced switch configuration.

  4. Disconnect the serial cable.
