Logic Solver Lock and Unlock functions

The CSLS must be unlocked to commission, decommission, download, debug SIS modules and allow HART write commands. Locking also prevents a user-initiated logic solver switchover.

The Lock and Unlock functions are software-based. You lock and unlock the CSLS in DeltaV Explorer through the CSLS context (right-click) menus.

Physical key switches

The physical key switches on the CSLS carrier and SIS Controller carrier can be used to allow or prevent users from using the Unlock function. The key switches require physical presence by plant personnel. The Unlock software function works in conjunction with the physical key switches as described below.

CSLS physical key-switch

Enable or disable the physical key switch by selecting or clearing the Enable Key-Switch checkbox on the CSLS Properties dialog (Security tab).

If the key-switch is enabled, it must be in the unlocked position for the Unlock software function to work.

SIS Controller physical key-switch

The Keylock Ethernet Isolation Port (EIP) module enables the physical key switch on the SIS Controller carrier. When enabled by the Keylock EIP, the key switch on the carrier inhibits the unlock function for all assigned CSLSs. This enables you manage the unlock function for several CSLSs from one location.

If the Keylock EIP module is installed, key-switch functionality is enabled for the SIS Controller. There is no software means to enable or disable the functionality for the SIS Controller key switch.

Typically, you would use either the key-switches on the CSLSs or the key-switch on the SIS Controller to manage the unlock inhibit functions. For example, if you have the Keylock EIP module installed on your SIS Controller carrier, turn the key switch on the SIS Controller carrier to the locked position and turn all the assigned CSLS key switches to the unlocked position during normal operations. When you need to use the Unlock software function, turn the key switch on the SIS Controller carrier to the unlocked position.

If you do not have the Keylock EIP module installed in the SIS Controller carrier, turn the CSLS key switches to the locked position during normal operations (if physical presence is required at your site to inhibit the unlock software function). Turn the key switch on a particular CSLS when you want to use the Unlock software function for that CSLS.

CSLS key-switch single unlock function

You can use the unlock inhibit key switch on the CSLS carrier to perform a single software unlock. This enables you to allow unlock for the CSLSs without having to go back and turn the key switch to the locked (inhibit) position. It also reduces the chances of leaving the key switch in the unlocked (allow) position. To enable a single-unlock function, turn the key switch to the unlock position until the LED flashes red on the active CSLS. Then, turn the key switch back to the lock position. The LED will flash red (at a faster rate) before turning off to indicated that the CSLS is in the single unlock allowed state. You will then be able to perform one software unlock function within the next five minutes. The CSLS automatically returns to the unlock inhibited state in five minutes (or immediately after a software unlock occurs). At an appropriate time, you can lock the CSLS, knowing that the keys switch is in the locked position.

Note: The single unlock functionality requires CSLS major revision 2 or higher.

SIS Controller Auto Lock function

The Auto Lock function automatically returns the SIS Controller to the Locked (inhibit) state after a user-configured time has expired. This prevents the controller from remaining in the Unlocked (allow) state indefinitely. When the Auto Lock function is enabled, users do not have to remember to return the controller to the Locked state.

You enable and configure Auto Lock on the SIS Controller Properties dialog (Security tab). Use the dialog to enable the Auto Lock function and to set a time after which the controller returns to the Locked state.

CSLS Unlocked Alert

The CSLS Unlocked Alert occurs when either the CSLS or SZ controller's key switch is in the unlock inhibit position, CSLS is unlocked and the configured time of CSLS unlocked alert has been exceeded.

You enable and configure CSLS Unlocked Alert on the SIS Controller Properties dialog (Security tab). Use the dialog to enable the function and to set a time after the alert occurs.
