Implementing CHARMs Smart Logic Solver systems

The following list is a suggested order to perform the tasks required to install, setup, and configure a DeltaV SIS CSLS system:
  • Install the DeltaV hardware.
  • Install the DeltaV software and set it up for your needs.
  • Enable CHARMs Smart Logic Solvers in System Preferences.
  • Create user accounts and grant at least one user the keys to DeltaV SIS locks.
  • Assign DeltaV SIS keys and locks as needed.
  • In DeltaV Explorer, configure the SIS Controllers and CSLSs you need.
  • Configure LS CHARMs as required.
  • Assign CSLSs.
  • Commission CSLSs.
  • Create SIS modules to execute the logic your safety strategy requires.
  • Create operator graphics for your SIS system.
  • Download the configuration.
  • If necessary, use DeltaV diagnostics to troubleshoot your DeltaV SIS CSLS system.
