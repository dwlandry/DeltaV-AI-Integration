Deleting non-SIS modules and their assignments

Modules and their assignments can be deleted in DeltaV Explorer without having to delete the assignment separately. This is done through the Delete module dialog.

The Delete module dialog in DeltaV Explorer allows you to do the following:
  • Remove the associated non-SIS module assignment/s (if any)
  • Stop and remove the runtime non-SIS module/s from its assigned node
  • Delete the module/s from the currently active configuration database
  • Check for references

Checking references allows you to see the is used by references that would be broken should the selected module(s) be deleted and then adjust the 'deletion plan' accordingly in order to avoid creating broken references between modules.

Use the Delete Assignment option in the right-click context menu to delete only the assignment or Delete from Controller in the right-click context menu of the hierarchy.

Modules can still be deleted from a controller or module assignments deleted separately using the right-click context menu in the DeltaV Explorer hierarchy.
