Bulk edit SLS 1508 logic solver cards

SLS 1508 logic solver cards do not have card-level parameters so you can use the Card.fmt format specification file included with the DeltaV software to export and import Logic Solver card data. If you do create your own format specification file, note that the Object type you specify is card (the standard fields for Logic Solver cards are the same as for Local I/O cards).

When you create Logic Solver cards with bulk edit, remember that they use two slots (four for redundant cards) and that they must start in an odd-numbered slot.

To successfully import bulk edited cards, the node to which you are assigning the cards must be defined in the database.

The general procedure to bulk edit Logic Solver cards is:

  1. Create one Logic Solver card.
  2. Use the Card.fmt format specification file to export the card or create your own format specification file.

    Format Specification Files can allow existing card configurations to be overwritten in the database but you can prevent this by specifying information that must exist.

  3. Edit the cards in the bulk edit Excel template.
  4. Import the cards.
