Alias and formula syntax tables

Refer to the following tables when creating format specification files and editing data for formulas and aliases. For object syntax tables for process cells, unit modules, equipment modules, and control modules, refer to the appropriate section.

Valid Field Values for Formulas

Field

Valid Values

Required for Import

description

As many as 255 characters using any keyboard characters.

No

recipe_name

34 characters or fewer. This string must contain at least one alphabetical character and can include the following characters: $, -, and _.

Yes

formula_name

64 characters or fewer. This string must contain at least one alphabetical character and can include the following characters: $, -, and _.

Yes

version

As many as 20 characters using any keyboard characters. This string is the Description field in the Properties dialog.

No

operator_can_download

T = Released

F = Not released

No

Parameter list

Depends on subtype

No

Note that for an import or export of a formula to succeed, batch parameters must already exist.
