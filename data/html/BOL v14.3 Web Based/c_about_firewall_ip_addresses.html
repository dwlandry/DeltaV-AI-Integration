IP configuration for the firewall IPD

The firewall IPD is configured with the default subnet mask 255.254.0.0. Refer to KBA NK-1600-0290 for the default root and management password.

The firewall IPD supports the following ranges of IP addresses:

  • Primary network - 10.5.128.16 to 10.5.128.47
  • Secondary network - 10.9.128.16 to 10.9.128.47

For initial IP configuration, connect a PC with terminal emulation to the firewall IPD serial port. After you configure the IP address, you can use a Management station to manage the firewall IPD. The Management station can reside on the DeltaV network connected to the Primary and Secondary switch (a connection for each of two NIC cards in the PC) or it can be a standalone PC on a bench setup. In either case, the Management station's Primary NIC must have its IP address set up for the Primary network (this is usually 10.4.128.xx where xx is 16 to 254). After the primary IP address from the approved address list has been assigned through the serial port, the Management station can communicate with the firewall IPD. Refer to the DeltaV TM M-series Hardware Installation and Reference manual for information about the Management station.

Note: The firewall IPD does not respond to ICMP Echo requests (pings).
