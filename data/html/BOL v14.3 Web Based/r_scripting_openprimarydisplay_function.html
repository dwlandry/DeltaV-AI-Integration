OpenPrimaryDisplayAsync function

OpenPrimaryDisplayAsync() opens the primary control display configured for the specified module, device, or node name.
Arguments
1–4, Optional arguments are indicated by a ? following the argument name.
Argument Description
module name A literal or graphics expression that resolves to the name of a DeltaV module, node, or device, if the primary control display name configured for that module, node, or device matches the name of a display.
placement? A Placement object or array of Placement objects whose values define the initial placement of the primary display when it opens. The Placement objects override the default pop-up window placement rules.
X? A number indicating the X coordinates for the primary display's trigger point.
Y? A number indicating the Y coordinates for the primary display's trigger point.
Return values (Promise object, that when resolved, returns a Boolean)
True, if module name (case-insensitive) matches a running DeltaV module, node, or device name, AND the primary control display name (case-insensitive) configured for that DeltaV module, node, or device matches the name of a published display available to be opened by this instance of DeltaV Live.

False, otherwise.
Syntax
DL.OpenPrimaryDisplayAsync(moduleName, placement?[], X?, Y?)

Examples
Example Result 
if (!await DL.OpenPrimaryDisplay(Dsp.Context)) {
     // do something dealing with the display not being found
}

// direct display to open in specific Display Frame
let pos = new Placement(
PlacementOption.FullDisplayFrame, "ParkIt_1");
DL.OpenPrimaryDisplayAsync(DL.DN("FIC-101"), [pos]);

// direct display to open in pop-up centered on specific Screen2
// in Layouts that have it, falling back to centered on Screen1
let posPrefs = [];
let pref1 = new Placement(PlacementOption.Screen, "Screen2");
pref1.Alignment = PlacementAlignment.Centered;
pref1.UseCachedPosition = false;
posPrefs.push(pref1);
let pref2 = new Placement(PlacementOption.Screen, "Screen1");
pref2.Alignment = PlacementAlignment.Centered;
pref1.UseCachedPosition = false;
posPrefs.push(pref2);
DL.OpenPrimaryDisplayAsync(DL.DN("FIC-101"), posPrefs);
Note:
  • This function has no effect if a primary control display cannot be resolved for the module name argument, or if that display is not available for this workstation/session because it is not included in the active display set.
  • It is recommended that you use the DL.DN function fro the module name to enable display and display frame rename tracking.
