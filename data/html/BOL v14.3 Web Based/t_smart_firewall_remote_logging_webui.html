Configure Emerson Smart Firewall remote logging using its WebUI

This procedure uses the Smart Firewall's WebUI to configure the Smart Firewall for use with a syslog server.

There are many types of syslog server software packages available, from no cost, open source versions to more costly private versions. If your IT department does not have a syslog server preference, we suggest that you install a simple syslog server, such as the free KIWI Syslog Server and use it to collect and archive firewall logs for security analysis.

Note:

Users are responsible for acquiring the syslog daemon and must install and run the syslog daemon per the manufacturer's instructions.

Emerson provides no support or warranty for any syslog daemon. The KIWI Syslog Server has been tested to work with the DeltaV system and the Emerson Smart Firewall. The free KIWI Syslog Server for Windows is available at http://www.kiwisyslog.com/.

Refer to the Emerson Smart Firewall's WebUI help for any additional information.

  1. Connect to the firewall from a browser using the firewall's IP address.
  2. Open the Configuration tab and choose Logging.
  3. Select the Logging facility for UI events.

    This is the category assigned to firewall events. It is a label only and does not affect how events are logged. The default facility is User. You might change this if User is already assigned to a different group of events in your system log.

  4. Select Enable to turn on remote logging.
  5. Enter the name or IP address of the remote server (normally on the DeltaV 2.5 LAN) to which the log will be saved. This is the same computer as where the syslog server is installed.
  6. Select the minimum priority level for events that are sent to the remote log. It is recommended this be set to Debug.
  7. Click Apply.
  8. Close the web browser when all changes are complete and applied/saved.
