Recipe Studio

The Batch Operator Interface uses procedural function charts (PFCs) built in the Recipe Studio application. The PFCs developed in Recipe Studio interact with the Batch Operator Interface in the following manner:

  • A batch executes based on how the PFC was designed in Recipe Studio.

  • The Batch Operator Interface application displays the PFC, allowing the operator to view each step of the batch process. The recipe must be assigned to a Batch Executive to be added as a batch in the Batch Operator Interface.
