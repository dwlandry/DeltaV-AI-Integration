10-Pin Mass Termination Block

The 10-pin mass termination block is used for relay panels or optically isolated panels. The 10-pin assembly provides an interface to many off-the-shelf, 8-channel PLC terminations and to other termination panels that use a 10-pin cable pin out.

The two-row header accepts a 10-pin 0.093 mm2 (28 AWG) ribbon cable with 2x5 header connectors (AMP part #1658622-1, Strain Relief #499252-5) that can interface to a Phoenix Contact UMK-8 RM Series VARIOFACE output module or other similar modules.
