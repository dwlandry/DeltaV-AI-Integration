Setting up each Batch Operator Interface

Operators can use the Batch Operator Interface to schedule and run batches. Typically, the Batch Operator Interface runs on an Operator Station, separate from the ProfessionalPLUS and Batch Executive workstations.

When setting up each Batch Operator Interface, you need to follow these steps:

  1. Setup the workstation using DeltaV Workstation Configuration application (Start > DeltaV Installation > DeltaV Workstation Configuration).
    Note:

    You must create a workstation configuration file from your ProfessionalPLUS workstation and use that for installing the Workstation Configuration on the Batch Operator Interface computer.

  2. Verify the Batch Operator Interface workstation is communicating on the DeltaV network.
  3. Start the Batch Executive (using the Application Manager).
  4. Start the Batch Operator Interface. 
  5. Select the Batch Executive node to connect to. You can now run a batch using the Batch Operator Interface.
