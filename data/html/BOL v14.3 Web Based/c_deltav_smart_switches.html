DeltaV Smart Switches

DeltaV Smart Switches are used in DeltaV Control Networks. The DeltaV Smart switches are

  • DeltaV MD base Smart Switches and media modules
  • DeltaV RM100 base Smart Switches and media modules
  • DeltaV RM104 base Smart Switches and media modules
  • DeltaV FP20 8-port Smart Switches

By default, Smart Switches work in a plug and play mode as unmanaged switches without requiring any setup or configuration. When you commission the switches using the Network Device Command Center (NDCC) the switch is given a network address and associated with a control module so that switch hardware conditions can be interpreted as DeltaV alarms. Commissioning also provides access to switch and network diagnostics and to the security lock-down capability.

DeltaV Smart Switch features include:

  • Easy switch commissioning using the Network Device Command Center.
  • DeltaV Smart Switch diagnostic tools using DeltaV-integrated Network Device Command Center.
  • Support for PlantWeb-style hardware alarms driven by alert conditions detected in DeltaV Smart Switches.
  • Easy security using the patented auto-lockdown of unused switch ports.
  • The Network Device Command Center (NDCC) application that is the user interface for switch commissioning, locking and unlocking switches, and viewing diagnostic information.
  • Control function block module classes that hold the DeltaV configuration for DeltaV Smart Switches. Switch modules (one for each switch) are instantiated from these classes and run in ProfessionalPLUS or Application Stations. The modules detect active Hardware Alarm Conditions (HAC) based on real-time information read from Smart Switches.
