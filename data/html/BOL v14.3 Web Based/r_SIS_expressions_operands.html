Operands in Logic Solver Expressions

Operands can be any of the following:

  • Constants - an unchangeable value.

  • Inputs - references to Logic Solver Calc/Logic (LSCALC) block inputs (IN1..IN16, float with status).

  • Outputs - references to Logic Solver Calc/Logic (LSCALC) block outputs (OUT1..OUT16, float with status).

  • Module – references to module parameters that reside in the same module as the given expression.

  • Temporary variables.
