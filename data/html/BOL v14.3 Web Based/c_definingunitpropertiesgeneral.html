Defining unit properties - general

Set the general properties of the module on this dialog.

Phase class: The name of the parent class. This field cannot be changed.

Description: A brief description of the module.

Work in progress: The modules that are not yet completed. It works in two ways:

  • First, if a user requests a download that would include this module, the system indicates modules that have Work in progress checked. This alerts the user that a download might not be appropriate for this module.

  • Second, Work in progress can be used as search criteria when opening a module in Control Studio. To find the Work in progress modules, click the Main button, click Open, then click the Find button. (From DeltaV Explorer, select Edit > Find from the menu.)   The resulting dialog enables you search for Work in Progress modules. Set the condition to either Matches or Is Not, and enter a value of either True or False. The value corresponds to the condition. Click Find Now.

Simulate: Determines if the Batch Executive or the Recipe Simulator will run the module. If selected, the module can be simulated with Recipe Simulator.

Restore parameter values after restart: Retains the online parameter value changes for Batch input and report parameters in nonvolatile memory.
