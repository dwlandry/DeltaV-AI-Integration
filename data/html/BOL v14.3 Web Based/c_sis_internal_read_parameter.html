SIS internal read parameter

An Internal Read Parameter provides a connector from which you can wire on a function block diagram. The parameter connector is not visible outside of the block or module by default. You can use the Show Parameter function to make an Internal Read Parameter appear as an input connector on a composite block. An Internal Read Parameter can be one of the following types:

  • Floating point with status — a floating point value with a status indicator.

  • Boolean with status — a True or False value with status indicator.

  • 32-bit unsigned integer with status — a whole number without a positive or negative sign associated with it with a status indicator. 

  • Named Set — a value from 0 to 255 that displays an assigned text message.

You configure the restart characteristic for this parameter. The options are Restore parameter value after restart or Preserve parameter value on download.

For major revision 2 and later CSLSs, you configure the write access characteristic for this parameter. The options are Not Writeable, Writeable or Not Operator Writeable When Locked. The Writeable option enables an LSCALC block to write to the internal read parameter. The Not Operator Writeable When Locked enables an operator to write to the internal read parameter if the CSLS is unlocked.

Using an internal read parameter to write to a function block

For example, the user needs to write to the NUM_TO_TRIP parameter on a discrete voter block. First, the user exposes the NUM_TO_TRIP parameter using the Show context command on the block. Then, the user adds an internal read parameter to the module with write access configured as Writeable or Not Operator Writeable When Locked.
