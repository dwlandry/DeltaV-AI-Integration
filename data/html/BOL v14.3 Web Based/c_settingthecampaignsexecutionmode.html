Setting the campaign's execution mode

The final step after adding the campaign to the server is to set the campaign's execution mode. The SetExecutionMode4 method can be called from the IDVBCMCampaignEdit4 interface. The SetExecutionMode4 function takes nine possible parameters. The first three are Boolean flags and are listed as follows:

IsManual

IsAutoRelease

IsAutoStart

If the IsManual flag is set to TRUE then the two other Boolean flags will be ignored and the execution mode will be manual. If the IsManual flag is FALSE, then one or both of the IsAutoRelease and IsAutoStart flags can be set to TRUE.

If the IsAutoRelease flag is set to TRUE then, as batches become available, they will be released automatically to the Batch Executive.

If the IsAutoStart flag is set to TRUE, which implies the IsAutoRelease, then batches will automatically be released and started on the BatchExecutive.

To have the Campaign Manager server automatically remove completed batches from the Batch Executive, use the SetAutoRemove3 method on the IDVBCMCampaignEdit4 interface. The first four parameters to SetAutoRemove3 are three Boolean flags and a Long Integer. This method will associate the automatic removal of batches with the campaign's execution mode (that is, based on which execution mode the campaign is currently in, the automatic removal of completed batches may be enabled or disabled). The first Boolean parameter will enable automatic removal of completed batches when the campaign is in manual mode, the second and third perform the same action for the AutoRelease and AutoStart modes, respectively. The Long Integer parameter determines the number of minutes the Campaign Manager server waits before attempting to remove a completed batch.

Note:

It is important to auto remove batches if they are set to auto start so the Batch Executive batch list does not get too large.

In certain extreme cases, it may be necessary for the Campaign Manager server to forcibly place running campaigns into Manual mode. In these cases, the automatic removal feature will be turned off by the server if it is enabled for Manual mode.

The following is an example of how to set the campaign's execution mode and add the campaign to the Campaign Manager server.

Private Sub SetCampaignExecutionMode(ByRef objCampaignEdit _
    As IDVBCampaignEdit4)
    Dim bIsManual As Boolean
    Dim bIsAutoRelease As Boolean
    Dim bIsAutoStart As Boolean
    Dim bRemoveManual As Boolean
    Dim BRemoveAutoRelease As Boolean
    Dim bRemoveAutoStart As Boolean
    Dim lRemoveMinDelay As Long
    Dim sOperatorName As String
    Dim sOperatorPassword As String
    Dim sVerifierName As String
    Dim sVerifierPassword As String
    Dim sComment As String
    ' Prompt user for Auto Remove
    Call PromptUserForAutoRemove(bRemoveManual, bRemoveAutoRelease, _
        bRemoveAutoStart, lRemoveMinDelay, sOperatorName, _
        sOperatorPassword, sVerifierName, sVerifierPassword, sComment)
    ' Set the campaign's AutoRemove properties
    Call objCampaignEdit.SetAutoRemove3(bRemoveManual, bRemoveAutoRelease, _
        bRemoveAutoStart, lRemoveMinDelay, sOperatorName, _
        sOperatorPassword, sVerifierName, sVerifierPassword, sComment)
   ' Prompt user for execution mode
    Call PromptUserForModes(bIsManual, bIsAutoRelease, bIsAutoStart, _
        sOperatorName, sOperatorPassword, sVerifierName, _
        sVerifierPassword, sComment)
    ' Set execution mode
     Call objCampaignEdit.SetExecutionMode4(bIsManual, bIsAutoRelease, _
        bIsAutoStart, sOperatorName, sOperatorPassword, sVerifierName, _
        sVerifierPassword, sComment)
End Sub
