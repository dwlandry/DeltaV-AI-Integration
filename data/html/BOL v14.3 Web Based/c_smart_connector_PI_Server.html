DeltaV Smart Connector for OSIsoft PI Server

The DeltaV Smart Connector is used to collect configuration and process data from the DeltaV system and populate this data in the OSIsoft PI Server. The DeltaV Asset Connector is a component of the DeltaV Smart Connector and is used specifically for transferring DeltaV parameter configuration data to PI Server. The DeltaV Asset Connector automatically creates and configures attributes on the configured parameters based on the data contained in the PI Server configuration file. The following table lists the DeltaV parameter attributes and the source of their property values from the historian configuration file.

Tag Name <PATH>Tag name </PATH>
Scan <ENAB> Enabled </ENAB> (Value of 1 or 0)

The Scan attribute of a parameter may also be set to 0 if a tag that was previously in the historian configuration file is removed from history collection.

CompDev/Compressing <CDEV> Compression Deviation </CDEV>

If CDEV is set to –1, the Compressing parameter attribute is set to 0.

If CDEV is not set to –1, the Compressing attribute is set to 1 and the CompDev attribute will be set to the value of CDEV.

Step <STEP> Step </STEP>

If the DeltaV STEP value is 0, the Step attribute is set to 1.

If the DeltaV STEP value is 1, the Step attribute is set to 0.

If the DeltaV STEP value is 2 and the parameter type is Integer, the Step attribute is set to 1.

If the DeltaV STEP value is 2 and the parameter type is Float, the Step attribute is set to 0.

Note:

If the DeltaV Asset Connector receives an invalid point type value in the historian configuration file, it log an error and do the following:

  • If the corresponding point does not already exist, an error will be logged and the historical parameter will not be created.
  • If the corresponding point already exists, the DeltaV Asset Connector does not edit its configuration and only outputs an error message to the log file.
Additionally, all attributes of a point with an invalid point type listed in the historian configuration file will be written to an Error Tag.csv file so that the one or more parameter configurations can be reviewed and/or corrected at a later time.
