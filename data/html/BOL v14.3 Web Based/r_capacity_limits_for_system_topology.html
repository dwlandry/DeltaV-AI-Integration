Capacity limits for system topology

Description of system capacity Limit

Control Network nodes

120

Controller node limit

This is the total simplex and redundant controllers per control network (each redundant controller pair counts as a single node).

1001

Combined number of the following: Remote I/O nodes, Ethernet I/O Cards (EIOCs), CHARM I/O cards (CIOCs) and Wireless I/O cards (WIOCs) in a system

300

EIOCs

603

Number of Wireless Gateway nodes per Wireless I/O network

Workstations per Control Network

(non-remote)

65 workstations4 consisting of:
  • 1 ProfessionalPLUS workstation
  • Up to 10 Professional Stations
  • Up to 59 Operator, Maintenance and/or Base Stations
  • Up to 20 Application Stations5

Remote workstations (using Remote Access Services or RAS) per system

20 remote workstations on each of 6 Application Stations (where 1 is a Remote Application Station and 19 are Remote Operator Stations)

2 remote workstations on the ProfessionalPLUS

Application Stations set up as RAS servers

6

where 1 additional RAS is the ProfessionalPLUS

DeltaV Remote Clients

(using Windows Remote Desktop Connection and a Remote Desktop Services server)

7,200 graphic data links on all displays open through a Remote Desktop Services server6

60 database connections per Remote Desktop Services server7

15 concurrent sessions per Remote Desktop Services server8

Maximum number of client sessions (# of connections) attaching to a remote workstation

This affects any client retrieving information where the source of that information is on a remote workstation, including but not limited to: Process History View and Batch History View

10

DSTs per system  

30,000 DSTs distributed among controllers and Application Stations

SCADA tags per system

25,000 (recommended)

Inter-Zone Servers

DeltaV Zones (including the current system)

1 This is a fixed system limit that includes SZ controllers. The system does not permit the configuration of more than 100 controller nodes.
2 Additional -not counted against the controller node limit.
3 This is a fixed system limit. The system does not permit more than a maximum of 60 EIOCs in the I/O network.
4 This is a fixed system limit. The system does not permit the configuration of more than 65 workstation nodes.
5 A pair of Application Stations with a redundant subsystem enabled counts as one workstation.
6 Graphic updates slow considerably when the total data links exceeds 7,200. No warning message is given.
7 If this database limit is reached, a message warns that the application can't connect to the database and it shuts down.
8 This is a tested limit, not a fixed limit.
