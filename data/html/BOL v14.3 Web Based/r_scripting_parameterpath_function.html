ParameterPath function

ParameterPath() extracts and returns the full path of the specified parameter name from a DeltaV parameter path string.
Arguments
1
Argument Description
path string A full or partial DeltaV parameter path.
Return values (string)
The substring preceding the first field delimiter, when a field delimiter (.) is present.
The full argument string, otherwise.
Syntax
DLPATH.ParameterPath(path string)
Examples
The following examples demonstrate how to extract the full path of a parameter name and show it as the label on a text element.
Example Result 
DLSYS.Text1.Label = DLPATH.ParameterPath
("ZONE1%FIC101/PID1/MODE.ACTUAL.STR")
 Returns "ZONE1%FIC101/PID1/MODE" as the label text. 
DLSYS.Text2.Label = DLPATH.ParameterPath("THISUSER/ALMCNT[12][15].CV")
 Returns "THISUSER/ALMCNT[12][15]]" as the label text. 
DLSYS.Text3.Label = DLPATH.ParameterPath("TIC200/BLK1/BLK2/OUT")
 Returns "TIC200/BLK1/BLK2/OUT" as the label text. 
DLSYS.Text4.Label = DLPATH.ParameterPath("ALARMS[1].PRI")
 Returns "ALARMS[1]" as the label text.
Note: If the argument path includes array parameter syntax, that syntax is included in the returned parameter path.
