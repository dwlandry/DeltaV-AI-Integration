Batch Executive action confirmation

The Action Confirmation functions are configured for each Batch Executive. As a Batch Operator Interface (or other Batch Executive client) connects to the Batch Executive, it inherits the configuration of the Batch Executive for Action Confirmation. 

By default all commands display a prompt requiring a Yes response before the command is initiated. For example, when an operator adds a batch to the batch list, by default the system displays a dialog asking if the user wants to add the batch. The operator selects Yes or No. Yes allows the command to execute and the batch is added to the batch list. Clicking No cancels the command and the batch is not added. Using the Batch Executive Action Confirmation tab, you can set which commands display a prompt. For example, you want to prompt operators before they start or stop a batch because they are essentially irreversible actions, but you do not want to prompt operators before holding a batch, which is a temporary action. Therefore, you would enable prompts on the Start and Stop commands and disable prompts for the Hold command.

There are two additional action columns, one for Confirm and the other for Verify. Confirm is the first level of validation for a command, usually at the operator level, to confirm the action by entering a username and password. Verify is the second level of validation (usually at the supervisor level) and requires that Confirm also be selected. Verify requires the user have the BATCH_ACTION_VERIFY key. The confirmer and verifier can be the same person. The Electronic Signatures Properties dialog in the DeltaV Explorer is used to configure confirmer and verifier to be the same person.

Action Confirmation Properties of the Batch Executive

To configure confirm and verify for phase parameters (when the phase is in manual control), select the Prompts check box on the configuration dialog. When the phase is run manually, the operator will be prompted for a confirmation and verification on phase parameters.

Note:

Prompts that are coded in phases using phase request codes ignore the Batch Executive Action Configuration selection.
