Zone 1 Enclosure specifications

The Zone 1 Carrier is installed on a panel in a customer-supplied enclosure with the appropriate certifications for the installation environment. Refer to document 12P3292, DeltaV Type KJ7000 Series Zone 1 I/O System Installation Instructions for certification requirements for the enclosure. This document can be found on the DeltaV Documentation Library DVD. This document is in Portable Document Format (.PDF). A letter (A-Z) is appended to the filename and is incremented for each release of the document. The following figure shows a fully-loaded Zone 1 Carrier installed in a typical enclosure.
