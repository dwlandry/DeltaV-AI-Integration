Creating link groups

Link groups can only occur between phases that are in the same recipe and of the same recipe level. If the current level is an operation, the only valid phases for link groups are phases in the current operation. If the current level is a unit procedure, the valid phases for link groups are phases found in any operation referenced by steps in the unit procedure. If the current level is a procedure, the valid phases for link groups include all phases found in any unit procedure referenced by steps in the procedure and any operations referenced by the steps in the unit procedures. In other words, the valid phases follow the hierarchy down all the recipe levels.

This means that the number of valid phases for a link group becomes greater the higher up the recipe level hierarchy you go. You can create a link group from any phases that are referenced (either directly or indirectly by drilling down into the components) by the recipe.

Note:

Any phase used in a link group must be based on a phase class with a number of partners greater than zero (0).

Link groups are created using Recipe Studio. To create a link group, open the recipe (at the operation, unit procedure or procedure level). On the Home tab, in the Algorithm group, click Link Groups. Click Add. Enter the Link Group name and description. Select the phases from the list of valid phases (based on the current recipe component). Click OK, and then click Close.

Note:

You can modify, delete, and rename link groups from the Link Group dialog.
