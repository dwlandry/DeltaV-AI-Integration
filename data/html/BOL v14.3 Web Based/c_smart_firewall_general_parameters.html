General parameters (Smart Firewall)

A number of parameters hold information written to the Smart Firewall during the adding of the firewall. These parameters are configured and downloaded to the firewall using the Network Device Command Center (NDCC). The firewall uses these values to customize its behavior for your DeltaV system.

For all the following parameters:

  • The parameter category is Configuration
  • Restore parameter value after restart is false (unchecked)
  • The parameter filter is either Common Configuration or Advanced Configuration

Changes to these parameters in the module class are not automatically propagated to the firewall. Parameter settings must be modified in BOTH the module class and to the firewall directly.

Parameter Name

Parameter Type

Default Value

Allow instance value to be configured - Default Value

Description

BCK_TIME_IP_ADDR

String

(empty string)

No

A computer to be used as a backup NTP time server.

LOC_DESCRIPTION

String

(empty string)

Yes

DeltaV description (typically location) for the firewall.

MGINFO

String

(empty string)

Yes

The encrypted firewall management password. This parameter is written to when the user sets the firewall management password in NDCC.

DO NOT write to this parameter other than through NDCC. DO NOT delete the MGINFO parameter. Doing either of these things will cause DeltaV to fail to communicate to the firewall.

MGMT_IP_ADDR

String

(empty string)

Yes

The management IP address for this firewall. (During firewall replacement, the same IP address is assigned to the replacement firewall.)

NETWORK

8-bit unsigned integer

0

Yes

The network to which this firewall is connected. This parameter is written to during the adding of the firewall and is used to determine where to display the firewall in the NDCC application.

The values are
  • 0 - Unknown Network
  • 1 - ACN Primary
  • 2 - ACN Secondary
  • 3 - Remote Primary
  • 4 - Remote Secondary
  • 5 - Other network (for example, the Thin Client network or the Level 2.5 network)

PRI_TIME_IP_ADDR

String

(empty string)

No

A computer to be used as the primary NTP time server.

SYSLOG_IP_ADDR*

String

(empty string)

No

A computer hosting a syslog server which should receive firewall event log records.

* These parameters exist to allow experienced users (or your Information Technology group) to use third party tools such as a Syslog Server or third party SNMP package to collect this information. Typical DeltaV users will not need to set these addresses.
