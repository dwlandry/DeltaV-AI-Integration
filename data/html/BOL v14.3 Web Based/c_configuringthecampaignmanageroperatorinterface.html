Configuring the Campaign Manager Operator Interface

Users with configuration privileges have a great deal of control over the setup of the Campaign Manager Operator Interface. To make changes to the interface, click View > Campaign Manager Options. The following dialog opens.

Note:

You can also configure the options for all clients connecting to a single Campaign Manager Server node through DeltaV Explorer > Campaign Manager > Configure Client. The dialogs are the same as in the Campaign Manager Operator Interface.

The Options dialog has three tabs: General, Column Ordering, and Display Colors. The options available are listed below.
