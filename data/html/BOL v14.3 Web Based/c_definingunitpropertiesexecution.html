Defining unit properties - execution

Use the Execution tab to set the node execution rate for the module.

Node Assignment: Displays the controller that executes this module.

Scan Rate: To specify the rate at which the controller executes the module, select a time from the Scan rate box. The displayed time is the current value in the database for this module. The priority of a module is associated with the scan rate. If the module's scan rate is 100 milliseconds (ms) or 200 ms, it is considered high priority. If the module's scan rate is 500 ms or one second, it is considered medium priority. If the module scan rate is two seconds or greater, it is considered low priority.
