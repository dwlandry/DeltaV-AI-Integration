MONITOR_Output dynamo

The LSMON function block has a single dynamo which is used multiple times when the block has more than one output parameter.

When you add this dynamo to a picture, the Dynamo Properties dialog prompts you to enter both the path to the LSMON block and the output number. If you prefer to use a custom faceplate rather than the default faceplate, enter its name in the Faceplate display name field.
