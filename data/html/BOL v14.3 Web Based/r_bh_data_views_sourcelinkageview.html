Batch Historian data views: sourcelinkageview

Source Linkage View

This view allows a user to connect a batch component (at any point in the Area/Process Cell/Unit hierarchy) and a DeltaV component (at any point in the Area/Node/module hierarchy). This connection is used to relate DeltaV alarms and events (from the Chronicle) with some part of a batch. For example, to include temperature alarms on Reactor102, which is part of Process Cell1 (which is part of Area1), create the following linkage:

DeltaV component

linked to a

Batch component

Reactor1/CTLR1/*

<-->

Area1/ProcessCell1/Reactor102

where Reactor1 is the DeltaV area, CTLR1 is the controller that Reactor1 modules run in, and * is the module name of the temperature loop for Reactor102.

Note:

There should be one linkage for each module for which the user would like to include alarm and event data.
