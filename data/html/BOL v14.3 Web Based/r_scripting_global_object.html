Global object

The following Global object values and functions are supported in DeltaV Live graphics expressions and scripting. See the subtopics under the Global object for more details about each function.

Global object values

Name Description
NaN Represents a "Not-a-Number" value and indicates that a value is not a legal number.
Infinity A numeric value that represents positive infinity.

Global object function

Name Description Syntax
parseInt() Parses a string argument and returns an integer of the specified radix (the base in mathematical numeral systems). parseInt(string, radix)
parseFloat() Parses a string and returns a floating point number parseFloat(string)
isNaN() Determines whether a value is an illegal number. isNaN(number)
isFinite() Determines whether a value is a finite, legal number. Number.isFinite(value)
