Creating a recipe

Before building your recipes, take some time to think about each recipe and how best to represent it with the DeltaV Batch subsystem. This section contains information on the issues you need to consider as you plan your recipes and provides suggestions for taking advantage of the DeltaV Batch subsystem.

Before you can start creating recipes with Recipe Studio, ensure your equipment, plant areas and phase classes are set up in DeltaV Explorer. Using DeltaV Explorer, you define the unit classes, units, process cells and phase classes needed by any of your recipes. Also, note that without a Recipe Studio license assigned to the workstation, Recipe Studio operates in read-only mode and does not allow you to save your work.
