Screen and display elements reference

Screen and display elements are used to configure layouts.

Screens

Screen

Screens, which are graphics elements used in creating layouts, represent the size and relative position of an operator's physical monitors. In a layout, screens define the total available layout space and serve as containers in which to place display frames. Display frames are then used to divide a screen's available real estate into regions and configured so that particular displays appear in each region. Layouts can have either a single screen (monitor) or an entire video desktop that includes multiple screens. Typically, screens should be configured to match the monitor sizes and relative positions of the video hardware present on the Operator Stations the layout is assigned to.

When multiple screens are added to layout, the screens snap together and become attached. You can double-click a screen to zoom in on it, which can be helpful when you are configuring the screen or adding display frames to it.

Displays

Display frame

Display frames, which are graphics elements that represent regions on a layout screen, are used to divide a screen's available real-estate into regions and designate which level of displays open in each region. Display frames also provide the configuration options for a layout's automatic display routing and coordination, which allows you to customize which displays open in each region and how operators navigate between them.

Display frames are added to a layout by dragging them from the Palette pane into a screen element on the content pane; the frame fills the screen's available space. If one or more display frames already exist on a screen, the existing display frames reduce size to allow the new display frame to snap in. Screen boundaries provide guides for placing and containing display frames. To achieve optimal use of the video area, a display frame's aspect ratio should be configured to match the aspect ratio of the displays that will open in them. Likewise, displays should be configured to match the aspect ratio of the display frames where they may appear.

A display frame is configured to be one of two types: static or dynamic. Static frames prevent the initial display in a frame from being replaced while online. They are especially helpful for displays that you want permanently visible in the layout, such as Alarm Banner displays. On static frames, you can also specify which frame a display should open in when launched from that frame. Dynamic frames, on the other hand, allow displays to be replaced by other displays in response to operator actions. For example, if a dynamic frame named DF_level2 is configured to open level 2 displays, then all level 2 displays launched from other display frames in the layout open in DF_level2, replacing the current display. A display frame must be dynamic to support automatic display coordination.
