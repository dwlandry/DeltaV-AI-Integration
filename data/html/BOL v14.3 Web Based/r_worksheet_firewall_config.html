What is the IP address of the gateway?

For the Smart Firewall this is the address of the router located on the plant network to which the Smart Firewall is connected. Typically, this is the same address as the default gateway on the computers on that network. The gateway is optional and required only if the DeltaV workstations communicate with computers other than those on the network directly connected to the firewall.
