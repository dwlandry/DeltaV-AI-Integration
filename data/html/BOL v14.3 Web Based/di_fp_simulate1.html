Simulate (DI_FP)

  • Sim Enable - This check box is used to enable or disable the simulate value as input to the discrete input (DI). When the check box is checked, the simulate value is used as the PV input for the DI.

  • Sim Value - This value is used as the Boolean form of the PV input to the DI when simulate is enabled. Sim Value is the simulated field value. Click this field to enter a value.

  • Field Value - Determines the PV input to the DI when simulate is disabled. This value is the actual Boolean field value. The Boolean field value is read-only and can have a value of 0 or 1.
