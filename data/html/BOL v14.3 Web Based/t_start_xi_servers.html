Start the OPC .NET Services

The OPC .NET services are named OPC .NET Server and OPC .NET Discovery in the Services dialog.

  1. Make sure the DeltaV service is running
  2. Open the Windows Component Services application.
  3. Right-click DeltaV OPC .NET Server, and then click Start. Wait until the service has started.
  4. Right-click DeltaV OPC .NET Discovery, and then click Start. Wait until the service has started.
Note:

You must shut down the OPC .NET services prior to shutting down the DeltaV service.
