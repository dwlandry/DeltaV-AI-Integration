DVSYS object

The DVSYS object provides a means to use legacy DeltaV Operate syntax for parameter paths and path modifiers in DeltaV Live. It is recommended that you use the DVSYS Object and its functions only on graphics configurations that have been migrated from DeltaV Operate to DeltaV Live, and that you use the DLSYS object and its functions for graphics configurations created in DeltaV Live.

DVSYS object functions

Function Description Syntax
Read() Reads the specified DeltaV parameter path and immediately returns the status of the read attempt, and if successful, the requested value. DVSYS.Read(path string)
ReadAsync() Reads the specified DeltaV Operate-style parameter path and immediately returns the status of the read attempt. DVSYS.ReadAsync(path string)
