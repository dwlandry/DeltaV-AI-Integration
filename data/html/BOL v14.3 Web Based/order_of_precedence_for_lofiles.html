The order in which the system applies the settings files

The User_Ref and UserSettings Pictures and The Layout Templates topics provide information on the settings files used to customize the DeltaV environment.

If you are using more than one file per workstation to customize the DeltaV environment settings, the system applies the files in a specific order.

If a UserSettings file exists, it is always applied first.

If both <Workstation_Settings>.grf and UserSettings.grf are found, UserSettings.grf is applied before <Workstation_Settings>.grf.

If both <WorkstationName>_Picture.Layout and DeltaVPicture.Layout are found, only <WorkstationName>_Picture.Layout is applied.

If both <Workstation_Settings>.grf and <WorkstationName>_Picture.Layout are found, <Workstation_Settings>.grf is applied before <WorkstationName>_Picture.Layout.

If the system is an Operator Keyboard system and both DeltaVPicture.Layout and DeltaV_OK_Picture.Layout are found, DeltaV_OK_Picture.Layout is applied.

Note: This order applies to remote client session-specific settings as well.
