Read function

Read() reads the specified DeltaV parameter path and immediately returns the status of the read attempt, and if successful, the requested value. The Read function is useful with scripts that execute periodically because once data is available, calls to .Read() perform successfully.
Arguments
1
Argument Description
path string A literal or graphics expression that resolves to a DeltaV parameter.
Return values (RtValue object)
A number representing the status of the read attempt. 0 represents a successful read; ?? represents an unsuccessful read.
The value read. The data type returned is determined by the <read-as suffix>.
Syntax
DLSYS.Read(path string)
Examples
Example Result 
let pv = DLSYS.Read("FIC101/PID1/PV.CV");
  • A successful read: a status of 0, and the PV of FIC101's PID1 block.
  • An unsuccessful read: ?? 
let actModeName = DLSYS.Read("FIC101/PID1/MODE.ACTUAL.STR");
 
const x = DLSYS.Read('MOD1/SGGN1/OUT.CV').Status.Text
const y = DLSYS.Read('MOD1/SGGN2/OUT.CV').Status.Text
Dsp.Text1.Label = x
Dsp.Text2.Label = y
  • A successful read: a status of 0, and the OUT value of SGGN1 on the Text1 label and the OUT value of SGGN2 on the Text2 label.
  • An unsuccessful read: ??
