Guardian registration parameters (Smart Firewall)

The Guardian registration information parameters are manually entered with information from the firewall. Once configured, you can use these parameters in custom displays showing the Emerson Smart Firewall.

For all the following parameters:
  • The parameter category is Misc
  • Allow instance value to be configured is false (unchecked)
  • Restore parameter value after restart is false (unchecked)
  • The parameter filter is On-line
  • XINFO_MODEL
  • XINFO_HWREV
  • XINFO_SWREV
  • XINFO_SERIAL
