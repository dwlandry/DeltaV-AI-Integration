MA1_CH_ analog dynamo, 1 function block, horizontal combination bar graph

This dynamo can be used for loop indication of PID loops where general percent of scale is important.

The following elements are present on the dynamo:

  • Alarm Box

  • Alarm Icon

  • Combination (Combo) Bar Graph

  • Display Tag

  • Dynamo Background

  • Engineering Units Descriptor

  • Mode Icon

  • OUT Bar Graph

  • PV and SP Data Fields

  • Ramp Status Icon

  • Status Box

  • Status Icon
