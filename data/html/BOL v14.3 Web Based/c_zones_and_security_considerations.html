Zones and security considerations

There are three places where DeltaV Zones and security interact:

  • Local Shared Areas (in remote zone)
  • Remote Zone Areas (in local zone)
  • User Manager

When you configure Local Shared Areas in DeltaV Explorer, you define the other DeltaV systems that have access to the areas in a system and whether the access from each other system to each local shared area is read only or read and write. Users can see data from areas in another DeltaV system if the other system shares those areas with read only access. Users can write data between zones if certain requirements are met.

In the DeltaV User Manager you specify the remote zone areas that the following apply to:

  • Assigning groups or keys to users
  • Assigning users, keys, and SIS keys to groups

When you make these assignments a Plant Area dialog opens. The drop-down list contains all of the local areas and all of the Remote Zone Areas in this system. The Remote Zone Areas are listed in the format Remote_Zone_Area_Name (Zone_Name).
