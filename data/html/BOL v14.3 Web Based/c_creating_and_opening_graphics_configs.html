Creating and opening graphics configurations

Layouts, displays, display sets, GEM classes, standards, and functions are created from the ribbon's New command or from their permanent folder's context menu in the Explorer view. When you create one of these configurations, it automatically opens as a Content tab in the Content Tabs view. The New ribbon command can be used from either the Home > Graphics tab or Insert > Graphics tab.

To create a new language or theme, you must first open the appropriate Languages or Themes library folder as a tab and then click New Language or New Theme in the Content pane.

Double-click any graphics configuration or library folder in the Explorer view to open it as a Content tab. You can then navigate between open configurations and folders by selecting their tabs; the selected tab is the active tab. When a folder is selected as the active tab, the configurations contained in that folder are listed in the Content pane. You can do the following with this list of configurations:
  • View certain information about each configuration, such as whether it is locked for editing or marked as a work in progress.
  • Use the context menu to cut, copy, paste, or delete configurations.
  • Double-click a configuration to activate it in the Content pane.
