Public Sub

Verify (

ByVal rType As RecipeExchangeType,

ByVal recipeName As String,

ByRef strlog As String,

)

This method verifies the specified recipe.

Return Values

S_OK - success

E_NOT_CONNECTED - Please call Connect First.

E_VERIFY_FAILED - The Verify Failed.

E_INVALID_TYPE - The type is not supported.

else - failed

Memory Allocation

The caller is responsible for release of the strlog.

Visual Basic Usage Example

Private Sub Button1_Click()

  Dim myRecipeExchange As RecipeExchange
  Set myRecipeExchange = New RecipeExchange
  myRecipeExchange.Connect
  Dim bstrLog As String

  Dim itemType As tagRecipeExchangeType
  itemType = Procedure
  Dim itemName As String
  itemName = "make_toothpaste"
  Call myRecipeExchange.Verify(itemType,
                               itemName,
                               bstrLog)

  MsgBox bstrLog, vbOKOnly, "Verify"

  myRecipeExchange.Disconnect

End Sub

Parameter Name

Purpose

rType

The type of the specified recipe or equipment to be verified.

recipeName

The name of the specified recipe or equipment to be verified.

This name should include the path.

e.g., "operationFolder1/op1","procedure1/formula1".

strlog

String that will return the log information of the verifying.
