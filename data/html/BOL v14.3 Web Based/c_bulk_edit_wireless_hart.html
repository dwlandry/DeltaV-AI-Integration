Bulk editing WirelessHART devices

WirelessHART devices are a subtype of HART devices in the Format specification - Select fields dialog. Wireless gateways can be changed to WirelessHART gateways.

Note:

The wireless devices currently supported are the Rosemount 648 Wireless Temperature Transmitter and the Rosemount 3051S Wireless Series devices

The general procedure to bulk edit WirelessHART devices is:

  1. Configure one or more WirelessHART devices. 

  2. Use the sample format specification file or create your own and export data from the existing configuration. 

  3. Edit the WirelessHART devices in the bulk edit Excel add-in. 

  4. Import the edited WirelessHART devices.
