Fieldbus system capacities

The system capacities for fieldbus are:

  • The H1 card can run a total of 96 function blocks: 32 (maximum) H1 card fieldbus blocks and 64 (maximum) DeltaV non-H1 card fieldbus blocks

  • The H1 4-port Plus card can run a total of 128 DeltaV non-H1 card fieldbus blocks

  • 50 VCRs maximum for each port on the H1 and H1 4-port Plus cards

  • 16 devices per segment for the H1 and H1 4-port Plus cards

  • Maximum number of VCRs per device.
