Monitoring CPU usage on pictures with object run-time attributes enabled

Using object run-time attributes such as IsSelectable and HighlightEnabled on an object increases the CPU usage when the operator moves the cursor over the object. As CPU usage becomes excessive, the system's performance degrades. It is recommend that you use the Windows Task Manager to monitor and test CPU usage on pictures with object run-time attributes. If system performance degrades, reduce the number of objects in pictures with object run-time attributes enabled until performance is acceptable.
