Bulk edit Local Safety Network Bridges

This section outlines how to bulk edit Local Safety Network Bridges (LSNBs), which exist in the DeltaV Explorer hierarchy under the CSLSs.

The general procedure to bulk edit LSNBs is:

  1. Create and configure one LSNB, including the hardware alarms.
  2. Use the LSN_Bridge.fmt format specification file to export the LSNB or create your own format specification file.
  3. Copy and edit the exported LSNB in the bulk edit Excel template as required.
  4. Import the edited data.
