Module GEM classes

This section provides a reference for the module GEM classes provided with DeltaV Live. In Graphics Studio, the module GEM classes are found in the Library Explorer pane, in the GEM Classes\Emerson\High_Performance_GEMs folder.

In the individual GEM class topics, each image shows the GEM and its main components at a 200 percent magnification, for readability purposes. When a GEM is initially added to a display, some of its components may be hidden because their visibility is optional. The component descriptions in each topic describe the GEM's online behavior.

The following table lists the GEMs contained in the High_Performance_Gems set and their corresponding function blocks:
High Performance GEM classes
GEM class Function block Description
HP_Alarms This GEM is mapped to an Area. Used to configure alarm roll-up calculations and shows alarm count information on running displays.
HP_AT_VLV_ PID Used for control valve indication with PID loop modules.
HP_B_Valve DC, EDC
HP_C_Valve PID, MANLD, AO
HP_EDC_PMP_ EDC Used for indication on discrete pumps.
HP_EDC_VLV_ EDC Used for indication on normally open or normally closed discrete valves.
HP_HorizAnalog PID, AI, AO, ALM, MANLD, RTO
HP_M1_CH_S_ TAGAI, TAGAO, TAGDI, TAGDO
HP_MA1_CH_ PID Used for loop indication of PID loops where general percent of scale is important.
HP_MA1_DH_ PID Used for loop indication of PID loops where deviation from SP is important.
HP_MA1_N_ PID Used for loop indication of PID loops where deviation from SP is important.
HP_MA1_VLV_ PID Used for control valve indication with PID loop modules.
HP_MA2_DH PID Used for analog indication, on PID loops and ALM function blocks, where deviation from SP is important.
HP_MA2_DV_M_ PID, ALM Used for analog indication, on PID Loop and ALM function blocks, where deviation from SP is important and vertical space on the display is available.
HP_MA2_DV_S_ PID, ALM Used for analog indication, on PID Loop and ALM function blocks, where deviation from SP is important and vertical space on the display is available.
HP_MA3_CH_ PID, AI, ALM Used for analog values on analog modules (PID loops, AI indicators, ALM function blocks) where the output is not needed.
HP_MA3_CV_M_ PID, AI, ALM Used for analog indication, with PID loops, AI indicators, and ALM function blocks, where general percent of scale is important and vertical space on the display is available.
HP_MA3_CV_ML PID, AI, ALM Used for analog indication, with PID loops, AI indicators, and ALM function blocks, where general percent of scale is important and both vertical and horizontal space on the display is available.
HP_MA3_CV_S_ PID, AI, ALM Used for analog indication, with PID loops, AI indicators, and ALM function blocks, where general percent of scale is important and space on the display is limited.
HP_MA3_CV_SL_ PID, AI, ALM Used for analog indication with PID loops, AI indicators, and ALM function blocks. It is also used where general percent of scale is important, and vertical space on the display is limited but horizontal space is available.
HP_MA3_N_ PID, AI, ALM Used for analog data display with analog modules (PID loops, AI indicators, and ALM function blocks).
HP_MD1_PMP_ DC Used for indication on discrete pumps.
HP_MD1_VLV_ DC Used for indication on normally open or normally closed discrete valves.
HP_MSHDI_ SHDI Used for control with SHDI modules.
HP_MSHDO_ SHDO Used for control with SHDO modules.
HP_Numeric PID, AI, AO, ALM, MANLD, RTO

HP_VertAnalog PID, AI, AO, ALM, MANLD, RTO
