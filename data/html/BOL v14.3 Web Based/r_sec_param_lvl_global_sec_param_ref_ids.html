SLS 1508 secure parameter level global secure parameter reference ItemIDs

ItemIDs for secure parameter level global secure parameter references are of the form:

SISNET/SLxx/SPyy/field 

where:

xx is the Slot ID (33 through 64 for Domain Globals, 65 through 80 for System Globals)

yy is the Secure Parameter Number (01 - 16) within the source logic solver.  

The valid fields and their values are:

Field

Access

Description

Secure Parameters

High-Density Secure Parameters

VALUE

W

0 (False) or 1 (True)

STATUS

W

1 = BadNotConnected, 

0 and 2 through 7 = 

       BadNonSpecificNotLimited

8 through 15 = 

       GoodNonCascadeNonSpecific

0 = Bad

1 = GoodNonCascade

REVISION1

W

0 through 7

0 through 3

These fields are write only because their intended use is to simulate secure parameter reference values for secure parameters in other logic solvers that may not be currently available.

Examples of this type of ItemID are:

  • SISNET/SL33/SP01/VALUE

  • SISNET/SL33/SP01/STATUS

  • SISNET/SL33/SP01/REVISION

1 The revision of the referenced source logic solver slot. A revision of 0 indicates the slot is not in use.

The revision must match the number shown for this secure parameter's slot revision in the Global Secure Parameter References dialog. If the revisions do not match, the status of the parameter reference is ConfigErr. (The slot revision changes when a secure parameter is renamed or deleted and re-added to a module.)
