Operator messaging

You can send messages to the operator using two methods: phase parameters and operator prompts.

Phase message parameters can be used to send a message to the operator when the applicable phase starts. Phase parameters do not require acknowledgment from the operator for the phase to continue. You create the phase parameter at the phase class. Write your phase logic to send the message to the operator.

Operator prompts send a message to the operator and require the operator to respond to that message. The phase will not continue until the operator has responded. There are four types of operator prompts: Boolean, string, floating point, and integer. You configure the operator prompts in the phase logic by setting the parameters, PROMPT_BOOL, PROMPT_STRING, PROMPT_FLOAT or PROMPT_INT.

Phase messages for the operator are displayed through the Batch Operator Interface on the Phase Summary screen and also on the Phase Control screen when the phase is executed manually by the operator. Operator prompts are displayed on the Unacknowledged Prompts screen until acknowledged and responded to by the operator.

Both operator prompts and phase messages are sent to the batch event journal. Every batch produces a batch event journal file. This file is in ASCII format and is accessed from the Event Journal screen in the Batch Operator Interface.
