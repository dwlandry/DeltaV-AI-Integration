Batch Historian clients

The DeltaV Batch Historian stores data to a SQL database in a set of predefined views that allow users and applications to easily query for batch history using standard Microsoft SQL queries. Several Batch Historian clients are provided to make viewing, comparing, and reporting batch data easy.

The clients include:

  • Batch History View

  • Batch Historian Administration

  • History Web Service

Batch History View and Batch Historian Administration clients are fully supported applications included with the Batch Historian.

Note:

Refer to Appendix D for the table descriptions of each view of the Batch Historian database. These views can be used to build customized queries.
