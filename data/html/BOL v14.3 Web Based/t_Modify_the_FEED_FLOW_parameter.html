Modify the FEED_FLOW parameter

  1. In DeltaV Explorer, select TOTAL_FLOW_100 under the unit module UM_COLOR_100.
  2. Right-click the FEED_FLOW parameter in the right pane and open the Properties dialog.
  3. Browse for the following External parameter path: 
    UM_COLOR_100/EM_TOTAL_100/FIC_COLOR_100/PID1/PV
  4. Repeat the above steps for the FEED_FLOW parameters in UM_COLOR_200 and UM_COLOR_300, substituting 200 (or 300) where appropriate in the names.
