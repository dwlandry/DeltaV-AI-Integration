SLS 1508 SIS Simulation parameters

During preliminary design of SIS modules you may want to download a module to test a piece of the logic before you have completely configured the module. Enable the simulation parameter in LSDI and LSAI blocks in SIS modules downloaded to the simulated Logic Solver card. You cannot enable the simulation parameters in modules that are running in physical Logic Solver cards.

You must completely configure the LSDI and LSAI blocks to successfully download and use simulation:

  1. Create an SIS module in Control Studio.

  2. Assign the module to a simulated Logic Solver card.

  3. Enable a channel in the Logic Solver.

  4. Define the channel type for the correct input type (Analog Input or Discrete Input).

  5. Assign the channel to the input block's IO_IN parameter.

  6. From the SIMULATE or SIMULATE_D properties dialog, enable simulation and enter a simulate value.

  7. Save the module.

  8. In DeltaV Explorer, download the Logic Solver.

Note:

If you restart the workstation you must re-download the simulated Logic Solver.

Note:

After you complete your simulation configuration and before you export the configuration, make sure simulation parameters in the configuration are disabled. If you do not disable the simulation parameters, the CRCs of the simulated system do not match the CRCs of the system downloaded to the runtime system.
