This event is fired whenever a campaign's execution mode or auto remove properties changes. Note that the automatic removal of batches can be associated with any of a campaign's three possible execution modes.

Return Values

none

Memory Allocation

none

Parameter Name

Purpose

bstrCampaignID

The unique Campaign ID of the campaign that changed.

bIsManual

True if the campaign is in manual.

bIsAutoRelease

True if the campaign is in auto-release.

bIsAutoStart

True if the campaign is in auto-start.

bAutoRemoveInManual

True if automatic removal of completed batches is enabled when the campaign campaign is in manual mode.

bAutoRemoveInAutoRelease

True if automatic removal of completed batches is enabled when the campaign is in auto-release mode.

bAutoRemoveInAutoStart

True if automatic removal of completed batches is enabled when the campaign is in auto-start mode.

lRemoveMinDelay

The number of minutes the Campaign Manager server will wait before attempting to remove a batch
