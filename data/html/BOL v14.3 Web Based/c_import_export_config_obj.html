Bulk editing configuration objects

The following sections each outline how to bulk edit one type of configuration object or logical group of configuration objects. The sections do not go into detail for procedures on creating format specification files or exporting and importing data. Those subjects are explained in detail elsewhere. The following sections do explain any special considerations required when bulk editing specific objects. Each section includes the supporting object syntax and other tables required to successfully bulk edit the specific object type or group.

Later sections outline how to bulk edit more complex configuration objects, nested modules, for example.
