Variables overview

Variables provide a means to reuse, or share, property values or other data through graphics expressions or scripts.

For example, assume that you want the line color property for all elements making up a particular GEM or group to reflect the same animated color value. You can create a variable for that color value and then reference that variable from the line property of all elements contained by the GEM or group. Variables are referenced in graphics expressions from any property showing a diamond next to it. Click the diamond and select Variables from the context menu.

Or, you may want the click action on several elements contained in a linked GEM or group to trigger user scripts that cooperate in manipulating the 'state' data for the linked GEM or the group, affecting the appearance and behavior of subsequent click actions. To write a script using variables, use the Script Assistant.

Variables are created and configured on the Variables tab in the Graphics Configuration pane, but only within displays, contextual displays, Gem classes, groups, or layouts. You can also use the Variable command on the ribbon's Insert tab or the right-click context menu on a graphics configuration to add a variable to the Graphics Configuration pane. You can create the following types of variables:
  • Color
  • Font
  • Boolean
  • Image
  • String
  • Localizable string
  • Measurement
  • Number
