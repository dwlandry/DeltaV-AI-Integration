SIS module faceplates

The SIS module faceplates include only two faceplates, SIS_MOD_fp or SIS_MOD_WIDE_fp, either of which can be used with the SIS_DEFAULT module template. This section provides a reference for the SIS_MOD_fp and SIS_MOD_WIDE_fp. In Graphics Studio, these faceplates are found in the Graphics Explorer pane, in the Contextual Displays\Faceplates folder.

In the individual faceplate topics, the images show all of the faceplate's main components. The component descriptions describe the faceplate's online behavior.

  • SIS_MOD_WIDE_fp (SIS module wide faceplate)
