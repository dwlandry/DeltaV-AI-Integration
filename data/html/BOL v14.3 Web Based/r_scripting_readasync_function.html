ReadAsync function

ReadAsync() reads the specified DeltaV Operate-style parameter path and immediately returns the status of the read attempt.
Arguments
1
Argument Description
path string A literal or graphics expression that resolves to a DeltaV parameter.
Return value (Boolean)
Syntax
DLSYS.ReadAsync(path string)
Examples
Example Result 
const x = (await DLSYS.ReadASync('MOD1/SGGN1/Bias')).Value
const y = (await DLSYS.ReadASync['MOD1/SGGN2/Bias')).Value
Dsp.Text1.Label = x
Dsp.Text2.Label = y
