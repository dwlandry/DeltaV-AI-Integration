Logic Solver Sequencer function block

The LSSEQ function block associates system states with actions. The combination of LSSTD blocks (which associate transitions with states you define) and LSSEQ blocks provide a sequencing capability similar to DeltaV Sequential Function Charts (SFC).

The LSSEQ block can have as many as 16 states and 16 discrete output. For each state, the block sets the value of the outputs based on the pattern defined by the MATRIX parameter. The block can step through the states in sequence using internal increment and decrement parameters, or the block can be set to specific states (and the corresponding outputs set) from logic external to the block.

The LSSEQ block does not support modes or alarm detection.
