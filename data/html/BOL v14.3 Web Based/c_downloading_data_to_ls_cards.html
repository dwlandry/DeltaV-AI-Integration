SLS 1508 Logic Solver downloads

Downloading data to a logic solver requires the following:

  • The logic solver under the SIS Network subsystem in DeltaV Explorer must be assigned to a Logic Solver card (under a standard DeltaV controller I/O subsystem) or to a workstation (under the Assigned Logic Solvers subsystem).
  • The logic solver must be unlocked.
  • The Logic Solver card must be commissioned.
  • The download must be performed from the logic solver under the SIS Network subsystem. Downloading the associated controller or workstation or the control network does not download data to the logic solver.

All logic solver downloads are total downloads. That is, all modules and I/O are downloaded. Downloads are matching downloads when the logic solver already has a configuration. All function block parameters designated as Preserved on Download are copied from the running modules in the newly downloaded module before the next execution so that the download is non-disruptive. When you create top-level parameters in SIS modules and SIS composite blocks can be, you select on the properties dialog whether or not the parameter value is preserved on download.

You can download only one logic solver at a time.
