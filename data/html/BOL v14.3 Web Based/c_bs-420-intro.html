The Autronica BS-420 in a DeltaV system

This section describes how to use signal information from the Autronica BS-420 (and BC-420) with the Local Safety Network Gateway (LSNG) in DeltaV configurations, including fire and gas alarm detection and control of the BS-420 and connected detection devices. The use includes an example configuration that processes the BS-420 signals into DeltaV parameters for use in configuration logic.

Note:

The LSNG and DeltaV software support detection devices only.

This section assumes the following:
  • You have performed the basic configuration of the LSNG in DeltaV Explorer.
  • The BS-420 is configured and connected to the LSNG Modbus ports.
