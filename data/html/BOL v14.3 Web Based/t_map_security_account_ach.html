Map the security account for Advanced Continuous Historian

On the Application Station where you are running the Advanced Continuous Historian, you must use the PI System Management Tools (PI SMT) application to complete the following steps:

  1. Under Collectives and Servers, select the server or collective.
  2. In the System Management Tools pane, click Security > Mappings and Trusts.
  3. Click the Mappings tab.
  4. Open the Add New Mapping dialog by clicking the New button in the toolbar.
  5. In the Windows Account field, specify an Active Directory principal or a local Windows group or user account (typically, the DeltaVAdmin account). To specify the account, complete either of the following tasks:
    • Click the Browse button, and then select the account.
    • Type the account name in the Windows Account field.

      After typing the account name, click the Resolve SID button to verify that this is a valid account. If the account is valid, a Security Identifier (SID) appears in the field. Otherwise, an error message appears.

  6. In the PI Server list, select the server where you want to create the mapping.
  7. In the PI Identity field, enter a PI identity, group, or user (typically the piadmins Group or piadmin User).
    1. Click the Browse button to open the Select PI Identity, PI Group, or PI User dialog.
    2. Use the Type option to filter the choices, and then select a PI identity, PI group, or PI user from the list.
    3. Click the OK button.
  8. Click the OK button to create the mapping and close the Add New Mapping dialog.
