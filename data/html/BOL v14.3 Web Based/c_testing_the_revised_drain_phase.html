Testing the revised DRAIN phase

To test the operator prompt, you will need to open the Batch Operator Interface. You might also want to open DeltaV Operate to see if all the valves are closed and that the process is otherwise in a state of readiness. With both operator interfaces open, you can switch back and forth to run the batch recipes and watch the batch progress on the Process picture.

You can resize the operator interface screens so you can see the important parts of both at one time. You might even want to open the unit module UM_BLEND_500 in Control Studio. Select the DRAIN running logic and put it in online mode so you can see the phase progress through the steps of the Sequential Function Chart. (This is useful if you encounter any errors that you need to fix.)

Note:

In the following procedure, the Batch Executive is stopped before downloading.
