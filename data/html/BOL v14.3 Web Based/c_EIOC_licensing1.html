Ethernet I/O Card license demand guidelines

There are three license types associated with the Ethernet I/O Card (EIOC): an interface license, a system-wide (physical device) license, and one or more DST licenses.

Interface license

An interface license is available for each of the protocols supported by the EIOC:
  • Ethernet/IP
  • Ethernet/IP Control Tag Integration
  • IEC 61850
  • Modbus TCP
  • OPC UA
Only one interface license can be assigned to an EIOC.

Ethernet I/O physical device licenses

A physical device EIOC license is required to support the total number of EIOC physical devices (PDTs) in a single DeltaV system. Several license levels are available. EIOC system-wide licenses are assigned to the ProfessionalPlus workstation. They cannot be unassigned.
Note: PK controller physical devices also consume licenses from the EIOC system-wide license.

DST licenses

The table describes the DST license consumption. For the Ethernet/IP, IEC 61850, Modbus TCP, and OPC UA protocols, the DST license type consumed is determined by the most expensive type of signal configured for the logical device. For the Ethernet/IP Control Tag Integration protocol, the DST license type consumed is determined by the most expensive type of signal configured for the Control Tag. The DST license demand from the logical devices configured for an EIOC are counted against the system-wide AO DST, AI DST, DO DST, and DI DST license capacities assigned to the system.

Ethernet I/O physical device licenses

A system-wide EIOC license is required to support the total number of EIOC physical devices in a single DeltaV system. Several license levels are available. EIOC system-wide licenses are assigned to the ProfessionalPlus workstation. They cannot be unassigned. Placeholder EIOC devices do not count against the system-wide license. However, placeholders do impact download performance.
Note: PK controller physical devices also consume licenses from the EIOC system-wide license.
1 This parameter is only supported by the Ethernet /IP Control Tag Integration and OPC UA protocols.
