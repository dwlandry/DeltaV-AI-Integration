MPCPro controlled variable detail display (MPCPROOUTPUT_DT)

DeltaV Operate View of a Controlled Variable Detail Display (MPCPROOUTPUT_DT)

The MPCPro Controlled Detail display provides Limit, Range, and Tuning information. It includes the following items:

Limits

  • SP High Limit – This field displays the maximum value of SP in engineering units. Click this field to enter a new limit. The valid input range for this value is 0 to 100 % of the CV Scale in engineering units.

  • SP Low Limit – This field displays the minimum value of SP in engineering units. Click this field to enter a new limit. The valid input range for this value is 0 to 100 % of the CV Scale in engineering units.

Range

  • SP Delta Range – The range (up and down) relative to the SP used by the Optimizer in managing constraints and optimization.

  • SP High Range – The SP maximum value applied by the Optimizer as a target SP.

  • SP Low Range – The SP minimum value applied by the Optimizer as a target SP.

Tuning (Controlled Detail Display)

  • Response Trajectory  – An exponential trajectory defined by its filter time constant, current process output, and future required process output (SP). Response Trajectory is used to increase stability by slowing down the controller reaction to CV error. When unmeasured disturbances are significant, Response Trajectory filter time constant values between 1 and 5 times the TSS are recommended.
