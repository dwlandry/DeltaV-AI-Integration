User account passwords

DeltaV user, application, and service account passwords must comply with the operating system complexity settings.

If the same username is going to be used on different workstations in a DeltaV workgroup environment, the password for that particular username must be the same on all workstations. For a domain system, the username and password for all domain users reside on the domain server rather than on each workstation. Each user has only one username and password that apply to all the workstations in the domain.

The passwords for the DeltaVAdmin service account and SOFTPHASEUSER accounts are pre-assigned in your DeltaV system. During installation you are prompted to set the password. You can change the password later using DeltaV Security Administration application or, on non-DeltaV computers, the ServPwd utility (located in the \DeltaV\bin directory and copied to the required computer).

Several applications that run as Windows services must be re-registered as Windows Services when the password on these accounts is changed. This password is stored only in SAM (the Windows Security Account Manager database). Therefore, you must use this special DeltaV utility to change the password and re-register DeltaV Services.

Important:

Only change the DeltaVAdmin and SOFTPHASEUSER password using DeltaV Security Administration application or the ServPwd utility (for non-DeltaV computers).

Important:

Manage the Administrator (or Emerson) account password using DeltaV Security Administration or DeltaV User Manager.
