DO dynamo

The Discrete Output (LSDO) function block has a single dynamo. When you add this dynamo to a picture, the Dynamo Properties dialog prompts you to enter the path to the LSDO block and to enter off/on feedback words such as Closed and Open. (The maximum number of characters for the PV_D "0" State or "1" State word is 24.) If you prefer to use a custom faceplate rather than the default faceplate, enter its name in the Faceplate display name field.
