Startup variables

Startup_glb is the first file opened and defines what is necessary to start the rest. Most of the variables are used to define the window size and position for the main picture layout. 

The following table describes the global variables declared in Startup_glb. Changes to these global variables are made either in the User_Ref picture or the Layout file. Refer to Customizing the DeltaV Operate Environment.

Variables Declared in Startup_glb

Global Variable

Description

gn_ab_h

Specifies the height of the Alarm Banner window

Note Change the value of this variable using the Layout file.

gn_ab_w

Specifies the width of the Alarm Banner window

Note Change the value of this variable using the Layout file.

gn_ab_x

Specifies the starting X coordinate for the Alarm Banner window

Note Change the value of this variable using the Layout file.

gn_ab_x2

Specifies the starting X coordinate for the Alarm Banner window on Monitor 2

Note Change the value of this variable using the Layout file.

gn_ab_y

Specifies the starting Y coordinate for the Alarm Banner window

Note Change the value of this variable using the Layout file.

gn_ab_y2

Specifies the starting Y coordinate for the Alarm Banner window on Monitor 2

Note Change the value of this variable using the Layout file.

gn_init_step_size

Specifies the percent completion of the initialization sequence by each GLB file (100 / # of GLB files)

gn_main_h

Specifies the height of the main window

Note Change the value of this variable using the Layout file.

gn_main_h_large

Specifies the height of the main window if the menu bar is not visible

gn_main_h_small

Specifies the height of the main window if the menu bar is visible

gn_main_w

Specifies the width of the main window

Note Change the value of this variable using the Layout file.

gn_main_x

Specifies the starting X coordinate for the main window

Note Change the value of this variable using the Layout file.

gn_main_x2

Specifies the starting X coordinate for the main window on Monitor 2

Note Change the value of this variable using the Layout file.

gn_main_y

Specifies the starting Y coordinate for the main window

Note Change the value of this variable using the Layout file.

gn_main_y2

Specifies the starting Y coordinate for the main window on Monitor 2

Note Change the value of this variable using the Layout file.

gn_mh_disabled

Disables opening the main pictures on any monitor except the Primary Monitor

gn_mh_orientation

Specifies the orientation of the monitors as vertical, horizontal, or square

gn_scr_w

Specifies the maximum width of the Operator Interface windows

gn_scr_x

Specifies the starting X coordinate used for the Operator Interface windows

gn_space_y

Specifies the amount of space between each window in Operator Interface

gn_tb_h

Specifies the height of the Toolbar window

Note Change the value of this variable using the Layout file.

gn_tb_w

Specifies the width of the Toolbar window

Note Change the value of this variable using the Layout file.

gn_tb_x

Specifies the starting X coordinate for the Toolbar window on Monitor 2

gn_tb_y

Specifies the starting Y coordinate for the Toolbar window

Note Change the value of this variable using the Layout file.

gn_tb_y2

Specifies the starting Y coordinate for the Toolbar window on Monitor 2

Note Change the value of this variable using the Layout file.

gn_unseen_h

Specifies the height that would make the picture invisible

gn_unseen_w

Specifies the width that would make the picture invisible

gn_unseen_x

Specifies the X coordinate that is outside the visible area of the monitor

gn_unseen_y

Specifies the Y coordinate that is outside the visible area of the monitor

gs_def_path

Specifies the path to the converted function block detail display (*.def) pictures

gs_det_path

Specifics the path to the converted module detail display (*.det) pictures

gs_hep_path

Specifies the path to the converted help (*.hep) pictures

gs_iab_path

Specifies the path to the converted function block faceplate (*.iab) pictures

gs_iaf_path

Specifies the path to the converted module faceplate (*.iaf) pictures

gs_std_path

Specifies the path to the converted standard pictures (*.std) pictures

gs_trb_path

Specifies the path to the converted function block trend (*.trb) picture

gs_trn_path

Specifies the path to the converted module trend (*.trn) pictures
