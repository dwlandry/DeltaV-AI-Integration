Create a layout from scratch

  1. In the Graphics Explorer pane, right-click the Layouts root folder and select New > Layout from the context menu. The layout opens as a content tab and becomes available for editing in the Content pane.
  2. Rename the layout, if desired.
  3. Configure the layout's properties in the Graphics Configuration pane.
  4. Add screens to the layout by dragging screen elements from the Palette pane and dropping them on the Content pane. Add one screen for each physical monitor on the Operator Station for which this layout is intended.
    1. Arrange the screens to match the arrangement of the intended Operator Station’s monitors. Info: Each screen snaps together and becomes attached to another screen.
  5. Configure the properties for each screen.
  6. Add a display frame to each screen by dragging a display frame element from the Palette pane and dropping it inside a screen on the Content pane. The frame fills the screen's available space.
  7. Add additional display frames for each area of a screen you want to designate as a specific content region.
  8. Configure each display frame's properties in the Graphics Configuration pane.
  9. Click the Save button.
    Tip:
    • Double-click a screen to zoom in on it.
    • To zoom back out, click Fit To Window in the ribbon's View tab.
