getFullYear function

Returns the year for the specified date, according to local time.
Arguments
0
Return values (number)
A number (four digits for dates between year 1000 and 9999), representing the year of the specified date.
Syntax
dateObj.getFullYear()
Example
Example Result
With Button1 on a display, this script is added as a custom script on a Button1 action. 
var today = new Date();
Dsp.Button1.Label = today.getFullYear();
 Assuming the current year, local time, is 2018: Returns "2018".
This script is added, as a custom script on an action, to any element with a Label property, such as a button. 
var moonLanding = new Date("July 20, 69 00:20:18");
this.Label = moonLanding.getFullYear();
 Returns "1969".
