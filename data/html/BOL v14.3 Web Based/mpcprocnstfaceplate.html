MPCPro Constraint Variable function block faceplate (MPCPROOUTPUT_FP)

DeltaV Operate View of the MPCPro Constraint Variable Faceplate

A red border around the faceplate indicates this required output is disabled or has failed; a yellow border indicates a fail condition exists but the configured fail action is for no action (not required) or simulate. A blue border indicates limits are exceeded.

The following items are found on the MPCPro Constraint Variable function block faceplate:

  • AV Value – This field displays the PROC_OUTn value of the MPCPro block in yellow. The background color of the 3-D box changes from gray to orange or red when the PROC_OUTn status becomes uncertain or bad, respectively. The PROC_OUTn value is visible in the decimal format provided by SCALE_ATTR_OUTn.DECPT.

  • Units – This area provides the engineering units description used for the Constraint Variable as defined in the SCALE_ATTR_OUTn parameter.

  • EU 100 – This value corresponds to 100% of scale for the Constraint Variable.

  • Target Mode – This field contains a word in white text that describes the target mode for the loop. The background changes to blue when the target mode and normal mode are different.

  • Actual Mode – This field contains a word in yellow text that describes the ACTUAL mode of the loop. The background changes to blue when the actual mode and normal mode are different.

  • EU 0 – This value corresponds to 0% of scale for the Constraint Variable.

  • Tick marks – Use this vertical arrangement of black lines to indicate percentages of CNSTRn scale.

  • AV bar graph – This field indicates the value of the CNSTRn parameter for the MPCPro block, which is the same as the AV value.

  • AV High Limit slider – To move this button, hold down the left mouse button while the cursor is over the arrowhead and then move the mouse up or down to correspond to the new limit value desired. The new value is then written to the maximum value of PROC_OUT in engineering units.

  • AV High Limit Entry – The High Limit Entry is the 3-D recessed box displaying the maximum value of PROC_OUT . The High Limit Entry box is next to the High Limit slider.  Double-clicking this box produces a dialog that prompts you for the new limit value. The valid input range for this value is 0 to 100 % of the PROC_OUT Scale in engineering units. The value is visible in the decimal format provided by SCALE_ATTR_OUTn.DECPT.

  • AV Low Limit slider – To move this button, hold down the left mouse button while the cursor is over the arrowhead and then move the mouse up or down to correspond to the new limit value desired. The new value is then written to the minimum value of PROC_OUT in engineering units.

  • AV Low Limit Entry – The Low Limit Entry is the 3-D recessed box displaying the minimum value of PROC_OUT . The Low Limit Entry box is next to the Low Limit slider.  Double-clicking this box produces a dialog that prompts you for the new limit value. The valid input range for this value is 0 to 100 % of the PROC_OUT Scale in engineering units. The value is visible in the decimal format provided by SCALE_ATTR_OUTn.DECPT.

  • Connected block mode – This field displays the actual mode of the connected block.

  • Disable button - Disables or enables this output during control.

  • Detail picture button – Opens the Detail picture for the module.

  • MPC Operate Pro button – Opens the MPC Operate Pro application for the block.

  • MPCDiagnostics button –  Opens the MPCDiagnostics application for the block.

  • Limit Information - This field displays a word in yellow text representing the AV_ACT[n] value of the MPCPro block. The background color of the 3-D box changes from gray to blue when the AV_ACT[n] value is non-zero. The text displayed represents the following values:

    Text

    0.0

    Not Limited

    1.0

    Low Limited

    2.0

    High Limited

    3.0

    Constant
