Modify the update interval

There are two ways to modify the update interval.

Set the update interval

Using the Configure Update Interval dialog

  1. Open the Configure Update Interval dialog.
    1. Select the Add-Ins tab.
    2. In the DeltaV group, select Runtime Data > Configure Update Interval.
  2. If the named range containing the update interval exists, the cell address is shown in the Named Range Location text box. This can be changed by clicking the Selected button.
  3. Enter the update interval.
  4. Click OK.

Manually updating the interval

  1. Select the cell that contains the update interval. To find the cell that contains the update interval,
    1. Select the Home tab.
    2. In the Editing group, select Find & Select > Go To...
    3. Select DVUpdateInterval.
    4. Click OK.
  2. Type a new value.

    If the value is not valid (must be a whole number between 1 and 65), the default rate of 10 seconds is used.
