Creating phase classes

The phase class contains the common properties for the phase logic. Create the phase class in DeltaV Explorer.

For each phase class, you can configure the following class items:

  • Number of Phase Partners

  • Phase Messages

  • Phase Parameters (input and report)

  • Phase Algorithm Parameters

In the Phase Class Properties dialog, enter the description. Each phase inherits its phase class properties.

Phase Class Properties Dialog

Every step in an operation is associated with a phase class. That association links the step to the appropriate phase logic that controls the state transitions. Each phase logic runs on a unit or unit class. When the batch executes, each step in an operation runs on the correct equipment through these associations.
