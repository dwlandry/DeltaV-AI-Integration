Setting up a partner Application Station for redundant DeltaV OPC DA Server

These instructions assume that you already have one Application Station, to which you are adding a second Application Station to use for running an OPC client connected to a redundant DeltaV OPC Data Access Server. Also assumed is that you've made any necessary version upgrades to DeltaV software on the existing Application Station. Alternative setup scenarios include setting up a new pair of Application Stations or reconfiguring an existing pair of Application Stations for redundant DeltaV OPC DA Server.

  • Install DeltaV on the new Application Station
