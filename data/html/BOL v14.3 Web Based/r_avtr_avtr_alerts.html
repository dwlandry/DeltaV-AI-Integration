Analog Voter AVTR_ALERTS

The following table shows the alerts that can appear for an AVTR block, an explanation of each alert, the bit position of each alert, and how to access the alert bit from DeltaV Operate.

Bit Value

Explanation

Bit Position

Access from DeltaV Operate

Trip Active

Inactive when OUT_D is in the normal operating state, active when OUT_D is in the trip state.

0

AVTR_ALERTS.F_CV[1]

Pre-Trip Active

Inactive when PRE_OUT_D is in the normal operating state, active when PRE_OUT_D is in the trip state.

1

AVTR_ALERTS.F_CV[2]

Bypass Active

Active when there is a maintenance bypass on any input (any BYPASSn parameter is True).

2

AVTR_ALERTS.F_CV[3]

Startup Override Active

Active whenever the startup bypass is active.

3

AVTR_ALERTS.F_CV[4]

Deviation Limit Exceeded

Active when the difference between the highest and lowest non-bypassed INn value exceeds DEV_LIM. Forced inactive when DEV_LIM is 0.0.

4

AVTR_ALERTS.F_CV[5]

Expiration Reminder

Active when either a maintenance bypass or a startup bypass is about to expire.

5

AVTR_ALERTS.F_CV[6]

Bypassed Input Pre-Tripped

Active if one or more bypassed inputs have exceeded the pre-trip limit.

6

AVTR_ALERTS.F_CV[7]

Bypassed Input Tripped

Active if one or more bypassed inputs have exceeded the trip limit.

7

AVTR_ALERTS.F_CV[8]

Input Bad

Active if any input has bad status.

8

AVTR_ALERTS.F_CV[9]
