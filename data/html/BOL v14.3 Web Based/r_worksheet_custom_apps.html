Worksheet for custom applications

The ports and protocol information should be provided by the application developer or vendor. If you do not have the ports and protocol information for the custom application, leave it blank. You can determine this information later using the firewall logs.

Application names can be a maximum of 55 characters. Since the applications list in the Smart Firewall is sorted alphabetically by name, it is suggested that you use an asterisk (*) as the first letter in all custom applications so they appear at the top of the list and are easily differentiated from the default DeltaV applications in the list. The asterisk counts as one character.

Note: Custom rules should be added to the applications list in the firewall (Configuration Applications Add new application.
