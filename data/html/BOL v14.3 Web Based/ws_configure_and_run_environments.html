The configure and run environments

DeltaV Operate provides both a configuration and a run-time environment. The configuration environment provides all necessary development tools, including access to toolbars and the files in the system tree. In addition, any process-monitoring background tasks that may be running, such as I/O drivers, Historical Collect, and enabled alarm services, continue to run while the configuration environment is active.

The run-time environment, on the other hand, is designed primarily for operators. With this environment, operators can display pictures and monitor the process. Typically, the run-time environment is configured to restrict operator access to other parts of DeltaV Operate by hiding menu bars and disabling the ability to switch tasks.

Configuration engineers can toggle between the two environments to test and run pictures and schedules. There are a number of ways to switch environments.

From the configure mode, you can switch to run using one of the following methods:

  • select Switch to Run from the Workspace menu 

  • select the Switch to Run button on the toolbar

  • press the Ctrl+W keys

From the run mode, those with permission can use one of the following methods to switch to configure mode: 

  • right-click and select Quick Edit from the context menu

  • press the Ctrl+W keys

As you switch environments, the status bar and window title bar change. In the configuration environment, the text Configure appears. When you switch to the run-time environment, the text changes to Run. In the configure mode, the system tree normally appears in the left pane, unless you have hidden it.

Documents open in one environment remain open when you switch to the other environment. For example, if you have two pictures and one schedule open in the configuration environment, these files remain open when the run-time environment becomes active. If you close one of the pictures in the run-time environment and switch back, the picture that you closed is now closed in the configuration environment. 

Note:

To improve performance, close unnecessary, open documents before switching between environments to test a picture.

You cannot switch to the configuration environment in DeltaV Operate while a script is running. Similarly, you cannot exit the application. Once the script completes, you can switch environments and exit normally. The same restrictions apply to scripts running in pictures. You cannot close a picture until all running scripts complete.

Switching to the run-time environment also hides the system tree, if it is displayed, as well as the workspace and picture toolbars. Switching back reverses the process.

Displaying DeltaV Operate Full-Screen

You can display DeltaV Operate full-screen in either environment. Displaying DeltaV Operate full-screen in configure mode lets you see the exact same scale and display sizes that operators will experience in run mode. To display the full screen, select Full Screen from the Workspace menu.

When you display DeltaV Operate full-screen, it hides the menu bar and any docked toolbars. Floating toolbars remain visible. It also hides the system tree in the configuration environment if it is docked. In the run-time environment, the system tree and configure mode toolbars are always hidden.

Enabling Environment Protection (Restricting Operator Access)

You can restrict operator access to the menu bar and pop-up menus, and prevent task switching by enabling environment protection. This is done through the User Preferences dialog (Environment Protection tab), available from the Workspace menu. Once enabled, environment protection takes effect when you switch to the run-time environment.
