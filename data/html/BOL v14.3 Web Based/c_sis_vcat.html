DeltaV SIS Version Control

Version Control and Audit Trail (VCAT) in DeltaV SIS systems is similar to version control for non-SIS DeltaV items. VCAT can be enabled for SIS items only, if desired. You can enable VCAT for SIS only if SIS is enabled in DeltaV System Preferences.

When DeltaV SIS software is enabled in the DeltaV System Preferences, the Version Control Configuration dialog that opens from Database Administration contains controls to enable version control for DeltaV SIS Module Authorization and SIS Module Function Test Recording. 

VCAT security for DeltaV SIS software uses the following functions and locks that parallel existing VCAT functions. This ensures that you can configure your installation so that only qualified users can perform SIS-related VCAT activities.

  • SIS_VC_CHECKOUT_CHECKIN (default lock = Can Configure SIS)

  • SIS_VC_DOWNLOAD_CHECKEDOUT (default lock = SIS Version Control)

  • SIS_VC_DOWNLOAD_UNAUTHORIZED (default lock = SIS Version Control)

  • SIS_VC_PURGE_RECOVER_ITEMS (default lock = SIS Version Control)

  • SIS_VC_ROLLBACK_ITEMS (default lock = SIS Version Control)

The tasks you perform using VCAT for DeltaV SIS items are nearly identical to the tasks used required to use DeltaV VCAT.

The remainder of this section contains information specific to using VCAT with DeltaV SIS objects.
