Thermocouple / mV input card specifications

Installation notes

  • The Thermocouple terminal block is recommended to provide terminations for field wiring for the Thermocouple / mV input card. An optional terminal block is the 8-channel terminal block.
  • When the Thermocouple / mV input card is plugged into a Thermocouple terminal block, it functions as a Thermocouple card; when it is plugged into an 8-channel terminal block, it functions as an mV card.
  • This card requires an S-series controller.

  • Each channel is optically isolated from the system and factory tested to 1500 VDC.

Note: For all thermocouple sensor types, when a function block is assigned to a thermocouple card, the XD_SCALE and the OUT_SCALE in the function block display the full scale range. When attempting to measure a temperature outside of the full scale range, the module's OUT parameter is clamped within the full scale range and the status of the value transitions to BAD beyond that range. That is, the block displays a value up to the full scale range and beyond that range the value does not change beyond the range limit (High or Low).
Note: In the 25°C reference accuracy column in the following table, total error is made up of reading accuracy, CJC accuracy, and sensor accuracy.
