What's the difference between Operator Keyboard and DeltaV Operate on multiple monitors?

DeltaV Operate on Multiple Monitors

Delta V Operate is designed to run on multiple monitors with no additional engineering required. Up to four monitors can be easily integrated into an existing DeltaV system providing more screen real-estate for your operators. Main operator graphics can be opened on any screen and displays can be easily swapped between monitors. The bottom or center two monitors display the standard DeltaV alarm banner and each monitor uses a toolbar so that operation exactly matches an existing DeltaV workstation.

Operator Keyboard

The DeltaV Operator Keyboard on the other hand, allows you to configure one monitor to act as a dedicated operating screen. Due to the flexible nature of the keyboard configuration, it can be engineered to emulate systems with dedicated keyboards that your operators may already be accustomed to operating. The Operator Keyboard requires engineering and configuration as it is not an "out of the box" solution. Due to its different alarm strategy and the ability to open full screen displays, the Operator Keyboard does not easily integrate into an existing DeltaV system. Refer to About Operator Keyboard for more information.
