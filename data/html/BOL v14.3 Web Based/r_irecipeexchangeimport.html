)

Note:

You can verify your recipe against the DeltaV XML recipe import schema found in the _Support\Recipe Exchange folder on the DeltaV installation disk #1. The XML schema file is named DeltaV_XX_RecipeExchange_Import.xsd (where XX is the DeltaV version number). Additionally, the DeltaV_XX_RecipeExchange_Common.xsd is  a common file used by both the import and export schema files.

This method imports a XML format recipe file.

Return Values

S_OK - success

E_NOT_CONNECTED - Please call Connect First.

E_INVALID_IMPORT_XMLFORMAT - The import XML file has Invalid format.

E_IMPORT_FAILED - The import Failed.

else - failed

Memory Allocation

The caller is responsible for release of the strlog.

Visual Basic Usage Example 

Private Sub Button1_Click()

  Dim myRecipeExchange As RecipeExchange
  Set myRecipeExchange = New RecipeExchange
  myRecipeExchange.Connect
  Dim bstrLog As String

  Dim strFileName As String
  strFileName = "d:\samples\make_toothpaste.xml"
  Dim bNoToAll As Boolean
  bNoToAll = True
  Dim bPreDownloadStatus As Boolean
  bPreDownloadStatus = True
  Dim bAutoCheckOut As Boolean
  bAutoCheckOut = True
  Dim bAutoCheckIn As Boolean
  bAutoCheckIn = True 
  
  Call myRecipeExchange.Import(strFileName, 
                               bstrLog, 
                               bNoToAll,
                               bPreDownloadStatus) 
  
  MsgBox bstrLog, vbOKOnly, "Import"

  myRecipeExchange.Disconnect

End Sub

Parameter Name

Purpose

FileName

The name of the file that will be imported.

Strlog

String that will return the log information of the importing.

NoToAll

=True, import with the "No To All" option (in response to the question about updating existing objects in the database with the object in this file).

=False, import with the "Yes To All" option (in response to the question about updating existing objects in the database with the object in this file).

bPreDownloadStatus

=True, import with the "Preserve Download Status" option.

=False, import without the "Preserve Download Status" option.

bAutoCheckOut

=True, turn on the auto check out VCAT preference.

=False, turn off the auto check out VCAT preference.

bAutoCheckIn

=True, turn on the auto check in VCAT preference.

=False, turn on the auto check out VCAT preference.
