4-wire 16-Channel Analog Input Terminal Block

Installation Notes

  • The 4-wire 16-Channel Analog Input Terminal Block provides 4-wire terminations for the AI, 16-Channel, 4-20 mA HART, Series 2 card.
  • Set the keys on the terminal block to A2 to match the AI, 16-Channel, 4-20 mA HART, Series 2 card.
