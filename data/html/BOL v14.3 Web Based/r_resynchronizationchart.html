Key Legend

<defaults> Formula - The formula uses the parameter's default value. That is, either the formula parameter values were not configured prior to running the batch or the formula parameter values were not set by the operator when the batch was created.

Custom Formula - The formula as created at runtime by the operator setting the formula parameter values.

Configured Formula - The formula as created at configuration time; that is, the formula parameter values were configured using Recipe Studio or DeltaV Explorer.

Batch create value - The initial parameter values when the batch is initially created. These can be different from the default values; for example, if the operator scaled the batch when creating it.

Persisted value -The current runtime value of the parameter.

Formula value - The value of the parameter from when it was created. This is only valid when the formula parameter value has been configured in Recipe Studio or DeltaV Explorer (Configured Formula).
