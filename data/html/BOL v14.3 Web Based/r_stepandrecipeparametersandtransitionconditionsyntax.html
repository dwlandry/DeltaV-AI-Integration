Step and recipe parameters and transition condition syntax

When you include a step parameter in a Boolean condition, use one of the following:

'stepname/parametername'
'stepname/parametername' operator value

When you include a recipe parameter in a Boolean condition, use one of the following:

'parametername'
'parametername' operator value
Note:

You can browse in the Expression Editor dialog to find the correct parameter.
