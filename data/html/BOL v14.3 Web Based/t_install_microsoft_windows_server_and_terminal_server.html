Install Microsoft Windows Server and Remote Desktop Services

Microsoft Windows Server (the version supported for this release) must be installed and Microsoft Remote Desktop Services (formerly Terminal Server) must be installed and the RDS role enabled on the server machine before the DeltaV software is installed. Multiple reboots of the computer are required for this process.

Note: For complete information on configuring the Windows operating system to support the Remote Desktop Services role and Remote Clients, refer to the Emerson Knowledge Base Article for your operating system.
  1. Install Windows Server (the version supported for this release) on the server machine per the instructions found in the Emerson Knowledge Base Article for that operating system.
  2. Add the Remote Desktop Services role per the instructions found in the Emerson Knowledge Base Article for the operating system.
    Note: When adding the role, be sure to select Audio and video playback to allow operators to hear alarm sounds.
  3. When installing the DeltaV software, use one of three choices as the workstation type for the server:
    • ProfessionalPLUS as a Remote Client Server
    • Operator Station as a Remote Client Server
    • Simulate for standalone laptop or workstation
    Important: During installation of the DeltaV software, the correct workstation type must be selected to designate the workstation as a Remote Client server.
  4. After installing the DeltaV software, you must configure the Windows Server operating system properties to enable remote access.
    1. From Administrative Tools, select Services.
    2. Right-click the Routing and Remote Access service and select Properties.
    3. Set the service to enable automatically.
    4. Click OK to close the dialogs.
    5. Open the Systems Properties dialog by clicking Start > Control Panel > System & Security > System.
    6. Select the Remote Settings link.
    7. Select Allow remote connections to this computer.
    8. Click OK if prompted with security message.
    9. Click Select Users... to configure the users.
    10. Enter the users that will have remote access. Click Add to add the user. Click OK when done adding users
    11. Click OK to close the System Properties dialog.
    12. Close the remaining open windows.
  5. On the remote node (the machine that connects remotely to the DeltaV system) you must install the appropriate Microsoft licenses. DeltaV licenses for remote use are assigned in DeltaV Explorer and are based on the existing license structure for DeltaV workstations.
