DVRead and DVReadStatus Function

These functions read the value associated with the parameter property reference and put the value in the cell you specify. The DVReadWithStatus function also returns the status of the call to indicate if any problem occurred between the function call and the DeltaV OPC .NET Server, or other DeltaV data handling software.

Note: To use the DVReadWithStatus function, you must select two adjacent cells (horizontal or vertical) first.
