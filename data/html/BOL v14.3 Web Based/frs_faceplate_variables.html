Faceplate variables

IA_glb contains module Faceplate related definitions. The following table describes the variables declared in IA_glb. IAFB_glb contains function block Faceplate related definitions. The second table describes the variables declared in IAFB_glb. Changes to these global variables are made either in the User_Ref picture or the Layout file. Refer to Customizing the DeltaV Operate Environment.

Variables Declared in IA_glb

Variable

Description

gn_ia_LockEnabled

Allows the faceplate to be pinned

gn_ia_trend_x

Specifies the X coordinate of the Trend window

Note Change the value of this variable using the SetPictureCoordinates function.
