Stopping ongoing connections

When communication is established between an external and internal workstation through the firewall, the communication persists until:

  • Either or both of the workstations stop communicating
  • The firewall is restarted
  • The Operation mode is changed to Deny All

Examples of when communication persists

Suppose that communications through the firewall exist between an external and internal workstation and the Operation mode is set to Normal meaning that all configured protection settings are applied to the communication. When a protection rule is deleted from the firewall, the protection rule persists until one of the actions cited above is taken. If one of the workstations is deleted, the communications with the deleted workstation persist until one of the above actions is taken.

As another example, suppose that communications through the firewall exist between an external and internal workstation and the Operation mode is set to Allow All meaning that all protection rules are bypassed and all traffic can pass through the firewall. If the Operation mode is changed from Allow All to Normal, the existing communications (Allow All) persist until one of the above actions is taken.
