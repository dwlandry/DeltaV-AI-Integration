Securing a workstation in the workplace

Make sure that workstations are physically housed in secure locations. Emerson offers the following recommendations for DeltaV workstations:

  • The ProfessionalPLUS workstation is a mission-critical machine. Make sure it is located in an extremely secure location to avoid physical tampering.
  • Make sure the Application Station is located in a heightened-security area. However, if it must be located in the engineer’s workspace, take precautionary measures to prevent unauthorized physical access to this workstation.
  • Physically isolate the Operator Station CPU from the operator working on it so that it cannot be booted with custom media but can still be reset in the event of a system crash.
  • Use the DeltaVScreenSaver for multi-user operator workstations to make sure that the workstation is locked when the user leaves it and to prevent operators from locking out other operators.
