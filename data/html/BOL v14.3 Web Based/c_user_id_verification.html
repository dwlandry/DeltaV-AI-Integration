User ID Verification

The DeltaV system provides an additional security feature called User ID Verification. In many batch process environments it is necessary to be able to link certain operator actions to the specific individual who performed the action or who approved the action. For example, modifying a batch can be an action for which you need to record who performed the action as well as who approved it. Tracking of such information is particularly important in environments where multiple batch campaigns are running simultaneously. In industries such as pharmaceutical manufacturing, maintaining electronic batch records could be a regulatory requirement. Confirmation and verification settings are set up for Batch Operator Interface commands and for Campaign Manager Operator Interface commands.

If User ID Verification is enabled for adding a batch, a Change User button is available in the Recipe List, Create Batch, and Select Equipment dialogs. This button enables you to temporarily change the user who will be performing the function (adding/creating a batch and binding equipment). Any security checks (area privileges, and so on) are performed on the changed user. Once the function is complete, the logged in user's privileges are checked. Normally the user is changed to a person capable of confirming or verifying the action.
