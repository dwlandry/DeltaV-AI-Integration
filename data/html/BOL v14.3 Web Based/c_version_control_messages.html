Version Control messages

The Version Control - Messages dialog pops up to inform you of changes in the version control database. The changes monitored include:

  • An item has been checked out.
  • An item has been checked in.
  • An item has been added or deleted.
  • A label has been applied to an item.
  • An item has been purged, recovered, or rolled back to a previous version.
  • An item's version number changed during DeltaV upgrade.

The dialog has the following buttons:

  • Clear - Use the Clear button to remove all messages from the dialog.
  • Cancel - Use the Cancel button to stop long operations such as recursive check ins. Canceling an operation interrupts it at the point at which you click the button. Any portion of the operation that has already occurred is not undone by clicking the Cancel button.
  • Copy - After you select one or more messages, the Copy button is available. Use the button to copy selected messages to the clipboard. You can then paste the messages into another application.

Click the minimize (-) button in the upper right to hide the message dialog. When you perform an action that affects the Version Control database, the message window pops up automatically.

Right-click the Control menu (the application icon in the upper-left corner) to define other behaviors of the dialog:

  • Always on Top - places the messages dialog on top of all other windows so that it is always visible
  • Keep Minimized - keeps the messages dialog minimized even during Version Control operations
  • Auto Minimize - minimizes the messages dialog when you select another window
