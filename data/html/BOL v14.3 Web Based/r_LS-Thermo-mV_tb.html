CHARM Thermocouple / mV Terminal Block specifications

Installation notes

  • The CHARM Thermocouple / mV Terminal Block installs on the CHARM Baseplate and holds a single LS Thermocouple / mV input CHARM. It provides the field wiring for the LS Thermocouple / mV input CHARM.
  • The CHARM Thermocouple / mV Terminal Block's keying is fixed to allow only the LS Thermocouple / mV input CHARM.
