Configure a CSLS LS CHARM

When a CSLS is created under the Local Safety Network, the LS CHARMs default to the Undefined channel type. You must then configure the LS CHARMs to define the type of I/O signal.

  1. Navigate to an LS CHARM in the CHARMs subsystem under a CSLS.
  2. Right-click, and then select Properties.
  3. Select a CHARM class. The Enabled check box is automatically selected.
  4. Fill in the Description and Cabling ID fields if desired.
  5. Select a CHARM hardware type.
  6. Select a CHARM functionality.
  7. The Device Tag field is blank at this point but if you click OK and reopen the dialog, the field contains the default DST. To select a Device Tag other than the default, click the Browse button next to the Device Tag field.
    Note: The Browse dialog displays the Unassigned I/O references of the appropriate type for the channel type.
  8. Select an I/O reference, and then click OK.
  9. If required, enter the HART Long Tag.
  10. Click OK in the LS CHARM Properties dialog.
