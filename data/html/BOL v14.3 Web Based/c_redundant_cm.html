Redundant Campaign Manager Server

The Campaign Manager becomes redundant when enabled on a Redundant Batch system. Therefore, you must enable the Redundant Batch subsystem in order to have a redundant Campaign Manager.  From DeltaV Explorer, select the Application Station where the Campaign Manager will exist, right-click and select Properties. From the Redundancy tab, select Enable a redundant subsystem and also select the Batch option.

Note:

Once a redundant subsystem is configured, you cannot concurrently enable any other subsystem (redundant or not) on the Application Station other than the Batch Executive and Campaign Manager subsystems.

The following configurations are supported for the Campaign Managers in redundant Batch system.

Simplex Campaign Manager

A simplex Campaign Manager can connect to either a redundant or simplex Batch Executive. However, once Redundant Batch is enabled, the Campaign Manager on that workstation is automatically redundant (that is, you cannot have a simplex Campaign Manager on a Redundant Batch pair).

To connect a simplex Campaign Manager to a redundant Batch Executive, do not enable Redundant Batch on the Campaign Manager workstation. Then you can have that simplex Campaign Manager connect to a redundant Batch Executive running on another workstation pair.

Redundant Campaign Manager

The redundant Campaign Manager can connect to any Batch Executive, either redundant or simplex.

To connect a redundant Campaign Manager to a simplex Batch Executive, the two must reside on different workstations. Enable Redundant Batch on the Campaign Manager machine and enable the Batch Executive (as simplex) on another workstation.

To connect a redundant Campaign Manager to a redundant Batch Executive, it is recommended that the two reside on the same workstation pair or the campaigns may behave unexpectedly. Therefore, whenever Redundant Batch and both the Batch Executive and Campaign Manager are enabled on the same Application Station pair, then the redundant Campaign Manager should connect to the redundant Batch Executive that is on the same Application Station pair.
