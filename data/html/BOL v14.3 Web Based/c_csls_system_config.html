CHARMs Smart Logic Solver configuration

DeltaV SIS CHARMs Smart Logic Solver (CSLS) system hardware and DeltaV SIS software are used to install, configure, and maintain safety instrumented systems in conjunction with sensors and final elements to take a process to a safe state when hazardous conditions occur. DeltaV SIS CSLS hardware includes the following:
  • DeltaV SIS Controllers (model SZ) — Connect to the DeltaV area control network (ACN) and isolate the CHARMs Smart Logic Solver from the rest of the system.
  • CHARMs Smart Logic Solvers — Connect to the DeltaV SIS controllers through the Local Safety Network (LSN). CSLSs run SIS modules that contain the safety system logic.
  • LS CHARMs (LS stands for logic solver) — The SIS-specific input and output CHARacterizing Modules that bring field signals into the DeltaV SIS CSLS system.

Safety Instrumented Functions (SIFs) are implemented in DeltaV SIS software using CSLSs that are installed on an LSN under a DeltaV SIS controller.

DeltaV SIS Controllers appear in DeltaV Explorer under the Control Network subsystem. CSLSs appear in DeltaV Explorer under the Local Safety Network subsystem of a DeltaV SIS controller. CSLSs are where the safety logic configuration is downloaded and run.

The DeltaV SIS Controller (SISCTLR) has a Modbus TCP connection available to support stand-alone DeltaV SIS installations. The available module types are restricted to control module or template with algorithm types of FBD or SFC. The SISCTLR supports redundancy.

CSLS components are physically separate from, but integrated with, the DeltaV distributed control system (also known as a basic process control system or BPCS). Each CSLS executes SIS modules that perform the safety logic required for each SIF. Safety instrumented functions are configured in one or more SIS modules using the DeltaV engineering tools-DeltaV Explorer and Control Studio. SIS modules are downloaded to run in CSLSs.

In some cases data needs to be shared between SIS modules and/or CSLSs. This data is shared through the use of Secure Parameters and Secure Parameter References. Each CSLS can publish Secure Parameters. These are Boolean with status values that the SIS module can write to and can be referenced by any other SIS module in the same or different CSLS connected to the same LSN.

The simplest CSLS system consists of a single SISCTLR and single CSLS. Up to 16 CSLSs may reside on a single LSN. Larger systems require the addition of separate SISCTLRs, LSNs, and CSLSs to a maximum of 30,000 DSTs.
