Pending Download Changes dialog

The Pending Download Changes dialog lists detailed information about the updated download status of a node or subcomponent of a node selected in DeltaV Explorer.
Item
The selected node or subcomponent of a node
Subsystem
A subsystem of the selected node
Note: If a subcomponent of a node is selected, the Subsystem column does not appear in the Pending Download Changes dialog.
Download Contributors
A list of all modified download scripts contributing to the pending download of a selected item
Download Type
The reason that a download is needed:
  • Add
  • Delete
  • Modify

Save download status information

You can copy the detailed information listed in the Pending Download Changes dialog in the following formats:
  • Tab-delimited text
    You can copy download status information to the Clipboard as tab-delimited text and then paste it into another application, such as a text editor or Microsoft Excel.
    • To copy all details, right-click within the Pending Download Changes dialog, and then select Copy all.
    • To copy details for an individual item, select it, and then press Ctrl+C.
    • To copy details for multiple items, press Ctrl while selecting each individual item, and then press Ctrl+C.
  • XML-encoded data

    To copy all download status information encoded with standardized XML element tags to the Clipboard, right-click within the Pending Download Changes dialog, and then select Copy as XML. You can then paste the details into a text editor, save the file with a .xml file name extension, and import it into Microsoft Excel as an XML table by using the Developer > Import command.



    Note: For more information about importing an XML data file as an XML table, refer to the documentation for Microsoft Excel.
