Use the serial port to retrieve the Smart Firewall's IP address and reset the administrator password

The Smart Firewall's serial port is reserved for factory setup and can be used to retrieve the Smart Firewall's IP address and to reset the administrator password.

  1. Connect a standard, 9-pin serial cable between the Smart Firewall and a PC running a terminal emulation program such as HyperTerminal for Microsoft Windows.
  2. Open the terminal emulation program and enter the following settings:
    • Baud Rate: 115200
    • Data bits: 8
    • Parity: None
    • Stop bits: 1
    • No handshake
  3. Press Enter. The Smart Firewall displays:
    Please specify one of the following options:
    1. Show management IP
    2. Set admin password
    3. Exit

    Your current option is: __

    From here you can show the current IP address, set the administrator password, and return to the firewall's login prompt. Use the firewall's web UI to change the management IP address.
