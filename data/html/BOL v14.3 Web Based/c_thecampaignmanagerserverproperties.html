The Campaign Manager Server properties

The Campaign Manager server properties enables and configures the Campaign Manager server on the node. You configure the Campaign Manager server through DeltaV Explorer. Select and right-click the node that is the Campaign Manager Server, and then select Properties. The Properties dialog opens with three tabs; General, Server, and Action Confirmation.

The Campaign Manager server must be enabled, a Batch Executive node must be selected, and the Campaign Manager must be downloaded before the Campaign Manager client can run.
