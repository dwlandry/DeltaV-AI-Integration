Running phases from DeltaV Operate

When running the phase from the DeltaV Operate faceplates and detail displays, the OWNER parameter is set to External and the operator uses the XCOMMAND parameter. This is shown on the phase's faceplate. When the phase is Idle, you can use the Change Phase Owner toggle button to change from DeltaV Batch to  External (operator) ownership.

Phase Logic Module Faceplate Showing External Control

When running phases from the DeltaV Operate Phase Control object, it is the same as running from the Manual Phase Control screen in the Batch Operator Interface. The OWNER parameter is set to Operator and the commands are sent via the XCOMMAND parameter. This is shown on the Phase Control object's hierarchy.

To run phases from DeltaV Operate, you must have the Restricted Control key. Keys are assigned in User Manager. Security for the OWNER and XCOMMAND parameters is changed from DeltaV Explorer.

To control your phases manually using the Phase Control and Manual Phase Toolbar, you can use the ManualPhaseView.grf picture or create a display and add the Phase Control and Manual Phase Control Toolbar objects to it.

To use the faceplate method, you need to create an operator display that includes the batch equipment and a starting point. Refer to the pertinent topics for more information on configuring DeltaV Operate.

You can create a button on the operator display that will launch the Batch Operator Interface in a specific view. This will enable you to control the view that the operator initially sees when controlling a batch.

Start the phase from the operator's display. After the phase is started, use the HOLD, RESTART, ABORT, STOP, and RESET setpoints to control the phase. If you are testing the phase logic, verify that the state transition diagram progresses as expected. Check each path of the state transition diagram.

Any time a phase is in a terminal state (Stopped, Aborted, or Complete), you must issue a RESET command to return it to Idle.

When a phase's owner is External, the normal 2000 (upload reports) request is not issued when the phase completes its Run logic. However, if a phase has already issued the 2000 request but the Batch Executive is not available to respond (for example, the Batch Executive is offline), you can put the phase into External mode and clear the request from DeltaV Operate. To do this, use the ACK button on the phase's detail display.

The toolbar contains the following buttons:

  • Detail Display button: open the detail display for the module.

  • Primary Control Display button: open the primary control display.

  • Control Studio button: open Control Studio.

  • Event Chronicle button: open the Process History Viewer.
