Using DeltaV toolbars

DeltaV Operate provides a number of standard toolbars for use in configure mode. The toolbars group  commonly used buttons by category.  DeltaV toolbars are "owned by" the Workspace or by Picture. The toolbar's owner defines when the toolbar appears: WorkSpace toolbars appear when the WorkSpace runs; picture toolbars appear only when one or more pictures are displayed. In other words, you won't see the toolbar for adding shapes if you don't have a picture open first.

By default, tool tips are enabled on the toolbars. If you've forgotten what a particular button does, pause your cursor over the button and the tool tip describes the button's function.

  • The DeltaV WorkSpace toolbars are:

    • DeltaV Standard

    • DeltaV Edit

    • DeltaV Utilities

  • The DeltaV Pictures toolbars are:

    • DeltaV Shapes

    • DeltaV Picture

    • DeltaV Text

    • DeltaV Toolbox

    • DeltaV Operating Experts

    • DeltaV Animation Experts

    • DeltaV Tools

    • DeltaV Advanced

    • DeltaV Batch Controls

    • Tools
