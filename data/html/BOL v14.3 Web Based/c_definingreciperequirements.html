Defining recipe requirements

A recipe requires both processing and formulation information. You can choose to perform logic and set recipe parameter values at different levels and in different ways depending on the physical plant and formulations made there. You should have a good understanding of the options involved before determining your overall design strategy.

Creating recipes based on general class-oriented design allows flexibility in using your recipes. Start by defining the basic recipe requirements for use in any of your recipes. This allows you to create a class-based recipe design.

Recipe design begins where the lowest level of equipment configuration ends: in developing logic strategies. A small number of well-designed, versatile, and modular phase classes will allow you to develop and implement new recipes quickly without affecting currently running batches or batch control.
