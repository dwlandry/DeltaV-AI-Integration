Create a formula for PRC_PAINT

To define the PRC_PAINT formula, complete the following steps:

  1. With nothing selected in the Diagram view, right-click in the lower right corner of the Formula view , and then select New Formula to open the Properties from the context menu.
  2. In the New Formula box, enter the name for the formula: LIGHT.

    The formula named LIGHT is created in the Formula view, with values set as the default values originally set in the definition of the phase input parameters for the three parameters. The default values are shown in angle brackets, (< >).

    Note: You may need to press the F5 key to refresh the screen to see the parameters.
  3. Right-click the value for AGITATE_TIME, and select Modify Value from the context menu (or double-click to open the Properties dialog, clear the Use default value check box and change the value to 50. Click OK. Note that you can easily reset the value to the default by selecting the Use default value check box.
  4. Change the remaining two parameter properties for the LIGHT formula, as shown in the following table. Then, add two more formulas--one for a MEDIUM batch (using the default values) and one for a DARK batch.
    Parameter Light Medium Dark
    AGITATE_TIME 50 <30> 40
    PRC_BASE_AMT 180 <150> 130
    PRC_COLOR_AMT <15> <15> 20
  5. Save the PRC_PAINT formula.
