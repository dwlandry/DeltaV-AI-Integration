Configure the structure of external phases in DeltaV Explorer

The external phase referenced in this example uses the DeltaV Soft Phase server. Specific instructions for writing an external phase of type Syncade is covered in its documentation set. However, all external phases must be created in DeltaV Explorer under System Configuration/Control Strategies/External Phases, as described here.

  1. Create a phase class. (In this example, the DeltaV soft phase exe file will have the same name as this phase class, for example, CS_MANUAL_ADD.)
  2. Create a unit class, for example, TANKS.
  3. Associate the phase class with the unit class. That is, drag CS_MANUAL_ADD to TANKS.
  4. Create an external phase under Control Strategies. Associate the external phase with your phase class (CS_MANUAL_ADD in our example).
  5. Right-click the external phase and select Properties.
  6. Set the external phase server to SoftPhase. (If creating a Syncade external phase, select the Syncade option here.)
  7. Enter the soft phase node (that is, where the soft phase will run). (This step is only applicable for the phase server type of Soft Phase.) If left blank, the system defaults to the Batch Executive.
  8. Click OK.
  9. Create a process cell in an area. The process cell must be class based for the Batch Executive to recognize it. Either drag the process cell class down to the area, or select the area and right-click, selecting New > Process Cell.
  10. Create the unit module in the process cell. You can either drag the unit class (TANKS) down to the process cell or select the process cell and right-click, selecting New > Unit Module.
  11. Name the instance, for example, TANK_600.
  12. Expand the unit that will need to run the soft phase (TANK_600) and select the unit phase (CS_MANUAL_ADD).
  13. Right-click the unit phase and change the phase type to External Phase type.
  14. Select the external phase name. You can click Browse and select the external phase created previously.
  15. Assign the area to a Batch Executive.
  16. Download the Batch Executive.
  17. Assign the unit module to the appropriate node (controller) and download that node.
