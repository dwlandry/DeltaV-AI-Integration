Customizing Batch Operator Interface screens

The DeltaV Batch subsystem lets developers customize the information presented to operators in the Batch Operator Interface. By configuring the Batch Operator Interface screens individually, developers can determine what types of information operators receive.

The screens are configured by accessing the System Configuration and Defaults window in the Batch Operator Interface. From the System Configuration window, you can choose from a series of 15 labeled tabs. Each of these tabs opens a window that allows you to configure the corresponding Batch Operator Interface screen or section of a Batch Operator Interface screen.

To ensure that the batch production environment is fully operational, supervisory personnel should evaluate the customized Batch Operator Interface screens. Once this has been done, the batch production process can begin.

You can perform the following tasks from the System Configuration and Defaults window:

  • Display or Hide Columns

  • Change Column and Row Sizes

  • Order and Prioritize Sorts

  • Change Fonts

  • Change Filters

When configuring large systems with multiple Batch Operator Interface workstations, it is easier to configure one workstation's screens and copy the configuration than it is to manually set up each workstation. 

Prompting for an action, confirming an action and verifying an action are configured on each Batch Executive. Enabling commands can be configured at the Batch Executive or for each Batch Operator Interface.

To transfer one workstation's screens setup to another Batch Operator Interface workstation, copy the DVBClient.ini file from the configured workstation to the other workstations.

  1. Go to the C:\DeltaV\DVData\Batch folder.

  2. Select the DVBClient.ini file.

  3. Right-click and select Copy from the context menu.

  4. Go to the DeltaV\DVData\Batch folder on the other machines and paste the file.

Note:

You can access the other workstations' hard drives if they are all on the same DeltaV network. Use Windows' Network Neighborhood to browse for the workstation and DVData folder.
