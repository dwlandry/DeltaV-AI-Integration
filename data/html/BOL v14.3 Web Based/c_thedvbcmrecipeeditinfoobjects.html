The DVBCMRecipeEdit/Info objects

The DVBCMRecipeEdit and DVBCMRecipeInfo objects are used to edit or read information about a recipe object within a given batch. These objects cannot be instantiated unto themselves. Instead, both must be retrieved using the appropriate DVBCMBatchEdit or DVBCMBatchInfo object, or DVBCMCampaignEdit or DVBCMCampaignInfo object methods (get_RecipeEdit or get_RecipeInfo).

The DVBCMRecipeEdit object can represent two types of recipes, depending on where it is called. If the object is called from a campaign's edit object, then it encapsulates all the data for the campaign's base recipe and is used to fill the recipe objects of all future batches added to the campaign. The campaign's recipe edit object can only be retrieved when the campaign is in the defined state. Once any of the campaign's batches have been released to the Batch Executive, the recipe object can no longer be retrieved.

If the DVBCMRecipeEdit object is called from a batch's (versus a campaign's) edit object, then the recipe edit object is used to display and edit the recipe information for that specific batch. The batch recipe edit object can only be retrieved while that batch is in the defined state. Once that batch has been released to the Batch Executive, the recipe edit object can no longer be retrieved. The recipe edit object can be used to view or edit the recipe's scale, formula, parameters or bound units. If only reading (not writing) data, an info object should be used to save system resources and avoid lockout problems.

The DVBCMRecipeInfo object can represent two types of recipes, depending on where it is called. If the object is called from a campaign's info object, it encapsulates all the data for the campaign's base recipe and provides information for all batches currently based on the campaign's base recipe as well as all batches in the future that will be based on the campaign's base recipe. If it is called from a batch's info object, it is used to display the recipe information for that specific batch. The object can be used to view the name, formula, scale, parameter names and values, and bound units and values of the campaign's base recipe or the batch's recipe. If only reading (not writing) data, an info object should be used to save system resources and avoid lockout problems.
