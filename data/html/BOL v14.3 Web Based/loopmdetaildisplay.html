MPC loop detail display (LOOPM_DT)

DeltaV Operate View of the MPC Loop Detail Display (LOOPM_DT)

The loop detail display provides you with access to frequently modified parameters for a loop module as well as status and diagnostics information. It includes the following items:

  • Predict button - Launches the Predict application and connects to the module and function block referred to by the detail display.

Subtopics:

  • Limits (LOOPM_DT)
  • Simulate (LOOPM_DT)
  • Tuning (LOOPM_DT)
  • Alarms (LOOPM_DT)
  • Diagnostics (LOOPM_DT)
