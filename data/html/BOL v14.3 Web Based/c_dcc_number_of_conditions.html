Configure the number of conditions and number of conditions used

The interlock, permissive, and force setpoint conditions are configured from a tabbed dialog that opens from the Properties selection on a block's context menu. From the dialog you can add and modify conditions. By default, a DCC block has one interlock condition and zero permissive and force setpoint conditions.

There are three parameters that set the number of the three condition types used:

  • F_USED_CND — number of force setpoints used can be as many as 8.

  • I_USED_CND — number of interlock conditions used can be as many as 16.

  • P_USED_CND — number of permissive conditions used can be as many as 8.

In an instance of a class-based module, conditions cannot be added or deleted, but their evaluation order can be changed and the number of conditions used (evaluated) can be changed.
