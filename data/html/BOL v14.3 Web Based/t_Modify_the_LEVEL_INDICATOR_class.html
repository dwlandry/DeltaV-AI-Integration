Modify the LEVEL_INDICATOR class

  1. Open LEVEL_INDICATOR in Control Studio and select the AI block.
  2. Select the tuning parameter SIMULATE, and then open the Properties dialog.
  3. Select Enabled, check the Allow instance value to be configured box, and then click OK.
  4. Select the I/O parameter OUT_SCALE and open the Properties dialog.
  5. Change the 100% scale to 1000 and the Engineering unit to gallons (gal), and then check the Allow instance value to be configured box.
  6. Select the L_TYPE tuning parameter, and then change the named state to Direct.
  7. Select the HI_ALM parameter in the Alarm Parameters window, and then open the Properties dialog.
  8. Change the Limit value to 950, and then click OK.
  9. Open the Properties dialog for the module class and, on the Displays tab, browse for and select Process as the primary control display.
  10. Save the module, and then close Control Studio.
