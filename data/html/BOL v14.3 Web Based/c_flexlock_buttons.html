FlexLock buttons

The FlexLock window contains five buttons:
DeltaV Desktop
Switches the desktop to the DeltaV desktop. Depending on your privileges, the DeltaV Desktop allows you access to either both desktops or to only the DeltaV Desktop and DeltaV Operate.
Windows Desktop
Switches the desktop to the Windows desktop, provided the current user has sufficient privilege. The Windows desktop includes the DeltaV programs as well as all Windows programs. If the current user does not have sufficient privilege, a popup appears from which the user can open a dialog to gain temporary access to the Windows desktop. From the dialog, the user enters a user name and password for an account that has Windows desktop access. The access on the Windows desktop is of the user logged on to the DeltaV software.
DeltaV Operate
Launches the DeltaV Operate application on the current desktop (either the DeltaV Desktop or the Windows Desktop). DeltaV Operate allows operators to interact with the process control system through the use of high-resolution graphics.
To configure DeltaV Operate to launch automatically after a user logs on, select the Autorun DeltaV Operate option.
Note:
  • If you are logged on to the DeltaV system with Windows desktop privileges, you are running DeltaV Operate on the Windows desktop, and Flexlock's automatic switching is enabled, you must close DeltaV Operate before using DeltaV Logon to log off the DeltaV user. The next user (specifically one without Windows desktop privileges) may not be able to run DeltaV Operate because FlexLock only allows one instance of DeltaV Operate to run on the system.
  • If a DeltaV Live workstation has been configured to use DeltaV Live only, the DeltaV Operate button is disabled.
DeltaV Live
Launches a new instance of the DeltaV Live application on the current desktop (either the DeltaV Desktop or the Windows Desktop).
To configure DeltaV Live to launch automatically after a user logs on, select the Autorun DeltaV Operate option.
DeltaV Logon
Launches the DeltaV Logon application, where you select a computer or domain name, select a user name, and enter your password to gain access to DeltaV software.
