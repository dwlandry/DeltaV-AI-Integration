Troubleshooting communication rules

If an application is running but not working properly it is possible that your installation is configured to use communications ports that are different from the DeltaV defaults. To resolve possible incorrect rule configuration, you will create a special rule that allows the problem application to communicate through the firewall using all possible ports and protocols. This will allow you to collect log data on the application so you can discover all of the ports and protocols that the application is using. You can then compare the data in the log to the configuration data in the rules you created to allow the application to communicate through the firewall.
