Built-in Windows groups

This topic is concerned only with the default groups created by DeltaV software. It is possible to create additional Windows groups, but this is not necessary and not recommended for use with DeltaV software. When you select File > New > User the New User dialog opens.

DeltaV User Manager New User dialog

By default, the Operating System (Windows) Account and DeltaV Database Account check boxes are selected.

Once a user account exists, you can modify the account type in DeltaV User Manager by double-clicking the account name to access the user account properties.

Note: To ensure proper tracking of security events, the software creates a record in the Windows Events Viewer's Application log when a user is added or deleted with the DeltaV User Manager application.

You do not assign DeltaV users to Windows groups directly. When you create a user in the DeltaV User Manager the selections you make for each user determine the Windows groups to which the user is assigned. The following tables show how the New User dialog selections put users in Windows groups that standard DeltaV software created during DeltaV software installation.

Note: The DeltaV installation creates other groups to support Emerson software that can be purchased and installed separately.

Basic Configuration

DeltaV Basic Configuration

Domain DeltaV Basic Configuration

Have restricted access to DeltaV applications and their folders.
In workgroup settings, access to Windows features is controlled by New Technology File System (NTFS) security settings.
In domain systems, access to Windows features for users in this group is controlled by NTFS security settings and further limited by the DeltaV Basic Configuration Group Policy Object (GPO).

Basic Operator

DeltaV Basic Operator

Domain DeltaV Basic Operator

Have restricted access to DeltaV applications and their folders.
In workgroup settings, access to Windows features is controlled by NTFS security settings.
In domain systems, access to Windows features for users in this group is controlled by NTFS security settings and further limited by the DeltaV Basic Operator Group Policy Object (GPO).
Note: Be aware that NTFS permissions and Group Policies can disallow privileges granted through DeltaV keys. For example, if a user is granted the Can Configure or Can Download key but is prevented from accessing the DeltaV Explorer because of NTFS permissions associated with that user's role, downloading and configuring privileges are disallowed.
