DeltaV remote I/O nodes and cards

The DeltaV I/O Network contains Remote I/O Nodes and cards as well as CHARM I/O Cards and CHARMs. Remote I/O Nodes can be installed in Zones 1 and 2 and bring I/O from cards installed in these locations into the DeltaV system. Remote I/O Nodes perform no control and have no assigned modules. Remote I/O cards are added to the I/O subsystem under Remote I/O Nodes and the cards are assigned to a DeltaV controller. It is possible to assign all cards under a Remote I/O Node to a single controller or assign individual cards under one Remote I/O Node to multiple controllers. Refer to the DeltaV Explorer help for instructions on how to add Remote I/O Nodes and cards and assign remote I/O to a DeltaV controller.
