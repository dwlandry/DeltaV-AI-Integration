IDVBCMCampaignEdit4::setexecutionmode4

Note:

There is not an equivalent Info method.

Note:

Some previous versions of this method took only a confirmer name and a verifier name. The current method takes a confirmer name and password and a verifier name and password. If the old methods are used and confirmation is required for modifying campaigns, the confirmer and verifier names passed to SetExecutionMode(2) must be the same as those passed to AddCampaign or GetCampaignEdit (whichever call was made to retrieve the DVBCampaignEdit Object). Note also that there may be a potential issue here if the Add Campaign action does not require confirmation info, but the Campaign Modification action does. In this case, it may be necessary to call GetCampaignEdit after calling AddCampaign (and retrieve a new DVBCampaignEdit object) in order to pass the user names and passwords necessary.

This method is used to change the execution mode of the campaign. It is only avaiable from the campaign edit object, which must be in the DEFINING state and not locked (unless by the caller). If bIsAutoStart is set, bIsAutoRelease is implied and should also be set. Setting a campaign's execution mode to manual immediately stops all automatic processing of batches unless they are under the control of the Batch Executive, in which case they must be stopped from the Batch Operator Interface or if the AutoRemove functionality has been associated with Manual mode.

Return Values

S_OK - success

else - failed

Memory Allocation

none

Visual Basic Usage Example

Private Sub Button1_Click()
    Dim objCampaignEdit As IDVBCMCampaignEdit4
    Call GetCampaignEditObject(objCampaignEdit)
    Call objCampaignEdit.SetExecutionMode4(False, False, True)
End Sub
