Using DeltaV OPC Mirror

OPC defines two kinds of applications: servers and clients. Servers provide data services to control systems, industrial buses or proprietary devices. Clients access servers to make use of their data.

The OPC specification also defines how OPC clients and servers communicate, but it does not define how servers interconnect with each other. To connect servers, you need a client application like the OPC Mirror. The OPC Mirror linkage can be between DeltaV OPC Data Access Servers or any other OPC servers. Any data item that an OPC server accepts when adding items is also acceptable in OPC Mirror.

OPC Mirror connecting two OPC servers

OPC Mirror's standard Windows interface makes it easy to learn and it requires no custom code to transfer data between all standard OPC systems. After it is configured, it runs quietly in the background, transferring data back and forth between OPC servers. Mirror can even handle large integration tasks.
