WirelessHART devices: configuring and using

WirelessHART devices are configured exactly like hard-wired HART devices. Refer to the DeltaV Explorer online help for information on configuring HART devices. The 1420 Wireless Gateway and WirelessHART devices are supported by Version Control Audit Trail and Bulk Edit. WirelessHART devices also support PlantWeb Alerts.
