Guardian registration parameters (Smart Switch)

A number of parameters hold Guardian registration information read from the switch. You use these parameters in custom displays showing DeltaV Smart Switches. These parameters are not configurable values:

  • XINFO_MODEL
  • XINFO_HWREV
  • XINFO_SWREV
  • XINFO_SERIAL
