Secure writes from DeltaV Diagnostics

DeltaV Diagnostics uses the Secure Write Mechanism to send commands to Logic Solvers.

The following commands for a Logic Solver are available: 

  • Lock

    Note:

    Locking removes forced inputs, which may cause a plant trip.

  • Unlock

  • Switchover

  • Force Reset on Active (All outputs go to zero.)

  • Force Reset on Standby 

Note that Force Reset has no effect on a simulated Logic Solver card.
