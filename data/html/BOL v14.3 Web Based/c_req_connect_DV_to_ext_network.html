Requirements for securely connecting a DeltaV Control Network to an external network

It is important to adhere to the following requirements when connecting a DeltaV Control Network to an external network.

  • All external network access to a DeltaV Control Network must be through a DeltaV workstation. Direct connections between the DeltaV Control Network and external networks are strictly prohibited.
  • For security reasons, all DeltaV workstations must be segmented from external network access through a perimeter firewall such as the Emerson Smart Firewall or through another security device that tightly controls and monitors network access to DeltaV workstations.

Important Internet restrictions

  • DeltaV workstations must never be installed or configured to allow users unrestricted access to the Internet for any reason.
  • DeltaV workstations must never be installed or configured to allow direct access from the Internet to a DeltaV workstation for any reason.

Requirements for passing information into or out of a DeltaV Control Network

Observe the following requirements for passing information such as data files, process data, and so on into or out of a DeltaV system:

  • Use a secure Demilitarized Zone (DMZ) architecture. Install a DMZ network between the Emerson Smart Firewall and the external network.
  • Install computers in the DMZ network to provide interposing access points for passing information between the DeltaV Control Network and the external networks.
  • Terminate communications that import or send information into the DeltaV Control Network in the DMZ computer and store the information on the DMZ computer in a location such as an OPC database or a folder.
  • Terminate communications from a DeltaV workstation that receives information from an external network in the DMZ computer and ensure that the information is fetched or pulled from the appropriate location in the DMZ computer.
  • Terminate external communications received from a DeltaV workstations in the DMZ computer and ensure that the information is fetched or pulled from the appropriate location in the DMZ computer. The DeltaV workstation sending the information should communicate only to the DMZ computer and the information placed in the appropriate location on that computer.
  • Never configure direct communications connections between applications running on an external computer and a DeltaV workstation.
  • Use a secure VPN for any remote user connections to DeltaV workstations that originate from outside of the facility and then terminate the connection on a DMZ computer and make a new remote connection from the DMZ computer to the DeltaV workstations.
