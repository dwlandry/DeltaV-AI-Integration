OPC Historical Data Access clients

This section describes an OPC HDA sample client application for use with the DeltaV OPC History Server. This client application, OPCHDAClient.exe, is located in the DeltaV\bin directory. It allows you to create an XML input script file that is used as a command line argument and writes output to text files. The XML schema file (DvOpcHda.xsd) for the XML script files is located in the DeltaV\DVData directory, and several example XML script files are available in the DeltaV\samples\opchda directory. You can write your own OPC HDA client applications based on the OPC HDA specifications outlined in the DeltaV OPC History Server topic.

To use the OPCHDAClient.exe sample client provided with the DeltaV software, it is assumed that the user is familiar with XML and has access to an XML schema tool, such as XML spy.
