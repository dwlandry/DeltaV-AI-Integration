Add SISNet Repeaters to an operational system

Additional SISNet Repeaters can be added to an operational DeltaV SIS system to extend the system. However, care must be taken to add the SISNet Repeaters without disrupting communication on the remote peer ring.

Note: Refer to Set up the remote peer ring and to the specifications in the SISNet Repeater and Distance Extender Specification section before adding SISNet Repeaters and SISNet Distance Extenders to an operational system.
Note: SISNet Distance Extenders are considered to be part of a SISNet Repeater node (primary or secondary). Add SISNet Distance Extenders along with SISNet Repeaters one node at a time to ensure that communication on the remote peer ring is not disrupted.

The following example shows how to add a third SISNet Repeater pair to an operational system.

  1. Install the carriers, Logic Solvers, cards, terminators, and the new SISNet Repeater pair. In this example, the new SISNet Repeater pair is referred to as Pri. (Primary) and Sec. (Secondary) SISNet Repeater 3.
    A Third SISNet Repeater added to an operational system


  2. Remove the cable labeled “a” in the preceding image from the existing two Pri. SISNet Repeater nodes and replace it with a new fiber-optic cable that connects R (RxD) on Pri. SISNet Repeater 1 to T (TxD) on the new Pri. SISNet Repeater 3.
  3. Install a fiber-optic cable that connects R (RxD) on the new Pri. SISNet Repeater 3 to T (TxD) on Pri. SISNet Repeater 2.
  4. Open DeltaV Diagnostics and be sure that OInteg is GOOD for each primary SISNet Repeater (REPEATER01). (The path to SISNet Repeaters is SISNetwork/Repeaters/Controller/SISNet Repeaters/REPEATER01/02.)
  5. Remove the cable labeled “b” in the preceding image from the existing two Sec. SISNet Repeater nodes and replace it with a new fiber-optic cable that connects T (TxD) on Sec. SISNet Repeater 1 to R (RxD) on the new Sec. SISNet Repeater 3.
  6. Install a fiber-optic cable that connects T (TxD) on the new Sec. SISNet Repeater 3 to R (RxD) on Sec. SISNet Repeater 2.
  7. In DeltaV Diagnostics, be sure that OInteg is GOOD for each secondary SISNet Repeater (REPEATER02). (The path to SISNet Repeaters is SISNetwork/Repeaters/Controller/SISNet Repeaters/REPEATER01/02.)
