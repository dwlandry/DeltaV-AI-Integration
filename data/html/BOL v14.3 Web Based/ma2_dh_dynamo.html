MA2_DH_ analog dynamo, 2 function blocks, horizontal deviation bar graph

This dynamo can be used for analog indication where deviation from SP is important. Used with PID loops and ALM function blocks.

The following elements are present on the dynamo:

  • Alarm Icon

  • Display Tag

  • Dynamo Background

  • Engineering Units Descriptor

  • Mode Icon

  • PV Data Field

  • PV-SP Deviation (comparison) Bar Graph

  • Status Icon
