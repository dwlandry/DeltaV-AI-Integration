PopupClose function

PopupClose() closes 'this' display, if it is running in a pop-up window.
Arguments
0
Return values (Boolean)
True, if the display or contextual display containing the script calling this function is running in a pop-up window and is closed by the user.
False, otherwise.
Syntax
DL.PopupClose()
Examples
Example Result
Add a button to a display that is configured to open as a popup display. Configure an action on the button using this expression: 
DL.PopupClose()
 When the user clicks the button, the popup display closes.
Note: This function closes pop-up displays and contextual displays in either their visible (restored) or minimized state. It also force closes contextual displays running in tooltip-style pop-up windows.
