Bulk editing equipment and control modules

This example shows how you can use Bulk Edit to configure copies of a module. The example module is a control module that consists of an Analog Input function block and a Calculation function block. The module provides temperature both in degrees Celsius and degrees Fahrenheit. The information in this section applies to equipment modules as well.

The example starts with the creation of the custom module and then outlines the requirements for successfully creating the format specification file and editing the exported data. Note that successful import and export of a module requires the module be template based. The template and the module must have the same SubType (as defined in the module and template Properties dialogs). Following the steps in the example ensures this.
