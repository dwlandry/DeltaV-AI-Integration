The batch list screen

The Batch List screen is the primary administrative screen in the Batch Operator Interface. This is the screen that opens by default when the Batch Operator Interface is launched.

Batch List Screen

The following tasks are performed only through the Batch List screen:

  • Adding a batch

  • Removing a batch

In addition, all other commands can be issued from the Batch List screen.

The summary column in the Batch List screen uses the following abbreviations to represent all the statuses found in that recipe. A number listed next to the abbreviation represents the number of phases in that state.
