Integrating PROVOX and RS3 I/O

The DeltaV Interface to PROVOX I/O and DeltaV Interface to RS3 I/O enable you to use existing PROVOX and RS3 I/O with a DeltaV system. Support for PROVOX and RS3 I/O is integrated into the DeltaV Explorer, Diagnostics and Control Studio applications.

Documentation for these interface products is in the following locations:

  • DeltaV installation disk #1 \_Support\DeltaV Interface for PROVOX IO

  • DeltaV installation disk #1  \_Support\DeltaV Interface for RS3 IO
