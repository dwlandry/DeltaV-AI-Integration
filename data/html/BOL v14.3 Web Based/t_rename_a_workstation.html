Rename a workstation

  1. Log in to Windows on the ProfessionalPLUS workstation as a user with Administrator privileges.
  2. Log in to DeltaV as a user with Administrator privileges.
  3. From the ProfessionalPLUS workstation open DeltaV Explorer.
  4. Select the node being renamed, right-click, and then select Rename. If this node has Alarms and Events enabled, you are prompted to disable Alarms and Events prior to renaming the workstation. To disable it, expand the workstation in the DeltaV Explorer hierarchy and right-click the Alarms and Events item. Select Properties from the context menu. Uncheck the box and click OK.
  5. Enter the new workstation name.
  6. On the popup dialog that appears, click the Yes button to create a workstation configuration file.
  7. On the workstation you are renaming, log in to Windows as a user with Administrator privileges.
  8. Stop all DeltaV programs.
  9. Run DeltaV Workstation Configuration.
  10. From DeltaV Workstation Configuration, click Next, Next, Browse, and select the correct workstation name from the list in the workstation configuration file.
  11. Restart the computer when prompted by DeltaV Workstation Configuration. After the computer has restarted, log in to Windows as a user with Administrator privileges and let DeltaV Workstation Configuration complete.
  12. From the ProfessionalPLUS workstation use DeltaV Explorer to download all the nodes (you can either download them individually or as a group) on your DeltaV network.

If you rename any workstations that are SQL servers (such as the Batch Historian, or Version Control machines), you must shut down and restart the workstation or restart the SQL Server. For more information about renaming a server, refer to the SQL Server online help.

If you are renaming a workstation on a domain, you must verify the name and IP address of the newly renamed workstation has been updated in Active Directory and also on the DNS server. Go to the workstation that was promoted to domain controller first and verify that Active Directory is updated. Go to the DNS server (also on the first domain controller), right click the My Computer icon (this icon may have been renamed to the actual computer's name) and select Properties. Verify the IP address for the newly renamed workstation is updated. Workstation Configuration creates a new IP address for the workstation when it is renamed.

If you are renaming a Continuous Historian workstation, you will need to export your datasets and import them after the rename. This is due to Continuous Historian using the workstation name as part of the data source name. Historical data collection will be stopped during the renaming process.
