The following table shows the available fields and valid field values for unit modules.

Valid Field Values for Unit Modules

Field

Valid Values

Required for Import

description

As many as 255 characters using any keyboard characters. Note that only the first 24 characters appear in faceplates.

No

area

Plant area name may be up to 16 characters long.

Yes

unit_mod_class

Unit class name. The class must already exist in the database.

Yes1

unit_mod_name

Unit module name. As many as 16 characters. The string must contain one letter and can include the following: $, -, _.

Yes

No

Equipment ID used by the system to acquire and release resources.

Valid range: 1 to 65535.

No

Specifies the number of requesters that can use this resource simultaneously.

No

How downstream units are selected. Valid values are:

  • no_downstream_units

  • use_selected_units

No

Used on class-based unit modules only. All units in the Downstream list must currently exist in the configuration.
