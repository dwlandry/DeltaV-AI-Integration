Bulk edit SLS 1508 logic solvers

This section outlines how to bulk edit Logic Solvers, which exist in the DeltaV Explorer hierarchy under the SIS Network.

The general procedure to bulk edit Logic Solvers is:

  1. Create and configure one Logic Solver, including the hardware alarms.
  2. Use the Logic Solver.fmt format specification file to export the Logic Solver or create your own format specification file.
  3. Copy and edit the exported Logic Solver in the bulk edit Excel template as required.
  4. Import the edited data.

You must at least provide unique names in the logic_solver column for each Logic Solver. 

To create assigned Logic Solvers the node_name column must contain the name of a node that already exists in the database and the card_slot column must contain a node slot number that contains a Logic Solver card. 

To create unassigned Logic Solvers enter <NULL> in the node_name and card_slot columns.
