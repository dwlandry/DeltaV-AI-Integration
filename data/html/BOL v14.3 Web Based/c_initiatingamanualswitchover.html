Initiating a manual switchover

From DeltaV Diagnostics, a user with the Diagnostic key (including the Diagnostic_Switchover function) can initiate a manual switchover, in which the standby assumes the role of active.

After a switchover event that occurs when the Unattended Workstation Reboot on Failover or Manual Switchover option is disabled, the standby takes over as the active. However, the former active will not reestablish itself as the standby until the Application Station (former active now the pending standby) is restarted.  That is, to bring the former active into standby status, you must restart the Application Station where the red error light is flashing in the DeltaV Status window. This is true for a manual switchover, as well as for an unplanned switchover. This leaves the system in a simplex mode.

The Unattended Workstation Reboot on Failover or Manual Switchover option restarts the failed workstation without human intervention so that it can reestablish itself as the new standby (provided there is not an underlying problem with the physical computer).
