Soft phase application example

The following is an example of how you can use Soft Phases in your batch process. This is only an example and learning tool.

Soft phases are programs running on the PC that behave like controller based phases. Soft phases can be included in recipes just like any other phase in the DeltaV system. These phases are configured using predefined Visual Basic (version 6), VB .NET, Visual C++ (version 6) and VC .NET shells that include predefined function calls for common needs.

The example soft phase issues a series of prompts to the operator. These prompts request the lot number and amount of color stabilizer to add to the batch. The sample code checks the color stabilizer file (an XML file, color_stabilizer_db.xml) to determine if the material exists, if there is enough of the requested lot number available, and verifies that the material's expiration date has not been exceeded. If all conditions are met, the soft phase allows the recipe to continue. If even one condition is not met, then the soft phase relays this information back to the operator. At this point the operator can choose to proceed with entered information (lot number and quantity) or can enter another selection.

Note:

You must create the color_stabilizer_db.xml file for use with the sample soft phase application.

This application shows interaction with external control (the operator and a soft phase) and an information system (a text file). You can expand this example to show interaction with other external controls and information systems, such as the following:

  • Material and inventory databases

  • Barcode readers

  • LIMS systems

This might also include manual processing steps required by the batch, which means you can easily capture historical data, electronic signatures and operator comments for these types of activities and have them included in the electronic batch record.
