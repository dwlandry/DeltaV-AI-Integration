CSLS AdviseAlerts diagnostic parameter

AdviseAlerts diagnostic parameter

Parameter name in Diagnostics Explorer

Context in Diagnostics Explorer

Runtime path

Description

AdviseAlerts

CSLS

CSLS_NAME/ADVISE_ALERTS

Advisory alert status of the CHARM smart logic solver, combination of both cards when redundant

AdviseAlerts condition text

Condition Text in AdviseAlerts

Meaning

Action

CHARMbus Termination Error

CHARMbus terminator on the last LS CHARM baseplate is missing.

If the condition persists, contact Emerson Technical Support.

CHARMs subsystem Mismatch

The configuration for one or more communicating LS CHARM does not match the physical LS CHARM.

If the condition persists, contact Emerson Technical Support.

Configuration Mismatch Between [CHARMs] Logic Solver and Controller

The Controller detects a mismatch between the configured and reported DeviceCRC.

If redundant, do a switchover of the logic solver. If the condition does not clear or the logic solver is simplex, download the logic solver.

CPU Free Time Low < 20%

The idle time on one or both of the main processors is less than 20% of the total task time.

Change to a slower logic solver scan rate and re-download.

High Railbus Error Rate

The Main Processor 1 detects a high percentage error rate in communications with the Controller.

Can be due to an environmental specification being exceeded. If the condition persists, contact Emerson Technical Support.

High Redundancy Link Error Rate

The Logic Solver detects a high percentage communications error rate on the redundancy link.

Can be due to an environmental specification being exceeded. If the condition persists, contact Emerson Technical Support.

I/O Processor Communication Error

The Logic Solver detects a high percentage error rate in communications with the I/O Processor.

Can be due to an environmental specification being exceeded. If the condition persists, contact Emerson Technical Support.

I/O Processor Integrity Error

The I/O Processor is reporting a calibration or self-test error.

Check the value of IO_DEV_STATUS. A calibration issue requires a hardware return. If an incomplete self-test error persists, contact Emerson Technical Support.

Internal Communications Error

A high percentage error rate exists in communications between the main processors.

Can be due to an environmental specification being exceeded. If the condition persists, contact Emerson Technical Support.

Local Safety Net High Error Rate

The total bit error rate on the controller interfaces exceeds 10-4.

If the condition persists, contact Emerson Technical Support.

Non-Critical Mismatch Between Main Processor Data

The main processors have detected a mismatch in dynamic data other than outputs and secure parameter values

The logic solver will still be able to respond to a demand if this condition is active. If the condition persists, do a switchover of the logic solver or download it. If the condition does not clear, contact Emerson Technical Support.

Non-Volatile Memory Alert

The Non-Volatile Memory (NVM) available for parameter change records is low or exhausted.

Use DeltaV Explorer to upload recorded parameter changes for the logic solver, then re-download.

Proof Test is Overdue

The number of days since the last proof test has exceeded the required proof test interval

Perform a manual proof test.

Proof Test Reminder is Active

The number of days since the last proof test is approaching the required proof test interval.

If an automatic proof test has been configured, this alert indicates the test will begin in five minutes. Otherwise, a manual test should be scheduled.

Self-Test Incomplete

A periodic memory test failed to complete in the allotted time.

Check the value of DIAG_STATUS and IO_DEV_STATUS to determine if the issue is with the main processors or I/O processor. If the condition persists or repeats, contact Emerson Technical Support.

SIS Communications High Error Rate

For CHARMs Smart Logic Solvers, the total bit error rate on local peer communication interfaces has exceeded 10-4.

If the condition persists, contact Emerson Technical Support.

SISNet High Error Rate

The Main Processor 1 or Main Processor 2 has detected a high peer bus error rate.

Can be due to an environmental specification being exceeded. If the condition persists, contact Emerson Technical Support.

Task Checkpoint Alarm

A non-critical task has not completed properly in one of the subsystems.

If the condition repeats, contact Emerson Technical Support.
