Back up a historical data set

The current backup status of a historical data set appears in the Backup Status column of the Continuous Historian Administration application.

Value

Description

Modified Either the data set has changed since the last time it was backed up or the data set has never been backed up.
Backing Up The data set is currently being backed up.
Note:

Screen-update delays may cause this value to be temporarily out-of-date.

Backed up The data set has been backed up and no data has changed since the last time it was backed up.
Note: During manually-initiated backup operations, screen updates to the value in the Backup Status column are suspended.

To back up an active or current data set to a specified directory, the user must have the DeltaV security key for the HDS_BACKUP function, and then complete the following steps:

  1. Select the Primary storage area from the left pane of the main display.
  2. Click the Backup DeltaV Continuous Historian Data icon on the toolbar or select Backup DeltaV Continuous Historian Data from the Tools menu.
  3. Browse to the directory where you want the files backed up. It is recommended that you select a directory location on the current workstation, but outside the \DeltaV system directory.
  4. Click OK. If you interrupt the backup operation by clicking the Abort button, any exported data sets already created are not affected; however, creation of an exported data set that is in progress is not completed.

    The Backup DeltaV Continuous Historian Data dialog shows the progress of each data set as it is backed up and informs you if there are any errors.

A subdirectory is created for each data set with a unique name based on the date and time in the format DvCH_YYMMMDD_hh.mm. The file names of the backed up data sets are unique within the subdirectory. If the same files are backed up again, the directory name will change, but the same data sets will have the same archived file names. Each backup file is a collection of historical data files that may be restored as a collection or brought back online individually as extended historical data sets. Backing up historical data does not delete the data sets from Primary storage.

Note:

The DeltaV Continuous Historian also includes an automated backup utility that can be used to perform scheduled backups of DeltaV Continuous Historian data from the Windows Scheduler or from a third party application. For more information, refer to Books Online.
