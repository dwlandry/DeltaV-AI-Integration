Accessing intelligent field device diagnostic data

You can configure a module to access diagnostic data from any Profibus DP, DeviceNet, or Foundation fieldbus device listed in Library/Device Definitions in DeltaV Explorer. Providing access to diagnostic data from Profibus DP, DeviceNet, and fieldbus devices allows you to better predict problems in your control environment and to implement strategies that react to and prevent less than optimal processes. Additionally, the opportunity for operators to troubleshoot device problems and prevent unstable process situations is enhanced. The configuration engineer is also able to create an alarm, based on device diagnostic information, to signal the need for operator intervention.

A module configured to access diagnostic data from a Profibus DP, DeviceNet, or fieldbus device allows you to specify:

  • A reference parameter that refers to a DeviceNet diagnostic parameter

  • A reference parameter that refers to the array of bytes returned by a Profibus DP diagnostic message

  • A reference parameter that refers to the resource block, transducer block, or function block parameter of a fieldbus device

  • Alarms triggered by diagnostic parameter values

  • Data marshalling of diagnostic parameters to detail displays and historians
