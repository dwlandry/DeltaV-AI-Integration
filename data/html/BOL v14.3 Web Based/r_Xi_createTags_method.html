CreateTags method (C#)

To create new history tags, use the following syntax in a C# program: 

public void XiContext.CreateTags (
        List<OPCHDA_TAGDATA> TagData, 
        out List<TAG_ERROR> ErrorList);
Parameter Description
TagData A list of OPCHDA_TAGDATA objects, representing the tag to be created and its type.

The OPCHDA_TAGDATA class is defined as follows: 

public class OPCHDA_TAGDATA {
    public string TagName;
    public uint TagType; // 2=Float, 3=String
    public OPCHDA_TAGDATA();
}
ErrorList A list of TAG_ERROR objects returned, containing the return code for each corresponding tag created.

The OPCHDA_TAGDATA class is defined as follows: 

public class TAG_ERROR {
    public int TagError;
    public string TagName;
    public TAG_ERROR();
}
Important:

After creating a history tag using the CreateTags method, it cannot be modified or deleted.

Rules and operation

The CreateTags method attempts to validate all .HDE tags passed according to the following rules:

  • Historical data is identified by the history tag string specified for a history sample. History tag strings must conform to the following syntax:

    HDE_tag_prefix.HDE

    The .HDE suffix distinguishes a history tag from a scanned data tag.

    HDE_tag_prefix must conform to the following rules:

    • Can be no more than 160 Unicode characters
    • Can contain alphanumeric characters only
    • Must include at least one alphabetic character (using the current DeltaV locale)
    • Can contain no character that has a different code value if converted to upper case (using the current DeltaV locale)
    • Can contain the following nonalphanumeric characters:
      • Dollar sign ($) – 0x0024; decimal 0036
      • Hyphen (-) – 0x002D; decimal 0045
      • Slash mark (/) – 0x002F; decimal 0047
      • Left bracket ([) – 0x005B; decimal 0091
      • Right bracket (]) – 0x005D; decimal 0093
      • Underscore (_) – 0x005F; decimal 0095
    Note:

    All history tags are converted to uppercase before being created in a data set.

  • The OPC write interface supports a maximum of 2,000 unique history tags with one or more history samples in the current and active historical data set.
  • Two or more history samples cannot have an identical history tag and time stamp.
