View the picture in run mode

  1. Click Workspace > Switch to Run or press CTRL+W.
  2. Click the Open Main Display button and select TANK101.

    If you have a controller configured, the datalinks appear as numbers. The numbers are not realistic because you do not have any real I/O devices configured. If you have a placeholder for a controller, the numeric datalinks appear either as symbols (such as @ or &) or as specified in the User Preferences dialog.

  3. Return to configure mode either by right-clicking anywhere in the background of the picture and then selecting Quick Edit, or by pressing CTRL+W.
