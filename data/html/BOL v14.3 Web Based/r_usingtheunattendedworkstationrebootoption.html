Using the unattended workstation reboot option

You can enable the Unattended Workstation Reboot on Failover or Manual Switchover option (select and right-click the Application Station, and then select Properties. Click the Redundancy tab). This option is designed primarily for when either of the Application Stations will be located in an unmanned facility.

Note:

Changing this option after the initial configuration of a redundant subsystem requires a download of the ProfessionalPLUS (or Professional) workstation's Setup Data.

With the Unattended Workstation Reboot on Failover or Manual Switchover option disabled, a switchover causes the standby to take over as the active. However, the former active will not reestablish itself as the new standby until the Application Station is restarted. This is true for a manual switchover as well as for an unplanned switchover. This leaves the system in simplex mode.

To bring the former active into standby status, you must restart the Application Station where the red error light is flashing in the DeltaV Status window.

The Unattended Workstation Reboot on Failover or Manual Switchover option restarts the failed workstation so that it can reestablish itself as the new standby.

Important:

To do system maintenance or perform software upgrades, you can disable the Unattended Workstation Reboot on Failover or Manual Switchover option. Otherwise, the Application Station may restart before you finish your task. You will need to download the workstation pair when this option is enabled or disabled.
