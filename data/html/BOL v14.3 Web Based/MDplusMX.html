SD Plus, SX, SQ controller specifications

Installation notes

  • The S-series controller models are: SD Plus, SX, and SQ.
  • The controller installs in the right slot of the Power / Controller carrier.
  • The DeltaV system supports redundant controllers. A redundant controller consists of a pair of S-series controllers installed on separate Power / Controller Carriers.
  • Power each controller in a redundant pair from a separate System Power Supply (24 VDC) installed to the left of the controller on the Power / Controller Carrier.
