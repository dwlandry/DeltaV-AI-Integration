External phases

In Batch applications, there is often a need for custom phases (also called external phases) that allow users or programs to perform tasks outside of the normal control environment. For example, after charging an ingredient to a blender, the user may need to open a materials database, update the ingredient quantity and close the database. Another example of an external phase usage is a phase that allows the operator to use a bar code scanner to read the label of the ingredient being added.

External phases run on a workstation instead of in the controller. When the external phase is executed, the phase is controlled by the phase server specified. Commands for controlling that phase are defined by the phase server where the phase is running and must be issued through that phase server.

External phases are configured by associating the phase with a unit class and instantiating that unit class as a unit module.

There are two types of external phases, the DeltaV Soft Phase (allows you to write your own soft phases that use the DeltaV SoftPhase server type), and the Syncade external phase (requires the installation of the Syncade phase server). Each of these server types is an option in the External Phase Properties dialog (in DeltaV Explorer under System Configuration/Control Strategies/External Phases).
