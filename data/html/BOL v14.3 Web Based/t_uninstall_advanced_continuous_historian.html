Uninstall the Advanced Continuous Historian

Completely uninstalling the Advanced Continuous Historian requires that you also uninstall DeltaV from the Application Station. You can then reinstall DeltaV, at which time you can elect to:

  • Reinstall the Advanced Continuous Historian
  • Install a different historian

by enabling the DeltaV Continuous Historian, Advanced Continuous Historian, or Enterprise Historian option in the Select Historian dialog while reinstalling DeltaV.

To uninstall the Advanced Continuous Historian, complete the following steps:

  1. Back up the Advanced Continuous Historian database.
  2. Navigate to Control Panel > Programs and Features.
  3. On the Uninstall or change a program page, select and uninstall all OSIsoft PI Server software.
  4. Delete any of the following folders that exist on the C: or D: drive:
    • D:\PI
    • C:\Progam Files\PI
    • C:\Progam Files\PIPC
    • C:\Progam Files (x86)\PIPC
    • C:\ProgamData\OSIsoft
    • C:\Progam Files\Microsoft SQL Server\MSSQL12.ADV_CONT_HIST
    • D:\MSSQL2K\MSSQL12.ADV_CONT_HIST
      Note:

      Deleting the MSSQL12.ADV_CONT_HIST folder uninstalls the ADV_CONT_HIST SQL Server Instance associated with the Advanced Continuous Historian.

  5. Navigate to Control Panel > Programs and Features.
  6. On the Uninstall or change a program page, select and uninstall DeltaV.
