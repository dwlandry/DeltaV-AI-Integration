Diagnostic parameters specific to batch redundancy

The following DeltaV Diagnostics parameters, specific to redundancy, appear under DeltaV System/Control Network/nodename, where nodename is the name of the Application Station with Redundant Batch and Client is a Batch client:

Diagnostic Parameter

Description

ApplicationStationNodeName > WinName

On a Redundant Batch pair, this displays the name of the Application Station running as the active node. That is, the  DeltaV Batch Executive or Campaign Manager is running on this node.

Redundancy > STBY

The status of the standby node: GOOD or BAD

Redundancy > Standby > WinName

The name of the Application Station running as the current standby.

Redundancy > PExist

Whether or not an Application Station running as the standby can be located.

Redundancy > PAvail

Whether or not the Application Station running as the standby is available to run as the active.

Redundancy > RedEnb

Whether or not the redundant node is licensed as a redundant Application Station and enabled.

Redundancy > Status

The current status of the of the redundant node:

Good - no problems detected.

Failed Component - Standby is initializing or configuring or one or more of the subsystems on the standby is not ready. Subsystems could mean any of the following: communication subsystem, batch subsystem, control subsystem (in the case of DeltaV Connect), OPC, and so on.

Standby Not Detected - Standby computer is rebooted or offline.

Active is not Configured - Transitioning after download.

Standby not available - Transitioning after switchover or processing a download.

Redundancy Not Enabled - Option not selected on the Properties dialog of the Application station.

Redundancy > BatchLic

Indicates if the Batch subsystem is licensed for redundancy.

Redundant Batch includes the Batch Executive and Campaign Manager subsystems.

Redundancy > BatchPAvail

Indicates if the redundant Batch subsystem is successfully synchronizing data.

Redundancy > DLINK

Shows the status of the direct link communications connection between the redundant Batch subsystem workstations. The parameter has the following values: Good - the link is enabled and functioning properly.

Bad - the link is enabled but not functioning properly.

Disabled - the link is not enabled.
