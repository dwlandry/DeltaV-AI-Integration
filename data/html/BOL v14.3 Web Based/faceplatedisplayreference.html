Module faceplate reference

The following sections describe the faceplate displays used in DeltaV Operate's run mode.

Note: The following faceplates are similar in appearance and function so only the PID Loop faceplace (LOOP_FP) is documented:
  • DTC_FP (PID_DEADTIME faceplate)
  • FFLP_FP (Fieldbus loop faceplate)
  • FLC_FP (Fuzzy Logic Control faceplate)
  • LOOP_FP (PID loop faceplate)
