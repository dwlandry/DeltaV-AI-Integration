Creating and opening pictures

In DeltaV Operate configure mode, you can start by creating a new picture from the main template or by opening an existing picture. To create a new picture, click the New Picture from Template button on the Standard toolbar. In the New Picture dialog box, main is the default template selection.

To open an existing picture, double-click the picture from the Pictures folder in the system tree. By default, the system tree is docked on the left side of the screen, and the picture appears to the right of it. To create more room for your picture, you can do any of the following:

  • Dock the system tree on the other side of the screen by dragging it.

  • Set the system tree to float on top of your picture by dragging it away from the sides of the screen. You can also resize it by dragging any of the sides.

  • Hide the system tree completely so that the picture appears to fit the full screen.

For more information on using the system tree of DeltaV Operate, refer to The System Tree and Work Area.

To save your drawing, click the Save button on the Standard toolbar. Pictures are saved as .GRF files and stored in the Pictures folder in the system tree. When saving picture files, you must follow the guidelines of VBA naming constraints:

  • The name may be up to 31 characters in length.

  • The name may contain alphanumeric characters and underscores.

    Note: Avoid using "_1" at the end of the picture name when naming copies of a picture. "_1" is reserved for use by the Update Main Picture utilty for creating copies to use on multiple monitor workstations.

  • The name must start with a letter.

  • The name must be unique (different from the template name).

  • When creating a new display, faceplate, or detail display, you cannot name the new file the same as any filename that exists in the \DeltaV\DVData\Graphics-iFix folder.

  • You cannot name the new graphic file by appending a 2 to the filename (such as TAGAI_fp2) because that name is reserved as part of temp files created by DeltaV Operate (and located in \DeltaV\DVData\Graphics-iFix\Pic\Temp\* (where * is one of the subfolders under Temp).

Also, it is recommended that you do not use any names that are common to other functions, statements, or methods in Visual Basic, as you may cancel one of the keywords in the code. For more information on VBA, refer to the Writing Scripts section.

The DeltaV system maintains two instances of main pictures so that the picture can be opened on up to two monitors (on multiple monitor workstations). When you create or modify a main picture, you must run the Update Main Pictures utility to update the other copy of the picture. Follow the steps in the Updating Main Pictures and Dynamos topic.

Note:

To show the DeltaV Utilities toolbar, click Workplace > Toolbars. On the Toolbars dialog, select Workspace as the owner and then select the DeltaV Utilities check box.

Renaming Pictures

You can rename a DeltaV Operate picture by right-clicking the picture name in the system tree and selecting Rename. After assigning a new name it is important to open and close the picture while you are still in configure mode. Doing so automatically resolves the links in the picture.  Remember to run the Update Main Pictures utility to create a second copy of the renamed main picture.

Do not rename DeltaV Operate pictures using the Windows Explorer.

Copying Pictures

To copy an existing picture, open the picture you wish to copy and use the Save As command to save a copy under a new name. Then open the copy in DeltaV Operate configure mode and close it to resolve the links in the picture.  Remember to run the Update Main Pictures utility to create a second copy of the renamed main picture.

While it is possible to copy and move pictures using Windows Explorer, you must still open and close the picture in DeltaV Operate to resolve the links.
