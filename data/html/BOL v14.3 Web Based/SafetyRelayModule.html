SIS Relay Module

The SIS Relay module can be used with DeltaV SIS hardware to switch up to 2.5A at 250 VAC for safety applications. It opens contacts for field power when de-energized.

The SIS Relay module contains three relays from different manufacturers. A relay coil is energized for all three relays in normal operation. If a demand occurs, the SLS removes the power from the coil for all three relays at the same time. Each relay can be proof tested in the field. The SIS Relay module's LED shows if power is correctly installed and the state of the relay coil. The dimensions of the SIS Relay module are the same as those of the Voltage Monitor.
