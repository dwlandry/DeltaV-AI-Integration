Configure secure parameters

To transfer data from one SIS module to another, you must configure a Secure Parameter and a Secure Parameter Reference. This pair (parameter and reference) is required whether the SIS modules are assigned to the same logic solver or different logic solvers. 

  1. Drag a Secure Parameter from the Special Items palette to the function block diagram for the SIS module. 

    A Properties dialog appears with a parameter type of Boolean with status.

  2. Name the parameter, select a parameter category, change the value if desired, and click OK.
  3. Wire a Boolean parameter that you want to reference from another module to the secure parameter.
  4. Click the Main button, then click Save.
    Note:

    If the module is assigned to a logic solver, the database verifies that the logic solver has a secure parameter slot available, and assigns the slot for the parameter.

    The number of secure parameters than can be configured in a module depends on:
    • The type of logic solver the module is assigned to.
    • For SLS 1508 logic solvers, whether it is configured for high-density secure parameters.
    • The number of remaining slots available in the logic solver.

    An unassigned module containing secure parameters can only be assigned to a logic solver that has enough slots available to contain the configured secure parameters.
