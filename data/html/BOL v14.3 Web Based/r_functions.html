Functions

The DeltaV software supports a wide variety of functions. DeltaV functions are generally in the following format: 

FunctionName( param1, param2, ..., paramN)

The function name is followed by a parenthesis, and the parameters of the function are separated by commas. These functions can be used in either the Assignment or IF-THEN-ELSE-END_IF expression constructs.

Note:

The functions that are valid in the expression editor depend on where the expression editor was opened from.
