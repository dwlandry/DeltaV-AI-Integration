OnEnterActiveStepChangeComplete event

Notifies the control that the Enter Active Step Change command is complete.
Arguments
Argument Description Type
bstrExecutive The connected to Batch Executive name. String
bstrBatchId The ID of the Batch. String
bstrCreateId The unique ID of the selected (active) batch. String
bstrPath The path of the step. String
bSuccess The result of the requested command. Boolean
bstrStatusMessage Information regarding the cause of failure if the request did not succeed. String
Controls applied to
Batch PFC
Syntax
BatchPFCControl1.OnEnterActiveStepChangeComplete(bstrExecutive, bstrBatchId, bstrCreateId, bstrPath, bstrSuccess, bstrStatusMessage)
