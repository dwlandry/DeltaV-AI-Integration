Create a CHARMs Smart Logic Solver (CSLS)

Right click the Local Safety Network subsystem under the appropriate SIS Controller and select New CHARMs Logic Solver. The CSLS appears in the hierarchy and is given the default name CLSLn, where n is the next available number. You can rename the CSLS if desired.
Creating a CSLS also creates the following subsystems:
  • Assigned SIS Modules
  • CHARMs (including 96 placeholder LS CHARMs)
  • Hardware Alarms
Note:

You can also create a CSLS by dragging an unassigned CHARMs Smart Logic Solver to the Local Safety Network.
