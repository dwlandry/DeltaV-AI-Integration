MA3_CV_S_ analog dynamo, 3 function blocks, small vertical combination bar graph

This dynamo can be used for analog indication where general percent of scale is important and space on the display is limited. Used with PID loops, AI indicators, and ALM function blocks.

The following elements are present on the dynamo:

  • Alarm Icon

  • Combination (Combo) Bar Graph

  • Display Tag

  • Dynamo Background

  • Engineering Units Descriptor

  • Mode Icon

  • PV Data Field

  • Status Icon
