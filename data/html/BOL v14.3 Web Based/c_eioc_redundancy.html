EIOC node redundancy

EIOC nodes can be configured for redundancy. Switchovers occur with no bumps in device data values or status. Redundant EIOC nodes operate as an Active/Standby pair. The active EIOC configures and updates the standby to keep it synchronized with the active. The standby EIOC in a redundant pair monitors the health of the active EIOC and becomes the active when:

  • The currently active EIOC fails to communicate with the standby over the redundancy link
  • The currently active EIOC fails to communicate with all configured Ethernet devices

Redundant EIOC nodes are two paired EIOCs having either a simplex device network or redundant device networks (the EIOC supports redundant device network connections through its carrier).

With redundant EIOC nodes, if the active node fails the pair can switchover to the standby for communication to the devices. Once switched over to the standby, if the previous node is still not communicating, you are operating in a simplex EIOC mode.

Note:

When creating physical devices on redundant EIOCs, be aware that the system assigns the primary and secondary IP addresses of the standby by adding 1 to the existing address. Therefore, when the EIOC primary port has a network IP address of 192.168.1.1; the standby EIOC primary port is given the primary network IP address of 192.168.1.2.
