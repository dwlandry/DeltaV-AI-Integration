The frsSIS dynamo sets

The frsSIS dynamo sets are in the Dynamo Sets folder in DeltaV Operate configure mode. The two frsSIS dynamo sets each contain the following dynamos:

frsSIS dynamo sets
Dynamo Description

Any_SIS_Block

Used for any SIS function block, this simple dynamo can call up a custom faceplate for any SIS function block, primitive or composite.

AVTR_1Input_

Used for a 1oo1 analog voter (LSAVTR) function block.

AVTR_2Input_

Used for a 1oo2 or 2oo2 analog voter (LSAVTR) function block.

AVTR_3Input_

Used for a 1oo3 or 2oo3 analog voter (LSAVTR) function block.

AVTR_InputX_

An input-only dynamo that can be added to the AVTR_3Input_ dynamo for voting arrangements with more than three inputs. For example, for a 6oo8 voter, add five copies of the AVTR_InputX_ dynamo to one AVTR_3Input_ dynamo, for a total of eight inputs.

CEM_Effect_

Used for a Cause & Effect Matrix  (LSCEM) function block. Can be used multiple times when the CEM block has more than one effect.

DO_

Used for a Discrete Output  (LSDO) function block.

DVC_

Used for a Digital Valve Controller (LSDVC)  function block.

DVTR1_Input_

Used for a 1oo1 discrete voter (LSDVTR) function block.

DVTR2_Input_

Used for a 1oo2 or 2oo2 discrete voter (LSDVTR) function block.

DVTR3_Input_

Used for a 1oo3 or 2oo3 discrete voter (LSDVTR) function block.

DVTR_InputX_

An input-only dynamo that can be added to the DVTR_3Input_ dynamo for voting arrangements with more than three inputs. For example, for a 6oo8 voter, add five copies of the DVTR_InputX_ dynamo to one DVTR_3Input_ dynamo, for a total of eight inputs.

EFFECT_

Used for the Effect (LSEFFECT) function block.

MONITOR_Output_

Used for a single output of the Monitor (LSMON) function block.

SEQ_

Used for a Step Sequencer (LSSEQ) function block.

STD_

Used  for a State Transition Diagram (LSSTD) function block.
