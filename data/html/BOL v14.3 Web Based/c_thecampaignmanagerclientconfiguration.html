The Campaign Manager's client configuration

The Campaign Manager client configuration is an option on the context menu of the Campaign Manager sub-system. This option sets the configuration of the default options that all Campaign Manager Operator Interfaces (CMOI) attaching to this Campaign Manager server node will use. If selected in the Client Configuration dialog, the individual CMOI clients can override the default settings. This allows you to set the defaults for all CMOI clients to start with and allows for individual changes to be made on each CMOI client as needed.

In the client configuration dialogs, you can

  • Configure the General Defaults

  • Set the Column Order

  • Define the Display Colors

Refer to DeltaV Explorer help for more information about the Client Configuration dialog.
