Create an SIS composite template

If you have bit of logic that you intend to reuse, create an SIS Composite Template:

  1. From Control Studio create a new SIS Composite Template. 

  2. Add the items required for your template

  3. Save the template. You are prompted for a name and a location within the SIS Composite Templates library.

  4. Protect the template if desired.

You can now insert this composite block in any SIS module you create.
