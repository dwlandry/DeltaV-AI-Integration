Archiving Batch Historian data

You can configure regularly scheduled archives through the Batch Historian Administrator's Tool using the AutoArchive function. Refer to the Administrator's Tool online help for more information.

Additionally, the Batch Archiver is used by the Batch Executive to remove the event files when they are older than the date specified in the Batch Executive configuration. This function does not move the data to another location, therefore, it is important that you configure the AutoArchive and the AutoBackup functions to preserve your historical data.
