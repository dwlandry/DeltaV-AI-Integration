Create a display set

  1. Select the Graphics Explorer pane as the active pane in the Explorer view.
  2. On the ribbon's Home tab, in the Graphics group, click New > Display Set. The display set opens as a content tab and becomes available for editing in the Content pane. A new Display Set tab also appears in the ribbon.
  3. Rename the display set, if desired.
  4. Enter a title and description for the display set, if desired, in the Graphics Configuration pane.
  5. Add displays to the navigation hierarchy.
    1. Drag a display from the Graphics Explorer pane into the Navigation Hierarchy pane. When you see a tooltip showing the desired level, drop the display.
  6. Click the Save button.
    Tip:
    • To change the level of a display in the display set, click Promote or Demote in the ribbon's Display Set tab. (The Overview level cannot be changed.)
    • To move a display up or down within a display set, click Move up or Move down in the ribbon's Display Set tab.
