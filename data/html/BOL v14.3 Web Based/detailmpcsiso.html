MPC single input single output detail display (MPCSISO_DT)

DeltaV Operate View of the MPC Single Input Single Output (SISO) Detail Display

The MPC SISO detail display includes the following items:

  • SP High Limit - This field displays the maximum value of the SP in engineering units. Double-click this value to get a prompt that allows you to enter a new limit. The valid input range for this value is -99999 to 99999.

  • SP Low Limit - This field displays the minimum value of the SP in engineering units. Double-click this value to get a prompt that allows you to enter a new limit. The valid input range for this value is -99999 to 99999.

  • SP Filter Time - This field indicates the SP filter time constant in seconds. Double-click this value to get a prompt that allows you to enter a new value. The valid input range for this value is 0.00 to 600.0 seconds.

  • High Limit - This field displays the maximum value of the Manipulated variable in engineering units. Double-click this value to get a prompt that allows you to enter a new limit. The valid input range for this value is -99999 to 99999.

  • Low Limit - This field displays the minimum value of the Manipulated variable in engineering units. Double-click this value to get a prompt that allows you to enter a new limit. The valid input range for this value is -99999 to 99999.

  • Max MV Move Per Sec - This field indicates maximum amount (in engineering units) of change allowed per sec. The valid input range for this is any positive number up to 99999.
