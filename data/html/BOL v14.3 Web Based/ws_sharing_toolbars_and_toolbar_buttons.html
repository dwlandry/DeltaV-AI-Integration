Using toolbars and toolbar buttons on multiple nodes

You can use any custom toolbar on any DeltaV Operate workstation. You do this by:

  • Importing a toolbar's TBX file.

  • Copying a toolbar category's TBC file.

TBX files define toolbars. TBC files define the categories of toolbar buttons available when you customize a toolbar . TBX and TBC files reside in the Local path on the source computer. You can use these files on another node by copying them to the target computer's Local path. To use a toolbar on another node, you must subsequently import the TBX file with the WorkSpace. Toolbar files (*.TBX, *.TBC, *.XBT, ASSOCIATION.DAT) saved as read-only cannot be used in DeltaV Operate.

Typically, you import a toolbar when you want to add toolbars created by a toolbar developer but you do not want others to reuse the toolbar's buttons. Copying a toolbar category, on the other hand, is done when you want to create one or more toolbars locally from the buttons in the toolbar category.

Note:

If you use a toolbar button to launch a custom ActiveX control, the OCX must be installed and registered on the target computer.
