Logic Solver Discrete Input function block

The LSDI function block accesses a single discrete input from a two-state field device and makes the processed physical input available to other function blocks. You can configure inversion on the input value.

LSDI Function Block

The LSDI block supports signal status propagation and simulation.

In SLS 1508 systems the input specified can be one of the 16 channels on this logic solver or an input channel on a logic solver on the same controller. In CHARMs Smart Logic Solver systems the input specified can be any of the LS CHARMs of any CSLS in the Local Safety Network.

The LSDI block does not support mode and does not have alarms.
