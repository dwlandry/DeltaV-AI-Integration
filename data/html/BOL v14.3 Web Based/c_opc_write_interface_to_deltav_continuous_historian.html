OPC write interface to the DeltaV Continuous Historian

You can write a client application that interfaces with a DeltaV OPC Historical Data Access (HDA) or DeltaV OPC .NET server to write history samples to a DeltaV Continuous Historian database.

Important: To use the OPC write interface, the Enable historical data entry option on the Advanced tab of the Continuous Historian Properties dialog must be enabled on the workstation where the DeltaV Continuous Historian is running.

Before writing to the DeltaV Continuous Historian database, history tags must be created. The OPC write interface provides a custom interface method, CreateTags, to create an array of history tags.

Writing history samples to the DeltaV Continuous Historian database relies on using the standard GetItemHandles method for the IOPCHDA_Server interface and the Insert method for the IOPCHDA_SyncUpdate interface, as described in OPC Historical Data Access Specification Version 1.20.
