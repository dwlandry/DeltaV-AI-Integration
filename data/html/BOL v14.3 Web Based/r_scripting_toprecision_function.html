toPrecision function

The toPrecision function returns a string representing a given number and written with a specified length.
Arguments
0–1, Optional arguments are indicated by a ? following the argument name.
Argument Description
precision? An integer specifying the number of significant digits.
Return values (string)
A string, representing the given number formatted to the specified precision.
If the precision? argument is omitted or undefined, the entire number is returned as a string.
Syntax
numObj.toPrecision(precision?)
Examples
Example Result 
var SP = DLSYS["U012-LT-101/PID1/SP.CV"];
this.Label = SP.toPrecision(3);
 Returns "5570" on the element's label. 
var numObj = 5.123456;
dsp.Text2.Label = numObj.toPrecision(2)
 Returns "5.1" on the Text2 label.
