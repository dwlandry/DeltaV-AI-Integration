toExponential function

The toExponential function returns a string representing the Number object in exponential notation.
Arguments
0–1, Optional arguments are indicated by a ? following the argument name.
Argument Description
[fractionDigits?] An integer (between 0 and 20) representing the number of digits in the notation after the decimal point.
Return values (string)
A string representing the given number in exponential notation and with one digit before the decimal point.
If fractionDigits? is omitted or undefined, it is set to as many digits as necessary to represent the value uniquely, and is still returned in exponential notation.
Syntax
numObj.toExponential(fractionDigits?)
Examples
Example Result
Assuming you have:
  • the module parameter, U012-LT-101/PID1/SP.CV, with a value of 5567.89
  • a button (Button1) on a GEM
  • the following script added as a custom script to a Button1 action 
var SP = DLSYS["U012-LT-101/PID1/SP.CV"];
Gem.Button1.Label = SP.toExponential();
 Returns "5.56789e+3" on Button1's label. 
var numObj = 77.1234
Dsp.Text2.Label = numObj.toExponential(4)
 Returns " 7.71234e+1".
