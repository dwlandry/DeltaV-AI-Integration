Module faceplates reference

The following topics provide a description of each module faceplate display provided with DeltaV Live.
Note: The following faceplates are similar in appearance and function to the PID Loop faceplate (LOOP_fp), so only LOOP_FP is documented:
  • DTC_FP (PID_DEADTIME module faceplate)
  • FFLP_FP (Fieldbus loop module faceplate)
  • FLC_FP (Fuzzy Logic Control module faceplate)

The faceplate images show all of the main components that can be configured on the faceplate. The component descriptions describe the faceplate's online behavior.
