VB

Public Sub GetVersions(

bstrCMControlVersion As String, 

bstrCMServerVersion As String)

This method may be used to obtain the versions (in 7.2 or later systems) of the CM Server and Control. The control must be connected to a CM Server to obtain its version.

Return Values

S_OK - SUCCESS

else - failed

Memory Allocation

The caller is responsible for freeing the returned strings.

Visual Basic Usage Example

Private Sub GetVersions()
    Dim strControlVersion As String Dim strServerVersion As String
    ' Get a variable for the new interface in 7.2
    Dim DVBCMClient2 As IDVBCMClient2
On Error GoTo Handler:
    ' Get the interface
    Set DVBCMClient2 = DVBCMClient.Object
    ' Use New methods
    DVBCMClient2.GetVersions strControlVersion, strServerVersion
    Exit Sub
Handler: MsgBox Err.Desciption
End Sub

Parameter Name

Purpose

bstrCMControlVersion

Pointer to a string that will receive the version of the Campaign Manager control on which the method is called.

bstrCMServerVersion

Pointer to a string that will receive the version of the Campaign Manager server to which the control is connected.
