Propagation behavior

The following table defines the propagation behavior for module elements.

Module element

Propagation behavior

Module properties

Never propagate to instances.

Module algorithms

Always propagate to instances.

Parameter values

Propagate to instances if the class designer unchecks the Allow instance value to be configured check box for the parameter. If the box is checked, the state of the Use default value from library object check box at the instance level governs the propagation behavior.

Alarm properties

Propagate to instances if the class designer unchecks the Allow instance value to be configured check box for the alarm properties.

I/O assignments

Cannot be configured at the class level.

History collection entries

Propagate to instances if the class designer unchecks the Allow instance value to be configured check box for the associated parameter. If the box is checked for the associated parameter, the state of the Use default value from library object check box at the instance level governs the propagation behavior.
