Maintenance (MAINT_ALM) hardware alarms

Active 3.3 VDC Error

WIOC: Internal problem with current active WIOC. The WIOC needs to be replaced.

Active Commissioning Module Error

WIOC: The Active unit might not commission properly after a reboot, commissioning data might be lost or corrupted. The cause of the problem is internal.

Active Primary 24 VDC Error

Power supply loss detected with the active’s primary supply. Check connection or replace power supply.

Active Primary I/O Port Error

WIOC: Active Unit unable to communicate on primary ACN.

Active Primary Temperature Error

WIOC: The active unit's primary temperature sensor is too high or too low.

Active RTC Error

The Real Time Clock is not working properly. System time might not be set properly.

Active Secondary 24 VDC Error

Power supply loss detected with the active's secondary supply. Check connection or replace power supply.

Active Secondary I/O Port Error

WIOC: Active Unit unable to communicate on secondary ACN.

Active Secondary Temperature Error

WIOC: The active unit's secondary temperature sensor is too high or too low.

Active Temperature Error

CIOC: The active unit's temperature is too high or low.

Assignment Mismatch - Remote Node ID, card_type Card, Cnn

The controller needs to be downloaded because the remote I/O card in slot Cnn, which was previously assigned to this controller, has been reassigned to a different controller.

Assignment Mismatch - Remote Node node_name, card_type Card, Cnn

The controller needs to be downloaded because the remote I/O card in slot Cnn, which was previously assigned to this controller, has been reassigned to a different controller.

Assignment Mismatch  - with CIOC

Perform setup data download of the controller. The CHARM I/O card (for example, CIOC-2), that was previously assigned to this controller, has now been unassigned.

Assignment Mismatch - Node Id

Perform setup data download of the controller. The CHARM I/O card (for example, CIOC ID 2517893127), , that was previously assigned to this controller, has now been unassigned.

Card in Failsafe Mode - card_type Card, Cnn

The simplex I/O card in slot Cnn is in failsafe mode and driving any outputs to the configured failsafe value.

CHARM Bus Terminator Error

The terminator on the CHARM bus is missing or broken.

CHARMs Simulation Enabled

CHARMs simulation has been enabled through DeltaV Explorer. The value coming from the I/O device is being disregarded.

Configuration Error - card_type Card, Cnn

An invalid configuration has been detected for the I/O card in slot Cnn.

Database Space - Allocated database space low, value% free

The amount of free space in the folder allocated for Batch Historian database storage has fallen below 10%.

You can increase the maximum size of the Batch Historian database storage folder in DeltaV Explorer by navigating to the Output tab on the Batch Historian Properties dialog for this workstation, selecting a location in the Directory Path column, and clicking Modify.

Direct Link Unavailable

The Redundant Batch system's Direct Link connection is unavailable. This connection is through an Ethernet card in both the active and standby computers.

Hardware Error - card_type Card, Cnn

A hardware error preventing reliable operation has been detected for the simplex or redundant I/O card in slot Cnn.

Hardware Error - card_type Card, Cnn, Pnn

A communications problem has been detected at port Pnn of the I/O card in slot Cnn.

HART Connection For CIOC Is Unbound- Perform Setup Data Download

The binding between the CHARM I/O card  (for example, CIOC-2) and the controller for receiving HART data is bad. Setup data download needs to be performed. Without the setup data download, there will be no communication between the CHARM I/O card and the controller.

HART Connection For Node Id:%u Is Unbound - Perform Setup Data Download

The binding between the CHARM I/O card (for example, CIOC ID 2517893127) and the controller for receiving HART data is bad. Setup data download needs to be performed. Without the setup data download, there will be no communication between the CHARM I/O card and the controller.

Initialization Error - card_type Card, Cnn, Pnn

The AS-Interface I/O card in slot Cnn failed to initialize port Pnn after receiving configuration data.

Network Integrity Error - Primary Network

All communications attempts between a node on the primary network and all other nodes in the system have failed. There is no communications on this network interface.

Network Integrity Error - Secondary Network

All communications attempts between a node on the secondary network and all other nodes in the system have failed. There is no communications on this network interface.

No Communications On Port - card_type Card, Cnn, Pnn

A communications failure has been detected at port Pnn of the I/O card in slot Cnn. Port communications failure errors include the following:

  • A port cannot communicate with any devices connected to it.

  • A loss of power to the segment connected to the port.

  • The I/O card has detected an error with the port’s communications chip.

  • A port on an H1 fieldbus card cannot communicate with any devices connected to it, including the standby H1 card in a redundant configuration.

NON-HART Connection For CIOC Is Unbound- Perform Setup Data Download

The binding between the CHARM I/O card (for example, CIOC-2) and the controller for receiving non-HART data is bad. Setup data download needs to be performed. Without the setup data download, there will be no communication between the CHARM I/O card and the controller.

NON-HART Connection For Node Id: nn Is Unbound - Perform Setup Data Download

The binding between the CHARM I/O card (for example, CIOC ID 2517893127) and the controller for receiving non-HART data is bad. Setup data download needs to be performed. Without the setup data download, there will be no communication between the CHARM I/O card and the controller.

Not Bound - Needs Setup Data, Remote Node ID, card_type Card, Cnn

The remote I/O card in slot Cnn of the remote I/O node has been assigned, but setup data has not been downloaded to the controller.

Not Bound - Needs Setup Data, Remote Node node_name, card_type Card, Cnn

The remote I/O card in slot Cnn of the node_name remote I/O node has been assigned, but setup data has not been downloaded to the controller.

Not Communicating - card_type Card, Cnn

The I/O subsystem cannot communicate with the I/O card in slot Cnn.

Not Communicating - on Pri Zone Network

The local Inter-Zone Server cannot communicate with any other zone over the primary Inter-Zone Network.

Not Communicating - on Sec Zone Network

The local Inter-Zone Server cannot communicate with any other zone over the secondary Inter-Zone Network.

Not Communicating - Standby

A standby controller in the DeltaV network’s redundancy subsystem is not communicating with the primary controller.

Not Communicating - with Zone zone_name on Pri Zone Network

The local Inter-Zone Server cannot communicate with the zone_name zone over the primary Inter-Zone Network.

Not Communicating - with Zone zone_name on Sec Zone Network

The local Inter-Zone Server cannot communicate with the zone_name zone over the secondary Inter-Zone Network.

Power Error - card_type Card, Cnn, Pnn

A power problem, such as a loss of power to the segment connected to the port, has been detected at port Pnn of the I/O card in slot Cnn.

Primary Cascade Port Error

The primary cascade port is not communicating properly. Replace the primary I/O port. The cause of this error is internal. Note that this message is only displayed if the option is enabled.

Primary CHARM Bus Voltage Error

The left-hand CIOC has detected that primary CHARM bus power is outside its normal operating range.

Possible causes:
  • Left-hand CIOC is bad
  • CHARM baseplate is bad
  • One or more CHARMs are bad
  • Terminator is bad
  • Extender or cable is bad
  • CIOC carrier is bad

Primary Commissioning Module Error

The unit might not commission properly after a reboot, commissioning data might be lost or corrupted, or the primary I/O port might need replacing. The cause of the problem is internal.

Primary I/O Port Error

Either a primary commissioning module error or a primary cascade port error has been detected.

Redundancy Serial Link Error

The serial link between the WIOC nodes has an error. The redundant terminal block may need to be replaced.

Secondary Cascade Port Error

The secondary cascade port is not communicating properly. Replace the secondary I/O port. The cause of this error is internal. 

This message is displayed even when configured as simplex networks. This is done to ensure commissioning if an error occurs with the primary I/O port.

Secondary CHARM Bus Voltage Error

The right-hand CIOC has detected that secondary CHARM bus power is outside its normal operating range.

Possible causes:
  • Right-hand CIOC is bad
  • CHARM baseplate is bad
  • One or more CHARMs are bad
  • Terminator is bad
  • Extender or cable is bad
  • CIOC carrier is bad

Secondary I/O Port Error

Either a secondary commissioning module error or a secondary cascade port error has been detected.

Secondary Commissioning Module Error

The unit might not commission properly after a reboot, commissioning data might be lost or corrupted, or the secondary I/O port might need replacing. The cause of the problem is internal.

Standby 3.3V DC Error

WIOC: Internal voltage problem with the current standby WIOC. The WIOC needs to be replaced.

Standby Card Not Available - card_type Card, Cnn

The I/O card in slot Cnn is not communicating with its redundant partner. The standby I/O card is not available for switchover.

Standby Commissioning Module Error

WIOC: The Standby unit might not commission properly after a reboot, commissioning data might be lost or corrupted. The cause of the problem is internal.

Standby Primary 24 VDC Error

Power supply loss detected with the standby's primary supply. Check connection or replace power supply.

Standby Primary I/O Port Error

WIOC: Standby Unit unable to communicate on primary ACN.

Standby Primary Temperature Exceeded

WIOC: The standby unit's primary temperature sensor is too high or low.

Standby RTC Error

The Real Time Clock is not working properly. System time might not be set properly.

Standby Secondary 24 VDC Error

Power supply loss detected with the standby's secondary supply. Check connection or replace power supply.

Standby Secondary I/O Port Error

WIOC: Standby Unit unable to communicate on secondary ACN.

Standby Secondary Temperature Exceeded

WIOC: The standby unit's secondary temperature sensor is too high or low.

Standby Temperature Error

CIOC: The standby unit's temperature is too high or low.

Standby Unavailable

A standby controller in the DeltaV network’s redundancy subsystem is not available for switchover, because its configuration information is not valid.

Termination Error - card_type Card, Cnn, Pnn

Termination is disconnected at port Pnn of the I/O card in slot Cnn.
