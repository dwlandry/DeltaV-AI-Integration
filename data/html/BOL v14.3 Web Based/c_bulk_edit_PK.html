Bulk editing a PK controller's Ethernet-connected devices

This section outlines how to bulk edit a PK controller PO1 subsystem's physical and logical devices, and signals. The general procedure to bulk edit the PK is

  1. Create a PK controller.
  2. Configure the controller's PO1 subsystem.
  3. Under the PO1 subsystem, create and configure a physical device of the type you want to bulk edit.
  4. Under the physical device create and configure a logical device of the type you want to bulk edit.
  5. Under the logical device configure the signals.
  6. For each level (physical device, logical device, and signal) use the sample format specification files or create your own and export data from the existing configuration.
    Note: The PK controller's PO1 subsystem is not bulk edited, only the objects contained in it are bulk edited.
  7. In DeltaV Explorer, select the PK object that you want to export and select File > Export > User Defined to create a text file for importing into the bulk edit Excel add-in.
  8. Edit the text file for the PK object in the bulk edit Excel add-in.
  9. Import the text file for the PK object into DeltaV Explorer.
Note:

You can bulk edit the PK controller's other objects (such as local I/O card and channels) using the appropriate FMT files. For example, you can bulk edit the local I/O cards using the Card.fmt file. Refer to the topics on the object you are wanting to import.
