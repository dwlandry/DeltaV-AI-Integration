Functions overview

Functions provide a means to create logic that converts values of one type into values of a different type. They are created and managed in configuration libraries and can be referenced by properties in display, layouts, or GEM classes. You can create functions for float, string, and Boolean values to return values of various types, including colors, fonts, Booleans, images, strings, measurements, and numbers. The name of a function must be unique within its contained library.

Configuring functions

When you configure functions, you must define the value types to be converted (inputs) and the logic (conversions tables) used to covert the inputs to the desired type. Optionally, you can also define calculations to be performed prior to the conversion.
Inputs
A function can have from one to five inputs, defined as float, string, or Boolean, or a mixture of these three. Input names are referenced from function expressions while input titles are referenced from complex animations. You can optionally provide a default value for an input to further extend the capability of the function. A default value can be either a literal value or a reference to a standard of the same type. Within the same function, inputs without a default value must precede inputs with default values.
Calculations
Sometimes you need to calculate additional values from the inputs, such as total, average, ratio, volume, and so forth. When configuring functions, you can use graphics expressions to define the calculations (up to five) needed to obtain these values. In these expressions, you can also reference inputs and other calculations. The result of the calculation is automatically converted, if possible, to the intended result type. When executing in Operations Hub, calculation expressions are evaluated in the top-to-bottom sequence as they appear in Graphics Studio.
Conversion logic
Conversion logic defines what input values to convert and the values to be returned. You can choose to write the logic based on rules, values, or scripts. Rule-based logic uses rules that define the input and output values. This logic works well when several inputs, or calculations derived from inputs, help determine the function's return value. Value-based logic compares a single value (input or calculated) with several choices to determine whether the test value matches any of those choices, and then returns the appropriate values based on the comparison results. You can define these choices as single values or as a range of values. With script-based logic, you can write your own expressions to define the inputs and output types. Alternatively, you can use open document editing to write the logic for functions.
