Add displays to a display set as hierarchical displays

This topic explains how to add displays to the navigation hierarchy of an existing display set.

  1. Open the display set to which you want to add displays.
  2. From the Graphics Explorer pane, drag a display into the Navigation Hierarchy and drop it at the desired level.
    Tip: If you hover in the hierarchy while dragging the display, a tooltip shows you the location of each level.
  3. Repeat step 2 for each display you want included in this display set (you can have up to four levels).
  4. Click the Save button to save your changes.
    Tip:
    • To move a display up or down in the Navigation Hierarchy but keep it at the same level, click Move up or Move down.
    • To move a display to a different level, click Promote or Demote.
    Note:
    • A display may belong to multiple display sets but may be included only once in a single display set.
    • A display that belongs to multiple display sets can be placed at a different level in each display set's hierarchy.
    • Relative placement of displays at the same level is significant, as it determines the positioning of display call up buttons in a Navigation Bar.
