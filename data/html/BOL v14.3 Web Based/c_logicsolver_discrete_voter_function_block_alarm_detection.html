Logic Solver Discrete Voter function alarm detection

Due to the number of conditions in each block and the potential for having many voter blocks in a module, some of the DVTR_ALERTS conditions propagate to the module level parameter SIF_ALERTS. The following table lists the block alarm conditions that propagate to the module level. Active conditions in any Discrete Voter block set the corresponding alerts in the module level SIF_ALERTS parameter.

Alarm Condition in DVTR_ALERTS

Alert in Module Parameter SIF_ALERTS

Trip Active

Trip consensus in an AVTR or DVTR block

Bypass Active

An AVTR or DVTR block has a bypassed input

Startup Override Active

An AVTR or DVTR block has an active startup override

Expiration Reminder

A bypass or startup override is about to expire in an AVTR or DVTR block

Inhibited

A function block is inhibited

Alarm conditions do not propagate when the REPORT_OPTS option Alarm conditions do not roll up to module level is selected. You might want to prevent propagation when the voting scheme is used to calculate a permissive rather than an interlock or trip condition.
