Bulk edit SLS 1508 logic solver channels

This section outlines how to export a Logic Solver channel of one subtype, copy and edit the exported data, and then import the edited data. Because there are several Logic Solver channel subtypes that have unique fields, create a separate format specification file for each subtype you use so you can bulk edit channel parameters and alarm parameters. 

The general procedure to bulk edit Logic Solver channels is:

  1. Create and configure one Logic Solver.
  2. Configure one channel of each type you want to bulk edit. 
  3. For each channel type, create a format specification file and export the channel.
  4. For each set of exported data, copy and edit the exported Logic Solver channel in the bulk edit Excel template as required.
  5. Import each data file.

The logic_solver column must contain the name of an existing Logic Solver.

The channel_slot column must not duplicate any other channel_slot value for the Logic Solver.

The ls_channel_type column must contain the channel type for which the specification file was created.

The device_signal_tag column must contain a unique tag.

The other columns and their values depend on the type of channel you are configuring.
