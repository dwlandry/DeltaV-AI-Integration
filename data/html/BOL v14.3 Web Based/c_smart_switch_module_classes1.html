Smart Switch module classes

You want all of your DeltaV Smart Switches to have consistent behavior. To assist that goal, DeltaV software includes two control module classes from which switch modules are created:

  • SWITCH_STDCFG_$X — Class for switches on the primary network.
  • SWITCH_SECCFG_$X — Class for switches on the secondary network.

The switch module classes hold common switch setup information and hardware alarm behavior configuration for Smart Switches. You can modify parameter settings of the classes to tailor them to your needs.

The Network Device Command Center detects which DeltaV ACN or DeltaV Remote network a switch is on and creates a switch module instance named the same as the switch from the appropriate module class when commissioning a switch.

Note:

During commissioning of a switch, Network Device Command Center (NDCC) only detects the primary and secondary network for the DeltaV ACN and DeltaV Remote networks. For all other networks, it uses the SWITCH_STDCFG_$X module.

Classes are provided for both primary and secondary networks because you may need to have different values for the following parameters:

  • TRAP_IP_ADDR
  • SYSLOG_IP_ADDR
  • PRI_TIME_IP_ADDR
  • BCK_TIME_IP_ADDR
Note:

It is recommended that you set these addresses in the switch module class or make the class configurable at the instance.

Important:

NDCC only detects the primary and secondary network for the DeltaV ACN and DeltaV Remote networks. For all other networks, it uses the SWITCH_STDCFG_$X module.

Therefore, if you need to have any parameters set for these other networks, you must set the module class to allow for the instance to be configured, and you must set the correct IP addresses for things such as the SYSLOG or NTP servers for those networks (that is, the subnets must be appropriate for the switch's network).

It is recommended that you do not add any other parameters or logic in these module classes. Any additions to the classes may not be preserved when upgrading to future versions of DeltaV software.

The control module classes are in the configuration library at: DeltaV _System/Library/Advanced Definitions/Control Module Classes/Switches. If the module classes have been deleted or renamed, you cannot commission switches.

Note:

It is not recommended to assign the smart switch module to a member of an Application Station pair because the standby Application Station is not communicating with the switch, it is getting all updates from the active Application Station. The smart switch module (in the active Application Station) is communicating to the switch through Network Device Command Center SNMP processes that are not redundant.

Networks monitored by NDCC

Network Device Command Center (NDCC) is capable of discovering (and therefore, commissioning, monitoring, and managing) DeltaV Smart Switches from the following networks (provided there is no routing or redirecting of the network traffic):
  • DeltaV Area Control Network (the ACN), primary and secondary
  • DeltaV Remote Network, primary and secondary
  • DeltaV level 2.5 network
  • Thin Client network (for virtual DeltaV workstations), primary and secondary
