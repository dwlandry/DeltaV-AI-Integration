Only 48 of the 96 LS CHARM slots can be configured as output LS CHARMs. LS DVC HART DTA CHARMs are included in the output CHARMs count. This can be any combination of simplex and redundant as long as the slot count of output LS CHARMs does not exceed 48. This limit is not enforced during configuration, only during download. The remaining 48 slots can be configured as input LS CHARMs.
