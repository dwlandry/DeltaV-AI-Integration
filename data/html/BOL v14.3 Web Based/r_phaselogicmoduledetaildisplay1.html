Phase logic module detail display (PLM_DT)

The phase logic module detail display in DeltaV Operate allows the user to do the following:

  • Showing phase logic module name and description

  • Showing phase alarms

  • Providing a means to acknowledge alarms

  • Showing phase details (value of request register and request parameters)

  • Providing a means to acknowledge requests

  • Showing diagnostic data

  • Showing restart type

  • Showing failure state

  • Providing a means to select the default monitor on which to present the detail display
