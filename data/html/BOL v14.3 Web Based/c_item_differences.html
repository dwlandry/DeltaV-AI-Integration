Item differences

You can view and print differences between two versions of an item graphically or as text. There are several ways to display differences. With an item of interest selected:

  • From the context menu or Tools menu, select Version Control > Show Differences. This will show the differences between the current version and the latest version in the VCAT database.
  • From the context menu or Tools menu, select Version Control > Show History. This opens the History dialog that shows all the versions of the currently selected item. Select any two versions and click the Differences button.
  • From the Tools menu, select Version Control > History Report. This opens the History Options dialog. Click OK on the History Options dialog to open the History Report. The dialog has a Differences button that works the same way as the Differences button on the History dialog. The History Report dialog also has a Print Latest Changes button.

The differences dialogs have a print icon you can use to print the current comparison.
