MPCPro manipulated variable detail display (MPCPROINPUT_DT)

DeltaV Operate View of a Manipulated Variable Detail Display (MPCPROINPUT_DT)

The MPCPro Manipulated Detail display shows Limit and Tuning information for MPCPro manipulated variables. It includes the following items:

Limits

  • High Limit – This field displays the maximum value of the MV in engineering units. Click this field to enter a new value. The valid input range for this value is -99999 to 99999.

  • Low Limit – This field displays the minimum value of the MV in engineering units. Click this field to enter a new value. The valid input range for this value is -99999 to 99999.

Tuning

  • Max MV Move Per Sec – This field displays the maximum MV change per second.
