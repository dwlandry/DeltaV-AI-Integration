Setup the existing (primary) Application Station (the preferred active)

  1. In DeltaV Explorer, right-click the existing Application Station under System Configuration/Physical Network/Control Network.
    Note:

    Do not create a second Application Station in DeltaV Explorer. The preferred standby (secondary Application Station) is created by enabling the redundant subsystem in the Properties dialog of this workstation.

  2. Click Properties on the shortcut menu for the Application Station. You can optionally change the name of the existing Application Station on the General page of the Properties dialog, but this is not necessary. However, changing the Application Station name is strongly recommended if it coincidentally ends with the characters _S.
    Important:

    As a general rule, do not specify an Application Station name that ends with the characters _S. When the DeltaV system creates a pair of Application Stations for redundant subsystems, it appends these characters to whatever name you specify as the base name for the Application Station. Having a pair of Application Stations named nodename_S and nodename_S_S could result in misleading or undesirable results.

  3. On the Redundancy page of the Properties dialog, select the Enable a redundant subsystem option, and then select the Batch option.
    Important:

    To enable a redundant subsystem, you must first disable all previously-enabled subsystems for this Application Station. After enabling the redundant subsystem feature on a pair of Application Stations, you cannot also enable any other subsystems, either redundant or simplex on this Application Station.

  4. You can optionally enable the Unattended Workstation Reboot on Failover or Manual Switchover option, if, for example, either of the Application Stations will be located in an unmanned facility.
    Important:

    Before enabling the Unattended Workstation Reboot on Failover or Manual Switchover option, refer to Operational Considerations for Redundant Batch Subsystem for more information.

  5. Select Enable Direct Link for Batch Synchronization if you are connecting the pair with a direct connection.
  6. Click OK to close the Properties dialog.
  7. Export the workstation configuration file either to removable media or to a network location that can be accessed by both Application Stations you will be configuring. You can use the default name for a workstation configuration file, DevData.cfg, or specify a different file name.
  8. On the existing Application Station, run Workstation Configuration (DeltaV/Installation/DeltaV Workstation Configuration).
  9. When the introductory DeltaV Workstation Configuration dialog appears, click Next.
  10. For the Select Workstation Type option, select Professional / Operator / Application / Base / Inter-Zone Server, and then click Next.
  11. When prompted to provide the workstation configuration file that you made in DeltaV Explorer, click Browse, navigate to the exported workstation configuration file, and double-click it.
  12. Select the workstation name, and then click Next. The following message appears: A node with a Redundant Subsystem has been selected. Is this the preferred active Application Station?  Respond Yes to this prompt when configuring the existing (primary) Application Station. When you respond Yes, the Application Station is given the name specified for it in DeltaV Explorer.
  13. Follow the on-screen instructions to complete the configuration of the Application Station.
