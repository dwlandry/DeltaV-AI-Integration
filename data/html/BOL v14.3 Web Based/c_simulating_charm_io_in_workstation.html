Simulating CHARM I/O in a workstation

You can simulate CHARM I/O with either a real CIOC or a virtual CIOC running as a virtual machine in a host computer. The host computer must be a non-DeltaV workstation but can include a virtual CIOC as well as other virtual DeltaV workstations; such as, a virtual Operator Station. The number of virtual CIOCs that can be run in a workstation depends upon the workstation's computing resources. Visit the DeltaV website and refer to the DeltaV Virtual CHARMs I/O Simulation product data sheet for specifications on running virtual CIOCs in a host computer.

No actual CIOC hardware is required to simulate CHARM I/O with a virtual CIOC. Instructions for creating virtual CIOCs can be found on the DeltaV Virtualization media.

Once the setup tasks are complete, the virtual CIOC appears as a decommissioned CIOC in DeltaV Explorer. It can then be commissioned, configured, and used for simulated CIOC data.
