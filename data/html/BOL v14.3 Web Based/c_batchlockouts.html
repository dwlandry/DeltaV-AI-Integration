Batch lockouts

A batch edit object can be locked out for two different actions: for edit or for control. The methods used to accomplish this are LockControl and LockEdit. There are also corresponding unlock methods, UnLockControl and UnLockEdit. If a batch edit object is retrieved from the Campaign Manager server for the purpose of changing a batch's properties, then the code should be encapsulated between these two methods to ensure only one user is making changes at a time. The LockEdit function will fail if called by a batch edit object that is already locked by another user.

The LockControl and UnLockControl methods are used to restrict who can take control of the batch and change its state. If a user locks a batch for control, only that user can release that batch to the Batch Executive, start the batch on the Batch Executive, or remove the batch from the Batch Executive. LockControl will not restrict the batch from being manipulated through the Batch Operator Interface.

Note:

Deleting a batch from the campaign is a campaign LockEdit function as you are editing the campaign, therefore locking the batch for edit or control will have no effect on this functionality.

The Start, Release and Remove batch commands are controlled by two locks, the batch LockControl and the campaign LockEdit. If either lock has been invoked, you cannot perform these commands. When locked at the campaign level using the campaign LockEdit, all batches in that campaign are effectively locked and another user cannot perform any one of these commands or other modifications on any batch in the campaign. When locked using the batch LockControl (where the specific batch must be called), another user cannot perform any one of these commands on the individual batch that is locked.

Additionally, the ability to make batch modifications are controlled by two locks, the batch LockEdit and the campaign LockEdit. If either lock has been invoked, you cannot modify a batch. When locked by the campaign LockEdit, all batches in the campaign are effectively locked. When locked using the batch LockEdit (where the specific batch must be called), another user cannot perform batch modifications on the individual batch that is locked.

For a list of all the commands affected by the batch LockControl and batch LockEdit, refer to the topic, The DVBCMBatchEdit/Info Objects and subsequent methods and properties topics.
