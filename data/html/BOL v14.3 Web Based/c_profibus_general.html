Profibus DP - General Information

Profibus DP (Decentralized Peripherals) is a communications protocol that provides an interface for discrete devices such as actuators and sensors in the field. Twisted pair shielded copper cable is used for data transmission. The high speed, easy to install, RS485 transmission technology that is used by Profibus DP is also referred to as H2.

Profibus PA (Process Automation) is a Profibus variant that meets the needs of process automation and provides an interface for analog devices such as valve positioners and transmitters typically located in hazardous areas. Data and power are transmitted to field devices on the same twisted pair, shielded copper cable using Manchester Bus Powered (MBP) transmission technology, also referred to as H1.

Profibus PA is supported in a DeltaV system only when the Profibus DP card is used in conjunction with the Pepperl+Fuchs PROFIBUS DP/PA transparent segment coupler family of devices. The Pepperl+Fuchs PROFIBUS DP/PA transparent segment coupler family of devices are Emerson Alliance Program products.

Emerson recommends that Profibus PA and Profibus DP slaves are not connected to the same Profibus DP card.
