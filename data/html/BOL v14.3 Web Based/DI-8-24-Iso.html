DI 8-channel 24 VDC isolated card specifications

Installation notes

  • The 8-channel terminal block is recommended to provide terminations for field wiring for the DI 8-channel 24 VDC isolated card. Optional terminal blocks are the Fused 8-channel terminal block and the 16-pin mass terminal block.
  • If you use a mass terminal block with the DI 8-channel 24 VDC isolated card, refer to the terminal block specifications for the input rating for each block. Those specifications might be more restrictive than the specifications listed in the following table.
  • This card requires an S-series controller.

Specifications

DI 8-channel 24 VDC isolated card specifications
Item Specification
Number of channels Eight
Detection level for On > 10 VDC
Detection level for Off < 5 VDC
Input impedance 5 kΩ
LocalBus current (12 VDC nominal), per card
  • 75 mA typical
  • 100 mA maximum
Field circuit power, per card None
Isolation Each channel is optically isolated from the system and from each other and factory tested to 1500 VDC.
Heat dissipation 3.1 W
Optional fuse 2.0 A
Mounting Assigned slot of I/O carrier
