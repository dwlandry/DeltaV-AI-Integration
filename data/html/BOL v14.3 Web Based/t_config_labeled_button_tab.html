Configure Labeled Button tab

A labeled button is used to change any writeable Logic Solver parameter to a value that is specified at configuration time. A typical use could be to reset a CEM Effect (that is, to write the .CV field of the Boolean RESETx parameter to 1).

If no object is selected when the SIS Data Entry Expert is invoked and the Labeled Button tab is used, it creates a pushbutton with a text label on a picture and creates a click-event script for the pushbutton. Otherwise, the SIS Data Entry Expert creates a click-event script for the selected SIS object. If a non-SIS object is selected, this tab is not available.

If Electronic Signature is enabled for the parameter, the Electronic Signature dialog appears when the labeled button is clicked in Run mode. When the Electronic Signature is successfully entered or if Electronic Signature is not enabled, the confirmation dialog is displayed. The operator must then confirm the write request.

The SIS Data Entry Expert dialog prompts for the following:

  • A text label (of up to 40 characters) for the button. This can be a string or a tilde character followed by the name of a variable object (disabled if an object is selected). The font of the text label can be changed. The foreground color of the text label and the foreground color of the button can also be changed and made dynamic. The color and font selections are applied immediately so that you do not need to switch to run mode to see the effect.

  • The full path of the parameter to be written.

  • The numeric value to be written.

  • The Confirmation Information text displayed on the confirmation dialog. This can be a string or a tilde character followed by the name of a variable object. The string can be up to 300 characters and contain any keyboard character except double quote marks ("). Strings can also contain %P which is replaced in Run mode with the value from the %P Parameter. For example, Do You Want to Reset the %P?. When the string is displayed in Run mode, %P is substituted with the value of the parameter defined by %P. Use the browse button to select a variable.

  • The full path of the %P parameter (optional). This option is used in the confirmation information field and is replaced in Run mode with the value of the %P Parameter.

Select the Labeled Button tab on the SIS Data Entry Expert dialog to see the fields associated with the labeled button.  After configuring the required fields, click OK on the SIS Data Entry Expert dialog to create the labeled button on the picture.
