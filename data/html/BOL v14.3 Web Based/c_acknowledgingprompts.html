Acknowledging prompts

Prompts can be built into recipes as the recipes are being developed. If the prompt's parameters are defined as Operator Prompts, the operator receives the prompt when that portion of the recipe executes. The prompt is generated by a particular phase in the running batch, and it requires a specific response.

Soon after starting the PAINT recipe, the operator is notified of an unacknowledged prompt by the blinking question mark (?) on the Unacknowledged Prompts icon on the toolbar.

A valid acknowledgment is required in response to a prompt. For example, if the prompt is expecting a number, a number must be entered as the acknowledgment. If the prompt is expecting a yes or no response, then one of those two responses must be entered.

In this particular recipe, the operator is prompted to supply the agitating time to the batch. 0 is defined as the minimum and 100 minutes is defined as the maximum value.

The operator enters a value of 75 and then clicks the Acknowledge button. Since this is an acceptable entry in this recipe, the batch process continues and the prompt is removed from the prompt list.

You can also acknowledge prompts when running phases externally in DeltaV Operate.
