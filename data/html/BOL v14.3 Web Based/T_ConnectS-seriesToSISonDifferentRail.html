Connect S-series controllers to a Safety Instrumented System on another DIN rail

S-series I/O can connect to a SIS system on another DIN rail using extender cables as shown in the following figure.
SIS Adapter between an S-series Left Extender and M-series 8-Wide Horizontal I/O Carrier on another DIN rail


  1. Connect an S-series Right Extender to the S-series 8-Wide I/O Carrier.
  2. Connect a SIS Adapter to the M-series 8-Wide I/O Carrier that is holding the Logic Solvers.
  3. Connect an S-series Left Extender to the SIS Adapter and install extender cables between the extenders.
  4. Install two 120 ohms BNC terminators on the BNC connectors on the last 1-Wide Horizontal Carrier Extender.
