DeltaV Wireless I/O Card configuration options

Like the CIOC, the WIOC can be configured to support hardware alarms and redundancy, to show integrity errors when its time is not synchronized with other nodes, and to enable the use of cascade ports to connect multiple WIOCs together in series. Following are some additional configuration options for WirelessHART I/O cards.

Note: After changing any of the following properties: Network ID, Common Join Key, or Rotation Period, wait until all devices have rejoined the network before attempting to change these properties again. The rejoining process can take an hour or even more to complete. If devices do not rejoin the network, it may be necessary to restore Network ID and Join Keys using AMS Device Manager or a HART handheld device.
Note: There may be a temporary loss of data after making changes to any of the following:
  • Network ID
  • Common Join Key
  • Enable Network Key Rotation

Change the Network ID and Common Join Keys online

The DeltaV system generates a default Network ID of 01 and a unique Common Join Key when a WIOC is created. All wireless devices in the network must be configured with the Network ID and Common Join Key to participate in the network. Users with the key to the Wireless Provisioning Lock can modify the Network ID and Common Join Key. The Network ID and Common Join Key can be modified when the WIOC is commissioned or decommissioned. Any online changes to the Network ID or Common Join Key are automatically propagated to all wireless devices after a download of the WIOC (including a Changed Setup Data download). Online changes are changes made to a commissioned, downloaded WIOC with reporting devices. Valid ranges for the Network ID are 1 through 32767 and 32767 through 36863. These options are available through the WIOC Properties dialog in DeltaV Explorer.

Enable active advertising

When Active Advertising is enabled, the server polls the wireless network looking for new or unreachable devices to join the network. Users with the key to the Wireless Provisioning Lock can specify the number of minutes that Active Advertising runs. Changes to the active advertising setting take effect immediately without a download.

Rotate the network key

When Network Key Rotation is enabled and downloaded for the WIOC, the WIOC generates a new random network key on a periodic basis to enhance network security. The network key is used to authenticate wireless devices on the network. Users with the key to the Wireless Provisioning Lock can rotate the network key. The key is rotated immediately after the command is issued. The key can be rotated when the WIOC is commissioned. This option is available from the WIOC's context menu in DeltaV Explorer.

Supports HART-IP

The WIOC HART server supports HART-IP which allows the integration of steam trap and machinery health applications into the DeltaV system.
