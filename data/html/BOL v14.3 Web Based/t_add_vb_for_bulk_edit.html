Add Visual Basic for applications

Bulk edit requires that Visual Basic for applications be added to Microsoft Office to ensure that the add-in works correctly.

To add the feature, follow these steps:

  1. Open Control Panel.
  2. Open Programs and Features.
  3. Select the version of Microsoft Office Professional Plus installed on the computer.
  4. Right-click and select Change.
  5. On the dialog that appears, select Add or Remove Features.
  6. Click Continue.
  7. Under Office Shared Features, click Visual Basic for Applications and select Run from My Computer.
  8. Click Continue.
  9. Wait for VBA to be configured, and then click Close.
