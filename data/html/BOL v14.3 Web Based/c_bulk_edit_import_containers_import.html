Import contained and containing module data

To create the new modules you must import the edited files.

Note:

You must import the files for the contained modules before you import the file for the containing module.

The steps for importing are the same for all modules:

  1. From DeltaV Explorer, select File > Import > User Defined.

  2. In the Format source dialog, browse to and open FLOW_CONTROL.FMT.

  3. Click Next.

  4. In the Import data source dialog, browse to and open FLOW_CONTROL_ASCII.TXT.

  5. Click Next.

  6. On the Import results dialog, click Import.

    After a moment the Import complete dialog appears. It has a log of the import actions. If errors are reported scroll through the log or open DeltaV\DVData\ImportExportProgress.log to determine the cause.

  7. If the import was successful, click Close.

  8. Repeat steps 1 through 7, opening TOTAL_FLOW.FMT and TOTAL_FLOW_ASCII.TXT.

    Note that the FLOW_CONTROL and TOTAL_FLOW modules were imported to the AREA_A level.

  9. Repeat steps 1 through 6, opening TOTALIZER.FMT and TOTALIZER_ASCII.TXT.

    The import replaces the contained modules created by importing the TOTALIZER modules with copies of the contained modules you created. The hierarchy under AREA_A now looks similar to the following figure.

    Note that the TOTALIZER-n modules are populated with FLOW_CONTROL-n and TOTAL_FLOW-n modules.

    Importing TOTALIZER_ASCII.TXT moved the FLOW_CONTROL and TOTAL_FLOW modules under the TOTALIZER modules. The tildes you prepended the MODULE_BLOCK_BINDING.MNAME values in the TOTALIZER_ASCII.TXT file caused the import to remove the extra modules created when  TOTALIZER_ASCII.TXT was imported.
