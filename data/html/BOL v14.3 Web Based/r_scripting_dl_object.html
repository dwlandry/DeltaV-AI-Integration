DL object

The DL object provides functions related to accessing information about or commanding behavior in 'this' instance of DeltaV Live. The following DL object functions are supported in DeltaV Live graphics expressions and scripting. See the subtopics under DL object for more details about each function.

In the table below, <CP> stands for the additional context or placement information.

Functions for the DL object
Function Description Syntax
DN() Evaluates and returns the argument as a string. When the argument is a literal string, the .DN function authorizes display rename tracking to automatically update the string argument to match the new name. DL.DN(DisplayName)
OpenContextDisplayAsync() Opens the specified contextual display, providing it with the primary context information (tag), optional additional context information, and optional initial placement rules. DL.OpenContextDisplayAsync(cDisplayName, tag, placement?[], context1?, context2?, context3?, context4?, X?, Y?)
OpenDetailAsync() Opens the detail display configured for the specified module, device, or node name, (tag), optional additional context information, and optional initial placement rules. DL.OpenDetailAsync(tag, placement?[], context1?, context2?, context3?, context4?, X?, Y?)
OpenDisplayAsync() Opens the specified display, optional additional context information, and optional initial placement rules. DL.OpenPrimaryDisplayAsync(moduleName, placement?[], X?, Y?)
OpenFaceplateAsync() Opens the faceplate display configured for the specified module, device, or node name (tag), optional additional context information, and optional initial placement rules. DL.OpenFaceplateAsync(tag, placement?[], context1?, context2?, context3?, context4?, X?, Y?)
PopupClose() Closes 'this' display, if it is running in a pop-up window. DL.PopupClose()
PopupMinimize() Closes 'this' display, if it is running and visible in a pop-up window. DL.PopupMinimize()
PopupRestore() Restores 'this' display to its visible state, if 'this' display is running and minimized in a pop-up window. DL.PopupRestore()
OpenContextDisplayAsTooltip () Opens the specified contextual display in a tooltip-style window, providing it with the primary context information (tag), optional additional context information, and optional initial placement rules. DL.OpenContextDisplayAsTooltip(DisplayElement, cDisplayName, tag, context1?, context2?, context3?, context4?, X?, Y?)
OpenPrimaryDisplayAsync() Opens the primary control display configured for the specified module, device, or node name. DL.OpenPrimaryDisplayAsync(moduleName, placement?[], X?, Y?)
