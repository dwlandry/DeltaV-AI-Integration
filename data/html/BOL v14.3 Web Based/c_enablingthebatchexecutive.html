Enabling the Batch Executive

In order to run a batch either in Recipe Simulator or real time, you must first enable the Batch Executive on a machine that will run the Batch Executive application. This lets the DeltaV database know which machine has the responsibility for processing the recipes, arbitrating equipment, handling messages, coordinating phase link groups, and recording events. A maximum of four Batch Executives can be enabled on a DeltaV network.

General Properties of the Batch Executive

Once the Batch Executive subsystem is enabled (from the subsystem Properties dialog), you must download the workstation for the change to take effect.

When downloading the Batch Executive, the following functions are not available through the Batch Operator Interface or the DeltaV Operate Batch controls:

  • Add a batch to the batch list.

  • Create a manual phase batch.

  • Create a campaign.

  • Release a batch.

When importing a workstation, be sure to correctly answer which components you want to overwrite during the download. Individually select 'No' on any items that are not to be imported. Then, you can answer 'Yes' to overwrite the existing Batch Server object (BATCH_AREA). This imports the Batch Executive configuration changes.
