Requirements for automatic assignment

Several conditions must be met before automatic assignment can occur:

  • Automatic assignment must be enabled.  Automatic Assignment can be enabled from the Module Properties dialog in Control Studio.

  • The DeltaV function block must support automatic assignment.

  • The DeltaV function block must be in a loop with a synchronized control path.

  • The function block execution order must be correct; it must follow the logical flow in the control.

  • All the blocks in the synchronized control path must support auto assignment or must be assigned to fieldbus. .

  • The module's input and output links must be of the same parameter type. .

  • The module must be assigned to a controller node and saved before automatic assignment can occur.

Also, the system enforces limits on VCRs and function blocks. .
