DeltaV RM100 Base Smart Switches

Installation notes

  • The RM100 Base Smart Switches can be mounted on a 19 inch rack or on a wall. If the switch is mounted on a 19 inch rack, be sure to install sliding mounting rails to properly hold the switch.
  • Ensure that there is at least one free rack space (approximately 5 cm) above and below the switch because heat is discharged through the switch's housing.
  • The RM100 Base Smart Switches consist of a base switch and, depending upon the switch type, up to two media modules that plug into the base switch and provide the media options.
  • All of the 8-port and SFP media modules are hot-pluggable; however, when a twisted pair media module is replaced with a fiber-optic media module, the switch performs a warm restart that temporarily disrupts communications.
  • The RM100 Base Smart Switch-RP supports redundant input power.

Port information

Port information for the DeltaV RM100 Base Smart Switches
Model Number and types of ports Image
RM100-Base Smart Switch
  • 2, 10/100/1000mb/s twisted pair ports with RJ45 connectors
  • 8, fast Ethernet ports
  • 2, 100/1000mb/s SFP-based ports
  • 2 sockets for media modules for an additional 8 or 16 ports.

Either the 10/100/1000mb/s twisted pair ports or the SFP ports can be used. Both port types cannot be used at the same time.

RM100-Base Smart Switch-RP
  • 2, gigabit Ethernet combo ports
  • 8, fast Ethernet ports
  • 2, 100/1000mb/s SFP-based ports
  • 2 sockets for media modules for an additional 8 or 16 ports.
Redundant input power

The standard power supply alone supplies power to the RM100-Base Smart Switch-RP. The redundant power supply automatically becomes active if the standard supply fails.

RM100-8TX
  • 8, 10/100mb/s twisted pair ports with RJ45 connectors
  • 2, 10/100/1000mb/s twisted pair ports with RJ45 connectors
  • 2, 100/1000mb/s SFP-based ports

This is a fixed-configuration switch; no additional media modules can be added to it.

Either the 10/100/1000mb/s twisted pair ports or the SFP ports can be used. Both port types cannot be used at the same time.

RM100-24TX
  • 24, 10/100mb/s twisted pair ports with RJ45 connectors
  • 2, 10/100/1000mb/s twisted pair ports with RJ45 connectors
  • 2, 100/1000mb/s SFP-based ports

This is a fixed-configuration switch; no additional media modules can be added to it.

Either the 10/100/1000mb/s twisted pair ports or the SFP ports can be used. Both port types cannot be used at the same time.
