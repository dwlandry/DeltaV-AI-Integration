Enable DCOM on the PC

Normally, DCOM is enabled on the machine when Windows is installed. However, if DCOM is not enabled, you can do so by following these steps on both the server and client machines:

  1. Run the executable file, dcomcnfg.exe. The Component Services window opens.
  2. In the left pane, open Component Services. A Computers folder appears.
  3. Open the Computers folder. The My Computer icon appears.
  4. Right-click the My Computer icon and select Properties.
  5. Select the Default Properties tab.
  6. Select the Enable Distributed COM on this computer check box.
  7. Changing this value requires a reboot.

The EnableDCOM key in the Windows registry is set to "Y" when this check box is selected. If DCOM is not enabled, then all cross-machine calls are rejected (the caller, typically, gets an RPC_S_SERVER_UNAVAILABLE return code).
