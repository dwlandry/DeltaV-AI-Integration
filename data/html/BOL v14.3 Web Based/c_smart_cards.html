Smart cards

The DeltaV system supports the use of smart cards for logging on to DeltaV workstations. The use of smart cards in the DeltaV system requires the following:

  • A Domain-based environment using Active Directory.
  • A smart card reader that supports the Microsoft CryptoAPI.
  • A smart card for each DeltaV user who requires access to the workstation.
  • A smart card reader installed on the workstation and the smart card reader's service is running.
  • A Certificate Authority installed (that is, Active Directory Certificate Services enabled with the Certification Authority role installed) on the DeltaV control network.
Note:

When using Smart Cards to log into DeltaV, do not enable the policy: Interactive logon: Require smart card, as this will prevent the system from functioning as expected.

The DeltaV system administrator has the option of requiring the use of smart card, or making it optional on a per DeltaV workstation basis. The system administrator is responsible for the following on each workstation where the smart card is used
  • Installing the smart card software and hardware.
  • Setting up certificates for each card on the server machine where certification authority is deployed.
Note: After enrolling the certificate for a smart card, you typically must pull the card and reinsert it before you can use it to log on.

To make sure a smart card is working correctly, use it first to log on to Windows before logging on to the DeltaV system. The card must be able to log a user on to Windows in order to ensure that it can be used to log a user on to the DeltaV system.

Leave the card in the reader when using applications that interface with the DeltaV database (for example, Control Studio, DeltaV Explorer and Recipe Studio). If you remove the card from the reader you lose user privileges for certain functions on these applications.

Tip:

If an error occurs stating the Smart Card logon is not supported for your user account, contact your system administrator. The issue could be with how the certificate is configured on the DeltaV domain controller.

For example, the following steps might be needed

  1. On the domain controller, run Microsoft Management Console (mmc.exe).

  2. Go to File > Add/Remove Snap-ins.

  3. Select Certificates, click Add and when prompted, select Computer account.

  4. Click Next, Finish, and OK.

  5. In the hierarchy, expand Certificates (Local Computer), right-click Personal, click All Tasks, then click Request New Certificate.

  6. Click Next (accepting defaults) until you are on the Request Certificates page. There, select Domain Controller Authentication and click Next until the final page and then click Finish.
