LSNB diagnostics

The LSN Bridge, regardless if it is Assigned/Decommissioned or Assigned/Commissioned, is shown with the following subsystems: LSN Communications, GSN Communications and Redundancy.

The LSN Communications subsystem displays the integrity of the Local Safety Network while the GSN Communications subsystem indicates the integrity of the Global Safety Network from the LSN Bridge's perspective. Both Communications subsystem show the Primary and Secondary nodes when expanded.

The Redundancy subsystem of the LSN Bridge behaves in the same manner as the Redundancy subsystem of a CSLS. It has a Standby subsystem. Under this, it has its own LSN and GSN Communications subsystem that, when expanded, also show their Primary and Secondary nodes.

The CHARMs SIS Network is similar to the current SIS Network for the SLS 1508 Logic Solvers. A folder representing each domain appears under the CHARMs SIS Network. Each Domain folder lists the LSN Bridges that are configured to be part of that Domain. Only assigned and commissioned LSNBs appear under the CHARMs SIS Network.
