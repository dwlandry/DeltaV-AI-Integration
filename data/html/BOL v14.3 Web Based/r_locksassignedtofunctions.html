Locks assigned to functions

Locks are assigned to various user functions, such as downloading, uploading, changing the configuration database, and so on. Functions are assigned to default locks initially. Use the DeltaV Explorer to change the lock associated with a function. Batch functions, Campaign Manager, Continuous Historian, and Event History have their own locks.

Refer to the following table for a list of the function locks, the default function to which each lock is assigned, and descriptions of the tasks that users with a key to the lock can perform:

EDIT_DOWNLOAD_MODULES

Can Edit

Permits the following actions for modules assigned to the nodes that have the Can Edit lock:
  • Edit modules
  • Download the modules
  • Upload changes to the modules
  • VCAT for module checkout/checkin
  • VCAT for download of checked out module

NODE

EDIT_IO_AND_SETUP_DEVICES

Can Setup Devices

Permits the following actions for modules assigned to the nodes that have the Can Setup Devices lock:
  • Edit IO properties, channel and CHARM
  • Autosense CHARMs if the node is CIOC
  • Assign CHARM to controller (if there is currently no assignment)
  • Autosense devices
  • Reconcile device
  • AMS Device Manager
    • Change the AMS Device Manager database
    • Send reconciled data to the device
    • Send the command to start bulk transfer
    • Open the device in AMS Device Manager and editing device information
  • Lock/unlock Hart 7 devices using Hart Command
  • Replace fieldbus devices
  • Decommission/Commission fieldbus devices
  • Download fieldbus device and port
  • Modify fieldbus resource and transducer blocks
  • Modify fieldbus device properties
  • Change device database for fieldbus
  • List/sense wireless devices
  • Commission wireless devices
  • Edit device placeholder properties on CIOC, CSLS, and WIOC
  • Download card
  • Download CHARM
  • Lock or unlock a node
  • Download the CIOC
  • VCAT for checkout/checkin device

  • VCAT for download if device is checked out
