Bulk editing HART devices

The main uses of Bulk Edit for HART devices are:

  • Creating HART devices on channels from a template or definition using Bulk Edit import 

  • Comparing the parameter values of multiple devices by exporting devices having a common template or definition to check for differences 

This section outlines how to bulk edit HART devices and SIS HART devices.
