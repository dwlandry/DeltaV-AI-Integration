DeltaV Control Network overview

The DeltaV Control Network is an isolated Ethernet local area network (LAN) that provides communication between DeltaV controllers and workstations. Cat 5(e) ScTP cable and fiber-optic cable can be used in DeltaV Control Networks.

A DeltaV Control Network is dedicated to the DeltaV system; no other devices can be attached to a DeltaV Control Network. The DeltaV Control Network has been designed to be redundant for communication reliability. It uses primary and secondary communication channels that are implemented with separate Ethernet NIC cards as well as separate Ethernet switches for each channel.

A small DeltaV system with only one ProfessionalPLUS and one controller does not require an Ethernet switch. For small systems of that kind, use a shielded crossover cable with shielded RJ45 connectors at both ends so that the controller's RJ45 connector is properly grounded. For large DeltaV systems with multiple workstations and controllers, where there are additional cable requirements, use Ethernet switches such as the DeltaV Smart Switches.

Note:

Take care when designing your network so that you do not have large amounts of network traffic running through the area control network across switches which are also used for control (for example, controllers and CIOCs). Such traffic can compromise control integrity, causing ACN switchovers and device dropouts.
