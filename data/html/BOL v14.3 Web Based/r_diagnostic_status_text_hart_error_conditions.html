Diagnostic status text for HART error conditions (CHARMs I/O)

Channel and CHARM error conditions trigger status information in DeltaV Diagnostics to help you troubleshoot problems. Because Diagnostics displays only one status error message at any given time, the most serious error is reported. The following table lists the order of precedence for all error conditions used in determining HART status.

Error conditions that cause both bad integrity and bad variable status have the highest priority; errors indicating uncertain variable status only are classified as medium priority; and, conditions reported for information purposes only have the lowest priority.
