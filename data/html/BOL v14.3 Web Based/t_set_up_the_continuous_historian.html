Enable historical data collection

The Continuous Historian subsystem must be enabled on each workstation that will be used to collect, store, and retrieve historical data. The Continuous Historian subsystem exists under the workstation in DeltaV Explorer.

You can enable the DeltaV Continuous Historian on a ProfessionalPLUS workstation, an Application Station, or an Operator Station. No more than one Continuous Historian subsystem can be enabled on a single DeltaV workstation. Within the DeltaV network, only the DeltaV Continuous Historian, the Advanced Continuous Historian, or OSIsoft PI Server can be enabled to run on an Application Station. You can also, however, install PI Server on a non-DeltaV workstation outside the DeltaV network.

Complete the following steps to set up the Continuous Historian subsystem:

  1. Configure history collection for module and node parameters.
  2. Assign the modules.
    Note: Historical data for modules can only collected if the modules are assigned.
  3. Download the controllers or workstation to which the modules are assigned.
  4. Enable the Continuous Historian subsystem for the workstation(s) that collects historical data and configure the historian properties. To enable the Continuous Historian subsystem on a ProfessionalPLUS workstation or an Operator Station, right-click the Continuous Historian subsystem under the workstation in DeltaV Explorer on the ProfessionalPLUS workstation, and then select Properties from the context menu. On the Continuous Historian Properties dialog, select the Enabled check box. To enable the Continuous Historian subsystem on an Application Station, right-click the Continuous Historian subsystem under the workstation in DeltaV Explorer on the ProfessionalPLUS workstation, and then select Properties from the context menu. On the Continuous Historian Properties dialog, select one of the following options in the Continuous Historian Selection field:
    • Use DeltaV Continuous Historian
    • Use Advanced Continuous Historian
    • Use Enterprise Historian
    Important:

    You will not be able to successfully download the workstation unless the historian that you enable matches the historian selected in the Select Historian dialog while installing the DeltaV Application Station or the historian selected in the Continuous Historian box of the DeltaV Upgrade Wizard configuration dialog while upgrading the Application Station.

  5. Assign specific area folders and nodes to the Continuous Historian subsystem.
  6. Download the workstation.
    Note: After the initial download of the history collection subsystem there may be a short period of time before the overall integrity of the subsystem reports GOOD.
