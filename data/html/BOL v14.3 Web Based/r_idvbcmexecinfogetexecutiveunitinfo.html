VB

Public Sub GetExecutiveUnitInfo(

ByVal bstrUnitClass As String,

ByRef vArrayUnitNames As Variant,

ByRef vArrayUnitIDs As Variant,

ByRef vArrayAreaNames As Variant,

ByRef vArrayAreaIDs As Variant,

ByVal lWait As Long)

This method returns all of the units that match the unit class name passed in on a given Batch Executive. For a given unit class, this method will return a complete list of unit names and resource IDs that are of that unit class type.

Return Values

S_OK - success

else - failed

Memory Allocation

The caller is responsible for releasing both the vArrayUnitNames and vArrayUnitIDs safearrays.

Visual Basic Usage Example

Private Sub Button1_Click()
    Dim vArrayUnitNames As Variant, vArrayUnitIDs As Variant
    Dim vArrayAreaNames As Variant, vArrayAreaIDs As Variant
    Dim szUnitClass As String, szName As String, szTemp As String
    Dim objExecInfo As DVBCMExecInfo
    Dim lCount As Long, lID As Long
    Dim bUnitOutOfService As Boolean
    Call GetExecutiveInfoObject(objExecInfo)
    Call GetUnitClassName(szUnitClass)
    Call objExecInfo.GetExecutiveUnitInfo(szUnitClass, vArrayUnitNames, _
            vArrayUnitIDs, vArrayAreaNames, vArrayAreaIDs)
    For lCount = LBound(vArrayUnitNames) To UBound(vArrayUnitNames)
        lID = vArrayUnitIDs(lCount)
        szName = vArrayUnitNames(lCount)
        szTemp = "The unit named, " & szName & " has an ID = " _
                & lID & " and is in the area named = " _
                & vArrayAreaNames(lCount) & " whose ID is = " _
                & vArrayAreaIDs(lIndex)
    Next lCount
End Sub

Parameter Name

Purpose

bstrUnitClass

The name of the unit class from which to retrieve the information.

vArrayUnitNames

A safearray of strings representing the names of the units that match the class name passed in.

vArrayUnitIDs

A safearray of Booleans which indicate whether the corresponding unit entry is currently out of service.

vArrayAreaNames

A safearray of strings representing the names of the areas to which each of the units above belong.

vArrayAreaIDs

A safearray of longs representing the resource IDs of the areas.

lWait

Optional. Default = 30000. Time to wait for a server resource in milliseconds.
