Locked logic solver functionality

You can apply a software lock to logic solvers to prevent inadvertent changes. To lock or unlock a logic solver, select a logic solver in Explorer or Diagnostics. You must have SIS Can Download privilege to lock and unlock a logic solver.

When a logic solver is locked, the system prevents the following operations:

  • Control Studio:
    • Entering debug mode when editing SIS modules
    • Making online changes to parameters categorized as tuning (only for CSLS major revision 2 and later)
      Note: The Enhanced access control for function block parameters check box on the CSLS properties (Security tab) dialog must be selected to enable access control for online changes.
  • DeltaV Explorer:
    • Decommissioning the logic solver
    • Deleting the logic solver
    • Downloading the logic solver
      Note: The system also prevents downloads to logic solvers if the hosting computer is locked.
  • Diagnostics:
    • Performing user-initiated switchovers
    • Forcing Reset on Active
    • Forcing Reset on Standby

You can make parameter changes in Control Studio On-line when a logic solver is locked.
