Granting SOFTPHASEUSER Permissions to the Installed Soft Phase Directories

You must grant the SOFTPHASEUSER access to the Soft Phase directories as installed on the non-DeltaV machine.

  1. On the non-DeltaV machine, run Windows Explorer.
  2. Right-click on the top-level Soft Phase directory (the 'root directory' where you installed the Soft Phase environment).
  3. Select Sharing and Security from the context menu.
  4. Click the Security tab.
  5. Add the SOFTPHASEUSER to the list of users with permission to access this folder.
  6. Give the SOFTPHASEUSER the Read & Execute and Write permissions.
  7. Click the Advanced button on the Security tab.
  8. Select the check box for Inherit from parent the permission entries that apply to child objects. Include these with entries explicitly defined here.
    Note:

    This last option gives Read & Execute permissions to the subdirectories of the 'root' Soft Phase directory (where you installed the Soft Phase environment).

  9. Click OK until all dialogs are closed.
