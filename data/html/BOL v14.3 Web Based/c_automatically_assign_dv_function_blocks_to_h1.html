Automatically assigning DeltaV function blocks to the H1 card

A subset of DeltaV function blocks can be automatically assigned to run in the Series 2 H1 card rather than in the DeltaV controller. DeltaV function blocks that run in the H1 card are included in the fieldbus macrocycle and their execution is fully synchronized with function blocks running in other devices on the segment. Automatic assignment  minimizes scheduling delays that commonly occur in loops in which the control spans the controller and field devices. This feature is enabled on a module-by-module basis on the Execution tab of the module Properties dialog in Control Studio. Automatic assignment is disabled by default.
