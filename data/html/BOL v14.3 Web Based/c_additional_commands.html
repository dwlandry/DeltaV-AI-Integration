Additional Smart Switch commands (serial port interface)

There are additional commands available that this topic has not covered. To see a list of the commands available, enter a question mark (?) at the Emerson prompt. The available commands depend on whether you are logged in as admin or user. Several of the commands (show and clear for example) have several options. To see the options for a command, enter the command and a question mark (?) at the Emerson prompt.

Following are examples of switch commands that can be used to troubleshoot network problems.

  • show running-config
  • show sysinfo
  • show temperature
  • show port-locking
  • show port-locking all
  • show port all
  • show interface ethernet x/x (x/x is module/port on switches that are modular)
