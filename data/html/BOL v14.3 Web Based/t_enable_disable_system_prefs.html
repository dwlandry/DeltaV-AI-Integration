Enable or disable a system preference

To enable or disable a function by using DeltaV System Preferences, complete the following steps:

  1. Click DeltaV Engineering > System Preferences on the Start menu.
  2. In the System Preferences dialog, select or clear the check box for the function that you want to enable or disable. Options on the System Preferences dialog are arranged in groups. You can enable or disable individual options or all options included in a group.
Note: After changing a system preference option, it may be necessary to restart the affected DeltaV client application for the change to take effect.

If enabling or disabling a function requires restarting the DeltaV Database Server, shut down and restart the server by completing the following steps:

  1. Click DeltaV Engineering > Database Administration on the Start menu.
  2. In the Database Administration window, select Shutdown Server on the File menu.
  3. On the Shutdown Server dialog, enable the Force shutdown even if clients are connected option.
  4. If a notification window appears for any application connected to the DeltaV Database Server, exit the application by clicking the Yes button.

    After the Shutdown Server command terminates, the message Database Server is shut down appears in the status bar of the Database Administration window.

  5. Select Connect to Server on the File menu.

    After the Connect to Server command terminates, the message Database Server is running appears in the status bar of the Database Administration window.

  6. Optionally, restart any application that you exited while shutting down and restarting the DeltaV Database Server.
