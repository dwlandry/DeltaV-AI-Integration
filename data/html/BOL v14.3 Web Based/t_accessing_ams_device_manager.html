Access AMS Device Manager

From DeltaV Explorer, you can launch AMS Device Manager in context from a HART device.

Note:

After AMS Device Manager is launched either from DeltaV Explorer or the Start menu, only one instance of it runs on the DeltaV workstation.

Prerequisites for Launching AMS Device Manager from DeltaV Explorer

There are some prerequisites for launching AMS Device Manager from DeltaV Explorer:

  • AMS Device Manager must be installed on the same workstation as the DeltaV software.

  • The user must be logged onto the DeltaV system.

  • If accessing a HART device, the user must select a HART-enabled channel.

  • The DeltaV device tags and the AMS tags must match for each device.

To access AMS Device Manager from a HART device in DeltaV Explorer:

Be sure that the prerequisites listed above have been met.

  1. Click Start > DeltaV Engineering > DeltaV Explorer to open DeltaV Explorer.
  2. Navigate to the HART channel and ensure that it is enabled. (Right-click the channel and select Properties to see if it is enabled.) Refer to the DeltaV Explorer online help if you need assistance in navigating to an object.
  3. Autosense the HART device to create the DST. (Right-click the channel, and then select Auto-sense HART device.) The DST appears beneath the channel in the Explorer hierarchy.
  4. Right-click the device, and then select the desired AMS Device Manager command from the context menu.

You can also access device methods from DeltaV Operate.
