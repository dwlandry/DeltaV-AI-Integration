Recipe Studio

The DeltaV Recipe Studio application is used to create and modify recipes. Recipes are any series of steps used in a batch process. This includes phases, operations, unit procedures and procedures. A recipe can be as simple in design as a single phase or as complex as a series of procedures that has embedded unit procedures, operations, and phases.

Before you begin using Recipe Studio, review the sections for information on recipes, Procedural Function Charts (PFCs), and the development of control strategies.
