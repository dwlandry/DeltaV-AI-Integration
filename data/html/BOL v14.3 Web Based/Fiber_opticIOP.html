Fiber-optic I/O Port specifications

Installation notes

  • The CHARM I/O Carrier and the WirelessHART I/O Carrier can house either a fiber-optic I/O port (IOP) or copper I/O Port. The fiber-optic IOP consists of a control network port. The copper IOP consists of a primary and secondary control network port and a primary and secondary cascade port.
  • Fiber-optic I/O ports can be used for remotely located CHARM I/O (CIOCs) and WirelessHART I/O cards (WIOCs). CIOCs and WIOCs with a fiber-optic port cannot be daisy-chained and are used in star-connected networks.
  • The IOPs are removeable. To remove an IOP, depress the button next to the IOP and pull it out of the carrier.

Item Specification
Redundant Ethernet connections (primary and secondary)

Fiber-optic: 100BASE-FX with MTRJ connectors; full duplex; multimode; 1300 nm; 2 km nominal distance.

Fiber-optic link budget

62.5/125 um:

  • Transmit power minimum: -20 dBm
  • Receive sensitivity maximum: -31 dBm
  • Attenuation maximum: 11 dB
  • Input power maximum: -14 dBm

50/125 um:

  • Transmit power minimum: -23 dBm
  • Receive sensitivity maximum: -31 dBm
  • Attenuation maximum: 8 dB
  • Input power maximum: -14 dBm
