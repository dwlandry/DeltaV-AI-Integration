Secure parameters in SLS 1508 SIS systems

A checkbox in each SLS 1508 Logic Solver's properties dialog sets whether it has eight secure parameters or 16 high-density secure parameters. Secure parameters can be read by other modules in Logic Solvers on the same controller. Additionally, you can configure a logic solver to publish its secure parameters globally to the SIS Network domain it is in or to publish globally to the entire SIS Network. Publishing as domain global makes the secure parameter data available to all other logic solvers in the SIS Network domain on the same fiber optic ring. A total of 32 logic solvers in each SIS Network domain (no more than 16 on any controller) can publish globally to the domain.

In addition as many as 16 logic solvers in the SIS Network can be configured as system global publishers. System global data can move around the entire SIS Network, depending on Ethernet connections between fiber optic rings.
