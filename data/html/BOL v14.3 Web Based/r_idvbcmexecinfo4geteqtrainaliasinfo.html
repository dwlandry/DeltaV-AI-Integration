VB

Public Sub GetEqTrainAliasInfo(

ByVal bstrEqTrainBaseClass As String

ByRef bstrAlias As String

ByRef vUnitClass as Variant

ByRef plType As Long

ByRef vArrayDownstreamAlias As Variant

ByVal lWait As Long)

This method returns the properties of the equipment train alias with downstream aliases.

Return Values

S_OK - success

else - failed

Memory Allocation

The caller is responsible for releasing the vArrayDownstreamAlias safearray.

Visual Basic Usage Example

Private Sub Button1_Click()
    Dim bstrEqTrainBaseClass as String
    Dim bstrAlias As String
    Dim vUnitClass As Variant
    Dim plType As Long
    Dim vArrayDownstreamAlias As Variant
    Dim objTrainAliasInfo As IDVBCMExecInfo4
    Call objTrainAliasInfo.GetEqTrainAliasInfo(bstrEqTrainBaseClass, bstrAlias, vUnitClass, plType , vArrayDownstreamAlias)
End Sub

Parameter Name

Purpose

bstrEqTrainBaseClass

The returned string representing the equipment train class from which to retrieve the alias and unit information.

bstrAlias

The name of the unit alias about which to retrieve the information.

vUnitClass

The name of the unit class associated with the alias in bstrAlias.

plType

The value (as long) for the alias' selection mode. 1=defer, 2=fixed, and 3=from policy

vArrayDownstreamAlias

Safearray of the names of the units configured as downstream of the current unit.

lWait

Optional. Default = 30000. Time to wait for a server resource in milliseconds.
