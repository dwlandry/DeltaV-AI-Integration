Create ping rules

It is assumed that you have tested communications by establishing ping communications between the computers on the internal and external network.

  1. In the firewall's web UI navigate to Protection > Inbound/Outbound connections, select Add Inbound connection or Outbound connection to create the inbound and outbound ping rules to allow all of the ping communications you have established.
  2. On the Create Inbound/Outbound connection page, select Ping from the Application drop-down list.
  3. Select the DeltaV workstation and the external workstation from the drop-down lists.
  4. Select Enabled.
  5. Deselect Log.
  6. Click the Apply button. It will take a few seconds to build the rule and you will receive a message when the rule is successfully built.
  7. Continue to create the inbound and outbound ping rules for all of the pings that are currently running.
    Note: Connections only appear on the Dashboard Summary if actual communications are occurring through the firewall. If communications stop for some reason (such as the application is terminated or stops communicating) the connection entry will not appear on the Dashboard Summary. If the applications create multiple communications using the same rule you will observe multiple entries in the connections section.
