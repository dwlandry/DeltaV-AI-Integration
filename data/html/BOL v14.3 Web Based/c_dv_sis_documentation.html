DeltaV SIS documentation

The DeltaV SIS documentation includes this book and the DeltaV SIS Safety Manual and online help for SIS components. The information in this book documents only the features and tasks in DeltaV SIS systems that are unique or different than that in standard DeltaV systems. To configure and operate a safety instrumented system with DeltaV SIS software you use the same tools used by a DeltaV process control system. Features and tasks that are common to both DeltaV SIS systems and basic DeltaV systems are covered in the standard DeltaV documentation. If you are not already familiar with DeltaV systems, please read the DeltaV Getting Started manual to learn how to use the DeltaV engineering tools.

Although DeltaV SIS software uses DeltaV engineering tools, and the features and tasks required to design,  implement, and operate a safety instrumented system with DeltaV SIS software are similar to the tasks required to implement a process control system with basic DeltaV systems, there are differences between the two. These differences are explained throughout this book in two different ways:

  • Features that are similar for both basic DeltaV systems and DeltaV SIS system are explained by exception. That is, this document explains only the differences and refers to the DeltaV documentation for general information. The User Manager is one example of a feature in this category.

  • Features that are unique to DeltaV SIS systems or that differ greatly between a basic DeltaV system and DeltaV SIS system are explained in full. The DeltaV SIS function blocks are an example of a feature in this category.

There are two types of SIS systems, SLS 1508 Logic Solver systems and CHARMs Smart Logic Solver systems. The major differences in the two systems are in the hardware and the configuration of a system within DeltaV Explorer. The two different systems has caused the SIS documentation to be subdivided into three parts:
  • SLS 1508 SIS system information — This part documents features that are unique for SLS 1508 systems. An example of this type of information is SISNet Domains.
  • CHARMs Smart Logic Solver SIS system information — This part documents features that are unique for SIS Controllers and CSLSs.
  • Common information — Both systems use the same function blocks, module types, and secure parameters, the only differences being configuration limits. Minor differences due to the two SIS system types are noted when necessary.

When a topic contains information specific to a particular SIS system type, that system type is included in the topic title or topic text. Topics that contain information that is the same in both system types use generic terms like logic solver and SIS and do not specify an SIS system type.

The DeltaV SIS documentation (except the DeltaV SIS Safety Manual) is included as a book within the standard DeltaV Books Online. The DeltaV Safety Instrumented Systems book contains the information you need to implement and operate a safety instrumented system. If you need information on basic DeltaV configuration or operation, refer to the DeltaV Books Online.

The DeltaV SIS Safety Manual contains additional information on DeltaV SIS systems. The DeltaV SIS Safety Manual is distributed on the DeltaV Documentation Library disk.
