High Performance M1_CH_S_ Tag integration dynamo (HP_M1_CH_S_)

HP_M1_CH_S_ dynamo for analog tag I/O blocks


HP_M1_CH_S_ dynamo for discrete tag I/O blocks


This dynamo can be used with tag integration blocks (TAGAI, TAGAO, TAGDI, TAGDO). When customizing the dynamo, select a block type in the FB field on the Dynamo Properties dialog:
  • AI: TAGAI block
  • AO: TAGAO block
  • DI: TAGDI block
  • DO: TAGDO block

For the analog blocks, the dynamo displays a combination bar graph representing the output of the blocks. For the discrete blocks, the dynamo displays a PV Word. When OUT_D equals 1, the dynamo shows the On Word; when OUT_D equals 0, the dynamo shows the Off Word. You define the On Word and Off Word in the Dynamo Properties dialog.

The following elements are present on the dynamo:

  • Alarm icon

  • Display tag

  • Combination Bar Graph or

  • Abnormal status icons
