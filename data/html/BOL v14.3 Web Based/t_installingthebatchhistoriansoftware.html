Install the Batch Historian software

To install the Batch Historian server and the Historian Administration Tool, complete the following steps:

  1. Insert the DeltaV Installer disk into the drive.
  2. From the DeltaV installation menu, select Other DeltaV Products. If the menu does not appear, select Start > Run, navigate to the \DV_Extras\BH_Server folder on the DeltaV Installation disk #1, and run the setup.exe program.
  3. From the next screen, select Batch Historian Server.
  4. Accept the defaults for the dialogs that appear during the installation. Microsoft SQL Server Standard is required to run the Batch Historian server. If not already installed, you are prompted to install it.
  5. To install Microsoft SQL Server Standard, insert the SQL Server Standard disk into the drive. When done, the SQL installation program reboots the system.
  6. After the system restarts, repeat t_installingthebatchhistoriansoftware.html#t_installingthebatchhistoriansoftware__step_C48A264467194113A502A3AD6EF2F9F2 through t_installingthebatchhistoriansoftware.html#t_installingthebatchhistoriansoftware__step_F92DD7258D9B43329DB663A53BC93D57 above.
  7. After the Batch Historian software has been installed, click Yes to reboot the system.

    During the installation of Batch Historian Server, the status of the workstation to which modules are assigned (the Virtual Controller) shows "No Configuration", even if modules are assigned. After rebooting, the Virtual Controller is restored.

    Note:

    When renaming a Batch Historian workstation, you must synchronize the new DeltaV workstation name (changed using Workstation Configuration) and the SQL server name as shown in SQL Server Management Studio.
