Intrinsically Safe I/O Cards

The I/O subsystem supports the following types of Intrinsically Safe (I.S.) I/O cards:

  • I.S. AI, 8-Channel, 4-20 mA, HART
  • I.S. AO, 8-Channel, 4-20 mA and I.S. AO, 8-Channel, 4-20 mA, HART
  • I.S. DI, 16-Channel
  • I.S. DO, 4-Channel
