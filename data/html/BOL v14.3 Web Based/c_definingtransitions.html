Defining transitions

Between each step, you must place a transition. The transition defines when a recipe stops executing one step and starts executing the next step. The movement from one step to another is controlled by the Boolean condition of the transition. When the condition evaluates to the Boolean condition (either true or false):

  1. The step that follows the transition begins running.

  2. The preceding step stops running.

Transitions use the following syntax:

  • Value

  • Value operator value

where value is a constant or an identifier.

For example, the following conditions can be defined in a transition:

5

5 > 3

For more information about transition constants, identifiers and operations, refer to the Expressions topic.
