DeltaV Fiber Switches for P-Series

Specifications

The DeltaV system supports the Single Port Fiber Switch and the Four Port Fiber Switch. The Single Port Fiber Switch is an Ethernet switch with one 100BASE-FX port and four 10/100BASE-TX ports. The Four Port Fiber Switch is an Ethernet switch with four 100BASE-FX ports and one 10/100BASE-TX port. The switches can be mounted on a DIN rail and provide comprehensive LED diagnostics.

Single Port and Four Port Fiber Switch Specifications
Item Specification
Input voltage 24 VDC ±20%
Input current
  • 0.25 A for the Single Port Fiber Switch
  • 0.35 A for the Four Port Fiber Switch
Link budget
  • Multimode 62.5/125 µm - max attenuation 11 dB
  • Multimode 50/125 µm - max attenuation 8 dB
  • Wavelength 1300 nm
Fiber interface 100 BASE-FX with MT-RJ receptacle, full duplex only
Fiber type Refer to the "Setting up the DeltaV Control Network" topic.
Nominal fiber distance 2 km
Twisted pair ports 10/100 BASE-T, RJ45 compatible
Cable type Category 5e screened twisted pair (ScTP)
Mounting Vertically on a horizontal DIN rail
