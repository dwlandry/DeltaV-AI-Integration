Source linkage and Batch Historian administration

Within the DeltaV system, process history data and batch history data are collected and stored in different databases. However, the ability to view process trend and alarm and event data with respect to a batch is a common request. For example, when a batch report is generated, it is useful to have the report include trends, alarms, and other events that are relevant to that batch. Source Linkages are the key to creating this type of report. Source Linkages link data stored in the Continuous Historian database (process history) to data stored in the Batch Historian database (batch history) and are typically used by Batch Historian clients to retrieve process history data related to one or more batches.

Each Source Linkage defines a relationship between equipment used by a batch (such as a tank) and any modules used to control the process (such as a level indicator on the tank). Source Linkages allow users or applications to view how process history relates to batch history.

You can use Source Linkages to retrieve two types of process history data: alarm and event data and continuous (trend) data. Process alarm and event data can be stored in the Batch Historian database along with batch event data. To store alarm and event data in the Batch Historian database, configure the Batch Historian to use the alarms and events collected on a workstation as an input source. (Refer to The Batch Historian Properties topic for information on configuring the Batch Historian). Once the alarm and event data has been stored, use Source Linkages to retrieve the relevant alarms and events for any batch.

Continuous (trend) data is stored in a separate database from alarm and event data and batch data. Like alarm and event data, you can use Sources Linkages to retrieve the relevant continuous data for any batch.

Note:

Batch History View does not require Source Linkage data. The Process Trend, Process Events, or Process Trend Comparison menu option can be used to display data for any DeltaV module, regardless of whether or not a Source Linkage has been created for that module.
