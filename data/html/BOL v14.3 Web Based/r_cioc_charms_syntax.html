Combined CIOC and CHARMs syntax table

DeltaV includes a format specification file, named CharmIO.fmt, for the purpose of editing CHARM I/O configuration. You can create your own fmt file if you have specific requirements.

The fields available when you create a format file for combined CIOCs and CHARMs are shown in the following table.

16 characters or fewer. The string must contain at least one alphabetical character and can include letters, numbers and the following characters: $, -, and _.
