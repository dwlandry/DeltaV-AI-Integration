CHARMs Smart Logic Solver Carrier specifications

Installation notes

  • The CHARMs Smart Logic Solver Carrier installs on vertical T-type DIN rails.
  • Redundant CHARMs Smart Logic Solvers (CSLS) and redundant Power Modules plug into the slots on the CHARMs Smart Logic Solver Carrier. The CSLS and the Power Modules receive 24 VDC input power through the carrier. Refer to Powering the CHARMs Smart Logic Solver Carrier. The Power Modules generate 6.3 VDC power for the CHARMs.
  • The CHARMs Smart Logic Solver Carrier houses a primary and secondary Safety Network Port (SNP) for connections to the Local Safety Network. Each port has a port activity LED. The SNPs are removable. To remove a SNP, depress the button next to the SNP and push it out of the carrier.
  • A physical keylock switch on the CHARMs Smart Logic Solver Carrier along with an unlock software function restricts how and when the CSLS can be unlocked for downloads and upgrades.
