Recipe authorization

Recipe Authorization allows you to control recipe downloads to the Batch Executive. When recipe authorization is enabled, a recipe must be authorized before it can be downloaded. In the DeltaV system, a recipe is considered authorized when it has all of its required approval signatures. A signature consists of a signer's name, the signer's approval or rejection of the recipe, the time, and a comment. A signer is a person or group responsible for and capable of approving or rejecting a recipe. For example, a signer can be managers or supervisors. You can configure up to five signers in the DeltaV system.

Recipe authorization functionality resides within the DeltaV Version Control Audit Trail program. Version Control must be installed and enabled before you can use the recipe authorization function.

Before using the recipe authorization function you must grant keys to recipe authorization function locks and enable and set up recipe authorization.

Important Considerations about Recipe Authorization

There are a few things that you should know when recipe authorization is enabled:

General Considerations

  • Only users with the key to the VC_DOWNLOAD_UNAUTHORIZED function are permitted to download an unauthorized recipe.

  • Signers cannot reject a recipe that has been downloaded.

  • Disabling recipe authorization unauthorizes all recipes if recipe authorization is re-enabled at a later date.

  • When you add a new signer description, all previously authorized recipes are unauthorized until a new signer approves them.

  • When you delete a signer description, all unauthorized recipes that have approvals from all other remaining signers are automatically authorized.

Version Control Considerations

  • A recipe can be approved or rejected only when checked in to Version Control.

  • Recipe authorization is not a recipe editing function and does not effect the recipe version in Version Control.

  • When recipe authorization is enabled, rolling back a recipe version in Version Control unauthorizes the recipe.

  • When recipe authorization is enabled and a previously authorized recipe is deleted, recovering the purged version in Version Control authorizes the recipe.

  • When recipe authorization is enabled, recipes can be downloaded only when all the required recipe approvals have been signed and the recipe is checked in to Version Control.
