Region object

The Region object holds information that determines the rectangular region in a display frame.

Region object values

Value Description
.X

Relative to the display frame, the horizontal position of the upper-left corner rectangular region as measured from the left boundary of the display frame.

.Y

Relative to the display frame, the vertical position of the upper left-corner rectangular region as measured from the top boundary of the display frame.

.Width

The width of the rectangular region.

.Height

The height of the rectangular region.
