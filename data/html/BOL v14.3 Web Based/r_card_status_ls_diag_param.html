Card Status condition text

Condition Text in STATUS

Meaning

No Card

Card is not communicating with controller

Not Operational

Card is in reduced operational mode because a failure was detected during or immediately after powerup tests.

Subsystem Fault

One or more subsystems have a condition present that causes Bad OINTEG.

Cfg Mismatch with Controller

Controller sees mismatch between configured and reported DEV_CRC.

Unconfigured Unit

Controller has configuration for slot, but card has no configuration.

Termination Block Incorrectly Installed

Card is in even slot.

Good, No Installed Config

Controller has no configuration for the card slot.
