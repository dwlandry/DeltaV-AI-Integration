Languages overview

DeltaV Live supports the use of multiple languages (up to 12) for all configurable string content that appears in DeltaV Live display configuration and online displays. This language-specific content allows different operators to see the same DeltaV Live display, in the same DeltaV system, with their preferred language content. A languages container in the Library Explorer pane provides a means for you to access languages and add them to the configuration database. A language must be active to be used in the system and must be published to be available in DeltaV Live online. In Graphics Studio, you can use an active language to translate configurable content or to select it as the current display configuration language. DeltaV Live users can also switch the language in which to view content using the toolbar's View the Current Language button. All configurable content appears in the currently selected language.

Publishing languages

Languages must be published to deploy their updates online. The following changes are considered publishable changes:
  • Creating or deleting a language
  • Modifying a language's name, title, description, or decimal symbol
  • Changing the Active status of a language
Languages are published as a group rather than individually; therefore, any time you add, delete, or modify a language in the database, all languages are published. Additionally, publishing a language publishes only its properties, not its associated language-specific content. Language-specific content is published when the graphics configuration on which it is configured is published. Published languages are deployed to all DeltaV Live workstations.

Exporting and importing languages and language-specific strings

Each language can be individually exported and imported, but only its properties, such as Name and Title, are exported or imported with it. Its associated language-specific content is exported or imported with the graphics configuration on which it is configured. Additionally, languages are included in full configuration exports (and imports?).

When exporting a graphics configuration containing language-specific content, the properties of each associated language are implicitly exported with that graphics configuration. Then, when importing that graphics configuration to another DeltaV Live configuration database, any of the exported languages that do not exist (by Name) in that database are automatically added.

Note: Multi-language configuration is supported only in DeltaV Live applications.
