System Preferences

DeltaV System Preferences improve system use by allowing you to hide any non-required Engineering Tool functions. Disabling a function conceals the applicable menus and choices but does not remove the application. Any configuration that exists for a disabled function becomes inaccessible, but the data is retained in the database. If needed at a later date, you can re-enable the function.

If you uninstall DeltaV software and then install DeltaV software on the same computer, the system preference settings for your previous DeltaV installation are retained.

Enabling or disabling a feature is independent of licensing.

Options on the System Preferences dialog are arranged in the following groups.

  • General
    • Production System Warnings
    • Simulation Download
    • Signature Policies
  • DeltaV SIS
    • CHARMs Smart Logic Solvers
      • LSN Gateways
    • SLS1508 Logic Solvers
  • Batch Control
    • Batch
      • Advanced Unit Management
  • Networking
    • Zones
    • Smart Network Devices
    • Asset Optimization Alarms
    • Ethernet I/P Integration with Tags
  • I/O
    • AS-Interface
    • DeviceNet
    • Fieldbus
    • Profibus DP
    • PROVOX I/O
    • RS3 I/O
    • I/O Network
    • Wireless I/O
