The Batch Historian software

The Batch Historian software includes the Batch History View application, the Batch Historian Server, and the Batch Historian Administration Tool. The Batch Historian Server and the Batch Historian Administration Tool applications are installed separately from the standard DeltaV software to protect the Batch Historian from inadvertently being installed and run on a non-supported workstation. (Emerson supports the Batch Historian only when it is installed on an Application Station.)  The Batch History View application is installed with the DeltaV software. The Historian Administration Tool is installed with the Batch Historian server.

Note:

Emerson strongly recommends that the Batch Executive and Batch Historian not be installed on the same workstation.

Up to four Batch Historians can be enabled on a DeltaV system.

The Batch Historian requires Microsoft SQL Server Standard to be installed. If not already installed on the Batch Historian computer (can be accomplished as part of the DeltaV installation process), the Batch Historian Server installation will install it.
