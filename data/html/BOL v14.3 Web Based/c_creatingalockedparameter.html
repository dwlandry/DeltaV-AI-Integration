Creating a locked parameter

Locking a parameter makes that parameter's value unchangeable unless the operator has the BATCH_MODIFY_LOCKED_PARAMETER function key. The operator also needs the BATCH_MODIFY_PARAMETER function key to modify any parameter, including locked parameters, during the execution of the batch. 

Note:

BATCH_MODIFY_PARAMETER is not required during the creation of a batch.

Recipe parameter that can be locked are Process Input, Process Output, and Process Parameter categories.

Recipes with locked parameters that are used with a campaign or batch in a campaign also require the operator or the user identity creating the campaign have the BATCH_MODIFY_LOCKED_PARAMETER function key in order to make modifications to a locked parameter.

When confirmation is enabled, the locked parameter can be changed if the confirmer has the BATCH_MODIFY_LOCKED_PARAMETER function key (in addition to the BATCH_MODIFY_PARAMETER function key for changes made during the execution of the batch).

Only recipe parameters can be locked. A phase parameter cannot be locked and must be deferred to an operation parameter. The operation parameter can then be locked. 

When a recipe parameter is locked, the person acknowledging the operator prompt that modifies the locked recipe parameter must have the BATCH_MODIFY_LOCKED_PARAMETER function key.

When a locked parameter is deferred to another recipe's parameter, the locked status does not defer as well. This means it is possible to defer a parameter to an unlocked parameter at a higher level. If you want the parameter deferred to to also be locked, you must lock the parameter from that recipe.

Locked parameters are created by the following methods:

  • Selecting the Lock changes to this parameter during batch creation/runtime option on the parameter's Properties dialog. Changes to this property can be passed to a batch currently on the batch list by using Recipe Resynchronization.

  • From the Recipe Studio Parameter view, select the parameters to be locked, right click and select Lock (or Unlock).

  • From DeltaV Explorer List (or Details) view, select the parameters, right click and select Lock (or Unlock).
