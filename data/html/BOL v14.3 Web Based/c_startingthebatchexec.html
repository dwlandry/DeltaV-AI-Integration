Starting the Batch Executive

You must start the Batch Executive to execute recipes. However, before starting the Batch Executive you must:

  • Enable the Batch Executive with DeltaV Explorer.

  • Configure the Batch Executive properties in DeltaV Explorer.

  • Assign areas and recipes to the Batch Executive.

  • Download the Batch Executive configuration from DeltaV Explorer. When downloading the Batch Executive, the following functions are not available to the operator:

    • Adding a batch to the batch list.

    • Creating a manual phase batch.

    • Creating a campaign.

    • Releasing a batch.

The Batch Executive runs as a service on the workstation. This means the Batch Executive continues to run in the background even if the user logs off the workstation, provided the workstation is still running. The Windows operating system requires that the user have the Administrator privilege to start and stop a service.

Therefore, in order to start (or stop) a Batch Executive the user logging into the Windows operating system must have Windows Administrator privileges on that machine.

Additionally, the user logging into the DeltaV desktop must have the Batch_Control_Start and Batch_Control_Stop function locks. These functions are normally assigned to the Batch Operate lock, but can be reassigned.

Note:

The two users (Windows logged-on user and DeltaV desktop user) do not have to be the same. You can have one user log into the operating system and a different user logging into DeltaV, provided they have the correct privileges and keys.

To start Batch Executive, click Start > DeltaV Batch > Application Manager. In the Administer drop-down list, select the Batch Executive that you want to use, and then click the Start button.

Warning:

Starting and stopping a Batch Executive impacts all recipes that have been scheduled or are currently executing. The keys to the Batch_Control_Start and Batch_Control_Stop function locks should be tightly controlled.

To start a Batch Executive automatically when a workstation boots, go to Start > Settings > Control Panel > Administrative Tools > Services. Select and right-click the DeltaV Batch Manager, and then select Properties. On the Properties dialog, select Automatic (Delayed Start) as the Startup type, and then click OK.

CAUTION:

Do not change any other fields in this dialog. If you make any changes to the Log On as: fields, you will not be able to log on to this workstation again, and the Batch Executive will not start.
