Building graphics expressions

A graphics expression is a language-neutral, TypeScript expression that provides a means for the properties of graphics configurations and elements to reference either live data or values within the system and then resolve that information to a single value at the appropriate time in DeltaV Live online. The resulting value either presents itself to users as it is or presents the information in a more useful way, such as through animation. Online graphics update periodically to reflect the dynamic value determined by the expression's result.

Graphics expressions can be configured for any property that supports opening the Script Assistant and a browser window. You can build these expressions by entering the expression in the property field, browsing to the desired value, or using the Script Assistant.

Graphics expressions are built using the DeltaV Live-supported TypeScript operators, TypeScript-specific objects and their functions, DeltaV-specific objects and their functions, and DeltaV Live prefixes that allow you to reference various values.

These expressions are evaluated using data quality information available for DeltaV parameters. If the data quality for any DeltaV parameter value in the expression is anything other than good, the data quality for the final computed value reflects the worst data quality.
