OpenFaceplateAsync function

OpenFaceplateAsync() opens the faceplate display configured for the specified module, device, or node name (tag), optional additional context information, and optional initial placement rules.
Arguments
1–8, Optional arguments are indicated by a ? following the argument name.
Argument Description
tag A literal or graphics expression that resolves to the name of a DeltaV module, node, or device, if the faceplate's name configured for that module, node, or device matches the Name of a contextual display.
placement? A Placement object or array of Placement objects whose values define the initial placement of the faceplate's when it opens. The Placement objects override the default pop-up window placement rules.
context 1? A literal or graphics expression whose value is placed in the faceplate's Context 1 property immediately before starting to run in DeltaV Live. If a context 1? value is not present in the expression, the faceplate's Context 1 Default Value is used.
context 2? A literal or graphics expression whose value is placed in the faceplate's Context 2 property immediately before starting to run in DeltaV Live. If a context 2? value is not present, the faceplate's Context 2 Default Value is used.
context 3? context 1? A literal or graphics expression whose value is placed in the faceplate's Context 3 property immediately before starting to run in DeltaV Live. If a context 3? value is not present, the faceplate's Context 3 Default Value is used.
context 4? A literal or graphics expression whose value is placed in the faceplate's Context 4 property immediately before starting to run in DeltaV Live. If a context 4? value is not present, the faceplate's Context 4 Default Value is used.
X? A number indicating the X coordinates for the faceplate's trigger point.
Y? A number indicating the Y coordinates for the faceplate's trigger point.
Return values (Promise object, that when resolved, returns a Boolean)
True, if tag (case-insensitive) matches a running DeltaV module, node, or device name, AND the faceplate name (case-insensitive) configured for that DeltaV module, node, or device matches the name of a published contextual display available to be opened by this instance of DeltaV Live.
False, otherwise.
Syntax
DL.OpenFaceplateAsync(tag, placement?[], context1?, context2?, context3?, context4?, X?, Y?)
Examples
Example Result 
DL.OpenFaceplateAsync("FIC-101")
 Opens the faceplate configured for the FIC-101 module. 
DL.OpenFaceplateAsync(Dsp.Context, "true")
 Opens the faceplate configured for the ??? Context property and ??????. 
if (!await DL.OpenFaceplateAsync("FIC-101")) {
     // do something dealing with the display not being found
}
DL.OpenFaceplateAsync(Dsp.Context, null, "true")
Note: If faceplate displays use this function to open as pop-up windows in DeltaV Live, then when minimized, they appear in a group on a layout's menu bar. Detail displays and other contextual displays each appears in its own group in the menu bar.
