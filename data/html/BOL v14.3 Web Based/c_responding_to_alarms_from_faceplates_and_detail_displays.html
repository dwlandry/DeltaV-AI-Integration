Responding to alarms from faceplates and detail displays

This section describes the alarm information found on module faceplates and detail displays. Note, however, that these contextual displays are customizable and can differ from one plant to another.

Several options are available for opening contextual displays. The table below describes some of these options.
From... Do this
Alarm lists Select an alarm and click the Open Faceplate, Open Detail Display, or Open Primary Control Display button on the alarm list's menu bar.
Alarm lists Select an alarm, then right-click on it and select the appropriate option from the context menu.
Alarm banners Click the module alarm button to open the faceplate and, if configured, the primary control display for the module.
Displays containing the module where the alarm was tripped Click a datalink to open a faceplate or detail display. (This action is dependent on the datalink being configured to do so.)
Faceplate Click the Detail Display button to open the detail display from that module.

Alarms are presented somewhat differently on analog module faceplates than on discrete module faceplates.

Alarm indications
Provides a scrollable list of the current alarms. This list functions like the first two columns of an Alarm Summary. The first column shows the state of the alarm represented by one of the following symbols:

  • Active/unacked -- blank field

  • Active/acked -- checkmark

  • Inactive/unacked -- empty box

The second column shows the alarm name or parameter. The text and colors are as configured for the alarm's current state.
Acknowledge This Point Only button
Click the rightmost button on the faceplate to acknowledge all the alarms for this point only. The alarm stops blinking when it is acknowledged. (Remember that on an alarm banner, this button acknowledges all alarms in the main picture.)
Alarm Trip Value
Appears as a small arrowhead in the color of the alarm priority. The arrowhead points to the alarm trip value on the PV (process variable) bar graph. For high alarms, a PV above the trip value activates the alarm; for low alarms, a PV below the trip value activates the alarm.

Discrete module faceplates

A discrete module faceplate has only one alarm indicator, labeled DA for discrete alarm. Discrete modules have no associated detail display; rather, the parameters typically found on a detail display are included on the module. The following image shows a sample of a discrete module faceplate:

Device alarm faceplates

Fieldbus devices that support PlantWeb alerts have a faceplate that allows the user to suppress the alarms for the device and set the priority for each alarm. For more information, see the topic on suppressing alarms.

Asset optimization alarm faceplates

Optimization assets and external mechanical assets that support PlantWeb alerts have a faceplate that allows the user to suppress the alarms for the asset. For more information, see the topic on suppressing alarms.
