MPCPro Controlled Variable function block faceplate (MPCPROOUTPUT_FP)

DeltaV Operate View of the MPCPro Controlled Variable Faceplate

A red border around the faceplate indicates this required output is disabled or has failed; a yellow border indicates a fail condition exists but the configured fail action is for no action (not required) or simulate. A green border indicates that a remote setpoint is configured and the block is in RCAS mode.

The following items are found on the MPCPro Controlled variable function block faceplate:

  • Controlled Variable – This field displays the PROC_OUTn value of the MPCPro module in yellow. The background color of the 3-D box changes from gray to orange or red when the status becomes uncertain or bad, respectively. The background blinks red when the CV Bad Alarm is unacknowledged. The PROC_OUTn value is visible in the decimal format provided by SCALE_ATTR_OUTn.DECPT.

  • Units – This area provides the engineering units description used for the Controlled Variable as defined in the SCALE_ATTR_OUTn.UNITS parameter.

  • EU 100 – This value corresponds to 100% of scale for the Controlled Variable.

  • Target Mode – This field contains a word in white text that describes the target mode for the loop. The background changes to blue when the target mode and normal mode are different.

  • Actual Mode – This field contains a word in yellow text that describes the ACTUAL mode of the loop. The background changes to blue when the actual mode and normal mode are different.

  • Setpoint Limits  – These arrowheads are vertically positioned relative to the bar graph to indicate the High and Low SP Limits. Although these arrows cannot be dragged with the mouse, the values they indicate can be modified by using the detail display.

  • Setpoint slider  – To move this button, hold down the left mouse button while the cursor is over the arrowhead and then move the mouse up or down to correspond to the new SP (setpoint) value desired. The new value is then written to the SPn parameter of the MPCPro block. The arrowhead is controllable only when the target mode is AUTO or MAN with setpoint tracking disabled.

  • Setpoint Entry – The Setpoint Entry is the 3-D recessed box displaying the SPn value of the nth Controlled Variable in the MPCPro block. The Setpoint Entry box is next to the Setpoint slider. The background color of this box changes to orange or red when the PROC_OUTn status becomes uncertain or bad, respectively. Double-clicking this box while the target mode is AUTO or MAN produces a dialog that prompts you for an SP (Setpoint) value. The valid range for input is defined by the engineering unit EU 0 and EU 100 values of SCALE_ATTR_OUTn. Valid input ranges from -10 percent to 100 percent of PROC_OUTn scale. The SP value is visible in the decimal format provided by SCALE_ATTR_OUTn.DECPT.

  • Working Setpoint – Another arrowhead with the same size and movement range as the Setpoint slider but with a transparent fill color and a black border indicates the Working Setpoint (SP_WRKn) of the nth Controlled Variable in the MPCPro block. This arrow's movement range is restricted within the Setpoint Limit arrows and is the actual SP used by the controller to calculate output moves. When SPn and SP_WRKn have the same value, SP_WRKn is superimposed upon SPn and, therefore, is not distinguishable from SPn. The Working Setpoint is visible as a separate entity when setpoint ramping prevents SP_WRKn from going to SPn immediately.

  • Tick marks – Use this vertical arrangement of black lines to indicate percentages of PROC_OUTn.

  • Controlled Variable bar graph - This field indicates the value of the PROC_OUTn parameter for the MPC block, which is the same as the value displayed in the Controlled Variable display box.

  • EU 0 – This value corresponds to 0% of scale for the CV.

  • Connected block mode – This field displays the actual mode of the connected block.

  • Disable button - Disables or enables this output during control.

  • Detail picture button – Opens the Detail picture for the module.

  • MPC Operate Pro button – Opens the MPC Operate Pro application for the block.

  • MPCDiagnostics button –  Opens the MPCDiagnostics application for the block.

  • Limit Information - This field displays a word in yellow text representing the SPWRK_ACT[n] value of the MPCPr block. The background color of the 3-D box changes from gray to blue when the SPWRK_ACT[n] value is non-zero. The text displayed represents the following values:

    Text

    0.0

    Not Limited

    1.0

    Low Limited

    2.0

    High Limited
