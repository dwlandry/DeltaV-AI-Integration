MA1_N_ analog dynamo, 1 function block, no bar graph

This dynamo can be used for loop indication of PID loops where the data value is of key importance and the percentage of scale is not.

The following elements are present on the dynamo:

  • Alarm Box

  • Alarm Icon

  • Display Tag

  • Dynamo Background

  • Engineering Units Descriptor

  • Mode Icon

  • OUT Bar Graph

  • PV and SP Data Fields

  • Ramp Status Icon

  • Status Box

  • Status Icon
