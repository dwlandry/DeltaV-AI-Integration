Advanced Smart Switch troubleshooting

In addition to the Smart Switch information available from the Network Device Command Center, you can use the command line interface show commands in this section to troubleshoot system health information about the DeltaV Network Smart Switches and their network connections. This information is also available using the Web interface to the switches. The commands can be used on FP20, MD20, MD30, RM100, and RM104 DeltaV Network Smart Switches.

Use these commands from a terminal that is directly connected to the serial port of the switch or from a Telnet session connected to the switch after logging in using the username and password of admin and Emerson1 respectively. We suggest you use the Telnet connection for using these commands and not the serial connection as it is much easier.

Typically you will only access these commands on instructions from Emerson to help troubleshoot network problems.

These commands provide read only access to the switch information and cannot change the configuration of the switch.
